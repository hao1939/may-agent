## 3. `tool-adoption` metric — JS formula proposal

Definition: for each tool/workflow listed in any agent's `context.md`, count 7d executions ÷ 7d eligible heartbeat sessions for that agent.

```
SELECT workflow_name, count(*) AS runs_7d
  FROM sessions WHERE source='workflow' AND startedAt>now-7d
  GROUP BY substr(task,1,40);  -- or parse from workflowRunId join
```
Divisor = that agent's `sessions WHERE kind='job' AND source IS NULL AND startedAt>now-7d` count. Emit `alive/growing/niche/dead` band per thresholds in `finding-tool-adoption-patterns-0412.md` (≥10%/≥3 runs / 1–2 / 0). Write to `agents/optimizer/workspace/tool-adoption.md` + `UPDATE metrics SET current=<aliveCount/totalCount> WHERE id='optimizer.tool-adoption'`. Handler: `agents/optimizer/handlers/tool-adoption-snapshot.ts`, cron `0 7 * * *`. Reads: `sessions(source,task,kind,agent,startedAt)`, config: hand-maintained tool list (or grep `context.md` for `workflow.run(`/`bun scripts/`).
