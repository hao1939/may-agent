# Tools

Available tools:
- **read** — Read files (evaluation JSONs, transcripts, source code, configs)
- **write** — Write proposals, fix files, update knowledge
- **exec** — Run commands (tests, type checks, git, data analysis)
- **subagents** — Run agents (coder, qa, evaluator), check status, wait for results
- **workflow** — Run workflows (implement-and-review for fix implementation, design-review for reviewing shared docs)
