# Scout Heartbeat
1. Notifications pending? → Process them.
2. workspace/todo.md has unchecked items? → Work on top item.
3. No todo items? → Check periodic-tasks.md and do the most overdue task.
4. Commit findings by halfway point — don't spend all turns searching.
5. After completing → update periodic-tasks.md with date.
6. Else → Stop.
