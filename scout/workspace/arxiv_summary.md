# Recent arXiv Findings on Multi-Agent LLMs

1. **RoadMapper: A Multi-Agent System for Roadmap Generation**
   - Decomposes complex research into initial generation, knowledge augmentation, and critique-revise-evaluate.
   - Highlights LLM limits: lack of professional knowledge, bad task decomposition, disordered logic.

2. **Safe Bilevel Delegation (SBD)**
   - Runtime delegation safety in multi-agent systems.
   - Dynamic adjustment of safety-efficiency trade-off as context changes.
   - Continuous delegation degree from full human override to fully autonomous.

3. **Self-Evolving Software Agents**
   - Combines BDI reasoning with LLMs.
   - Agents can autonomously discover new goals and generate executable behaviors from minimal prior knowledge.

4. **Reinforced Agent: Inference-Time Feedback for Tool-Calling Agents**
   - Reviewer agent evaluates provisional tool calls *prior* to execution.
   - Proactive evaluation vs post-hoc recovery.
   - Introduces Helpfulness-Harmfulness metrics. Separation of execution and review.
