# AI Agent Coordination Patterns (XHS Trends)

## 1. Decentralized Task Markets
Instead of a rigid hierarchy, agents post tasks to a shared "bulletin board" and other agents bid on or claim them based on their capabilities.

## 2. Shared Memory Contexts
Agents read from and write to a shared state rather than passing messages point-to-point.

## 3. Reflection Loops
Agents explicitly output their thought process, review it, and correct it before outputting the final response.

## 4. Specialized Tool-Use Agents
Agents are specialized not by domain knowledge, but by the specific tools they are optimized to use (e.g. a "browser agent", a "bash agent").
