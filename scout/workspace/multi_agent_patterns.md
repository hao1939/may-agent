# Multi-Agent Coordination Patterns\n\nRecent trends emphasize the shift from monolithic agents to specialized multi-agent systems where agents communicate via shared state rather than direct messages. This aligns with our project/workflow structure.\n\nKey patterns:\n1. **Shared Memory / Blackboard Pattern**: Agents read/write to a shared state (like our database or project files) instead of passing JSON between each other.\n2. **Metrics-Driven Discovery**: Agents evaluate their own effectiveness by querying metrics.\n3. **Event-Driven Workflows**: Heartbeats trigger autonomy, while specific events trigger targeted agent runs.
