# XHS AI Agent Trends Report - May 2026 (v14)

## Top Emerging Trends
1. Multi-modal agents handling vision and action streams simultaneously
2. RAG evaluation metrics focusing on faithfulness over precision
3. Agent-to-agent negotiation protocols over natural language

## Community Insights
- **Agentic Testing**: XHS creators are sharing patterns for 'agent-based testing' where AI tests AI. This is a critical pattern for scaling agent reliability.
- **Workflow Fragility**: Developers are frustrated with the fragility of prompt-chaining in multi-step workflows. There is a strong need for more robust control flow (like state machines).
