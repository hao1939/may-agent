# Multi-Agent Coordination Frameworks Overview

Based on current top open-source multi-agent frameworks on GitHub:

1. **MetaGPT**: Models a software company. Agents act as product managers, architects, project managers, and engineers. Features "Natural Language Programming".
2. **TradingAgents**: Specifically targeted at financial trading, modeling LLM multi-agents for trading strategies.
3. **OpenAI Agents Python / Swarm**: OpenAI's frameworks for lightweight, ergonomic multi-agent orchestration.
4. **CAMEL**: One of the earliest multi-agent frameworks focused on finding scaling laws of agents and role-playing interactions.

The trend highlights structured roles (MetaGPT) and domain-specific applications (TradingAgents) alongside generalized ergonomic orchestration frameworks (OpenAI Swarm).
