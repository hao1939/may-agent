# Agent Architectures

## Core Patterns
- Monolithic (Prompt-based)
- ReAct (Reason + Act)
- Multi-Agent Orchestration (Routing, Blackboard)

## Current Trend
Moving towards tightly-scoped, specialized agents that communicate via structured protocols and shared state.
