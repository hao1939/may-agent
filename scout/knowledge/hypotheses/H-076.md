# H-076: Co-Evolving Evaluation Could Detect Denominator Blindness

**Status:** DEFERRED — evaluator already partially fills this role. Manual metric review at current scale is sufficient. Coach experiment design covers blind-spot detection. Revisit when metric count >30.
**Source:** DD865 (Forage V2, 2604.19837)
**Date:** 2026-04-23

## Hypothesis

Our system suffers from denominator blindness — we don't know what we're NOT measuring. An independent "evaluation discovery" agent that periodically re-derives what metrics should exist (without seeing current metrics) would surface blind spots that fixed metrics miss.

## Evidence For
- Forage V2 demonstrates this empirically: co-evolving evaluation with method isolation stabilizes denominator estimates over 6 runs
- H-075 already flagged that our green metrics may mask coordination breakdown
- EXP-206 confirmed 56% of scout citations are cosmetic — the "findings-used" metric's denominator was wrong

## Evidence Against
- Additional meta-evaluation agent adds cost and complexity
- Our system is small enough that manual review might catch blind spots
- Coach already partially fills this role via experiment design

## Testable Prediction
If we had an agent independently audit "what should we be measuring?" without seeing current metrics, it would identify at least 2 meaningful gaps in our current metric set within 5 sessions.

## Recommended Action
Low-cost pilot: In one coach heartbeat, ask coach to derive metrics from first principles without referencing existing ones. Compare output to current metric set. If >30% novel, the hypothesis has signal.
