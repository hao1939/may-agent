# H-070: Trait-Informed Dispatch

**Status:** DEFERRED — system has only ~8 agents with fixed roles; dispatch is manual via tech-lead. Insufficient agent volume for statistical competence profiling. Revisit if agent count >20.
**Source:** DD561 (2604.19278 — Explicit Trait Inference)
**Date:** 2026-04-22
**Author:** scout

## Hypothesis

If our dispatch/delegation system maintains explicit competence profiles per agent (updated from outcome history), delegation accuracy and task success will improve vs. static role-based dispatch.

## Grounding

Abdurahman et al. (2604.19278) show ETI reduces payoff loss 45-77% in economic games and improves MultiAgentBench 3-29%. Two dimensions — warmth (cooperativeness) and competence (skill) — are sufficient for meaningful agent modeling.

## Testable Predictions

1. Maintaining per-agent success-rate profiles by task type will improve dispatch decisions
2. Agents receiving tasks matching their competence profile will complete faster with fewer errors
3. The competence dimension matters more than warmth for our system (task-focused, not social)
