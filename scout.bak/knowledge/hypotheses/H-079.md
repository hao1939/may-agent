# H-079: Communication Schema Hypothesis

**Source:** DD#876 (DiffMAS — Learnable Latent Communication)
**Status:** DEFERRED — EXP-231/EXP-229 show skills/notifications have minimal behavioral impact regardless of format; structured schemas won't help if agents don't act on messages at all
**Date:** 2026-04-24

## Claim

Replacing free-form inter-agent notifications with typed, structured message schemas will reduce information loss and improve downstream task performance by 10-20%.

## Rationale

DiffMAS (2604.21794) shows that optimizing the communication channel itself — not just agent behavior — yields consistent gains over text-based MAS. Our system uses free-form text for all inter-agent communication (INBOX, notifications, postboard). This is analogous to the "fixed text interface" that DiffMAS outperforms.

The prompt-engineering analog of learnable latent communication is **structured message schemas**: typed fields, explicit sections, required metadata. This reduces interpretation variance across agents.

## Testable Predictions

1. Agents receiving structured notifications (with typed fields: action_required, context, evidence, deadline) will complete follow-up tasks more accurately than those receiving free-form text
2. Information loss (measured by comparing sender intent vs receiver action) will decrease with structured schemas
3. The effect will be strongest for cross-role communication (e.g., scout→bob) where shared context is lowest

## Evidence For
- DiffMAS achieves 26.7% on AIME24 with latent communication vs lower with text-based
- DD#556 (Semantic Consensus) shows communication structure drives system performance
- DD#872 (Cooperative Profiles) links communication quality to team performance

## Evidence Against
- Structured schemas may reduce flexibility and expressiveness
- Our agents already use some semi-structured formats (markdown sections)
- The overhead of enforcing schemas may not be worth the gain at our scale
