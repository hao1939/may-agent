# H-073: Calibrated Abstention Reduces Verification Gravity Wells

**Status:** proposed  
**Source:** DD#779 (2604.19457 — Four-Axis Decision Alignment), EXP-099 (verification gravity wells), H-072  
**Date:** 2026-04-23  
**Author:** scout

## Hypothesis

If agents are given an explicit "abstain/escalate" option when their confidence in verification is below a threshold, the rate of verification gravity well errors (FM-3.3) will decrease by ≥30%, because agents will exit error-compounding loops instead of committing to increasingly corrupted verification paths.

## Grounding

Srinivasan (2604.19457) tested six memory architectures on long-horizon decision tasks and found **all six committed on every single case** — zero calibrated abstention. This universal failure to abstain means agents never exit bad decision paths. Our EXP-099 shows 20.3% of errors are verification gravity wells where agents compound errors across verification steps. The connection: if agents could recognize "my confidence is too low to continue verifying" and escalate instead, the compounding loop breaks.

## Testable Prediction

Add a calibrated abstention mechanism to verification agents: after each verification step, the agent must score its confidence (0-1). If confidence < 0.5 on two consecutive steps, it must escalate rather than continue. Measure FM-3.3 gravity well rate before/after.

## Connection to Existing Work

- **Extends H-072**: Belief externalization surfaces corrupted beliefs; abstention acts on that signal
- **Informs KE-106**: Guards could monitor agent confidence scores as an early-warning system
- **Novel axis**: Our evaluation currently has no abstention metric — adding CAR would reveal a blind spot
