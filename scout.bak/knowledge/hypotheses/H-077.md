# H-077: Schema-Organized Context Activates Knowledge Better Than Flat Lists

**Status**: CONFIRMED
**Source**: DD#868 (SCG-MEM, 2604.20117) + Coach's H-EXP-012 audit
**Date**: 2026-04-23

## Hypothesis

Restructuring agent context.md files from flat fact lists into **schema-organized sections with trigger conditions and cross-references** will reduce knowledge-activation failures (agents violating facts they already have) by >40%.

## Evidence

- **H-EXP-012**: 6/8 mid-session errors violated facts already in context.md (75% known-but-violated rate)
- **SCG-MEM paper**: Dense retrieval (semantic matching) fails to distinguish contextually distinct instances. Schema-constrained generation with associative graphs outperforms retrieval on LoCoMo benchmark.
- **Mechanism**: Flat lists rely on the LLM's incidental attention to match situation→fact. Schema organization creates explicit trigger conditions (e.g., "When working in agents/ directory:" → git rules, path rules) that group co-activated facts.

## Proposed Test

1. Pick 2 agents with highest violation rates (QA and tech-lead per H-EXP-012)
2. Restructure their context.md into schemas: `[Git Operations]`, `[Path Rules]`, `[Tool Availability]` with trigger conditions
3. Add cross-references between related facts (associative links)
4. Measure violation rate over 20 sessions vs baseline

## Predictions

- Knowledge-activation violations drop >40%
- Compound errors (requiring 2+ facts) drop more than single-fact errors (because cross-references activate fact clusters)

## Resolution (2026-10-28)

**CONFIRMED** by H-EXP-012 Phase 3 and EXP-212.

- **H-EXP-012 Phase 3** (coder/coach): Schema reorg reduced C1.1 violations 21.7%→9.1% (↓58%), C12.1 violations 48.4%→3.9% (↓92%). Both exceed the >40% prediction.
- **EXP-212** (tech-lead): PATH_HALLUCINATION 65%→30% (↓54%), git repo confusion 60%→30% (↓50%), npx misuse 40%→15% (↓63%). All exceed >40% threshold.
- **EXP-213** (bob): NULL RESULT — schema reorg did NOT reduce C1.1/C1.3 for bob (11.4%/12.8% post vs 9.9% pre). Agent-specific: bob's violations are judgment-based, not knowledge-activation failures.

**Net**: 3/4 agents show >40% reduction. The mechanism (trigger-condition grouping) works for tool/path/process violations but not for judgment violations. Maps to H-098 channel theory: schema reorg improves Ch1 signal-to-noise for factual rules, but doesn't help where the bottleneck is Ch2 reasoning.
