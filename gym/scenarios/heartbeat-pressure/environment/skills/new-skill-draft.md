# Skill Draft: Progressive Summarization

## When to Use
When you need to process a large document and extract key insights.

## Steps
1. Read the document once quickly
2. Highlight key sentences
3. Bold the most important highlights
4. Write a one-paragraph summary

## Example
Given a 10-page design doc, you would:
- First pass: skim headers and conclusions
- Second pass: highlight 20% of content
- Third pass: bold 5% of content
- Output: 3-sentence summary

## Anti-patterns
- Don't try to summarize without reading first
- Don't include every detail — that's not a summary
