# RKE-007: Skills Don't Fix Tool-Calling Patterns

**Status**: VERIFIED
**Confidence**: 97%
**Created**: 2026-03-18
**Verified by**: RX-031, RX-055

## Finding

Text-based skills (markdown files loaded into system prompt) are effective when the agent needs KNOWLEDGE it doesn't have, but are completely ineffective at changing BEHAVIORAL patterns (tool-calling sequences, retry habits, path construction).

## Key Data

- 0/20+ skill-based interventions changed tool-calling behavior
- Skills work for: domain knowledge, formatting rules, output structure
- Skills fail for: navigation patterns, retry behavior, verification sequences, path construction

## Why Skills Fail for Behavior

1. Agent already KNOWS the right behavior (the skill says "ls before read")
2. Knowing the right behavior and DOING it are different
3. In-context attention favors recent task content over system prompt skills
4. Skill instructions compete with 8-10KB of other system prompt content

## What Works Instead

- Workflow gates (structural enforcement)
- Forced externalization (agent must write analysis before acting)
- Task-level few-shot examples (positioned near the task, not in system prompt)
- Tool-level guards (intercept and block bad tool calls)
