# RH-048: Few-Shot Position Determines Effectiveness

**Status**: ACTIVE
**Priority**: MEDIUM
**Created**: 2026-03-28
**Last Updated**: 2026-04-05

## Claim

The position of few-shot examples in the agent's context (task-level message vs system prompt) is the dominant factor in determining whether the agent follows the demonstrated pattern. Content quality is necessary but not sufficient.

## Evidence

- **RX-031**: Indirect — workflow enforcement (structural position) > SOUL text (system prompt position)
- **RKE-015**: Task-level few-shot outperforms system prompt delivery 100% vs 0% (12+ runs)

## Tests In Progress

- RX-055: Tests whether skill trigger scope matters (a sub-question of position)

## Predictions

If H-048 is correct:
1. Moving any behavioral guidance from system prompt → task message will improve effectiveness
2. The content of the guidance matters less than its position relative to the task
3. System prompt few-shot will consistently underperform task-level delivery

## Connection to H-044

H-048 is a refinement of H-044. H-044 says structural > text. H-048 specifies that "position" (a structural property) is the mechanism. Text content in the right position can work; text content in the wrong position cannot.
