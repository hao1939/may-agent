# RH-044: Structural Interventions Are Necessary for Tool-Calling Pattern Changes

**Status**: ACTIVE
**Priority**: HIGH
**Created**: 2026-03-15
**Last Updated**: 2026-04-01

## Claim

Text-based interventions (SOUL.md changes, skill files, context.md hints) cannot change agent tool-calling patterns. Only structural interventions (workflow gates, guards, forced phases) reliably modify tool-calling behavior.

## Evidence

- **RX-031**: SOUL text changes showed 0/18 improvement on sycophancy. Workflow enforcement achieved 100% (15/15). See `experiments/RX-031/results.md`.
- **RKE-003**: Verified finding — structural enforcement outperforms text rules by +74pp on average.
- **RKE-007**: Skills don't fix tool-calling patterns (0/20+ attempts).

## Tests In Progress

- RX-055: Testing skill generalization (whether broadening skill triggers changes behavior)
- RX-058: Production observation to find new structural intervention targets

## Predictions

If H-044 is correct:
1. RX-055 (skill generalization) will show ≤33% improvement despite better skill content
2. RX-058 will identify new tool-calling failures that only structural interventions can fix
3. Any new text-based intervention will fail on tool-calling behavior

## Open Questions

- Is there a hybrid approach? (text instruction + structural nudge)
- Do tool-level guards count as "structural" or are they a separate category?
