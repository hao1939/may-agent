Agents with different capabilities negotiate task assignments using a market-based mechanism. Tested on warehouse logistics and software development scenarios.

New batch norm variant reduces training instability in ViTs. Achieves 0.3% accuracy improvement on ImageNet.

## 3. "Self-Monitoring Agents: Detecting Own Capability Boundaries"
Framework for agents to recognize when they're operating outside their competence and should escalate. Uses calibrated confidence estimation.

## 4. "Protein Folding Prediction with Graph Neural Networks"
Novel GNN architecture for protein structure prediction. Achieves state-of-art on CASP15 targets.

## 5. "Adversarial Prompt Injection Through Tool Outputs"
Demonstrates that tool outputs can contain hidden instructions that hijack agent behavior. Proposes sanitization layer.

## 6. "Efficient KV-Cache Compression for Long Contexts"
Compression technique reduces KV-cache memory by 60% with minimal quality loss. Tested on 128K context windows.

## 7. "Learning to Forget: Selective Memory Erasure in Agent Systems"
Mechanism for agents to identify and remove outdated or harmful memories. Prevents stale information from degrading decisions.

## 8. "Weather Prediction Using Foundation Models"
Applies transformer-based foundation models to numerical weather prediction. Outperforms ECMWF HRES on 3-day forecasts.

## 9. "Context Contamination in Multi-Session Agents: Detection and Prevention"
Identifies how incorrect information persisted across sessions spreads to corrupt future task performance. Proposes contamination boundaries.

## 10. "A New Loss Function for Text Classification"

## 11. "Automated Research Pipeline: From Paper Discovery to Knowledge Integration"
End-to-end system that discovers relevant papers, extracts key findings, and integrates them into a structured knowledge base. Includes evaluation against human researchers.

## 12. "Optimizing GPU Memory for Large Language Model Training"
