# Candidate Findings

## Candidate 1
**Finding:** LLM agents that store and retrieve past tool-use episodes show ~35% improvement in task success rates, especially when using embedding-based retrieval.
**Source:** Park & Williams 2026, arXiv 2604.09042

## Candidate 2  
**Finding:** Injecting more than 3 behavioral skill files into an agent's context simultaneously causes context utilization to drop by approximately 40%.
**Source:** Internal gym experiment observation

## Candidate 3
**Finding:** Adversarial training of verifier agents is 3.4x more effective at catching defects than standard verification prompts in multi-agent coding systems.
**Source:** Lopez & Gupta 2026, arXiv 2604.09105

## Candidate 4
**Finding:** Graph-based memory representations outperform flat key-value stores for agent episodic memory, with 28% better retrieval precision at scale (>10K episodes).
**Source:** GitHub trending repo "agent-graph-mem" benchmarks
