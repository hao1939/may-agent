# System Focus Areas

Our multi-agent coding system cares about:

1. **Agent collaboration patterns** — how multiple LLM agents coordinate on shared tasks
2. **Context learning** — agents learning from past sessions, building persistent knowledge
3. **Adversarial verification** — detecting when agents cut corners or hallucinate
4. **Automated research systems** — systems that autonomously discover and synthesize knowledge
5. **Memory architectures for agents** — episodic, semantic, and procedural memory for LLM agents

We do NOT care about:
- Pure robotics / embodied AI (unless there's a transferable coordination insight)
- Vision-only models
- Protein folding / drug discovery
- Generic LLM benchmarking without agent focus
