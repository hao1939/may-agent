# RKE-003: Structural Enforcement Outperforms Text Rules

**Status**: VERIFIED
**Confidence**: 99%
**Created**: 2026-03-10
**Verified by**: RX-031, RX-044

## Finding

Structural interventions (workflow gates, guards, forced phases) achieve +74pp average improvement over text-based rules (SOUL.md changes, skill files) for changing agent behavior. Text rules achieve 0% effectiveness on tool-calling patterns (0/20+ experiments).

## Key Data

| Approach | Pass Rate | N | Effect |
|----------|-----------|---|--------|
| Text rules (SOUL.md) | 0% | 20+ experiments | Baseline |
| Workflow enforcement | 100% | 15/15 runs | +100pp |
| Forced externalization | 74% avg | 19/19 across 7 scenarios | +74pp |
| Skill files (system prompt) | 0% | 0/18 on sycophancy | No effect |

## Mechanism

Text rules fail because:
1. System prompt dilution — buried among 8-10KB of other instructions
2. Knowing ≠ doing — agent KNOWS the right behavior but can't stop itself
3. No enforcement — agent CAN skip the instruction

Structural interventions succeed because:
1. Agent CANNOT skip a workflow phase
2. Phase separation creates mechanical barriers to bad behavior
3. Forced output (externalization) activates analysis before action
