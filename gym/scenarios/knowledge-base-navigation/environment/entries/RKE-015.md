# RKE-015: Task-Level Few-Shot Outperforms System Prompt Delivery

**Status**: PENDING VERIFICATION
**Confidence**: 90%
**Created**: 2026-04-02
**Needs**: Replication on non-behavioral tasks

## Finding

Few-shot examples placed in the task-level message achieve 100% effectiveness, while identical examples placed in the system prompt achieve 0%. The position of examples relative to the task is the dominant factor, not content quality.

## Key Data

| Position | Pass Rate | N |
|----------|-----------|---|
| Task message | 100% | 12/12 |
| System prompt (skill) | 0% | 0/12 |
| Injected context (task prefix) | 100% | 6/6 |

## Why Position Matters

1. **Attention proximity**: Task-level examples are processed alongside the task description
2. **Pattern activation**: "I just saw someone handle this — let me do the same"
3. **No dilution**: Task message isn't competing with 8KB of other instructions
4. **Frame setting**: Examples set HOW to approach this specific task
