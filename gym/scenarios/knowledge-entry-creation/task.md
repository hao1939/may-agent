Create a new knowledge entry from experiment results.

You have experiment results in `data/experiment-results.md`. Create a knowledge entry following the format below.

1. **Read** `data/experiment-results.md` to understand the finding
2. **Create** `knowledge/entries/KE-042.md` using the format shown below, populated with the experiment findings
3. **Verify** the new file exists and contains all required sections

## Required Format for KE-042.md

```markdown
# KE-042: [Title]

## Summary
[One-line summary of the finding]

## Evidence
[Data supporting the finding — experiment IDs, metrics, sample sizes]

## Recommendation
[Actionable recommendation based on the evidence]

## Tags
[Comma-separated tags: e.g., workflow, timeout, cost]
```

Required sections: Title, Summary, Evidence, Recommendation, Tags
