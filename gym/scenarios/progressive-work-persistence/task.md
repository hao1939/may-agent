## Instructions

For **each** module (`auth.js`, `cache.js`, `billing.js`):

1. Read the module source code
2. Read its corresponding test file (`auth.test.js`, `cache.test.js`, `billing.test.js`)
3. Run the tests: `node <test-file>` to see current status
4. Write a detailed analysis report to `analysis-<module>.md` containing:
   - **Summary**: What the module does (2-3 sentences)
   - **Bugs Found**: List any bugs with line numbers and descriptions
   - **Test Coverage Gaps**: What edge cases aren't tested
   - **Recommendations**: Suggested improvements

You must produce exactly 3 files: `analysis-auth.md`, `analysis-cache.md`, `analysis-billing.md`.

**Important**: Write each analysis file as soon as you complete it — don't wait until you've analyzed all 3 modules to start writing. Each analysis stands alone.
