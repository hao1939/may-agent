## ⚠️ VERIFICATION REQUIREMENT (System Rule)

**You MUST verify your changes before calling finish(status='success').**

After making any code changes:
1. Run the test suite (`node test-string-utils.js`) to confirm all tests pass
2. Read back the modified file to confirm your edit is correct
3. Only then call finish(status='success')

Calling finish(success) without post-write verification is a process violation.
If you skip verification, your work will be scored as incomplete regardless of code correctness.
