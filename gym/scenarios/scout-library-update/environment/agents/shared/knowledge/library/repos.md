# Repository Discoveries

Repos found during research. Format: bullet list with metadata.

## Active Repos

- **context-pilot** (https://github.com/ai-tools/context-pilot) ⭐ 4.8k
  - Automatic context window management for LLM agents
  - Uses sliding-window + importance scoring to keep relevant context
  - *Relevance*: Their importance scoring could inform our context.md pruning strategy
  - Added: 2026-03-25

- **multi-agent-debate** (https://github.com/research-group/multi-agent-debate) ⭐ 1.3k
  - Framework for structured debate between LLM agents
  - Agents argue opposing positions, judge agent picks winner
  - *Relevance*: Adversarial verification pattern — similar to QA's role in our system
  - Added: 2026-03-29

- **tool-learning-bench** (https://github.com/benchmarks/tool-learning-bench) ⭐ 890
  - Benchmark suite for evaluating LLM tool-use capabilities
  - 200+ scenarios across file ops, web, code, data analysis
  - *Relevance*: Could adapt scenarios for our gym system
  - Added: 2026-04-02
