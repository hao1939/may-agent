# Tech-Lead Proposals

Proposals for code changes, simplifications, and bug fixes.

When tech-lead identifies a production issue or improvement, they write a brief here and send it to Bob for architectural review.

## Template

```
# Proposal: [Short Title]
Date: YYYY-MM-DD

## Problem
[What's broken or suboptimal? Cite production data.]

## Proposed Change
[What you want to do. Be specific — file paths, approach.]

## Risk
[What could go wrong? What does this touch?]

## Evidence
[Metrics, error logs, code analysis.]
```
