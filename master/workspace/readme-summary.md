may-agent is a TypeScript framework for running teams of cooperating LLM agents that can delegate tasks to each other, forming parent-child session trees. It provides the infrastructure plumbing — including session management, append-only JSONL persistence for crash recovery, context window compaction, tool safety guardrails, a push-based event bus for UI backends, per-agent memory, a workflow engine with replay-based resume, and an evaluation system that scores agent efficiency and quality — so that developers can focus on defining what each agent does (name, model, tools, knowledge files) rather than how the coordination works. Built on top of pi-agent-core and pi-ai, it is unopinionated about agent behavior or strategy and instead offers primitives like sessions, persistence, delegation, and workflows that compose together to support complex multi-agent orchestration patterns.
