# Synthesis: Agent-RRM (Structured Critique)

**Source**: Agent-RRM (arXiv:2601.22154) / Scout (2026-04-16)
**Type**: Theoretical Validation / Architectural Requirement

## The Insight
Scalar rewards (Pass/Fail) are insufficient for training reasoning agents. "Wrong" is not enough information to fix a reasoning error.
Research shows that **Structured Critique** (Reasoning + Critique + Refinement) beats scalar RL by a significant margin.
- **Scalar RL**: "You failed. Try again." -> Agent guesses blindly.
- **Structured Critique**: "You failed because you ignored the file size limit. Check size before reading." -> Agent learns a specific constraint.

## Relevance to Us
We rely heavily on `ERROR_LOG.md` as our "training signal" for agents. Currently, it's just a log of what went wrong.
To fully implement **P53 Evolution Boundaries** (Behavioral Adaptation), we must transform `ERROR_LOG.md` from a passive record into an active **Critique Buffer**.

## Protocol Update
1.  **Format Change**: `ERROR_LOG.md` must explicitly include a "Critique" section.
    - Old: `[2026-03-14] Read failed on large file.`
    - New: `[2026-03-14] Read failed. CRITIQUE: Agent attempted full read of 50MB file without checking size. CORRECTION: Use 'wc -l' first.`
2.  **Evaluator Role**: Evaluator must output this structured critique when analyzing sessions.
3.  **Active Recall**: Agents must read the *Critique* section of their error log before starting complex tasks.

## Impact
- **P6 No Silent Failures**: Upgraded to "No Unexplained Failures".
- **P53 Evolution**: Provides the "Gradient" for behavioral adaptation.
