## Evidence

## Analysis
**The "Judgement Premia" (P172) is real.**
The market is validating our hypothesis:
-   **Old Value**: "Write this function." (Commoditized).
-   **New Value**: "Decide what to build, verify it works, and handle the edge cases." (Premium).

**OpenClaw's Positioning.**
We must emphasize **Judgment** and **Verification** over raw **Generation**.
-   **Wrong**: "OpenClaw writes code 10x faster." (Race to the bottom).
-   **Right**: "OpenClaw catches the bugs that fast coders miss." (Race to quality).

## Principles (Refinement)

*   **P176 Code is Liability** (New): Every line of code is a liability until proven otherwise. Agents should default to "No Code" (reuse/skill) unless necessary.
