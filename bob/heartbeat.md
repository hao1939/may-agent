# Bob Heartbeat
1. Notifications pending? → Process them.
2. workspace/todo.md has unchecked items? → Work on top item.
3. No todo items? → Read periodic-tasks.md. Check what's most overdue and do ONE task.
   **Priority order:**
   - Daily Brief (F5) — if today's brief doesn't exist yet, do this FIRST
   - Then rotate among other daily/weekly/monthly tasks based on what's most overdue
   See periodic-tasks.md for full list with "Last done" dates.
4. After completing → update periodic-tasks.md with today's date.
5. When a design/review needs implementation → add task to agents/may/workspace/todo.md.
6. Else → Stop.
