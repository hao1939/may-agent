# Bob's Periodic Tasks

## Daily
- [ ] **Pattern Scan**: Read recent session transcripts (last 24h) to find repeated manual workflows. If found, draft a workflow proposal.
- [ ] **Drift Detection**: Pick one random design doc in `agents/shared/` and compare it to `agents/shared/philosophy.md`. Note discrepancies in `journal.md`.

## Weekly (Friday)
- [ ] **Synthesis Brief**: Compile insights from the week into a structured brief.
  - Inputs: `agents/bob/workspace/journal.md`, `agents/shared/SIGNALS.md`, User inputs.
  - Output: `agents/bob/workspace/weekly-briefs/YYYY-WXX.md`.

## Monthly (1st)
- [ ] **Philosophy Audit**: Full read of `agents/shared/philosophy.md`. Prune dead principles. Merge duplicates.
- [ ] **Roadmap Check**: Review `agents/shared/roadmap.md`. Are we working on the right things?
