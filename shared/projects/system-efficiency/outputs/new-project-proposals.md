# New Project Proposals

## 1. Agent Memory & Learning
**Goal**: Ensure agents accumulate useful knowledge across sessions — lessons learned, user preferences, codebase patterns.
**Owner**: coach
**First milestone**: Audit current memory usage across all agents (what's in context.md files, how often lessons are written)
**Value**: Agents that learn produce better output over time without repeated mistakes.

## 2. Workflow Reliability
**Goal**: Reduce workflow failures — timeouts, provider errors, empty iterations. Target: 95%+ of iterations produce a deliverable.
**Owner**: optimizer
**First milestone**: Instrument iteration outcomes (success/empty/error) and produce a weekly dashboard.
**Value**: Directly attacks the "worker produces nothing" problem that plagues this project.

## 3. Project Pipeline
**Goal**: Maintain a healthy queue of 5+ active projects with clear goals and measurable outcomes.
**Owner**: coach
**First milestone**: Review all existing projects, close completed ones, propose 3 new ones based on system gaps.
**Value**: Increases project.active-count toward target of 3+.
