# New Project Proposals

## 1. Automated Test Coverage Expansion

**Goal**: Increase test coverage across core agent infrastructure (workflows, tools, handlers) from current baseline to 80%+.

**Owner**: code-agent (with orchestrator oversight)

**Why**: Untested code leads to silent regressions. Several handler-reliability issues traced back to missing test cases.

**First Milestone**: Produce a coverage report (`outputs/coverage-baseline.md`) identifying the 10 lowest-covered files, then write tests for the top 3.

---

## 2. Agent Documentation Generator

**Goal**: Auto-generate up-to-date documentation for each agent's capabilities, tools, and workflow integrations.

**Owner**: worker (triggered by orchestrator)

**Why**: Agent capabilities are implicit in code. New projects waste iterations discovering what's already possible. A living doc reduces redundant exploration.

**First Milestone**: Produce `outputs/agent-capabilities-catalog.md` listing each agent, its tools, and example use cases — generated by scanning agent config files.

---

## 3. Cross-Agent Knowledge Sharing Pipeline

**Goal**: Build a lightweight system where insights/lessons from one agent session are surfaced to other agents working on related tasks.

**Owner**: orchestrator (coordination) + worker (implementation)

**Why**: Agents repeatedly rediscover the same patterns. Context updates exist but are per-agent. A shared knowledge base (beyond project files) would reduce wasted iterations.

**First Milestone**: Produce `outputs/shared-knowledge-design.md` specifying the format, storage location, and injection mechanism for cross-agent lessons. Then implement a prototype that aggregates lessons from `.state/` directories.

---

## Selection Criteria

| Project | Impact | Effort | Priority |
|---------|--------|--------|----------|
| Test Coverage | High (prevents regressions) | Medium | P1 |
| Doc Generator | Medium (reduces wasted iterations) | Low | P1 |
| Knowledge Sharing | High (compounds over time) | High | P2 |

**Recommendation**: Start projects #1 and #2 immediately. They're low-risk, high-output, and each produces measurable deliverables within 2-3 iterations.
