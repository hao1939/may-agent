# Knowledge Archive

Archived knowledge items that are no longer in the active navigation path.
Items here are searchable but NOT listed in INDEX.md's active sections.

## Why Archive?

From H-047 (Memory Lifecycle Gap): as knowledge base K grows, P(access) for any item decreases.
Archiving keeps the active layer small and high-signal, moving items that no longer add navigational value.

## Archive Categories

### `hypotheses/`
- **Refuted**: Hypothesis tested and falsified (e.g., H-004, H-013)
- **Superseded**: Hypothesis subsumed by a more precise/general later hypothesis (e.g., H-035 → H-041)

### When to Archive
- Hypothesis refuted by experiment → archive with "refuted" note
- Hypothesis fully subsumed by later hypothesis → archive with "superseded by H-XXX" note
- Knowledge entry contradicted by newer evidence → archive with note
- Research thread abandoned → archive all related files

### When NOT to Archive
- Hypothesis still testable and not subsumed
- Knowledge entry still cited by active work
- Item has historical value for understanding evolution (keep a summary pointer in INDEX)
