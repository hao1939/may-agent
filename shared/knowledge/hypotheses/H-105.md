# H-105: Three-Layer Reasoning Model — Thinking-Token Monitoring Is ~3× More Faithful Than Output Monitoring

**Status:** Proposed
**Created:** 2026-04-12
**Author:** Bob
**Prior probability:** 0.72
**Sources:** DD-750, KE-146, KE-147, H-103, H-104

## Core Claim

Agent reasoning operates across three distinct layers — **latent** (model weights/activations), **thinking** (extended thinking tokens/chain-of-thought), and **output** (final visible actions/text) — and each layer loses fidelity relative to the one below it. Monitoring and verification at the thinking-token layer catches approximately **3× more** reasoning failures than monitoring at the output layer alone.

The key insight from DD-750's 12-paper literature synthesis: the "reasoning externalization gap" (KE-146) means that output-level guards systematically miss failures that are visible in thinking traces. DD-750 documents that thinking-token analysis catches ~87.5% of verification gaps (7/8 categories) while output-level monitoring catches only ~28.6% (2/7 observable categories). This ~3× gap is not random — it reflects a structural property of how reasoning compresses as it moves from internal processing to external output.

## The Three-Layer Model

```
Layer 3: OUTPUT    — Final tool calls, finish() payloads, written files
                     Observable by current guards. Lossy compression of Layer 2.
                     
Layer 2: THINKING  — Extended thinking tokens, chain-of-thought traces
                     Observable via thinking-token analysis. Lossy compression of Layer 1.
                     
Layer 1: LATENT    — Model activations, attention patterns, weight-space reasoning
                     Not directly observable. The "ground truth" of model cognition.
```

**Information loss at each boundary:**
- Latent → Thinking: The model selects which reasoning to externalize. Some computation never surfaces (e.g., pattern matching, retrieval, implicit heuristics). Estimated ~40-60% loss based on DD-750's analysis of cases where thinking tokens show sudden conclusions without visible reasoning steps.
- Thinking → Output: The model further compresses thinking into action. DD-750 documents that agents frequently reason correctly in thinking tokens but then produce incorrect or incomplete outputs (the "externalization gap" of KE-146). Estimated ~60-70% additional loss for verification-relevant signals.

## Relationship to Existing Hypotheses

### Reframes H-103 (Format Tax)
H-103 posits that structured output formats impose a cognitive tax that degrades reasoning quality. The Three-Layer Model explains *why*: format constraints operate at Layer 3 (output), forcing the model to compress Layer 2 reasoning into rigid structures. The tax isn't just about format — it's about the information loss at the Layer 2→3 boundary being amplified when output formats are more constrained. **Prediction:** Format tax should be lower for formats that preserve more thinking-trace structure (e.g., narrative > table > single-value).

### Extends H-104 (Guard Dependency Hierarchy)
H-104 hypothesizes that guard effectiveness depends on the reasoning phase they monitor. The Three-Layer Model provides a mechanistic explanation: guards operating closer to Layer 1 have access to higher-fidelity reasoning signals. H-104's "verification guard" (which checks reasoning quality) should outperform "commit guard" (which checks output correctness) precisely because verification operates closer to Layer 2 while commit operates purely at Layer 3. **Prediction:** The effectiveness ranking of guards should correlate with which layer they primarily monitor.

## Testable Predictions

### P-105a: Thinking-Trace Fidelity Gap
**Claim:** Analysis of extended thinking tokens in sessions with verification failures will reveal that the agent *correctly identified* the issue in thinking but failed to act on it in output in >50% of cases.
**Test:** Examine thinking traces from 20+ sessions flagged for FM-3.3 (verification failure). Code each for whether the thinking trace contains reasoning about the verification step that was ultimately skipped.
**Falsification:** If <30% of verification failures show correct thinking-trace reasoning, the gap is smaller than hypothesized and output-level monitoring may be sufficient.

### P-105b: Guard Effectiveness Correlates with Layer Proximity
**Claim:** Guards that analyze or constrain reasoning process (Layer 2-adjacent) are more effective than guards that only check final outputs (Layer 3-only). Specifically, the ratio should be ≥2× in error catch rate.
**Test:** Categorize existing guards by primary layer of operation. Compare error catch rates (errors caught / errors present) across categories using existing experiment data (EXP-103, EXP-132, EXP-140 results).
**Falsification:** If Layer 3-only guards catch errors at ≥80% the rate of Layer 2-adjacent guards, the layer model doesn't explain guard effectiveness.

### P-105c: Suppressed Reasoning Detection
**Claim:** In sessions where agents make avoidable errors (FM-1.3 class), extended thinking analysis will reveal suppressed reasoning — the agent considered the correct approach in thinking tokens but chose a different path in output — in >40% of cases.
**Test:** Sample 15+ FM-1.3 flagged sessions. Analyze thinking traces for evidence of correct-approach consideration followed by incorrect-approach execution.
**Falsification:** If suppressed reasoning appears in <20% of cases, errors are more likely due to genuine reasoning failures (Layer 1) rather than externalization failures (Layer 2→3).

### P-105d: Einstellung Effect Operates at Layer 2→3 Boundary
**Claim:** The Einstellung effect (KE-147) — where familiar approaches block consideration of better alternatives — primarily manifests as a Layer 2→3 compression artifact. Agents will show broader solution exploration in thinking tokens than in output actions.
**Test:** In sessions where Einstellung-like behavior is observed (stale approach fixation), compare the solution space explored in thinking traces vs. the solution space visible in output. Measure the ratio of approaches-considered-in-thinking to approaches-attempted-in-output.
**Falsification:** If thinking traces show the same narrow solution exploration as output (ratio <1.3×), Einstellung operates at Layer 1 (latent), not Layer 2→3.

### P-105e: Intervention Effectiveness by Layer
**Claim:** Interventions that target Layer 2 (e.g., prompts that restructure thinking process, few-shot examples of reasoning patterns) will be more effective at reducing errors than interventions that target Layer 3 (e.g., output format requirements, post-hoc verification checks). The effectiveness gap should be ≥1.5×.
**Test:** Design paired experiments where the same class of errors is addressed by a Layer 2 intervention vs. a Layer 3 intervention. Compare error rate reduction.
**Falsification:** If Layer 3 interventions are equally effective (gap <1.2×), the layer model's practical implications are limited.

## Prior Probability Justification: 0.72

**Evidence supporting (pushing toward 0.8+):**
- DD-750's literature synthesis across 12 papers consistently shows reasoning externalization gaps
- KE-146 directly documents the phenomenon in our own agent data
- The 87.5% vs 28.6% catch rate difference from DD-750 is large and consistent across multiple error categories
- Analogous to well-established findings in human cognitive science (thinking-aloud protocols capture more than behavioral observation alone)
- Our own FM-3.3 failure data shows agents frequently "knowing" what to do (based on context) but not doing it

**Evidence against (pulling toward 0.6):**
- The 3× multiplier is estimated from a relatively small sample in DD-750; true effect size may be smaller
- Extended thinking tokens may not be a faithful representation of Layer 2 — they could be post-hoc rationalization (the "thinking token illusion")
- Layer 1 (latent) reasoning is fundamentally unobservable, making the three-layer model unfalsifiable at its deepest level
- Some verification failures may be genuine capability limitations (Layer 1), not externalization failures — monitoring thinking wouldn't help
- Selection bias: DD-750 studied papers that found gaps, not papers that found output monitoring sufficient

**Net assessment:** Strong theoretical framework with good preliminary evidence, but the specific 3× multiplier needs direct experimental validation. The model's unfalsifiability at Layer 1 is a structural weakness, but P-105a through P-105e are all testable at the Layer 2→3 boundary where the practical implications lie.

### Alternative Testing Approaches (While Blocked)

1. **Text-as-thinking proxy (EXP-146-alt):** Agents "think out loud" between tool calls. Analyze output text for reasoning that doesn't result in action — a weaker proxy for the Layer 2→3 gap. Limitation: only captures Layer 3 information, cannot test core claim about Layer 2 fidelity.

2. **Kimi-k2.5 micro-analysis:** The single amy-kimi session contains genuine thinking traces. While N=1 is far below the required N≥40, qualitative analysis of whether thinking-output divergence exists in that session could provide directional evidence.

3. **Cross-system literature comparison:** DD-750 already synthesized 12 papers. Additional literature search for thinking-trace studies in production systems could strengthen or weaken the theoretical basis without requiring our own data.

## Architectural Implications (If Confirmed)

1. **Guard redesign priority:** Shift from output-checking guards (current architecture) toward thinking-trace analysis guards. This could mean post-processing extended thinking tokens for known failure patterns rather than (or in addition to) checking final outputs.

2. **Prompt engineering focus:** Invest in prompts that improve Layer 2 reasoning quality (e.g., structured thinking templates) rather than output format enforcement. This aligns with KE-133+147's finding that few-shot examples can harm exploration.

3. **Observability infrastructure:** Build tooling to analyze thinking tokens at scale — currently we monitor outputs but not the reasoning process. A "thinking trace analyzer" could flag sessions where thinking-output divergence exceeds a threshold.

4. **Selective transparency:** Rather than requiring all reasoning to surface in output (which may increase format tax per H-103), allow agents to reason freely in thinking tokens and use automated analysis to extract verification-relevant signals.

5. **Reframing the verification problem:** Current approach treats verification failures as output-level problems (agent didn't check its work). The three-layer model suggests they're externalization problems (agent reasoned about checking but the reasoning didn't survive compression to output). Solutions should reduce compression loss, not add more output-level checks.
