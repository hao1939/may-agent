# H-003: Verification skill improves gym pass rate on verification scenarios

**Status**: Archived — Effectively refuted by subsequent evidence
**Priority**: high
**Proposed by**: pi (from knowledge base analysis)
**Archived**: 2026-04-04 by Bob (P4 knowledge compilation audit)
**Reason**: EXP-008 directly tested verify-after-edit skill on verification scenarios and found 0% effect (80% both arms). EXP-017/18/19 extended this to 20+ consecutive text injection failures. KE-002 (0/20) establishes that skills-as-text do not change judgment behaviors. H-003's premise ("skills are more structured than raw text") is not supported — the structure of the text doesn't matter when the mechanism (text injection) is fundamentally ineffective for judgment-class behaviors.

## Hypothesis

Installing the verification skill (skills/verification/SKILL.md) into the coder agent improves pass rate on verification-related gym scenarios (skip-verification, verify-before-finish, etc.).

## Existing Evidence

- KE-002: Text rules don't fix judgment failures (0/18). But skills are more structured than raw text — they have trigger conditions and specific procedures.
- 8 gym scenarios test verification behavior
- Coder currently does NOT have the verification skill installed

## Experiment Design

**Control**: Run 3 verification scenarios with coder (no verification skill)
**Treatment**: Run same 3 scenarios with coder + verification skill installed
**Metric**: Pass rate per scenario, total ops
**Scenarios**: skip-verification, verify-before-finish, read-before-edit
**Success criteria**: Treatment pass rate > control pass rate on at least 2/3 scenarios
