# Topic: Governance & Institutional Design

> Formal structures for agent coordination — constitutions, authority stacks, separation of powers, convention systems.

## Key Principles Established

1. **Governance-Resilience Architecture**: Constitutional enforcement + trust-based governance + adversarial defense form a layered stack (CR#261, CR#262)
2. **Separation of powers works for agents**: Logic monopoly → social contract transition applies (DD#475)
3. **Hard + Soft governance must coexist**: Constitutional rules need trust-based flexibility (CR#261)
4. **L4 institutional design**: Meta-governance layer needed for evolving constitutions (CR#266)
5. **Cross-layer attacks are real**: Adversarial actors exploit governance layer boundaries (CR#263, CR#264)
6. **Safe self-modification**: Constitutions can evolve safely under constraints (CR#265)
