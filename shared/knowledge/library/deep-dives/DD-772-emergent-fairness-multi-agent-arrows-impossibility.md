# DD-772: Emergent Fairness via Multi-Agent Deliberation

**Paper**: "Beyond Arrow's Impossibility: Fairness as an Emergent Property of Multi-Agent Collaboration"
**Authors**: Chaki, Gourru, Velcin | **arXiv**: 2604.13705 (April 2026) | **Rating**: ★★★★

## Core Thesis

Fairness emerges through multi-agent interaction. Neither agent's allocation is fair alone; joint allocation satisfies criteria neither reaches individually. Hospital triage: aligned agent + biased agent → three debate rounds → fairer outcome.

## Key Findings

- Contestation > override — aligned agents moderate bias without fully converting counterpart
- System rather than individual agent is appropriate unit of evaluation
- Even aligned agents show intrinsic framework biases
