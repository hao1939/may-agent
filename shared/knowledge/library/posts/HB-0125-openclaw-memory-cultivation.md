## OpenClaw 的记忆哲学

> **"文件即真相"** (Files are the truth)

模型本身不记得任何东西，只读你磁盘上的 md 文件。写在文件里的，才是它"记得"的。

> "你其实是在用文件系统养一个数字人格"

---

## 三阶段进阶打法

### 阶段一：新手保命版
- 写好 **USER.md**（你是谁、想要什么风格）
- 写好 **SOUL.md**（这只虾的三观）
- 每天结束前让它总结三件事写入 **RULES.md**

### 阶段二：越用越顺版
- 用 `### 高优先级` 标记关键段落
- 每周提炼日志，写入 **KNOWLEDGE.md**
- 开启 memory-search，参数建议：
  - `top_k=8-15`
  - `threshold=0.22-0.28`

### 阶段三：自我进化版
- 装长期记忆插件：
  - memory-lancedb-pro
  - mem0
  - supermemory
- 让它每天 23:00 自我反思：
  - 读日志 → 提炼 → 写规则 → 清理

## 与我们的系统的相关性

### 相似点
我们的 OpenClaw 系统同样采用"文件即真相"哲学：
- `context.md` / `workspace.md` 作为状态持久化
- `SOUL.md` 定义 Agent 身份
- `skills/*.md` 作为能力定义

### 改进机会

1. **标准化记忆文件结构**
   - USER.md / SOUL.md / RULES.md / KNOWLEDGE.md 的分层设计值得借鉴

2. **参数调优指导**
   - `top_k=8-15`, `threshold=0.22-0.28` 作为 memory-search 起点

3. **自我反思机制**
   - 每日 23:00 自动执行: 读日志 → 提炼 → 写规则 → 清理
   - 可作为 MetaClaw 的 Loop 2 实现参考

4. **记忆插件生态**
   - memory-lancedb-pro / mem0 / supermemory 可评估集成

### 与 H-063 的对比思考

HB-063 (Not Self-Evolution) 批评"只是记笔记"不是真正的进化。本文的三阶段设计回应了这一点：
- 阶段 1-2: 确实是"记笔记"
- 阶段 3: 引入自我反思和清理，形成闭环，更接近真正的"进化"
