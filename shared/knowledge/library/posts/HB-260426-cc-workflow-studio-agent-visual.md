## 核心内容

**CC Workflow Studio** 是一个开源的 Visual Studio Code 扩展，定位是**AI工作流可视化设计工具**，充当用户视觉化思维与AI智能体执行指令之间的桥梁。

### 主要功能

| 功能 | 描述 |
|------|------|
| **可视化编排** | 拖放式画布设计复杂多AI智能体协作与工具调用工作流 |
| **导出智能体指令** | 一键导出Markdown格式指令/技能文件，供AI编程智能体直接使用 |
| **AI对话编辑** | 通过自然语言与AI对话生成、修改或优化工作流 |
| **即时运行** | 编辑器内直接运行工作流，实时查看自动化效果 |
| **多智能体支持** | 原生支持Claude Code，通过MCP支持GitHub Copilot、Cursor、Codex |

### 技术信息

- **项目地址**: `breaking-brake/cc-wf-studio`
- **平台**: VS Code 扩展
- **协议支持**: MCP (Model Context Protocol)
