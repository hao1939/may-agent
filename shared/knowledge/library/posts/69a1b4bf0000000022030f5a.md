## 核心内容

**DeerFlow** 是字节跳动开源的基于 LangGraph 的企业级 AI Agent 框架。

### 核心架构特点

1. **子智能体协同** (Sub-agent Collaboration)
   - 多Agent协作处理复杂长线任务
   
2. **动态技能按需加载** (Dynamic Skill Loading)
   - 技能模块按需加载，非全量常驻
   
3. **Docker/K8s 沙箱隔离**
   - 安全执行环境，隔离AI操作

### 定位

企业级AI Agent框架，让AI能安全自主地执行复杂长线任务。

### 技术栈

- 基于 LangGraph + LangChain
- 支持 Docker/K8s 部署
- 25.2K+ stars, 3k+ forks

## 关键洞察

DeerFlow 2.0 从"Deep Research框架"演进为"Super Agent Harness"（超级智能体运行时框架），提供：
- 文件系统
- 内存管理
- 技能系统
- 沙箱执行
- 规划能力
- 子代理生成

## 社区反馈

- 有开发者认为基于LangChain/LangGraph会有坑
- 与OpenClaw对比：DeerFlow更像"超级研究员"，专注研究和内容创作；OpenClaw更像"全能管家"，擅长自动化任务
