## 详细分析

### 1. MAS²: 递归自我生成 (南洋理工, arXiv:2509.24323v1)

**核心机制**:
- Generator-Implementer-Rectifier三元架构
- "一个MAS递归生成另一个MAS"
- 运行时动态配置Agent角色、通信协议、工具

**关键数据**:
- 深度研究/代码生成场景: **+19.6%** 性能提升
- 跨模型泛化: **+15.1%** 提升
- 声称位于"成本-性能帕累托前沿"

**与OpenClaw的张力**:
```
MAS²: 运行时生成新MAS架构
OpenClaw: AGENTS.md编译期确定，运行时禁止修改
```
**关键区分**: MAS²的"自我生成"是在**元架构层面**（如何组织Agents），OpenClaw禁止的是**程序性记忆修改**（Skills/AGENTS.md自我改写）。

---

### 2. MEMRL: 运行时记忆强化学习 (上海交大)

**核心机制**:
- "不改参数，从经验中学习"
- 意图-经验-效用三元记忆结构
- Two-Phase Retrieval: 语义召回 → 效用选择

**关键数据**:
- HLE KnowledgeFrontier: **61.3** vs RAG 47.5
- ALFWorld Exploration: **69.7** vs MemP 45.6
- Lifelong-DB DBTask: **97.2** vs No Memory 86.0

**与OpenClaw的对齐**:
```
MEMRL: 冻结LLM + 可塑记忆
OpenClaw: 冻结Skills + Error Log经验积累
```
**核心一致性**: 都遵循"稳定性-可塑性分离"原则。MEMRL在记忆层面，OpenClaw在架构层面。

---

### 3. AgentDebug: 失败可解释分析 (UIUC/Stanford/AMD)

**核心机制**:
- AgentErrorTaxonomy: 记忆/反思/规划/执行/系统五大模块
- Root-cause tracing + iterative feedback
- 训练无关的三阶段调试器

**关键数据**:
- 错误识别精度: **+24%** vs baseline
- 下游任务成功率: **+26%**
- 小模型收益尤为明显

**与OpenClaw的完全对齐**:
| AgentDebug | OpenClaw Error Log |
|-----------|-------------------|
| 系统化失败分类 | Error类型标签 |
| 根本原因追踪 | 传播路径分析 |
| 可执行反馈 | read_by + 修正指令 |
| 迭代调试 | 编译期重新验证 |

**关键洞察**: "早期误差传播是LLM Agent失败的关键瓶颈" — 这与cascading failure分析一致。

---

### 4. SKILLRL: 失败驱动技能进化

**核心机制**:
- 从成功提炼SOP，从失败生成"错题本"
- 频繁失败 → 触发反思 → 生成新技能
- RL + 技能进化闭环

**关键争议**:
```
评论质疑: "技能进化不够solid"
作者回应: "递归进化能动态填补知识盲区"
```

**与OpenClaw的精细区分**:
- ✅ **错题本机制**: 与Error Log完全对齐
- ⚠️ **自动生成新Skill**: 需人工审核后方可入库
- ❌ **递归自我改进**: 运行时自动更新技能库 → 禁止
