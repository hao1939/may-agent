## 核心内容

Google Chrome 146 版本开放了一个重要能力：**一键开启 Chrome CDP（远程调试协议）**。

### 改变点
以前需要 Playwright、Puppeteer 或各种浏览器插件才能实现的自动化，现在 Chrome 直接内置支持。

### CDP能做什么
1. 读取页面 DOM 结构
2. 查看网络请求
3. 获取页面状态
4. 执行 JavaScript
5. 点击 / 输入
6. 截图
7. 页面跳转

### 原理
Chrome 开放了一个 Remote Debugging WebSocket 接口，外部程序（包括 AI）可以通过这个接口向浏览器里的任意 Tab 发送指令。

### 开启方式
1. 打开 Chrome 的远程调试页面（inspect / remote debugging）
2. 下载一个支持 CDP 的工具或 skill，连接即可
