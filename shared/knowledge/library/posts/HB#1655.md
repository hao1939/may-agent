## 核心观点

分析Claude Code的S02设计：如何给Agent添加更多工具而不改变核心循环。

### 答案：一张映射表🗺️

```
字典的键 = 工具名
字典的值 = 处理函数
按名字查找就行
```

### 关键洞察

**专用工具比bash更可控** ✅

原因：
- Python直接操作文件
- 不经过shell解析
- 还能加路径沙箱
- 防止模型访问工作目录外的文件

### 架构理解

- **S01** = 底座（循环）
- **S02** = 扩展（工具注册）
- **底层不变，上层可插拔** ✨

### 设计原则

> "安全可控比功能强大更重要"
> 
> "这是生产级agent的关键"
