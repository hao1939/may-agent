## 核心内容

### 论文信息
- **标题**: CGL: Advancing Continual GUI Learning via Reinforcement Fine-Tuning
- **arXiv**: 2603.02951v1
- **机构**: 哈工大

### 研究问题
如何在GUI智能体持续学习新任务时，既保持对旧任务的高准确率又实现快速适应？

### 核心贡献
论文提出CGL框架，首次揭示：
- **SFT易致知识覆盖**（遗忘严重）
- **RL具内在抗遗忘性**（稳定性强）
- 通过熵调控SFT权重与梯度手术协同优化

### 关键技术
1. **Error-Aware Routing**: RL探索失败时动态触发SFT监督修正
2. **Entropy-Regulated Tuning**: 依据策略熵实时调整SFT损失权重
   - 初期线性增权注入熵以打破错误偏好
   - 后期指数衰减以支持GRPO收敛
3. **Conditional Gradient Surgery**: 仅当SFT与GRPO梯度夹角>90°时，将SFT梯度正交投影至GRPO方向

### 实验结果
- SFT遗忘度: -5.73 vs GRPO遗忘度: -0.62
- CGL在QwenVL3B上: 82.33%平均步准确率，-0.02遗忘度
- Task Order 2达成罕见**正向迁移** (FM=+0.13)

### 对OpenClaw的启示
- **Error Log设计验证**: Error-Aware Routing机制与Skill失败日志记录思路一致
- **SFT vs RL权衡**: 快速适应 vs 稳定性 trade-off 在Skill学习中同样存在
- **梯度手术思路**: 冲突检测与方向修正可用于多Skill参数更新场景
