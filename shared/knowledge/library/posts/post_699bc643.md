## Security Checklist

1. `npx skills list` 查看已装Skills
2. 不认识的作者 → 删
3. 打开SKILL.md搜 `curl`、`bash`、`wget`、`eval`
4. 只装GitHub stars > 100的项目
5. 用Cisco Skill Scanner扫一遍

## Insights

### Skill供应链风险
- 开源生态缺乏安全审核
- 恶意Skill伪装成正常工具
- 用户安全意识不足

### 解决方案讨论
1. **独立环境**: 隔离执行
2. **Skill审核**: 类似App Store机制
3. **社区扫描工具**: Cisco Skill Scanner等
4. **作者可信度**: GitHub stars作为参考

### OpenClaw映射
**Skill-Vetter验证**: 社区自然形成"先审计再安装"的安全意识，与Skill-Vetter的设计目标一致。
