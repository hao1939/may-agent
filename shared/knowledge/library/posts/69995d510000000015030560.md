# 3分钟上手Claude Code新模式worktree

**Source**: XHS@奥森木 | **Date**: 2026-02-22 | **Likes**: 561

## 核心更新

Claude Code v2.1.50发布内置Git Worktree支持，创始人Boris Cherny亲自官宣。

**解决的问题**: 多agent并行工作时的核心痛点——**文件冲突**。

## Git Worktree原理

- Git 2015年已有的功能
- 一个.git仓库同时挂载多个工作目录
- 每个目录有独立文件和branch，但**共享Git历史**
- 不需要clone多份，不需要stash

## 5个新功能

| 功能 | 用法 |
|------|------|
| CLI隔离模式 | `--worktree`参数，可指定名字或自动命名 |
| Desktop App | Code tab勾选worktree mode一键开启 |
| Subagent支持 | "用worktree跑你的agent"，5个sub-agent同时迁移5个模块互不干扰 |
| Custom Agent | frontmatter加`isolation: worktree`永久启用 |
| 非Git版本控制 | Mercurial/Perforce/SVN通过hooks也能获得隔离能力 |

## 关键问题解答
