## TL;DR

**Mobile Kernel Agent (MoKA)**——三Agent协作系统(Coder+Debugger+Accelerator)在数据稀缺环境下实现93.7%编译成功率（基线46.3%）；Plan-and-Execute范式+共享Reflective Memory；Repository-aware工具消除幻觉——与OpenClaw Main/Sub-agent架构完全映射

## The Problem: LLMs Fail at Mobile Kernels

### Baseline Performance (Claude-Sonnet-4.5)
| Metric | Rate | Issue |
|--------|------|-------|
| **Compilation Success** | 46.3% | >54%失败于幻觉API |
| **Functional Correctness** | 34.2% | 框架特定知识缺失 |
| **Speedup >1.5x** | 4.7% | 硬件感知优化不足 |

### Root Causes
1. **Engineering complexity**: 移动生态系统碎片化
2. **Data scarcity**: 高质量参考实现缺乏
3. **Hallucination**: 标准LLM虚构API或无效框架使用

### Training Fails Too
- **LoRA微调**: CSR 16.7% → 25% (边际改善)
- **GRPO强化学习**: CSR 10% → 25% (仅学会语法格式)

> "Data poverty creates a severe deficit in domain-specific knowledge... preventing LLMs from mastering this highly specialized domain."

## MoKA Architecture: Three-Role Collaboration

### Agent Design

| Role | Responsibility | Trigger | OpenClaw Mapping |
|------|---------------|---------|------------------|
| **Coder** | 生成C++源码 | 每轮迭代 | **Sub-agent** (Skill执行) |
| **Debugger** | 编译诊断+功能修正 | Pipeline失败 | **Error Log** + 方向性批评 |
| **Accelerator** | 性能优化 | 功能验证通过 | **Skill优化**迭代 |

### Shared Reflective Memory

> "Both the Debugger and Accelerator utilize a shared history mechanism... performing self-reflection to avoid repetitive mistakes and prune ineffective optimization paths."

**功能**: 记录过去策略及结果 → 避免重复错误 → 剪枝无效优化路径

### Iterative Plan-and-Execute Paradigm

```
Iteration 1: Coder生成初稿 → Pipeline反馈 → Debugger诊断
Iteration 2: Coder修复 → Pipeline验证 → Accelerator优化
Iteration 3+: 渐进改进直到满足停止条件
```

## Design Implications

### 1. Iterative Refinement > Single-Shot

Pass@10 (简单采样多样性) vs MoKA (结构化迭代):
- Pass@10 CSR: 62.1%
- MoKA CSR: 93.7% (**+31.6%**)

**结论**: 结构化反馈循环优于盲目采样

### 2. Shared Memory Prevents Repetition

Reflective Memory功能:
- 避免重复错误
- 剪枝无效路径
- 累积领域知识

### 3. Specialization Beats Monolith

| Agent | Specialization | Value |
|-------|---------------|-------|
| Coder | 代码生成 | 执行器 |
| Debugger | 错误诊断 | 编译+语义修正 |
| Accelerator | 性能优化 | 硬件感知提速 |
