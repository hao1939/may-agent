## Core Concept

**MindPower**: 首个以机器人为中心(Robot-Centric)的心智理论(ToM)推理框架，将感知、心理推理、决策和行动整合到具身智能体中。

## Key Innovation

### 1. 机器人中心视角 (Robot-Centric)
- 现有ToM基准采用"旁观者/角色中心"视角
- MindPower采用"第一人称"视角，智能体主动推断并协助人类

### 2. MindPower推理层级体系 (6层级)
```
感知(Perception) 
  → 信念(Belief) 
    → 愿望(Desire) 
      → 意图(Intention) 
        → 决策(Decision) 
          → 行动(Action)
```

### 3. Mind-Reward优化目标
- 基于强化学习的一致性优化方法
- 对齐中间推理状态与最终动作
- 超越GPT-4o: 决策准确率+12.77%, 动作生成+12.49%

## Benchmark Design

- **590个交互场景**，两个家庭模拟器
- **两大任务类型**:
  1. 错误信念纠正 (False Belief Correction)
  2. 隐式目标推断与完成 (Implicit Goal Inference & Completion)
