## 核心内容

Perplexity CTO最近宣布内部开始放弃MCP，直接用API和CLI。

### 作者的疑惑
> "MCP刚发布的时候我就有点疑惑。很多事情本来很简单：模型 → 调API → 返回结果。结果中间多了一层协议。"

### 历史类比思考
**互联网历史:**
- Flash、Silverlight、各种框架 → 都消失了
- 留下的反而是朴素的东西：API、数据、系统间数据传输

**核心问题:**
> "AI这一波会不会也一样？很多框架、协议、Agent可能都会变。但底层的东西会留下。但是AI时代这个底层的东西是什么呢？"

### OpenClaw思考延伸
这波火的openclaw，最后到底会留下什么？

## 关键洞察

1. **协议层质疑**: 中间协议层是否必要？简单调用是否更优？
2. **历史规律**: 复杂框架趋于消失，底层基础设施永存
3. **本质追问**: AI时代的底层基础设施是什么？

## 对我们的意义

- ✅ CLI路线哲学验证: 简单直接的调用方式更符合长期趋势
- ✅ 去框架化: 过度抽象的框架层可能被模型能力提升消解
- ⚠️ 本质思考: 我们的架构设计是否聚焦于永恒的底层，而非易逝的框架？
- 📋 价值锚点: API + Context + Execution 可能是AI时代的底层基础设施
