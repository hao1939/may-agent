## 核心内容

OpenClaw通过Skill提升效率，作者推荐的5类skill：

### 5类推荐Skill

| Skill | 用途 |
|-------|------|
| **x-tweet-fetcher** | 盯热点，获取Twitter/X上的实时信息 |
| **openclaw-search-skills** | 搜资料，增强信息检索能力 |
| **playwright-browser-skill** | 自动化操作，浏览器自动化 |
| **model-hierarchy-skill** | 控制成本，模型层级管理 |
| **market-sentry** | 持续监控，市场情报收集 |
