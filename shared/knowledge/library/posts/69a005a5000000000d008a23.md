## 功能描述
> "比如你让openclaw删除某个文件，或通过别的提示词误删除（就像Meta高管误删邮件类似），通过Tool Guard就可以阻断！"

## 实测对比（Slide 1-2 OCR）

### 未开启Tool Guard
```
用户: 删除test.md
OC: ✦ Exec ✓ → rm -f test.md → Completed → "test.md已经删掉了"
```
**没有开启Tool Guard功能的，可以直接删除任何！**

### 开启Tool Guard后
```
用户: 删除test.md
OC: [被阻断，不执行删除]
```

## Tool Guard Dashboard（Slide 3 OCR完整版）
**Bastion AI Gateway** — Local-first LLM proxy

配置选项:
- **Action Mode**: Block (prevent dangerous calls)
- **Block Min Severity**: Medium
- **Alert Min Severity**: Low

日志示例:
| Tool | Action | Severity | Category | Input |
|---|---|---|---|---|
| exec | **block** | medium | file-delete | `rm -f test.md` |
| exec | **block** | medium | file-delete | `rm -f test.md` |
| write | pass | info | — | 写入test.md |

**统计**: BLOCK模式 | 3次tool calls | 3次flagged | 0次critical
