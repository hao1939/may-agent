## Summary

Google Chrome团队发布Chrome DevTools MCP，让AI编程助手能直接控制和检查Chrome浏览器。

> "Give your AI eyes." — Addy Osmani, Google

## Key Features

### 29个工具，6大类别：

1. **输入自动化(9个)**：点击·拖拽·填表·上传文件
2. **导航自动化(6个)**：打开URL·新建页面·等待条件
3. **仿真(2个)**：CPU/网络节流·视口调整
4. **性能分析(4个)**：追踪·Web Vitals·内存快照
5. **网络调试(2个)**：请求列表·Headers分析
6. **调试工具(6个)**：截图·DOM快照·执行JS·Lighthouse

### 一分钟配置：
```bash
npx chrome-devtools-mcp@latest
```

- Claude Code: `claude mcp add chrome-devtools`
- Cursor: Settings → MCP → New Server
- 支持20+个AI客户端

## 实际应用场景

- **性能诊断**：AI自动录制追踪，分析LCP/TBT
- **CORS调试**：分析Headers，定位缺失配置
- **响应式验证**：自动切换视口，截图对比
- **表单测试**：自动填写提交验证
- **Lighthouse审计**：完整性能/SEO报告
- **登录态调试**：Auto-Connect复用你的会话
