## ⭐ 学术论文阅读自动化工作流

### 痛点
```
每天刷arXiv/HuggingFace → 筛选耗尽精力 → 真正读完的没几篇
```

### 工作流（三步）
```
1. 自动获取：hf-paper-skill
   → 每天自动抓取关注方向的最新论文并整理后推送
   → "我不再主动刷网站，paper会自己出现"
   → 我只需判断"值不值得看"

2. 只做选择：人工筛选（保留人在决策链中）

3. 半自动精读：paper-submitter skill
   → 感兴趣的idea一键提交到AI paper精读网站
   → 拆结构/讲方法动机/总结贡献点
   → 同步到Notion，方便后续检索
```

### Skills（均为对话生成，未开源）
```
hf-paper-skill      — 自动抓取HuggingFace Daily特定方向论文
paper-submitter     — 一键提交到精读网站 + Notion同步
← 作者注："纯OpenClaw对话生成的skill"（❤️18）
← 评论反响强烈，可能开源（点赞数决定）
```
