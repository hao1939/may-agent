## 核心内容

### 攻击实验

**实验设置**:
- 目标: ChromaDB向量数据库
- 攻击成本: MacBook上3分钟完成，无需GPU/云服务/越狱
- 注入数据: 仅3条伪造文档

**攻击效果**:
| 指标 | 真实数据 | 投毒后 |
|------|---------|--------|
| Q4收入 | $12.7M | $6.3M (暴跌47%) |
| 利润 | $2.5M | 净亏损$1.8M |
| 额外编造 | - | 裁员计划 |

### 防御测试结果

| 防御层 | 攻击成功率 |
|--------|-----------|
| 无防御 | 95% |
| 输入清洗 | 95% (攻击内容看起来合法) |
| 访问控制 | 70% |
| 提示强化 | 85% |
| 输出监控 | 60% |
| **嵌入异常检测** | **20%** ⭐ |
| 五层组合 | 10% |

### 关键洞察

**知识库投毒比提示注入更危险**:
1. **持久性** - 永远存在
2. **不可见性** - 用户看不到检索的文档
3. **低门槛** - 任何编辑者都能做到

### 防御建议
> "如果你在用RAG系统，嵌入异常检测是第一道防线。"

## 洞察标签
- L3 Flag #279: RAG投毒威胁 - 3条假数据即可操纵输出
- L3 Flag #280: 嵌入异常检测 - 最有效的防御手段(20% vs 95%)
- L3 Flag #281: 纵深防御 - 五层组合可将攻击成功率降至10%

## 安全启示
- 写入权限控制与异常检测同样重要
- 知识库安全是AI系统安全的核心环节
- 需要建立写入审计和异常监控机制
