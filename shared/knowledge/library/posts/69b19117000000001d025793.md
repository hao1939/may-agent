## 核心内容

### 论文
**Remember Me, Refine Me: A Dynamic Procedural Memory Framework for Experience-Driven Agent Evolution**

### TL;DR
长期记忆正在被拆分为独立能力层。ReMe同时强调记忆的**写入、检索和更新**，让memory不再只是向量库挂件，而更像agent runtime里的正式模块。

### 研究动机

**过去agent memory方案的问题**:
- 要么只是存，要么只是取
- 很少认真处理"什么时候写、什么时候调、什么时候忘"
- 任务拉长后面临：脏信息累积、检索时机不稳、经验无法复用

**核心问题**: 如何让memory不只是被动存档，而能随着任务经验持续演化

### 方法简介

**ReMe的三阶段记忆生命周期**:
1. **提炼**: 从历史执行里提炼可复用经验
2. **调用**: 根据当前场景做更合适的调用
3. **精炼**: 持续更新和精炼memory池

**关键创新**:
- 旧经验不是越积越乱，而是逐步变成更高质量的procedural memory
- Agent用到的不是原始轨迹堆积，而是更可复用、可维护的经验层

### 实验结论
- 让memory变得更可控、更能服务长期执行
- memory schema、retrieval timing、forgetting policy都成为可单独研究的问题

## 对我们的意义

**完全验证我们的方向**:
1. **Memory作为独立层** - 与我们的架构设计一致
2. **完整生命周期管理** - 写入→检索→更新，不只是向量存储
3. **经验层而非轨迹层** - 抽象可复用的procedural memory

**下一步研究方向**:
- Memory schema设计
- Retrieval timing策略
- Forgetting policy机制
