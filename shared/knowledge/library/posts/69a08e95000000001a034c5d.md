## 5步降本方案

### 步骤1: 换默认模型（最快见效，省50-95%）
```json
// openclaw.json
{
  "agents.defaults.model.primary": "kimi-k2.5"
}
```
日常便宜模型，需要深度推理临时切Opus

### 步骤2: 心跳指定便宜模型
夜间heartbeat用Opus → **$750/月**
换成Haiku级别 → 几乎可以忽略

### 步骤3: 精简注入文件
六份workspace文件→压缩后省30-60% context

### 步骤4: 按任务拆workspace
不同任务独立工作区，避免context交叉污染

### 步骤5: 优化记忆模块
QMD(BM25+向量搜索)按需检索 → token消耗降72%
⚠️ **QMD需要4GB+内存**，低配VPS跑不动，先用前面几步

**结果: 月成本从$200+降到$30以内**
