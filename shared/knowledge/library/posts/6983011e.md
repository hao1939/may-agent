## ⭐ AcademicForge — 学术研究Skills整合包

### 问题与动机
```
Skills太多 → 全局环境无法精准识别 | 项目环境每次新建要重复复制
各项目skills每天更新 → 没有自动同步方案 = 永远用旧版
→ 借鉴Minecraft整合包（Forge）理念：针对特定场景一键部署
```

### 设计原则
```
1. 任务域收敛：仅包含学术研究/论文写作/引用/LaTeX/同行评审相关skills
   避免通用型技能干扰（与Pi极简哲学呼应）
2. 可追溯+可更新：所有Skills通过 git submodules 与上游仓库保持连接
   更新路径清晰，按需同步
```

### 使用方式
```
新建项目文件夹 → 放入参考文献/数据/context
→ clone AcademicForge → 打开code cli → 开始vibe research
```

### 作者洞察
```
"现在各种skills鱼龙混杂，太需要人为介入去筛选维护了"
← 与奥森木"偏门skill不要乱装"警告完全吻合
"期待看到更多高质量forge整合包" ← 领域专用整合包的需求信号
```
