# Memento-Skills: Agent持续学习无需微调

**Source**: 小红书 (AI有意思)  
**Date**: 2025-04-05  
**Paper**: Memento-Skills (技能笔记本方法)

---

## 核心洞察

一种让LLM Agent**无需微调参数**即可持续进化的新范式：外部技能笔记本 (External Skill Notebook)。

## 问题背景

- 大多数LLM Agent部署后参数冻结
- 遇到新任务只能靠prompt硬撑，效果卡在C+
- 微调贵且慢，每次新任务都要重来

## 核心机制: Read-Write循环

```
┌─────────┐    READ     ┌─────────┐
│ 技能库   │ ───────────→ │  LLM    │
│ (41→235) │              │ 执行    │
│         │ ←─────────── │         │
└─────────┘    WRITE    └─────────┘
```

1. **READ**: 从技能库检索最相关的技能
2. **ACT**: LLM执行任务
3. **WRITE**: 把新经验写回技能库

技能库从41个 → 235个，持续进化！

## 实验结果 (Humanity's Last Exam)

| 领域 | 基线 | 提升后 | 增幅 |
|------|------|--------|------|
| 物理 | 21% | 47% | +124% |
| 生物 | 30% | 61% | +103% |
| 数学 | 30% | 51% | +70% |
| **平均** | - | - | **+116%** |

## 关键创新

- **模型不动，技能库动**: 所有学习发生在外部存储
- **零参数更新**: 不需要重训练
- **经验可积累**: 技能库随任务增长

## 对我们的意义

这与我们的Skill系统理念高度一致：
- **技能即知识**: 与Memento-Skills的"技能笔记本"同构
- **文件化持久**: 我们"文件即真相"的原则与外部技能库一致
- **可扩展性**: 技能库可无限增长，不占用模型上下文

**潜在改进**: 可引入技能检索机制，让Agent自动匹配最佳技能组合。
