## 核心问题

从可验证奖励中进行强化学习（RLVR）面临着**探索效率低下**的问题：
- 模型难以生成成功的运行结果
- 导致学习信号微弱
- 对于需要获取新颖推理模式或特定领域知识的任务尤为严重

---

## 解决方案: CBRL

**Context Bootstrapped Reinforcement Learning (CBRL)**

通过随机地在训练提示前添加**少量示例**来增强RLVR训练。

### 课程学习策略

```
注入概率
    ↑
高  │  ████
    │     ███
    │        ██
    │          █
低  │           ██
    └────────────────→ 训练进度
      早期      后期
```

- **早期**: 高概率注入示例，启动探索
- **后期**: 逐渐降至零，模型必须独立成功

### 核心机制

迫使策略将推理模式**内化**为示例，而不是在测试时依赖它们。

---

## 实验结果

- **两个模型家族**验证
- **五个推理Gym任务**
- **Q语言编程任务**实际应用

**结论**: CBRL可以持续提高成功率，提供更好的探索效率，且**算法无关**。

---

## 技术亮点

| 特性 | 说明 |
|------|------|
| 算法无关 | 可应用于各种RL算法 |
| 课程学习 | 自动递减示例注入概率 |
| 内化机制 | 迫使模型学习而非记忆示例 |
| 实际验证 | 在Q语言(与主流语言差异大)上验证有效 |

## 对我们的启示

1. **RL训练优化**: RLVR探索效率问题有解了
2. **示例工程**: 少量示例+课程注入可显著提升训练效果
3. **内化 vs 记忆**: 训练目标应指向能力内化而非表面记忆
4. **跨领域适用**: 对特殊领域编程语言(Q语言)同样有效
5. **与Trace2Skill结合**: CBRL提升探索效率 → Trace2Skill蒸馏技能 = 完整 pipeline
