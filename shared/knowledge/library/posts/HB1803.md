## 核心内容

在本地AI桌面应用中同时实现Sub Agent和Agent Team两套多智能体方案的实战经验。

### 双方案对比

| 特性 | Sub Agent | Agent Team |
|------|-----------|------------|
| 架构 | 轻量快速 | 重量级协作 |
| 运行 | 进程内，毫秒级启动 | 独立进程，基于SDK |
| 通信 | 无法直接通信 | mailbox通信 |
| 生命周期 | Map管理+EventEmitter | AI自主决定结构 |
| 适用场景 | 简单后台任务 | 复杂研究分析任务 |

### 核心架构亮点

**双引擎设计**: 用`/team`命令切换执行引擎
- 两套系统通过适配层共享Provider配置和记忆系统
- 解决SDK stream生命周期管理（resume循环+空闲检测）
- 解决ESM/CJS混合加载难题

## 与OpenClaw关联

**架构验证**: OpenClaw的Main Agent ↔ Sub-agent结构与Sub Agent方案一致（轻量、进程内、快速启动），与Agent Team的重量级协作形成对比。

**决策启示**: 简单任务用Sub Agent（OpenClaw路线），复杂协作用Agent Team。
