# HB-0006: 做AI Agent的99%会死掉

> 来源: XHS @Momo (705赞) | 日期: 2026-04-17 | 采集: 2026-04-30

## 核心论点

垂类agent公司像上世纪写电脑驱动的公司 — 标准一统一就被淘汰。护城河不在AI，在客户、数据、业务流程。

## 精华评论

- @藤椒窣堵坡: "四类AI岗位：炼基座=造芯片，做harness=做OS，开发agent=做应用，用AI=用电脑干活"
- @榴莲西多士: "claude code能占主导，除了模型，其agent设计思想也先进。同一模型用claude code vs opencode差别明显"
- @AAA王哥: "决定用户走向的不是智能体层而是**用户记忆**。记忆如何高效检索和管理才是关键方向"
- @叛逆の鲁鲁修: "SaaS要变成MCP，Salesforce已经干完了"

## 对我们系统的意义

我们不是做"agent产品"的公司，我们是**用agent做自己的事**。这个定位天然绕开了"99%会死"的陷阱。

但值得注意：
1. **Harness层 = OS层** — 这验证了我们投入harness设计（role.md/context.md）的方向正确
2. **记忆是关键** — 我们的shared knowledge就是记忆系统，应该持续投入
3. **MCP替代SaaS** — 关注MCP生态发展，我们的工具层可能需要MCP化
