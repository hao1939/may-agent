**Title:** AI2提出自反思搜索强化学习

## Summary

AI2与华盛顿大学提出MR-Search：将搜索任务建模为**跨episode的元强化学习**问题，模型在每次尝试后生成自反思，将经验作为上下文指导下一次搜索。

## Key Insights

### 核心创新

| 传统RL | MR-Search |
|--------|-----------|
| 每个episode独立 | 多个episode组成meta-episode |
| 只在最终答案给稀疏奖励 | 每轮搜索后生成self-reflection |
| 难以学习复杂搜索策略 | 测试阶段持续优化策略 |

### 自反思驱动探索

每轮完成后模型进行反思：
1. 评估当前答案
2. 检查是否遗漏信息
3. 再次搜索并修正答案

→ 将"独立尝试"变成"逐步改进"的搜索过程

### 技术创新

- **Turn-level grouped advantage**: episode级别计算RLOO advantage，细粒度奖励分配，critic-free训练
- **支持长推理与工具交互**: ReAct Agent流程（思考→搜索→观察→推理）
- **Test-time Scaling**: 增加推理轮数时性能持续提升（传统方法收益有限）
