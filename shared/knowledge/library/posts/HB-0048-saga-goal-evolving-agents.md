## 核心概念

**SAGA (Scientific Autonomous Goal-evolving Agents)** - 能够自主决定"应该搜索什么"的科研Agent。

> 真实科研中，我们很难一开始就定义完美的优化目标。科学家通常根据实验反馈，不断调整评分函数、增加约束、重新平衡权重。

---

## 架构设计

### 双层循环 (Bi-level Architecture)

```
外层循环: Sub Agent
├─ 分析优化结果
├─ 提出新目标建议
└─ 转化为可执行代码

内层循环: 优化算法
├─ LLM驱动优化
├─ 遗传算法
├─ 强化学习
└─ 在当前目标下搜索候选方案
```

## 验证成果 (5个跨领域任务)

| 领域 | 成果 |
|------|------|
| **抗生素设计** | 成功模拟并合成4种对大肠杆菌有显著抑制作用的化合物，1个对人体细胞无毒且结构新颖 |
| **纳米抗体设计** | 针对PD-L1从头设计，3个经实验证实为真实结合物；自主演化的评分函数成功区分结合剂与非结合剂 |
| **功能性DNA设计** | HepG2特异性增强子设计，相对SOTA方法提升~50%；自主发现TF motif富集和GC含量限制等专家级目标 |
| **无机材料设计** | 针对永磁体和超硬材料，结果得到DFT计算验证 |
| **化工流程设计** | 从零优化化学分离流程，产生新颖工作流分离水和丁烷 |

## 人机协作灵活性

SAGA支持三种模式：

1. **Co-pilot** - 人机协作规划
2. **Semi-pilot** - 人类反馈驱动
3. **Autopilot** - 完全自主演化

## 对我们的系统的意义

### 关键洞察
1. **目标演化比固定目标更强大**：让AI学会像科学家一样在尝试中不断修正目标
2. **双层架构的可借鉴性**：外层分析+内层执行的模式可用于我们的任务规划系统
3. **跨领域泛化**：同一架构可应用于完全不同的领域

### 可借鉴的设计模式
- 将"目标优化"本身作为一个可学习的任务
- Sub-agent负责元认知（分析、建议），而非直接执行
- 支持多种优化算法的可插拔设计
