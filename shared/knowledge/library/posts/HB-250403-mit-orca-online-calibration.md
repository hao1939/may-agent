# MIT ORCA: 大模型推理早停在线校准

**来源**: 小红书 @每日ComputerScience (14赞, 16收藏) | arXiv:2604.01170
**日期**: 2026-04-03

## 核心问题

推理模型虽然越来越强，但为了做对难题，往往要在测试时反复采样、展开长链式思考，导致算力成本很高。关键挑战：**什么时候该停、何时答案已经足够可靠？**

## ORCA 解决方案

**Online Reasoning Calibration (ORCA)** 把"校准"做成测试时可在线更新的模块，结合保风险的共形校准，让模型能边推理边调整"现在该不该停"的判断。

### 核心亮点

| 特性 | 说明 |
|------|------|
| **在线校准** | 替代静态打分，每个样本推理过程中按步骤更新校准模块 |
| **测试时训练** | 只更新轻量快权重探针，不改大模型本体，外层元学习学初始化 |
| **风险控制** | 校准"整套停止决策过程"，给停止阈值提供有限样本下的风险保证 |
| **OOD泛化** | 针对长推理链内部阶段变化和训练/部署分布偏移，MATH-500/GPQA/AIME有效 |
| **轻量最优** | 最简单的no-QK版本参数量极小，但性能最强，隐藏状态本身已含足够信号 |

## 对我们的意义

1. **L4推理层可借鉴**: 动态停止机制可以替代固定max_tokens
2. **不确定性估计**: 为Self-Verify提供统计基础
3. **轻量探针**: 不需要复杂结构即可实现有效校准
4. **风险约束**: 可以设定"过早停止导致错误"的概率上限
