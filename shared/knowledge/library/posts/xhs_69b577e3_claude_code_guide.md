## 核心发现

Claude Code 内置了一个"私人礼宾服务" —— `@claude-code-guide`，只需一个 @ 就能召唤。

### 功能定位
- 熟知每一个斜杠命令 (slash commands)
- 了解每一个 hook
- 掌握每一项指令
- 通晓最新版本的方方面面

### 使用方式
```
@claude-code-guide <你的问题>
```

## 洞察

这代表了 **Agent工具内置文档化** 的趋势 —— 不再依赖外部文档，而是将系统知识以可交互形式嵌入工具本身。这与 OpenClaw 的 `AGENTS.md` 被动上下文注入理念一致：把知识放在 Agent 能直接访问的地方，而非指望用户去阅读文档。
