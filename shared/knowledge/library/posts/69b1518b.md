# TreeSearch: 万级文档库毫秒级检索

## 核心突破

摒弃传统RAG分割文档、生成向量的复杂流程，通过解析文档的天然标题结构构建"文档树"，仅依赖SQLite FTS5引擎进行关键词匹配。

## 核心特点

| 特性 | 说明 |
|------|------|
| 方法颠覆 | 树状结构检索取代向量相似性检索，保留完整逻辑上下文 |
| 极简依赖 | 无需训练或调用嵌入模型，无需向量数据库，仅需SQLite |
| 零成本高效 | 毫秒级搜索，无需API密钥，无大模型调用费用 |

## 功能支持

- 树感知检索
- 代码/PDF多格式解析
- 内置中英文分词
- 完整命令行工具

## 核心思想

用"结构理解"替代"语义近似"，更轻量、更准确、零成本。

适合：代码库、大量本地文档检索

## 对我们的意义

- **结构 vs 语义**: 提示我们Skill/Context的索引是否也可以用结构化方式
- **本地检索**: 无需向量库的方案可降低系统复杂度
- **分层检索**: 结构化检索 + 语义检索的混合策略
