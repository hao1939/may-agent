## 核心内容

### YC CEO Garry Tan开源的gstack工作流

将软件开发拆分为**8个明确的角色边界**：

| 角色 | 职责 |
|------|------|
| /plan-ceo-review | 产品规划 |
| /plan-eng-review | 架构设计 + 故障分析 |
| /review | 代码审查 + 生产风险评估 |
| /ship | 同步主分支、跑测试、开PR |
| /qa | 分析diff找到受影响的路由并测试 |
| /browse | 持久化浏览器 + 登录状态保持 |

### 核心技术创新

**持久化Chromium守护进程**:
- 冷启动: ~3秒
- 后续调用: 100-200ms
- Cookie、Tab、登录状态跨命令保持

### 核心理念

> "AI编程的关键不是更强的模型，而是给Agent明确的角色边界。"
