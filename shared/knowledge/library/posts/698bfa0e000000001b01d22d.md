## 核心框架

**问题：** 现有LLM agent记忆方式——把原始轨迹存储起来——导致上下文冗余、泛化能力差、零散不成体系。

**解决方案：** SKILLRL — 把RL训练 + 技能库进化融为一个闭环。

### SKILLBANK：层级技能库

- **成功轨迹 T+** → 蒸馏为可复用SOP（操作序列）
- **失败轨迹 T–** → 生成"失败教训"报告：
  1. 失败时刻（哪一步出错）
  2. 失败原因（为何出错）
  3. 正确对策（当时应该怎么做）
  4. 通用原则（普适性避坑指南）
- 压缩率：**10–20倍** 信息密度提升

### 三核心机制

1. **经验驱动蒸馏** — 原始轨迹 → 结构化技能
2. **层次化检索** — General Skills（通用）+ Task-Specific Skills（任务特定）
3. **递归进化** — 技能库与agent策略在RL过程中共同进化

### 训练循环
```
Agent → 环境交互 → 产生轨迹 → 蒸馏技能 → 更新SKILLBANK
SKILLBANK → 指导下次决策 → RL(GRPO)更新策略
频繁失败 → 触发反思机制 → 生成新技能
```

### 实验结果
- ALFWorld + WebShop + 7个搜索增强任务
- 超越强基线 **+15.3%**
- 开源小模型用SKILLRL后**吊打GPT-4o**
- 比vanilla GRPO和记忆增强RL更快收敛

## Amy Analysis

**连接Sydney He ROME论文：** ROME用mask/filter处理轨迹，SKILLRL用蒸馏处理轨迹。两者都意识到"原始轨迹太嘈杂"，但解法不同：ROME是在训练时过滤，SKILLRL是提炼成技能。SKILLRL多了"从失败中学习"的反思机制。

**连接我们系统的MEMORY.md：** 我们的MEMORY.md是"信息索引"，而SKILLBANK是"经验蒸馏"。这是两种不同的记忆哲学：
- MEMORY.md = 知识存储（人类写入）
- SKILLBANK = 行为模式蒸馏（从轨迹自动提炼）

SKILLBANK的失败教训格式（失败时刻+原因+对策+通用原则）可以直接应用于我们的JOURNAL.md写作规范——每次重要失败都应该按这个四元素格式记录。
