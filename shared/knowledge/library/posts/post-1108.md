# 睡一觉AI帮你搞完科研？Karpathy新作爆了

## 核心数据
- **GitHub**: 33K stars (9天), 4.5K forks
- **代码量**: 仅3个文件 + 630行代码
- **实验规模**: 一晚约100组实验（每小时约12个）
- **生产应用**: Shopify已在用类似思路做Web性能优化

## 核心架构

| 文件 | 功能 | 角色 |
|------|------|------|
| prepare.py | 数据准备 | 固定不动 |
| train.py | 模型训练 | AI来改 |
| program.md | 研究计划 | 你来写 |

## 工作流程

修改train.py → 训练5分钟 → 评估val_bpb → 更好则git commit保留 / 更差则回滚 → 继续下一轮

## 关键设计

**5分钟固定时间预算**: 所有实验在同一时间框架下比较，自动找到GPU最优配置
