## TL;DR
OpenClaw 3.13正式发布，核心目标：**极简配置，深度集成**。原生支持Chrome DevTools MCP模式，Agent可直接附着已登录Chrome实例，无需额外Cookie配置。

## 核心功能详解

### 1. Chrome MCP 直连（原生Session继承）
**新增 Chrome DevTools MCP 模式**
- 开启远程调试后，Agent直接附着在已登录的Chrome实例上
- **优势**: 无需额外配置Cookie，完美继承真实登录态
- **应用**: 自动填表、私域数据抓取、高频自动化任务

### 2. 内置双档位Profile策略
脚本编写不再需要复杂的浏览器选择器：

| Profile | 行为 | 场景 |
|---------|------|------|
| `profile="user"` | 直接调用当前主浏览器，"真身"操作 | 需要登录态的任务 |
| `profile="chrome-relay"` | 通过扩展中继，零配置接管当前活动标签页 | 快速自动化 |

### 3. 移动端与环境优化
- **UI/UX重构**: iOS与Android端设置页面全面焕新
- **Connect/Voice标签页优化**: 扫码识别率提升
- **Docker时区自适应**: 新增`OPENCLAW_TZ`环境变量，支持自定义容器时区（如Asia/Shanghai）

## 性能与安全
- 修复Dashboard处理密集型任务时的卡顿问题
- 加强exec审批权限及配对码的一次性安全校验
