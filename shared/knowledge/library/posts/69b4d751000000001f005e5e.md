## 内容摘要

OpenClaw 内置斜杠命令速查表，帮助用户快速控制系统状态、上下文和任务执行。

## 10个核心命令

| 命令 | 功能 |
|------|------|
| `/status` | 快速检查系统状态 |
| `/context list` | 查看当前上下文 |
| `/reset` | 清空上下文 |
| `/new` | 切换/新建对话 |
| `/think` | 控制思考成本 |
| `/skill <name>` | 指定使用某个 Skill |
| `/model <name>` | 切换模型 |
| `/compact` | 压缩上下文 |
| `/whoami` | 确认当前身份/配置 |
| `/stop` | 中断当前任务 |

## 使用场景

- **系统监控**: /status 快速诊断
- **上下文管理**: /context, /reset, /compact 控制记忆
- **成本控制**: /think 调整推理深度
- **任务控制**: /skill, /model, /stop 精细化操作
