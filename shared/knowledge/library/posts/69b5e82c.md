# AGENTS.md：写给 AI 的 README

## 问题背景
很多人用 AI 写代码都会遇到：AI 经常犯同样的错误
- 代码风格不一致
- 改错文件
- 不遵守项目架构
- 每次都要重新写 prompt

## 解决方案：AGENTS.md
可以理解为：**写给 AI 的 README**

### 核心特性
- 自动加入上下文
- Codex 每次执行任务都会看到
- 所有规则可写入其中

### AGENTS.md 内容结构
1. **项目结构** — 目录用途说明
2. **如何运行项目** — install/dev/test 命令
3. **测试和 lint** — 质量检查流程
4. **工程规范** — commit/PR 流程
5. **禁止规则** — 不要修改 core 模块、不要引入新依赖
6. **完成标准** — 测试通过、lint 通过

### 层级设计（关键）
AGENTS.md 可以有层级，越靠近当前目录优先级越高：
- **全局**: `~/.codex/AGENTS.md`
- **项目级**: `repo/AGENTS.md`
- **模块级**: `repo/module/AGENTS.md`

### 复盘机制
官方建议：如果 Codex 连续犯同一个错误，让它写一份 **retrospective（复盘）**，然后更新 AGENTS.md。

这样 AI 会越来越像团队成员。
