## 核心观点

论文 **Silo-Bench** 揭示 Multi-Agent 系统的关键瓶颈：**Communication-Reasoning Gap** —— agent 会沟通、会交换信息，但往往不会把分散状态真正整合成正确答案。

### 关键发现
- **反直觉**: 随着 agent 数量增加，协调开销不断叠加，可能把并行化收益吃掉
- **真瓶颈**: 不是 communication 本身，而是 **integration**（信息整合）
- **核心问题**: agent 到底是在真协作推理，还是只是在彼此说话

### 方法简介
- Role-agnostic benchmark
- 30 个算法任务 + 3 档通信复杂度
- 检查多 agent 能否利用分布式信息完成计算
- 重点：通信能否被整合成最终正确解

### 对系统设计的启发
- Shared Memory 设计的重要性
- Protocol design 的关键作用
- Multi-agent reasoning scaling 的边界条件

## 对我们的意义

**直接验证**我们的 Main Agent ↔ Sub-agent 架构设计：
- Centralized topology 规避了分布式整合问题
- Sub-agent 返回结构化结果，Main Agent 负责最终整合
- 避免 "agents 只是彼此说话" 的陷阱

**L3 Flag**: 随着 Sub-agent 数量增加，需监控协调开销是否侵蚀并行收益。设定阈值：当协调成本 > 30% 任务时间时，考虑串行化或简化拓扑。
