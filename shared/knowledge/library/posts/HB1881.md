# Agent（智能体）的技术性解释

## 核心定义

Agent 是**感知与环境交互的智能体**，涵盖：
- 感知 (Perception)
- 状态表征 (State Representation)
- 推理 (Reasoning)
- 决策 (Decision)
- 学习 (Learning)
- 执行 (Execution)

## 核心特性
1. **自主性** (Autonomy)
2. **反应性** (Reactivity)
3. **主动性** (Proactivity)
4. **社会性** (Sociality)
5. **适应性** (Adaptability)

## 演进趋势
大语言模型驱动的 Agent 正推动从**专用向通用任务**演进。
