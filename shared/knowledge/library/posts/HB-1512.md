## 核心发现

### 1. CTDE范式完整生产级验证
论文采用 **Centralized Training with Decentralized Execution (CTDE)** 框架，与OpenClaw架构完全映射：
- **Centralized Critic** ↔ AGENTS.md (全局信息共享训练)
- **Decentralized Actors** ↔ Skill执行 (分布式本地决策)
- **GNN-augmented observations** ↔ Context Engine (全局上下文注入本地)

> "A centralised critic utilises global information to train decentralised agents throughout the offline phase which solves the non-stationarity challenge present in multi-agent systems."

### 2. 三层目标层次结构
论文提出 **Lexicographical Ordering** 处理多目标冲突：
```
Priority 1: Fault Tolerance (故障容忍)
Priority 2: Resource Utilisation (资源利用)
Priority 3: Cost (成本)
```

这与OpenClaw的 **P109 > Skill > 其他** 优先级设计哲学一致。

### 3. 关键创新：分离"学什么"与"如何排序"
> "Hybrid policy combines learned, multi-objective evaluations from decentralised actors with a centralised, stress-aware lexicographical selection mechanism, **allowing agents to learn what is important while the system dictates how to prioritise it**."

**验证OpenClaw设计**：
- Skill学习"什么有效" (what works)
- AGENTS.md规定"何时使用" (when to use)
- 运行时系统压力决定优先级 (stress-aware prioritization)

### 4. 非平稳性问题解决方案
论文明确指出CTDE解决MARL的 **non-stationarity challenge** (其他Agent策略变化导致环境非平稳) —— 这正是HB#1504 "合作病理学"中提到的"环境非平稳性"问题的工程解。

## 技术架构

### MAMDP形式化定义
```
ℳ = ⟨𝒮, {𝒪i}i=1^N, {𝒜i}i=1^N, 𝒫, ℛ, γ⟩

𝒮: Global state (Kubernetes集群状态)
𝒪i: Local observation (节点i的观测)
𝒜i: Action space (节点i的调度决策)
𝒫: State transition (Pod放置后的状态转移)
ℛ: Shared reward (全局奖励信号)
```

### 状态表示：图神经网络
- 集群状态表示为图 𝒢t = (V, E)
- V: Worker nodes
- E: Node间关系(网络拓扑/资源依赖)
- 每个Agent通过GNN获得 **全局上下文的本地嵌入**

## 实验验证

### 测试环境
- **平台**: Google Kubernetes Engine (GKE) 生产级环境
- **场景**: 
  1. 资源密集型批处理工作负载
  2. 故障注入下的关键任务负载

### 核心结果
1. **智能合并策略**: 资源密集型工作负载的优化放置
2. **战略自限制策略**: 故障注入下保持系统稳定
3. **目标解耦**: 成功分离故障容忍与资源利用的冲突目标
