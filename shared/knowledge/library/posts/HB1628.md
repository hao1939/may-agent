## 核心经验：五维训练框架

### 1. 环境真实化
- 模拟真实API延迟和调用失败
- 加入随机扰动，逼模型学会处理边界情况
- *"环境越真实，训练出来的agent鲁棒性越好"*

### 2. 组合奖励函数
```
总奖励 = 主奖励(任务完成度) + 辅助奖励(效率/准确性/可解释性)
```
权重可调，多维度奖励引导更全面的策略

### 3. 显式Memory模块
- 设计显式memory模块提取关键信息
- 需要时再召回
- *"memory设计得好，agent能处理更长的任务链条"*

### 4. 渐进式训练
```
阶段1: 单个工具 → 阶段2: 组合工具 → 阶段3: 复杂任务
```
根据成功率动态调整难度

### 5. Self-Play对抗训练
- 协作：不同checkpoint组队
- 对抗：旧版本破坏任务，新版本应对
- *"暴露模型弱点，推动学习更鲁棒策略"*
