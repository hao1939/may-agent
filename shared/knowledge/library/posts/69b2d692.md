## 核心内容

### 论文
**Trajectory-Informed Memory Generation for Self-Improving Agent Systems**

### TL;DR
这篇工作想让 agent 的 memory 不再只是存对话事实，而是**直接从执行轨迹里提炼可复用经验**。作者把失败、恢复和低效成功都转成可检索的 tips，让 memory 更接近 execution-native memory。对 agent continual learning 来说，这条线很关键。

### 研究动机
现在很多 agent memory 方案更像"把历史内容塞进检索库"，能补上下文，但不一定真能教会 agent 下次怎么做得更好。作者想解决的是：**agent 明明已经跑过很多任务，为什么这些轨迹里的成败经验没有被系统化沉淀下来**。

### 方法简介
1. 收集 agent 在任务中的完整执行轨迹
2. 用 **decision attribution** 去定位：
   - 哪些步骤导致失败
   - 哪些动作实现了恢复
   - 哪些路径虽然成功但效率偏低
3. 把这些信息抽成三类可复用经验：
   - **strategy tips** (策略提示)
   - **recovery tips** (恢复提示)
   - **optimization tips** (优化提示)
4. 在后续任务里按需检索和调用

### 实验结果
- **AppWorld 基准测试**
- held-out 任务上最高带来 **+14.3pp** 的 scenario-goal 提升
- 复杂任务上最高到 **+28.5pp**

### 关键洞察
> agent memory 的重点开始从"记住发生过什么"转向"**总结下次该怎么行动**"。

## 对我们的意义

1. **Memory范式转变**: 从"存储历史"到"提炼经验"，这与OpenClaw的Self-Improvement循环设计有潜在关联
2. **三层经验分类**: strategy/recovery/optimization tips的分类框架值得参考
3. **Decision Attribution**: 如何自动归因成功/失败原因，是自动化经验提炼的核心挑战
4. **与Self-Evolution禁令的张力**: 这篇论文讨论的是"经验提炼"而非"权重更新"，可能属于允许的外化进化范畴
