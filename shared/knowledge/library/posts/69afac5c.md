## 核心论点

最近在思考AI Agent的发展方向，发现一个有意思的趋势：**所有Agent本质上都是带技能包的Coding Agent**。

### 架构演进趋势

| 旧范式 | 新范式 |
|--------|--------|
| 重型集成 | 轻量组合 |
| MCP | CLI |
| RAG | 文件系统 |

**"CLI正在吃掉MCP，文件系统正在吃掉RAG。Agent架构正在从'重型集成'走向'轻量组合'。"**

## 分析

### 价值
- L2级：架构演进方向的敏锐观察
- 与我们的Skill-centric架构高度一致

### 与OpenClaw对比
1. **我们的架构**: Channel + Gateway + Runtime，本身就是轻量组合
2. **OpenClaw**: 被批评为"重型集成"（见69b39eb1的批判）
3. **社区趋势**: 从框架依赖转向原生工具组合

### 关键洞察
"CLI吃掉MCP"与我们"CLI优先于MCP"的技术选型完全对齐。MCP的复杂性正在被原生Unix哲学取代。
