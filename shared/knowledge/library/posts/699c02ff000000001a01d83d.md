## OC用于SEO的工作流

### 安装三个Skills
```bash
npx clawdhub@latest install octolens        # 网页浏览
npx clawdhub@latest install programmatic-seo # SEO分析套件
npx clawdhub@latest install fs-architect    # 文件系统访问
```

### 工作流步骤
1. **搜索分析研究**: "分析关键词X的前10条Google结果，抽H2标题+字数+People Also Ask，存/research/"
2. **Content Gap识别**: 找出竞品有排名但你没覆盖的话题
3. **数据驱动起草Brief**: 先大纲后文章（不要直接让AI写全文）
4. **自动化审查维度**: On-page SEO/AI痕迹去除/Schema校验/可读性/E-E-A-T

### 技术写作技巧：Topology Constraints（拓扑约束）
> "不要使用bullet points，先把内容以节点+边的方式映射，若读者问X则引导到章节Y"
**效果**: 迫使模型组织逻辑结构，减少空洞段落

### 安全注意("致命三角")
- API层设预算上限 | 任务添加请求/时间上限
- 不在含敏感数据的主机上运行
- 使用VPS或"隔离机" | 最小权限原则
