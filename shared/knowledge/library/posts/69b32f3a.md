## 项目概览

**bit-frog** — 一个400行代码的极简Agent实现，砍掉所有抽象层。

## 核心特性

### 1. Tool Use (热加载)
- 内置命令行执行和知识检索
- 支持热加载：往 `./tools/` 目录扔 `.py` 文件，不用重启，下轮对话就能用
- **关键理念**: "工具不是预定义死的，是agent自己'长'出来的"

### 2. Memory (Obsidian双链笔记)
- `./memory/` 目录下每个话题一个 `.md` 文件
- 使用 `[[双链]]` 关联
- **不用向量数据库，不用embedding** — 纯文本，人可直接读
- 每次对话自动加载索引到system prompt

### 3. 反思与学习
- **触发条件**: 对话超过40条消息
- **压缩机制**: LLM从历史对话提取结构化知识
  - 成功经验 → `./success/`
  - 失败记录 → `./failure/`
  - 性格演化 → `./soul` (灵魂文件)

### 4. 上下文管理
- System prompt每轮重新构建
- 动态注入：记忆索引 + 可用工具列表 + 灵魂状态
- "不是一次性写死的prompt，是活的"

```
用户输入 → 构建prompt → 调LLM → tool call?执行并回送:输出回复
```
