## 核心内容

### Sub-Agent的"交响乐团"模式

**核心问题**: 单独sub-agent像"只会埋头干活的程序员"，不知道大局 → context溢出 → 胡言乱语

**解决方案**: Project Manager统筹全局，复杂项目拆解成小任务，分配给不同sub-agent在不同窗口同时干活

### 推荐工作流程

```
早上: Project Manager制定今日任务清单 → 分配各sub-agent工作
白天: 各窗口并行工作，互不干扰
晚上: Project Manager总结今日完成 + 明日重点
```

### 窗口分工示例

| 窗口 | Agent组合 | 职责 |
|------|-----------|------|
| 前端 | ui-ux-designer + code-reviewer | 界面设计与代码审查 |
| 后端 | strategic-planner + task-executor | 架构设计与功能实现 |
| 测试 | testing-engineer + error-debugger | 测试策略与问题解决 |

### 常用Agent组合推荐

1. **strategic-planner**: 架构设计
2. **task-executor**: 功能实现
3. **code-reviewer**: 代码质量把控
4. **testing-engineer**: 测试策略
5. **error-debugger**: 疑难杂症
6. **ui-ux-designer**: 用户体验优化
