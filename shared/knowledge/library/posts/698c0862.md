## 正文
OpenClaw 生态里 multi-agent 的玩法越来越多了。从最简单的 sub-agent，到社区演示的线性流水线 / DAG 并行 / 多 Agent 辩论，再到 Claude Code 原生的 Agent Teams — 选项多到让人困惑。我自己在搭建 multi-agent 系统的过程中，踩了不少坑。最大的教训是：**不是越复杂越好，而是要匹配你的实际需求**。

这篇文章把 multi-agent 的选项整理成**四个层次**，帮你判断 "我现在在哪，该不该升级"。

（注：原帖包含四重进化的详细对比图，此处为框架概述）

## Multi-Agent 演进四层次

```
Level 1: Sub-agent — 最简单的代理委托
Level 2: 线性流水线 — 顺序执行任务
Level 3: DAG并行 — 有向无环图并行执行
Level 4: 多Agent辩论 — 多代理讨论决策
```
