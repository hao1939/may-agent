## 核心内容

所有AI编程Agent（Claude Code、Cursor、Copilot）核心都是同一个模式：**一个while循环**。

### Learn Claude Agents第1课
- **84行Python代码**
- **1个工具**（Bash）
- 构建一个能用的Agent

### 核心逻辑（3步）
1. 把用户消息发给LLM
2. 检查LLM是否要调用工具
3. 如果要，执行工具，把结果喂回去，继续循环

### 退出条件
`stop_reason != "tool_use"` —— 模型不再需要调用工具时，循环结束。

### 关键代码
```python
while True:
    response = client.messages.create(
        messages=messages, tools=tools
    )
    if response.stop_reason != "tool_use":
        break
    for tool_call in response.content:
        result = execute_tool(tool_call)
        messages.append(result)
```

### 核心洞察
> "没有这个循环，你（人类）就是那个循环，手动复制粘贴AI的输出再喂回去。"

**Agent vs Chatbot的区别**:
- Chatbot: 一问一答
- Agent: 自主循环执行直到完成任务

> "整个教程后续11课都是在这个循环上叠加机制，但循环本身从不改变。"

## 对OpenClaw的验证

| 概念 | 本文验证 | OpenClaw对应 |
|------|----------|--------------|
| while循环 | ✅ 核心机制 | Main Agent执行循环 |
| tool_use检查 | ✅ 决策点 | Skill调用决策 |
| 结果反馈 | ✅ 上下文积累 | Error Log/结果反馈 |
| 循环退出条件 | ✅ 任务完成判断 | SIGNALS.md handoff机制 |

**结论**: OpenClaw的架构与Claude Code底层逻辑完全一致，差异在于:
- Claude Code: 单Agent + 通用工具
- OpenClaw: 分层架构 (SOUL/DOMAIN/SKILL) + 领域特化
