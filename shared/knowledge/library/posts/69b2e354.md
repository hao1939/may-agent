## 核心功能
每次出错、被你纠正、发现更好做法时，AI自动记录学习，下次直接参考，避免重复犯错！

## 关键机制

### 1. 错误自动捕获
- 工具调用失败、逻辑卡住时
- 自动提取错误信息 + 上下文
- 写成markdown日志

### 2. 用户纠正记录
- 你说"不对，应该这样"时
- AI主动记录你的偏好
- 变成持久记忆

### 3. 学习提炼推广
- 定期把高频learnings提取成：
  - 提示词优化建议
  - 新规则
  - 代码片段

### 4. 自省回顾
- session结束时自我反思
- 总结"哪里做得好/坏"
- "下次怎么改进"

## 典型使用方式

### 安装（推荐pskoett版）
```bash
npx clawhub@latest install self-improving-agent
```

### 日常触发
- AI错了，你直接纠正 → 它记下来，下次优先用你的方式
- 失败后AI自己说"我学到了..."
- 主动问："总结最近的学习点，推广到AGENTS.md"

### 输出文件示例
`.learnings/2026-03-errors.md`
```
- 失败：rm -rf 用错路径 → 学到：先dry-run预览
- 偏好：总结用bullet而非段落 → 已推广到prompt
```
