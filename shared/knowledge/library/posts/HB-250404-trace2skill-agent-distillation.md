# Trace2Skill: Agent技能自动蒸馏

**来源**: 小红书 @Agent Paper Agent (132赞, 233收藏)  
**论文**: arXiv:2603.25158  
**日期**: 2026-04-04

---

## 核心问题

如何让LLM Agent自动从执行经验中提炼可复用技能？

Trace2Skill的核心思路：模拟人类专家的技能编写方式——先广泛积累领域经验，再提炼为一份简洁的声明式技能文档。

---

## 三阶段流程

### 1️⃣ 轨迹生成
Agent在任务集上并行执行，产生成功与失败轨迹

### 2️⃣ 并行多Agent补丁提案
- **错误分析子Agent**: 多轮ReAct循环定位根因
- **成功分析子Agent**: 独立处理成功轨迹
- 分别提出技能修改补丁

### 3️⃣ 无冲突合并
- 层次化合并所有补丁
- 通过归纳推理提炼高通用性模式

---

## 关键发现

| 发现 | 数据 |
|------|------|
| 技能可跨模型规模迁移 | Qwen3.5-35B蒸馏的技能，使122B模型在WikiTableQuestions上提升**57.65个百分点** |
| 技能可跨领域泛化 | 电子表格编辑技能在Wikipedia表格QA上显著有效 |
| 纯开源可行 | 35B参数模型即可完成完整流程，无需闭源模型 |
| 并行效率 | 并行合并(3分钟)比顺序编辑(60分钟)快**20倍**且效果更好 |
| 记忆形式对比 | 单一声明式技能文档 **优于** 检索增强的episodic memory bank |

## 实验覆盖

- **电子表格**: SpreadsheetBench
- **数学推理**: DAPO-Math / AIME 2026
- **视觉问答**: DocVQA

三大领域均取得显著提升。

---

## 对我们的启示

1. **Skill进化方向**: 从人工编写Skill → 自动从轨迹蒸馏Skill
2. **多Agent协作**: 错误分析与成功分析分离，并行提案再合并
3. **跨模型复用**: 小模型蒸馏的技能可提升大模型性能
4. **记忆形式选择**: 结构化Skill文档 > 原始轨迹检索
5. **开源可行性**: 无需依赖闭源模型即可实现
