# HB#1367 — AutoResearch原理：约束式自主改进Harness
**Source**: XHS@万有引力AI (英国) | **Date**: 2026-03-15
**Status**: 完整 | **Reference**: Karpathy's AutoResearch

## TL;DR
Karpathy的AutoResearch不是一个通用AI科学家，而是一个小型、严格约束的系统——让Agent修改训练脚本、运行有边界的实验、衡量结果、保留有用更改、丢弃无用更改。

## 核心洞察

### 为什么大多数"自主AI研究"项目有问题？
> "只看到了成功的部分：(Agent编辑了一些代码，运行了一个实验，展示了更好的结果……)"

**看不到的关键问题**：
1. 它的harness优化了什么？
2. 评估是否稳定？
3. Agent失败时会发生什么？

### AutoResearch设计哲学
**不是**: 通用AI科学家
**而是**: 严格约束的自主改进Harness

```
目标循环:
修改训练脚本 → 运行有边界实验 → 衡量结果 
     ↑_________________________________|
     有帮助保留 / 无帮助丢弃
```

### 关键设计特点
1. **小型代码库** — 简洁设计展示如何构建有用的自主改进Harness
2. **严格约束** — 边界明确的实验空间
3. **结果导向** — 以实际改进为保留标准
