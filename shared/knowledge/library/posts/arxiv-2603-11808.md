## 核心贡献

### 1. Skill四元组形式化定义
论文首次给出Agentic Skill的数学形式化：

**S = (𝒞, π, 𝒯, ℛ)**

| 组件 | 含义 | 对应OpenClaw |
|------|------|-------------|
| **𝒞** Applicability Conditions | 适用条件/触发条件 | Skill的触发条件 |
| **π** Policy | 核心程序知识/执行策略 | Skill的instructions + 执行逻辑 |
| **𝒯** Termination Criteria | 终止条件/成功验证 | Skill完成标准 |
| **ℛ** Interface | 标准化接口 | MCP工具接口 |

> "This formal structure ensures that skills remain simultaneously executable, reusable, and governable"

### 2. SKILL.md三层渐进披露架构

| Level | 组件 | 内容 | Token用量 |
|-------|------|------|----------|
| L1 | Metadata | YAML frontmatter: name, description, version, trigger | 30-100 |
| L2 | Instructions | 程序知识、工作流、最佳实践 | 200-5,000 |
| L3 | Resources | 可执行脚本、参考文档、模板 | 无限制 |

**关键洞察**: Level 1作为"table of contents"，使Agent能感知数千个Skill而不退化上下文窗口。

### 3. Skill提取三阶段框架

```
┌─────────────────────────────────────────────────────────────┐
│  Stage 1: Repository Structural Analysis                    │
│  - 使用repo2AI生成目录结构和文件内容表示                      │
│  - 识别核心执行脚本、配置文件、辅助模块                        │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│  Stage 2: Semantic Skill Identification                     │
│  - Dense Retrieval: bi-encoder编码task和code module         │
│  - Binary Ranking: cross-encoder精细排序                     │
│  - 提取标准: Recurrence, Verification, Non-obviousness,    │
│              Generalizability                               │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│  Stage 3: Translation to SKILL.md                           │
│  - Frontmatter Generation (YAML)                            │
│  - Instruction Drafting (LLM可消费的程序指导)                │
│  - Asset Bundling (scripts/, references/, templates/)       │
└─────────────────────────────────────────────────────────────┘
```

### 4. Tri-Agent架构案例分析

**TheoremExplainAgent (TEA)**:
- Planner: 教学设计，将定理转换为故事板
- Coding Agent: 将故事板转为Manim Python脚本
- Error Correction: 多轮调试循环

**Code2Video**:
- Planner: 内容结构化 + 视觉资源检索
- Coder: 故事板转Python + scope-guided auto-fix
- Critic: VLM评估空间布局和视觉清晰度

### 5. 四阶段安全验证管道

| 阶段 | 名称 | 验证内容 |
|------|------|---------|
| G1 | Static Analysis | 可疑字符串、未授权网络调用、文件系统操作 |
| G2 | Semantic Classification | 指令-目的对齐、隐藏prompt注入检测 |
| G3 | Behavioral Sandboxing | 隔离容器执行、网络隔离、资源监控 |
| G4 | Permission Validation | allowed-tools清单验证 |

> 社区Skill调查中**26.1%存在漏洞**（数据泄露、权限提升）

### 6. Agentic Stack: Skills vs MCP

论文明确定义了两层架构的互补关系：

| 维度 | Agent Skills | Model Context Protocol |
|------|-------------|------------------------|
| 主要职责 | 程序知识 ("What to do") | 工具连接 ("How to connect") |
| 存储单元 | SKILL.md目录 | JSON-RPC端点Server |
| 状态修改 | 上下文 + 系统权限 | 可用工具 + 外部数据 |
| 持久化 | 文件系统 (持久) | 会话级 (运行时) |
| 操作性质 | 知识/程序 | 连接/动作 |

**关键洞察**: Skills为MCP工具提供领域智能。
