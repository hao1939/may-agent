## 核心问题

在真实科研中，我们很难一开始就定义完美的优化目标。科学家通常根据实验反馈，不断调整评分函数、增加约束、重新平衡权重。

**SAGA** (Scientific Autonomous Goal-evolving Agents) 不仅仅是在给定的目标下进行搜索，更在于它能自主决定"应该搜索什么"。

---

## 核心架构：双层循环 (Bi-level Architecture)

```
┌─────────────────────────────────────────┐
│  外层循环: 目标演化 (Goal Evolution)      │
│  - LLM Agent 分析优化结果                 │
│  - 提出新目标建议                         │
│  - 将目标转化为可执行代码                  │
└─────────────────┬───────────────────────┘
                  ↓
┌─────────────────────────────────────────┐
│  内层循环: 方案搜索 (Solution Search)     │
│  - LLM 驱动优化                           │
│  - 遗传算法                               │
│  - 强化学习 (RL)                          │
│  - 在当前目标下搜索候选方案                 │
└─────────────────────────────────────────┘
```

## 实验验证 (5 个跨领域任务，含湿实验)

### 1. 抗生素设计
- 成功模拟并合成出 **4 种**对大肠杆菌有显著抑制作用的化合物
- **1 个**对人体细胞无毒且结构新颖

### 2. 纳米抗体设计
- 针对 PD-L1 从头设计纳米抗体
- **3 个**经实验证实为真实结合物
- SAGA 自主演化的复合评分函数成功区分结合剂与非结合剂

### 3. 功能性 DNA 设计
- HepG2 特异性增强子设计
- 相对 SOTA 方法 **~50%** 的性能提升
- 自主发现专家级目标（TF motif 富集、GC 含量限制）

### 4. 无机材料设计
- 针对永磁体和超硬材料进行设计
- 结果得到 DFT 计算验证

### 5. 化工流程设计
- 从零开始优化化学分离流程
- 产生新颖的工作流来分离水和丁烷

## 人机协作模式

SAGA 支持三种灵活模式：

| 模式 | 描述 |
|------|------|
| **Co-pilot** | 人机协作规划 |
| **Semi-pilot** | 人类反馈驱动 |
| **Autopilot** | 完全自主演化 |

---

## 关键洞察

> "让 AI 学会像科学家一样，在尝试中不断修正自己的目标"

- 自动化目标函数设计是科学发现代理的核心未满足需求
- 不是将目标视为固定输入，而是系统性地探索目标空间及其权衡
- 目标演化比固定目标搜索更有效

## 对我们的意义

### 与 MetaClaw 的相关性

**高相关** - SAGA 的"双层循环"架构与 MetaClaw 的自我进化理念高度吻合：

| SAGA | MetaClaw |
|------|----------|
| 外层: 目标演化 | 元学习循环 |
| 内层: 方案搜索 | 任务执行循环 |
| 目标代码化 | 技能/策略学习 |

### 可借鉴的设计
1. **目标代码化**: 将演化目标转化为可执行代码（不是自然语言）
2. **双层分离**: 明确区分"做什么"(目标)和"怎么做"(搜索)
3. **湿实验反馈**: 真实世界验证（对应我们的 gym 测试）
4. **渐进式自治**: 从 Co-pilot 到 Autopilot 的渐进过渡

### 假设关联
- 支持 **H-035** (决策拓扑理论) - 不同目标空间需要不同的搜索策略
- 支持 **Three-Loop Architecture** 合成 - SAGA 实现了任务执行 + 知识演化的双循环
