# 如何写好一个自己的Skill

**Source**: XHS@溪树知识 | **Likes**: 316 | **Collects**: 526 | **Date**: 2026-03-11

## 核心方法论

好的skill = **定场景 + 立目标 + 理规则 + 给示例 + 划边界**

### 1. 定场景
- 你什么时候用这个skill？
- 触发的条件、核心意图、上下文环境

### 2. 立目标  
- 帮你解决什么问题？
- 一句话说清楚成果，越具体越好

### 3. 理规则
- 怎么执行呢？
- 步骤、逻辑、约束条件

### 4. 给示例
- 参考什么？
- 输入→输出的完整样例，正例+反例

### 5. 划边界
- 什么不做？
- 明确限制、异常情况处理、兜底策略
