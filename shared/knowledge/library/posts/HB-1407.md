## Content

**Lossless-Claw** 是由 Martian Engineering 开源的 AI Agent 上下文管理插件。

### 核心问题
传统 Agent 系统使用滑动窗口机制，token限制导致旧消息被丢弃。

### 解决方案
通过 **DAG（有向无环图）结构的分层摘要机制**：
- 所有历史对话完整保存
- 自动压缩旧对话形成层级化摘要
- 按需动态恢复完整上下文
- 实现"几乎无限记忆"的 Agent 运行模式

### 技术特性
| 特性 | 说明 |
|------|------|
| 无损上下文管理 | 历史消息持久化，不因token限制被删 |
| DAG分层摘要 | 层级化摘要结构 |
| 按需展开 | Agent可随时检索恢复完整上下文 |
| SQLite持久化 | 对话和摘要统一存储 |
| **OpenClaw插件化架构** | 可作为Context Engine接入Agent系统 |
