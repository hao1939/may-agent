## 核心观点
SKILLRL框架：最高效的强化学习是教会AI"从失败中反思和进化"。

## 技术架构
### SKILLBANK — 会进化的"技能大脑"
区别于简单记忆，从经验中"蒸馏"可复用技能：

1. **从成功中提炼套路**: 把成功操作总结成"SOP"
   - 例：购物时"先搜关键词再筛选"

2. **从失败中总结教训**: 对失败轨迹深刻反思
   - 生成"错题本": 错误原因 + 正确做法 + 通用原则

### RL + 技能进化闭环
```
Agent利用技能大脑知识决策
    ↓
环境交互 → RL算法(如GRPO)更新策略
    ↓
频繁失败 → 触发反思机制
    ↓
从失败经验学习 → 生成新技能 → 更新技能大脑
```

## 实验效果
- 开源小模型 + SKILLRL → **性能吊打GPT-4o**
- ALFWorld等复杂任务成功率碾压主流RL和记忆增强方法
