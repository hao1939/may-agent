## 正文
作者Eyad在Amazon/Disney/Capital One写了7年代码，现在是AI Agent创业公司CTO，每天用Claude Code做生产级系统。这篇教程拿了7.3M阅读和55K收藏，核心是7条实战规则：
	
【先想后打】
打开Claude Code第一件事不是打字，是想。Shift+Tab×2进Plan Mode，把架构、技术选型、验收标准想清楚。"Build me an auth system"和"Build email/password auth using existing User model, store sessions in Redis with 24h expiry, add middleware for /api/protected"——产出质量差距巨大。5分钟规划省几小时debug。
	
【CLAUDE.md写法】
Claude每次启动都先读这个文件。四条原则：精简（模型只能可靠遵循~150条指令，系统提示已占50条）、只写项目特有的（别解释components是什么）、说why不只说what（"Use strict mode because we've had production bugs from implicit any"）、持续更新（按#键自动添加）。金句：好的CLAUDE.md像你明天会失忆时给自己留的笔记。
	
【上下文管理】
200K窗口在20-40%就开始降质。四招：功能分会话、外部记忆（SCRATCHPAD.md）、Copy-Paste Reset大法（复制关键→/compact→/clear→粘贴回）、果断/clear重来。
	
【提示词+模型分工】
具体>模糊，约束>开放，示例>描述。明确说"不要做什么"防过度工程化。Opus做规划，Sonnet做执行，CLAUDE.md保证交接一致。
	
【系统化】
claude -p跑headless批任务，日志复盘→改进CLAUDE.md→下轮更好。这才是AI编程的正确姿势。
