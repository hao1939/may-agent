## 核心内容

Kimi发布新论文，杨植麟署名，下一代模型架构曝光，获Karpathy、马斯克双双点赞，原帖超100万阅读。

### 核心创新：改动残差连接

**不是**改attention、FFN、位置编码，而是改动从2015年ResNet开始所有深度网络都在用的残差连接：

```
h = h + f(h)  →  被替代
```

**PreNorm稀释问题**：每一层贡献权重恒定为1，导致隐藏状态越加越大，深层相对贡献越来越小——深层网络在打酱油。

### Attention Residuals (AttnRes)

**核心思想**：
- Transformer用attention替代序列维度的循环RNN → Self-Attention
- 深度维度的循环（残差连接）也可以用attention

**机制**：
- 每一层不再无脑累加前序层输出
- 用学到的query向量，对所有前序层做softmax attention
- 选择性拿有用的，忽略没用的

**工程优化**：
- Block AttnRes：层分成若干block，attention只在block级别操作
- 避免O(Ld)内存爆炸，开销可控

### 效果

集成到Kimi Linear (48B/3B activated)：
- GPQA-Diamond +7.5
- HumanEval +3.1
- Math +3.6

Scaling Law跨所有规模一致提升，Block AttnRes追平1.25倍算力baseline。

### 统一视角

所有残差变体写成深度混合矩阵：
- 标准残差：全1下三角
- Highway：半可分矩阵
- **AttnRes：满秩稠密矩阵**

> "从RNN到Transformer是序列维度的注意力革命。AttnRes是深度维度的。"
