## Core Finding

来自UT Austin的研究者对视觉-语言-行动（VLA）大模型的持续强化学习（Continual RL）做了系统性研究，发现：

> **简单的序列微调（Seq. FT）加 LoRA 在可塑性、稳定性和零样本泛化上全面超越复杂的持续学习方法**

### Why Simple Works

1. **大预训练模型作为稳定器**: VLA模型参数量巨大，共享的底层视觉-语言理解能力成为天然稳定器
2. **LoRA的隔离效应**: 只更新一小部分参数，相当于给每个任务开了一个"微调频道"，主干知识基本没动
3. **预训练规模效应**: 规模大到一定程度，遗忘的代价就变低了

### Experimental Scope
- 3个VLA模型
- 5个终身学习benchmark
- 横跨模拟环境任务

## Implications for Continual Learning

### 传统认知
持续学习领域几十年老梗：
- 先学任务A → 再学任务B → 测试A → **基本不记得**（灾难性遗忘）
- 研究方向：经验回放、正则化约束、任务专属参数...越来越复杂

### 本文挑战
> "大模型时代，复杂方法的优势到底还有多少？"

## OpenClaw Mapping

| VLA Continual RL | OpenClaw Equivalent |
|------------------|---------------------|
| Seq. FT + LoRA | **Error Log + Skills** |
| 主干知识冻结 | AGENTS.md 核心稳定 |
| 任务专属适配层 | Skill模块化扩展 |
| 预训练规模抗遗忘 | L3设计哲学验证 |

### Core Insight

OpenClaw的 **Error Log（经验记录）+ Skills（能力扩展）** 架构，与VLA+LoRA在机制上高度同构：
- **主干稳定**: AGENTS.md作为预训练"知识主干"
- **模块化扩展**: Skill作为"适配层"，隔离更新
- **经验累积**: Error Log作为"任务经验"，不直接修改核心
