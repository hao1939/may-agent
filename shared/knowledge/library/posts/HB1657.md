## Summary

作者分析learn-claude-code系列，解读Claude Code如何在不修改核心循环的情况下扩展工具能力。

## 核心设计：映射表模式

```
字典的键 = 工具名
字典的值 = 处理函数
按名字查找就行
```

**架构分层**：
- **S01**: 底座（循环）— 核心执行逻辑不变
- **S02**: 扩展（工具注册）— 上层可插拔

## 关键洞察：专用工具 > Bash

| Bash方案 | 专用工具方案 |
|----------|--------------|
| 经过shell解析 | Python直接操作文件 |
| 解析风险 | 不经过shell解析 |
| 路径不可控 | 可加路径沙箱 |
| 可能越界访问 | 防止访问工作目录外文件 |

## 核心观点

> "安全可控比功能强大更重要 — 这是生产级agent的关键"
