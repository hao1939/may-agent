## 核心功能

RTK 是一个自动整理、压缩和去重命令行输出的工具。

### 问题场景
当 Claude Code 等 AI 在电脑上执行命令（如查看代码、运行测试、查看 Git 状态）时：
- 命令行返回**大量冗长信息**
- 其中**很多没有价值**
- 这些冗余信息消耗大量tokens

### RTK解决方案
RTK 自动对输出进行：
1. **整理** — 结构化关键信息
2. **压缩** — 去除冗余内容
3. **去重** — 消除重复信息

只保留真正重要的内容，再交给 AI。

## 对OpenClaw的启示

### 成本优化是真实需求
- 社区明确关注token成本问题
- 60-90%的节省幅度说明**输出压缩**有巨大价值

### 技术路径参考
RTK的思路可迁移到OpenClaw：
- **Command输出压缩** — 类似RTK的自动整理
- **Context去重** — 避免重复信息占用上下文
- **渐进式加载** — 只加载必要信息

### 与Error Log设计的协同
Error Log本身已是"去冗余"实践：
- 只记录关键决策和错误
- 不记录完整对话历史
- 与RTK"只保留重要内容"理念一致
