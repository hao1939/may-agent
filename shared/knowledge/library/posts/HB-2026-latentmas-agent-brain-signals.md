## 核心洞察

**Agent之间直接交换KV Cache，无需解码成文本再编码——"脑电波互传"**

LatentMAS是一个完全不需要额外训练的框架，让Agent之间实现非文本通信。与cache-to-cache类似，但应用于**Multi-Agent level**。

---

## 问题意识

当前的Agent协作模式本质上在**模仿人类**：
1. Agent A把模型里的东西解码成**文本**
2. Agent B读到文本后再**编码**回向量

**信息瓶颈**: 文本是离散的、低维的，而模型内部的潜空间状态是连续的、高维的。

> "模仿人类的交流方式，把高维状态压缩成文字来通信，不仅慢，可能还会丢失大量细微的语义信息。"

既然大家都是Transformer，为什么要费劲说人话呢？直接"加密通信"岂不是更高效？

---

## LatentMAS技术方案

### 步骤1: Latent Thoughts（潜空间思维）
- Agent A不再输出Token
- 而是自回归地生成**最后一层的隐藏状态**
- 通过线性层对齐后直接作为下一步的embedding输入
- 而不是map回文本字典空间
- 这些高维向量被定义为**Latent Thoughts（潜空间思维）**

### 步骤2: KV Cache直接传输
- Agent A思考完，直接把它的**KV Cache打包**，无损传输给Agent B
- Agent B不需要重新阅读文本
- 直接把这份记忆**拼到自己的缓存里**
- 然后接着A的思路往下想

### 对齐问题如何解决？
**关键洞察**: Agent系统里面的模型都是**同一个模型**，所以这是**agent-level的脑电波互传**，不存在分布偏移。

（cache-to-cache是llm-level的互传，不同模型间需要alignment）

### 线性层参数从何而来？
号称"不需要额外训练"，但线性层怎么来？

**答案**: 用数学公式推导出来的**解析解**
- 简单的岭回归
- 把隐藏状态映射到输入token的分布空间

## 实测效果

| 指标 | 效果 |
|------|------|
| **推理速度** | 提升**4.3倍** |
| **Token使用量** | 减少**83.7%** |
| **准确率** | 在数学、科学、代码等9个基准测试上平均提升**13.3%** |

**成本优势**: 对于生产环境来说，成本优势巨大。

**信息量验证**: 准确率提升证明"潜在思维"确实比"文本思维"包含了更丰富的信息量。
