## 论文标题
ToolTree: Efficient LLM Agent Tool Planning via Dual-Feedback Monte Carlo Tree Search and Bidirectional Pruning

## 摘要
Large Language Model (LLM) agents are increasingly applied to complex, multi-step tasks that require interaction with diverse external tools across various domains. However, current LLM agent tool planning methods typically rely on greedy, reactive tool selection strategies that lack foresight and fail to account for inter-tool dependencies. In this paper, we present ToolTree, a novel Monte Carlo tree search-inspired planning paradigm for tool planning. ToolTree explores possible tool usage trajectories using a dual-stage LLM evaluation and bidirectional pruning mechanism that enables the agent to make informed, adaptive decisions over extended tool-use sequences while pruning less promising branches before and after the tool execution. Empirical evaluations across both open-set and closed-set tool planning tasks on 4 benchmarks demonstrate that ToolTree consistently improves performance while keeping the highest efficiency, achieving an average gain of around 10% compared to the state-of-the-art planning paradigm.

## 核心创新

### 1. 双反馈机制 (Dual-Feedback)
| 信号 | 时机 | 功能 | 作用 |
|------|------|------|------|
| **Pre-evaluation (r_pre)** | 执行前 | 预测工具效用 | 引导选择、预剪枝 |
| **Post-evaluation (r_post)** | 执行后 | 评分实际输出 | 驱动回溯、后剪枝 |

### 2. 先验增强UCT选择
```
UCT(s,a) = Q(s,a) + λ·r_pre(s,a)·√(ln N(s)/N(s,a))
```
- Q(s,a): 利用项（累积后评估奖励）
- r_pre(s,a): 先验项（预执行预测分数）
- N(s), N(s,a): 访问计数

### 3. 双向剪枝 (Bidirectional Pruning)
- **Pre-pruning (τ_pre)**: 扩展前剪枝 — r_pre < τ_pre 的子节点不生成
- **Post-pruning (τ_post)**: 执行后剪枝 — r_post < τ_post 的边标记为不可扩展
- **确定性缓存**: 相同(a, args)调用直接复用结果

## 实验结果

### 封闭集工具规划 (GTA/m&m)
| 方法 | GTA AVG | m&m AVG |
|------|---------|---------|
| ReAct | 48.16 | 72.56 |
| ToT | 51.47 | 75.59 |
| LATS | 53.91 | 75.83 |
| **ToolTree** | **55.89** | **76.90** |

### 开放集工具规划 (ToolBench/RestBench)
| 数据集 | ToolTree | 相对提升 |
|--------|----------|----------|
| ToolBench | 69.04 AVG | +11.9% |
| RestBench-TMDB | 74.50 AVG | +9.8% |
| RestBench-Spotify | 71.36 AVG | +12.3% |

### 消融实验
| 变体 | 准确率 | 关键发现 |
|------|--------|----------|
| 完整ToolTree | 76.44 | 基线 |
| - Post-evaluation | 68.94 | **-7.5点，后评估最关键** |
| - Pre-evaluation | 71.80 | -4.6点，先验引导重要 |
| - 双向剪枝 | 74.58 | -1.9点，剪枝节省成本 |

## OpenClaw关联

### 架构映射
| ToolTree概念 | OpenClaw对应 |
|-------------|-------------|
| Pre-evaluation (r_pre) | AGENTS.md匹配 / L1意图验证 |
| Post-evaluation (r_post) | Error Log质量评分 / L2后验诊断 |
| Bidirectional Pruning | L1过滤 + L2验证 + L3审计 |
| UCT Selection | Sub-agent调度策略 |
| Training-free | 零微调设计哲学 |

### 关键洞察
1. **后评估 > 先验**: 移除后评估导致-7.5点准确率下降，证明执行反馈比预测更关键
2. **训练自由**: 零微调，纯推理时搜索，与OpenClaw设计哲学一致
3. **三层剪枝**: L1(pre) + L2(execution) + L3(post) 与OpenClaw分层验证完全对应
