## 正文
今年一月，安全研究员公开了一个编号为 CVE-2026-25253 的漏洞：攻击者只需要知道你的 OpenClaw Gateway 地址，90 秒内就能在你电脑上执行任意命令。
	
这个漏洞已经修复了。但它暴露了一个根本问题——OpenClaw 之所以强大，恰恰因为它有权限在你电脑上做任何事：读写文件、执行命令、控制浏览器、访问网络。
	
装好 OpenClaw 之后，它默认拥有你当前用户的全部权限。具体来说：
- 文件系统： 读、写、删除你能访问的所有文件，包括文档、照片、密钥文件
- 命令执行： 在终端里运行任意命令，安装软件、启动服务、修改系统配置
- 浏览器： 启动一个独立的 Chrome 实例，操控网页、填写表单、上传下载
- 网络： 发送 HTTP 请求、调用外部 API、访问内网服务
- 剪贴板和输入： 读取剪贴板内容
	
这些能力让它能帮你"真正干活"。但如果 AI 模型产生幻觉、第三方 Skill 有恶意代码、或者 Gateway 被未授权访问，同样的能力就变成了风险。
	
工作区配置：给 AI 立规矩
	
你需要要告诉 OpenClaw"你是谁、该怎么做事"。这一步很多人跳过了，但它直接决定了 AI 的行为质量和安全边界。
	
安全配置 + 工作区配置不是一次性的事，OpenClaw 每次大版本更新都值得回来检查一遍。但只要把上面这些做好——安全六件事 + 工作区八个文件 + API Key 管理——你已经比 90% 的用户更安全、更高效了。
