# HB#1579: AI Planning Framework for LLM-Based Web Agents

**Source**: arXiv:2603.12710 [cs.AI] (University of Haifa)  
**Date**: 2026-03-13  
**Type**: Academic Paper - AI Planning & Web Agents

## 核心贡献

本文将现代LLM Web Agent架构**形式化映射**到经典AI规划范式，建立了统一分析框架。

### 三大Agent架构 ↔ 经典搜索算法映射

| Agent架构 | 规划范式 | 搜索策略 | 代表实现 |
|-----------|----------|----------|----------|
| **Step-by-Step** | BFS (广度优先) | 每步d=1，优先考虑即时反馈 | WebArena, Mind2Web |
| **Tree Search** | 最佳优先树搜索 | 维护搜索树𝒯，用价值函数V(s)引导 | Koh et al. 2024 |
| **Full-Plan-in-Advance** | DFS (深度优先) | 预生成完整轨迹τ，严格按计划执行 | 本文新实现 |

### 关键形式化定义

**POMDP建模**：
- 状态空间 𝒮 (accessibility tree表示网页状态)
- 动作空间 𝒜 (click, type, scroll等)
- 目标：到达终端状态 s_G 满足用户指令

**Context Drift现象**：
> "Over many steps, the original goal simply falls out of memory, replaced by the most recent instructions"

**失败归因框架**：
1. 规划执行逻辑的**根本性缺陷**
2. LLM幻觉引入的**外部噪声**

## 五大创新评估指标

论文提出超越简单成功/失败的轨迹质量评估框架：

| 指标 | 描述 | 用途 |
|------|------|------|
| **Step Alignment** | 步骤级语义等价性 | 对比Agent与人类黄金轨迹 |
| **Element Accuracy** | 交互元素准确率 | 技术正确性评估 |
| **Trajectory Efficiency** | 路径效率 | 避免冗余动作 |
| **Error Recovery** | 错误恢复能力 | 从错误中恢复的质量 |
| **Partial Success** | 部分成功度量 | 细粒度进度评估 |

## 关键实验发现

**Step-by-Step vs Full-Plan-in-Advance对比**：

| 指标 | Step-by-Step | Full-Plan-in-Advance | 差距 |
|------|--------------|---------------------|------|
| 总体成功率 | 38.41% | 较低 | SBS胜 |
| Element Accuracy | ~70% | **89%** | FPA显著胜 |
| 人类轨迹对齐度 | 高 | 较低 | SBS胜 |
| 任务分解一致性 | 易漂移 | 高 | FPA胜 |

**核心洞察**：
> "While the Step-by-Step agent aligns more closely with human gold trajectories, the Full-Plan-in-Advance agent excels in technical measures"

## 与OpenClaw架构的映射

| 论文概念 | OpenClaw对应 | 映射关系 |
|----------|-------------|----------|
| **Full-Plan-in-Advance** | Main Agent + AGENTS.md规划 | ✅ 完全对齐 |
| **Context Drift防御** | Error Log + read_by机制 | ✅ 直接解决 |
| **全局约束** | 禁止运行时自进化 | ✅ 理念一致 |

### 关键验证

1. **AGENTS.md即"预规划"**：FPA要求预生成完整轨迹，AGENTS.md正是执行前生成的完整计划
2. **Error Log解决Context Drift**：论文识别的核心失败模式，Error Log直接对抗
3. **禁止Self-Evolution的合理性**：论文强调plan作为global constraint，运行时自进化会破坏它
