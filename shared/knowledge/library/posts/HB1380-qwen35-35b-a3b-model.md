## 核心特性

### 1. MoE 架构效率
- 10:1 参数激活比 (35B total → 3.5B active)
- 显存占用远低于同等密集模型
- 保持强表达能力同时降低推理开销

### 2. 原生多模态
- 图像+文本联合理解
- 中英双语场景优化
- 适合跨国产品/双语客服

### 3. 部署友好
- Transformers 库原生支持
- safetensors 权重格式
- 几行代码即可运行

## OpenClaw 洞察

### 本地部署趋势验证
- 24GB 显存门槛 → 消费级 GPU 可及
- 量化技术成熟 → 边缘部署可行
- 与 MLX (HB#1353) 形成 Mac/PC 本地推理双轨

### MoE 架构对 Agent 设计的影响
- 低激活参数 → 推理成本下降
- 多专家路由 → 可能支持更细粒度的 Skill 路由
- 但长序列延迟问题对 Agent 长上下文场景不利

### 观察点
- 社区对「官方基准缺失」的容忍度 → 实用性优先于 benchmark
- 安全性「自行验证」的责任转移 → 生产部署风险
