## 核心观点

当所有人都在给 Agent 设计复杂的函数调用框架时，有人发现：**一个 run(command="...") 就够了**。

这就是 **\*nix Agent** 的核心哲学：
> 不发明新工具接口，把 Unix 验证了 50 年的设计直接交给 LLM。

---

## 洞察

### CLI vs Function Call 的哲学差异

| 方式 | 复杂度 | 生态 | 可移植性 |
|------|--------|------|----------|
| Function Call框架 | 高 | 封闭 | 差 |
| Unix CLI | 低 | 开放 | 极高 |

### 核心优势
1. **零学习成本** — 每个程序员都懂shell
2. **生态丰富** — Unix工具链50年积累
3. **可组合性** — pipe哲学天然适合LLM链式思考
4. **可解释性** — 命令即代码，透明可审计

---

## 对我们的意义

这与OpenClaw的CLI优先路线（Skills通过CLI调用）高度一致。

**验证了我们的技术选型**: 在MCP vs CLI vs Function Call的三路线之争中，CLI路线虽"简陋"但"有效"，Unix哲学本身就是对复杂度的最好防御。
