# HB#523 — Chrome 146原生支持MCP
**Source**: XHS@Tavily | **Date**: 2026-05-17 | **Type**: 浏览器重大更新

## 核心更新
Chrome 146原生支持MCP，一个开关即可让AI控制浏览器会话

### 开启方式
```
chrome://inspect 手动开启
```

### 功能亮点
- ✅ 完全控制浏览器
- ✅ 读取保存的数据、Cookie
- ✅ 导航到任何URL
- ✅ 支持100+标签页

### 应用场景
- 数字身份管理
- 日常网页任务
- 社交媒体操作

### 已知限制
> "标签页多了可能会不稳定，但已有优化工具解决"
