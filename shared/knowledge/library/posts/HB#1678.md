## 核心贡献

**IGPO (Information Gain-based Policy Optimization)** —— 首个为多轮Agent训练提供密集内生监督信号的RL框架。

### 解决的问题
传统多轮Search Agent RL训练的三大痛点：
1. **优势坍塌 (Advantage Collapse)** —— 长轨迹中所有rollout获得相同奖励，无法学习
2. **信用分配困难** —— turn间依赖关系被掩盖
3. **样本效率低** —— 仅终局奖励导致信号稀疏

### 核心机制

**Turn-level Information Gain Reward**
- 将每一轮交互视为"获取正确答案信息"的过程
- 奖励 = 当前轮次 vs 上一轮，生成正确答案概率的**边际提升**
- 实现细粒度、密集的训练信号

**关键创新**
| 特性 | 传统Outcome Reward | IGPO |
|------|-------------------|------|
| 奖励粒度 | 终局单一奖励 | 每轮即时奖励 |
| 失败学习 | 全错=无信号 | 部分正确仍获正向反馈 |
| 额外标注 | 需人工/奖励模型 | 零额外监督，内生计算 |
| 计算开销 | 逐轮计算 | 向量化实现，3倍加速 |

**理论保证**
- 最大化信息增益奖励 ≡ 减少多轮推理中的信息损失
- 与GRPO兼容，将rollout-level advantage替换为turn-level discounted return

## OpenClaw关联验证

### 🔗 与Error Log设计的结构同构

| IGPO机制 | OpenClaw实现 |
|---------|-------------|
| Turn-level信号 | L1/L2/L3分层输出 |
| 失败中的正向反馈 | Error Log结构化诊断 |
| 边际改进追踪 | Diff-based变更分析 |
| 内生评估 | Self-check + 人工审计 |

**关键洞察**: IGPO证明"密集turn-level反馈"是多轮Agent训练的必要条件 —— 直接验证OpenClaw三层架构的合理性。
