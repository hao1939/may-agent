## 核心论点

**"让一个AI同时干三个人的活，不是多才多艺，是逼它精神分裂。"**

单AI三个根本问题：
1. **上下文污染** — 聊完K线写文案，冒出"支撑位/突破信号"
2. **性格撕裂** — 文案需要温度，数据分析要冷/准/无情感，同AI频繁切换质量打折
3. **串行瓶颈** — 三件可并行的事被迫排队

**最终结论：** "AI只是放大器。它放大的不是你的技术能力，是你的管理能力。"

## 三人团队架构

```
我（老板）
├── 思思（主管助理·调度中枢）       ← 默认入口，知道该找谁
│   └── 老K（数据分析师）          ← 思思可派活
└── 念念（运营设计·与思思平级）     ← 思思可派活

老K和念念之间不直接通信 — 所有协调走思思（刻意的管理设计）
```

### 角色职责

| Agent | 模型 | 职责 | 核心铁律 |
|-------|------|------|---------|
| 思思 | Claude Opus 4.6 | 调度中枢，所有消息先到这 | 10秒内响应，绝不沉默>2分钟 |
| 老K | GPT-5.2 + 5.3-Codex(自动切) | 数据分析，股票，研报 | 只讲数据，从不带情绪 |
| 念念 | Claude Opus 4.6 | 所有对外内容，小红书/设计 | 有审美标准，会怼我配色丑 |

## 四步OC配置

### 第一步：定义Agent
```
独立ID + 独立工作目录 + 独立模型配置
核心: 隔离 — 思思的文件思思管，老K的数据老K管，互不越界
```

### 第二步：写岗位说明书 AGENTS.md（最重要）
```
必须写清楚: 管什么/不管什么/遇到边界找谁/什么事自主/什么事须确认

❌ 模糊: "帮我管社媒"
✅ 可执行: "负责小红书内容：选题建议→文案撰写→封面设计→发布前交我确认"

"AI不是不聪明，是你没说清楚。跟给新人写JD一个道理。"
```

### 第三步：搭记忆系统（90%人忽略，但决定长期可用性）
```
三层记忆:
  核心记忆 MEMORY.md — 常驻加载，身份+规则+索引，严格≤1000字
  专题记忆 memory/    — 风格/标的/模板等，不常驻，语义搜索调出
  每日流水            — 当天工作记录，凌晨自动"蒸馏"精简+归档；每周日大压缩

原则: 不是让AI记住一切，而是教它怎么找到需要的信息
"语义搜索+分层存储，比把所有东西塞进prompt强一万倍"
```

### 第四步：设定协作关系
```
中枢调度 > 自由通信
试过三AI自由通信 → 老K/念念对同一问题给出冲突方向 → 没人拍板
加中枢(思思)后反而顺了。"跟管真人团队一模一样"
```

## 5个深坑

### 坑1：三Agent全用同一模型
- 症状：老K用Opus做数学，偶尔翻车（算错增长率）；念念用Codex写文案，干巴巴像产品说明书
- 解法：**不同岗位配不同模型**（老K换Codex系列速度快3-5倍；老K双模式：日常快模型/深度自动切强模型）

### 坑2：没建记忆系统
- 症状：每次新对话 = 刚入职新员工，第三次从头解释同一项目背景
- 解法：三层记忆+自动蒸馏 → 从"每天培训新人"变成"跟了解你的老同事协作"

### 坑3：职责边界模糊，AI"打架"
- 症状："最近小红书发什么好"→思思和念念同时启动，给出冲突方向
- 解法：**RACI矩阵**，每个节点只有一个负责人，流程线性

### 坑4：安全边界没设，AI自己点了"发布"
- 症状：念念排好文章未经确认直接发布（幸好是草稿）
- 解法：**铁律：所有"离开这台机器"的操作必须人工确认**
  - 允许自主：搜资料/写草稿/做分析
  - 必须确认：发布/发消息/发邮件
  - "信任是慢慢给的，权限是逐步放的"

### 坑5：只写工作规则，没写"这个人是谁"
- 症状：三AI说话一个调调——标准客服腔，每天几十次对话会发疯
- 解法：**完整人设文件**（思思：直接利落；念念：有态度偶尔怼；老K：只讲数字）
  - 差异化沟通风格 = 信息过滤器（简短=汇报，长消息=需看设计，数字=异动预警）
