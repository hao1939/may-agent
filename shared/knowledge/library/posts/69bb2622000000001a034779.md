## 核心内容

Stripe、Ramp、Coinbase 都在内部偷偷建设 AI 编码 Agent：
- Stripe: Minions
- Ramp: Inspect  
- Coinbase: Cloudbot

这些不是 Copilot 那种辅助工具，而是能独立接任务、写代码、提 PR 的"AI员工"。

## LangChain 开源 Open SWE

LangChain 创始人 Harrison Chase 将这些共同模式提炼成开源框架 **Open SWE**，今日发布。

## 三家不约而同的架构选择

### 1. 隔离沙盒
每个任务跑在独立云环境，有权限但严格隔离

### 2. 精选工具集
Stripe 给 Agent 配了约 **500 个工具**，每个都精心筛选

### 3. Slack 优先
在工程师已有工作流里接入，不学新工具

### 4. 丰富启动上下文
执行前加载完整的 issue、Slack 对话或 PR

### 5. 子 Agent 编排
复杂任务拆给专门的子 Agent

## 与 Cursor/Copilot 的本质区别

| 类型 | 模式 | 特点 |
|------|------|------|
| Cursor/Copilot | 辅助工具 | 在编辑器里给建议 |
| Minions/Inspect/Cloudbot | 自主工人 | Slack 说句话，Agent 自己写代码、跑测试、提 PR |

## 作者深度思考

### 1. 趋同进化 = 工程最优解
三家独立开发出几乎相同的架构，这种"趋同进化"说明这是工程最优解。就像分布式系统最终收敛到微服务架构，内部 coding agent 正在收敛到"沙盒+Slack+子agent"模式。这将成为行业标准。

### 2. "500个精选工具"的启示
约束反而让 Agent 更可靠——搜索空间变小了。和人类新员工入职一样，你不会第一天给他所有系统权限。

### 3. 真正的壁垒
对中小公司来说 Open SWE 意味着以前只有 Stripe 级别团队能建的东西现在开源了。但**真正壁垒不是框架代码，而是你的 AGENTS.md 里那些只有内部人知道的工程规范和业务逻辑**。
