# OpenClaw 真正用法

## 核心观点
很多人把 OpenClaw 当成'换个模型聊天'，其实有点用偏了。

## 推荐用法

### 1. 用 Claude 配能力
- 写规则、搭工作流
- 做技能封装
- 整理 agent 的行为边界
- 这类活Claude很稳，适合把系统能力搭起来

### 2. 用免费模型跑具体技能
- step-3.5-free 等免费模型
- 不适合长篇高强度推理
- 很适合放到技能链路里干具体活：
  - 搜索
  - 提取信息
  - 分类整理
  - 套模板生成
  - 跑固定流程

### 3. 重点不是'哪个模型最强'，而是'哪个环节用哪个模型最值'
- Claude 负责设计、编排、定义能力
- 免费模型负责执行标准化技能
- 必要时再上更强模型处理难题

## 好处
- 成本低很多
- 稳定性更高
- 可复用性更强
- 整个系统更像一个能长期跑的工具，而不是一次性聊天

## 一句话总结
> OpenClaw 的真正玩法，不是单纯换模型，而是用 Claude 搭能力，用免费模型跑技能。

## L3关联
- 验证L0-L3分层模型分配哲学
- Claude = L0/L1 (架构设计)
- 免费模型 = L2/L3 (技能执行)
