## 核心思想

CompassMem 将 memory 组织成 **Event Graph（事件图）**：
- Agent 沿事件图进行**主动搜索**，逐步收集证据
- Memory 不再只是存储信息，而是作为一张**"逻辑地图"**来引导检索和推理

### 与被动存储的区别

| 维度 | 传统 Memory | CompassMem |
|------|-------------|------------|
| 角色 | 静态外挂数据库 | 主动方向性线索提供者 |
| 检索方式 | 浅层语义相似度 | 结构化目标导向导航 |
| 组织形式 | 扁平存储 | 事件图 + 逻辑关系 |

### 类人记忆设计

直接对应人类记忆的**"联想式检索"**：
- 记忆以**事件为骨架**
- 由**丰富逻辑关联**连接
- 通过在网络中**导航**来选择性访问相关事件
- 从而支持规划与推理

## 作者的批判性思考

作者坦诚指出论文的问题：

1. **效率问题** (主要concern):
   - 高昂的 token 消耗和延迟
   - 落地性很差，"太 toy 了"

2. **与 Knowledge Graph 的区别**:
   - 文中虽有说明但预实验不足
   - 但作者认为这是手段而非重点

3. **核心想传达的观点**:
   > "关注 memory 问题一个新的方向：memory 在 agent 系统中的角色，即 memory 可以不仅仅提供'被动提供扁平知识'这一个功能"

## 对我们的意义
