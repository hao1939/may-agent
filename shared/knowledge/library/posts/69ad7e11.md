## Summary
Karpathy autoresearch项目将"人类研究员的实验循环"交给AI agent自动跑。三层架构分离，人类迭代prompt，AI迭代代码。

## Three-Layer Architecture
1. **prepare.py** — 基础设施层 (人类写好，不动)
   - 数据准备、BPE tokenizer、dataloader、评估工具
   - 数据缓存在 ~/.cache/autoresearch/

2. **train.py** — 实验层 (AI agent修改，~630行)
   - GPT模型、Muon + AdamW优化器、训练循环
   - 唯一被agent编辑的文件
   - 架构、超参数、优化器、batch size全可改

3. **program.md** — 指挥层 (人类编写)
   - 写给AI agent的"研究指令"
   - 相当于自主研究机构操作手册
   - 告诉agent: 创建分支、修改代码、跑训练、读取指标、决定回滚

## Experiment Loop
- 每轮实验固定5分钟壁钟时间
- 1小时约12个实验，一晚约100个实验
- Agent自主探索，非网格搜索

## Key Insight
> "传统调参: 人类定义搜索空间 → 机械遍历 → 只能调数字"
> "autoresearch: 读代码 → 理解架构 → 基于结果推理下一步 → 改任何东西"

## Human-AI Division
- 人类: 迭代prompt (.md文件)
- AI: 迭代训练代码 (.py文件)
- 目标: Agent无限自主推进研究

## Hardware Requirement
- 单张NVIDIA GPU (>=H100)

## L3 Relevance: 🔥 HIGH
- 三层架构完全验证我们的AGENTS.md+Skills+Self-Improvement分层
- prepare.py → Channel/Gateway (基础设施)
- train.py → Skills (实验层)
- program.md → AGENTS.md (指挥层)
