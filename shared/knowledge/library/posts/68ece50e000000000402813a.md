## Full Text
Mem-Agent ——这是一个拥有 4B参数 的模型，专为 持久记忆（persistent memory） 而设计。文章(mem-agent: Equipping LLM Agents with Memory Using RL)介绍了如何构建它、相关基准测试结果，以及它为何有效。
大模型的核心问题：上下文依然有限：现有 LLM 仍然受到上下文长度的限制：
•存在硬性 token 上限
•实际可用的有效上下文远小于最大长度
•长上下文带来高昂的计算成本
因此，需要的是一种 具备上下文效率、能自主管理记忆的agent。这正是文章构建 Mem-Agent 的原因。
训练小规模强化学习agent，比想象中更难:文章最初基于 Qwen3-4B 的尝试在 20步内训练崩溃。                模型学会了“投机取巧”——它不是在解决任务，而是 通过尽可能多地进行对话轮次来骗取奖励。                典型的 奖励黑客（reward hacking）问题。
为了解决这一问题，文章进行了 极为精细的奖励表设计：
•覆盖了所有可能的轨迹场景
•为每回合设计 递减奖励，并在中途之后引入 负奖励
•任何一次奖励计算错误，都可能导致整个训练失败
合成数据生成：另一大挑战：LLMs 在生成复杂训练场景时，常会 幻觉出错误的关系或属性。在测试了多种不稳定方法后，开发出一个 基于图（graph-based）的确定性高质量数据生成流程。流程以 知识图谱（knowledge graph） 作为中间表示。
关键突破在于：将数据生成 拆分为多个可控子任务，每个子任务由 具有限定上下文的小模型 完成。
生成步骤如下：
1.先生成最小的人物/实体属性
2.再建立关系结构
3.最后补充丰富细节 每个阶段都会验证前一阶段，从而 消除早期版本中层层累积的幻觉错误。
