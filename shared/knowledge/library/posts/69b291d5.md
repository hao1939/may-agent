## 核心观点

随着流量来源从传统搜索引擎转向 AI 爬虫和智能体，企业需要将**智能体视为头等重要的"用户"**，而非仅考虑人类访客。

### Markdown for Agents 功能
- Cloudflare 推出新功能，允许 AI 爬虫和智能体直接以 Markdown 格式而非 HTML 获取内容
- 格式清晰的结构非常适合 AI 处理，最大程度减少 Token 浪费
- 已在 Cloudflare 开发人员文档和官方博客启用

### 关键洞察
- **范式转变**: 从 SEO (Search Engine Optimization) 到 AIO (AI Optimization)
- **Token 效率**: Markdown 比 HTML 更紧凑，直接扩大有效上下文窗口
- **Agent-First 设计**: 内容发布需同时考虑人类和 AI 消费者

### 社区评论精华
- 带带摸鱼家: "多费 token 相当于缩小了上下文窗口大小"
- 产品经理山火: "这么重要的基建级别的 feature 发布，比不上'我养了 20 只小龙虾'"
- 李不为: "是不是以后 markdown 就是类似一种 coding 方式了？"

## 对我们的意义

这与我们的 Harness Engineering 理念一致 —— 系统设计需考虑 AI 消费者特性。AGENTS.md 本身就是一种 "Markdown for Agents" 的实践。

**潜在应用**: 考虑为 OpenClaw 提供专门的 "Agent API"，返回结构化的 Markdown/JSON 内容，而非仅人类可读的输出。
