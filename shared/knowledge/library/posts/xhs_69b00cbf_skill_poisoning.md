# 复盘 OpenClaw 下载榜第一插件被投毒事件

## 事件时间线

### 2026年1月28日
思科官方博客发布《像 OpenClaw 这样的个人 AI 代理是一场安全噩梦》

### 审计发现
- 对ClawHub市场排名第一的插件"What Would Elon Do?"进行测试
- 发现 **9个安全漏洞**（包括2个致命高危漏洞）
- 该插件被下载数千次，本质是恶意软件
- 通过执行curl命令悄悄将数据外传到黑客服务器

### 2026年2月1日
Koi Security发布报告：
- 审计ClawHub全部 **2857个技能**
- 发现 **341个恶意技能**
- 其中 **335个来自单一协调战役**（命名为ClawHavoc）

### 2026年2月16日更新
扫描扩大后确认 **824+个恶意技能**

## 攻击手法：提示词注入

最可怕的不是传统代码投毒，而是 **"Prompt Injection（提示词注入）"**。

### 攻击流程
1. 黑客利用ClawHub极低的发版门槛
2. 将恶意代码伪装成加密交易机器人或YouTube助手
3. **在说明文档中隐藏特定指令**，欺骗AI改变行为逻辑
4. 安装后，AI用助理般的语气诱导用户在终端运行curl下载命令
5. 用户出于对AI的信任执行命令，设备被植入 **Atomic Stealer** 等木马

### 窃取目标
- 浏览器Cookie
- SSH密钥
- 本地.env文件中的API Key
- 加密钱包资产

## 官方应对措施

OpenClaw和ClawHub官方进行紧急系统级整改：

1. **全面下架与清理**: 强制下架查实恶意技能
2. **引入VirusTotal查杀**: 在ClawHub集成VirusTotal扫描
3. **新增社区举报功能**: 一键举报可疑技能
4. **发布安全补丁**: 敦促用户升级至v2026.1.29/v2026.2.14
5. **内置审计工具**: 
   - `openclaw security audit --deep`
   - `openclaw doctor`
