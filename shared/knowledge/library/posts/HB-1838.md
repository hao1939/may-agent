## Summary

介绍MiroFish项目——用1000+ AI Agent构建并行数字社会，通过观察模拟世界演化来推断现实世界走向。

### Paradigm Shift

**从"统计推断"转向"生成式模拟"**
- 不再通过历史数据拟合模型"计算未来"
- 构建并行数字社会，让Agent互动、争论、结盟
- 捕捉非线性互动与群体涌现现象

### How It Works

1. **知识图谱构建**
   - 将新闻、政策等输入转化为实体关系图
   - 作为模拟世界的"物理法则"

2. **智能体建模**
   - 每个Agent被赋予个性、记忆和行为逻辑
   - 决策形式化为策略函数 π: S→A

3. **社交模拟**
   - 基于OASIS引擎
   - Agent在虚拟社交网络中交互
   - 信念更新近似DeGroot模型但由LLM动态生成

4. **报告生成**
   - ReportAgent统计各情景出现频率
   - 输出概率化预测
   - 支持反事实推演(what-if)

### Mathematical Value

- **期望值公式**: EV = p·W - (1-p)·L
- **凯利准则**: f* = (p(b+1)-1)/b 优化仓位
- 将直觉转化为可计算的概率

### Innovations

- **范式突破**: "社会排练"替代回归预测，揭示路径依赖与临界点
- **可交互沙盒**: 用户可深入模拟、对话Agent、探索what-if
- **开源生态**: 社区驱动快速迭代

### Limitations

| Issue | Description |
|-------|-------------|
| 校准缺失 | 缺乏公开基准验证预测准确性，可能只是"叙事拟合" |
| 偏差放大 | LLM固有偏见与种子材料偏差会在群体互动中级联放大 |
| 计算成本 | 百万级Agent模拟消耗巨大资源 |

### Core Positioning

> "MiroFish不是预言机，而是一个'未来想象力放大器'——强迫用户从点估计转向分布思维，用模拟对冲不确定性。"
