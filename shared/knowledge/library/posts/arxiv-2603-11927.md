## Abstract

Modern e-commerce search engines, rooted in passive retrieval-and-ranking models, frequently fail to support complex decision-making. CogSearch is a cognitive-oriented multi-agent framework that reimagines e-commerce search as a proactive decision support system.

By synergizing four specialized agents, CogSearch mimics human cognitive workflows: decomposes intricate user intents, fuses heterogeneous knowledge, and delivers actionable insights.

## Four-Agent Architecture

Based on Simon's three-stage decision model (1955):

### 1. Planner Agent — Intent-Driven Task Generation
- Input: Context tuple 𝒞t = {qt, ℋ<t^search, ℋ<t^click}
- Output: Task DAG 𝒢 = (𝒱, ℰ)
- Action space: ProductSearch (T_prod), WebSearch (T_web), ToolInvocation (T_tool)

### 2. Executor Agent — Multi-Source Acquisition
- **ProductSearch**: Keyword-Vector Fusion retrieval + Multi-Source Enrichment
- **WebSearch**: "Expand-Retrieve-Filter" pipeline
  - Query Expansion
  - Parallel Retrieval
  - Multi-Criteria Filtering: Score(d) = α·Rel(d,q) + β·Auth(d) + γ·Fresh(d)
- **Tool Integration**: MCP-based API invocation

### 3. Guider Agent — Cognitive-Aligned Guidance
- Dynamic Cognitive Facet Generation
- Clarify-Guide-Contextualize (CGC) mechanism
- Proactive need identification

### 4. Decider Agent — Integrated Decision-Making
- Synthesizes user profile, behavior context, interaction signals
- LLM-based reasoning for recommendations
- Structured decision rationale output

### Memory System
- Central hub for context storage
- Maintains agent states and task graph
