## Summary
PinchTab浏览器控制桥接工具详细介绍。1.3k GitHub Stars，通过无障碍树优先方案实现token消耗降低13倍。

## Technical Specs
- **无障碍树优先**: 不截图、不解析HTML，返回结构化无障碍树(e0, e1...)
- **Token效率**: 约1000 tokens/页，比截图方式便宜13倍
- **体积**: 12MB Go二进制，零配置
- **跨平台**: macOS/Linux/Windows
- **隐身模式**: 自动绕过navigator.webdriver检测
- **真实账号**: AI可直接使用已登录Chrome会话
- **内存优化**: 多Agent共享同一Chrome实例，省1.3GB/Agent

## Integration
- OpenClaw/NullClaw/Playwright MCP无缝集成
