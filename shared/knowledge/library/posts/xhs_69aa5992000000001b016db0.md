## Content Summary
Claude Code隐藏机制：`context: fork`将Skill变成独立Agent执行单元。

### 核心发现
- **普通Skill**: 文本注入当前对话，借用主对话context执行
- **context: fork Skill**: 开独立执行单元，有自己的工具集，看不到主对话历史，任务完成后返回结果

### 关键配置
```yaml
context: fork        # 加这一行，Skill 变 Agent
allowed-tools: Bash, Read, Glob  # 给它武器
```

Fork版本拥有SendMessage、TaskCreate等只有Agent才有的工具。

### 关键评论
- **作者回复**: "开成子agent关键在于上下文隔离，当然主agent能这样串行skill，但是上下文会不干净"
- **高能丽丽**: "这就是subagent的调用流程吧？" → 作者: "不是subagent是调用的agent tool"

## Relevance
- **完全验证我们的Skill-Agent统一设计路线**
- context: fork ≈ 我们的Skill.Runtime隔离
- allowed-tools ≈ 我们的Capability声明
