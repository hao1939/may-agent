## 核心内容

**问题**: Claude Code / Codex CLI 等终端Agent工具发展迅速，但训练数据策略不透明，研究者面临资源匮乏+轨迹收集成本高。

**方法 — Terminal-Task-Gen**:
- 轻量级合成任务生成管道
- 基于种子数据+技能分类学的任务构建
- Docker隔离环境生成解决方案轨迹
- 产出: 大规模开源 Terminal-Corpus 数据集

**实验**:
- 基准: Terminal-Bench 2.0
- 模型: Qwen3系列微调 → Nemotron-Terminal
- 消融实验: 数据过滤 / 课程学习 / 长上下文训练
- 核心结论: 高质量轨迹数据可弥合高效模型与前沿模型的性能差距
