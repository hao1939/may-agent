## Summary

作者分享3周AI Agent浏览器自动化实践踩坑经验，从Playwright+Agent转向PinchTab的真实体验。

## Key Points

### Playwright + Agent 的痛点
- 网页结构一改 → Agent卡住
- 读取整页HTML → Token成本极高
- Workflow越来越重 → 维护负担大

### PinchTab 优势
- 浏览器变成AI可直接调用的服务
- AI无需写复杂浏览器脚本
- 一步一步浏览、读取、决策
- 数据量更小，更像"人类浏览"
