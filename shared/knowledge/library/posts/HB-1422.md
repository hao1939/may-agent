## Paper Summary

### 核心贡献
**SearchLLM**: 首个用于开放式生成搜索的大型语言模型

### 技术框架

#### 分层多维奖励系统
将约束分为两个层级:
1. **底线约束 (Baseline)**: 事实基础、基本答案质量、格式合规
2. **行为优化目标**: 对噪声检索的鲁棒性、与用户需求对齐

#### 评估机制
- 奖励模型根据: 用户查询 + 会话历史 + 检索证据集
- 结合: 基于规则的检查 + 人工校准的LLM裁判
- 输出: 可解释的得分向量

#### 训练优化
- **门控聚合策略** (Gated Aggregation Strategy)
- **GRPO** (Group Relative Policy Optimization)

### 部署与效果
**部署平台**: RedNote (小红书) AI搜索入口

| 指标 | 效果 |
|------|------|
| 有效消费率 | **+1.03%** |
| 重新搜索率 | **-2.81%** |
| 安全可靠性 | 保持严格标准 |

## Key Insights

### 1. 搜索范式的转变
从"物品为中心的排名" (item-centric ranking) 到"答案为中心的合成" (answer-centric synthesis)

### 2. 奖励设计分层模式
```
底线约束 (不可协商)
    ↓
行为优化 (可提升)
```
这与OpenClaw的架构分层理念相通。

### 3. 生产部署验证
小红书AI搜索入口的真实部署，验证了技术方案的工程可行性。
