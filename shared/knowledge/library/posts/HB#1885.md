## 对OpenClaw的启示

### 短期（LLM Harness）
当前基于LLM的Agent架构（OpenClaw路线）是**正确且必要**的工程选择，但需认识到其本质边界：LLM是**通讯/推理工具**，不是**世界理解引擎**。

### 中期（2-3年）
World Model成熟后，OpenClaw的Harness架构需要适配新的感知层：
- 当前: LLM → Tool → 数字世界
- 未来: World Model → Physical Action → 物理世界

### 长期定位
Harness层（协调、审计、安全协议）在World Model时代依然关键，但执行单元会从LLM Calls变为World Model Simulations。
