## 核心内容

Google Cloud Tech 发布文章，归纳出 5 种实用的 Agent Skill 设计模式：

### 1. 工具包装器 (Tool Wrapper)
按需加载特定库的上下文知识，而非将所有规范塞进系统提示。适合封装团队内部编码规范或框架最佳实践。

### 2. 生成器 (Generator)
通过模板+风格指南的组合，强制Agent产出结构一致的文档，解决每次生成格式不统一的问题。适合API文档、报告生成等场景。

### 3. 审查器 (Reviewer)
将"检查什么"与"如何检查"分离——审查标准存放在外部清单文件中，可灵活替换（如从代码风格检查换成安全漏洞扫描）。适合自动化代码审查。

### 4. 反转模式 (Inversion)
颠转交互方向，让Agent先扮演"访谈者"，通过分阶段提问收集完整需求后，再生成最终输出。核心在于设置严格的"禁止跳过"门控条件。

### 5. 流水线 (Pipeline)
为复杂任务定义严格的顺序步骤，每步设置检查点，未经用户确认不得推进下一步，防止Agent跳步或输出未经验证的结果。

## 对我们系统的意义

这 5 种模式与我们的 SkillNet 架构高度相关：
- Tool Wrapper → 我们的 Skill 动态加载机制
- Generator → 文档生成 Skill 的标准化输出
- Reviewer → 代码审查/PR Review Skill
- Inversion → 需求收集阶段的交互设计
- Pipeline → 多步骤任务的 checkpoint 机制
