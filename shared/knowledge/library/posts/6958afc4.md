## 正文

### 范式分类框架

Agentic AI优化可以从两个维度分类：
1. **优化对象**: Agent (A) vs Tool (T)
2. **反馈来源**: 执行信号 (1) vs 输出信号 (2)

```
        | 执行信号 (Execution) | 输出信号 (Output)
--------|---------------------|------------------
Agent   | A1                  | A2
Tool    | T1                  | T2
```

---

### 1️⃣ A1: Tool Execution Signaled Agent Adaptation
**（看执行结果，改Agent）**

**特点:**
- 反馈信号极强、极其客观（报错就是报错）
- 适合代码生成、数学证明、API调用等有标准答案的场景
- 使用RLVR（Reinforcement Learning with Verifiable Rewards）

**论文举例:**
- **DeepSeek-R1 (Code)** / **CodeAct**: 通过强化学习，让模型在沙盒里不断试错，学会写出能完美运行的代码

---

### 2️⃣ A2: Agent Output Signaled Agent Adaptation
**（看最终答案，改Agent）**

**特点:**
- 反馈信号比较稀疏（做完一整套动作才给一个分）
- 适合复杂的QA、多步推理任务
- 容易让模型学会"大局观"

**论文举例:**
- **Search-R1** / **ReSearch**: 专门做搜索增强的。Agent自己决定搜什么，最后看回答问题的准确率来更新模型
- **Self-Refine**: Agent自己生成答案，自己当Critic给自己提意见，然后修改，全程不需要外部工具的硬反馈，只看最终质量

---

### 3️⃣ T1: Agent-Agnostic Tool Adaptation
**（独立优化工具，Agent不动）**

**特点:**
- 即插即用（Plug-and-Play）
- 工具通用性强，但可能跟特定Agent配合度一般

**论文举例:**
- **Dense Retrievers (DPR, ColBERT)**: 传统的向量检索模型，训练好放在那，谁都能用
- **HuggingGPT**: 这其实是个调度框架，它调用的成百上千个HuggingFace模型都是T1范式的代表——现成的、独立训练好的

---

### 4️⃣ T2: Agent-Supervised Tool Adaptation
**（Agent监督改工具，Agent不动）**

**特点:**
- **性价比极高**: 不用动昂贵的大模型，只训一个小模型
- **共生效应**: 工具完全为了配合Agent而生，效果往往比通用工具好

**论文举例:**
- **s3** (明星案例): 训练一个小的Searcher，目标是找到那些"能让冻结的大模型回答正确"的文档，而不是仅仅找"相似"的文档。数据效率比微调Agent高**70倍**！
- **AgentFlow**: 训练一个小的Planner来指挥冻结的专家模型，也是T2的典型
- **Mem-α**: 把记忆模块当做工具来训。如何读写记忆？看这对Agent未来的任务有没有帮助

## Amy 的分析

**核心洞察：Agentic AI优化的系统分类框架**

这篇论文速递提供了一个非常有价值的2×2分类框架，清晰地组织了Agentic AI领域的优化方法。

**框架解读:**

| 范式 | 优化对象 | 反馈来源 | 适用场景 |
|------|---------|---------|---------|
| A1 | Agent | 工具执行结果 | 有明确对错标准的任务（代码、数学） |
| A2 | Agent | 最终输出质量 | 需要大局观的复杂任务（QA、推理） |
| T1 | Tool | 独立优化 | 通用工具，即插即用 |
| T2 | Tool | Agent监督 | Agent专属工具，高性价比 |

**关键洞察:**

🔥 **T2范式的性价比优势**
- s3案例: 数据效率比微调Agent高**70倍**
- 不用动昂贵的大模型，只训一个小模型
- 工具完全为Agent量身定制

🔥 **A1范式的客观反馈**
- 代码报错就是报错，没有歧义
- RLVR在这种场景下特别有效
- DeepSeek-R1和CodeAct是典型案例

**对我们系统的意义:**

★ **OpenClaw的Skill系统属于T1范式** — 通用、即插即用，但可能需要向T2演进

★ **工具调用反馈机制** — 可以考虑引入A1范式的执行反馈来优化Agent
