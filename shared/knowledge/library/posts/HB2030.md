## 核心内容

### MCP架构
MCP采用客户端-服务器模型，分为三层：
- MCP主机（AI应用或代理）
- MCP客户端库
- MCP服务器

### MCP安全四大风险

| 风险 | 描述 |
|------|------|
| 未监控的访问 | AI助手可能访问或修改敏感数据而不被检测 |
| 缺乏内置审批流程 | 标准MCP实现对关键操作（数据库修改、金融交易）难以人工干预 |
| 有限的审计和监控 | MCP本身不提供全面的监控功能，导致安全调查信息缺失 |
| 权限管理复杂性 | 多个MCP服务器间管理访问权限复杂，增加敏感操作暴露风险 |

### 思科建议的8项安全措施

1. **JWT身份验证**: 带过期时间和令牌轮换机制
2. **标准化协议**: OAuth 2.1 / OpenID Connect
3. **加密凭据存储**: CyberArk Conjur / HashiCorp Vault
4. **访问控制**: RBAC + ACLs
5. **参数模式验证**: Validate all parameters against schema
6. **URL和外部标识符验证**
7. **文件路径和系统命令清理**
8. **适当的授权检查**
