## Core Contribution

四组件框架，自动从Agent执行轨迹中提取可执行的学习经验，通过上下文记忆检索提升未来性能：

| 组件 | 功能 | OpenClaw映射 |
|------|------|--------------|
| **Trajectory Intelligence Extractor** | 语义分析推理模式（分析/规划/验证/反思） | Error Log语义分析层 |
| **Decision Attribution Analyzer** | 因果归因：直接/近端/根因 | Step-level错误归因 |
| **Contextual Learning Generator** | 生成三类Guidance | Error分类体系 |
| **Adaptive Memory Retrieval** | 多维相似度检索 | Skill选择机制 |

## Three-Tip Typology（核心创新）

论文定义三种学习类型，与OpenClaw完全映射：

### 1. Strategy Tips（策略提示）
- **来源**: Clean Success（无错误、无冗余步骤）
- **内容**: 有效策略编码
- **示例**: "执行结账前系统验证所有前提条件（购物车、地址、支付方式）"
- **OpenClaw映射**: AGENTS.md最佳实践 / Skill成功案例

### 2. Recovery Tips（恢复提示）
- **来源**: Failure-then-Recovery（失败→识别→纠正→成功）
- **内容**: 错误处理和纠正序列
- **示例**: "结账失败时，先调用get_payment_methods()验证支付方式"
- **OpenClaw映射**: Error Log中的Recovery Pattern

### 3. Optimization Tips（优化提示）
- **来源**: Inefficient Success（成功但次优）
- **内容**: 效率改进机会
- **示例**: "清空购物车时使用empty_cart()而非循环调用remove_from_cart()"
- **OpenClaw映射**: Performance Review / 方向性批评

## Key Empirical Findings

**AppWorld Benchmark Results**:
- 平均提升: **+14.3 percentage points**
- 复杂任务: **+28.5pp (149%相对提升)**
- 关键洞察: 学习经验在复杂任务中价值最大

**验证的设计原则**:
1. **Provenance追踪**: 每个学习必须链接回源轨迹（验证有效性、审计）
2. **Step-level归因**: 第15步失败，问题可能在第3步（非显而易见）
3. **语义理解**: 超越关键词匹配，理解推理结构
4. **多维检索**: 任务类型+领域+语义相似度+执行模式

## Critical Insight: "Agents Have Amnesia"

> "Agents have amnesia because most LLMs are stateless. An agent that struggles with a particular API authentication flow today will struggle with the same flow tomorrow unless its prompts are manually updated."

直接验证OpenClaw设计哲学：
- **问题**: LLM Stateless → 重复犯错
- **OpenClaw解**: Error Log作为持久化外部记忆
- **增强**: 论文的Three-Tip框架可丰富Error Log分类

## 与OpenClaw架构对比

| 维度 | IBM框架 | OpenClaw |
|------|---------|----------|
| **记忆载体** | Vector DB + 结构化Tips | Error Log + AGENTS.md |
| **学习触发** | 自动轨迹分析 | 人类审查 (read_by) |
| **归因粒度** | Step-level自动归因 | Step-level人工归因 |
| **经验类型** | 3类Tips自动生成 | 方向性批评人工写入 |
| **检索机制** | 多维相似度 | 基于Task的Skill选择 |

**关键差异**: IBM框架强调*自动生成*，OpenClaw强调*人类审查*——这符合OpenClaw的Safety-First设计（避免错误传播）。
