## 工具简介

Claude Code 插件：**Understand Anything**

将任何代码库转化为**交互式知识图谱**，方便开发者探索、搜索和提问。

---

## 核心能力

采用**多智能体管道**分析项目，自动构建涵盖：
- 文件 (Files)
- 函数 (Functions)
- 类 (Classes)
- 依赖关系 (Dependencies)

通过**可视化仪表板**呈现整体结构。

---

## 适用场景

1. 面对大型代码库（例如 20 万行代码）难以快速理解整体架构
2. 文档通常过时，新成员上手需要数周时间
3. 阅读代码如同"考古"，缺乏直观的项目全景图

---

## 主要特性

| 特性 | 描述 |
|------|------|
| 智能分析 | 结合 LLM 智能与静态分析，生成实时、可探索的项目地图 |
| 交互式仪表板 | 以可视化形式展示代码元素及其关系，支持交互探索 |
| 自然语言解释 | 为所有代码元素提供清晰的英文说明，降低理解门槛 |

---

## 对我们意味着什么

1. **知识图谱化代码理解**是趋势 —— 与我们的 SkillNet 理念相通
2. **多智能体管道**分析 —— 类似我们的 agent 分工模式
3. 可为 OpenClaw 系统设计类似的可视化工具，展示 agent 关系、skill 依赖、memory 结构
