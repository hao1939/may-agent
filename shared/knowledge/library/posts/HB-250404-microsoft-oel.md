# Microsoft OEL: 在线经验学习实现部署中持续改进

**来源**: 小红书 @大模型知识分享 (56赞, 72收藏)  
**论文**: Online Experiential Learning for Language Models  
**日期**: 2026-04-04

---

## 核心问题

当前改进大语言模型（LLM）的主流范式依赖于**离线训练**，包括人工标注或模拟环境，而模型在**真实部署过程中积累的丰富经验**却未被充分利用。

---

## 解决方案: OEL

**Online Experiential Learning (OEL)** —— 使语言模型能够从自身部署经验中持续改进的框架。

### 两阶段闭环

```
┌─────────────────────────────────────────────────────┐
│  部署环境                                             │
│  ┌─────────┐    交互轨迹    ┌─────────┐             │
│  │  用户   │ ─────────────→ │  模型   │             │
│  └─────────┘                └────┬────┘             │
│       ↑                          │                  │
│       └──────────────────────────┘                  │
└─────────────────────────────────────────────────────┘
                          │
                          ▼
┌─────────────────────────────────────────────────────┐
│  第一阶段: 经验提取                                    │
│  从用户侧收集的交互轨迹中提取并积累可迁移的经验知识      │
└─────────────────────────────────────────────────────┘
                          │
                          ▼
┌─────────────────────────────────────────────────────┐
│  第二阶段: 知识固化                                    │
│  通过同策略上下文蒸馏将知识固化到模型参数               │
│  (无需访问用户侧环境)                                  │
└─────────────────────────────────────────────────────┘
                          │
                          ▼
                    改进后的模型
                          │
          ┌───────────────┴───────────────┐
          │                               │
          ▼                               ▼
    收集更高质量轨迹                 后续轮次更丰富经验
```

### 关键特性

- **循环迭代**: 两个阶段循环迭代，形成在线学习闭环
- **隐私保护**: 无需访问用户侧环境即可固化知识
- **质量飞轮**: 改进的模型→更高质量轨迹→更丰富的经验知识

---

## 实验验证

- **环境**: 基于文本的游戏
- **覆盖**: 多个模型规模
- **变体**: 思考与非思考两类

### 关键结果

| 指标 | 表现 |
|------|------|
| 连续迭代 | 稳定提升 |
| 任务准确率 | 提高 |
| Token效率 | 提高 |
| 分布外泛化 | 保持性能 |

---

## 深度分析发现

1. **提取的经验知识优于原始轨迹**
   - 经验提取过程过滤了噪声和冗余
   - 保留了可迁移的模式和知识

2. **同策略一致性对学习效果重要**
   - 知识来源与策略模型之间的同策略一致性是关键
   - 确保学习信号的有效性

---

## 对我们的启示

1. **部署后持续学习**: 模型部署不是终点，而是在线学习的起点
2. **经验提取 > 原始存储**: 从轨迹中提取结构化知识优于存储原始交互
3. **隐私保护设计**: 无需访问用户环境即可实现知识固化
4. **质量飞轮效应**: 改进模型→更好轨迹→更丰富经验→进一步改进
5. **与现有系统结合**:
   - JOURNAL作为轨迹存储
   - Compact作为经验提取
   - Insights作为知识固化目标
