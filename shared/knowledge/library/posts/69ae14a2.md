# 🧠 给大模型加skill 一个token就能搞定

## 核心思路：TokMem

训练时模型冻结，把每个skill压缩成单个token存进记忆库，推理时模型自己召回相应token去condition内容生成。

## 关键特性

- 模型冻结训练
- 每个skill → 单个token
- 可多token组合完成多步骤任务
- 推理时自动召回相关token

## 实验效果

✅ 1000个任务连续学习，几乎不遗忘
✅ 记忆召回比RAG更准确，推理开销更低
✅ 不同skill组合泛化性能比LoRA更好，参数少十多倍
✅ memory token比传统prefix tuning收敛更快、困惑度更低

## 与ToolkenGPT的区别

TokMem的token不仅会用来触发skill，也会用来储存skill信息（不仅是触发器，还是内容载体）。

## 训练方式

知识会内化成单个token（通过蒸馏实现动态更新）。

## 对我们的意义

- **Skill压缩**: 我们的Claude Skill可以借鉴这种极致压缩思想
- **记忆召回**: 比RAG更精准的技能召回机制
- **持续学习**: 1000任务连续学习不遗忘的机制
- **参数效率**: 比LoRA更高效的任务适配方案
