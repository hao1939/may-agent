## 项目概述

**OpenClaw-RL**: LLM-based Agent的在线强化学习框架，把用户对话中的**不满、重问、纠正、满意**等自然反馈，自动转化为RL训练信号，让OpenClaw"越用越聪明"。

Tagline: *"Train any agent simply by talking"*

## 核心技术亮点

### 1. 完全异步4组件架构（最核心创新）🌟

```
Agent Server (前台对话)
    ↓
Trajectory Collector (轨迹收集)
    ↓
Evaluator (PRM/判别器评估)
    ↓
Policy Trainer (策略训练)
    ↓
[循环]
```

**关键设计**: 四者完全解耦，后台持续优化，前台对话零卡顿。

### 2. 三种学习范式（可自由组合）

| 模式 | 全称 | 机制 | 适用场景 |
|------|------|------|----------|
| **Binary RL** | Binary RL via GRPO | 把下一轮用户/环境反馈当成标量奖励（好/坏），PPO式优化 | 明确对错场景 |
| **OPD** | On-Policy Distillation | 从反馈中提取"后见之明"提示，计算token级方向性优势 | 细微改进场景 |
| **Hybrid** | Combination | 标量奖励 + token级信号联合优化 | 官方推荐，效果最强 |

### 3. 完全自托管 & 隐私优先
- 所有训练/推理都在本地跑
- 无需云API

### 4. 支持的真实世界Agent场景（非模拟器）
- 终端操作（shell sandbox）
- GUI自动化（屏幕+无障碍树）
- SWE（代码仓库+测试）
- 工具调用（function calling）

## 对我们意味着什么

### 🔥 与OpenClaw核心立场的张力

OpenClaw原设计原则：**禁止运行时自进化** ❌  
OpenClaw-RL：**在线强化学习，边聊边训** ✅

这看似矛盾，但仔细看架构设计有微妙之处：

1. **异步解耦** = 训练与推理分离，不阻塞用户交互
2. **用户反馈驱动** = 明确的信号源，非自主探索
3. **本地化部署** = 可控的训练环境

**结论**: OpenClaw-RL不是对OpenClaw的否定，而是**Skill层级的进化**——在保持Agent架构稳定的前提下，通过RL让Skill执行更精准。
