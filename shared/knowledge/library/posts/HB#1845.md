## 核心观点

> **Prompt 是临时的。Repo 结构才是长期的。**

很多人以为用 Claude Code 的关键是写 prompt。其实不是。关键是：**把 repo 结构设计给 AI 用**。

---

## 四组件架构

### 🔵 1️⃣ CLAUDE.md
**项目核心说明**：
- 系统做什么
- Repo结构
- 操作规则

> 越短越好。

### 🟣 2️⃣ .claude/skills/
**可复用 workflow**：
- code review
- debugging
- refactor
- release

> 相当于专家模式。

### 🟠 3️⃣ .claude/hooks/
**自动规则**：
- 自动跑 tests
- 自动格式化
- 禁止改关键目录

> 给 AI 加护栏。

### 🔴 4️⃣ docs/
**项目文档**：
- architecture
- ADR
- runbooks

> AI 不需要记住一切。只需要知道信息在哪里。
