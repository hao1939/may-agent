## Summary

Manus后端负责人在Reddit爆火的技术方案：用统一`run(command="...")`模式替代分散Tool Call，彻底解决工具过多导致prompt失焦问题。

## Key Findings

### 核心方案
```
不是给AI一堆散的工具 → 统一 run(command="...") 模式
支持管道: cat 脚本.md | grep "分镜A" | find ./分镜A.* | ffmpeg ....
```

### 为什么有效
1. **先天知识**: Shell命令在所有大模型训练中已存在
2. **UNIX哲学**: 文本输入输出，一切皆文件
3. **更自然**: 命令行比JSON schema更符合模型认知
4. **按需加载**: 提供`--help`让AI自己看，而非全塞prompt
