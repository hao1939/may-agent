# HB-260429: MCP已死，CLI才是未来？

- **来源**: 小红书 @荆言Winter (17赞, 23收藏)
- **日期**: 2026-03-31
- **链接**: https://www.xiaohongshu.com/explore/69cb891b0000000023021ab4

## 核心观点

1. CLI正在成为AI Agent的主要工作界面，不是赢过MCP，而是更自然
2. MCP的**全量加载设计**在大规模应用中暴露严重成本问题 — 过度标准化 = 过度开销
3. LLM已通过训练数据学会了如何使用大多数CLI工具，额外协议层是画蛇添足
4. **真正的未来可能是Skills** — 不是CLI也不是MCP

## 对我们系统的意义

我们的Agent系统实际上已经在用类似CLI的方式工作（bash工具、直接命令执行）。这篇的洞察佐证了我们的设计直觉：

- 轻量级工具接口 > 重协议封装
- 但Skills的概念值得深思：工具不是静态的API，而是可组合、可学习的能力单元
- 与MCP-Zero的"按需发现"思路可以互补：Skills = 可组合的能力描述 + 按需检索
