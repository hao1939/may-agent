## Summary

作者阅读Anthropic Claude Code团队文章《Seeing Like an Agent》的感悟，提出了AI Agent设计的换位思考原则。

### Key Takeaways

**为AI Agent设计工具/harness时，需要从Agent角度思考：**
1. 考虑模型当前能力，模型能力提升后需不断推翻之前假设
2. 换位思考：AI Agent具体需要哪些工具完成任务
3. 工具真的是必要的，还是会让Agent困惑

**Perplexity放弃MCP转向CLI**
- 反映核心概念：模型能力不足时需要更多scaffold
- 模型能力提升后，反而不需要过多干预
- 与OpenClaw "Context over Tools"理念一致

**产品设计的类比 (See like a user)**
- 用户当前能力是否足以达成目标？
- 用户手中的任务是什么？
- 需要提供哪些工具/功能协助完成jobs to be done (JTBD)？
- 用户能力是否随产品使用而提升？

> "两年前需要大量引导教用户与AI chatbot对话，今天很多用户根本不需要引导。过多引导反而让用户困惑烦躁。"

### Core Insight

设计AI Agent或AI产品时，需考虑**谁在**使用这个工具：
- 如果是AI Agent → 站在Agent角度考虑
- 如果是人 → 站在人的角度考虑

**未来需要的不仅是人类用户的empathy，还有Agent的empathy？**
