## 核心洞察

传统 RAG 和图记忆只能捕捉"两两关系"，难以把跨时间、跨片段、跨主题的高阶关联串起来，导致检索碎片化、回答不完整。

**HyperMem** 提出超图记忆架构，把长期对话拆成"主题—事件—事实"三层，用超边把分散但相关的内容重新组织。

---

## 技术架构

### 三层超图记忆

| 层级 | 作用 | 存储内容 |
|-----|------|---------|
| Topic | 主题脉络 | 对话主题结构 |
| Episode | 事件连续性 | 时间线上的事件序列 |
| Fact | 可问答事实 | 提取的具体事实 |

不再只是存聊天块或三元组，同时保留三层信息。

### 超边建模高阶关联
- 同一主题下的多个事件可被一条超边显式连接
- 同一事件下的多个事实可被一条超边连接
- **解决传统图结构难以表达"多对多联合依赖"的问题**

### 粗到细分层检索
```
查询 → 找主题 → 定位事件 → 抽取事实
```
- 逐层缩小候选范围
- 提高准确率，减少无关上下文干扰

### 词法+语义双索引
- **BM25**: 关键词匹配
- **Qwen3-Embedding-4B**: 深层语义相似性

### 轻量传播增强表示
- 通过超边做 embedding propagation
- 让时间上分散但语义相关的记忆获得更对齐的向量表示
- 提升跨时段检索能力

## 应用场景

- 需要**长期记忆**的对话 Agent
- **跨轮追踪**用户意图
- **多跳推理**（需要整合多个片段信息）

---

## 对我们的意义

我们的对话系统可能遇到的问题：
- 多轮对话后上下文丢失
- 跨 session 记忆不完整
- 难以关联历史中的相关信息

**可借鉴思路**:
1. 记忆分层：主题/事件/事实三层建模
2. 超图结构：显式建模多对多关系
3. 双索引：BM25 + 语义 embedding 结合
4. 传播增强：让分散记忆获得对齐表示

**值得验证**:
- 当前记忆系统是否已有类似分层？
- 跨 session 记忆检索准确率如何？
- 是否能引入超边概念优化 memory graph？
