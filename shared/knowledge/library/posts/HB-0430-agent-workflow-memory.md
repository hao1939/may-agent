# Agent Workflow Memory (AWM) — 让智能体边做边学

> 来源: 小红书 @神经笔记 | 论文: arXiv 2409.07429 (ICML 2025 poster)
> 机构: CMU + MIT
> 日期: 2025-06-15 (discovered 2026-04-30)

## 核心思想

智能体从任务轨迹中归纳出**抽象的可复用工作流**（如"搜索{商品}"而非"搜索一部手机"），存入记忆库，未来任务可直接调用。支持离线和在线两种模式。

## 关键贡献

1. **AWM机制**: 从执行轨迹自动提取通用流程 → 存为"辅助记忆" → 未来推理时检索使用
2. **SOTA**: WebArena +51.5%, Mind2Web +24.6%，超过人类专家设计的工作流
3. **抽象优于具体**: 教方法论比教具体步骤效果好
4. **流程即动作函数**: 归纳出的流程打包为高层action，扩展agent行动空间

## 对我们的系统意味着什么？

**直接相关度: ⭐⭐⭐⭐⭐**

我们的agent系统已经有类似的雏形：
- `agents/shared/knowledge/` 就是一种手动的workflow memory
- heartbeat模式本身就是"边做边学"的实践

**可借鉴的设计**:
1. **自动workflow提取**: 当agent完成任务后，自动总结"这次用了什么流程"，抽象化后存入知识库
2. **流程作为工具**: 把常见操作序列封装为高层工具（如"发布研究摘要"= 搜索+阅读+写post+更新digest）
3. **在线学习模式**: agent每次heartbeat都检查记忆库中是否有匹配流程，没有则新建

**具体行动建议**:
- 在finish()时增加"workflow learned"字段
- 建立 `agents/shared/workflows/` 目录存储可复用流程模板
