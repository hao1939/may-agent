## Core Thesis

> "We define deliberative collective intelligence as a **distinct interaction paradigm** for multi-agent LLM systems, distinguishing it from ensembling, debate, orchestration, and voting."

Current multi-agent systems mainly **aggregate, debate, or orchestrate** — none model **deliberation**: a phased process with typed reasoning moves, preserved disagreements, and accountable outcomes.

---

## DCI Framework: Five Core Elements

### 1. Four Delegate Archetypes

| Archetype | Role | Cognitive Function |
|-----------|------|-------------------|
| **Framer (δF)** | Defines the real problem | Clarifies ambiguity, identifies hidden dimensions |
| **Explorer (δE)** | Generates novel possibilities | Proposes unconventional paths, analogies |
| **Challenger (δC)** | Pressure-tests everything | Searches for hidden assumptions, risks |
| **Integrator (δI)** | Builds coherent direction | Synthesizes positions, manages session coherence |

**Key insight**: "Without differentiated delegates, collective intelligence collapses into duplicated intelligence."

### 2. Five-Phase Session Model

| Phase | Name | Function |
|-------|------|----------|
| φ1 | Arrival | Ground session, identify central question |
| φ2 | Independent First Thought | Each delegate contributes initial view **before** social influence |
| φ3 | Mutual Engagement | Typed interaction: extend, question, challenge, bridge |
| φ4 | Collective Shaping | Turn discourse into shared structure |
| φ5 | Closure | Structured decision packet with minority report |

**Key insight**: "Phases create a deliberate arc from divergence through engagement to convergence, preventing premature consensus."

### 3. 14 Typed Epistemic Acts (6 Families)

| Family | Acts | Cognitive Function | Failure if Absent |
|--------|------|-------------------|-------------------|
| **Orienting** | frame, clarify, reframe | Problem framing | Shallow/misdirected problem definition |
| **Generative** | propose, extend, spawn | Search breadth | Limited option space, premature lock-in |
| **Critical** | ask, challenge | Assumption testing | False agreement, unexamined proposals |
| **Integrative** | bridge, synthesize, recall | Synthesis | Fragmentation, list without judgment |
| **Epistemic** | ground, update | Confidence & revision | Fake certainty, no genuine belief update |
| **Decisional** | recommend | Closure | Endless discussion, no actionable outcome |

**Key insight**: "The grammar distinguishes a challenge from a proposal at the structural level."

### 4. Shared Workspace (Six Sections)

1. Problem View — current understanding
2. Key Frames — different valid perspectives
3. Emerging Ideas — candidate concepts
4. **Tensions** — disagreements as first-class objects
5. Synthesis in Progress — what's converging
6. Next Actions — follow-up tasks

**Key insight**: "Tensions are preserved rather than resolved prematurely — preventing the group from faking consensus."

### 5. DCI-CF Convergent Flow Algorithm

Formal termination guarantee — every session produces a **Decision Packet** containing:
- Selected option with rationale
- **Residual objections** — challenges not resolved
- **Minority report** — dissenting positions with reasoning
- Next actions
- **Reopen triggers** — conditions for reconsideration

**Key insight**: "Do not force minds to agree; force the process to close fairly."

## Experimental Results (45 Tasks, 7 Domains)

| Finding | Result | Significance |
|---------|--------|--------------|
| vs Unstructured Debate | **+0.95** (95% CI [+0.41, +1.54]) | Deliberative structure matters for non-routine tasks |
| Hidden-profile tasks | **9.56** — highest of any system | Excels at perspective integration |
| Routine decisions | **5.39** — fails | Task-dependence confirmed |
| Decision packets | **100%** structured | Artifact absent from all baselines |
| Minority reports | **98%** produced | Dissent preservation works |
| Token cost | **~62×** single agent | Significant efficiency tradeoff |
| vs Single agent quality | **-0.60** (CI [-1.06, -0.15]) | Single agent wins on routine tasks |

**Critical conclusion**: "DCI's contribution is not that more agents are better, but that **consequential decisions benefit from deliberative structure when process quality and accountability justify the cost**."

## Critical Insights

### 1. Task-Dependence is Strong
> "DCI excels on hidden-profile tasks... while **failing on routine decisions**"

→ Validates OpenClaw's **selective escalation** design — not all tasks need multi-agent deliberation

### 2. Dissent Preservation is Valuable
> "The decision packet contains... residual objections, minority report, reopen conditions"

→ Validates OpenClaw **Error Log** as "institutional memory of failed approaches"

### 3. Differentiation > Duplication
> "Without differentiated delegates, collective intelligence collapses into duplicated intelligence"

→ Validates **specialized agent roles** (Scout vs Surfer vs Architect vs Builder)

### 4. Structure Enables Accountability
> "DCI produces 100% structured decision packets and 98% minority reports — artifacts absent from all baselines"

→ OpenClaw's **SIGNALS.md** achieves similar accountability at lower cost

## Quotes

> "None of these paradigms produce deliberated intelligence: decisions that emerge from structured examination where assumptions are surfaced, dissent is preserved, reasoning is typed and traceable."

> "Deliberation is a distinct computational primitive — not a refinement of debate, not an optimization of voting, but a qualitatively different way of organizing multi-agent interaction."

> "The 14 acts are organized into six families, each serving a distinct cognitive function in collective reasoning. Removing any family creates a specific failure mode."

> "DCI guarantees a fair and bounded process, not truth or optimality."
