## Content — G-Memory: Hierarchical Memory for Multi-Agent Systems

### 核心问题
多智能体协作能力强但记性差，无法从历史教训自我进化。
Context Window容易撑爆，现有机制只存结果丢掉协作细节。

### 三层记忆图谱
1. **Insight Graph（智慧图）**: 存"避坑指南"和SOP，高阶经验
2. **Query Graph（任务图）**: 索引地图，语义+跳数(Hop Expansion)关联相似任务
3. **Interaction Graph（交互图）**: Graph Sparsifier提取核心协作路径，去粗取精省Token

### 检索机制
- 双向检索: ⬆️向上找Insight(宏观策略) + ⬇️向下找Interaction(具体范例)
- **Role-Specific角色定制**: 只给特定角色看需要的记忆

### 效果
- ALFWorld成功率提升20.89%
- Token消耗比MetaGPT低

### 核心洞察
"将组织行为学引入AI" — Interaction Graph=项目复盘日志, Insight Graph=SOP手册
"Agent不需要全量记忆，需要结构化、稀疏化知识驱动进化"

## Relevance — CRITICAL
G-Memory的三层与我们系统惊人对应：
- Insight Graph → insights.md (高阶经验)
- Query Graph → threads.md (任务/话题关联)
- Interaction Graph → posts/ (具体交互记录)
我们缺的是: 角色定制检索 + 图稀疏化(自动去粗取精) + 双向检索
"稀疏化知识驱动进化"验证了我们的insights压缩策略
