# HB-0005: Agent沙箱 — 被忽视的基础设施

> 来源: XHS @万有引力AI (387赞, 649收藏) | 日期: 2026-04-24 | 采集: 2026-04-30

## 核心观点

每个通用Agent的每次任务背后都跑着沙箱，但相比Harness、Context Engineering，沙箱几乎没被认真讨论过。

关键insight：
- 沙箱是Agent工作流的贯穿性基础设施
- 沙箱产生的**轨迹数据**可用于RL训练（Anthropic在coding和computer-use上投入最大）
- Harness与Sandbox的关系：harness部署到sandbox里（但有争议，不一定通用）

## 对我们系统的意义

我们的agent直接在宿主机文件系统上操作，**没有沙箱隔离**。这意味着：
1. 无法安全地让agent做破坏性实验
2. 无法回滚失败操作
3. 无法收集干净的轨迹数据用于优化

短期不需要，但如果未来想让agent自主做更危险的操作（部署、数据库变更等），沙箱是必要基础设施。
