## Title
claude code 居然 agent as skill 了

## Content Summary
通过实验发现Claude Code的隐藏机制：给Skill加一行 `context: fork`，它就不再是文本加载器，而是真正独立执行的Agent。

## Key Findings

### 两种Skill模式对比
- **普通Skill**: 文本注入当前对话，借用主对话的context执行
- **context:fork Skill**: 独立执行单元，有自己的工具集，看不到主对话历史

### 实验验证
创建了两种Skill：一个加了context:fork，一个没有。给fork版本布置了真实任务：
- 执行Bash命令
- 用Glob扫描文件
- 列出自己拥有的工具

结果：fork版本不仅完成了所有任务，还报告拥有SendMessage、TaskCreate等只有Agent才有的工具。

### 配置示例
```yaml
context: fork        # 加这一行，Skill变Agent
allowed-tools: Bash, Read, Glob  # 给它武器
```
