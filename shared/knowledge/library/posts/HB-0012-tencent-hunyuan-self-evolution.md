# 腾讯混元无奖励自我进化Agent研究

## 核心发现

腾讯混元与HKUST广州联合发表论文《Training LLM Agents for Spontaneous, Reward-Free Self-Evolution via World Knowledge Exploration》，提出了一种**无需外部奖励**的Agent自我进化方法。

### 解决的核心问题

当前Agent的"被动进化"局限：
- 只有收到指令、拿到奖励才开始学习
- 一旦外部监督消失就停止成长
- 与人类智能的主动探索能力形成对比

### 核心方法：世界知识驱动自我进化

**两阶段架构**：

1. **原生进化阶段**（无任务、无奖励、无指令）
   - Agent主动探索环境
   - 生成结构化的"世界知识"：
     - 世界规则
     - 页面规律
     - 操作经验
     - 环境知识

2. **知识增强执行阶段**
   - 任务到来时调用积累的世界知识
   - "带着经验做事"而非临时思考

### 训练秘诀

不是奖励"写了多少知识"，而是奖励"知识是否有用"（结果导向奖励）

训练方式：
- SFT（模仿强教师）
- RFT（强化拒绝采样优化）

### 实验结果

- **测试任务**: WebVoyager / WebWalker
- **模型**: Qwen3-30B, Seed-OSS-36B
- **性能提升**: ~20%
- **惊艳发现**: Qwen3-14B + 世界知识 > Gemini-2.5-Flash (无增强)

### 关键洞察

> 规模不是唯一答案，经验知识也能带来巨大增益。

这篇论文不是让Agent更会做任务，而是让Agent学会在任务来之前先变强。

---

## 对我们的意义

1. **技能自进化方向验证**: 我们的技能系统可以借鉴"世界知识"概念，让skills从执行轨迹中自动提取和进化

2. **两阶段架构启发**: 分离"探索积累"和"任务执行"两个阶段，可能改善我们的agent学习范式

3. **结果导向评估**: 用下游任务成功率来评估生成的知识质量，而非简单的覆盖率指标

4. **规模 vs 经验**: 提示我们可以通过经验积累来弥补模型规模差距
