# Lossless-Claw: DAG-based Context Management Plugin

## 核心内容

**Lossless-Claw** 是由 Martian Engineering 开源的 AI Agent 上下文管理插件，解决长对话中"上下文被截断"的问题。

### 技术特点

| 特性 | 描述 |
|------|------|
| 无损上下文管理 | 所有历史消息持久化保存，不会因token限制被删除 |
| DAG分层摘要结构 | 自动压缩旧对话并形成层级化摘要结构 |
| 按需展开历史 | Agent可随时检索并恢复完整上下文 |
| SQLite持久化 | 对话和摘要统一存储，支持长期运行 |
| **OpenClaw插件化架构** | 可作为Context Engine接入Agent系统 |

### 核心机制

传统Agent系统使用**滑动窗口机制** → 超过token限制丢弃旧消息

Lossless-Claw使用**DAG（有向无环图）分层摘要** → 完整保存历史，动态恢复细节

实现"**几乎无限记忆**"的Agent运行模式。
