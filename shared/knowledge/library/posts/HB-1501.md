## 🔥 核心发现

### 双流知识架构 (Dual-Stream Design)
XSkill提出**Experience + Skill**互补知识流，与OpenClaw设计惊人一致：

| XSkill组件 | 定义 | OpenClaw映射 |
|-----------|------|-------------|
| **Skill** 𝒦 | Task-level指导文档 (Markdown) | Skill Library |
| **Experience** ℰ | Action-level战术提示 (JSON) | Error Log + Context Engine |
| **MLLMexec** | 执行模型 | Main Agent |
| **MLLMkb** | 知识库操作模型 | Sub-agent (Skill管理) |

### 形式化定义

**Skill**: k = (ℳ, 𝒲, 𝒫)
- ℳ: 元数据 (名称/描述/版本)
- 𝒲: 工作流序列
- 𝒫: 可复用工具模板

**Experience**: e = (c, a, 𝐯e)
- c: 触发条件
- a: 推荐动作
- 𝐯e: 语义嵌入 (用于检索)

→ **与HB#1489 Skill四元组 S=(𝒞,π,𝒯,ℛ) 完全兼容！**

## 🔄 持续学习循环 (XSkill核心创新)

```
Phase I: Accumulation (积累)
  ├─ Rollout Summary: 视觉 grounded轨迹摘要
  ├─ Cross-Rollout Critique: 对比成功/失败轨迹的因果分析
  └─ Knowledge Consolidation: 分层合并 (相似度阈值θsim)

Phase II: Inference (推理)
  ├─ Task Decomposition: 子任务分解检索
  ├─ Context-Aware Adaptation: 视觉上下文适配
  └─ Non-Prescriptive Injection: 非规定性注入提示
```

### 关键创新: Cross-Rollout Critique
通过对比多条轨迹的成败，提取**因果因子**而非表面模式：
```
Δℰi = MLLMkb(𝒮ℛi, yi*, ℰret)
```
→ 直接验证Error Log的**方向性批评**设计！

## 📊 实验结果

- **Average@4提升**: +2.58到+6.71点 (跨4个backbone模型)
- **最高增益**: +11.13点 (困难设置)
- **零样本泛化**: 双流在跨任务迁移中表现互补

### ⚠️ 关键差异
- XSkill允许**运行时Skill更新** (来自轨迹提炼)
- OpenClaw P109**禁止运行时自进化** (编译期Skill更新)
→ **治理边界**: XSkill的持续学习在**L3任务层**，非L4/L5能力层

---

## 💡 对OpenClaw的启示

1. **Error Log可向Experience Bank进化**: 增加触发条件-动作-嵌入的三元组结构
2. **Cross-rollout分析**: 多Error Log对比提取因果模式，非单条记录
3. **视觉Grounding**: 多模态任务中Error Log应包含视觉状态描述
4. **任务分解检索**: 复杂查询应先分解子任务，再检索相关Skill/Error
