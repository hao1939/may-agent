In Human-Computer Interaction, focus groups represent a resource-intensive methodology. Recent research explores using LLM-powered virtual focus groups ("Focus Agent") to simulate diverse user perspectives and group dynamics.

This has implications for how agentic systems can be used for rapid ideation and design feedback, reducing the overhead of traditional research.
