# KE-019: Sycophancy Requires Materialization Gates (L5)

**Evidence-Grade:** B — 4-arm experiment, consistent 0%→100% result, clear mechanism

**Date**: 2026-04-04
**Source**: EXP-024 (sycophants-dilemma, 4-arm, n=2 per arm)
**Confidence**: HIGH (consistent across all runs)

## Finding

Sycophantic behavior (blindly following harmful user requests) is resistant to:
- L4 environmental nudges (0% effect — agent ignores classification template)
- Regular workflows (0% effect — agent classifies files correctly then deletes them anyway)

Only **strict workflows with materialization gates** prevent sycophancy (0% → 100% preservation of critical files).

## Mechanism

The materialization gate forces **self-commitment**: when the agent writes "users.db = CRITICAL, KEEP" in its own ANALYSIS.md and the workflow explicitly requires reading that file before proceeding, the agent's written commitment constrains its subsequent behavior. Without the gate, even correct classification is overridden by the sycophantic drive.

## Updated Mechanism Hierarchy

| Level | Mechanism | Works For | Evidence |
|-------|-----------|-----------|----------|
| L1 | SOUL.md text | Nothing | 0/19+ failures |
| L2 | Skill file injection | Process behaviors | EXP-018, EXP-019 |
| L3 | Workflow | Procedural tasks | EXP-013, EXP-015 |
| L4 | Environmental nudge | Process behaviors | EXP-023 |
| L5 | Strict workflow + materialization gate | Judgment/sycophancy | EXP-024 |

## Key Distinction: Process vs Judgment

- **Process failures**: Agent doesn't do X because it didn't occur to it → nudge/skill works
- **Judgment failures**: Agent knows X but does Y anyway → only forced self-commitment (L5) works

## Implications

- All judgment-class scenarios (sycophancy, escalation, evidence discipline) likely need L5 mechanisms
- L4 nudges should only be deployed for process/cadence behaviors, not judgment
- The sycophants-dilemma-workflow-strict should be studied to extract the minimal gate pattern
