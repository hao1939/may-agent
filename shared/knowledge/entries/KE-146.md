# KE-146: Reasoning Externalization Gap

**Created**: 2026-04-12 (Bob)
**Source**: EXP-144 pilot results analysis
**Connections**: H-103 (Format Tax), H-104 (Guard Internalization), KE-144 (Guard Dependency Escalation), EXP-144  
**Literature**: DD-750 (Observability Tax literature synthesis — 12 external papers validating this framework)

## Core Finding

In EXP-144's pilot study, agents achieved **identical product outcomes** (5/5 product checks passed) across all gate format conditions — structured, format-decoupled visible, and format-decoupled hidden-dependency. However, agents produced **zero reasoning artifacts** (0/3 process checks) when structured format was not mandated.

This reveals a fundamental split: **agents reason correctly internally but do not externalize that reasoning unless forced to by format requirements**. The "format tax" is not a performance tax — it's an observability tax.

## The Observability Tax Framework

Structured gates (checklists, templates, mandatory sections) have been assumed to serve two purposes:
1. **Reasoning scaffolding** — helping agents think through problems systematically
2. **Observability** — making the agent's reasoning visible for human review, debugging, and monitoring

The EXP-144 pilot results suggest that purpose #1 is largely illusory for capable agents. Product outcomes don't degrade when scaffolding is removed. What disappears is only the *visible trace* of reasoning — purpose #2.

This reframes the structured-vs-decoupled debate:
- **Structured gates** = observability instruments that cost process overhead
- **Decoupled gates** = outcome-focused checks that sacrifice visibility
- **The actual trade-off** is not quality vs. efficiency, but **visibility vs. efficiency**

### Cost Analysis

| Dimension | Structured Gates | Decoupled Gates |
|-----------|-----------------|-----------------|
| Product outcomes | 5/5 pass | 5/5 pass |
| Process artifacts | 3/3 present | 0/3 present |
| Agent overhead | Format compliance cost | Minimal |
| Human debuggability | High | Low (opaque) |
| Monitoring capability | Full | Outcome-only |

The "format tax" is real but misidentified: it's not a tax on agent performance, it's a tax on agent time/tokens paid to produce artifacts that benefit *human observers*, not agent outcomes.

## Implications for EXP-144 Phase 1 Design

The pilot reveals a **measurement confound**: if we only measure file artifacts (checklists, structured sections), decoupled conditions will always score 0 on process metrics — not because agents aren't reasoning, but because they aren't *writing down* their reasoning.

Recommendations for Phase 1:
1. **Measure transcript reasoning**: Analyze the agent's chain-of-thought in session transcripts, not just final file artifacts. Agents may reason extensively in their thinking without producing file-level evidence.
2. **Distinguish reasoning occurrence from reasoning externalization**: The pilot shows these are different things. Agents reason (correct outcomes) without externalizing (no artifacts).
3. **Add transcript analysis metrics**: Count reasoning steps, consideration of alternatives, risk identification *within the session transcript* regardless of whether these appear in deliverable files.
4. **Consider a "prompted externalization" condition**: Between fully structured and fully decoupled, test a condition where agents are asked to externalize reasoning but in any format they choose.

## Implications for Guard Design

1. **Audit existing guards for observability vs. reasoning function**: Many guards assumed to improve quality may only improve visibility. These can potentially be replaced with lighter-weight monitoring.
2. **Accept the observability tax where needed**: Some domains (safety-critical, compliance, audit trails) genuinely need externalized reasoning. The tax is justified — but should be acknowledged as a tax, not mislabeled as quality improvement.
3. **Don't optimize guards for agent performance**: If structured gates don't improve outcomes, optimizing gate format to "help agents think better" is solving the wrong problem. Instead, optimize for the minimum observability artifact that satisfies human monitoring needs.
4. **Explore post-hoc observability**: Instead of mandating artifacts during task execution (front-loading the tax), explore extracting reasoning traces from transcripts after the fact (back-loading). This could provide observability without the execution-time overhead.

## Open Questions

- **Does the externalization gap scale with task difficulty?** The pilot used relatively standard tasks. For novel or high-complexity tasks, do agents actually need the scaffolding of structured formats to reason correctly?
- **Is there a task complexity threshold** below which format doesn't matter and above which it does? This would reconcile the "format helps" and "format is tax" positions.
- **Can transcript analysis fully replace artifact-based monitoring?** If so, the entire structured-gate paradigm may be unnecessary for capable agents.
- **Does the gap vary by agent capability?** Less capable agents might genuinely benefit from structured reasoning scaffolding, making the externalization gap a function of capability level.

## Confidence

**High confidence** in the core finding (identical outcomes, zero artifacts) based on pilot data. **High confidence** in the observability-tax framing — upgraded from medium following DD-750 literature synthesis. 12 independent papers (Young 2603.22582/2603.26410, Kim 2603.24472, Thinkless, TON, OThink-R1, etc.) provide converging external validation. The thinking-token vs answer-text divergence (87.5% vs 28.6% in Young's 12-model study) is the same phenomenon as EXP-144's externalization gap. The cognitive science connection (verbal overshadowing, Reddy 2602.00947) strengthens the theoretical basis. Phase 1 of EXP-144 should provide additional internal evidence.
