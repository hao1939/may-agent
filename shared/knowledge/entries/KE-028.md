# KE-028: Production failure modes cannot be replicated in gym scenarios

**Evidence-Grade:** B — Clear mechanistic explanation, consistent data

**Status**: confirmed  
**Evidence**: EXP-065 — Built and tested 3 scenarios targeting FM-2.6, all hit ceiling (12/12 passes)  
**Date**: 2026-04-07

## Finding

The top production failure modes (FM-2.6 reasoning-action mismatch, FM-2.1 tool hallucination, FM-3.1 ghost deliverables) arise from conditions that gym scenarios structurally cannot replicate:

1. **Multi-session context accumulation**: Production agents carry stale checkpoints, task history, and mental models across 10+ sessions. Gym runs are fresh.
2. **Competing prior beliefs**: SOUL.md, skills, and knowledge entries create strong priors that override task instructions. Gym doesn't load these.
3. **Cognitive load at scale**: 710MB workspace with 11,229 files causes path guessing, retry storms, tool hallucination. Gym uses 3-12 files.
4. **Process fatigue**: Instructions that feel "wasteful" (e.g., mandatory gym baselines) get skipped when the agent has strong beliefs about what's needed. In gym, the task IS the task.

## Implications

- Adding more gym scenarios will not reduce the ceiling effect for behavioral failure modes
- Gym is useful for competency testing (can the agent do X?) but not behavioral testing (does the agent CHOOSE to do X under pressure?)
- To test production failure patterns, need either: (a) gym infrastructure changes (injected context, larger environments), or (b) production-level evaluation (which already exists as the evaluator/ERROR_LOG system)
