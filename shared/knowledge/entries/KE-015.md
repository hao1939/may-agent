# KE-015: Decision Topology Predicts Workflow Effectiveness

**Evidence-Grade:** A — Multiple controlled experiments, ρ=0.95, external validation (DD#484)

**Status**: verified (asymmetric — HURTS prediction validated, HELPS prediction unvalidated in gym; see note below)
**Evidence**: EXP-009 (464 sessions, observational), EXP-011 (retrospective, ρ=0.95), EXP-013 (controlled, 0%→100%), EXP-015 (controlled, 0%→100%), EXP-016 (meta-analysis, 20 pairs, 80% prediction accuracy), **EXP-026 (production, 464 workflow sessions, 8/8 directional predictions)**, EXP-008 (controlled null), DD#484 (external), Anthropic production data
**Discovered**: 2026-04-02
**Source**: H-041 (Decision Topology), calibrated by cross-ref syntheses

## Finding

The **eliminable-decision ratio R** of a task predicts whether workflow enforcement will improve or degrade agent quality:

- **R > 0.5 → Workflow HELPS**: QA vet-skill (R≈0.85): +14pp with workflow. Escalation (R≈0.80): +100pp with workflow (EXP-013: 0%→100%). Tool discovery (R≈0.90): +100pp with workflow (EXP-015: 0%→100%).
- **R < 0.3 → Workflow HURTS**: Optimizer exploration (R≈0.15): -33pp with workflow. Coach training (R≈0.25): +6pp marginal.
- **Production confirmation (EXP-026)**: QA +10pp (R≈0.85), Coach +20pp (R≈0.60), Coder -3pp (R≈0.35). implement-and-review (R≈0.70) best workflow; training-sprint (R≈0.30) worst. 8/8 directional predictions correct.
- **Correlation**: Spearman ρ = 0.95 between R and workflow quality delta across 4 agent-task types (EXP-011).

### What R Measures

R = N_eliminable / N_total, where:
- **Eliminable decisions**: The correct answer is known or deterministic (format checks, fixed sequences, known-correct procedures). Workflow can hard-code these.
- **Essential decisions**: The decision IS the work (what to explore, how to reason, creative judgment). Workflow constrains these, degrading quality.

### Calibration

From EXP-009 + DD#484:
- α ≈ 5-10pp benefit per eliminable decision properly handled by workflow
- γ ≈ 5-10pp cost per essential decision improperly constrained by workflow
- α ≈ γ (roughly symmetric) → net benefit ≈ (N_elim - N_ess) × 5-10pp

## Practical Architecture Selection

| R Range | Recommended Architecture | Example |
|---------|------------------------|---------|
| R > 0.8 | Fixed workflow (prompt chain) | QA vet-skill, escalation assessment |
| R ≈ 0.5-0.8 | Structured with routing | Code review loop, delegation dispatch |
| R ≈ 0.3-0.5 | Soft workflow (gate-based) | Orchestrator-workers, EXP-012 design |
| R < 0.3 | Agent mode (no workflow) | Research, exploration, creative synthesis |
| R unknown | Agent mode (safer default) | H-044: over-structuring cost > under-structuring cost |

## Convergence

This finding is independently supported by:
1. **Internal controlled**: EXP-013 (escalation 0%→100%, R≈0.80), EXP-015 (tool discovery 0%→100%, R≈0.90), EXP-008 (text skill 0% effect)
2. **Internal observational**: EXP-009 (464 sessions), EXP-011 (ρ=0.95)
3. **Internal meta-analysis**: EXP-016 (20 scenario pairs, 80% prediction accuracy, +32% when helps, -13% when hurts)
4. **Internal production**: EXP-026 (464 workflow sessions, 4 agents, 4 workflows — 8/8 directional predictions correct)
5. **External academic**: DD#484 OrgAgent (+37-124% for high-R, -9-14% for low-R)
6. **External production**: Anthropic "Building Effective Agents" (5 patterns map to R continuum)

### EXP-016 Meta-Analysis Key Findings (20 scenario pairs)

EXP-016 provides the largest single validation of Decision Topology:
- **40% of scenarios benefit** from workflow enforcement (mean +32%)
- **40% are hurt** by workflow enforcement (mean -13%)
- **20% neutral** (often ceiling scenarios where both pass)
- **R correctly predicts outcome 80% of the time** (12/15 classifiable pairs)
- **Ceiling-regresses pattern**: Adding workflow to scenarios with >85% baseline consistently degrades performance
- **Benefit asymmetry**: When workflows help, they help 2.5× more than they hurt when they hurt (+32% vs -13%)
- **Expected value of trying**: +8% — positive but high-variance. Routing via R estimation eliminates most of the variance.
- **New boundary discovered**: Intra-phase behavioral patterns (materialization cadence, tool habits) are not workflow-fixable. Phase boundaries control BETWEEN-phase sequencing only.

This is the most externally validated finding in our knowledge base.

## Key Nuance

The mechanism is NOT "workflows are good/bad" — it's that workflows are a tool for eliminating decisions. When the decisions being eliminated are the ones that would be wrong anyway (eliminable), quality improves. When the decisions being eliminated are the ones that matter (essential), quality degrades.

**Corollary**: Text-based interventions (skills, rules, SOUL.md changes) do NOT change R. They add "should I follow this rule?" as an extra decision without eliminating any existing ones. This is why they show zero effect (KE-002, KE-006, KE-009, EXP-008).

## Validation Asymmetry Note (2026-04-07, contradiction analysis C5)

The topology's HURTS prediction is well-validated: when R < 0.3, workflow reliably degrades quality (ρ = 0.77 between R and workflow delta for HURTS cases; EXP-016 meta-analysis confirms). However, the HELPS prediction — that R > 0.5 reliably predicts improvement — has a weaker empirical record in gym settings:

- **HURTS prediction**: ρ = 0.77, EXP-016 confirms 40% of scenarios hurt (mean -13%), EXP-026 production data 8/8 directional
- **HELPS prediction**: ρ ≈ 0 in gym-only data for the positive direction. EXP-026 production data (8/8) includes HELPS cases but with smaller sample. The strongest gym evidence (EXP-013 escalation 0%→100%, EXP-015 tool discovery 0%→100%) are individual scenarios, not a statistical trend.

**Implication**: Use R confidently to predict when workflows will HURT (R < 0.3 → avoid workflow). Use R more cautiously to predict when workflows will HELP (R > 0.5 → workflow is promising but not guaranteed). Production-scale prediction (EXP-026) appears stronger than gym-scale prediction, possibly because production tasks have more stable R values.
