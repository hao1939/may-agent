# KE-016: Workflow Effectiveness Depends on Decision Type

**Evidence-Grade:** B — Well-quantified with R ratio, 20 scenario pairs

**Source**: EXP-016 (Cross-Scenario Meta-Analysis), Coach, 2026-04-02
**Confidence**: HIGH (20 scenario pairs, 80% prediction accuracy)
**Category**: Training methodology

## Finding

Workflow enforcement (splitting tasks into explicit phases) is not universally beneficial. Across 20 tested scenario pairs:
- **Helps** in 40% of cases (mean +32% improvement)
- **Hurts** in 40% of cases (mean -13% regression)
- **Neutral** in 20% of cases

## When Workflows Help

Workflows help when the agent has **knowledge it can't act on** due to action bias or habitual behavior:
- **Assessment tasks** (R > 0.7): escalation 0%→100%, feasibility 40%→100%
- **Discovery tasks** (R > 0.5): tool discovery 0%→100%, dependency detection 60%→80%
- **Verification tasks** (R > 0.5): edge-case testing 83%→100%, root-cause diagnosis 63%→100%

The common mechanism: a forced externalization phase (write assessment, write plan, calculate independently) breaks the agent's default action-first behavior.

## When Workflows Hurt

Workflows hurt when:
1. **Baseline is already good** (>85%): adding phases only adds overhead and context fragmentation
2. **Decisions are essential** (R < 0.3): synthesis, creativity, and judgment can't be forced into phases
3. **Target behavior is intra-phase**: cadence, frequency, tool choice habits aren't controlled by phase boundaries

## Routing Rule

Use Decision Topology R ratio (EXP-011): R = N_eliminable / (N_eliminable + N_essential + N_navigation)
- R > 0.5 → workflow likely helps (+32% expected)
- R = 0.3-0.5 → uncertain, test both
- R < 0.3 → workflow likely hurts (-13% expected)

## Implications

- Don't reflexively add workflow phases to failing scenarios
- Classify the task's decisions FIRST using Decision Topology
- Text injection remains 0% effective — structural intervention is the only proven method
- Some behavioral patterns (materialization cadence, grep habits) are not fixable by any known method
