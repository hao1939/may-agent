# KE-381: Mandatory failure analysis on rejected experiments generates valuable follow-on hypotheses

**Evidence-Grade:** B — Retrospective + prospective tracking (H-EXP-014)
**Status**: active (Phase 2 tracking: 1/5 closures produced follow-on)
**Evidence**: H-EXP-014 Phase 1 found 3 past experiment failures that could have spawned useful follow-ons but didn't. The failure analysis of H-EXP-011 → spawned H-EXP-012 (validated, 58-93% improvement) proves the pattern.
**Discovered**: 2026-07-29
**Promoted-from**: H-EXP-014 (episodic → declarative, per H-EXP-018 audit)

## Claim

Failed experiments are not dead ends. A mandatory 3-question failure analysis protocol produces actionable follow-on hypotheses:
1. **Why did it fail?** (root cause, not just "below threshold")
2. **What did we learn that we didn't know before?** (novel information)
3. **Does this suggest a different hypothesis?** (pivot opportunity)

Evidence: H-EXP-011 rejected (27% catch rate) → failure analysis identified mid-session confusion → H-EXP-012 validated (58-93% improvement). Without the failure analysis, the most impactful finding in the chain would have been lost.

## Implication

Never close a failed experiment without the 3-question analysis. The failure itself is data.
