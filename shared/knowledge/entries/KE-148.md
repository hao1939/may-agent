# KE-148: Format as Toll — Structured Gates as Task Decomposition Infrastructure

**Created**: 2026-04-12 (Bob)
**Source**: EXP-144 Phase 1 Results (N=50)
**Related**: H-103 (Format-Decoupled Gates), DD-747 (Format Tax), DD-748 (BCR), KE-134 (Hump Curve), KE-135 (Gate-Task Synergy), KE-146 (Externalization Gap), H-105 (Three-Layer Reasoning)

---

## Core Insight

**Structured gate formats are not a tax — they are a toll.** A tax is a pure cost that reduces capacity. A toll is a cost that buys access to something valuable. EXP-144 shows that structured format requirements in workflow gates provide three forms of value that offset (and likely exceed) their cost:

1. **Task decomposition** — Format templates force upfront planning that speeds downstream execution
2. **Reasoning externalization** — Format mandates are the only reliable way to make agent reasoning visible
3. **Auditability** — Externalized reasoning enables debugging, oversight, and learning

The "format tax" framing from DD-747 is misleading for agent systems. DD-747 studied format effects on single-turn benchmarks where format compliance competes with reasoning within a fixed output. In multi-turn agent workflows, format requirements at gate boundaries serve as *structural forcing functions* that shape the reasoning process itself.

---

## Evidence Base

### The Duration Paradox (strongest signal)
EXP-144 compared structured gates (mandated artifact format) vs format-decoupled gates (free-form reasoning) across 50 sessions. On compound-edit tasks (N=24):

| Condition | Mean Duration | SD |
|-----------|---------------|-----|
| Structured | 266.1s | 15.6s |
| Decoupled | 308.5s | 35.0s |
| **Difference** | **+42.4s (+16%)** | p<0.001, d=-1.56 |

**Removing format requirements made agents slower, not faster.** This is a very large effect (d=-1.56) in the opposite direction of what the "format tax" theory predicts. The structured format template appears to provide task decomposition that agents use to organize their execution efficiently. Without it, they explore more and backtrack more.

### The Externalization Gap (confirmatory)
On hidden-dependency tasks (N=26), 0/13 format-decoupled sessions created any reasoning artifact, despite being explicitly asked to "write your thinking in whatever format is clearest." All 13 structured sessions created the mandated artifact. Product accuracy was identical (100% both conditions).

**Agents don't externalize reasoning unless mandated to.** The reasoning happens in the chain-of-thought but never reaches a file. This isn't laziness — the agent solves problems perfectly without externalization. It's an architectural property: externalization is costly and adds no value *to the agent*. Its value is entirely for external observers (developers, monitoring systems, other agents).

### Accuracy Equivalence (context)
Product accuracy was 100% in both conditions across all 50 sessions. This confirms that format requirements don't hurt task performance at the current difficulty level (3 gates, well-within-capability tasks). But it also means the "format tax" isn't detectable on accuracy — it manifests as a speed and auditability tradeoff, not an accuracy tradeoff.

## Mechanism: Why Format Templates Speed Execution

The most likely explanation for the duration paradox:

1. **Template as plan.** When an agent must produce `ANALYSIS.md` with `## Problem / ## Root Cause / ## Fix Plan` sections, it is forced to decompose the task into these analytical steps before acting. This creates an implicit execution plan.

2. **Plan as commitment device.** Having written a plan artifact, the agent follows it sequentially rather than exploring alternatives. This reduces branching and backtracking.

3. **Format as cognitive anchor.** The template sections serve as a checklist — the agent knows it's "done thinking" when all sections are filled. Without this, the agent may spend extra time in open-ended exploration.

This mechanism explains why the duration effect is scenario-dependent:
- **Compound-edit** (complex, multi-step): Format-as-plan provides significant value → 16% speedup
- **Hidden-dep** (simple, find-and-fix): Minimal planning benefit → no duration difference

## Implications for Gate Design

### 1. Don't decouple format from reasoning gates
DD-747's recommendation ("generate freeform first, then extract structured artifacts in a second pass") may be correct for single-turn benchmarks but is **wrong for agent workflow gates**. In agent workflows, the format IS the scaffolding. Separating them removes the forcing function that makes gates valuable.

### 2. Format requirements serve different stakeholders
| Stakeholder | Value of format mandate |
|-------------|------------------------|
| The agent itself | Task decomposition, execution speed |
| The operator/developer | Auditability, debugging |
| Downstream agents | Structured input for next phase |
| The monitoring system | Process compliance verification |

No single stakeholder captures all the value. This is why format mandates appear to have "no accuracy benefit" — the benefit isn't accuracy, it's execution efficiency + observability.

### 3. Gate format should match task structure
The compound-edit duration effect (d=-1.56) suggests that format value scales with task complexity. For simple tasks, format adds little. For complex multi-step tasks, format templates provide significant task decomposition value. Gate design should calibrate format requirements to task complexity.

### 4. Connection to H-105 (Three-Layer Reasoning)
H-105 proposes three reasoning layers: latent (weights), thinking (chain-of-thought), and output (artifacts). KE-148's finding is that the output layer isn't just a report of the thinking layer — it's a **forcing function** that shapes the thinking layer. Mandating structured output causes more structured thinking, which causes faster execution. The layers interact bidirectionally.

## Open Questions

1. **Does the duration paradox hold at 4+ gates?** It's possible that format value peaks at moderate gate counts and becomes a net cost at higher counts (reconciling KE-148 with DD-747).
2. **Does format value scale linearly with task complexity?** The compound-edit vs hidden-dep contrast suggests yes, but only two data points.
3. **Can format templates be optimized?** Not all format requirements are equal — some templates may provide better decomposition scaffolding than others.
4. **Does this generalize beyond Claude?** DD-747's format tax findings were robust across 10 models. KE-148's reversal may be Claude-specific or task-specific.
