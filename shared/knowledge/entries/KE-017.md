# KE-017: Materialize-Findings Skill File Improves Both Behavior AND Product Quality

**Evidence-Grade:** C — n=3 per arm, single scenario

**Date**: 2026-04-04  
**Source**: EXP-022 (Coach)  
**Confidence**: Medium (n=3 per arm, single scenario)

## Finding
The `materialize-findings-concise` skill (3 rules: early write, write every 3 commands, reference in finish) is the first skill file to simultaneously improve:
- **Target behavior**: early-materialization +67pp (0%→67%)
- **Product quality**: report completeness +33pp (67%→100%)
- **Efficiency**: 44% faster completion (233s→130s)

## Why This Matters
Previous proven skill files improved either behavior or process but not product quality:
- `efficient-file-reading`: improved grep usage (behavior) but not task outcomes
- `structured-plan-writing`: improved planning (process) but not product metrics

The materialization pattern suggests that **forcing intermediate state persistence helps agents think more clearly**, producing better outputs faster. The act of writing findings crystallizes understanding.

## Mechanism Hypothesis
Materializing intermediate findings may work by:
1. **Reducing cognitive load**: Agent doesn't need to hold all findings in context
2. **Self-correction**: Writing forces structuring, which reveals gaps in analysis
3. **Progress tracking**: Written checkpoints prevent redundant re-reading
4. **Focus**: The write cadence creates natural analysis boundaries

## Applicability
Best fit for investigation-heavy agents (scout, coach, optimizer) that do multi-step analysis. May not help for simple fix-and-verify tasks.
