# KE-003: Rich delegation context reduces wasted ops by 47%

**Evidence-Grade:** C — n=5 sample, 47% figure has false precision

**Status**: verified
**Evidence**: EXP-002
**Discovered**: 2026-03-30
**Last verified**: 2026-03-30

## Claim

When callers include specific context in delegation tasks (file paths, error messages, root cause, fix approach), delegates use 47% fewer ops and 12% less time compared to minimal-context delegations.

## Evidence

May's delegation POC (EXP-002):
- Control (n=2, minimal context ~180 chars): avg 9.5 ops, 102.9s
- Treatment (n=3, rich context ~1200-1800 chars): avg 5.0 ops, 90.8s
- Delta: -47% ops, -12% time
- Control spent 2-4 ops on discovery before first edit. Treatment went straight to fix.

## Limitations

- Small sample (5 total). Needs more data.
- Only tested coder tasks. May not apply to research/design tasks.
- "Rich context" was hand-written. Automated context gathering (agents.context action) not yet tested.
