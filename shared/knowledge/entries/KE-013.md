# KE-013: Task Boundedness Is the Primary Driver of Delegated Session Quality

**Evidence-Grade:** B — 116 sessions analyzed with clear quantification, observational

**Status**: verified (observational)
**Evidence**: EXP-007 Phase 1 — 116 call sessions (7-day), 15,865 sessions (all-time)
**Discovered**: 2026-04-02
**Source**: H-014 (Delegation Quality Gap)

## Finding

In call (delegated) sessions, **task structure determines quality**:
- **Bounded-artifact tasks** (clear input, single output, verifiable): **90.0% good** (n=50)
- **Open-judgment tasks** (synthesis, diagnosis, planning): **40.6% good** (n=64)
- Gap: **49.4 percentage points**

This explains the hub-leaf performance gap better than information regime (H-013, refuted) or session kind alone.

## Key Nuance

Session kind (call vs job) is a proxy, not the cause:
- **QA**: +12.3pp on calls (bounded review tasks)
- **Coder**: +23.2pp on calls (receives well-scoped work from delegators)
- **Optimizer**: -38.6pp on calls (receives open-judgment tasks)
- **Bob**: -39.7pp on calls (receives synthesis tasks)

Agents that receive bounded tasks via delegation perform *better* than autonomously. The fix is task structure, not avoiding delegation.

## Implication

Convert open-judgment delegated tasks into bounded verification tasks wherever possible:
- ❌ "Diagnose this error pattern"
- ✅ "Check if [pattern X] matches these 3 sessions, return yes/no with evidence"
