# KE-008: Heartbeat step restructuring causes regression

**Evidence-Grade:** B — 4 experiments across 2 agents, consistent negative result

**Status**: verified
**Evidence**: 4 experiments across 2 agents (optimizer, coder), all negative
**Discovered**: 2026-03-17
**Last verified**: 2026-03-17

## Claim

Adding mandatory steps to an agent's heartbeat (e.g., "before acting, review X" or "after reading, summarize Y") degrades task performance. The added cognitive overhead displaces actual task execution, causing regression on previously-passing scenarios.

## Evidence

- **Optimizer** (Method #2): REGRESSION on all 3 scenarios (-2, -3, -2 checks). Heartbeat step restructuring added cognitive overhead that degraded core task execution.
- **Coder** (Method #2): REGRESSION on all 3 scenarios (-2, -3, -4 checks). Identical pattern to optimizer. Method #2 confirmed negative across both agents tested.

4/4 experiments showed regression. No improvements on any scenario.

## Mechanism

Agents have a finite attention/tool-call budget per session. Adding mandatory reflection steps consumes budget that would otherwise go to solving the actual problem. The "overhead" isn't free — it directly competes with productive work.

## Implications

- Don't add "read this first" or "review this checklist" steps to heartbeats
- If you need pre-task checks, bake them into the task structure (workflow enforcement, KE-007) rather than the heartbeat
- Heartbeats should be minimal: orient → prioritize → act
