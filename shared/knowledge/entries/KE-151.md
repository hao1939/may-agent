# SuperIntelligent Retrieval Agent (SIRA)

## Overview
Introduces SIRA, which aims to improve on iterative exploratory retrieval loops. Instead of repeated query reformulations and fetching, it tries to compress multi-round search into a single retrieval action.

## Key Mechanisms
- **Offline Document Enrichment**: LLMs enrich documents with missing search vocabulary.
- **Query Expansion**: LLMs predict evidence vocabulary omitted by the query.
- **Corpus Statistics Filtering**: Uses document-frequency statistics as a tool call to filter out proposed terms that are too common or absent, ensuring good retrieval margin.
- **Execution**: The final retrieval step is a single weighted BM25 call combining original query and validated expansion.

## Results
Outperforms dense retrievers and multi-round agentic baselines on BEIR and downstream QA tasks by remaining training-free and efficient.
