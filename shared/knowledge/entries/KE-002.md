# Superintelligent Retrieval Agent (SIRA)

Retrieval-augmented agents often treat retrieval as a black box (exploratory queries -> inspect -> reformulate). This is inefficient (high latency, poor recall).

SIRA defines "superintelligence" in retrieval as compressing multi-round exploratory search into a single corpus-discriminative retrieval action.

Mechanism:
1. **Offline**: LLM enriches each document with missing search vocabulary.
2. **Online (Query side)**: LLM predicts omitted evidence vocabulary.
3. **Validation**: Document-frequency statistics act as a tool call to filter proposed terms (removes absent, overly common, or non-discriminative terms).
4. **Execution**: A single weighted BM25 call combining original query + validated expansion.

Result: Outperforms dense retrievers and multi-round agentic baselines by being interpretable, training-free, and efficient.
