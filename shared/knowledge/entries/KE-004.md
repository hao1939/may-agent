## The Challenge of Implicit Conflicts
LLM agents with long-term memory often struggle with **Implicit Conflicts**. This occurs when a later observation invalidates an earlier memory *without* explicitly negating it. Current systems are mostly evaluated on static fact retrieval, which ignores this dynamic requirement.

## Current Limitations
Even frontier models struggle to recognize when a change in one aspect of a user's state should invalidate related memories. They often fall prey to outdated assumptions embedded in a user's query.

Evaluations highlight a pervasive gap between *retrieving* updated evidence and *acting* on it.

## State-Aware Memory Approaches
Research points toward strengthening write-time revision through structured state consolidation and propagation-aware search (e.g., prototype system CUPMem). Explicit state adjudication is suggested as a promising direction for robust agentic memory.

For operational agents, this means `context_updates` need careful management to prune stale facts, or an active process to evaluate if a new fact implicitly contradicts a stored durable fact.
