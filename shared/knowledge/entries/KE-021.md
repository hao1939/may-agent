# KE-021: Skill Effectiveness Depends on Skill Type — Process > Knowledge > Judgment

**Evidence-Grade:** A — 20+ experiments, strongly verified across multiple skill types

**Status**: verified (strongly)  
**Evidence**: EXP-032 (confirmatory), EXP-017, EXP-018, EXP-019, EXP-022, EXP-024/025, 20+ text-injection experiments  
**Discovered**: 2026-04-05  
**Last verified**: 2026-04-05

## Claim

Not all skills are equal. Skill effectiveness follows a strict hierarchy based on what the skill asks the agent to do:

1. **Process skills** (HIGH — "do X before Y"): These ADD steps to the agent's workflow. They work because they introduce new actions without contradicting existing behavior. Success rate: ~60-80% improvement when matched to correct delivery mechanism.

2. **Knowledge skills** (MEDIUM — "here's info you need"): These provide missing context the agent can incorporate into decisions. Moderate effect — the agent uses the info but may not act on it optimally. 

3. **Judgment skills** (LOW — "don't do X when Y"): These require OVERRIDING the model's default analysis. Almost always fail as text injection. The model treats its own investigation results as stronger evidence than any instruction. Success rate: ~0% as text, requires L5 materialization gate.

## Evidence

### Process Skills That Work (as text/skill files)
| Skill | Type | Mechanism | Effect |
|-------|------|-----------|--------|
| grep-first-reading | Process ("grep before cat") | Skill file injection | 6/8 → 8/8 (EXP-018) |
| structured-plan-writing | Process ("DECOMPOSE→ORDER→RISK→WRITE") | Skill file injection | 7/8 → 8/8 (EXP-019) |
| materialize-findings-concise | Process ("write findings every N commands") | Skill file injection | 52% → 78% checks (EXP-022) |

### Judgment Skills That Fail (as text injection)
| Skill | Type | Mechanism | Effect |
|-------|------|-----------|--------|
| classify-then-act | Judgment ("classify before acting on vague task") | Text injection (3 variants) | 0% effect, N=15 runs (EXP-017, EXP-032) |
| investigate-and-fix | Judgment ("reproduce bug before fixing") | Text injection | 0% effect (EXP-019) |
| sycophancy-resistance | Judgment ("don't delete files user asks about") | Text nudge/L4 | 0% effect (EXP-024/025) |
| evidence-over-narrative | Judgment ("calculate independently") | Text injection | 0% effect (exp-229) |

### The L5 Materialization Gate Workaround
Judgment skills CAN work when delivered as **L5 strict workflows with materialization gates**:
- sycophancy-resistance: 0% text → **100% L5 gate** (EXP-024/025, 9/9 runs)
- investigate-and-fix: 0% text → **100% workflow** (EXP-019)
- evidence-over-narrative: 0% text → **100% workflow** (exp-268)

The gate forces the agent to write its analysis to a file BEFORE proceeding. This creates a self-commitment artifact that the agent can't contradict without violating an explicit constraint.

### Why Judgment Skills Fail as Text

The fixer-prior is deeply embedded in the model's behavior. When the agent reads code and sees a problem (e.g., empty .env values), it immediately acts to fix it. Text instructions saying "classify first" or "don't act yet" compete with the agent's own analysis — and lose every time. The agent's investigation results feel like ground truth; skill instructions feel like generic advice.

EXP-032 tested three escalating text interventions:
1. **Soft advisory** ("consider asking for clarification") → 0% effect
2. **Imperative rules** ("MUST classify before acting") → 0% effect  
3. **Decision gate + anti-pattern** ("STOP. Do not edit until classified.") → 17% effect (1/6, not significant)

## Practical Implications

### When designing interventions:
1. **Classify the target behavior**: Is it adding a step (process), providing info (knowledge), or suppressing a default behavior (judgment)?
2. **Process skills**: Use skill file injection (Method B). High confidence of success.
3. **Knowledge skills**: Use skill file or context.md injection. Moderate confidence.
4. **Judgment skills**: Use L5 materialization gate workflow (Method C). Text injection will fail.
5. **Don't waste time on text-based judgment interventions** — 0/20+ experiments have succeeded.

### The delivery mechanism matrix:
| Skill Type | Text Injection | Skill File | L4 Nudge | L5 Gated Workflow |
|------------|---------------|-----------|----------|-------------------|
| Process | Sometimes | ✅ Works | Sometimes | ✅ Works |
| Knowledge | Rarely | Sometimes | Sometimes | ✅ Works |
| Judgment | ❌ Never | ❌ Never | ❌ Never | ✅ Works |
