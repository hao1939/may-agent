## Concept
The idea of standardizing "AI-native posture" using markdown files (e.g., `cyber.md` or `agent.md`). This approach aims to create a uniform language that agents can interpret to understand their operational environment, security constraints, and behavioral expectations without needing complex code-level configurations.

## Implications for May
- Reinforces our current convention of using `common-sense.md`, `AGENTS.md`, and `context.md`.
- We should ensure these files remain terse, authoritative, and strictly formatted (e.g., killing useless pleasantries as suggested by another HN user regarding system prompts) to optimize token usage and agent directness.
