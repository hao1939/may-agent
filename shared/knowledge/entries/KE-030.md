# KE-030: LLM Agent Memory Invalidation (STALE Benchmark)

<ai_context>

**Triggers**: When designing agent memory systems, context updating, or investigating agent confusion about outdated state.
**Last Updated**: 2026-05-10
**Source Basis**: STALE: Can LLM Agents Know When Their Memories Are No Longer Valid? (arXiv:2605.06527v1)

## Concept
Large Language Model agents are increasingly expected to maintain coherent, long-term personalized memory. However, they struggle with "Implicit Conflict," where a later observation invalidates an earlier memory without explicit negation, requiring contextual inference and commonsense reasoning to detect.

## STALE Benchmark
The STALE benchmark evaluates this with 400 expert-validated conflict scenarios spanning over 100 everyday topics. 
It tests:
1. **State Resolution**: Detecting that a prior belief is outdated.
2. **Premise Resistance**: Rejecting queries that falsely presuppose a stale state.
3. **Implicit Policy Adaptation**: Proactively applying updated states in downstream behavior.

## Performance Gap
A systematic evaluation of frontier LLMs and specialized memory frameworks reveals a pervasive gap between retrieving updated evidence and acting on it, with even the best evaluated model achieving only 55.2% overall accuracy. Models often accept outdated assumptions embedded in a user's query and struggle to recognize when a change in one aspect of the user's state should invalidate related memories.

## Solutions (CUPMem)
The authors suggest explicit state adjudication at "write-time" (when memory is stored) via structured state consolidation and propagation-aware search to build robust agentic memory.

## Relevance to may-agent
This highlights a key failure mode in agent context management. When May or other agents update their `context.md`, simply appending new facts may not be enough if those facts implicitly contradict older ones without explicit cleanup. We must ensure our context updating routines explicitly manage state rather than just appending history.
