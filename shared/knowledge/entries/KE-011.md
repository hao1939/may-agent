# KE-011: Knowledge files are passive — agents skip them under ALL conditions tested

**Evidence-Grade:** A — Verified with 0/29 discovery rate, expanded multiple times

**Status**: observed (strengthened)
**Evidence**: 3 experiments with Method #6 (Knowledge File) + 3 zero-discovery experiments (EXP-028, EXP-030, EXP-031b) totaling 0/29 agents discovering available resources
**Discovered**: 2026-03-17
**Last verified**: 2026-04-05

## Claim

Placing knowledge in INDEX.md or reference files that require the agent to actively seek them out is ineffective. Agents skip knowledge files **under all conditions tested** — including oneshot mode, nudge-based hints, and explicit task-text hints. This is not limited to passive availability; even when directed toward resources, agents exhibit zero spontaneous discovery. Knowledge files need an active delivery mechanism (injection or workflow enforcement) to have any effect.

## Evidence

### Original observations (Sprint 1)
- **Optimizer**: Knowledge file was present in fork but never read. "Optimizer in oneshot mode skips INDEX.md — goes straight to task. Method #6 alone is passive; needs delivery mechanism."
- **Coder**: Mixed results — one experiment showed 3/4 vs baseline 2/4 (promoted), but another showed 4/5 same as baseline. The promote case may have been due to the knowledge being in a file the agent happened to read for task reasons, not because it sought out the knowledge.

### Zero-discovery experiments (2026-04-05) — dramatically stronger evidence
- **EXP-028**: Workflows available in tool list → 0/21 agents used them spontaneously
- **EXP-030**: Common-sense.md nudge pointing to LIBRARY.md → 0/6 agents read it
- **EXP-031b**: Explicit task-text hint to check scripts/ → 0/2 agents checked
- **Combined**: **0/29 agents discovered available resources** across 3 resource types and 3 salience levels (available, nudged, explicitly hinted). 95% CI upper bound: <10%.

This evidence is dramatically stronger than the original Sprint 1 observations and confirms the problem is not just passivity but a fundamental cognitive-tunnel effect (see XREF-zero-discovery-cognitive-tunnel.md).

## Mechanism

Agents have a task-focused attention pattern: read the task, find relevant files, act. They don't browse reference materials unless the task or their heartbeat explicitly directs them to. Knowledge that isn't in the agent's direct task path is invisible.

## Implications

1. **Inject knowledge at the point of need** — put it in context.md (always loaded), not in reference files
2. **Workflow enforcement can deliver knowledge** — Phase 1 of a two-phase workflow can require reading specific files
3. **context.md is the only reliable passive delivery channel** (confirmed by KE-001)
4. **Skills need to be injected into the task context**, not just placed in the filesystem
