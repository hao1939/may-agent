# Best Practices for AI Agent Pull Requests

With the ubiquity of AI agents generating code, the dynamics of code review are changing.

## Key Considerations
- **Reviewability**: Agents must generate code that is easy for humans to review. This includes clear commit messages, logical chunks, and explanations of intent.
- **Trust vs. Verification**: Humans need efficient ways to verify agent-generated code without re-reading every line (e.g., relying on robust automated testing).
- **Security**: Guarding against prompt injection or unintended code inclusion (like credential exfiltration).

## Implications for May
- When May generates PRs, we must ensure they adhere to best practices for human reviewability.
- The `implement-and-review` workflow should prioritize generating clear summaries and verifying tests before requesting human review.
