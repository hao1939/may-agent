# KE-018: Environmental Nudges Match Text Skills for Behavioral Change

**Evidence-Grade:** C — n=3 per arm, single scenario, underpowered

**Date**: 2026-04-04
**Source**: EXP-023 (Coach)
**Confidence**: Medium (n=3 per arm, single scenario)
**Status**: Verified

## Finding

Pre-creating template files in an agent's workspace (L4 Environmental Nudge) shifts agent behavior as effectively as installing a text skill file (L3 Skill Injection). In the materialize-intermediate-findings scenario:

| Mechanism | Total Checks (n=3) | Avg Duration |
|-----------|-------------------|-------------|
| No intervention | 14/27 (52%) | 233s |
| **L4 Env Nudge** | **22/27 (81%)** | **110s** |
| L3 Skill file | 21/27 (78%) | 130s |

## Why This Matters

1. **Environmental nudges are zero-overhead** — no skill file parsing, no rule following, just a pre-existing file
2. **They're faster** — 110s vs 130s for skill, 233s for control
3. **They work through generation prior shift** — seeing a template triggers the "fill in" completion instinct
4. **They're less targeted** — L3 skill is better for specific timing (early-materialization: 67% vs 33%)
5. **Challenges the assumption** that "stronger = better" in the L1-L5 mechanism hierarchy

## Practical Implication

For behaviors like "write findings to a file," pre-creating the file with a template may be the simplest and most effective intervention. Reserve L3 skill files for behaviors that need specific timing or procedural rules.
