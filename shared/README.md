# shared

Shared resources across May-agent Apps.

## Active

| Entry | Purpose |
|-------|---------|
| `common-sense.md` | Team rules loaded into every agent's system prompt |
| `file-write-policy.json` | Host file-write lane policy |
| `host.env` | Shared host environment defaults |
| `guards/` | Structural turn guards (`auto-test`, `build-check`, `cost-limit`, `finish-guard`, etc.) |
| `tools/` | Shared agent tools (`ssh-exec`, etc.) |
| `skills/` | Shared behavioral skills available across Apps |
| `knowledge/` | Shared knowledge entries, hypotheses, and index (`knowledge/INDEX.md`) |
| `daily-digests/` | Historical daily summaries |
| `tests/` | Shared guard, tool, and workspace layout tests |

May-agent design docs live with their project App at `projects/alex.app/docs/`.
