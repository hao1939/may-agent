# Shared Knowledge

Files here are available to all agents by reading directly. Agents distill
relevant parts into their own `knowledge/INDEX.md` for automatic prompt loading.

## Reference Files

| File | Purpose |
|------|---------|
| `system-design.md` | System architecture |
| `team.md` | Agent roster and roles |
| `philosophy.md` | Design values and principles |
| `roadmap.md` | Product direction and priorities |

## Knowledge Sharing

| File | Purpose |
|------|---------|
| `bulletin.md` | Cross-agent findings needing attention or action |
| `knowledge-index.md` | Directory of what each agent knows and where to find it |
| `focus-tasks.md` | Current high-priority tasks bridging roadmap and todo lists |
| `best-practices.md` | Evidence-backed operational practices from 976+ evaluations |

## Skills
