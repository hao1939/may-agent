## 评论区：如何打通OC访问互联网（精华81条）

**方案1: xfce4+xrdp (作者)**
- Ubuntu Server加桌面 → 配合OC自带Chrome扩展 → 可访问网页
- 已验证多个窗口正确工作

**方案2: Brave Search API (北雁 ❤️3)**
- "联网搜索用Brave Search API，配合Google Places等API还可以获取精确位置天气预报"

**方案3: Chrome插件relay (龙虾北 ❤️2)**
- "浏览器那块直接用Chrome插件relay，captcha问题基本没有了"
- 日常GLM基础任务，复杂切Opus，**一天三块钱以内**
- "建议把常用操作封装成skill，代码质量和稳定性提升很大"

**方案4: WSL+图形依赖 (Bladydora ❤️1)**
- WSL里装浏览器+图形依赖 → 小红书发帖评论都成功

**方案5: 直接装浏览器 (nndhd ❤️1)**
- "告诉它，安装浏览器，非无头模式，安装依赖，就搞定了"

**方案6: Windows作为Node (jio ❤️3)**
- 日常搜索用Tavily skill（开发者API Key）
- 搜索X用Bird skill
- "满足了动动嘴搜索全网的梦想"

**方案7: Tailscale内网穿透 (azza)**
- "最方便且免费的内网穿透软件，tailscale，直接连"
