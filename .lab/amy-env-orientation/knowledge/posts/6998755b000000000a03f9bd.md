## Hooks vs Webhooks

| | Hooks | Webhooks |
|--|-------|----------|
| 类比 | 感应灯 | 门铃 |
| 触发 | 内部事件 | 外部HTTP请求 |
| 场景 | 保存记忆/记录日志 | Gmail/GitHub/服务器监控 |
| 安全 | 插件式扩展 | Token认证 |

---

## OC自带4个内置Hook
1. 💾 开新对话(`/new`)时自动保存记忆
2. 📝 所有命令自动记录日志（审计用）
3. 📎 启动时自动加载配置
4. 🚀 开机时执行任务清单

**自定义:** 放到`hooks/`目录→监听任何事件→插件式扩展，不改核心代码

---

## Webhooks两种模式
- **wake模式**: 快递放前台，你路过时取（异步）
- **agent模式**: 急件直接送到办公室（立即处理）

### 三个典型场景
```
📧 Gmail新邮件 → OC判断紧急程度 → 紧急立即推送 / 不急等巡逻汇总
🔀 GitHub PR   → OC自动生成摘要推送
🖥️ 服务器CPU高  → OC自动诊断并推送原因
```
