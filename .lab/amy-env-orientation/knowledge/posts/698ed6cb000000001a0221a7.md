## Key Content
Author researched OpenClaw subagents vs multi-bot task execution.

**Initial conclusion:** Sequential reasoning tasks don't benefit from multi-agent. Parallel tasks DO benefit. Not a "pseudo" tech path.

**Citing Google Research/DeepMind paper "Towards a Science of Scaling Agent Systems" (arXiv 2512.08296):**

1. **Sequential reasoning → multi-agent hurts:** All multi-agent variants tested showed 39-70% performance DROP on sequential reasoning tasks. Single-agent is optimal for linear logic.

2. **Error amplification is the core failure mechanism:**
   - Independent architecture: errors amplified 17.2×
   - Centralized leader architecture: errors compressed to 4.4×
   - **"The core of Multi-Agent is not 'multi' but 'collaboration topology design'"**

3. **Parallel complex tasks → multi-agent helps:**
   - Finance reasoning (highly parallel): centralized +80.8%
   - Dynamic web navigation (adaptive): decentralized +9.2%
