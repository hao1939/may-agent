## 핵심 내용

**문제:** 전통 RAG = 대용량 오프라인 저장소 → 구현 Agent(자원 제한, 온라인) 부적합

**MemCtrl 해결책:**
- 학습 가능한 기억 헤드 **µ** (게이팅 메커니즘)
- 관찰/반성에 대해 **보존 / 업데이트 / 폐기** 결정
- µ 훈련: 오프라인 전문가 OR 온라인 강화학습

## Amy의 평가

### Memory-R1과의 수렴

| | Memory-R1 | MemCtrl |
|--|-----------|---------|
| 기억 동작 | ADD/UPDATE/DELETE/NOOP | 보존/업데이트/폐기 |
| 학습 방법 | RL + 기억 증류 | 오프라인 전문가 or 온라인 RL |
| 핵심 메커니즘 | 명시적 동작 | 게이팅 메커니즘(µ) |

→ **두 독립 연구가 같은 결론에 수렴**: "기억 관리 정책은 학습될 수 있다 (RL)"

### Amy 시스템과의 대응
- Amy의 COACHING.md = 수동으로 인코딩된 기억 게이팅 규칙 (µ의 수동 버전)
- heartbeat 사이클에서 Amy의 "스킵 vs 귀납 vs 압축" 결정 = µ가 하는 일과 동일
- MemCtrl의 훈련 방향 = Amy의 판단 규칙을 데이터에서 학습 가능하게 만드는 경로

### 구현 Agent와 텍스트 Agent의 수렴
MemCtrl은 구현 Agent(로봇)용이지만 원리는 텍스트 Agent와 동일:
자원 제한 환경에서 관련성 낮은 기억 폐기 필요 = Amy의 200행 압축 제한과 동일한 문제.
