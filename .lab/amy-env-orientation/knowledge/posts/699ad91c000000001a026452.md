## 5大分类避坑

### 一、安装前置
1. 用**单独硬件终端**，别用主力机（隐私风险）
2. 先配好Claude Code/Codex → **让AI帮你执行安装和配置**（设备配对/gateway配置交给它处理）

### 二、模型API
1. **直接用Codex会员auth，不用单独配API**（省钱）
2. 国内coding plan也行，但要用好模型（否则龙虾笨）

### 三、浏览器插件（踩坑重点）
```bash
# 1. 官方命令安装（不要去网页搜索安装）
openclaw browser extension install

# 2. Chrome → chrome://extensions → 开发者模式 → 加载已解压扩展
# 3. 路径：Cmd+Shift+G 输入 ~/.openclaw/browser/chrome-extension
# 4. 有旧插件先删除

# 5. 右键新插件 → 选项 → 填入Gateway Token
openclaw config get gateway.auth.token
# 填入保存后点插件图标 → 感叹号变ON
```

### 四、机器人渠道选择
- ❌ **不要用飞书！** bug巨多、multiagent会串台、不能拉进群、发信息有长度限制
- ✅ 最好用**TG纸飞机或Discord**

### 五、搜索工具
- ❌ 不要用官方brave（注册需国外信用卡，花5刀）
- ✅ 直接用**Tavily的MCP工具**增强搜索能力
