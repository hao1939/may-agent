## 核心认知破除
**"3个Agent ≠ 3个AI账号"**
> 在OpenClaw中，1个Agent = 角色人设 + 独立记忆工作区 + 行为红线
> 把一个全能但容易晕的AI，切分成了3个专注且记忆清晰的"数字员工"

## 6步搭建多Agent团队（零代码基础 30分钟）

### Step 1: 安装OC
```bash
# 去 docs.openclaw.ai 一行命令安装
# 这是全程唯一需要碰终端的一步
```

### Step 2: 规划角色（经典三人团队）
```
Boss（调度者）← 只分发任务，自己不干活
Writer（文案）← 专职写文章，懂排版
Coder（程序员）← 专职写代码
```

### Step 3: 让OC搭团队（一句话搞定）
发给OC的提示词:
```
帮我搭建一个3人多Agent团队：
Boss(调度者) + Writer(文案) + Coder(程序员)
请帮我完成以下配置：
参考文档：https://docs.openclaw.ai
```
OC自动创建工作区、写角色人设、更新配置文件 ← **全程不用手动改配置！**

### Step 4: 申请Telegram Bot（各Agent配"手机"）
@BotFather → /newbot → 给Boss/Writer/Coder各申请一个Token

### Step 5: 让OC配置通信
把3个Token发给OC:
> "帮我配置Telegram多账号通信"
OC自动写进配置+设白名单+重启服务

**⚠️ 白名单必须配！否则谁都能使唤你的AI团队，账单瞬间爆炸**

### Step 6: 测试
给Boss发: "帮我写一篇关于多智能体的文章"
→ Boss分发给Writer → Writer开始干活 ✅

## 工作区结构
```
~/.openclaw/
├── workspace-boss/
│   ├── SOUL.md      # 人设："你是主管，只分发任务"
│   ├── AGENTS.md    # 红线："禁止执行代码"
│   └── MEMORY.md    # 长期记忆
├── workspace-writer/
└── workspace-coder/
```
**⚠️ 避坑：工作区必须物理隔离！文案读到程序员的代码记忆→必定翻车**

---

## 3条避坑铁律
1. **不让一个Agent干两类事** ← 分权是稳定第一法则
2. **红线写在AGENTS.md** ← AI聪明但容易飘，规则约束边界
3. **工作区绝对物理隔离** ← 目录错乱=AI记忆错乱万恶之源
