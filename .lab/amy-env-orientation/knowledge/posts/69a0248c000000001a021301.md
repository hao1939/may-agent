## 五大必备Skill详解

### 01. self-improving-agent ⭐484 · 369次安装
`clawhub.ai/pskoett/self-improving-agent`

**机制**: 错误→记录到`.learnings/`→新会话开始时注入上下文（Hook机制）
**实测**: "内容发布任务，装后同类问题三个月没再出现"
"错误发生的那一刻，就是学习发生的那一刻"
⚠️ 评论：OC本身只存在1个月，"3个月没再出现"是夸大，但效果确实存在

### 02. Ontology ⭐78 · 61次安装
`clawhub.ai/oswalpalash/ontology`

**"最被低估的一个"**
- 把记忆变成**知识图谱**（而非上下文窗口）
- 实体类型: Person / Project / Task / Event / Document
- 关系: has_owner / has_task / references / for_event / blocks
- 可约束: "任务之间不能有循环依赖"
- 类比: "普通AI记忆像便利贴，Ontology给它装了Notion数据库"

### 03. Find Skills ⭐121 · 197次安装
`clawhub.ai/JimLiuxinghai/find-skills`

解决"发现"问题 — 直接告诉AI想要什么，它自动搜索ClawHub并返回安装命令

### 04. Humanize AI Text ⭐59 · 40次安装
`clawhub.ai/moltbro/humanize-ai-text`

去AI味引擎: patterns.json(替换惯用句式) + transform.py(注入口语化停顿) + detect.py(AI味指数) + compare.py(前后对比)
GPTZero检测对抗

### 05. Agent Browser ⭐168 · 309次安装
`clawhub.ai/TheSethRose/agent-browser`

**"5个里最喜欢的"** — AI自主操控浏览器（Rust核心+Node.js兜底）
功能: 打开页面/点击/填表/截图/解析内容
用途: 定时抓竞品价格/自动填表/监控网页变化/批量截图/操作无API网站

## 核心框架
```
没装Skill的AI = 每次从零开始的顾问
装对Skill的AI = 能干活的员工

五个痛点对应:
  跨会话记忆→self-improving-agent
  记忆碎片化→Ontology
  不知道有什么能力→Find Skills
  输出内容有AI味→Humanize AI Text
  无法自主操作网页→Agent Browser
```
