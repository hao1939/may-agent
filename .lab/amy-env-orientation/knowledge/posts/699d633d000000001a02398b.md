## OC 2026.2.23 核心更新：省钱三板斧

**实测**: 日消耗 $54，cache write 占大头 → 升级后保守估计省 **15~20%**

### 1. Bootstrap文件缓存（最重要！）
- AGENTS.md / MEMORY.md 每个session缓存快照
- **改文件不再导致 prompt cache 全部失效**
- 之前每改一次就重建cache → cache write费用巨大

### 2. Inbound flags移到user context
- reply/forward/thread等动态标志不再打碎prompt cache
- **群聊场景cache命中率显著提升**

### 3. Compaction三个bug修复
- 模型不可用时不再截断历史
- summary失败时保留原文，**不丢上下文**
