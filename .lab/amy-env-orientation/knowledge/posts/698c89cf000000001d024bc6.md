## 背景：4个API Key的调度问题
- 2个Gemini Key（两个Gmail各注册一个，每个$300免费额度）
- 2个NVIDIA Key（官网免费注册的Kimi 2.5）

**没这个插件之前的痛点：**
- OC切模型就宕机
- Gemini 429了Agent在那空转
- 交给Codex修要花半天

## 安装（3步）
```bash
# 1. 安装到skills目录
cd ~/.openclaw/skills
git clone https://github.com/sarahmirrand001-oss/openclaw-switch.git

# 2. 重启daemon
openclaw daemon restart

# 3. 验证
openclaw-switch status   # 看到降级链就成功了
```

## 使用命令
```bash
openclaw-switch status    # 查状态
openclaw-switch list      # 看所有模型
openclaw-switch switch 2  # 切模型（输编号）
openclaw-switch auto      # 自动轮换模式（429时自动切换）
```
**手动切换（不装插件）：** 对话框输 `/model` 选模型
**查当前模型：** `openclaw models status`
