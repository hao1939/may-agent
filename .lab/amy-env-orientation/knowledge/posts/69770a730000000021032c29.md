## superpowers框架概述
**GitHub 36.1k stars** | MIT | 支持 Claude Code / Codex / OpenCode

**核心理念**: 强制执行专业开发流程，让AI从"跳过设计直接写"变成"先思考后动手"

```
❌ 普通AI: 接需求 → 直接写 → 出bug → 打补丁
✅ superpowers: 讨论 → 设计 → 计划 → 执行 → 审查
```

---

## 4大核心要点

### 1. Brainstorming先行
先讨论需求、拆解设计，确认后再动手（不让AI直接写代码）

### 2. 子Agent驱动开发
每个任务派一个子Agent执行，主Agent审查
→ **可以自主跑几小时**，确认设计后放手

### 3. 强制TDD（测试驱动开发）
红-绿-重构循环：先写失败测试 → 写最小代码 → 测试通过才提交

### 4. 内置代码审查
任务之间自动审查，**严重问题会阻断流程**
