## 关键策略

### 1. 本地 vs VPS — 这不是选择题
**Alex强烈反对VPS，四个理由：**
- **安全性**：VPS默认不安全，需大量额外配置
- **性能**：VPS只能发挥OC约**20%的能力**
- **集成性**：本地能与所有设备/工作流无缝衔接
- **体验感**：看着它在面前实时工作，VPS给不了
- **结论：本地=完整版，VPS=阉割版**

旧笔记本 / $50 Raspberry Pi 都够跑。先跑起来，再升级硬件。

### 2. Brain Dump — 第一件事把自己"倒"给它
新员工第一天：告诉它你是谁、目标是什么。
- 背景（职业/技能/经历）
- 偏好（工具/工作风格）
- 目标和野心（短期/长期）
- Alex直接说："我要通过SaaS和产品每年赚100万美元。"→ 之后每个决策都朝这个方向

### 3. 反向提示（Reverse Prompting）— 最重要的概念
```
❌ 普通: "帮我做X"
✅ 反向: "根据你对我的了解，你觉得我们应该做什么？"
```
**为什么更好：** OC记住了你所有的背景/目标/偏好，上下文比你在任意瞬间能想到的还多。让它主动提议往往比你自己想出来的更有创意。

Alex重复了三遍：**反向提示，反向提示，反向提示。写在便利贴上，贴在显示器上。**

### 4. 大脑+肌肉架构
```
大脑: Claude Opus 4.6 — 决策+协调 (聪明但贵)
肌肉:
  编码 → Codex (便宜且强)
  找新闻 → XAI/Grok API (接入社交媒体,知道什么在火)
  搜索网络 → Brave API (便宜好用)
  本地编码 → MiniMax 2.5 (完全免费)
```
大脑省token，肌肉用最合适的工具做最合适的事。
Alex已花2万美元买Mac Studio跑本地肌肉模型（"未来所有肌肉都会被本地模型替代"）。

### 5. 早间简报（每天8:00 TG推送）
内容: 当天天气 + 关注领域热门新闻 + 待办事项 + **它认为今天自己能帮你完成的任务**
最后一条最关键——让它自己思考能做什么，不用你说。

### 6. Mission Control — 定制化任务仪表板
- Alex让OC用NextJS自己Vibe Coding搭建
- 包含: 待办清单 / 子代理追踪器 / 内容审批队列（推文/缩略图/脚本一键审批）
- **关键：不要用别人的Mission Control，告诉OC"帮我搭一个"，让它自己造**

### 7. 犯错了让它自己修
```
❌ 不要: 手动修配置文件/自己改代码
✅ 正确: "暂停。去读一遍我过去所有的新闻邮件，
         然后创建一个新技能，帮你以后写出更好的内容。"
```
**"你是经理，不是工程师。给方向，不给方法。"**

### 8. 安全三铁律（Alex）
1. 它能访问电脑上的一切 → 不想让它碰某账号，就别在那台电脑上登录
2. **绝对不要让它接触外部世界** → 不加群聊/不回推文评论 → 提示注入风险（一条消息泄露所有密码）
3. 每个指令前想清楚后果 → 拿不准就让它先给执行计划，审批后再动手
