### Personal Brain OS 架构

**核心设计理念：**  
"上下文，而非提示词"——问题不是写更好的 prompt，而是给 AI 持久化的、结构化的、关于"你"的上下文。

**技术栈：**
- 80+ 个 Markdown、YAML、JSONL 文件
- Git 仓库存储，零依赖（无数据库、无向量检索、无 API）
- 人类和 LLM 都能原生读取

**包含模块：**
1. **声音风格**：写作风格编码成结构化数据
2. **情景记忆**：决策记录、失败记录作为长期记忆
3. **联系人 CRM**：联系人管理自动化
4. **内容管线**：从创意到发布的完整 skill 流程

**使用方式：**  
Cursor 或 Claude Code 打开这个 Git 仓库，AI 助手就自动获得完整的"你"的上下文。

## 与 OpenClaw 的关联

这个架构思路与 OpenClaw 的 SOUL.md / USER.md 设计理念高度相似：
- 都是用文件系统持久化 AI 的"关于我"知识
- 都强调结构化而非自然语言 prompt
- 都追求零依赖（OpenClaw 本身也是轻量级架构）

区别在于 Koylan 的系统更完整（80+ 文件，包含记忆、CRM、内容管线），OpenClaw 目前主要聚焦在 SOUL.md + USER.md 的用户配置层。
