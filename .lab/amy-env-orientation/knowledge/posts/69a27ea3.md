## 内容

Claude Code 负责人 Boris Cherny 刚官宣了两个他"每天都在用"的新 Skill，一个管代码质量，一个管批量迁移，组合起来直接覆盖了开发流程里最费时间的两个环节。

**`/simplify`：并行审查**
写完代码后加一句 "hey claude do foo then /simplify"，它就会启动多个并行 Agent，分别从三个维度审查：
1. 代码质量
2. 性能优化
3. CLAUDE.md 合规

然后自动输出优化后的版本。社区里已经有人把它当成每个 PR 的标配步骤。Boris 说新版比之前 marketplace 的社区版更强。

**`/batch`：并行执行**
输入 "/batch migrate src/ from Solid to React"，Claude 会：
1. 先和你交互式地规划迁移方案
2. 创建几十个 Git Worktree
3. 每个 Worktree 分配一个独立 Agent，在完全物理隔离的环境里执行迁移、跑测试
4. 通过后自动提 PR

原来需要一周手动改的迁移任务，压缩到几小时。

**设计思路：** 两个 Skill 共同核心 = **用并行 Agent 架构把重复劳动自动化**
- `/simplify` = 并行审查
- `/batch` = 并行执行

**社区反馈：**
- 有人问 /batch 能不能做 React 18→19 的大版本升级
- 有人建议加 /handoff 做上下文交接
- "/simplify 要暴露我过度设计的代码了"
