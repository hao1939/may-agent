## 原生记忆5大局限

1. 跨会话容易失忆（聊过的事忘干净）
2. Compaction压缩后信息大量丢失
3. 纯文本搜索，语义理解有限
4. 信息是扁平的，没有关系图谱
5. 多Agent之间记忆完全隔离

---

## 5大开源记忆方案

| 方案 | 背景 | 核心优势 | 适合场景 |
|------|------|---------|---------|
| **Mem0** | YC孵化 | vs OpenAI Memory: 准确率+26%, 速度+91%, 省90% token | 想要更聪明的检索 |
| **Zep** | - | <200ms延迟, 关系感知, 多源聚合(聊天+文档+事件) | 生产级部署 |
| **Letta** | 前身MemGPT | AI自己管理记忆，能学习和自我改进 | AI自管理记忆 |
| **OpenViking** | 字节背景团队 | 结构化记忆架构，架构思路清晰 | 深度定制 |
| **EverMemOS** | - | 操作系统级记忆抽象，面向长期运行Agent | 长期Agent |

## 选型指南

```
刚入门       → 先用好原生三件套(MEMORY.md + memory/ + memory_search)
想要更聪明检索 → Mem0 (pip install即用)
生产级部署    → Zep
AI自管理记忆  → Letta
深度定制      → OpenViking + qmd
```

## 社区验证搭配
- OpenViking + qmd 检索加速（@onehopeA9实战）
- 原生记忆 + Obsidian 同步（第二大脑）
- Mem0 一键集成（最简升级路径）

**结论：原生记忆是地基，外挂方案是上层建筑。**
