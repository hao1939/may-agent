## Summary

Anthropic upgraded Claude Code's Todo mechanism to a Tasks system, enabling dependency graphs, cross-session collaboration, and multi-agent coordination.

## Key Points

### Three Problems Tasks Solves

1. **Task Dependencies** — Supports dependency graph, matching real engineering project execution flow
2. **Cross-Session Collaboration** — Tasks persist locally at `~/.claude/tasks`, multiple sessions/subagents share task state
3. **Multi-Agent Coordination** — When one session updates a task, updates broadcast to all Claude instances using the same TaskList

### Core Concept
- Upgrade from "to-do items" → "dependable, collaborative, cross-session executable task graphs"
- Claude evolving from "conversational assistant" → "project-managing AI Agent"

### Industry Implication
- Task Graph + Agent Execution pattern likely to become critical infrastructure for future AI programming systems

## Relevance to Our System
- Our SIGNALS.md + heartbeat.md pattern is a simpler version of cross-session task coordination
- We already persist state in the file system (workspace/todo.md), similar to ~/.claude/tasks
- Our multi-agent system (Amy, Bob, Coach, Evaluator) already does primitive multi-agent coordination
- The dependency graph idea could improve our task ordering
