## 内容

**Context（上下文）= AI每次对话能"看到"的所有信息**

比喻：找厨师做菜需要给他：
- 📜 菜谱（System Prompt）：做菜规则
- 🥦 食材清单（Workspace文件）：口味和习惯
- 🧠 记忆（Memory）：上次说不爱吃辣

### System Prompt 的"拼装术"
System Prompt 不是写死的文字，而是**模块化拼装**（从底到顶）：

```
5. Runtime（最顶层）— 运行环境信息
4. Workspace Files — AGENTS.md, SOUL.md 等
3. Skills — 技能指南（按需加载）
2. Safety — 安全提醒
1. Tooling（最底层）— 可用工具列表
```

### Context vs Memory 核心辨析
- **Context（上下文）= 工作台**：每次对话新建，对话结束消失
- **Memory（记忆）= 长期档案**：跨会话持久，需要主动读写
