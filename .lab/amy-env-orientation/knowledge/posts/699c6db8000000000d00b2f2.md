## 三步配置多Agent团队（OCR完整）

### Step 1: 创建Agent团队
```bash
openclaw agents add writing    # 写作助手
openclaw agents add dev        # 开发助手
openclaw agents add investment # 投资助手
openclaw agents add goals      # 目标助手
```
"每个命令会创建一个独立的'AI大脑'，拥有自己的工作空间、记忆存储和会话历史。它们之间完全隔离，不会互相干扰。"

### Step 2: 配置飞书群组专属绑定
```json5
{
  "agents": {
    "list": [
      {
        "id": "main",
        "name": "主协调Agent",
        "workspace": "/root/.openclaw/workspace",
        "default": true,
        "agentDir": "/root/.openclaw/agents/main/agent"
      },
      {
        "id": "writing",
        "workspace": "~/.openclaw/workspace-writing",
        "name": "文案小能手",
        "agentDir": "/root/.openclaw/agents/writing/agent"
      }
    ]
  },
  "bindings": [
    {
      "agentId": "writing",
      "match": {
        "channel": "feishu",
        "peer": { "kind": "group", "id": "飞书群组ID_1" }
      }
    }
  ]
}
```

**获取飞书群组ID**: 让Agent在群里发条消息，日志中会显示群组ID，格式 `oc_xxxxxxxxxxxxx`

### Step 3: 设置群组专属工作模式
```json5
{
  "channels": {
    "feishu": {
      "groups": {
        "飞书群组ID_1": {
          "requireMention": false,
          "allowAll": true
        }
      }
    }
  }
}
```
