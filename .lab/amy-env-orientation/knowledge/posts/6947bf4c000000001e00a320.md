## Full Text
现在审稿的共识很明确：靠堆 Prompt 和调用 GPT-4 API 的 work 已经出局了。那只是 API Wrapper Engineering，不是 Research。
	
社区现在看的不是 demo storytelling，而是 mechanism design。重点已经从让大模型做任务转向如何设计确定性框架来规约不确定性。
	
简单说：System 2 thinking 不能只靠 LLM 的 intrinsic capability，必须通过架构设计从外部 impose。
	
我们目前在推进的几个方向，都围绕这个核心：
1. Planning as Formal Verification
2. Self-Improvement with Minimal Human-in-the-Loop
3. Multi-Agent 的通信与博弈均衡
	
这些方向不拼算力，拼的是 first-principle thinking 和 system building 能力。需要你能把认知架构拆解成清晰的 state machine，能把理论设计翻译成高效且可扩展的 code。
	
如果你已经过了 quick demo 的阶段，想深入做 deterministic reasoning 与 neural generation 的接口设计，想清楚每一层 abstraction 的 formal guarantee 是什么，我们或许可以聊聊。
