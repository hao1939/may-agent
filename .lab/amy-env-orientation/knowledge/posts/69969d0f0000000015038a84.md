## 核心观点
> "你的大脑是用来思考的，不是用来记忆的。让AI做记忆，你做创造。"

---

## 5文件架构
| 文件 | 用途 |
|------|------|
| SOUL.md | AI的性格/角色设定（不变的"灵魂"） |
| USER.md | 你是谁/目标/习惯/重要决定 |
| MEMORY.md | 动态记忆（随时间积累） |
| TOOLS.md | AI能用什么工具/API/工作流 |
| AGENTS.md | **纠错本**：每次AI犯错写一条规则 |

**AGENTS.md示例：**
```
不要给我3个选项然后说"你决定"，要么直接给答案要么给1个推荐
我说"算了"的意思是不做，不是"再想想"
不要问"要不要"，直接干
```
"三个月后，AI犯的错会越来越少。这就是训练AI的过程。"

---

## 搭建步骤（总计2小时）
1. 选笔记软件（推荐Obsidian免费本地优先）
2. 建立5个文件，填入个人信息
3. 每天记录（越简单越好，持续才是关键）
4. 配置AI读取文件（OpenClaw: 直接配置文件路径 | ChatGPT: 上传/Custom Instructions | Claude: Projects知识库）
5. 训练它：AI犯错→AGENTS.md加一条

---

## TOOLS.md示例
```markdown
## 写作
- Obsidian: 主要笔记软件
- 飞书: 日常沟通
## 数据源  
- GitHub Trending | Product Hunt | Twitter(X)
## 注意事项
- Twitter链接不要用web_fetch，用API
- 视频链接用yt-dlp下载
```

## 实测效果（用了一个月）
- 问"我上周关于AI思考了什么" → 直接问AI，不翻笔记
- 让AI从素材库找东西，比自己找还准（记得所有上下文和关联）
- 规划下一步：AI基于USER.md目标+MEMORY.md进展给建议
