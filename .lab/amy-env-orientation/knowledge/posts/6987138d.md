## 内容（核心流程：用户消息→AI响应）

```
用户平台(TG/Discord) 
  → 消息输入
  → 渠道适配器（标准化+附件提取）
  → 网关服务器（识别会话+分配队列+Lane Queue顺序控制）
  → Agent Runner（核心大脑）
      ├─ 选AI模型
      ├─ 动态组装: 系统Prompt + 工具/技能/记忆 + 会话历史
      └─ 上下文窗口管理器（自动压缩，适配LLM输入限制）
  → LLM API调用
  → Agentic Loop（判断是否调工具→执行→生成文本）
  → 渠道适配器（流式输出）
  → 用户
```

**架构亮点：**
- 多平台：TG/Discord随便接
- 会话管理：网关+队列，对话不乱序
- 动态组装：Prompt+工具+记忆按需组合
- Agentic Loop：AI自主决策是否调工具，不只是"复读机"
- 上下文压缩：自动适配LLM输入限制
