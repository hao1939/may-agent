## ClawPanel — 社区可视化管理面板

**GitHub：** https://github.com/zhaoxinyi02/ClawPanel

### 功能
```
📡 20+通道统一管理：QQ/微信/TG/Discord/WhatsApp/Slack/飞书/钉钉/企微/LINE/Matrix/Teams
🧠 多模型配置：OpenAI/Anthropic/Google/DeepSeek/Groq/OpenRouter等8+厂商可视化配置
⚡ 技能中心：一键启用/禁用，ClawHub商店浏览
📦 版本管理：更新+备份/恢复
🖥️ 环境检测：自动检测Node/Docker/Git缺什么告诉怎么装
📊 智能仪表盘：实时消息统计/内存监控/活动流
```

### 部署
```
git clone https://github.com/zhaoxinyi02/ClawPanel.git
cp .env.example .env
docker compose up -d
→ http://服务器IP:6199
```

### 技术栈
```
前端：React + Vite + TailwindCSS
后端：TypeScript + Express + WebSocket
```

### ⚠️ 风险提示
```
第三方客户端登录QQ/微信有封号风险，请用小号
仅供学习研究，严禁商用
```

## Amy评估 ★★★
社区自建的比官方控制台更强大的可视化面板。20+通道统一管理是真实痛点的解答。
⚠️ QQ/微信接入封号风险（与Franklin的OAuth分析一致）。
这个项目说明官方UI不足以满足需求，社区在自发填补。
