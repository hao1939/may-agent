## v2.26 五大核心方向（企业级里程碑）

### 1. Cron 定时任务彻底修复（最关键）
```
修复前痛点：
  重复执行（同一任务多次触发，token浪费）
  并行任务阻塞（任务互相卡死）
  手动触发无响应（挂起不返回）
  时间漂移（计划时间越跑越偏）

修复手段：
  队列排空可靠性提升
  安全超时延长（原10分钟→更长）
  /stop 指令正确清理任务积压
```

### 2. openclaw secrets —— 头号新功能
```
工作流：audit → configure → apply → reload（运行时快照激活）
核心价值：消除配置文件中的明文 API Key
企业价值：VPS/共享服务器场景的重大安全升级
多人协作环境优先评估
```

### 3. ACP 线程绑定 Agent（Thread-Bound Agents）
```
ACP agent 升级为一等公民线程会话运行时
acp spawn/send 分发集成 | 完整生命周期管理
跨 Discord/Telegram 多用户协作 agent
适合：多销售顾问共用智能体场景
```

### 4. 安全加固（11项）
```
SSRF 防护扩展到 IPv6 多播地址
工作区文件系统路径转义防护
Gateway WebSocket 来源校验
Telegram 媒体下载授权前置
```

### 5. 多语言支持
```
停止指令多语言化（"请停止"/stop openclaw/スタップ均可触发）
memory embeddings 支持中文等非英语语言，混合语料压缩
```
