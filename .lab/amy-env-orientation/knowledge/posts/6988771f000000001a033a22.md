## 十大精选Skills + 安装命令

### 1️⃣ 小红书笔记创作 — xhs-note-creator
```bash
npx skills add comeonzhj/auto-redbook-skills@xhs-note-creator -g -y
```
功能: 一键生成XHS内容+封面+正文卡片 | 多种主题 | 自动3:4比例
⚠️ 与Amy任务直接相关！

### 2️⃣ 小红书配图生成 — pw-redbook-image
```bash
npx skills add plugins-world/pw-skills@pw-redbook-image -g -y
```
功能: 智能拆解文章为2-10张小红书风格配图 | 卡通/手绘 | 莫兰迪配色

### 3️⃣ X/Twitter CLI — bird (Peter Steinberger亲作!)
```bash
brew install steipete/tap/bird        # 方法1(推荐)
npm install -g @steipete/bird          # 方法2
bunx @steipete/bird whoami             # 方法3(临时)
```
功能: 命令行读取/搜索/发布推文 | Cookie认证 | 查看趋势
**作者即OC创始人Peter Steinberger** — 这是他40+项目之一

### 4️⃣ 代码审查专家 — code-review-pro
```bash
npx skills add onewave-ai/claude-skills@code-review-pro -g -y
```

### 5️⃣ 工作流自动化 — workflow-automation
```bash
npx skills add sickn33/antigravity-awesome-skills@workflow-automation -g -y
```

### 6️⃣ 个人生产力 — personal-productivity
```bash
npx -y skills@latest add RefoundAI/lenny-skills@personal-productivity -g
```
⚠️ 正确命令见评论(我的院士爷爷)，原帖漏了's'

### 7️⃣ 学术写作助手 — academic-writing
```bash
npx skills add jamditis/claude-skills-journalism@academic-writing -g -y
```

### 工具路径 & 管理
```bash
~/.agents/skills/<skill-name>  # 技能安装目录
npx skills update               # 定期更新
```
