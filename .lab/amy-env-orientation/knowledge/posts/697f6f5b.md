**D1 — 早报网页化**
→ 要求早报做成网页格式
→ OC自建GitHub仓库 + 配好自动部署 + 每天发链接，点进去就是漂亮网页

**D2 — YouTube下载器崩溃修复**
→ 问有无修复方案 → OC说有但没编译好 → 说"那你编译一个吧"
→ OC真的编译好了 → 部署上去 → 问题解决

**现在 — 用户投诉邮件自动化**
→ 投诉邮件来了 → 自动查付款记录+订阅记录+使用情况
→ 写好回复草稿发来 → 人工点一下发出去
