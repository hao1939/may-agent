## 九大踩坑+解决方案

### 坑1: AI修改配置文件→OC直接宕机
**原因**: 模型幻觉改openclaw.json极易出错
**解决**: ①写入底层规则"修改配置必须先沟通，禁止AI直接写入" ②手机装Termius手动改 ③崩溃→OC自动备份文件覆盖回滚

### 坑2: Claude Skill无法安装（格式不兼容）
**原因**: Claude Code的技能格式与OC不兼容
| 系统 | 格式 | 可用 |
|---|---|---|
| Claude Code | /plugin命令 | ✅ |
| OpenClaw | claude/ | ❌ |
**解决**: 让龙虾根据原Skill功能重新开发兼容版本
→ 成功将baoyu-xhs-images转换为OC版(位置: /root/.openclaw/skills/)

### 坑3: Brave搜索无免费额度
**解决**: 直接用Tavily替代(1000 Credits/月免费) + 安装技能`tavily-search`

### 坑4: MCP安装繁琐
**解决**: 发MCPReporter地址给龙虾→让AI全程处理
- 成功案例: 12306-mcp (8个工具，1951ms响应)

### 坑5: Skill触发不稳定
**解决**: 不依赖AI自动匹配；所有场景明确指定"什么场景用什么Skill"

### 坑6: 定时任务不执行
**解决**: ①读官方文档 ②喂给龙虾按官方修复 ③写入底层规则
  官方文档: docs.openclaw.ai/zh-CN/automation/cron-jobs
  官方文档: docs.openclaw.ai/zh-CN/automation/cron-vs-heartbeat
  → 将规则存储到`memory/cron-heartbeat-guide.md`

### 坑7: Coding Agent效果差
- M2.5+Opencode比Cursor/Claude差距大
- M2.5触发限速→龙虾静默切回普通开发
- 上下文超限(Context overflow)→需明确"压缩上下文指令"
- 界面识别严重幻觉

### 坑8: 阿里云应用镜像版本更新问题（评论补充）
> "阿里云应用镜像有硬伤，更新不了版本，更新要重置镜像" — 踹行(3赞)

### 成功案例: AI旅游助手
前置工具: 高德MCP + 12306MCP + planning-with-file + qwen-vl + 飞书文档
五阶段流程: 景点清单→高铁票→交通计算→行程编排→飞书文档
结果: 北京↔上海三天两夜行程，G3(06:52)/G10(14:00)，完整飞书文档
但评价: **"效果一般般"**
