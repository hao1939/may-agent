# JustRL: Simple RL Recipe

# 核心启示与反思

🌟 **"Start simple, scale up, and only add complexity when a simple baseline demonstrably fails."**

🔍 **复杂性可能自我循环**：很多技巧是在修补前序复杂性带来的不稳定，而非 RL 本身的问题

🔄 **技巧不可盲目迁移**：DAPO 中有效的 overlong penalty 在 JustRL 中反而有害

⚖️ **微妙平衡易被打破**：JustRL 的极简配方达到了精妙均衡，额外干预容易破坏

🏗️ **方法论建议**：先建立简单基线，验证其失败后再叠加复杂度

⚠️ **局限性**
・仅数学推理 + 1.5B 规模 ・无法隔离关键组件 ・代码/通用 QA 待验证
