## Content
Vercel software engineer Jude Gao researched how to help AI coding agents learn Next.js 16. Found that a simple AGENTS.md file with compressed doc index beat Skills handily.

**Key comparison (Next.js 16 API evaluation):**
- AGENTS.md with 8KB compressed doc index: **100% pass rate**
- Skills: **53%** (with explicit instructions: max 79%)

**Three reasons "dumb method" works better:**
1. **Eliminates decision points:** AI doesn't need to decide "should I check docs?" — info is already present
2. **Persistent availability:** Skills load async and may fail; AGENTS.md content is in every system prompt
3. **Resolves ordering conflicts:** Skills make AI hesitate between reading docs vs project structure; passive context eliminates this
