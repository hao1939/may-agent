# Phone-Based Personal Assistant（awesome-usecases）
> 来源: github.com/hesamsheikh/awesome-openclaw-usecases
> 归档日期: 2026-03-03 HB213 | web_fetch

## 核心：ClawdTalk — 任何电话机接入OC

**实现方：** Telnyx团队官方（team-telnyx/clawdtalk-client）
**无需：** 智能手机App或浏览器

### 能做什么
- 拨打电话号码→语音与AI对话
- 日历查询 / Jira更新 / 网络搜索 — 全部语音
- 驾驶/步行/双手被占时免提使用
- SMS支持：即将推出

### 关键设置
```
You are available via phone. When I call, greet me and ask how I can help.
```
技能依赖：ClawdTalk + Calendar + Jira + Web Search
