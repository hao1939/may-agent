# Synthesis: DD-777 + DD-778 + DD-779 — The Verification Trilogy

These three papers form a coherent picture of agent verification:

## The Triangle

1. **DD-777 (Co-Sight)** → KE-235: *How* to verify efficiently — conflict-directed meta-verification. Don't verify everything; verify where agents disagree.

2. **DD-778 (Action Rebinding)** → KE-236: *Why* self-verification fails — the observation-action gap and IAS show agents can be manipulated into rationalizing anomalies. External verification is essential.

3. **DD-779 (Explanatory Equilibrium)** → KE-237: *When* to verify and *how much* — structured artifacts + probabilistic auditing is sufficient. Game-theoretic foundation for calibrated verification.

## Unified Insight

Together they answer the "verification of verifiers" question (CR-324):
- **Structure** your claims (DD-779) so they're auditable
- **Detect conflicts** (DD-777) to know where to verify  
- **Use external verification** (DD-778) because self-verification is bypassable
- **Verify proportionally** (DD-779 + DD-777) — more on conflicts/ambiguity, less on clear-cut

## Connection to H-172 (Calibrated Verification)

All three papers support H-172. DD-779 provides the theoretical grounding, DD-777 provides the implementation pattern, DD-778 provides the threat model that motivates external verification.
