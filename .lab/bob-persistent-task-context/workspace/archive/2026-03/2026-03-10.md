# Weekly Brief: 2026-03-10

## High-Impact Items (P0)

### 1. V2 Architecture Upgrade (In Progress)
- **What:** Migrating from async/persistent sessions to synchronous/ephemeral sessions.
- **Why:** Reliability. The async queue model caused silent failures and "ghost" sessions. V2 uses direct synchronous calls (`callAgent`) and a proper chat loop.
- **Status:**
    - **Design:** Frozen (`docs/v2-design.md`).
    - **Phase 1 (Primitives):** `callAgent` implemented in `src/lib/manager.ts`.
    - **Phase 2 (Chat Loop):** Interactive loop skeleton (`src/v2/chat-loop.ts`) implemented.
    - **Next:** Full migration of the runner (`scripts/v2.ts`) and retiring the old `scripts/run/*.ts` machinery.

### 2. Crash Recovery (Shipped)
- **What:** Filesystem-based sentinel (`[STARTED]`) to detect crashed sessions.
- **Why:** Agents were losing state when the process died. Now, the system detects "orphaned" sessions on startup and marks them as interrupted.
- **Status:** **Live**. `src/lib/manager.ts` handles sentinel creation/cleanup.

### 3. Modular Skills (Shipped)
- **What:** Extracted core capabilities (`file-safety`, `error-handling`) into reusable skills.
- **Why:** DRY. We had duplicated "safety rules" in every agent's `SOUL.md`. Now they are injected dynamically.
- **Status:** **Live**. All agents updated. Legacy prompts removed.
