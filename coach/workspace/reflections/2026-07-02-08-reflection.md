## 2. Theme Extraction

### Theme A: Perpetual Forward Motion — Never Idle (STRONG, NEW)

**Core directive:** Projects should NEVER reach a "done and waiting" state. The cycle is:
1. No metric? → Build one.
2. Metric target met? → Question whether the metric actually reflects the goal.
3. Metric validated? → Add more metrics for different aspects.
4. All metrics good? → Try another approach to push further.
5. Everything looks good? → Keep watching for regressions.
