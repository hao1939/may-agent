## Root Cause Analysis

### Why did Hao have to intervene?

**Proximate cause:** The system has no quality-gate for skills and workflows. Anyone can create a skill; nobody validates it.

**Systemic cause:** The system optimizes for **production** (creating artifacts) over **evaluation** (measuring artifact effectiveness). This is a recurring pattern:
- LESSONS.md: Coach produces lessons, nobody measures if they work → proven 0% effective for text coaching
- Skills: Agents create skills, nobody measures if they improve behavior
- Workflows: Workflows exist but no tracking of whether they produce better outcomes than ad-hoc execution

**Has this been flagged before?** Yes — Hao's LESSONS.md audit (ts:1773505148856) explicitly established the principle: "don't debate whether lessons work in theory, measure whether they work in practice." The same principle applies to skills and workflows but was never generalized.

**Root cause:** No agent has "quality audit of accumulated knowledge assets" as a responsibility. Coach focuses on individual agent improvement. Evaluator scores sessions. Optimizer looks at execution efficiency. The gap is **asset-level quality assessment**.
