## Theme Analysis

### Theme 1: Event-Native Guard-Workflow Architecture [CRITICAL — Hao Priority]

**Core directive**: Design an architecture where:
1. Sessions/workflows are event streams (tool calls, LLM calls, workflow steps are all events)
2. Guards are event-triggered hooks that can inject actions into the workflow
3. Injected actions can be inner workflows, escalations, or other event types
4. The agent or orchestrator gets a chance to react to the injection
5. After the injected action completes, control returns to the interrupted point

**Why this matters**: This is a fundamental architectural evolution — from guards as binary gates (block/allow) to guards as reactive event sources that can compose with workflow execution. It addresses the limitation identified in multiple experiments (KE-161, KE-169) where guards are static and cannot adapt their intervention to context.
