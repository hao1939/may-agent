# KE-021: Skills cannot reliably override strong default model behavior (judgment tasks)

**Status**: verified  
**Evidence**: EXP-032 (3 skill versions tested, 10 total runs, no significant improvement)  
**Discovery date**: 2026-04-05  

## Finding

Skills that try to **override model judgment** ("don't do X when you think Y") are fundamentally less effective than skills that **add process steps** ("do X before Y"). Three progressively stronger versions of a "clarify-before-acting" skill all failed to prevent the agent from modifying files when given a vague task ("The configuration is wrong. Fix it.").

## Mechanism

1. **Model confidence trumps skill instructions**: When the model investigates and finds what it considers evidence (cross-file inconsistencies, empty credentials), its confidence in its own analysis overrides skill-level warnings.

2. **Process skills succeed by adding steps**: "verify-after-edit" and "read-before-edit" work because they insert NEW actions into the workflow, not override existing decisions.

3. **Judgment skills fail by opposing decisions**: "don't modify files without evidence" fails because the model believes it HAS evidence from its investigation.

## Skill effectiveness taxonomy

| Skill Type | Example | Mechanism | Effectiveness |
|---|---|---|---|
| Process (additive) | verify-after-edit | Adds step to workflow | HIGH |
| Knowledge (informational) | file-safety-classification | Provides missing info | MEDIUM |
| Judgment (overriding) | clarify-before-acting | Opposes model's analysis | LOW |

## Implication

Focus the skill library on **process skills** (HIGH) and **knowledge skills** (MEDIUM). Judgment improvements may require system-prompt-level changes, model fine-tuning, or architectural constraints (e.g., mandatory approval gates) rather than skill injection.
