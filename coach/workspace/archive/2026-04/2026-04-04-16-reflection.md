## Root Cause Analysis

### RCA-1: Manual Session Recovery = Missing Infrastructure

Hao resuming 3 sessions manually (#3-5) then resorting to a fresh session (#7) reveals:
1. **No automatic retry/resume**: When a session crashes, it's gone. The system doesn't retry.
2. **No interrupted-work queue**: Heartbeats don't check "was there work in progress that got interrupted?"
3. **Manual session IDs required**: Hao had to locate specific session IDs — there's no "resume all interrupted work" capability.

**Who should fix**: This is infrastructure (Optimizer) + architecture (Tech-Lead). The fix is either: (a) sessions are more robust (fewer crashes), or (b) the system automatically retries/resumes interrupted sessions.

### RCA-2: Reflection Recommendations Never Execute — Pipeline Gap

1. Coach's heartbeat doesn't read reflection recommendations
2. Other agents don't receive Coach's recommendations (no dispatch mechanism)

**Structural fix**: Coach needs to either:
- (a) Send improvement tasks to agents via the `agents` tool (message/send actions)
- (b) Write recommendations to a location that agents' heartbeats read
- (c) At minimum, ensure Coach's own heartbeat reads the latest reflection

### RCA-3: May as Manager — Requires Delegation Infrastructure

"Keep your hands empty and watch where need help" is the right principle, but May needs tools/processes to:
1. **Monitor agent health** — See which agents are succeeding/failing without asking

If May lacks these, she'll either: (a) do the work herself (violating the directive), or (b) ask Hao for updates (creating the CLARIFICATION pattern we see).

## Key Insights

### 1. The System Is Operating as a Broken Dispatcher
The core loop should be: Hao directs → May dispatches → Agents execute → Results flow back. Currently: Hao directs → messages may or may not get processed → Hao pings to check → Hao manually intervenes. The system is a broken dispatcher with a human compensating.

### 2. Two-Reflection 0% Execution = Systemic Process Failure
Generating recommendations is useless if they're never acted upon. Coach needs to change the recommendation→execution pipeline. Options: (a) only generate self-actionable recommendations, (b) dispatch recommendations to agents, (c) reduce recommendation count and focus on one thing.

### 3. Evidence-First Is Not Just for Experiments
Hao's directive to "follow the evidence first rule" applies to ALL agent work — not just Coach's experiments. Agents should verify their changes work before declaring success. This could be a new coaching responsibility: reviewing agent outputs for evidence quality.

### 4. Parallelism Unlocked
"Start all at the same time, don't wait" + lifted turn limits = the system should be capable of significant parallel output. The constraint is agent reliability (sessions crashing), not resource availability.

### 5. Fresh Session as Last Resort
Hao starting a "fresh session" after failed recoveries suggests session state accumulation may be part of the problem. Long-running sessions accumulate context debt. The fresh start succeeded where recovery failed.
