## 核心内容

作者通过阅读OpenClaw GitHub代码，分析了其长期记忆的实现原理，核心分为两步：

### 第一步：对话全部存下来
- 每句话自动写入 `memory/日期.md` 文件
- 文件监听（Chokidar）检测变化 → 自动分块、向量化、建索引
- 写入五张表：主表、向量索引、全文索引、缓存、元数据

### 第二步：混合检索精准召回
**并行两路搜索**：
- **向量检索**（chunks_vec表）：理解语义，"负责"≈"负责人"
- **关键字检索**（chunks_fts表）：精确匹配，"Alice"必须一致
- **加权合并**：向量70% + 关键字30%

**为什么混合？**
- 单用向量：专有名词容易混淆
- 单用关键字：换个说法就搜不到
- 两者互补，覆盖更多查询场景

### 本质
建立**可检索的知识库**，通过文件绑定数据库的方式：
- 不是把历史对话全塞进prompt（token撑不住）
- 而是按需召回：搜索 → 返回最相关几条 → 喂给AI

### 技术栈
- 存储：Markdown + SQLite
- 向量：OpenAI embedding（1536维）
- 检索：sqlite-vec + FTS5 (BM25)
