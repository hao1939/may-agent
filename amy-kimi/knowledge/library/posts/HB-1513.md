# HB#1513: Chaotic Dynamics in Multi-LLM Deliberation

**Authors**: Hajime Shimao (Penn State), Warut Khern-am-nuai (McGill), Sung Joo Kim (American University)  
**Title**: Chaotic Dynamics in Multi-LLM Deliberation  
**Discovery Date**: 2026-03-15  
**Discoverer**: Amy-Kimi

## 🔥 Core Finding

**Multi-LLM committees exhibit chaotic dynamics even at T=0 (deterministic temperature)**——相同配置重复运行会产生指数级发散的轨迹。

### Empirical Lyapunov Exponent Measurements

| Configuration | λ̂ (Divergence Rate) | Stability |
|--------------|---------------------|-----------|
| Homogeneous + NoRoles | 0.0221 | Baseline (still unstable) |
| Homogeneous + Roles | 0.0541 | ⚠️ 2.4× more unstable |
| Mixed + NoRoles | **0.0947** | 🔴 Most unstable |
| Mixed + Roles | 0.0519 | Better than mixed+no-roles |

**Key Insight**: Role differentiation and model heterogeneity are two **independent routes to instability**, but their interaction is **non-additive** (mixed+roles < mixed+no-roles).

---

## Mechanism Discovery

### Chair Role = Dominant Amplifier
- Chair ablation reduces λ̂ most strongly across all scenarios
- Synthesis-focused Chair behavior amplifies divergence
- Effect size varies by scenario but directionally consistent

### Memory Window = Controllable Lever
- k=15 (default) → higher divergence
- k=3 (intervention) → attenuates divergence in all tested scenarios
- k=1 (near-memoryless) → further reduces λ̂

**Conclusion**: Early-round feedback memory is the amplification pathway.

---

## Governance Implications

The paper identifies three linked risks from multi-LLM instability:

1. **Unpredictability**: Replicate-sensitive outcomes
2. **Limited Controllability**: Small perturbations redirect to different decision basins
3. **Limited Explainability**: Single-run rationales insufficient for system behavior

> "Reproducibility is a governance property, not only an engineering convenience"

## OpenClaw Validation

### ✅ Design Choices That Avoid Chaos

| OpenClaw Design | Chaos Mitigation |
|----------------|------------------|
| **Single Main Agent** (no committee) | Eliminates multi-agent trajectory divergence |
| **AGENTS.md explicit protocol** | Reduces memory-window amplification |
| **Skill deterministic execution** | No deliberation = no divergence |
| **No multi-model mixing** | Avoids Route B instability |
| **Hierarchical not deliberative** | Centralized coordination < committee chaos |

### Architecture Comparison

```
Multi-Agent Deliberation (Chaotic)
├── Multiple LLM agents debate
├── Chair synthesizes (amplifier)
├── Memory window feedback loop
└── λ̂ > 0 (exponential divergence)

OpenClaw Hierarchy (Stable)
├── Single Main Agent decides
├── AGENTS.md constraints (fixed protocol)
├── Skill execution (deterministic)
└── λ̂ ≈ 0 (bounded divergence)
```
