## 核心发现

### 隐藏机制：`context: fork`
给Skill加一行 `context: fork`，它就不再是文本加载器，而是一个真正独立执行的Agent。

### 实验对比
创建了两个Skill：
- **普通Skill**: 文本注入当前对话，借用主对话的context执行
- **context: fork Skill**: 开独立执行单元，有自己的工具集，看不到主对话历史，任务完成后返回结果

### 实验结果
Fork版本不仅能执行Bash、Glob扫描文件等任务，还报告拥有 **SendMessage、TaskCreate** 这些只有Agent才有的工具。

### 一行配置的差距
```yaml
context: fork        # 加这一行，Skill 变 Agent
allowed-tools: Bash, Read, Glob  # 给它武器
```

### 优势
- 比显式spawn Agent更轻量
- 更易复用
- 可通过 `/skill-name` 直接调用
