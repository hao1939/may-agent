## 正文
Anthropic黑客松冠军的Claude Code配置全家桶，agents + commands + skills 一应俱全，直接抄作业就行！

在github上已经拿下12000⭐ everything-claude-code，作者用了10个月实战打磨出来的

🤖 1. Agents (分身专家)
把任务委派给持有特定 Prompt 的"分身"
• planner.md → 需求拆解与规划
• code-reviewer.md → 专门负责代码审查
• build-error-resolver.md → 专门修复编译报错

⚡ 2. Skills (技能与范式)
定义"怎么做"的具体流程和团队技术栈偏好。
• backend-patterns.md → 后端架构设计模式
• frontend-patterns.md → 前端组件最佳实践
• tdd-workflow → 标准化的测试驱动开发流

⌨️ 3. Commands
把复杂的 Prompt 封装成 /命令，提升交互效率。
• /plan → 一键生成实现计划
• /tdd → 一键进入红-绿-重构循环
• /build-fix → 自动分析并修复构建错误

🛡️ 4. Rules
• security.md → 必须执行的安全检查
• coding-style.md → 缩进、命名等代码风格
• testing.md → 测试覆盖率的硬性指标

🧠 5. Hooks
在会话中自动触发脚本，实现"长期记忆"。
• session-start.sh → 会话开始：加载之前的记忆
• session-end.sh → 会话结束：保存新学到的知识
• pre-compact.sh → 上下文压缩前：抢救关键信息

🔌 6. Contexts & MCP
给 AI 注入不同的角色设定和外部工具连接能力。
• dev.md → 开发模式Prompt
• review.md → 审查模式Prompt
• mcp-servers.json → 连接 GitHub, Supabase 等外部工具

## Amy 的分析
**核心洞察：Hackathon Champion's Claude Code 配置全家桶 — 12K⭐的完整生态系统**

这篇帖子揭示了Claude Code生态中最成熟的配置体系之一 —— 来自Anthropic黑客松冠军，历经10个月实战打磨，GitHub 12K stars。

**6-Layer Configuration Architecture:**

```
┌─────────────────────────────────────────┐
│  6. Contexts & MCP — 角色设定+外部工具   │
│     (dev.md, review.md, mcp-servers)   │
├─────────────────────────────────────────┤
│  5. Hooks — 会话记忆脚本                │
│     (session-start, session-end)       │
├─────────────────────────────────────────┤
│  4. Rules — 强制约束                    │
│     (security, coding-style, testing)  │
├─────────────────────────────────────────┤
│  3. Commands — 快捷指令                 │
│     (/plan, /tdd, /build-fix)          │
├─────────────────────────────────────────┤
│  2. Skills — 技能范式                   │
│     (backend-patterns, tdd-workflow)   │
├─────────────────────────────────────────┤
│  1. Agents — 分身专家                   │
│     (planner, code-reviewer)           │
└─────────────────────────────────────────┘
```

**Key Innovations:**

1. **Specialized Agents** — Not one agent does all, but dedicated agents for specific tasks (planner≠reviewer≠debugger)

2. **Commands as Shortcuts** — `/plan`, `/tdd`, `/build-fix` — complex prompts encapsulated as slash commands

3. **Hooks for Memory** — `session-start.sh` loads memory, `session-end.sh` saves learnings, `pre-compact.sh` rescues critical info before context compression

4. **Rules as Guardrails** — Non-negotiable constraints (security, style, coverage)

5. **Contexts + MCP** — Role switching (dev mode vs review mode) + external tool integration

**What it means for our system:**

★ **Agent specialization** — Validated pattern: dedicated agents > generalist agent
★ **Hooks architecture** — "Pre-compact" hook is brilliant — rescue info before context loss
★ **Commands layer** — User-facing shortcuts for complex operations
★ **Rules as constraints** — Hard boundaries vs suggestions
★ **10-month refinement** — Real-world battle testing, not theory

**Comparison to our system:**
| Feature | everything-claude-code | OpenClaw |
|---------|----------------------|----------|
| Agents | Specialized (planner/reviewer/debugger) | Role-based (SOUL.md) |
| Hooks | session-start/end, pre-compact | ❌ Not native |
| Commands | /plan, /tdd, /build-fix | ❌ Not native |
| Rules | security, style, coverage | AGENTS.md constraints |
| MCP | mcp-servers.json | Skill system |

**Key Gaps for Our System:**
1. **Hooks mechanism** — Pre/post session scripts, pre-compact rescues
2. **Commands layer** — Slash commands for common operations
3. **Agent specialization** — More granular than current role system

**GitHub Reference:** `everything-claude-code` — worth studying for system design inspiration.
