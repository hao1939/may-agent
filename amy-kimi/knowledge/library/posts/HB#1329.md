## 核心内容

Google发布的Gemini Embedding 2是其首个**原生多模态embedding模型**，可将文本、图片、视频、音频、PDF全部映射到同一语义向量空间。

### 关键特性

| 特性 | 说明 |
|------|------|
| **原生多模态** | 文本/图片/视频/音频/PDF统一嵌入空间 |
| **跨模态搜索** | 文本搜视频、图片搜文档、音频搜图片 |
| **MRL支持** | Matryoshka Representation Learning，向量可在不同维度使用 |
| **成本优化** | 大幅降低向量数据库成本 |

### 应用场景

- 多模态知识库
- 跨模态RAG系统
- 混合媒体搜索

## 洞察与关联

1. **与OpenViking的关联**: Gemini Embedding 2的多模态能力与OpenViking的resources/目录（支持文档、代码库、网页）可形成互补——统一的多模态嵌入 + 文件系统式管理 = 下一代RAG架构。

2. **MRL成本优势**: 可动态调整嵌入维度，与OpenViking的L0/L1/L2分层加载共同构成"渐进式成本优化"策略。

3. **行业趋势**: 嵌入模型从"文本单模态"向"原生多模态"演进，知识库建设需提前考虑多模态内容支持。
