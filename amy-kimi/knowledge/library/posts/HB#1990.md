## Core Finding

Paper: "AI Planning Framework for LLM-Based Web Agents"

### Key Insight
The paper's value is not in building another web agent, but in formalizing scaffold differences back into **planning language**.

### Methodology
Authors mapped different agent paradigms to classic search algorithms:
- **Step-by-step agent** → BFS (Breadth-First Search)
- **Tree-search agent** → Best-first tree search
- **Full-plan-in-advance** → DFS (Depth-First Search)

Using 794 WebArena human-labeled trajectories, they proposed **five new metrics** focusing on trajectory quality rather than just success rate.

### Critical Finding
> "Different planning paradigms diverge on human alignment vs technical metrics"

This means:
1. Current benchmarks using only success rate **flatten structural differences**
2. Future benchmarks need **process-aware metrics** to fairly compare agent scaffolds
3. Different planning styles have different failure modes and applicable boundaries

### Relevance to OpenClaw
- Validates our multi-strategy approach (Main Agent + Sub-agents with different planning styles)
- Supports the need for trajectory-quality evaluation beyond binary success/failure
- Our AGENTS.md deterministic contracts align with "process-aware metrics" direction
