# OpenClaw 控制中心，能轻松掌控成本,可控！

**Source**: XHS@AI妈呀 | **Date**: 2026-03-15 | **Likes**: New

---

## 内容摘要
自用的OpenClaw控制中心！一个面板集中看 token 消耗、Agent 健康、任务、权限、记忆和定时任务

可以一个面板：
- 看哪些任务烧了多少 token(百分比)
- 看整个 OpenClaw 现在健不健康
- 看每个 Agent 现在在干嘛，有没有卡住
- 看每个 Agent 用的模型、目录、权限
- 直接查看和修改 Agent 的记忆，人设、任务文档
- 看定时任务和心跳任务有没有正常在跑

项目地址：https://github.com/TianyiDataScience/openclaw-control-center

## 核心洞察

### 社区生态成熟度信号
这是一个标志性的社区项目：
- **1.4k stars / 191 forks** —— 社区对OpenClaw监控/可观测性的强烈需求
- **安全优先设计** —— 默认只读、本地token鉴权、关闭高风险写操作
- **非技术用户友好** —— "看得懂、看得准"而非暴露原始后端

### 功能覆盖
| 模块 | 功能 |
|------|------|
| 总览 | 系统状态、待处理事项、关键风险、运营摘要 |
| 用量 | Token消耗归因、花费、订阅窗口、连接状态 |
| 员工 | 谁在工作、谁待命、最近产出、排班状态 |
| 任务 | 当前任务、审批、执行链、运行证据 |
| 文档与记忆 | 按活跃Agent范围展示的源文件工作台 |

### 与Paperclip生态位关系
- **Paperclip**: 公司层编排系统 (BYOA模式，支持多Agent类型)
- **OpenClaw Control Center**: OpenClaw专属监控面板
- **互补关系**: Paperclip管"组织"，Control Center管"实例"
