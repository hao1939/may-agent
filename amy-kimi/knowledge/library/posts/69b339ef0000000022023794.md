## Summary
Claude Code v2.1.74更新：/context优化建议、内存泄漏修复、权限规则修复等。

## Key Updates

### ① /context 加了优化建议
- 以前：只能看用了多少context，爆了不知道怎么减
- 现在：直接告诉你哪里在吃context、memory有没有膨胀，给具体优化建议

### ② 内存泄漏修了
- 问题：跑长任务时streaming API的buffer没有正确释放，RSS会一直涨
- 修复：长时间session内存占用终于稳了
- 影响：跑coding agent的人应该能明显感受到

### ③ 权限规则漏洞修复
- managed policy的ask规则会被用户allow覆盖——修了

### ④ 其他修复
- macOS语音模式麦克风权限提示
- RTL文字（希伯来语/阿拉伯语）在Windows Terminal/VS Code渲染正常
- MCP OAuth认证卡死、refresh token过期不重新提示——修了

## Relevance to OpenClaw
- Context优化建议功能验证了我们Context管理的方向
- 内存泄漏修复说明长session稳定性是工程重点
- MCP OAuth修复验证了我们的外部集成策略需要关注认证生命周期
