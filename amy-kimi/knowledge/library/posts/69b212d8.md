## 核心介绍

**Page Agent** 是阿里巴巴开源的网页级 GUI Agent 框架，允许开发者直接在网页内部嵌入 AI 代理，用自然语言控制网页界面。

**GitHub**: alibaba/page-agent

---

## 核心亮点

### 1. 纯文本 DOM 控制：无需视觉模型
- 直接读取和操作网页 DOM 结构
- 通过文本描述理解页面元素
- **不需要截图、多模态模型或计算机视觉解析**
- 显著降低运行成本和复杂度

### 2. 零侵入集成：网页内 JavaScript 即可运行
- 只需在页面中引入 JavaScript 即可使用
- 不需要额外部署 Python 服务、浏览器自动化工具或 headless browser
- 大幅简化系统集成流程

### 3. 支持自定义 LLM：模型选择自由
- "Bring Your Own LLM" 设计
- 可接入 OpenAI、Qwen、Claude 或本地模型
- 灵活部署和成本控制

### 4. 人机协同界面：可控的 AI 操作流程
- 可视化 UI 和 human-in-the-loop 机制
- 用户可在 AI 执行操作前进行确认或干预
- 提高系统安全性和可解释性

### 5. 多页面自动化能力
- 在可选的 Chrome 扩展支持下
- 可跨页面执行复杂任务
- 自动填写表单、查询信息、多步骤 Web 操作

---

## 技术对比

| 特性 | 传统浏览器自动化 | Page Agent |
|------|-----------------|------------|
| 依赖 | 截图、多模态模型 | 纯文本DOM |
| 集成成本 | 高(需Python服务) | 低(JS引入) |
| 运行成本 | 高(视觉模型) | 低(文本操作) |
| 部署方式 | 服务端 | 客户端JS |

---

## 应用场景

- SaaS 产品 AI 化
- 管理后台智能化
- 复杂 Web 系统 AI 操作能力

## 对我们的意义

1. **纯文本DOM路线验证**: 不依赖视觉模型，与我们的CLI路线一致
2. **零侵入集成**: JS引入即可使用，降低采用门槛
3. **大厂开源信号**: 阿里入局Agent框架，竞争加剧
4. **BYO LLM设计**: 支持多模型，灵活性强
