# HB#1469 — 轻量AI棋界突破：Graph Attention过滤LLM噪声

**Source**: XHS@LLM 翰林院  
**Paper**: arXiv:2603.10512v1  
**Date**: 2026-05-26  
**URL**: https://www.xiaohongshu.com/explore/69b6818c000000002200d3d5  

## TL;DR
Resource-constrained环境下，Graph Attention Autoencoder作为"结构过滤器"去除LLM输出噪声，学生模型显著超越教师模型(GPT-4o-mini)——验证"过滤机制 > 原始能力"的设计哲学。

## Paper Details

### 标题
Resource-constrained Amazons chess decision framework integrating large language models and graph attention

### 作者
Tianhao Qian, Zhuoxuan Li, Jinde Cao, Xinli Shi, Hanjie Liu, Leszek Rutkowski

### 核心创新
**混合框架三组件**:
1. **Graph Attention Autoencoder** — 指导多步蒙特卡洛树搜索
2. **Stochastic Graph Genetic Algorithm** — 优化评估信号
3. **GPT-4o-mini** — 生成合成训练数据

### 关键洞察
> "Graph Attention mechanism effectively functions as a structural filter, denoising the LLM's outputs"

**范式**: Weak-to-Strong Generalization — 从噪声/不完美监督中学习，而非依赖专家演示。

### 实验结果
| 指标 | 结果 |
|------|------|
| 决策准确性提升 | 15%–56% (vs baseline) |
| N=30节点胜率 | 45.0% (超越教师模型) |
| N=50节点胜率 | 66.5% (决定性优势) |

## OpenClaw 关联验证

| 论文机制 | OpenClaw对应 |
|----------|-------------|
| Graph Attention as Structural Filter | Error Log as Directional Critic |
| 从噪声监督学习 | read_by审计轨迹 |
| Weak-to-Strong泛化 | Skill渐进式能力扩展 |
| 过滤LLM输出噪声 | /btw上下文隔离 |

### 核心洞察
**"过滤机制 > 原始能力"** — 论文证明即使是"较弱"的图注意力机制，通过有效过滤LLM噪声，也能让系统在特定任务上超越原始大模型。这与OpenClaw的"Harness > Model"哲学高度一致。
