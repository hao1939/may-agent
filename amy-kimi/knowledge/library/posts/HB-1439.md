# 🦞 养虾社Meetup｜4位大佬Agent心得

## 核心人物与观点

### 黄东旭 (PingCAP CTO, mem9.ai)
- **解决痛点**: "龙虾脑雾"——记忆太乱翻出无关信息
- **反直觉做法**: 不搞复杂权重，直接丢原始信息给大模型，让它自己判断
- **观点**: 
  - 取消邮箱注册，让大模型自动记忆Space ID
  - 未来安全软件对AI说一句"注意安全"就行
  - 多Agent还是单Agent？没标准答案

### 王晓妍 (OPC创始人)
- **血泪教训**: 一次创建80多个子Agent，监控告警爆发系统崩掉
- **六阶段路径**: 
  初体验 → 建Agent Team → 沉淀最佳实践 → AI Native组织 → 自治系统 → 协作涌现
- **管理进化**: Human in the Loop → on the Loop → out of Loop

### 刘艾伦 (MysticX.AI联创)
- **OpenClaw实战**: 7-8小时搭后台，团队只需2开发，日成本500刀
- **踩坑**: 读飞书弱，解决是导出Word解析
- **角色转变**: 产品经理从"提需求"变"产品思考者"

### 投资人圆桌
- **观点**: 不看好Fork开源包装新品；有机会的是周边产品和垂直Agent
- **$1000 token测试**: 测试AI时代管理能力，以前管人现在管Agent
- **金句**: "他们已经跟AI共生了，我们还只是在用AI"

## 作者洞察

四位都讲OpenClaw做产品，但背后都藏同个痛点——**管理复杂度**。

王晓妍从80个Agent混乱总结六阶段法，是血泪教训。刘艾伦3周做AI塔罗牌，但花大量精力在"提示词监督"和"死循环"——说明Agent产品隐性成本高。

黄东旭说"别给AI设边界"很酷，但团队也走过弯路。产品决策里，知道什么不做比做什么更难。

Agent处"Demo容易量产难"阶段，产品化会遇到：**可控性、可观测性、成本结构**三类问题。

市场热度在"能做什么"，竞争将转向"怎么做好做稳做便宜"。技术门槛被AI拉平后，**判断力比执行力更值钱**。

## OpenClaw验证点

| 社区痛点 | OpenClaw设计 | 对齐度 |
|---------|-------------|-------|
| 80-Agent混乱崩溃 | Main Agent中心化架构 | ✅ 完全规避 |
| 记忆翻出无关信息 | Error Log定向反思机制 | ✅ 精准解决 |
| 提示词监督成本高 | AGENTS.md被动上下文 | ✅ 降低负担 |
| 死循环隐性成本 | read_by追踪/审计机制 | ✅ 可观测性 |
| 成本结构不可控 | Token预算/L3 Flags | ✅ 内置管控 |
| Demo易量产难 | Harness工程化 | ✅ 同方向 |
