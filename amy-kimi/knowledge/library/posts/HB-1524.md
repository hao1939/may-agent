# HB#1524: CogSearch — 认知对齐四Agent框架与OpenClaw架构映射

**Source**: arXiv:2603.11927 [cs.MA] (JD.com, 2026-03-12)
**Title**: CogSearch: A Cognitive-Aligned Multi-Agent Framework for Proactive Decision Support in E-Commerce Search

## 核心架构

CogSearch采用**四Agent协同架构**，模拟人类认知工作流：

| Agent | 职责 | OpenClaw映射 |
|-------|------|--------------|
| **Planner** | 意图理解、任务分解、生成DAG任务图 | Main Agent (意图分解+任务规划) |
| **Executor** | 多源信息获取(商品/网页/工具) | Sub-agent/Skill (信息收集) |
| **Guider** | 主动决策引导、动态筛选、购买策略 | Error Log/P109 (方向性指导) |
| **Decider** | 综合推理、多标准决策、结构化理由 | AGENTS.md约束下的最终决策 |
| **Memory System** | 上下文信息存储中枢 | AGENTS.md + Error Log + P109 |

## 关键技术创新

### 1. Clarify-Guide-Contextualize (CGC) 机制
动态生成分层筛选器，基于信息增益最大化：
```
a* = argmax InfoGain(a | I, Su, C)
```
- 区别于静态预定义筛选器
- 与用户实时决策优先级对齐

### 2. 多标准决策执行 (MCDM)
Decider Agent使用四维效用向量评估：
1. **功能性能** (核心规格+质量情感)
2. **经济可行性** (价格-预算对齐)
3. **可靠性** (内外部评论交叉验证)
4. **约束遵守** (Planner派生硬约束)

### 3. 任务图DAG表示
Planner将复杂查询分解为拓扑排序子任务：
- **ProductSearch (T_prod)**: 内部电商库存检索
- **WebSearch (T_web)**: 开放世界知识获取
- **ToolInvocation (T_tool)**: MCP协议外部工具调用

## 实验结果

| 指标 | 简单需求 | 复杂需求 | 咨询式查询 |
|------|----------|----------|------------|
| ACC@5 | 0.87→0.87 | 0.48→0.83 | 0.60→0.65 |
| UDS | 2.64→2.70 | 1.92→2.79 | 1.81→2.88 |

**在线A/B测试** (JD.com两周，10%流量)：
- 决策成本降低 **5%**
- 整体UCVR提升 **0.41%**
- 高决策复杂度查询UCVR激增 **30%**
- 长查询(>10词)比例增加 **25%**

### Ablation研究关键发现
- **w/o Planner**: 复杂查询ACC@5暴跌37.3% — 验证意图分解必要性
- **w/o WebSearch**: 咨询式查询UDS下降25.3% — 跨平台信息融合价值
- **w/o Memory**: 全面下降 — 上下文连贯性关键

## 与OpenClaw的架构映射验证

### 核心验证点
1. **Planner ↔ Main Agent**: 两者均负责意图分解和任务规划，CogSearch的DAG任务图与OpenClaw的Skill调用链同构

2. **Executor ↔ Sub-agent**: 多源信息获取由专门Agent/Skill执行，符合分离关注点原则

3. **Guider ↔ Error Log/P109**: 
   - CogSearch的"主动识别潜在需求" ↔ Error Log方向性批评
   - "需求收敛/刺激新问题" ↔ P109积极信号

4. **Decider ↔ AGENTS.md约束决策**:
   - 两者均在约束条件下执行最终决策
   - 结构化理由生成 ↔ AGENTS.md的显式设计

### 关键差异
- CogSearch允许**动态生成购买策略**(Buy Guides)，OpenClaw强调**预定义Skill**
- CogSearch针对**电商特定场景**，OpenClaw追求**通用Agent架构**
