## 安装命令
```bash
npm install -g openclaw
# M1 Mac必须用Node 18+（版本兼容性坑）
```
**配置文件：** `~/.openclaw/openclaw.json`

## openclaw.json核心配置项（实测）
```
agents    — Sam/Bob双Agent配置
models    — Kimi K2.5 + Qwen 3 Max（多模型路由）
channels  — Discord集成
MCP工具   — 小红书发布MCP注册
```

## 多模型智能路由策略
- **复杂任务 → Kimi K2.5**（强推理）
- **简单任务 → Qwen 3 Max**（省钱）

## 5项踩坑总结
1. API Key别放明文，用**环境变量**
2. MCP服务崩溃是常态，加**systemd守护**
3. 小红书Cookie有效期短，定期更新
4. Discord消息要**限流**，别触发风控
5. `openclaw.json`配置复杂，花2小时才搞懂

## 功能实测清单
- ✅ 24/7 AI Agent在线（Sam对外拆任务，Bob执行写代码）
- ✅ MCP工具调用（小红书自动发布/邮件日报）
- ✅ 多模型智能路由（复杂→Kimi，简单→Qwen）
- ✅ Heartbeat定时任务（每天8点给妈妈发日报）
- ✅ 多平台消息聚合（Discord+飞书）
