## 核心贡献

MR-Search将agentic search重新定义为**元强化学习问题**：
- 不是优化单episode内的策略
- 而是训练一个能基于过去episodes调整搜索策略的meta-policy

### 与传统RL对比

| 维度 | 传统RL (Search-R1) | MR-Search |
|------|-------------------|-----------|
| Episode关系 | 独立，无记忆 | 顺序累积，上下文继承 |
| 探索方式 | 单轨迹内探索 | 跨episode元学习 |
| 奖励信号 | 最终答案稀疏奖励 | 每轮self-reflection + dense advantage |
| Credit Assignment | 困难，易局部最优 | RLOO无偏估计，细粒度归因 |
| Test-time行为 | 固定策略 | 持续in-context优化 |

## 技术机制详解

### 1. Meta-Episode结构 (图1)

```
Meta-episode = [Episode_0, Episode_1, ..., Episode_N]

每个Episode包含:
  - Thought-Action-Observation循环
  - 最终答案
  - Self-reflection生成

Reflection作为显式上下文指导后续episode
```

### 2. Self-Reflection驱动探索

每轮完成后生成显式反思：
- 评估当前答案质量
- 识别遗漏信息
- 规划下一步搜索策略

→ "独立尝试"变"渐进式知情搜索"

### 3. Multi-Turn RL算法

**RLOO (Leave-One-Out) Advantage估计**:
```
r̃_i,n = r(s_i,n, a_i,n) - mean_{j≠i} r(s_j,n, a_j,n)
```

**Discounted Cumulative Advantage**:
```
A_i,n = Σ_{n'=n}^{N} γ^{n'-n} r̃_i,n'
```

**关键优势**:
- Critic-free (无需辅助value model)
- 无偏估计
- 长程依赖处理

## 实验验证

### 主要结果

- **8个benchmark**: 平均相对提升 **9.2% ~ 19.3%**
- **Test-time Scaling**: 增加reflection轮数 → 性能持续提升 (图3)
- **对比基线**: 
  - Search-R1 + Sequential reflection (Search-R1-S)
  - Search-R1 + Parallel sampling (Search-R1-P)
  - MR-Search全面超越

### 关键发现

> "LLM agent的局限往往源于单轨迹内探索不足，而非推理能力不足"

- 并行采样中错误答案往往一致出现
- 自反思能力使模型成为更强的in-context meta-learner

### 核心洞察

**MR-Search的"显式reflection作为上下文"与OpenClaw Error Log设计完全同构**:

1. **事后诊断 → 行动指导**: 两者都将执行后的诊断信号转化为后续行动的上下文
2. **渐进式改进**: 拒绝"一次性正确"的幻想，拥抱迭代优化
3. **显式化原则**: Reflection/Error必须显式生成，而非隐式状态

### 设计验证

MR-Search论文从独立研究角度验证了OpenClaw的关键设计决策：
- ✅ **L1/L2/L3分层**: MR-Search的context management protocol与Memory三层架构对应
- ✅ **Error Log作为学习信号**: 自反思的显式生成验证了Error Log的设计哲学
- ✅ **禁止运行时Self-Evolution**: MR-Search的reflection是"上下文指导"而非"权重更新"，与L3立场一致
