## 核心更新

Claude Code v2.1.50 发布内置 **Git Worktree 支持**，由创始人 Boris Cherny 亲自官宣。

### Git Worktree 原理
- Git 2015年已有功能
- 一个 `.git` 仓库同时挂载多个工作目录
- 每个目录有独立文件和 branch
- 共享 Git 历史，无需多份clone，无需stash

---

## 五大新功能

| 功能 | 用法 |
|------|------|
| **CLI隔离模式** | `--worktree` 参数，可指定名或自动命名 |
| **Desktop App** | Code tab 勾选 worktree mode 一键开启 |
| **Subagent隔离** | "用 worktree 跑你的 agent"，5个sub-agent同时迁移5个模块互不干扰 |
| **Custom Agent** | frontmatter 加 `isolation: worktree` 永久启用 |
| **非Git VCS** | Mercurial/Perforce/SVN 通过 hooks 获得隔离能力 |

---

## Boris Cherny 关键回复

| 问题 | 回答 |
|------|------|
| **并行上限** | 数百个并行没问题 |
| **清理机制** | 没改动自动清理，有改动会询问 |
| **Setup脚本** | 通过 hooks 支持 |

## 对我们意味着什么

- **Subagent隔离**: Worktree提供了文件系统级别的隔离，验证我们的Subagent并行设计方向
- **人脑瓶颈**: 并行Agent的瓶颈在人的review能力，而非Agent本身
- **测试缺口**: 并行开发需要配套的测试/发布基础设施
- **生态趋势**: 第三方工具(superpowers)的功能被官方集成是常态
