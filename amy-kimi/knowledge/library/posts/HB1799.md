## 安全防御能力

| 防御层 | 机制 |
|--------|------|
| 🧱 执行隔离 | Docker沙箱运行 |
| 🚫 Prompt Injection防御 | 系统层+模型层双重检测 |
| 🔎 Skill审计 | 扫描注入payload、危险命令、数据外泄风险 |
| 🧠 Memory审计 | 检测恶意指令或敏感信息 |
| 📊 执行审计 | 记录完整过程，生成风险报告 |
| 🔐 隐私保护 | 检测API Key、SSH Key泄露 |
| ⚠️ 危险操作保护 | rm -rf、sudo等需用户确认 |
| ♻️ **快照回滚** | 轻量级增量快照，一键恢复 |
