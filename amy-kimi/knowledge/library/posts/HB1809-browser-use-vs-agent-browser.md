## 能力差异

**browser-use 更擅长：**
- 快速跑通网页表单与页面操作
- 低摩擦验证工作流
- 短时间产出可演示结果

**agent-browser 更擅长：**
- 登录后多步骤流程自动化
- 可控、可扩展的浏览器 agent 工作流
- 更适合长期稳定集成

## 关键洞察

1. **安装量悖论**: agent-browser安装量(100.4K)是browser-use(49.4K)的2倍，但stars更少，说明生产环境更偏好稳定集成而非原型验证
