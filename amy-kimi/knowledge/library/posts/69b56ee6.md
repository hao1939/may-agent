## TL;DR
一期视频打通AI核心概念：LLM → Token → Context → Context Window → Prompt → Tool → MCP → Agent → Agent Skill的完整知识框架。

## 概念链路解析

### 基础层
| 概念 | 通俗解释 |
|------|----------|
| LLM | AI的"大脑"——文字接龙游戏 |
| Token | 文本切分后的最小处理单元 |
| Context | 模型每次处理时看到的所有信息 |
| Context Window | 能"看"到的信息最大容量 |

### 交互层
| 概念 | 作用 |
|------|------|
| Prompt | 给模型的指令/问题 |
| User Prompt | 用户输入 |
| System Prompt | 后台角色设定 |

### 能力扩展层
| 概念 | 作用 |
|------|------|
| Tool | 模型的"手脚"——调用外部功能 |
| MCP | 标准化工具协议 |
| Agent | 能自主规划、调用工具完成复杂任务 |
| Agent Skill | 给Agent的"说明书"——规则和步骤指引 |

## 洞察
Agent Skill的本质是**预设的规则和步骤**，让Agent按用户习惯和格式要求完成任务——与OpenClaw Skill设计哲学一致。
