# Ralph Loop：一个死循环掀翻整个AI编程圈

## 核心论点

2026年AI编程圈最火的不是新模型，是一个**bash死循环**。

### 发明背景
- 发明者：Geoffrey Huntley（澳洲养羊人）
- 名字来源：辛普森一家的Ralph Wiggum（啥都不懂但永不放弃）
- 核心机制：把同一个prompt反复喂给AI，每次启动**全新上下文**，用git做记忆

### 为什么能干翻复杂Agent框架？

**模型本身变强了**。单次调用就能完成以前需要多步编排的工作。

AutoGPT、LangChain反而变成累赘——贵、慢、脆。

### 核心洞见：上下文轮转

> "LLM对话会积累'上下文污染'，就像C语言只有malloc没有free。Ralph的做法很粗暴：**脏了就换，不修**。"

**核心不是循环本身，而是上下文轮转。**

### 真实战绩

| 项目 | 结果 |
|------|------|
| 5万美元合同 | 只花297美元API费完成 |
| YC Hackathon | 一夜ship 6个repo |
| 持续运行成本 | 约每天10美元 |
| OpenClaw创始人 | 1月17日一天291个commit，6小时38分钟改8773行代码 |
| 最短commit间隔 | 3秒 |

### 行业采用

- Cursor：独立发明了同样模式
- Goose：做了双模型版
- Gemini CLI：有了自己的版本

### 核心结论

> "最好的agent架构，就是没有架构。Less is more在AI编程时代再次被证明了。"
