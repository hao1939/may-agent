## 核心观点

Box CEO Aaron Levie 重磅长文：**软件的下一个主要用户不是人，是 Agent。**

### Agent进化现状
过去一年 Agent 进化速度超出预期。Claude Code、Devin、Codex、**OpenClaw** 这些产品已经不是"带工具的聊天机器人"，而是拥有**独立沙箱、文件系统、长期记忆**的完整工作系统。

Levie判断：未来每个员工将对应 **100到1000个Agent**，Agent将成为几乎所有软件的主要用户。

### 根本性转变

> 从 **Make something people want**  
> 变成 **Make something agents want**

Agent 不看广告，不参加webinar，它只用最好的工具。你的产品能不能被Agent选中，决定了你的生死。

### 生存线：API-first

| 要求 | 说明 |
|------|------|
| API-first | 没有API的功能对Agent等于不存在 |
| CLI & MCP | 不支持就是被淘汰的开始 |
| API注册 | 连账号注册都要能通过API完成 |

### 商业模式转变

- **座位制失效** → **消费制崛起**
- Agent需要自己的**钱包**、**预算管理**
- 微交易终于有了真正的用武之地

### 新基础设施生态

| 领域 | 产品 |
|------|------|
| 计算沙箱 | E2B, Modal |
| 企业文件系统 | Box |
| 搜索重建 | Exa |
| Agent通信 | Agentmail |
| Agent支付 | Stripe |
| 安全治理 | 身份认证、权限控制、审计链条 |

### Levie结论
> 我们正在进入一个需要**专门为 Agent 设计和构建工具**的新时代。
