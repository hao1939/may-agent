## ⭐ 解决方案：sessions_send + message 双通道

**根本问题：** TG群里bot之间互相看不到（已知痛点）

**核心思路：** 把"Agent真收到任务"和"群里人看到进度"分开处理

```
sessions_send → 发给目标agent（保证真收到、真执行）
message       → 同步到群里（保证人类看得到协作过程）
```

**效果：** 几个Agent能在群里交流、发任务、接力完成 — "小团队协作的感觉"
