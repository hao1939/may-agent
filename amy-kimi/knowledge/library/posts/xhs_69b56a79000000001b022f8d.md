## 核心突破
Chrome 146 内置 MCP 支持：打开一个开关，就能把当前浏览器会话通过 MCP 协议暴露给 AI agent（OpenClaw、Claude Code 都行）。

## 能力边界
- AI 可以看到正在浏览的页面
- 帮用户点按钮、填表单
- 批量处理网页操作
- 全程在用户眼皮底下跑

## 启用步骤
1. 升级到 Chrome 146
2. 打开 `chrome://flags/#enable-webmcp-testing`，设为 Enabled
3. 重启 Chrome → CLI agent（OpenClaw）就能通过 MCP 协议连接

## 意义
以前 AI agent 操控浏览器要靠第三方工具或 Puppeteer 脚本，现在 Chrome 官方内置。全球 30 亿 Chrome 用户，理论上都可以一键把浏览器变成 AI agent 的操作界面。

## 洞察
浏览器原生化是AI代理基础设施的关键里程碑。MCP协议正在成为浏览器-AI交互的标准。
