👀 先 SFT 微调，再接 RL 强化，这套大模型能力提升的“黄金组合拳”，怎么打着打着就把模型打“废”了？
	
🛠️ CHORD 框架：从“两步走”到“协奏曲”
我们提出 CHORD 框架，改进了“先 SFT、后 RL”的流程。我们不把 SFT 和 RL 看作两个孤立的阶段，而是将它们融合成一首和谐的“协奏曲”。
方法一：全局动态调控 (μ)，从“硬切换”到“软过渡”
传统方式： SFT (μ=1) ➡️ RL (μ=0)，像一个开关，切换生硬。
CHORD 方式： 通过动态衰减的系数 μ，让模型平滑地从“模仿专家”过渡到“自我探索”。前期加大模仿权重，后期逐步放手让模型自由发挥，完美解决了“SFT 火候”难掌握的问题。
但这就够了吗？不，模型依然可能只会模仿专家数据。为了让模型把专家的经验当成“引导”而非“模板”，我们需要更精细的控制。
方法二：Token 级择优学习 (ϕ)，从“全盘吸收”到“取其精华”
一个聪明的学习者，绝不会把参考书逐字背诵。CHORD 赋予了模型这种智慧：
模型已经滚瓜烂熟的部分？➡️ 权重调低，避免死记硬背，防止“熵坍塌”。
模型完全不懂的部分？➡️ 权重调低，防止被“带偏”，保持策略稳定。
模型“似懂非懂”的部分？➡️ 权重调高，这才是学习的“甜点区”，引导模型集中火力攻克认知盲区。
这种择优学习，让模型学会了“批判性”地吸收专家经验。比如在数学任务中，CHORD 模型既学会了专家严谨的“Verify”验证步骤，又保留了自己简洁的推理风格，找到了效率和深度的完美平衡。

数学推理能力飙升： 在核心的数学推理任务（如 AIME、AMC）上，CHORD 全面超越了传统的 SFT、RL 及 SFT-then-RL 方法。
通用能力不降反升： 更关键的是，在通用问答（MMLU-Pro）上也展现了卓越的泛化能力，真正做到了 1+1 &gt; 2 的效果。
推理模式自发融合： 训练后的模型在回答长度和推理模式上，找到了一个介于纯 RL 和 SFT 之间的平衡点，既吸收了专家策略的深度，又保留了自身的高效风格。

# 先SFT后RL但是效果不佳？你可能没用好"离线专家数据"！

> CHORD框架通过动态融合SFT与RL，实现模型在专家数据与自我探索间的平衡，提升大模型性能。

[Slide 2]
提到提升大模型能力，SFT（监督微调）再接 RL（强化学习）的范式是一套常见操作。但在各种场景实践后，你可能会发现事情并没有那么简单。

作为大模型从业者或者研究人员的你，大概率也遇到过以下困境之一：

● 越学越差： 手里的有些 SFT 业务数据，但微调后再接 RL，模型性能不升反降，甚至不如直接 RL。到底是 SFT "火候"过了，还是数据本身有问题?

● 原地踏步：费尽心力搭建了 RL 训练管线，却发现模型提升有限，效果还不如用同样的数据做蒸馏 SFT 来得直接。

● 顾此失彼：SFT 后，虽然目标任务性能提升了，但模型的通用能力却明显下降，不得不在两者之间艰难取舍。

如果这些场景让你感到熟悉，问题很可能出在你使用的"离线专家数据（Off-policy Expert Data）"上。针对这一挑战，通义实验室 Trinity-RFT 团队提出 CHORD 框架——通过动态融合 SFT 与 RL，让模型学会"取其精华"，实现从模仿到超越的跃迁。

从 SFT 到 RL 的过程中到底发生了什么？

我们通过实验观察到一个非常有趣的现象：直接用高质量的专家数据做SFT，模型的性能并不会一路高歌，反而会走出一条 "性能暴跌 ➡️适应爬坡 ➡️过拟合僵化" 的奇特曲线 📊。

[图表：X轴为Step（0-100），Y轴为Accuracy(%)（60-90），曲线分三个阶段：Policy Shift（性能下降）、Readapt Phase（性能回升）、Overfitting Phase（性能趋于平稳后略降）]

这就像一位优秀的学生，突然被要求全盘模仿另一套完全不同的解题思路（与现有模型 Pattern 不同的 Off-policy 数据）。初期，他会因困惑和不适导致成绩暂时
