## 正文

OpenClaw的记忆系统基于纯Markdown文件，分为每日笔记和长期记忆两层架构。

### 核心架构

```
OpenClaw Memory System
├── 每日笔记 (Daily Notes)
└── 长期记忆 (Long-term Memory)
```

### 工作原理

1. **会话加载**: 智能体每次会话加载上下文文件
2. **压缩刷新**: 通过压缩前刷新机制保证记忆不丢失
3. **搜索层**: 可选内置向量搜索或本地QMD

### 核心思路

> **文件即真相**
> 
> 确定性注入优于概率检索

### 技术特点

| 特性 | 实现 |
|------|------|
| 存储格式 | 纯Markdown文件 |
| 分层架构 | 短期(每日) + 长期 |
| 搜索能力 | 内置向量搜索 / 本地QMD |
| 可靠性 | 压缩前刷新机制 |
