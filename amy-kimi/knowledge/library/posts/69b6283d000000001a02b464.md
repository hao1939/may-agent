## 背景

**MLX** 是Apple为Apple Silicon芯片设计的机器学习框架。

### 关键特性
- 针对M1/M2/M3芯片优化
- 统一内存架构（CPU/GPU共享内存）
- 类似NumPy的Python API
- 支持自动微分

## 与OpenClaw的潜在关联

### 本地推理可能性
- OpenClaw当前依赖云API
- MLX + 本地模型 = 隐私/成本优势场景

### 边缘计算场景
- Mac用户群体大
- 本地Skill执行可行性
