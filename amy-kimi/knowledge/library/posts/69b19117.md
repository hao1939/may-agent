## 核心洞察

长期记忆正在被拆成**独立能力层**，不再只是向量库挂件，而更像agent runtime里的正式模块。

### 过去方案的局限

- 要么只是存，要么只是取
- 很少处理"什么时候写、什么时候调、什么时候忘"
- 任务拉长后面临：脏信息累积、检索时机不稳、经验无法复用

### ReMe核心思路

将memory管理拆成**完整生命周期**：
1. **提炼** - 从历史执行里提炼可复用经验
2. **调用** - 根据当前场景做更合适的检索
3. **精炼** - 持续更新memory池，旧经验逐步变成更高质量procedural memory

### 关键改进

Agent用到的不是**原始轨迹堆积**，而是更可复用、可维护的**经验层**。

### 后续研究方向

顺着这条线，以下都将变成skill-aware agent system里可以单独研究的问题：
- memory schema设计
- retrieval timing策略
- forgetting policy

## 与我们系统的关联

✅ **Self-Improvement Pool验证**：ReMe的"提炼-调用-精炼"循环与我们的经验提炼流程高度一致

✅ **动态更新机制**：需要设计memory的渐进式精炼策略，而非简单追加

✅ **可研究问题**：retrieval timing和forgetting policy可作为后续优化方向
