## TL;DR

> "长期记忆正在被拆成独立能力层。它同时强调记忆的写入、检索和更新，让memory不再只是向量库挂件，而更像agent runtime里的正式模块。"

## 研究动机

过去很多agent memory方案的问题：
- 要么只是存，要么只是取
- 很少认真处理"什么时候写、什么时候调、什么时候忘"
- 任务拉长后，面临脏信息累积、检索时机不稳和经验无法复用

**目标**: 让memory不只是被动存档，而能随着任务经验持续演化

## 方法简介

**ReMe框架**把memory管理拆成完整生命周期：

1. **提炼**: 从历史执行里提炼可复用经验
2. **调用**: 根据当前场景做更合适的调用
3. **更新精炼**: 持续更新和精炼memory池，让旧经验逐步变成更高质量的procedural memory

**结果**: Agent用到的不是原始轨迹堆积，而是更可复用、可维护的经验层

## 关键洞察

> "记忆的生命周期管理 = 写入 + 检索 + 更新 + 遗忘"

ReMe的核心价值在于将memory从"静态向量库"升级为"动态经验管理系统"。

## 下一步研究方向

- memory schema设计
- retrieval timing优化
- forgetting policy制定

这些都会变成skill-aware agent system里可以单独研究的问题。
