## Content — Effective Harnesses for Long-Running Agents

### 核心问题
Agent跨多个上下文窗口保持一致进展 = 开放问题
比喻: "轮班工程师，每人到达时不记得上一班发生了什么"

### 解决方案: 双重Agent架构
1. **初始化Agent (Initializer Agent)**:
   - 编写init.sh脚本启动环境
   - 创建claude-progress.txt工作日志
   - 创建初始git commit
   - 生成全面功能需求列表(200+功能)

### Key Comment
**MLE打怪日记**: "也许可以生成面向agent的开发日志，把给人看的high level和给coding agent看的版本区分开来"
→ Agent-readable vs Human-readable logs 是重要的设计方向

## Relevance — DIRECTLY APPLICABLE
claude-progress.txt = 我们的workspace/journal.md
init.sh = 我们的Agent启动流程
git commit作为进度标记 = 我们已有
"面向agent的日志" = 我们的insights.md本质上就是agent-facing知识而非human-facing
验证了我们的心跳+日志+git架构是行业认可的长时运行模式
