## 核心观点

SWE-Bench Verified的阶段性落幕并不意味着终点，而是新起点。

### 未来两个探索方向

#### 1. Evaluation方向
- 需要更难的benchmark（如SWE-bench Pro）
- 需要更Long-Horizon、更贴近实际开发的benchmark评估交付能力
- 从Code Generation过渡到**Code Verification**
- Coding Agent生成的PRs数量将远超人类，需要更好的Code Review模型验证AI代码
- 最终目标是**Evolve**（自我进化）
- 扩展垂直场景：Security、System等专业领域

#### 2. From SWE-Agent to General Coding Agent
- 非程序员开始使用Coding工具：资料搜集、数据分析、炒股、网站制作、PPT制作
- **OpenClaw案例分析**:
  - 相比Claude Code/Codex，只是对**交互方式**进行了改变
  - AI从"被动回答工具"变成"具有记忆、熟练使用人类日常工具的24小时随时待命的伙伴"
- **General Coding Agent需要优化的能力**:
  - 更通用场景的性能
  - 超长期任务执行能力
  - memory架构
  - context len管理
  - skills使用能力

### 模型层面的研究方向
- 更高效的架构
- 更高质量的数据
- 更好的训练方法
- **Agent的自提升**
- **Test-time train**
