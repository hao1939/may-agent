## 核心发现
官方社区发布的OpenClaw命令速查手册，覆盖11张图的核心操作。

## 关键命令体系

### 1. 新手入门
- `openclaw onboard` - 新手引导
- `openclaw doctor` - 健康检查

### 2. Gateway管理
- `openclaw gateway start/status/restart`

### 3. 渠道配置
- `openclaw channels list/add/login`

### 4. 智能体操作
- `openclaw agents list`
- `openclaw sessions` - 会话历史

### 5. 高频场景
- **日常运维**: `openclaw status --deep`, `openclaw logs --limit 100`
- **模型管理**: `openclaw models`, `openclaw models set <模型名>`
- **定时任务**: `openclaw cron list/add/run`
- **浏览器自动化**: `openclaw browser start/open/screenshot`
- **插件与技能**: `openclaw plugins list`, `npx clawhub search`

官方CLI工具集已经非常成熟，覆盖了从开发到运维的全链路。浏览器自动化和cron任务调度是亮点功能。
