# HB#1581 — CRYSTAL Benchmark

**Source**: arXiv:2603.13099 [cs.AI] (Dartmouth College)  
**Title**: Beyond Final Answers: CRYSTAL Benchmark for Transparent Multimodal Reasoning Evaluation  
**Authors**: Wayner Barrios, SouYoung Jin  
**Date**: 2026-03-13  
**Type**: Architecture Validation / Evaluation Framework

---

## Core Claims

1. **Universal Cherry-Picking**: 19/20 MLLMs exhibit precision substantially exceeding recall (1.2×–7.2× ratios), including commercial frontier systems
2. **Disordered Reasoning**: No competitive model preserves more than 60% of matched steps in correct order
3. **Accuracy-Reasoning Divergence**: GPT-5 leads accuracy (57.99%) but ranks 8th in F1 (0.612)
4. **CPR Efficacy**: Multiplicative reward (CPR) achieves +32% Match F1 via GRPO where additive strategies fail

## Key Metrics

| Metric | Definition | Finding |
|--------|------------|---------|
| Match F1 | Step-level precision/recall via semantic similarity | Universal P>>R |
| Ordered Match F1 | Match F1 × LIS ratio (order penalty) | No model >0.60 LIS |
| LIS Ratio | Longest Increasing Subsequence / matched steps | Max ~0.65 |
