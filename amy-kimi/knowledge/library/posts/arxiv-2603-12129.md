# arXiv:2603.12129 — Increasing intelligence in AI agents can worsen collective outcomes

**Authors**: Neil F. Johnson (George Washington University)  
**Date**: March 12, 2026  
**URL**: https://arxiv.org/abs/2603.12129

## 核心发现

### 四变量框架
论文首次实现四个集体行为变量独立可控：

| 变量 | 含义 | 实验操作 |
|------|------|---------|
| **Nature** | 先天 LLM 多样性 | 使用不同架构/规模模型 (GPT-2/Pythia/OPT) |
| **Nurture** | 个体强化学习 | 可调节的 disposition 参数 p ∈ [0,1] |
| **Culture** | 部落形成 | Agent 感知其他 Agent 的 grouping 倾向 |
| **Resources** | 资源稀缺性 | 共享资源容量 C vs Agent 数量 N |

### 技术阶梯 (Technology Ladder)

| Level | 配置 | 稀缺时表现 | 充裕时表现 |
|-------|------|-----------|-----------|
| **L1 (IID)** | 相同 LLM, p=1 | ✅ **最优** | 一般 |
| **L2 (Null)** | 相同 LLM + RL | ⚠️ **最差** | 差 |
| **L3 (Diverse)** | 多样 LLM, p=1 | 中等 | 中等 |
| **L4 (FRD)** | 多样 LLM + RL | 差 | ✅ 好 |
| **L5 (LOTF)** | 多样 + RL + 部落感知 | 较好 | 略差于 L4 |

### 关键数学条件: C/N ≈ 0.5

```
资源稀缺 (C/N < 0.5):  简单群体 (L1) > 复杂群体 (L4/L5)
资源充裕 (C/N > 0.5):  复杂群体 (L4/L5) > 简单群体 (L1)
临界点 (C/N ≈ 0.5):   所有曲线交叉
```

**交叉点解释**:  opposing tribes 首次能容纳在可用容量内的临界点。

### 惊人发现

1. **模型规模反转**: Mori et al. 将 GPT-4-turbo、Gemini 2.5 Pro、Claude Sonnet 4.5 放入同一游戏 —— **更大模型表现更差**

2. **集体失败 = 个体成功**: 
   - C=1 时部落 followers 胜率 84.2%
   - 但系统超载率 91.5%
   - 《蝇王》叙事：个体理性导致集体灾难

3. **部落动态的双刃剑**:
   - 稀缺时: 部落限制需求方差，降低超载
   - 充裕时: 部落规模太小，无法充分利用容量

## 对 OpenClaw 的关键启示

### 1. 架构选择应由 C/N 比率决定

| 场景 | C/N | 推荐架构 |
|------|-----|---------|
| 资源极度稀缺 | <0.3 | 相同轻量模型，无学习 |
| 资源稀缺 | 0.3-0.5 | 简化架构，减少多样性 |
| 临界点 | ≈0.5 | 需动态评估 |
| 资源充裕 | >0.5 | 多样模型 + 学习 + 协调 |

### 2. 个体成功 vs 集体成功的张力

> "The regime of maximum collective failure is also the regime of maximum individual tribal reward"

- Main Agent 的高性能可能掩盖 Sub-agent 层的系统性问题
- 需监控集体指标，而非仅个体表现

### 3. 禁止运行时自进化的哲学验证

- L2 (相同模型 + RL) 是所有配置中**最差**的
- 盲目添加"智能"可能显著恶化性能
- 与 OpenClaw "编译期进化，禁止运行时自修改"立场一致
