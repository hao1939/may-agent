## 核心内容

AutoAgent论文(arXiv:2603.09716)由MemTensor(上海跃知科技)、上海交通大学、高等算法研究院(IAAR)联合发布，提出通过**认知演化与弹性存储**重构Agent架构。

### 论文核心贡献

**1. 演进式认知 (Evolving Cognition)**
- 结构化、双面认知：Internal Cognition（工具/技能知识）+ External Cognition（同伴Agent/环境反馈）
- 超越静态Prompt，形成可动态更新的知识库
- 持续通过交互经验优化

**2. 弹性记忆编排 (Elastic Memory Orchestration)**
- 动态组织交互历史
- 三层处理：保留原始记录 → 压缩冗余轨迹 → 构建可重用 episodic 抽象
- 减少token开销，同时保留决策关键证据

**3. 闭环认知进化 (Closed-loop Cognitive Evolution)**
- 分析决策结果的经验
- 对齐意图与实际结果
- 无需外部重训练，持续更新认知模型和技能库

**4. 实时上下文决策 (On-the-fly Contextual Decision-Making)**
- 统一动作空间：Emic Actions（自驱动问题解决）+ Etic Actions（寻求外部协助）
- 替代预定义工作流，实现自适应推理

### 关键洞察

> "大多数Agent框架本质上是硬编码的'复读机'——System Prompt中写死工具说明和操作流程，一旦环境偏移就陷入逻辑死循环。"

**静态认知 vs 动态现实**的断裂是制约Agent通用化的核心障碍。

### 技术实现

- 执行周期（Execution Cycle）处理实时任务推进
- 进化周期（Evolution Cycle）驱动长期适应
- Elastic Memory Orchestrator 耦合两个周期

### 评估结果

在GAIA、HLE等严苛基准测试中超越DeepAgent等前沿框架。

## OpenClaw 关联分析

### 1. 与Memory Gap发现的呼应
Bob的《The Memory Gap》合成文档提出：
- INDEX.md（Always-in-Context Index）
- Archivist（Decay机制）

AutoAgent的Elastic Memory Orchestrator实现了类似理念：
- ✅ 原始记录保留（L0 Memory）
- ✅ 压缩冗余（Decay的另一种实现）
- ✅ 可重用技能抽象（L2→L1蒸馏）

### 2. 与禁止Self-Evolution立场的张力
AutoAgent强调"无需外部重训练的连续更新"，这与OpenClaw禁止Self-Evolution的立场形成对比。

**关键区别**：
- AutoAgent的进化是**基于明确反馈的Skill库更新**（类似MetaClaw）
- 非权重层面的自主演化
- 有明确的"对齐意图与实际结果"步骤（可审计）

### 3. Harness Engineering验证
AutoAgent的"可观测+可干预"设计哲学与Harness Engineering一致：
- 认知状态显式结构化（可观测）
- 记忆编排主动管理（可干预）
- 进化闭环可审计（可追溯）
