## 核心内容

### 痛点
OpenClaw "聊着聊着就忘了" — 记忆管理问题

### 解决方案: memory-lancedb-pro
**核心理念**: 不是让龙虾存更多，而是让龙虾**更会找记忆**

### 四大特性

| 特性 | 说明 |
|------|------|
| **混合检索** | 不只看向量相似度，还做关键词全文检索 |
| **结果重排** | 找到后再精排，把最相关记忆放前面 |
| **作用域隔离** | agent、project、user记忆分开，不串台 |
| **低噪声写入** | 不是每句话都存，减少垃圾记忆 |

### 架构升级
把 OpenClaw 记忆从 **"随手记便签"** 升级成 **"会分类、会搜索的长期记忆库"**

### 性能配置
- 本地存 LanceDB
- embedding和rerank走云端
- 更吃API而非本机性能
