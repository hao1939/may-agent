## 核心贡献

### 1. 认知核心范式 (Cognitive Core Paradigm)

论文提出**推理不应被视为顺序模块**，而应被提升为整个系统的**认知核心**。

- 功能不是替代现有模块，而是理解、协调和赋能它们
- 将系统从刚性线性过程转变为集成智能Agent
- 实现整体场景理解和自适应决策

### 2. 三层认知层级 (Cognitive Hierarchy)

| 层级 | 名称 | 交互范围 | 核心能力 | OpenClaw映射 |
|------|------|----------|----------|--------------|
| L1 | Sensorimotor | Vehicle-to-Environment | 感知、控制 | L0/L1 执行层 |
| L2 | Egocentric | Vehicle-to-Agents | 反应策略、规划 | L2/L3 Agent协调 |
| L3 | Social-Cognitive | Vehicle-in-Society | 社会常识、交通规则、意图推理 | AGENTS.md Persona |

### 3. 七大核心推理挑战

**Egocentric层级 (C1-C4)**:
- C1: Heterogeneous Signal Reasoning — 异构信号融合
- C2: Perception-Cognition Bias — 感知-认知偏差
- C3: Responsiveness-Reasoning Tradeoff — 响应性-推理权衡
- C4: Long-horizon Causal Reasoning — 长程因果推理

**Social-Cognitive层级 (C5-C7)**:
- C5: Social Commonsense Reasoning — 社会常识推理
- C6: Traffic Regulation Reasoning — 交通规则推理
- C7: Multi-Agent Game-Theoretic Reasoning — 多Agent博弈推理

### 4. Glass-Box Agent趋势

论文分析揭示了一个明确趋势：向**整体可解释的玻璃盒Agent**发展。

- 可解释性需求驱动架构设计
- 验证实时安全性和社会合规性存在关键空白

## 关键洞察

### 响应性-推理权衡 (Responsiveness-Reasoning Tradeoff)

> "LLM-based推理的高延迟、审议性质与车辆控制的毫秒级、安全关键需求之间存在根本且未解决的紧张关系"

**对OpenClaw的启示**:
- Main Agent (审议) vs Sub-agent (响应) 的分层架构是应对这一权衡的工程解
- Fast/Slow分离设计有理论基础

### 从模块化到认知核心

传统AD架构: 感知 → 预测 → 规划 → 控制 (线性流水线)

认知核心架构:
```
        ┌─────────────────┐
        │  Cognitive Core │ (推理核心)
        │   (LLM/MLLM)    │
        └────────┬────────┘
                 │
    ┌────────────┼────────────┐
    ↓            ↓            ↓
┌───────┐   ┌───────┐   ┌───────┐
│ 感知   │   │ 规划   │   │ 控制   │
└───────┘   └───────┘   └───────┘
```

**与OpenClaw的对应**:
- Cognitive Core ↔ Main Agent (L3推理)
- 感知/规划/控制 ↔ Sub-agents/Skills (L1/L2执行)
