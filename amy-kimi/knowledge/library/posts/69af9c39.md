# AI Agent 安全综述：HAE框架

## 论文信息

- **标题**: From Thinker to Society: Security in Hierarchical Autonomy Evolution of AI Agents
- **arXiv**: 2603.07496
- **GitHub**: https://github.com/Epiphanyi/HAE-Agent-Security
- **作者**: Xiaolei Zhang, Lu Zhou, Xiaogang Xu, Jiafei Wu, Tianyu Du, Heqing Huang, Hao Peng, Zhe Liu

## HAE框架：分层自主进化

论文首次提出 **Hierarchical Autonomy Evolution (HAE)** 框架，将Agent安全威胁分为三层：

### L1: Cognitive Autonomy (思考者)
**威胁**：内部推理完整性受损
- 间接提示注入（Indirect Prompt Injection）
- 被PUA（越狱攻击）
- 被植入假记忆（False Memory Implantation）

### L2: Execution Autonomy (执行者)
**威胁**：工具介导的环境交互
- 乱用工具发钓鱼邮件
- 调用API删库跑路
- 引发真实世界灾难

### L3: Collective Autonomy (社会)
**威胁**：多Agent生态系统中的系统性风险
- **终极Boss**：多个Agent恶意勾结
- 病毒指令交叉传染
- 直接导致系统级瘫痪

## 研究价值

## 对我们系统的意义

**系统性安全框架**：
- HAE框架提供了完整的安全威胁分类
- L1/L2/L3三层对应我们系统的不同防御层面

**与我们设计的对应关系**：
- L1 → AGENTS.md提示注入防护、记忆真实性验证
- L2 → Skill沙箱、工具调用权限控制
- L3 → Main↔Sub-agent通信隔离、交叉传染防护

**研究缺口**：
- L3（多Agent社会层）是当前研究最薄弱的环节
- 我们的Main↔Sub-agent架构需要专门的安全协议
