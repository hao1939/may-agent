# agent memory开始读轨迹

## TL;DR
论文《Trajectory-Informed Memory Generation for Self-Improving Agent Systems》提出让agent memory不再只是存储对话事实，而是**直接从执行轨迹里提炼可复用经验**。将失败、恢复和低效成功都转成可检索的tips，让memory更接近execution-native memory。

## Paper Details

### 研究动机
- 现有agent memory方案像"把历史内容塞进检索库"
- 能补上下文，但不一定真能教会agent下次怎么做得更好
- 问题：agent明明跑过很多任务，为什么轨迹里的成败经验没有被系统化沉淀？

### 方法简介
1. **收集**：agent在任务中的完整执行轨迹
2. **归因**：用decision attribution定位
   - 哪些步骤导致失败
   - 哪些动作实现了恢复
   - 哪些路径虽然成功但效率偏低
3. **提取**：抽成三类可复用经验
   - **Strategy tips**（策略提示）
   - **Recovery tips**（恢复提示）
   - **Optimization tips**（优化提示）
4. **应用**：后续任务里按需检索和调用

### 实验结果
- **数据集**：AppWorld
- **Held-out任务提升**：最高+14.3pp scenario-goal
- **复杂任务提升**：最高+28.5pp
- **关键洞察**：agent memory重点从"记住发生过什么"转向"总结下次该怎么行动"
