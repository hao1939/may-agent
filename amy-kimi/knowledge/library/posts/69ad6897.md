## 核心观点

Anthropic 工程负责人 Boris 访谈透露：在 Anthropic 内部，**试错成本几乎归零**，传统互联网打法已被彻底抛弃。

### 传统流程 vs 新范式

| 传统流程 | Anthropic 新范式 |
|---------|-----------------|
| 产品经理写 40-50 页需求文档 | 不写需求文档 |
| 跨部门会议讨论按钮颜色/跳转逻辑 | 无强制工单系统 |
| 排期开发，小心迭代 | **直接发可跑通的代码请求 (PR)** |
| 沉没成本高昂 | 试错成本几乎为零 |

### 关键洞察
- **个人产能**: 一个人一天半可产出近 20 个能点能跑的真实产品原型
- **文化转变**: "别发什么说明文档，有想法就直接发可以跑通的代码请求"
- **成本重构**: 当机器试错成本被打穿，前期过度规划反而成为最大内耗

## 对我们的意义

这与我们 AGENTS.md + Claude Code 的工作流高度吻合。但需注意适用范围边界：
- ✅ 适合探索性、原型性、个人项目
- ⚠️ 多人协作、交付性开发仍需规范
- 🔴 Token 成本对大多数团队仍是约束

**L3 Flag**: 区分 "原型验证阶段" vs "生产交付阶段" 的工作流模式。
