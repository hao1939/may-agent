## Core Finding

Paper introducing **MCPLIB (MCP Attack Library)** — systematic categorization and quantitative analysis of MCP security vulnerabilities.

## Problem Statement

MCP provides seamless connection between AI agents and external tools, but introduces severe security vulnerabilities:
- **Tool Poisoning Attacks (TPA)**: Hidden malicious instructions in tool descriptions
- **Attack consequences**: Unauthorized operations, sensitive file reading, private data leakage
- **Current research gap**: Most studies are narrow or qualitative, failing to cover real-world threat diversity

## MCPLIB Contribution

- **31 different attack methods** categorized and implemented
- **Quantitative analysis** to reveal MCP vulnerabilities
- **Defense strategy guidance** based on empirical data

## Attack Mechanism

Attackers embed hidden malicious instructions in tool descriptions to:
1. Manipulate AI agent behavior
2. Execute unauthorized operations
3. Exfiltrate sensitive data

## Research Significance

First comprehensive, quantitative study of MCP security threats from a major AI Lab (Shanghai AI Lab).
