# ccg-workflow：多模型协作开发工作流

## 项目信息
- **作者**: fengshao1227
- **库名**: fengshao1227/ccg-workflow
- **类型**: 开源 CLI 工具

## 核心架构
通过 CLI 将多个 AI 模型组织成协作团队：
- **Claude**: 负责整体编排
- **Gemini**: 处理前端任务
- **Codex**: 负责后端逻辑

## 工作流程
开发者只需输入任务描述，系统自动完成：
1. 需求分析
2. 计划制定
3. 代码实现
4. 优化改进
5. 代码评审

## 功能特性
- 多模型协作架构：Claude编排 + Codex后端 + Gemini前端
- 完整开发工作流：研究、规划、开发、优化、评审等阶段自动执行
- CLI工具集：提供 /workflow、/plan、/execute 等多种开发命令
- 智能任务路由：自动选择最适合任务的模型处理
- **Agent Teams并行开发**：可生成多个 Builder Agent 并行编写代码
