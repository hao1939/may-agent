## 核心发现

OpenClaw 刚合并 `/btw` 新功能（by the way 模式）：

### 用法
- 在消息前加 `/btw`，AI 立刻回答
- 回答完对话**直接消失，不进记忆**
- 主任务继续跑，AI 完全不知道你问过

### 解决的问题
长任务执行中，用户突然有小问题想问：
- **以前**：直接发消息 → AI 回答 → 进入记忆 → 带着额外信息继续 → 上下文污染 → 注意力分散
- **现在**：/btw 走一次性通道 → 问完即走 → 主任务无感知

## 对 OpenClaw 的意义

1. **上下文管理精细化**：从"全进记忆"到"按需隔离"
2. **用户体验优化**：临时询问不干扰主线任务
3. **功能跟随速度**：Claude Code 刚出，OpenClaw 紧随其后
