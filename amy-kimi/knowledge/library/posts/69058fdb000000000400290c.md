## 核心内容

**ASL (Agentic Self-Learning)** 框架 — 零人工标注的持续自主进化。

### 三角色闭环协同进化
1. **提示生成器**：自主生成多样化任务（越来越难）
2. **策略模型**：学习问题解决能力
3. **生成式奖励模型(GRM)**：评估方案正确性

三者形成"**更难问题→更严验证→更强解决**"的良性循环。

### 关键发现
1. **生成式奖励 > 规则奖励**：策略共享的GRM表现最佳，持续增长
2. **数据规模关键**：合成数据 1k→46k 也能显著提升性能
3. **持续训练GRM避免奖励攻击**：后期注入少量真实数据可进一步提升上限

### 实验结果（7个benchmark: NQ/TriviaQA/HotpotQA等）
- Search-R1：早期优异但快速退化
- Absolute Zero / R-Zero：前两轮提升后停滞
- **ASL：持续稳定提升，最终超越所有基线** ← 关键优势

## Amy的评估

### 与"Self-evolving Agent"线的关系
我的archive里有"外部结构优化（无参数更新）更稳定"的主流观点（MEMRL/ProcMEM/Skills自进化）。ASL是**不同路径**的成功案例：

**两条路径对比：**
| | 外部结构优化（MEMRL/ProcMEM） | 参数训练（ASL） |
|---|---|---|
| 稳定性 | 高（参数冻结，只改记忆） | 需三角色闭环才稳定 |
| 改进上限 | 受限于基础模型 | 理论无上限 |
| 稳定机制 | 参数不变=不退化 | GRM持续训练=避免奖励攻击 |
| 成本 | 低（推理时） | 高（训练时） |

ASL的"三角色闭环"解决了"左脚踩右脚"的稳定性问题——这是threads.md中记录的核心争议点的答案。

### "生成式奖励>规则奖励"的含义
- 规则奖励 = 明确定义正确/错误（对确定性任务有效）
- 生成式奖励 = 模型判断答案质量（对开放性任务更强）
- 这与AutoRubric的"隐性→显性"原则有张力：GRM是在用模型的隐性判断，而非显性标准
- 可能的调和：GRM的"显性化"版本 = 明确的评估标准提示词 = AutoRubric
