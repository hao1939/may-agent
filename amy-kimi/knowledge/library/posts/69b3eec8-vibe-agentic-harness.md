# Vibe vs Agentic vs Harness

## 三代范式演进

### 一代：Vibe Coding 氛围编程
- **核心**：直觉驱动，凭感觉写代码
- **交互**：自然语言 → 直接出代码
- **流程**：无结构 → 复制粘贴 → 能用就行
- **特点**：快、随性、不规范、不可控

### 二代：Agentic Engineering 智能体工程
- **核心**：目标驱动，自主跑通全流程
- **交互**：自然语言+skill+md → 直接出可运行结果
- **流程**：/plan → /execute → /debug → /test → /review
- **特点**：能落地、全自动、但不稳定、难复用

### 三代：Harness Engineering 驾驭式工程
- **核心**：可控 & 规模化，驾驭AI
- **定位**：管理智能体的智能体
- **交互**：任务+规范+约束 → 稳定工程产出
- **流程**：有框架、有权限、可复现
- **特点**：企业级、团队级、可规模化

## 一句话总结

| 范式 | 输入 | 输出 |
|------|------|------|
| Vibe | 我要这个感觉 | AI给代码 |
| Agentic | 我要这个结果 | AI跑通全流程 |
| Harness | 我要稳定可控 | AI被安全驾驭 |

## 对我们的意义

完全验证我们的Harness方向正确性。从"能用"到"可控"是Agent技术成熟的必经之路。
