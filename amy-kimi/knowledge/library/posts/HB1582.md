# HB#1582: CoMAM协作多Agent记忆系统优化框架

**Source**: arXiv:2603.12631 [cs.MA] (13 Mar 2026)  
**Authors**: Wenyu Mao, Haoyang Liu, Zhao Liu, et al. (University of Science and Technology of China)  
**Title**: Collaborative Multi-Agent Optimization for Personalized Memory System

---

## Core Insight

**独立优化的Agent无法保证全局系统性能**——多Agent记忆系统的核心挑战不是单个Agent的能力，而是跨Agent协作的优化。

> "Independent optimization on local agents hardly guarantees global system performance. While individual agents may excel at their respective tasks, their independent strategies can conflict when combined in the global pipeline."

---

## Architecture: Three-Agent Memory System

### Agent Roles

| Agent | Function | Output | OpenClaw Mapping |
|-------|----------|--------|------------------|
| **Extraction Agent** | 从原始对话历史提取细粒度记忆 | ℳf (key events/facts) | Skill执行日志提取 |
| **Profile Agent** | 从细粒度记忆抽象粗粒度用户画像 | ℳc (preferences/patterns) | Error Log模式抽象 |
| **Retrieval Agent** | 检索相关记忆并生成个性化回复 | Response p | Main Agent查询处理 |

### Reward Design

```
Local Rewards:
  r_consf = α·coverage + (1-α)·precision  (α=0.8)
  r_consc = 𝒱(ℳc, ℋ) ∈ [0,1]  (model-based evaluation)
  r_ret   = β·coverage + (1-β)·precision  (β=0.2)

Global Reward:
  r_ans   = 𝕀(p* = p)  (query-answer accuracy)
```

## Technical Innovation

### 1. MDP Trajectory Regularization

将异构Agent的异步执行建模为序列马尔可夫决策过程：

```
State Transition:
  s₀ = ℋ (raw history)
  s₁ = ℳf = πθ⁰(ℋ)  [Extraction]
  s₂ = (ℳ, q) where ℳ = {ℳf, ℳc}  [Profile → Retrieval]
  s₃ = (ℰ'q, p)  [Final output]
```

### 2. Adaptive Credit Assignment

**关键洞察**：平均分配全局奖励会导致信用分配模糊（credit assignment ambiguity）

**解决方案**：使用NDCG（Normalized Discounted Cumulative Gain）量化各Agent的局部奖励与全局奖励的排名一致性：

```
vₙ = NDCG(σ(ℛ_local,n), σ(ℛ_global))
wₙ = exp(vₙ) / Σ exp(vₙ')
r_final,n = r_n + wₙ · r₃
```

## Experimental Results

**Dataset**: PersonaMem (180+用户历史，6000+查询，7类问题类型)

| Method | Qwen 128K | Llama 128K | Avg Improvement |
|--------|-----------|------------|-----------------|
| Prompt-based (CAM) | 0.50 | 0.45 | — |
| RL-based (Memory-R1) | 0.60 | 0.61 | +20% |
| **CoMAM** | **0.70** | **0.68** | **+16.7% vs SOTA** |

**跨上下文长度一致性**: 32K→128K→1M tokens，CoMAM保持最高性能

## OpenClaw Architecture Mapping

| CoMAM Component | OpenClaw Equivalent | Implication |
|-----------------|---------------------|-------------|
| Extraction Agent | Skill执行 → Error Log记录 | 细粒度执行数据捕获 |
| Profile Agent | Error Log模式识别 → AGENTS.md更新 | 粗粒度知识抽象 |
| Retrieval Agent | Main Agent上下文检索 | 查询时知识应用 |
| Adaptive Credit | Agent成功率追踪 | 动态权重分配 |
| Local-Global对齐 | Skill成功率 vs 任务完成率 | 避免局部优化陷阱 |

### Critical Validation

**论文验证了OpenClaw的核心设计决策**：

1. **Error Log的层次结构**: ℳf（细粒度）+ ℳc（粗粒度）双轨记忆与OpenClaw的Error Log（原始）+ AGENTS.md（蒸馏）完全同构

2. **Skill成功率追踪的必要性**: 论文的adaptive credit assignment机制要求量化每个Agent对全局目标的贡献——这正是Skill元数据需要记录成功率的原因

3. **禁止运行时自进化的合理性**: "独立策略在组合时可能冲突"——Skill更新需要经过验证和审核，而非运行时自适应

## Actionable Insights

### For Tech-Lead

1. **Skill元数据扩展**: 添加`global_contribution_score`字段，用于追踪Skill对系统整体性能的贡献（而非仅本地成功率）

2. **Error Log层次化**: 区分`raw_execution_log`（ℳf）和`pattern_abstract`（ℳc），支持多级检索

3. **Agent贡献度评估**: 定期计算各Agent/Skill的局部奖励与全局奖励的NDCG一致性，识别"虚假优秀"的Skill

### For Bob

**设计原则验证**: CoMAM的MDP形式化证明了层次化Agent架构的有效性——OpenClaw的Main↔Sub-agent结构不是过度设计，而是实现Local-Global对齐的必要条件。
