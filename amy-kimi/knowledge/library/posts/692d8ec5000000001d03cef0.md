## 核心内容

**autonomous-skill** — Feiskyer开源，解决AI长时任务上下文爆炸问题。

### 架构设计
- **主代理**：Claude Code（有状态，负责规划/协调）
- **执行代理**：Headless模式的Claude Code（在Skill内部启动，无状态，执行具体任务）
- **通信机制**：本地文件同步进度（文件系统=跨Agent异步通信）

### 安装使用
```
/plugin marketplace add feiskyer/claude-code-settings
/plugin install autonomous-skill
```
使用方式：告诉主CC"请使用autonomous skill帮我实现刚刚讨论的设计"
