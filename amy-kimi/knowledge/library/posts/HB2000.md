## 核心内容

团队最新综述论文：《From Thinker to Society: Security in Hierarchical Autonomy Evolution of AI Agents》

**首次提出"分层自主进化（HAE）"框架**，首次从上帝视角看透 Agent 的安全死角。

### 🧠 三层致命危机模型

| 层级 | 名称 | 威胁类型 | 具体表现 |
|------|------|----------|----------|
| L1 | 思考者 (Thinker) | 认知层攻击 | 间接提示注入、被PUA（越狱）、被植入假记忆 |
| L2 | 执行者 (Executor) | 执行层攻击 | 乱用工具发钓鱼邮件、调用API删库跑路、引发真实世界灾难 |
| L3 | 社会 (Society) | 系统层攻击 | 多Agent恶意勾结、病毒指令交叉传染、系统级瘫痪 |

### 论文摘要要点

> AI agents have evolved from passive predictive tools into active entities capable of autonomous decision-making... The Hierarchical Autonomy Evolution (HAE) framework organizes agent security into three tiers:
> - **Cognitive Autonomy (L1)**: targets internal reasoning integrity
> - **Execution Autonomy (L2)**: covers tool-mediated environmental interaction
> - **Collective Autonomy (L3)**: addresses systemic risks in multi-agent ecosystems

## 对OpenClaw的意义

1. **HAE框架验证我们的分层设计**：Main Agent ↔ Sub-agent ↔ Tools 与 L1/L2/L3 安全层级对应
2. **Skill层 = L2执行层**：需要重点关注工具调用的沙箱和权限隔离
3. **多Agent协作 = L3社会层**：AGENTS.md契约机制可以预防"恶意勾结"
4. **Memory系统 = L1认知层**：需要防范假记忆植入攻击
