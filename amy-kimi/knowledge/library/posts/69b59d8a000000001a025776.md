## 教程概述

**0元傻瓜式部署Open Claw【win版】本地模型**

作者折腾一整晚踩平所有坑，提供保姆级三步部署教程。

---

## Step 1：安置"大脑" (Ollama)

1. 下载安装 Ollama
2. 终端运行：`ollama run qwen2.5:7b`
   - 选择阿里Qwen，对中文更友好

### ⚠️ 避坑关键：OpenClaw要求记忆力达标

默认token太小，需要创建"大容量版"：
```bash
ollama create qwen2.5:7b-big -f Modelfile
```

---

## Step 2：请回"管家" (OpenClaw)

1. 安装：
   ```bash
   npm install -g @openclaw/openclaw
   ```

2. 配置：运行 `openclaw onboard`

3. **精髓**：手动修改 `openclaw.json`
   - 模型ID指向 `qwen2.5:7b-big`
   - `contextWindow` 调至 **32768**

---

## Step 3：远程操控 (进阶玩法)

运行：`openclaw gateway start`

---

## 常见坑点

作者提供的排障支持：
- Node环境报错
- Context Window 报错
- 显存溢出或 Token 失效

3. **中文优化**: Qwen比Llama更适合中文场景——本地化模型选择策略
