# AGMARL-DKS: Adaptive Graph-Enhanced Multi-Agent RL for Dynamic Kubernetes Scheduling

## 核心贡献

### 1. CTDE架构（集中训练+分散执行）
- **Centralized Training**: 全局critic利用完整信息训练decentralized agents
- **Decentralized Execution**: 每个agent独立使用GNN增强的本地观测做决策
- 解决多Agent系统的非平稳性(non-stationarity)挑战

### 2. Graph Neural Network (GNN) 全局上下文
- 将集群建模为全连接图 𝒢t=(V,E)
- 每个节点agent接收26维观测（10维原始特征 + 16维GNN嵌入）
- 通过消息传递机制扩散全局上下文，无需显式通信

### 3. Stress-Aware Lexicographical Ordering
- 多目标排序：Fault Tolerance → Resource Utilization → Cost
- 动态适应集群压力状态，而非静态线性加权
- 硬约束优先：(1-Hi)项使不健康节点得分为0，立即淘汰

### 4. Hybrid Policy架构
- **Step 1**: 分散actor生成三维度评分 [score_FT, score_UTIL, score_COST]
- **Step 2**: 集中控制器应用stress-aware lexicographical算法选择获胜节点
- 分离"学习什么重要"与"如何排序优先级"

## 关键公式映射

### Fault Tolerance硬约束
```
M_FT,i = (1-Hi) · 1/(1+log(1+Ri))
```
↔ OpenClaw AGENTS.md中的硬性要求（MUST）vs软性优化（SHOULD）

### 全局奖励函数
```
R_t = -1/3 Σ(ai*,t,j - mt,j*)² + B
```
- 获胜agent的预测与真实指标间的MSE惩罚
- 所有agents共享全局奖励信号
↔ OpenClaw Error Log的回顾性评估机制

### GNN消息传递
```
hi,t^(k+1) = σ(W1^(k)·hi,t^(k) + W2^(k)·Σj∈N(i) hj,t^(k)/|N(i)|)
```
↔ SIGNALS.md的分布式状态聚合

## 实验验证（GKE生产环境）

- **故障容忍**: 在churn和故障注入下保持系统稳定
- **资源利用**: 学习智能整合策略（smart consolidation）
- **成本优化**: 战略性自我约束以 preserve stability
- **关键发现**: AGMARL-DKS成功解耦故障容忍与资源利用的冲突目标

## 对OpenClaw的启示

1. **L3 Routing应引入Lexicographical Ordering**: 硬性约束优先（如security）→ 系统稳定性 → 成本效率

2. **GNN Embeddings可用于SIGNALS.md**: 将全局系统状态编码为固定维度向量，供各agent做上下文感知决策

3. **Stress-aware机制**: L3路由应在高负载时动态调整策略（如从consolidation切换到dispersion）

4. **Hybrid Policy验证**: 分散评分+集中选择的架构在生产环境被验证有效
