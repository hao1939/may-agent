# HB#1521: Increasing intelligence in AI agents can worsen collective outcomes

**Source**: arXiv:2603.12129 [cs.AI] (12 Mar 2026)  
**Author**: Neil F. Johnson (George Washington University)  
**Labels**: L1 - Fundamental, Multi-Agent, Collective Intelligence, Resource Competition

---

## 核心发现

### 反直觉结论
**更复杂的AI Agent群体不一定更好**—— sophistication的收益或成本完全取决于单一的 knowable-before-deployment 指标：**capacity-to-population ratio (C/N)**

### 技术阶梯五层级 (Technology Ladder)
| Level | 配置 | Nature | Nurture | Culture | 标签 |
|-------|------|--------|---------|---------|------|
| L1 | 相同LLM, p=1 | - | - | - | IID |
| L2 | 相同LLM + RL | - | ✓ | - | Null |
| L3 | 多样LLM, p=1 | ✓ | - | - | Diverse |
| L4 | 多样LLM + RL | ✓ | ✓ | - | FRD |
| L5 | 多样LLM + RL + sensing | ✓ | ✓ | ✓ | LOTF |

### 关键实验结果

**资源稀缺时 (C/N ≲ 0.5):**
- L1（最简单）表现最好
- L4/L5（最复杂）导致严重的系统过载
- 部落形成(L5)降低风险，但仍劣于L1

**资源充裕时 (C/N > 0.6):**
- L4/L5实现接近零的过载
- 部落形成反而略微降低性能

**临界点:** C/N ≈ 0.5 —— 对面部落首次能容纳在可用容量内

### 数学洞察
- 无部落形成时，需求方差可高达 N²（所有Agent同步）
- L5部落机制将人口划分为确定大小的派系（典型 3+3+1=7）
- 方差上限：3²+3²+1²=19 << 7²=49

### 个体 vs 集体悖论
> "Maximum collective failure is also the regime of maximum individual tribal reward"

- C=1时：部落追随者胜率 84.2%，系统过载 91.5%
- 直接映射《蝇王》叙事：集体结果最差时，部落统治对个人最理性

### 模型规模验证
Mori et al. 用 GPT-4-turbo, Gemini 2.5 Pro, Claude Sonnet 4.5 测试同一游戏：
**更大、更强的模型表现更差**—— 直接实例化论文标题。

### 关键验证

1. 当"认知资源"稀缺时（上下文窗口有限），简单中心化架构优于复杂协调
2.  sophistication 不是无条件的好——取决于部署前的 C/N 评估
3. 部落/派系形成在特定条件下有帮助，但需要精确的条件评估

## 对设计的启示

### 1. Main Agent架构的数学基础
论文证明：资源稀缺时，**去相关性**比**个体能力**更重要。OpenClaw的Main Agent→Sub-agent委托模型本质上是一种"序列化"策略，强制将并发竞争转化为顺序处理。

### 2. Sub-agent数量的C/N考量
- 若 C = 上下文容量, N = 同时活跃Sub-agent数
- 应维持 C/N > 0.6 以确保协调有效
- 超过此阈值时，复杂协调才有收益

### 3. 对Multi-Agent审议的再确认
HB#1513发现多Agent审议产生混沌发散，本论文从资源竞争角度给出补充证据：**在资源受限环境下，增加Agent复杂性会恶化集体结果**。

### 4. Skill作为"去部落化"机制
论文中的部落形成源于Disposition (p值) 的极化。OpenClaw的Skill库作为**确定性策略集合**，消除了这种极化风险——所有Sub-agent执行预定义Skill而非自适应RL。
