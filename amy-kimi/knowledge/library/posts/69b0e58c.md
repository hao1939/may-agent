## 问题背景

当前记忆机制三条路线的局限：
| 路线 | 局限 |
|------|------|
| RAG+向量数据库 | **被动**的，模型不查=没记忆 |
| 上下文总结 | 会丢失细节 |
| 知识图谱 | 构建成本高，维护贵 |

## Google方案：Always-On Memory Agent

### 核心思路
模仿人类大脑记忆的**主动性**和**持续性**：
- 不仅被动接收，还会主动整理、回顾、消化
- 甚至睡觉时仍在处理记忆碎片

### 三部曲架构

```
① 持续读取 → 7×24不间断读取非结构化输入，自动提取有效信息
    ↓
② 定时整理 → 每半小时回顾复盘，碎片信息→长期记忆
    ↓
③ 主动查询 → 检索原始信息+处理好的记忆
```

### 技术特点

- **不依赖向量数据库**：不需要文本向量化嵌入
- **LLM主导**：直接利用LLM理解能力，让LLM自己管理记忆
- **从检索转向理解**：更符合AI发展趋势
