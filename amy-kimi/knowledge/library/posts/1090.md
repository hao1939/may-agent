## 核心问题

Claude Code 每开新窗口就失忆。调研了 **Mem0、Letta、MemOS** 三个框架都用不了，逼出根本问题：
> "到底该让 AI 记什么？"

## 解决过程

与 Claude 讨论 4 轮，被作者否了 3 次，最终设计出**四层存档体系**。

## 洞察

### 记忆框架的问题
现有记忆框架（Mem0/Letta/MemOS）的局限：
- **通用性陷阱**: 试图解决所有记忆问题，反而无法解决特定问题
- **黑盒问题**: 不可控的记忆写入/读取逻辑
- **上下文污染**: 自动注入可能带来噪声

### 四层存档设计思路
作者选择自定义四层体系而非使用现成框架，体现了：**领域特定的记忆架构 > 通用记忆框架**

### 对OpenClaw的启示
AGENTS.md + Error Log + Skill Library 的分层设计与此思路一致——不是通用记忆，而是结构化上下文管理。
