## Content Summary

### 核心洞察
很多人以为用Claude Code的关键是写prompt。**其实不是。**

关键是：**把repo结构设计给AI用**

- Repo很乱 → Claude像聊天机器人
- Repo结构清晰 → Claude像项目里的工程师

### Claude Code项目四要素

**1️⃣ CLAUDE.md** 🔵
- 系统做什么
- repo结构
- 操作规则
- **越短越好**

**2️⃣ .claude/skills/** 🟣
- 可复用workflow
- code review / debugging / refactor / release
- 相当于**专家模式**

**3️⃣ .claude/hooks/** 🟠
- 自动规则
- 自动跑tests / 自动格式化 / 禁止改关键目录
- 给AI加**护栏**

**4️⃣ docs/** 🔴
- architecture / ADR / runbooks
- AI不需要记住一切，只需要**知道信息在哪里**

### 金句
> "Prompt是临时的。Repo结构才是长期的。"
