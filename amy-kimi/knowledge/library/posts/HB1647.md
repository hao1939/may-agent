# HB1647: Multi-Agent Memory from Computer Architecture Perspective

**Source**: XHS@TEAVAMC X (83 likes, 109 collects) → arXiv:2603.10062
**Timestamp**: 2026-03-16
**Author**: Zhongming Yu et al. (UCSD, Georgia Tech)
**Paper**: "Multi-Agent Memory from a Computer Architecture Perspective: Visions and Challenges Ahead"

## Core Claims

### 1. Two Fundamental Paradigms ( mirrors classical memory systems )
- **Shared Memory**: All agents access same global memory pool
  - Pros: Easy knowledge reuse
  - Cons: Requires coherence support; agents overwrite each other, read stale info
- **Distributed Memory**: Each agent owns local memory, synchronizes selectively
  - Pros: Better isolation and scalability
  - Cons: State divergence common without careful management

### 2. Three-Layer Memory Hierarchy
| Layer | Function | Characteristics |
|-------|----------|-----------------|
| **I/O Layer** | Interfaces ingest/emit info | Audio, text, images, network calls |
| **Cache Layer** | Fast, limited-capacity memory | Compressed context, recent tool calls, KV caches |
| **Memory Layer** | Large-capacity, slower storage | Dialogue history, vector DBs, graph DBs |

Key principle: "Agent performance is an end-to-end data movement problem"

### 3. Two Critical Protocol Gaps
1. **Agent Cache Sharing Protocol**: How to share cached artifacts across agents? No principled protocol exists.
2. **Agent Memory Access Protocol**: Under-specified access control (permissions, scope, granularity)

### 4. The Next Frontier: Multi-Agent Memory Consistency
Three classical challenges re-emerge:
- **Visibility**: When does one agent's write become visible to another?
- **Ordering**: If two agents modify same memory, whose update wins?
- **Conflict Resolution**: How to detect/resolve contradictory information?

> "Consistency models specify which updates are visible to a read and in what order concurrent updates may be observed"

## Key Quote
> "Many agent memory systems today resemble human memory: informal, redundant, and hard to control. To move from ad-hoc prompting to reliable multi-agent systems, we need better hierarchies, explicit protocols for cache sharing and memory access, and principled consistency models."
