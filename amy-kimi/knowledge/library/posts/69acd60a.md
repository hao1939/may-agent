# Agent 是怎么学会用 Skill 的？

## 核心发现（基于真实调试日志和源码调用链）

### Skill 工作机制
1. **Skill 不是启动注入**: Skill 内容不是启动时就注入上下文的，而是等模型主动"索取"后，以 tool_result 形式进入对话历史
2. **Skill 列表嵌入**: 本地的 skill 列表是嵌入在 skill 工具的 description 里，让模型自行读取
3. **标准工具调用协议**: 整个机制遵循标准的大模型工具调用协议，与 Anthropic / OpenAI API 完全兼容

### 调用流程
1. **Skill 扫描**: 系统扫描本地 `~/.claude/skills/` 目录下的所有 SKILL.md 文件，读取 frontmatter（name 和 description）及正文
2. **Skill 工具定义**: 系统内置名为 "skill" 的固定工具，将所有 skill 信息拼接成 XML 字符串，动态注入到 skill 工具的 description 字段
3. **模型决策**: 模型根据上下文和 skill 工具描述，决定是否需要调用某个 skill
4. **执行与注入**: 系统执行对应 skill，将结果以 tool_result 形式注入对话历史
5. **最终回答**: 模型根据 tool_result 生成最终回答

## 与我们系统的关联
- Skill 的"懒加载"机制验证了我们渐进式上下文注入的设计
- 工具描述作为"目录"让模型自行决定，与我们的技能发现机制一致
