## Core Finding: "Simple Seq. FT" Beats Complex CRL Methods

### The Paradox
| Conventional Wisdom | This Paper's Finding |
|--------------------|---------------------|
| Sequential Fine-Tuning causes catastrophic forgetting | Seq. FT + LoRA achieves **little to no forgetting** |
| Complex CRL methods (regularization/replay/parameter isolation) needed | Simple methods **outperform** sophisticated ones |
| Stability-plasticity trade-off unavoidable | Large VLAs + LoRA + on-policy RL **reshapes** the trade-off |

### Three Components Synergy
The robustness emerges from interplay:
1. **Large pretrained VLA** — rich prior knowledge
2. **LoRA parameter-efficient adaptation** — constrained updates prevent interference
3. **On-policy RL** — stable, controlled gradient updates

> "Removing any single one causes significant increase in forgetting."

- LIBERO (long-horizon manipulation)

- + 2 additional continual learning suites

### Key Metrics
- **Plasticity**: ability to learn new tasks
- **Forgetting**: performance degradation on old tasks
- **Zero-shot generalization**: unseen task performance

## Method: Sequential Fine-Tuning Recipe

```
For each new task T_k:
  1. Initialize from current policy π_θ
  2. Fine-tune with LoRA (low-rank matrices B, A)
  3. Use on-policy RL (GRPO in this work)
  4. Update: W_new ← W_0 + B·A
  5. Proceed to next task T_{k+1}
```

No replay buffer, no regularization penalty, no parameter isolation.

### Critical Insight
> "Complexity in continual learning strategies may be unnecessary for large pretrained models."

This validates OpenClaw's **Simplicity Principle**:
- No complex multi-agent debate loops
- No sophisticated memory consolidation
- Just: clear context + scoped feedback + deterministic execution

### New Perspective on Self-Evolution
The paper suggests **constrained adaptation** (LoRA) enables safe continual learning.
- This doesn't invalidate L3's "no self-evolution" rule
- But suggests: if evolution happens, it must be **parameter-constrained** and **review-gated**
