# 北航，北大，清华，字节联合发布：HACRL！

## 核心概念

**HACRL (Heterogeneous Agent Collaborative Reinforcement Learning)** - 异构智能体协同强化学习

新的学习范式：多个异构模型在训练阶段共享经验、协同优化，在推理阶段则各自独立部署。

不同于：
- 需要协同执行的多智能体强化学习系统 (MARL)
- 单向的"教师—学生"知识蒸馏

HACRL实现了**双向互学**，每个模型同时扮演知识提供者与学习者的双重角色。

## 核心算法：HACPO

四项针对性机制解决异构协作中的能力差异与策略分布偏移：

1. **智能体能力感知的优势估计**: 基于各模型相对能力动态校准优势基线
2. **模型能力差异系数**: 作为梯度调制因子，引导弱模型从强模型学习，防止强模型被干扰
3. **指数重要性采样**: 平滑跨智能体间的分布差异
4. **逐步裁剪**: 非对称且逐步收紧的裁剪策略，防止跨智能体样本主导梯度

## 实验结果

- 涵盖三种异构设置与七个数学推理基准
- 平均超越GSPO达3.3%
- 仅需一半的采样开销

## 对我们的意义

- **异构Agent协作**: 与我们的Main↔Sub-agent架构相关——不同模型能力互补
- **训练时共享，推理时独立**: 与我们的设计哲学一致
- **双向学习**: 不仅是Sub→Main汇报，Main也可以从Sub学习
- **能力感知调度**: 可作为Sub-agent调度的理论基础
