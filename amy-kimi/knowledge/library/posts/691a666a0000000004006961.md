## Full Text
当大模型变得越来越封闭（如 GPT-5 仅输出文本，不开放 logits），传统白盒蒸馏方法逐渐失效。微软提出的 GAD（Generative Adversarial Distillation）首次实现真正意义上的黑盒 + on-policy 蒸馏，让学生模型在不知道教师概率分布的前提下，依旧能持续逼近甚至复刻其行为。
核心亮点
首次实现黑盒 on-policy 蒸馏：不需要 logits、不需要 hidden states，只依赖教师输出文本。
学生 = 生成器，判别器 = 自适应奖励模型：构建类似 GAN 的对抗学习框架。
判别器在线共进化，避免 reward hacking：解决 RLHF 常见的奖励欺骗与模式崩溃问题。
性能大幅超过传统 SeqKD：在 LMSYS、Dolly、Vicuna、SelfInst 全面领先。
小模型对齐大模型能力显著提升：Qwen2.5-14B 使用 GAD 后性能逼近 GPT-5-Chat。
强 OOD 推理泛化：RL 框架让小模型不再死记硬背教师文本，而能学到更抽象的行为模式。
训练稳定，无长文本崩坏：对比离线奖励模型，GAD 训练过程整体平稳。
应用场景 / 用户反馈 / 实验结果
适合谁？
想提升开源模型能力的开发者和研究团队
需要用 API 模型（如 GPT-5）蒸馏出可离线部署模型的企业
从事大模型压缩、蒸馏、RLHF、对齐的研究者
想用有限预算复刻闭源大模型行为的创业团队
实验结果
以 GPT-5-Chat 作为教师，GAD 让 Qwen2.5-14B-Instruct 的能力接近 GPT-5 本体。
对比 SeqKD：
所有测试集均全面领先，无一例外
出现显著 OOD 提升（SelfInst、Vicuna、Dolly）
人类评估中：
GAD 的胜率普遍超过 50%，败率稳定低于 30%
训练动态表现：
离线判别器会发生 reward hacking，回复长度暴涨至 1300 tokens
GAD 判别器因 on-policy 训练保持稳定，几乎无异常行为
	
论文：arXiv：2511.10643
