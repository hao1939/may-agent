# AI Agent赛道，其实已经出现了5条完全不同的路线

## 核心观点

整理全球主要企业AI公司的公开定位，发现"AI Agent"其实是不同公司的不同叙事。

## 各公司定位

| 公司 | 定位 | 核心叙事 |
|------|------|----------|
| 特赞 | GEA架构 | 内容即上下文 |
| Palantir | AIP + Ontology | 数据操作系统 |
| Salesforce | Agentforce | AI驱动CRM agent |
| Adobe | Agent Orchestrator | 营销与创意agent |
| OpenAI Frontier | Enterprise platform | 企业AI Agent平台 |
| Writer | Agentic work platform | 工作流平台 |
| Sierra | Customer experience AI | 客户体验AI |

## 国内云厂商定位

百度、阿里、腾讯、火山更像**企业AI基础设施层**。

## 关键趋势

企业AI的竞争，本质不是模型能力，而是**"企业入口"**。谁掌握企业上下文，谁就更可能成为下一代系统层。

## 与我们系统的关联

- Context作为核心资产的观点再次验证
- "企业入口"竞争与我们的Gateway定位相关
- 不同叙事说明Agent市场尚未收敛，存在结构性机会
