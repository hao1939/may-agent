## 核心内容

Claude Code 推出的 **Skill Creator 官方插件**，旨在系统化地优化和测试自定义技能。

### 解决的核心痛点
以往缺乏标准的评估手段，用户很难确定技能是否按预期运行。

### 新工具能力
- **A/B 测试**: 对比不同Skill版本效果
- **基准测试**: 标准化评估Skill性能
- **精调描述词**: 解决技能触发不稳的问题

### Skill分类框架

| 类型 | 定义 | 验证重点 |
|------|------|----------|
| **能力提升型** | 增强模型原生弱项 | 功能正确性 |
| **偏好编码型** | 规范特定工作流 | 行为一致性 |

### 价值主张
让 AI 开发脱离「黑盒」状态，赋予用户通过**数据驱动**来迭代和掌控技能质量的能力。

## OpenClaw对比

| 维度 | Claude Code Skill | OpenClaw Skill |
|------|-------------------|----------------|
| 测试框架 | ✅ 官方A/B+基准测试 | ⚠️ 用户自定义 |
| Skill分类 | 能力/偏好二分类 | 工具型/认知型 |
| 触发优化 | 描述词精调 | Capability Bridge |
| 评估方式 | 数据驱动 | read_by审计 |

## 关键洞察

Claude Code 在** Skill 工程化**方向推进，OpenClaw 的差异化在于**显式上下文注入** (AGENTS.md 100% vs Skills 53%)。两者路径不同但都在解决「Skill质量评估」问题。
