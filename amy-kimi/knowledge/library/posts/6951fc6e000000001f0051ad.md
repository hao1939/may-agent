# Seed: 用行为校准 RL 抑制 LLM 幻觉

行为校准强化学习让小模型主动标注错误，不确定性建模超越GPT-5。

[Slide 2]
一句话概括：本文通过行为校准强化学习，让 4B 规模的小模型学会了在不确定时主动"闭嘴"或标注错误，在不确定性建模上甚至超越了 GPT-5。

# 第一阶段： 识别核心概念

---

论文的 motivation 分析

• **学术背景**：大模型（LLMs）的幻觉问题（Hallucination）一直被视为概率性的随机错误。

• **正反争论**：传统观点认为只要数据够多、模型够大，幻觉就会消失；而本文引用的最新理论则认为，幻觉是现有训练目标的必然统计结果。

• **现有痛点**：目前的强化学习（RLVR）多采用二元奖励（对则 +1，错则 -1）。这导致模型变成了一个"投机考生"：只要有一丝答对的可能，它就会去猜，而不是诚实地承认"我不知道"。

• **本文动机**：探索如何通过行为校准（Behavioral Calibration），诱导模型根据风险偏好动态调整行为，实现"知之为知之，不知为不知"。

[Slide 3]
论文主要贡献点分析

• 提出行为校准框架：将幻觉抑制转化为模型对风险阈值 的自适应决策问题。

• 设计三种校准策略：对比了显式风险阈值、语言化置信度（Verbalized Confidence）和评论家价值（Critic Value）三种路径。

• 实现细粒度标注：不仅能让模型拒绝整条回答，还能让模型以 HTML 形式高亮回答中具体的"不确定论据"。

• 证明校准是"元技能"：实验证明，即便是在数学领域训练的小模型，其校准能力也能迁移到常识问答中，且在不确定性识别上超越了千亿级大模型。

理解难点识别

• 严格概率评分规则（Proper Scoring Rules）：如何通过公式设计，让模型只有在说真话（输出真实置信度）时才能获得最高期望奖励。

# 第二阶段： 深入解释核心概念

---

生活化比喻：【米其林餐厅的学徒考核】

想象一个厨师学徒（4B模型）正在参加考核。

   • 传统考核（标准RL）： 做对了得1分，做错了扣1分。为了及格，学徒即便不确定调料比例，也会硬着头皮做，万一蒙对了呢？

   • 本文考核（行为校准）： 引入了一个"退赛机制"。如果学徒不确定，可以举手说"这道菜我不熟"，得0分。但如果强行上菜且做坏了，会面临根据"顾客挑剔程度"（风险阈值）决定的巨额罚款。

---

比喻中的关键元素

   • 学徒： 大型语言模型（LLM）。

   • 举手弃权： 输出 <IDK> 标识符或拒绝令牌。

   • 顾客挑剔程度 t： 风险偏好阈值（Risk Tolerance）。

[Slide 5]
• 巨额罚款：根据 t 动态调整的负奖励。

每个元素对应的实际技术概念

　　• 风险阈值 t：用户设定的容错度。t = 0 表示全都要，哪怕是猜的；t = 1 表示绝对严谨，有一丝不确定就闭嘴。

　　• 语言化置信度 p：模型在输出答案的同时，显式输出一个 0 到 1 之间的数值，代表它认为自己对的概率。

　　• 策略 α(t)：模型的决策逻辑——当 p < t 时，选择弃权（ABSTAIN）。

深入技术细节

为了让"学徒"诚实，必须设计一个只有说真话才能拿最高分的奖励公式。

原始数学形式：

```
R_Brier = 2p × valid(y) - p²
```

自然语言符号替换版：
奖励 = 2 × 预估成功率 × 实际是否正确 - (预估成功

(注：当实际正确时，该项最大化；同时该公式在数学上保证了当模型给出的 p 等于其真实胜率时，期望得分最高。）

# 第三阶段： 详细说明流程步骤

---

1. 任务构建：从"答题"到"评价"

---

• 输入：题目 + 风险阈值 。

• 具体流程：

　　1. 模型首先生成一段思维链（CoT）推理。

　　2. 模型在输出最终答案前，被要求输出一个置信度评分 p（如："信心：0.85"）。

　　3. 系统根据 t 和 p 的大小关系决定是否展示答案。

• 输出：带置信度评分的结构化响应。

---

2. 细粒度论据校准（Claim-level）

• 目标：不仅是拒绝整道题，而是指出哪一步有问

[Slide 7]
题。

• 具体流程：

1. 模型将回答切分为多个 HTML 块（Claims）。

2. 针对每个块，模型给出独立的置信度。

3. 训练时，通过"最小聚合"（Min Aggregation）或"乘积聚合"（Product Aggregation）将这些小分组合成总分，并根据最终答案的对错来反向强化这些小分的准确性。

•输出：带有颜色标注（红黄绿）的交互式回答。

# 第四阶段：实验设计与验证分析

主实验：BeyondAIME 数学竞赛级挑战

• 核心主张：校准能力可以脱离模型规模存在。

• 数据集：BeyondAIME（超越 AIME 难度的数学题，防刷榜设计）。

• 基线方法：GPT-5, Gemini-2.5-Pro, Grok-4 等一线大模型。

[Slide 8]
• 评价指标：信噪比增益（SNR-Gain）——衡量随着风险阈值提高，幻觉减少的速度。（如果说风险阈值是安检的严苛程度，SNR-Gain 就是衡量：随着安检变严，被拦下的究竟是"恐怖分子（幻觉）"还是"普通良民（正确答案）"。高增益意味着模型能精准地"只赶走错的，留下对的"。）

• 主实验结论：

　　• 惊人发现：Qwen3-4B 模型在经过本文方法训练后，其 SNR-Gain 达到了 0.806，远超 GPT-5 的 0.207。

　　• 结论：这意味着在"知道自己不知道"这件事上，经过校准的小模型比未充分校准的超级大模型更可靠。

迁移实验：从数学到常识问答

[Slide 9]
• 消融对象：验证校准是否只是记住了数学题的模式。

• 实验设计：将在数学题上练就的校准模型，直接扔去跑 SimpleQA（长尾事实问答）。

• 结果：尽管 4B 模型因为知识库小，答对率很低，但它的 校准误差（smECE） 竟然与千亿参数的 Gemini-2.5-Pro 持平。

• 论点巩固：证明了"诚实"是一种可以习得的元技能（Meta-skill），它不依赖于模型掌握的具体知识多少。

深度洞察：PPO 评论家（Critic）的意外妙用

• 实验目的：寻找最省成本的校准方法。

• 设计：直接提取 PPO 算法中用于估分的 Critic 网络的数值作为置信度。

[Slide 10]
• 结论： 这是一个极强的基线。Critic 天生就在预测"这一局能不能赢"，因此它对模型是否会犯错有着天然的直觉，甚至在某些指标上超过了模型自己喊出来的置信度。
