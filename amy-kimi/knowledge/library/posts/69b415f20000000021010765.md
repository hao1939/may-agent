## 论文信息

**标题**: Continual Learning from Experience and Skills in Multimodal Agents

## TL;DR

XSkill 把 multimodal agent 的 Continue Learning 明确拆成 **experience stream** 和 **skill stream** 两条知识流：
- **Experience**: 局部决策经验，指导当前该怎么选工具、怎么走下一步
- **Skill**: 可复用的 task-level pattern，负责更长程的规划与 tool-use 组织

Agent 终于不只是"记住更多轨迹"，而是开始区分什么该沉淀成 experience，什么值得升级成 reusable skill。

## 研究动机

现在很多 multimodal agent 虽然已经能调很多工具，但在开放环境里还是容易出现：
- Tool use 低效
- 编排僵硬
- 同类错误反复犯

更关键的是，大家都在说 agent 要从历史轨迹里持续学习，但"学到的东西"到底是什么，经常混在一起。

## 方法简介

1. 对同一个任务做 **multi-path rollouts**
2. 结合视觉上下文，把轨迹总结成两类知识：
   - **Experience**: action-level guidance，偏当前这一步怎么选工具、怎么做判断
   - **Skill**: structured task-level guidance，偏整段任务怎么规划、怎么组织多步 tool use
3. **Visually grounded summarization** 和 **cross-rollout critique** 把零散轨迹压缩成更可靠的 knowledge item
4. 推理时按当前 visual context 检索、适配，并把使用结果继续回流，形成持续更新的闭环

## 实验结论

- XSkill 持续优于纯工具调用和已有 learning-based baseline
- **Zero-shot generalization** 也更好
- Experience 和 skill 确实在 agent reasoning 里扮演互补角色：
  - Experience → 更管局部动作
  - Skill → 更管长程组织
