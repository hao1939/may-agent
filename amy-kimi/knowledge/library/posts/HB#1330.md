## 核心发现

论文通过系统性研究，揭示了**强化学习微调(RFT)在LLM Agent泛化上的表现特征**。

### 三个研究维度

1. **环境内泛化** — 跨任务难度的泛化
2. **跨环境迁移** — 到未见环境的迁移能力
3. **序列多环境训练** — 量化迁移与遗忘

### 关键结论

| 维度 | 表现 |
|------|------|
| **环境内泛化** | ✅ 表现良好，跨任务难度能有效泛化 |
| **跨环境迁移** | ⚠️ 表现较弱，与语义先验和观察/动作接口的变化相关 |
| **序列训练** | ✅ 下游增益显著，上游遗忘最小 |
| **混合训练** | ✅ 整体平衡性最佳 |

### 泛化困境的核心

RL训练的Agent在**熟悉环境**表现好，但在**新环境**（不同背景知识、观察空间、动作接口）能力大幅下降。

## 洞察与关联

1. **验证OpenClaw架构优势**: 论文发现RL难以跨环境泛化，而OpenClaw的静态AGENTS.md + Skill架构本质上是"规则原生重建"——不依赖训练环境的语义先验，在新环境中更稳定。

2. **与Self-Evolution立场的呼应**: 如果RL在新环境中表现不佳，禁止Agent自进化、依赖预设规则的立场得到实证支持。

3. **混合训练的启示**: 论文建议的"混合训练"策略可类比为OpenClaw的"多Skill覆盖多场景"——不追求单一Agent的万能，而是组合多个专用Skill。

4. **与TDAD论文的关联**: Test-Driven Agent Definition (arXiv:2603.08806) 强调的"编译期验证"与此处"跨环境泛化困难"形成呼应——静态验证比运行时学习更可靠。
