## 正文
最近很多人看到 OpenClaw 的演示视频很心动，但真正上手才发现门槛不低。
	
**第一关：你需要一台24小时不关机的服务器**
	
OpenClaw 不是手机 App，是一个持续运行的 AI 助手框架。它需要部署在一台稳定联网的机器上——旧电脑、树莓派、Mac Mini 或云服务器都行。关机了，你的 AI 就下线了。
	
**第二关：模型费用，比你想象的贵得多**
	
OpenClaw 软件本身免费开源，但它只是框架，"聪明"的部分来自 AI 模型 API：
	
Claude Sonnet 4.6：输入 $3 / 输出 $15（每百万 token）
Claude Opus 4.6：输入 $15 / 输出 $75（每百万 token）
Gemini 3.1 Pro：输入 $1.25 / 输出 $5（每百万 token）
	
看起来不贵？问题在于 Agent 模式下 token 消耗极快。每次对话都带着完整上下文，工具调用一来一回，一个复杂任务轻松消耗几万 token。重度使用一个月几百美元完全正常。
	
**第三关：顶级模型怎么用，这才是最大的坑**
	
国内用户面临三条路，每条都有问题：
	
订阅制（Claude Pro / Gemini Advanced）：最便宜，但风险最高。2026年初 Claude Code 和 Google 都出现大规模封号潮，国内 IP 登录是重灾区。账号没了，钱也没了。
	
官方 API：最稳定，但国内直连不了，必须有稳定的代理，这又是一道门槛。
	
国内 API 代理：价格便宜，但鱼龙混杂。模型掺假、限流、跑路的都有，用之前要做好功课。
	
**结论**
	
OpenClaw 是给"想让 AI 真正融入工作流"的人准备的工具，不是给普通用户的玩具。真正用起来需要：一台稳定的服务器 + 可靠的模型渠道 + 接受每月几十到几百美元的 API 费用。
	
想清楚这三点再入坑，别被演示视频骗了。
