# 你可能也在把 Claude Code 当成"写代码工具"

## 核心观点

Claude Code作为**Agent系统**，通过**规划、执行、验证**流程高效推进任务。

与其询问"能写什么代码"，不如探索其在**工程流程中的应用**，提升协作效率。

## 洞察

- 不是"代码生成器"
- 是"工程流程的协作者"
