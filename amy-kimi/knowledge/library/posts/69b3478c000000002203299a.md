## Summary
Manus后端负责人在Reddit提出的PTC(Programmatic Tool Calling)方案引发热议：用统一`run(command)`替代多Tool Schema，利用LLM先天掌握的Unix知识减少上下文占用。

## Core Proposal

### 问题
- 多Tool配置 → system prompt膨胀 → prompt失焦
- AI忙于选择工具，而非解决问题

### 方案: PTC范式
```
# 非此
[tool1_schema] + [tool2_schema] + ...

# 而是
run(command="cat 脚本.md | grep '分镜A' | find ./分镜A.* | ffmpeg ...")
```

### 为什么有效
1. **先天知识**: shell命令已训练进所有LLM
2. **统一命名空间**: 各种tool call变成command
3. **管道组合**: Unix哲学，文本输入输出
4. **按需帮助**: `--help`替代完整schema，AI只看需要的部分
