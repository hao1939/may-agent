# 纽约大学：LLM内部两大怪现象被破解

大语言模型中经常出现两个神秘现象：massive activations（极端激活）和attention sinks（注意力汇聚点）。它们通常同时出现，并且往往集中在相同的 token 上，但长期以来研究者不清楚它们的因果关系。该研究系统分析了 Transformer 内部计算机制，揭示这两种现象并非模型能力必需，而是由 Pre-Norm Transformer 架构与训练策略共同诱发的结构性副产物，并进一步解释它们在模型计算中的真实功能。

## 核心亮点

### 统一解释Spike与Sink的产生机制
研究发现 massive activations 来源于早期少数 MLP 层的"step-up blocks"，它们通过类似方向性二次放大器的机制产生极端激活，并在残差连接中长期传播。

### Spike会被归一化变成"常量向量"
在 Pre-Norm Transformer 中，RMSNorm 会把极端激活压缩成稀疏且几乎恒定的向量，使不同 token 在表示空间中高度相似。

### Attention Sink来自几何子空间分离
由于 spike token 的 key 向量集中在极低维子空间，部分 attention head 的 query 更容易与该子空间对齐，于是持续向这些 token 分配注意力权重，形成 sink。

### Sink本质是隐式门控机制
当模型缺乏显式 gating 时，会利用"第一 token"作为注意力权重的"默认倾倒位置"，从而调节不同 attention head 的信息流。

### 两种现象并非强耦合
通过修改 normalization 或 attention 结构，可以分别消除 spike 或 sink，而不会显著影响语言建模性能。
