## Core Finding: White-Box RL > SFT for Execution Reasoning

### The SFT Problem

现有方法依赖SFT模仿教师解释：
- I/O预测链
- 执行轨迹的自然语言描述

**关键缺陷**：
> "Intermediate execution steps cannot be explicitly verified during SFT, so the training objective can reduce to merely matching teacher explanations."

模型可能过拟合教师文本解释，而非真正理解执行过程。

### ExecVerify Solution

| Component | Function | Verification Level |
|-----------|----------|-------------------|
| **Constraint-Based Synthesis** | 难度控制的数据生成 | 结构化约束 |
| **White-Box Questions** | 从执行轨迹生成可验证问题 | 逐步验证 |
| **Two-Stage Training** | 执行推理 → 代码生成 | 能力迁移 |
| **GRPO RL** | 基于正确性奖励优化 | 端到端 |

## Three White-Box Question Types

从解释器轨迹 τ = {(lₜ, σₜ)} 自动生成：

| Question Type | Target | Example |
|---------------|--------|---------|
| **Control-flow** | 预测下一执行语句 lₜ₊₁ | "下一行执行什么？" |
| **Data-flow (Value)** | 预测变量值 σₜ₊₁ | "x的值是多少？" |
| **Data-flow (Type)** | 预测变量类型 | "y的类型是什么？" |

**关键属性**：所有问题有唯一可验证答案，源自执行轨迹。

## Reward Function Design

### White-Box Reward Formula

```
R_white-box = 2 × ((1-α) × R^(I→O) + α × R_white)
```

| Term | Meaning | Weight |
|------|---------|--------|
| R^(I→O) | 最终I/O正确性 | 1-α |
| R_white | 中间执行状态预测准确率 | α |

**α=0.5** 平衡终端奖励与步骤级准确性。

### O→I (Reverse) Prediction

- 模型从输出预测输入
- 奖励：2(正确) / 0(错误)
- 减少对前向模式匹配的依赖

## Two-Stage Training Pipeline

```
Stage I: Execution Reasoning (White-Box RL)
  ├── SFT Warm-up (30K samples)
  │   └── 注入执行感知推理模式
  └── White-Box RL (30K samples)
      ├── Control-flow questions
      ├── Data-flow questions  
      └── I/O + O/I prediction
              ↓
Stage II: Code Generation (Unit-Test RL)
  └── R^(gen) = Passed / Total tests
```

**关键洞察**：先强化执行推理能力，再迁移到代码生成。

| Level | Constraint | Complexity |
|-------|------------|------------|
| 1 | 单一方法 | 基础 |

| 3 | 控制结构约束(循环/条件) | 高级 |

## Key Quotes

> "SFT optimizes the cross-entropy loss over the entire sequence, without explicitly verifying execution details like variable values or control flow."

> "White-box RL leverages interpreter-provided execution steps to assign verifiable and step-level rewards."

> "Models may overfit to the teacher's textual explanations without truly understanding the execution process."
