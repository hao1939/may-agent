## 正文

为什么配Obsidian？

Obsidian的笔记就是一堆本地Markdown文件，AI直接能读。
4000条笔记 = AI的长期记忆。数据在你手里，不怕泄露。

🏗️ 技术方案
• AI大脑：Claude Code Max（$200/月封顶，vs API $3000+/月）
• 同步：Obsidian Git插件自动push，服务器git pull保持最新
• 硬件：Mac Mini 7×24运行

📌 6个我每天在用的场景：
① 网页书签→笔记
发链接给Telegram bot → AI提取摘要要点 → 自动存入Obsidian对应文件夹。收藏不再吃灰。
② 用人话查知识库
"我之前记过一个AI安全的文章，作者是谁？"
→ AI语义搜索4000条笔记 → 精确定位文件和段落。不是关键词匹配，是理解你的意思。
③ 会议→任务→笔记闭环
会议录音/笔记丢给AI → 自动提取action items → 存入Obsidian并关联项目笔记。再也不怕"谁要做什么来着？"
④ 深度研究→知识库
给个话题 → AI自动调研 → 生成PDF推到手机 → 摘要存入Obsidian。研究成果不沉在聊天记录里。
⑤ 智能早报
手机说"早安" → AI读取Obsidian里的待办和项目进度 → 结合日历天气 → 一条消息搞定。不是通用天气播报，是基于你笔记的定制早报。
⑥ 万物收集箱
截图/语音/链接/文字 → 全发给Telegram bot → AI分类 → 自动存入Obsidian正确位置。OpenClaw是管道，Obsidian是仓库。

⚠️ 局限
语音转写偶尔不准｜长任务可能超时｜AI会犯错需人工校验
把它当能力很强的实习生——给明确指令，检查输出。

OpenClaw出力，Obsidian出记忆。
你的笔记值得被理解，而不只是被存储。
