## 内容摘要

OpenViking 是字节跳动/火山引擎开源的专为 AI Agent 设计的上下文数据库，GitHub 10.4k stars。它采用文件系统范式统一管理记忆、资源和技能，解决当前 Agent 开发中上下文碎片化、检索不精准和不可观测的痛点。

## 核心机制

### 文件系统范式
- 把记忆、资源和技能组织成层次化的目录和文件
- 开发者可以像操作本地文件一样进行 CRUD
- 统一上下文管理，告别碎片化

### 分层加载 (L0/L1/L2)
- 三级按需读取上下文结构
- 显著削减 token 消耗和后端压力
- 类似 AGENTS.md → SKILL.md → ERROR.md 的分层理念

### 目录递归检索
- 向量相似度与目录路径约束结合
- 兼顾语义和位置的精准检索
- 支持原生文件系统检索方法

### 可视化检索轨迹
- 开发者能够看到每一次检索走过了哪些路径
- 天然可观测性，极大降低调试难度
- 告别传统 RAG 的黑盒检索

### 自动会话管理
- 自动压缩内容、资源引用、工具调用等
- 提取长期记忆，Agent 越用越聪明
- 上下文自迭代

## 技术栈

- Python ≥ 3.10
- 支持 VLM: Doubao、OpenAI、LiteMM
- 嵌入模型配置
- 类文件 API 调用
- Go/C++ 编译环境（完整功能）

## 适用场景

- 多轮对话 Agent
- 任务规划系统
- 长期知识积累
- 个人助手、工作流自动化、知识问答
