## 核心内容

### 论文信息
- **标题**: MEMO: Memory-Augmented Model Context Optimization for Robust Multi-Turn Multi-Agent LLM Games
- **arXiv**: 2603.09022
- **发布时间**: 2026-03-09

### TL;DR
MEMO 的价值在于把 multi-agent benchmark 里常被忽略的 **ranking instability** 直接拉到台前：同一系统多跑几次名次就变，这不是噪声细节，而是评测对象本身的问题。

### 研究动机
多轮多智能体交互里，小偏差会被不断放大，prompt choice 也会导向不同有效策略。只报平均 win rate，往往遮住了 **variance** 和 **prompt sensitivity** 这两个更关键的稳定性问题。

### 方法简介
论文提出 **retention + exploration** 双机制：
1. **Retention**: 维护 persistent memory bank，把自博弈中的结构化经验写回上下文
2. **Exploration**: 用 prompt evolution、TrueSkill 与 prioritized replay 提升探索效率

从而同时提高 win rate 与稳定性。

### 实验结果
- GPT-4o-mini: win rate 从 25.1% → 49.5%
- Qwen-2.5-7B-Instruct: win rate 从 20.9% → 44.3%
- 每任务仅需 2,000 场自博弈
- Run-to-run variance 显著下降

### 关键洞察
- MEMO 在 negotiation 和 imperfect-information games 中收益最大
- RL 在 perfect-information settings 中仍更有效
- **以后看 multi-agent leaderboard，最好都多问一句：ranking stability 和 prompt sensitivity 有没有被显式报告**

## 对 OpenClaw 的意义

### 1. 评测设计启示
- 我们的多 Agent 评测不能只报平均成功率
- 需要显式报告多次运行的 variance 和稳定性
- Prompt sensitivity 是系统级问题，不是噪声

### 2. 架构验证
- 我们的 AGENTS.md 契约本身就是 persistent memory bank 的一种形式
- Skill 的动态加载/卸载对应 MEMO 的 retention 机制
- 子 Agent 分工 + Main Agent 协调对应 imperfect-information game 的分解

### 3. 潜在改进方向
- 引入 TrueSkill 进行 uncertainty-aware selection
- 对 rare/decisive states 做 prioritized replay
- 在谈判类任务（如 AGENTS.md 协商）中应用 MEMO 的优化策略
