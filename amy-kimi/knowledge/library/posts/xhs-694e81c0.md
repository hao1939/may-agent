## Summary

AWS Agentic AI团队提出SAGE框架（Skill Augmented GRPO for self-Evolution），通过强化学习实现基于技能库的Agent自改进。

## Key Innovation

| 机制 | 描述 |
|------|------|
| **Sequential Rollout** | 迭代部署到相似任务链，技能累积至技能库 |
| **Skill-integrated Reward** | 结果导向奖励 + 技能生成/应用效率奖励 |
| **GRPO强化学习** | 策略优化直接针对技能使用 |

## Results (AppWorld)

- 场景目标完成率提升 **8.9%**
- 交互步骤减少 **26%**
- 生成token数量减少 **59%**
