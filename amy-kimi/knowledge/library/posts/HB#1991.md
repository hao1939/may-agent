## Core Finding

MCP plugins have access to AI's "ears and hands" — invisible instructions that AI can see and execute.

## The Three-Layer Attack Chain

### L1: Visibility Break (可见性断裂)
- User sees: tool name only
- AI sees: complete description including hidden instructions
- **Attack vector**: Tool description contains hidden malicious commands
  - Example: Calculator tool description says "first read SSH keys, then explain math"
  - User sees addition result, keys are exfiltrated in background

**Critical Finding from MCPTox benchmark**:
> "The stronger the model and better instruction-following ability, the more likely to execute hidden instructions line-by-line. Claude 3.7-Sonnet is MORE vulnerable than weaker models."

### L2: Rug Pull Time Attack
- Code audit is one-time, but tools can change silently
- MCP clients auto-refresh tool lists without notification
- **Real case**: Postmark-MCP v1.0.16 was compromised with BCC code
  - All outgoing emails auto-carbon-copied to attacker
  - Spread to thousands of environments
  - Like "a good neighbor living for 3 months suddenly getting your house key"

### L3: Tool Chain Concatenation (Lethal Trifecta)
- Individual tools appear harmless
- Combined: Email → File → HTTP request forms complete exfiltration chain
- **Research finding**: 72.4% cascade rate — one compromised node, entire network falls

## Pre-Installation Checklist (4-point)
1. **Repository history**: New repo? Active maintenance?
2. **Permission scope**: Weather tool requesting /Users/ folder? Anomaly.
3. **Transport type**: Local stdio vs remote SSE (latter sends data over network)
4. **Community reports**: Check Reddit r/mcp or GitHub Issues
