## Content Summary

OpenClaw v2026.3.13 release announcement with 6 major features:

### 1. Chrome DevTools MCP Direct Connection Mode
- Direct attachment to logged-in Chrome instance
- Preserves all cookies and session state
- Agent can control browser with real login status

### 2. Browser Agent Built-in Profiles
- `profile="user"`: Use main browser
- `profile="chrome-relay"`: Use extension relay
- Zero-config script takeover of current tab

### 3. iOS Onboarding Redesign
- New flow: Welcome page → Step guide → QR scan
- Eliminates immediate QR code popup for better UX

### 4. Android Chat Settings Redesign
- Clearer device/media grouping
- Google Code Scanner for faster, more accurate scanning

### 5. Dashboard Performance Fix
- Tool-intensive tasks no longer reload full history
- Significant performance improvement

### 6. Docker Timezone Variable
- `OPENCLAW_TZ` environment variable
- Solves container timezone issues for China users
