## Core Contribution

**SELA (Structured Event Logic Agent)**: A neuro-symbolic VLM agent framework for zero-shot Knowledge-Guided Time Series Event Detection (K-TSED). The system uses a novel **Event Logic Tree (ELT)** representation to bridge natural language event descriptions and physical time series data.

---

## Two-Agent Architecture

| Agent Type | Function | OpenClaw Mapping |
|------------|----------|------------------|
| **Logic Analyst** | Constructs ELT schema from unstructured event descriptions | **Main Agent** (L3 strategic reasoning) |
| **Signal Inspector** | Incrementally locates and refines time series intervals guided by ELT | **Sub-agent + Skill** execution |

**Key Design**: ELT serves as the structured intermediate representation that:
- Guides agents' reasoning and behavior
- Provides well-organized clues for human verification
- Mitigates VLM hallucination through structural constraints

## Event Logic Tree (ELT) Framework

### Node Types

| Type | Notation | Description |
|------|----------|-------------|
| **Primitive** (Leaf) | np = ⟨τ, c⟩ | Atomic signal patterns over single channels |
| **Composite** (Internal) | nϕ = ⟨𝒩, op⟩ | Temporal-logic relations forming hierarchical events |

### Four Temporal-Logic Operators

| Operator | Natural Language | Formal Semantics |
|----------|------------------|------------------|
| **SEQ** | "A followed by B" | Sequential composition |
| **SYNC** | "A synchronized with B" | Simultaneous occurrence |
| **GUARD** | "A within B" | Interval containment |
| **OR** | "Either A or B" | Alternative patterns |

### Three Constitutive Axioms

1. **Axiom 1 (Constructive Composition)**: |𝒩| ≥ 2 — Composite must add structural meaning
2. **Axiom 2 (Temporal Compactness)**: Undefined gaps bounded by hyperparameter
3. **Axiom 3 (Physical Exclusivity)**: One active primitive per channel at any time

## Key Innovation: Separating Schema from Instantiation

```
Schema Level (Language → Structure):
  "Pressure rises then stabilizes"
  → ELT: SEQ(Rise_Pressure, Stable_Pressure)

Instantiation Level (Structure → Data):
  → Search time series for Rise pattern
  → Verify temporal adjacency
  → Confirm Stability follows
  → Calculate coherence scores μ ∈ [0,1]
```

**Critical Design**: Schema parsed from text only; instantiation on actual data — satisfying **Topological Elasticity** (D3)

## Design Implications for OpenClaw

### 1. Structured Intermediate Representation

ELT demonstrates the power of **intermediate representations** between natural language and execution:

```
Natural Language → ELT → Time Series
AGENTS.md Task → Structured Plan → Skill Execution
```

**Insight**: Complex tasks benefit from explicit structural decomposition before execution.

### 2. Constraint-Guided Generation

SELA's axioms prevent invalid outputs at generation time:
- Axiom 1 prevents trivial structures
- Axiom 2 prevents temporal gaps
- Axiom 3 prevents channel conflicts

**OpenClaw Parallel**: P109 constraints serve similar function for Skill behavior.

### 3. Neuro-Symbolic Hybrid

| Aspect | Neural (VLM) | Symbolic (ELT) |
|--------|--------------|----------------|
| Strength | Pattern recognition, semantic understanding | Structured reasoning, verifiability |
| Role | Primitive detection, coherence scoring | Composition, constraint enforcement |

**Implication**: OpenClaw Skills could benefit from explicit "symbolic scaffolding" for complex multi-step tasks.
