## 内容（5次安装血泪教训）

### 最重要一条
> 一直改配置改不明白报错的话，**直接删除已有配置重新安装！！！**

### 前置建议
1. 用**单独硬件**（推荐Mac Mini）— 别用主力机（隐私风险），别用云服务器（内存不够麻烦）
2. 先配好Claude Code/Codex，让AI工具帮你执行安装，比自己敲命令省心

### 模型API
- 直接用Codex会员的auth，不用单独配API（省钱）
- 国内coding plan也行，但尽量用好模型

### 浏览器插件安装正确流程
```
1. openclaw browser extension install（官方命令，别去网页搜）
2. Chrome → chrome://extensions → 开发者模式 → 加载已解压扩展
3. Cmd+Shift+G 输入路径 ~/.openclaw/browser/chrome-extension
4. 删除旧插件
5. 右键新插件 → 选项 → 填入 Gateway Token
6. openclaw config get gateway.auth.token 获取token
7. 填入保存 → 感叹号变 ON
```

### ⚠️ 渠道避坑
- **不要用飞书！** bug多、multiagent会串台、不能拉进群、发信息有长度限制
- 推荐：Telegram / Discord

### 搜索工具
- 不要用官方Brave（注册需要国外信用卡，花$5）
- 直接用 Tavily MCP工具增强搜索
