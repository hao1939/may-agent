## Combinatorial Fusion Analysis (CFA)

### Mathematical Foundation

For scoring system A on dataset D = {d₁, ..., dₙ}:

- **Score function**: sₐ: D → ℝ
- **Rank function**: rₐ: D → ℕ (derived by sorting scores)
- **Rank-Score Function (RSF)**: fₐ(i) = sₐ(rₐ⁻¹(i))

### Cognitive Diversity (CD)

```
CD(A,B) = d(fₐ, fᵦ) = √(Σ(fₐ(i) - fᵦ(i))² / (n-1))
```

**Diversity Strength** of system A:
```
DS(A) = average of CD(A, A') for all other systems A'
```

### Score-Rank Duality

CFA独特之处在于同时使用：
- **Score-based aggregation**: 原始分数的数值融合
- **Rank-based aggregation**: 排序位置的组合优化（Kemeny Rank Space）

> "CFA leverages both the numerical information in scores and the ordinal information in ranks"

## Key Findings

### 1. Cognitive Diversity Mitigates Conflicts

| Design Choice | Benefit |
|--------------|---------|
| Multiple normative perspectives | Captures ethical pluralism |
| Explicit diversity measurement | Quantifies agent disagreement |
| Rank-score dual fusion | Robust against individual bias |

### 2. Empirical Superiority

VAS-CFA outperforms:
- Single-agent baselines
- Prior aggregation approaches
- Standard RLHF variants

### 3. Contrast with RLxF Limitations

| RLHF/RLAIF Limitation | VAS-CFA Solution |
|----------------------|------------------|
| Single evaluator | Multiple moral agents |
| Narrow reward signals | Diverse normative perspectives |
| Misses ethical complexity | Explicit ethical pluralism handling |
| Costly human labeling | Multi-agent fusion reduces human raters |
