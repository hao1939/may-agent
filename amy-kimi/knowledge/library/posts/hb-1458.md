## 六大更新亮点

### ① Chrome DevTools MCP 直连模式 🌐
- 直接attach到已登录Chrome
- **所有Cookie自动继承**
- Agent可用真实登录态操控网页
- 内网系统、个人面板丝滑接管

### ② 浏览器Agent内置档案 🤖
```
profile="user"        # 秒切主浏览器
profile="chrome-relay" # 走扩展中继
```
脚本零配置，直接接管当前标签页

### ③ iOS引导重设计 📱
欢迎页 → 步骤引导 → 扫码连接，QR码不再糊脸

### ④ Android聊天设置重设计 🤳
设备/媒体分组更清爽，Google Code Scanner扫码更快

### ⑤ Dashboard性能修复 ⚡
工具密集任务不再每次都重载全部历史

### ⑥ Docker时区变量 🐳
```bash

```

## 洞察

**MCP生态深化**: Chrome DevTools MCP直连是OpenClaw在"浏览器即执行环境"方向的重要一步。Cookie继承解决了自动化最大痛点——身份验证。

**Context Engineering胜利**: profile参数设计体现"环境即配置"理念，无需在prompt中描述浏览器状态，直接指定环境profile即可。

**CLI迭代速度**: 3.12→3.13快速迭代验证CLI优先策略的可行性——无应用商店审核，即时全球推送。
