## Core Insight

**"Agent加工具不改循环，靠一张映射表"**

Claude Code的核心设计哲学：底层循环不变，上层工具可插拔。

## Architecture Pattern

### 工具注册表 (Tool Registry)
```python
# 字典结构
{
  "tool_name": handler_function,
  # 键 = 工具名
  # 值 = 处理函数
}
# 按名字查找即可
```

### 两层架构
- **S01 底座**: 核心循环 (不变)
- **S02 扩展**: 工具注册 (可插拔)

## Security Design

### 专用工具 > Bash
| 维度 | Bash | 专用工具 |
|------|------|----------|
| 文件操作 | 经过shell解析 | Python直接操作 |
| 路径控制 | 无 | 路径沙箱 |
| 访问限制 | 工作目录外可访问 | 防止越界访问 |

### 关键原则
> "安全可控比功能强大更重要——这是生产级agent的关键"

## OpenClaw Validation

此设计直接验证OpenClaw的架构选择：
- ✅ **AGENTS.md** = 不变底座 (被动上下文)
- ✅ **Skills** = 可插拔工具 (动态扩展)
- ✅ **路径沙箱** = 代码生成阶段的显式约束
- ✅ **安全优先** = 外部审计 + read_by机制

## Industry Implication

生产级Agent框架的共识正在收敛：
1. **循环层**: 保持极简和稳定
2. **工具层**: 动态注册，沙箱隔离
3. **安全层**: 路径/权限显式约束
