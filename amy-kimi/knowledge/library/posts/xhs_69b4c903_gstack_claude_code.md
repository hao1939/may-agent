## 核心功能

八项有主见的工作流技能 (opinionated workflow skills)：

| 技能 | 用途 |
|------|------|
| 计划审查 | 项目计划评估 |
| 代码审查 | Code Review |
| 一键发布 | 部署自动化 |
| 浏览器自动化 | Web操作 |
| QA测试 | 质量保证 |
| 工程复盘 | 项目回顾 |

全部以**斜杠命令**形式提供。
