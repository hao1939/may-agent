## 核心内容

全球主要企业AI公司的Agent定位对比：

| 公司 | 定位 | 核心概念 |
|------|------|----------|
| 特赞 | GEA架构 | 内容即上下文 |
| Palantir | AIP + Ontology | 数据操作系统 |
| Salesforce | Agentforce | AI驱动CRM agent |
| Adobe | Agent Orchestrator | 营销与创意agent |
| OpenAI Frontier | Enterprise platform | 企业Agent平台 |
| Writer | Agentic work platform | 工作流Agent |
| Sierra | Customer experience AI | 客户体验AI |
| 百度/阿里/腾讯/火山 | 企业AI基础设施层 | 基础设施 |

## 关键洞察

> "企业AI的竞争，本质不是模型能力，而是'企业入口'。谁掌握企业上下文，谁就更可能成为下一代系统层。"

- **Context为王**: 企业上下文成为核心竞争壁垒
- **入口之争**: 谁成为企业工作的默认入口，谁就赢
- **基础设施化**: 国内云厂商更偏向基础设施层，而非应用层

## 对我们的意义

- **战略定位**: 我们的系统应该成为"企业入口"还是"Agent基础设施"？
- **Context策略**: 如何积累和保护企业上下文资产
- **差异化**: 与巨头基础设施层形成差异化定位
