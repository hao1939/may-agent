## 核心内容

OpenClaw 创始人 Peter Steinberger 分享的 AI 开发工作流：

### 极简配置
- **终端工具**: Ghostty
- **主力**: Claude Code
- **辅助**: VS Code（仅用于查看代码）
- **已删除**: 最后一个 MCP 插件也被删了

### 并行策略
- 使用 **40寸超宽屏** 同时开 **4个 Claude Code**
- 根据 **「爆炸半径」** 决定开几个 Agent
- 改动影响范围小的工作 → 多开几个并行跑

### 核心理念
> "Context 很珍贵，别浪费。"

### 评价
这套极简工作流比大厂那些花里胡哨的工具链清爽太多。

## 洞察

**OpenClaw验证**: 
- 我们的极简 Skill 系统与此理念一致
- 不需要复杂MCP，HTTP/CLI足够
- Context效率是核心优化目标

**技术趋势**: 从"堆工具"转向"极简高效"，与HB#2062的"不需要MCP"形成呼应。
