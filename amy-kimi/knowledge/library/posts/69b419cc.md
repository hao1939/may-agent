## Summary

介绍了一种名为SCS-Code（安全概念引导）的方法，通过操纵CodeLLM的内部表示来提升代码生成安全性。

## Key Findings

### 论文信息
- **标题**: Security-by-Design for LLM-Based Code Generation: Leveraging Internal Representations for Concept-Driven Steering Mechanisms
- **ArXiv ID**: 2603.11212v1
- **关键词**: CodeLLMs, Security Vulnerabilities, Secure Concept Steering

### 核心洞察
1. **模型已意识到漏洞**: CodeLLM在生成不安全代码时往往已经意识到漏洞存在
2. **安全子概念可区分**: CodeLLM可以区分安全子概念，比黑盒方法更细致
3. **轻量级模块化**: SCS-Code可集成到现有代码模型中

### 技术原理
- 在token生成过程中，引导LLM内部表示向安全且功能性的代码输出
- 利用模型内部表示而非外部启发式方法
