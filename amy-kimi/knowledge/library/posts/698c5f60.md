## 核心贡献
提出一种全新的记忆总结范式：**Span-level Skill-conditioned Memory Generation**

## 现有问题
- 很多Agent Memory System还停留在"手工搭记忆提取模块流水线"的范式
- 过于rigid且强依赖人类先验，难以不断泛化适应到新数据
- turn-level的顺序处理也不够scalable，长轨迹下成本和维护负担都很重

## MemSkill核心设计

### 1. Skill-conditioned Generation
- 把"怎么构建记忆"升级为一个**可学习、可进化的记忆技能库（Skill Bank）**
- 不再逐turn跑一堆固定模块，而是以span/chunk为单位做总结
- 每次只需根据当前span context选取一小组相关的memory skills进行组合

### 2. Controller → Executor流程
- **Controller**: 为skill bank中的候选skills打分并选择最佳的Top-K
  - 避免把整个技能库塞进LLM造成干扰
  - 用强化学习训练，用下游任务反馈作为奖励信号
- **Executor**: 在选定的skills条件约束下进行span-level的记忆生成与更新

### 3. Designer — Skill自进化
- 从failure cases里总结问题，改技能/增技能，让skill bank随时间进化
- 维护failure-driven的hard-case buffer
- Designer定期回看并提炼重复出现的失败模式
- 转化为skill edits（触发条件、抽取规则、输出schema）或new skills

## 实验验证
- **对话记忆**: LoCoMo、LongMemEval
- **具身决策**: ALFWorld
- **泛化能力**: LoCoMo→HotpotQA跨域验证

## 技术洞察
- Skill Bank将记忆构建从"硬编码"升级为"可学习"
- Controller-Executor分离是 scalable 架构关键
- Failure-driven evolution闭环实现自我进化
- RL训练Controller使skill selection从启发式走向最优
