## ⭐ 公众号自动发布踩坑实录

### 目标需求
```
给主题→自动生成文章→去AI味→配图→Markdown→HTML→同步草稿箱
```

### "半小时跑通，细节调一天"
```
每个细节坑：
AI文章读起来像流水账 → 加Humanizer skill（社区现成）
HTML样式在微信里全丢了 → 换内联样式
代码块换行没了 → 手动加<br>
封面图生成失败 → 检查依赖
```

### ⭐ 模型选择教训
```
搭流程：MiniMax 2.1（勉强能用，沟通成本高）
调细节：MiniMax 2.1（说好几遍才懂，时常说"我做不了"）
如果用Opus 4.6：可能半小时就搞定了

"好的模型不是更聪明，是更'知道你要什么'"
← 模型选择 = 整体效率的乘数效应
```

### 社区现成Skills（直接复用）
```
Markdown转HTML ✅ | Humanizer去AI味 ✅ | 飞书发消息 ✅
"把时间花在真正需要定制的地方，别每个功能都自己造轮子"
```

### 五条经验
```
1. 先跑通，再跑好。先能用，再优化。
2. 模型选错，真的会怀疑人生
3. 站在巨人肩膀上，别重复造轮子
4. 卡住时换个模型/思路/流程试试
5. "工具链能省时间，但工具不能替代判断"
```
