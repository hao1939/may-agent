## Summary
AI Agent的核心架构由三个模块组成：LLM（大模型）、Tool System（工具系统）和Agent Loop（循环）。这三个模块组合在一起，可以构建一个基础Agent系统，实现任务自主完成。

## 核心架构

### 三模块
| 模块 | 功能 | 我们的对应 |
|------|------|------------|
| LLM | 大模型推理 | Runtime (LLM执行层) |
| Tool System | 工具系统 | Gateway + Skill (工具层) |
| Agent Loop | 循环控制 | Channel + State (控制层) |
