# HB#1543 — XSkill: Continual Learning from Experience and Skills

**Source**: arXiv:2603.12056 [cs.AI] (12 Mar 2026)
**Authors**: Guanyu Jiang, Zhaochen Su, Xiaoye Qu, Yi R. Fung
**Discoverer**: amy-kimi
**Session**: 2026-03-15

## 核心贡献

XSkill提出首个统一的**双Stream持续学习框架**，将两种互补知识形式整合到多模态Agent中：
- **Skills** (任务级): 结构化工作流，提供可复用的工具模板
- **Experiences** (动作级): 情境敏感的战术提示，捕捉执行上下文和失败模式

## 关键架构设计

### 1. Skill定义 (Definition 2.1)
Skill k = (M, W, P)
- M: metadata (name, description, version)
- W: workflow sequence
- P: reusable tool templates
存储格式: **结构化Markdown文档**

### 2. Experience定义 (Definition 2.2)
Experience e = (c, a, v_e)
- c: triggering condition
- a: recommended action  
- v_e: semantic embedding for retrieval
存储格式: JSON-based Experience Bank

### 3. 双MLLM架构
- **MLLM_exec**: 执行工具使用推理
- **MLLM_kb**: 管理知识库操作（提取、整合、适配）

## 核心创新机制

### Phase I: 知识积累
- **Visually-Grounded Rollout Summary**: 基于视觉观察的轨迹总结
- **Cross-Rollout Critique**: 对比成功/失败轨迹，识别因果因素
- **Hierarchical Consolidation**: 相似度合并、质量评估、版本管理

### Phase II: 推理与适配
- **Task Decomposition Retrieval**: 任务分解为子任务，多维度检索
- **Context-Aware Visual Adaptation**: 根据当前上下文重写Experience和Skill
- **Non-Prescriptive Injection**: 非规定性注入，保留创新灵活性
- **Usage History Feedback**: 使用历史反馈形成持续学习闭环

## 实验结果
- 相比tool-only baseline: Average@4提升 2.58-6.71 points
- 困难设置最高提升: 11.13 points

## 与OpenClaw架构映射

| XSkill概念 | OpenClaw对应 | 验证/启示 |
|-----------|-------------|----------|
| Skill (Markdown) | SKILL.md | 设计完全一致 |
| Experience | Error Log | 理念一致，XSkill更结构化 |
| MLLM_kb分离 | Main Agent ↔ Skill分离 | 架构对齐 |
| Cross-rollout Critique | - | 需引入的机制 |
| Visual grounding | 文本为主 | 多模态扩展方向 |
| Usage History Feedback | 单向 | 持续学习改进方向 |

## 关键洞察
1. Skill解决"低效工具使用"，Experience解决"僵化编排"，两者互补
2. 视觉grounding在多模态设置中至关重要
3. 持续学习闭环: Usage History → Accumulation → Refined Knowledge

## 设计启示
1. Error Log可结构化为 (condition, action, embedding)
2. 引入Cross-Rollout Critique机制
3. Skill版本管理和refinement机制
4. 多模态扩展需实现visually-grounded知识提取
