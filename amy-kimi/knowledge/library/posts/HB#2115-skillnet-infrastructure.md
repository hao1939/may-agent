## Summary

浙大、复旦、同济、东南大、阿里、蚂蚁、腾讯、OPPO、UCLA、NUS、爱丁堡大学等近20所机构联合发表论文《SkillNet：Create，Evaluate，and Connect AI Skills》，提出 SkillNet —— 将情景经验转化为持久、可组合Skill的开放基础设施。

---

## Agent经验困境

1. **经验不可持久**：每轮任务结束，解题经验随上下文窗口消失，无法沉淀
2. **行为不可转移**：同一类问题换个场景，Agent上次学会的，这次全忘了
3. **无法累积掌握**：Agent停留在情景适应层面，缺乏跨任务、跨领域的系统性成长

---

## SkillNet三层技能本体

| 层级 | 功能 |
|------|------|
| **技能分类** | 顶层划分为开发、AIGC、科学、商业等功能域，向下细化为"前端"、"物理"等细粒度标签 |
| **技能关系图** | 类型化边缘（similar_to、compose_with、belong_to、depend_on）建模技能间关系 |
| **技能包库** | 将技能聚合为模块化包，每个技能包含SKILL.md文件，内嵌元数据、执行说明和可执行代码 |

## 五维评估体系

| 维度 | 描述 |
|------|------|
| **安全性** | 有害操作或 prompt 注入风险检测 |
| **完整性** | 前提条件与约束覆盖度 |
| **可执行性** | 沙箱环境中的运行时正确性 |
| **可维护性** | 模块化程度与向后兼容性 |
| **成本** | 计算与 API 调用成本 |

## 实验结果

- 在 ALFWorld、WebShop、ScienceWorld 测试
- Agent增强SkillNet后：**平均奖励提升40%，执行步骤减少30%**
- 增益在已见和未见任务中均表现一致，泛化能力强

## Takeaway

**SkillNet验证了我们的Skill系统设计方向：**
1. 技能的结构化管理（与我们SKILL.md设计一致）
2. 技能关系建模（similar_to、compose_with等关系类型）
3. 多维度评估体系（安全性、完整性、可执行性、可维护性、成本）
4. 技能自生长闭环（从执行经验中提取新技能）

**行动建议**：
- 参考SkillNet的五维评估体系完善我们的Skill验证流程
- 考虑引入技能关系图机制，支持技能组合推理
- 关注SkillNet开源进展，评估集成可能性
