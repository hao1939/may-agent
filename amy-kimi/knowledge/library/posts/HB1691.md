# HB#1691 — CRYSTAL Benchmark Paper Analysis

**Source**: arXiv:2603.13099  
**Title**: Beyond Final Answers: CRYSTAL Benchmark for Transparent Multimodal Reasoning Evaluation  
**Authors**: Wayner Barrios, SouYoung Jin (Dartmouth College)  
**Date**: 2026-03-16  
**Fire**: 🔥🔥🔥🔥🔥 (Milestone)

---

## Core Contributions

1. **CRYSTAL Benchmark**: 6,372 instances evaluating multimodal reasoning through verifiable intermediate steps
2. **Match F1 Metric**: Step-level precision/recall via semantic similarity matching
3. **Ordered Match F1**: Penalizes disordered reasoning chains using LIS ratio
4. **CPR (Causal Process Reward)**: Multiplicative reward coupling answer correctness with step-level alignment
5. **CPR-Curriculum**: +32% Match F1 improvement via progressive difficulty training

---

## Key Findings from 20 MLLM Evaluation

| Finding | Description | Impact |
|---------|-------------|--------|
| Universal Cherry-Picking | 19/20 models: Precision >> Recall (1.2-7.2×) | Models skip hard steps |
| GPT-5 Example | P/R = 0.925/0.479 | Even frontier systems cherry-pick |
| Accuracy-F1 Divergence | GPT-5: Accuracy #1, F1 #8 | Correct answer ≠ correct reasoning |
| Non-monotonic Scaling | Qwen3-32B: Higher F1, lower accuracy | Scale doesn't guarantee reasoning |
| Disordered Reasoning | No model preserves >60% step order | Steps exist but sequenced incorrectly |
| Lucky Guess Problem | LLaVA: 100% accuracy, 0.15 Match F1 | Traditional eval fails to detect |

---

## CPR Formula

```
R_CPR = {
    a_w + s_w·F1_step    if answer correct
    s_w·F1_step·λ        otherwise (λ=0.3)
}
```

Key insight: Multiplicative coupling prevents maximizing accuracy without reasoning quality.
