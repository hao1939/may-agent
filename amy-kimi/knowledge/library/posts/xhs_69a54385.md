## 核心内容

新一代智能体系统如何从以模型为中心走向面向环境和经验驱动的协同进化。

## 核心亮点

### 1. 全新核心视角: 环境-智能体协同进化
跳出传统"以模型为中心"的思路，聚焦智能体与环境双向迭代、动态共生，重新定义自进化的底层逻辑。

### 2. 清晰技术路径: 完整梳理范式演进
```
模型中心进化 → 数据/经验驱动进化 → 环境驱动协同进化
```

### 3. 内容深度突破
覆盖前沿关键议题：
- 协同进化机制
- 多智能体生态自适应
- 开放世界鲁棒性
- 安全对齐

### 4. 体系化参考
构建统一研究框架与范式分类，梳理主流基准、挑战与展望。

## 范式转变

| 阶段 | 特征 |
|------|------|
| Model-Centric | 静态大模型，知识截断 |
| Data/Experience-Driven | 经验积累，动态适应 |
| Environment-Driven Co-Evolution | 环境交互，终身进化 |

## 关键洞察

1. **社区趋势**: 从model-centric转向environment-driven
2. **核心矛盾**: 静态模型知识截断 vs 持续学习需求
3. **研究前沿**: 协同进化、多智能体生态、安全对齐
