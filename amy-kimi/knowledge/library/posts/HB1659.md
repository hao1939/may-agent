## Summary

作者团队系统性研究了LLM Agent + RL训练中的training collapse问题（训练前期上涨→突然断崖→梯度爆炸→模型练废），提出统一分析框架ARLArena。

## Training Collapse现象

```
训练前期一路上涨 → 突然成功率断崖下跌 → 梯度爆炸 → 格式全乱 → 模型"练废"
```

## 四维度分析框架

| 维度 | 说明 |
|------|------|
| 损失聚合 | Loss aggregation (token/序列层面) |
| IS裁剪 | 重要性采样裁剪 (Importance Sampling clipping) |
| 轨迹筛选 | Dynamic filtering (处理reward全相同的组) |
| 优势函数 | Advantage设计 |

## 最关键发现：IS Clipping决定稳定性

| 裁剪策略 | 表现 | 结果 |
|----------|------|------|
| 宽松裁剪 (SAPO/CISPO) | 早期涨得快 | 中后期崩塌 |
| Sequence-level clipping | KL/梯度/成功率更平滑 | 显著更稳定 |

## Collapse真实模式诊断

**Collapse时常见特征**：
- 负优势 (Adv < 0) 且 IS ratio很低的序列累积
- 宽松裁剪下这些序列仍贡献梯度
- 逐步把策略推偏
- 最终造成KL/梯度爆炸和格式崩坏

**解决方案**：Sequence Masking
- 屏蔽Adv < 0且IS低于阈值的序列
- 可稳定宽松裁剪变体（SAPO/CISPO）

## SAMPO方法：三要素组合

```
SAMPO = Sequence-level clipping + Turn-level advantage + Dynamic filtering
```

**效果**：ALFWorld / WebShop / Sokoban多任务训练平稳、无collapse，性能显著优于baseline

## 工程洞察

1. **光改clipping不够** — 需配合细粒度优势信号
2. **Turn-level advantage** — 改善credit assignment
3. **轨迹筛选** — 与细粒度优势配合进一步提升稳定性

## OpenClaw关联分析

| ARLArena概念 | OpenClaw映射 |
|--------------|--------------|
| Training Collapse | L3 Self-Evolution风险验证 |
| Sequence-level裁剪 | 决策点审计粒度 |
| Turn-level advantage | Error Log细粒度反馈 |
| Dynamic filtering | Signal-to-Noise过滤 |

**关键验证**: 该研究从RL训练稳定性角度，验证了OpenClaw"禁止运行时Self-Evolution"的合理性 —— 无约束的自主优化极易导致collapse。

**启示**: 如果未来OpenClaw引入RL训练能力，必须采用类似SAMPO的稳定化机制：
- Sequence-level审计（非token级）
- Turn/决策点级优势评估
- 负反馈动态过滤
