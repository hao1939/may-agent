## Core Finding: VPIR-Based Agentic Synthesis Pipeline

Paper proposes a **Verifiable Programmatic Intermediate Representation (VPIR)** — executable Python-like predicates whose truth values are mechanically verified against structured visual facts before natural language rendering.

### Three-Component Architecture

| Component | Function | OpenClaw Mapping |
|-----------|----------|------------------|
| **Planner** | Orchestrates layer-by-layer condition generation | Main Agent + Error Log orchestration |
| **Verifier** | Performs quality control on each layer | AGENTS.md as specification layer |
| **Composer** | Assembles verified layers into instructions | Skill composition + execution |

### Key Technical Design

**VPIR Predicate Execution:**
```python
# Sandbox environment with whitelisted operators
⟦p⟧(Ft) ≜ Exec(p; Env(Ft)) ∈ {0,1}

# True-logic and counterfactual false-logic pairs
⟦pt⟧(Ft) = 1, ⟦p~t⟧(Ft) = 0  # mechanically verified
```

**Structured Fact Extraction:**
- Object-centric grounding: Subject must be uniquely localizable
- JSON-typed representation: `{color: "red", count: 50, gui_state: "list-layout"}`
- Whitelisted primitives: `len`, `set`, `all`, `any`, `min/max/sum`

### Benchmark Results: Deep Compositional Reasoning is Hard

| Metric | Best Model | Key Finding |
|--------|-----------|-------------|
| **Path F1** | 53.33% | Even strongest model struggles |
| Hard Negatives | Sharp drop | False-path instances much harder |
| Depth scaling | Degrades | Accuracy ↓ as chain depth ↑ |
| Predicate complexity | Degrades | Complex predicates hurt performance |

### Critical Insight: "Decouple Logical Construction from Language Rendering"

> "Instead of generating the final instruction directly, we first represent each layer as an executable, Python-like predicate and mechanically verify whether it is true or false against structured visual facts, and only then translate the verified logic into natural language."

This validates OpenClaw's core design: **structured specification (AGENTS.md/SKILL.md) before LLM execution**.
