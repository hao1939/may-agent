## 核心内容: Claude Code Playground插件

### 什么是Playground
- 官方插件，知道的人不多但用过都说好
- **核心机制**: 让Claude Code生成独立HTML文件 → 浏览器交互操作 → 输出prompt回到Claude Code

### 为什么需要
> "有些问题用纯文字交互太痛苦了。你让Claude描述代码库架构，它写三段话，你看完还是脑子里画不出来。但如果画一张交互式架构图，点击每个模块就能看细节、写评论、提修改意见，这感觉完全不一样。"

### 安装
```
/plugin marketplace update claude-plugins-official
/plugin install playground@claude-plugins-official
```

### 触发方式
在prompt里加: `"Use the playground skill to ..."`

**关键**: 描述你想要的**交互方式**，不是描述你想要的结果

### 五个实际案例

| 案例 | 交互方式 | 用途 |
|------|----------|------|
| 1. 组件设计调整 | 实时预览界面，拖拽调整布局 | AskUserQuestion组件布局调整 |
| 2. 文案批改 | 逐行展示，每行有接受/拒绝/评论按钮 | SKILL.MD文件审阅 |
| 3. Remotion视频微调 | 动画参数用滑块实时调整 | 不用改代码再渲染再预览 |
| 4. 架构图可视化 | 代码库画成交互式节点图 | 点击节点评论或要求修改 |
| 5. 游戏数值平衡 | 滑块调整英雄属性数值 | AI根据调整给出平衡建议 |

### 核心工作流 (闭环)
```
Claude Code → 生成HTML → 浏览器交互 → playground输出prompt → 粘贴回Claude Code
```

**价值**: 文字世界和可视化世界无缝切换，各自做各自擅长的事

### 作者建议
> "想一种独特的交互方式，然后让模型去实现它。不要局限于已有案例，任何需要'看到'或'操作'才能做判断的场景都适合用playground。"

## 关键洞察

> "模型的表达能力远超文字。你一直在用纯文本和它交互，但给它一个画布，它能做到的事情可能超出你的想象。"
