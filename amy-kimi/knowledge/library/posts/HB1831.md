## 核心升级

OpenClaw 2026.3.13 可以直接接入**正在使用中的 Chrome 会话**。

不是新开干净浏览器，而是直接复用：
- 已登录状态
- Cookie
- 当前 tab
- 真实网页环境

## 传统浏览器自动化的痛点

- 要重新开浏览器
- 没有登录态
- 还要重复登录
- 一进后台系统就接不上

## 连接步骤

1. 打开日常在用的 Chrome（已登录账号）
2. 地址栏输入：`chrome://inspect/#remote-debugging`
3. 勾选 "Allow remote debugging for this browser instance"
4. 第一次连接时 Chrome 弹出提示，点击"允许"
5. OpenClaw 连接命令：

```bash
openclaw browser --browser-profile user tabs
openclaw browser --browser-profile user snapshot --format ai
openclaw browser --browser-profile user screenshot
```

## 功能

1. **user tabs**: 列出当前 Chrome 已打开的页面
2. **user snapshot --format ai**: 读出页面结构（标题、按钮、输入框、链接）
3. **user screenshot**: 直接截图当前页面
4. **接进真实网站工作流**

## 重要细节

- 第一次连接需要点一次允许
- 连接跑通后，后续连续操作不会每次都弹窗

## 意义

浏览器自动化从"演示工具"进入"真实场景生产力工具"阶段。
