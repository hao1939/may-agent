## 核心内容

Vercel 软件工程师 Jude Gao 的研究发现：在 Next.js 16 API 评测中，**8KB 的 AGENTS.md 文件达到了 100% 通过率，而 Skills 仅有 53%**（即使明确指令也只能达到 79%）。

### 对比方案
- **Skills（技能）**: 主动工具，AI 识别需求时主动调用文档
- **AGENTS.md**: 项目根目录下的 Markdown 文件，为 AI 提供每一轮对话的持久上下文

### AGENTS.md 胜出的三个原因

1. **消除决策点**  
   AI 不需要决定"我是否需要查阅文档"，信息已经直接呈现在面前

2. **持续可用性**  
   Skills 异步加载且可能调用失败，而 AGENTS.md 的内容在每一轮对话的系统提示词中都存在

3. **解决顺序冲突**  
   Skills 会让 AI 纠结是先读文档还是先看项目结构，而被动上下文消除了这种排序难题
