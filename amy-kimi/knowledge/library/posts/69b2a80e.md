## 五大设计原则

### 1. 用AGENTS.md写规则

通过 `if/then` 规则，明确什么时候必须触发某个skill。

### 2. 每个skill只做一件事

每个skill都必须有：
- 触发条件
- 输入
- 输出

### 3. skill的description就是路由信息

Agent在没加载完整skill前，就是靠description判断要不要用它。

### 4. scripts负责确定性工作

所有重复、机械、确定性的shell流程下沉到scripts：
- lint
- build
- test
- release check

### 5. 把理解与推理留给模型
