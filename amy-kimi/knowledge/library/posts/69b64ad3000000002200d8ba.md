## 核心洞察

**黄金工作流**: Claude 负责思考（大脑），Codex 负责执行（双手）。

### 工具分工

| 工具 | 角色 | 适用场景 |
|------|------|----------|
| Claude Code | 大脑 | 读源码、定Bug、理架构、出方案 |
| Codex CLI | 双手 | 改代码、跑命令、过测试、出Patch |

### 黄金工作流详解

```
Claude 调查 → Claude 出 Handoff 任务书 → Codex 执行修改 → 跑测试验证 → 失败则回退给 Claude 诊断
```

一句话总结：**Claude 负责出谋划策，Codex 负责攻坚落地**。

### 与OpenClaw设计验证

| 概念 | 本文 | OpenClaw对应 |
|------|------|--------------|
| 大脑-双手分工 | Claude/Codex分离 | Main/Sub-agent架构 |
| Handoff任务书 | 显式任务传递 | SIGNALS.md + handoff工具 |
| 失败回退机制 | 测试失败→Claude诊断 | Error Log审计循环 |
| 工作流编排 | 黄金四步 | Harness Engineering |

**关键验证**: 这种"规划-执行分离"模式正在成为AI编程领域的共识架构。
