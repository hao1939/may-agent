## 核心更新 (v2.1.72)

### 1. /plan 官方支持带描述
- 以前直接 `/plan fix the auth bug` 时灵时不灵，因为当时是Claude自己猜
- 现在是内置功能，更稳定、更精准
- **趋势**: Claude Code在弱化plan mode存在，厉害的模型能自动识别何时该进plan模式
- 作者观察到：最近几版已经开始可以不用命令也不用shift tab自动plan

### 2. bash权限提示大幅减少
- 作者自己也写过类似Claude Code的coding agent，有同样问题
- find、变量赋值、只读命令动不动就弹Allow bash command?
- 这次Claude Code把这类操作都加入了白名单
- **启示**: 该学学这个白名单思路

### 3. /copy 新增w键
- 选中内容直接写入文件，不经剪贴板
- SSH场景下应该很好用

### 4. 其他优化
- SDK prompt cache修复，输入token成本最高降低12x
- bundle体积-510 KB，启动更快
- Effort调节换新图标○ ◐ ●（仅官方订阅用户）
