> **"默认否定，显式授权。"**

## 6层安全护栏

### 1. 网络层：只监听本地
```json
"gateway": {
  "bind": "loopback",
  "auth": { "mode": "token" }
}
```
- 只绑127.0.0.1，外网完全访问不到
- Token认证，本地其他程序也无法随便调用
- 需远程→Tailscale加密隧道（而非暴露端口）

### 2. 消息渠道：白名单+配对制
```
Telegram: dmPolicy="pairing"（陌生人需手动批准）+ groupPolicy="allowlist"
Discord: DM直接关 + 群组白名单 + 频道级allow/deny
iMessage: 配对制+白名单
核心: 默认拒绝一切，逐个打开 ← 不是默认开放再堵漏洞
```

### 3. 行为层：AUTHORIZATION.md权限清单
```
可以直接做:
  - 读文件/搜索/查日历
  - 安装缺失工具/修明显bug
  - 更新记忆文件

必须先问:
  - 涉及钱的操作
  - 系统级改动(sudo/改防火墙)
  - 对外发消息(邮件/推特/公开内容)
  - 删除文件(trash可以，rm要问)
```

### 4. 危险命令策略（AGENTS.md硬性规则）
永远先问再执行: `rm -rf` | `sudo` | `chmod 777` | `dd if=` | 数据库drop
**"用trash代替rm——可恢复永远比删了强"**

### 5. 记忆隔离
```
私聊 → memory/（只有我能触发）
A群 → group-memory/a/
B群 → group-memory/b/
MEMORY.md只在私聊session加载 ← 防个人信息泄露到群里
```

### 6. 数据不出门
> "Agent有权限读你的文件、邮件、日历，但在群聊里它是参与者，不是你的传声筒。**有访问权不等于有分享权。**"

## 5条默认值总结
1. 网络默认不开放
2. 消息默认不响应
3. 操作默认先问
4. 记忆默认隔离
5. 数据默认不出门
