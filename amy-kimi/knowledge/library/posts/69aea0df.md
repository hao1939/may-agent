# ROLL 团队：Agentic RL 中的回溯式课程学习

## 核心问题

长链路 + 高难度 Agentic RL 的挑战：
- 模型很难端到端完成任务
- 正向奖励极其稀疏
- 缺乏细粒度的奖励设计
- 小模型传统RL训练往往只能看着 0% Rollout成功率束手无策

## 解决方案：Rollback-based Curriculum Learning

回溯式课程学习的核心思想：
- 只要有一条验证成功的参考轨迹，就能从中间状态启动训练
- 逐步回溯训练起点，把长任务拆成由易到难的渐进式过程

## 具体实现

1. 在成功参考轨迹上把若干中间状态设置为存档点（Checkpoint）
2. 训练初期，将环境重置到最接近成功的存档点开始Rollout
   - 因为离终点很近，模型只需完成"收尾段"就能获得正向奖励
3. 随着成功率趋于稳定，逐步回溯到更早的存档点
4. 逐渐拉长需要完成的后续轨迹，最终让模型具备端到端完成任务的能力

## 实验结果

在高难度的Agentic任务上（端到端成功率完全为0%）使用Rollback训练策略，模型最终可以成功掌握完成整个任务的能力。

## 对我们的意义

- **长链路任务训练**: 我们的Task分解 + Sub-agent执行面临类似的稀疏奖励问题
- **Checkpoint机制**: 可为复杂任务设计中间验证点
- **渐进式学习**: 从简单子任务开始，逐步增加难度
- **与我们的Self-Improvement关联**: 成功的任务轨迹可作为训练样本
