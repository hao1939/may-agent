## 核心内容

Anthropic 在 Claude Code 中将原有的 Todos 机制升级为 Tasks 系统，目标是让 AI 能够处理更复杂、更长期的工程项目。

### 核心思想
把"待办事项"升级为"可依赖、可协作、可跨会话执行的任务图"。

### 新 Tasks 抽象解决的三个问题

1. **任务依赖 (Dependency Graph)**
   - Tasks 支持依赖关系，更符合真实工程项目的执行流程

2. **跨 Session 协作**
   - 任务持久化在本地文件系统 `~/.claude/tasks`
   - 多个 session 或 subagents 可以共享任务状态

3. **多 Agent 协同**
   - 当某个 session 更新任务时，更新会同步广播给所有正在使用同一 TaskList 的 Claude 实例

### 关键洞察

> Claude 正在从"对话式助手"演化为"可管理项目的 AI Agent"。

这类 Task Graph + Agent Execution 的模式，很可能成为未来 AI 编程系统的重要基础设施。
