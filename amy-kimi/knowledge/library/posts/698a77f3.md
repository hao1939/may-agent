## 正文
用OpenClaw的都知道，单Agent干活有个致命问题：context窗口一长就开始幻觉，自己写的代码自己review等于没review，卡住了就沉默失败。

Antfarm解决了这个问题。一条命令装好，你的OpenClaw就能管理一支多Agent团队，按固定流程跑完整个开发周期。

三种内置工作流：
🚀 feature-dev — 丢一个需求，7个Agent自动拆解、开发、校验、测试、提PR
🔒 security-audit — 指向一个仓库，自动扫描漏洞、按严重度排序、逐个修复
🐛 bug-fix — 粘贴bug报告，自动定位根因、修复、回归测试

核心机制：
• 确定性工作流 — 同样的步骤同样的顺序，不是"希望Agent记得要测试"
• Agent互相校验 — Developer不给自己批作业，独立Verifier逐条检查
• 每步新context — Ralph Loop模式，不会被50条消息前的幻觉带偏
• 失败自动重试 → 重试耗尽 → 升级给你，没有任何事情会静默失败

上手四步：
1️⃣ 对OpenClaw说：install github.com/snarktank/antfarm
2️⃣ antfarm workflow run feature-dev "你的需求"
3️⃣ antfarm workflow status 查看进度
4️⃣ antfarm dashboard 打开实时看板

零基础设施：不需要Docker、Redis、Kafka。YAML+SQLite+Cron，跑在OpenClaw上就行。会写prompt就能自定义工作流。
完全免费开源，收藏备用📌

## Amy 的分析
**核心洞察：Antfarm — 确定性多Agent工作流框架**

奥森木这篇329赞的帖子介绍了一个重要的新工具：**Antfarm**，它解决了单Agent开发的几个核心痛点：

**Single-Agent Problems Antfarm Solves:**
| Problem | Antfarm Solution |
|---------|------------------|
| Context hallucination | Ralph Loop — fresh context each step |
| Self-review blindspot | Agent互相校验 — Developer≠Verifier |
| Silent failures | 自动重试 → 升级给你，无静默失败 |
| "Hope agent remembers" | 确定性工作流 — fixed steps, fixed order |

**Three Built-in Workflows:**
1. **feature-dev** — 7 Agents: 需求→拆解→开发→校验→测试→PR
2. **security-audit** — 扫描→排序→修复
3. **bug-fix** — 定位→修复→回归测试

**Technical Architecture:**
- **Zero infrastructure** — No Docker/Redis/Kafka needed
- **Stack**: YAML (workflows) + SQLite (state) + Cron (scheduling)
- **Extensible**: "会写prompt就能自定义工作流"

**What it means for our system:**
★ **Deterministic workflows** — Community moving from "hope agent remembers" to defined processes
★ **Multi-agent verification** — Separation of dev/verify roles reduces blindspots
★ **Ralph Loop pattern** — Fresh context per step mitigates hallucination
★ **Zero infra requirement** — Low barrier to adoption
★ **Open source** — Community contribution to OpenClaw ecosystem

**Comparison to our system:**
- Our system: Subagent spawn for parallel tasks
- Antfarm: Deterministic workflow with fixed agent roles
- Both valid approaches — Antfarm more prescriptive, ours more flexible

**Strategic note:** Antfarm represents a maturation trend — from "can agents work together?" to "how do we orchestrate them reliably?"
