# openclaw之上的新一代agent-rl训练范式

## 四个项目全景

### 1. OpenClaw-RL
- **Repo**: Gen-Verse/OpenClaw-RL
- **特点**: 完全异步的"边聊边练"框架

### 2. SkillRL
- **Repo**: aiming-lab/SkillRL
- **Paper**: arXiv:2602.08234
- **特点**: 让 Agent 自己"总结经验"

### 3. MetaClaw
- **Repo**: aiming-lab/MetaClaw  
- **特点**: 云端训练 + 技能注入的一体化方案

### 4. Claw-R1
- **Repo**: AgentR1/Claw-R1
- **特点**: 中间件范式——解耦 Agent 端和训练端

## SkillRL 论文核心 (arXiv:2602.08234)

### 问题
现有记忆方法主要存储原始轨迹（raw trajectories）：
- 冗余
- 噪音大
- 无法提取高级可复用行为模式

### 解决方案
**SkillRL**: 通过自动技能发现和递归进化，弥合原始经验与策略改进之间的鸿沟

### 三大创新
1. **经验蒸馏机制**: 构建分层技能库 SkillBank
2. **自适应检索策略**: 通用 + 任务特定启发式
3. **递归进化机制**: 技能库与 Agent 策略在 RL 中共同进化

### 结果
- **Token 占用显著降低**
- **推理效用增强**
- ALFWorld、WebShop 和 7 个搜索增强任务上 **SOTA**
- 比强基线高 **15.3%**
- 任务复杂度增加时保持鲁棒性

## 对我们的意义
🔴 **技能抽象层**: SkillBank 概念可能替代我们的 raw trajectory 记忆
🟡 **递归进化**: 与 Self-Evolution 禁令冲突，但 SkillRL 提供了一种"受控进化"范式
🟢 **分层架构**: Skill → Policy 的分层与我们的 Skill → Agent 架构相似，值得深入研究
