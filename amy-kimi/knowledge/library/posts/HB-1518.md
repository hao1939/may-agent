**Source**: arXiv:2603.10062 [cs.AR/MA] (UC San Diego / Georgia Tech) — Direct Paper Tracking  
**Title**: Multi-Agent Memory from a Computer Architecture Perspective: Visions and Challenges Ahead  
**Authors**: Zhongming Yu, Naicheng Yu, Hejia Zhang, et al.  
**Date**: 2026-03-09

## Core Thesis

论文首次将**多Agent记忆系统框定为计算机架构问题**，提出三层记忆层级模型，识别两个关键协议缺口，并指出**多Agent记忆一致性**是最紧迫的开放挑战。

## Two Fundamental Memory Paradigms

| Paradigm | Description | Pros | Cons |
|----------|-------------|------|------|
| **Shared Memory** | 所有Agent访问共享池(向量库/文档DB) | 知识复用容易 | 需要一致性支持；Agent互相覆盖/读取过期信息 |
| **Distributed Memory** | 每个Agent拥有本地记忆，选择性同步 | 隔离性好，可扩展 | 需要显式同步；状态发散常见 |

**Reality**: 大多数系统处于中间地带——本地工作记忆 + 选择性共享工件

## Three-Layer Memory Hierarchy

计算机架构的核心洞见：系统不是围绕"单一记忆"设计的，而是**记忆层级**——针对延迟、带宽、容量和持久性优化的多层结构。

| Layer | Function | Capacity | Speed | OpenClaw Mapping |
|-------|----------|----------|-------|------------------|
| **I/O Layer** | 信息摄入/输出接口(音频/文本/图像/网络) | Unbounded | Slowest | External tool calls |
| **Cache Layer** | 快速、有限容量的即时推理记忆 | Limited | **Fastest** | **Context Engine** |
| **Memory Layer** | 大容量、慢速检索和持久化 | Large | Slow | **Error Log + AGENTS.md** |

**Key Principle**: Agent性能是端到端数据移动问题。如果相关信息卡在错误层级(或从未加载)，推理准确性和效率都会下降。

## Two Critical Protocol Gaps

### Gap 1: Agent Cache Sharing Protocol

> "We lack a principled protocol for sharing cached artifacts across agents."

- 目标：使一个Agent的缓存结果能被另一个Agent转换和复用
- 类比：多处理器中的缓存传输
- 相关研究：KV cache sharing (Liu et al., 2024; Fu et al., 2025b; Ye et al., 2025)

### Gap 2: Agent Memory Access Protocol

关键问题（目前未明确规范）：
- 一个Agent能否读取另一个Agent的长期记忆？
- 访问是只读还是读写？
- 访问单元是什么：文档、chunk、KV记录、trace段？

## The Most Pressing Challenge: Multi-Agent Consistency

### Consistency Decomposition

多Agent记忆一致性分解为两个要求：

1. **Read-time conflict handling** (迭代修订下的读取冲突处理)
   - 记录跨版本演化
   - 过期工件可能仍可见

2. **Update-time visibility and ordering** (更新时可见性和排序)
   - Agent的写入何时对其他Agent可见？
   - 并发写入以何种允许顺序被观察？

### Why Harder Than Classical Settings?

- **工件异构性**：证据、工具trace、计划
- **语义冲突**：冲突通常是语义层面的，且与环境状态耦合

### Practical Direction

> "Make versioning, visibility, and conflict-resolution rules explicit, so agents agree on what to read and when updates take effect."

## Critical Quote

> "Many agent memory systems today resemble human memory: informal, redundant, and hard to control. To move from ad-hoc prompting to reliable multi-agent systems, we need better hierarchies, explicit protocols for cache sharing and memory access, and principled consistency models that keep shared context coherent."
