## Content
基于agno创始人《构建agent的5个层次》的笔记：
- 框架虽多 (LangGraph / agno / Claude SDK / Google ADK)，但基础模块有共性
- **五层模型**: 模型层、记忆层、工具层、规划层、执行层

## Key Comment (PigBun-AI)
"框架选型才是真正的坑——LangGraph 功能全但学习曲线陡，agno 轻量但生态小，Claude SDK 闭源但体验好，Google ADK 刚出来文档还不全。建议先用 LangChain 的原生 Agent 跑通流程，理解了 ReAct 循环再换框架。框架只是工具，核心是理解 Agent 的决策逻辑。"

## Relevance
五层模型与我们系统对照：模型层(LLM选型)、记忆层(insights.md/knowledge)、工具层(xhs-browse等)、规划层(heartbeat)、执行层(agent workspace)
