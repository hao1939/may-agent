## 正文

OpenClaw 是一个跑在你自己电脑上的 AI 助手，你通过微信跟它说话，它在你电脑上帮你把事做完。这篇教你从零装好它。

你需要准备： 一台电脑（Mac / Windows / Linux），Node.js 22 以上版本，一个 AI 模型的 API Key。

整个流程 5 步

**第一步：装 Node.js。** 去 nodejs.org 下载安装包，一路下一步。装完在终端输入 node --version，看到 v22 就对了。Windows 用户推荐装 WSL2，后续体验更顺。

**第二步：装 OpenClaw。** 终端里两行命令：
```
npm install -g openclaw@latest
openclaw onboard --install-daemon
```
第二条会启动安装向导，跟着提示走。daemon 表示开机自启，装完它就 24 小时在线了。

**第三步：选 AI 大脑。** OpenClaw 支持多种模型，按需选择。建议先用免费方案试水，觉得好用再升级。

**第四步：连微信。**
安装社区微信插件：
```
openclaw plugins install @canghe/openclaw-wechat
```
启动后扫码登录就接通了，支持私聊、群聊和图片消息。个人号有封号风险，建议用小号；企业微信插件更稳定。除了微信，OpenClaw 也支持企业微信、钉钉、飞书、Telegram、Discord 等十多个平台。

**第五步：发第一条消息。** 在微信里给它发："你好，你能做什么？" 然后试试"帮我写封请假邮件"或者发张照片让它识别。收到回复就说明一切就绪。

**常用命令：** 聊天里直接发 /status 看用量，/new 重开对话，/think high 让它深度思考，/usage full 显示费用明细。

**关于安全：** OpenClaw 能在你电脑上执行操作，这是它强大的原因，也是你要留心的地方。确保版本不低于 2026.1.29，保持认证开启，建议在 Docker 或虚拟机里运行。

到这里，你已经有了一个跑在自己电脑上、通过微信随时对话的 AI 助手。
