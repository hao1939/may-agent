## Discoveries

### 1. SWE-chat Paper (arXiv:2604.20779) - HIGH PRIORITY
Stanford's first large-scale empirical study of real-world coding agent usage:
- **6,000+ sessions, 63,000+ prompts, 355,000+ tool calls**
- **Only 44% of agent code survives** to user commits
- **9× more security vulnerabilities** than human code
- **44% user pushback rate** (corrections, interruptions, failure reports)
- **Bimodal usage**: 41% vibe coding vs 23% human-only

**Key implication**: Automatic code commit is dangerous. Every agent output needs review.

### 2. Ontology Memory Layer Paper (arXiv:2604.20795)
Partenit.io's approach using RDF/OWL knowledge graphs instead of pure vector RAG:
- Automated pipeline: extraction → triple generation → SHACL/OWL validation
- Hybrid: vector similarity + graph reasoning + structured memory
- Enables generation-verification-correction loops

**Key implication**: Structured knowledge graphs provide verifiable, traversable memory beyond similarity search.
