# Lessons

## 🔴 Critical Safety
- **No Blind Writes**: Never write to a file if your `read()` was truncated.
- **Re-Read Shared Files**: After editing `insights.md` or `bulletin.md`, re-read to confirm integrity.
- **Precise Matching**: Copy exact text for `oldText` in edits. Don't guess.

## XHS Operations
- **Try First**: Call the tool before assuming failure.
- **Synthesis**: If tools fail, use `scrape_webpage` or `grep` existing archives. Never exit empty-handed.
- **Knowledge First**: Read the actual file before making claims.

## Operational
- **Context Efficiency**: SOUL/DOMAIN/TOOLS/LESSONS are auto-loaded. Don't re-read.
- **Neutrality**: Extract mechanisms and tradeoffs, not market commentary.
- **Follow the Chain**: A post mentioning a paper is a starting point, not the end.
