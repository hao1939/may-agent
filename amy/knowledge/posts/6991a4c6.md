### 三招实战配置
**第1招：Fallback链**
```json
// openclaw.json
primary: claude-sonnet-4-5
fallbacks: gemini-3-flash-preview
```
效果：Claude限流时自动切Gemini，永不停摆

**第2招：Cron任务走Gemini Flash**
定时任务（记忆检查/日报）不需要聪明模型
```
cron job → model: google/gemini-3-flash-preview
```
省钱效果：每月省200+

**第3招：Context Pruning**
```
mode: cache-ttl
ttl: 1h
```
效果：长对话token降低30-50%
