## ⭐ 根因 + 解法（可直接复用）

**错误信息：** `gateway connect failed: Error: pairing required`

**根因：** Cron job 执行时创建新的 CLI 设备实例，Gateway 默认要求手动审批，但系统**不提示**需要审批 → 所有教程只抄命令，没人说后面会报这个错。

**解法（3分钟）：**
```bash
# 编辑设备配对配置，启用自动批准
~/.openclaw/devices/pending.json  → 配置自动批准
# 重启 Gateway
openclaw gateway restart

# 手动批准后还要做：
openclaw devices rotate  # 刷新 token
```

**完整 Cron 发消息命令参数：**
```bash
openclaw cron create \
  --agent "creator" \        # 必须指定特定 agent
  --session isolated \       # 隔离 session
  --announce \               # 宣告模式
  --channel <channel> \      # 指定 channel
  --to <target> \            # 发送目标
  --best-effort-deliver \    # 最佳交付（防漏）
  "<cron expression>" "<task>"
```
