[斜眼R]AI 编程代理的性能受限于其训练数据的截止日期。Next.js 16 引入了一系列全新 API，这些内容并不在当前大模型的训练数据中。这导致 AI 经常生成错误代码或回退到过时模式。为了解决这一问题，Vercel 对比了两种方案：
	
• Skills（技能）：一种主动工具，AI 识别到需求时主动调用文档。
	
• AGENTS.md：项目根目录下的 Markdown 文件，为 AI 提供每一轮对话的持久上下文。
	
[飞机R]起初Jude Gao以为Skills能很好地解决AI学习新框架特定知识的问题，结果却在实践中发现了意想不到的情况：
	
[惊恐R]将只有 8KB 的压缩文档索引嵌入AGENTS.md 文件后，在Next.js 16 API 的评测中达到了100%通过率，而火爆全网的Skills却仅有53%，即使有明确指令，最高也就79%，在效率和准确率上被打爆了。[斜眼R]
	
[露营灯R]Jude Gao分析出现“笨方法”更有效的原因有三个：
	
1、消除决策点：AI 不需要决定“我是否需要查阅文档”，信息已经直接呈现在面前。
	
2、持续可用性：Skills 异步加载且可能调用失败，而 AGENTS.md 的内容在每一轮对话的系统提示词中都存在。
	
3、解决顺序冲突：Skills 会让 AI 纠结是先读文档还是先看项目结构，而被动上下文消除了这种排序难题
	
[扯脸H]这个反直觉的结论让我们不得不思考一个问题：最新、最火的东西是不是最好的，或者说最合适的？
	
我们真的需要那么多Skills吗？并不见得，不是所有事情都需要用到它，也不是所有事情用它都会更高效，有时候简单原始反而是最合适的，正所谓大道至简嘛~

# Notes

AI 编程代理的性能受限于其训练数据的截止日期，Next.js 16 引入了一系列全新 API,这些内容并不在当前大模型的训练数据中。这导致 AI 经常生成错误代码或回退到过时模式。为了解决这一问题, Vercel 对比了两种方案：
· Skills(技能)：一种主动工具, AI 识别到需求时主动调用文档。
· AGENTS.md：项目根目录下的 Markdown 文件，为 AI 提供每一轮对话的持久上下文。

起初 Jude Gao 以为 Skills 能很好地解决 AI 学习新框架特定知识的问题, 结果却在实践中发现了意想不到的情况:

将只有 8KB 的压缩文档索引嵌入 AGENTS.md 文件后, 在 Next.js 16 API 的评测中达到了 100% 通过率，而火爆全网的 Skills 却仅有 53%, 即使有明确指令, 最高也就 79%, 在效率和准确率上被打爆了。

[Slide 3]
Jude Gao 分析出现＂笨方法＂更有效的原因有三个：

1、消除决策点：AI 不需要决定＂我是否需要查阅文档＂，信息已经直接呈现在面前。

2、持续可用性：Skills 异步加载且可能调用失败，而 AGENTS.md 的内容在每一轮对话的系统提示词中都存在。

3、解决顺序冲突：Skills 会让 AI 纠结是先读文档还是先看项目结构，而被动上下文消除了这种排序难题

这个反直觉的结论让我们不得不思考一个问题：最新、最火的东西是不是最好的，或者说最合适的？

我们真的需要那么多 Skills 吗？并不见得, 不是所有事情都需要用到它, 也不是所有事情用它都会更高效, 有时候简单原始反而是最合适的, 正所谓大道至简嘛～
