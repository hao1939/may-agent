## ClawPhD — 面向科研的OpenClaw Agent

### 定义
```
基于 Nanobot（OC轻量版）构建的学术科研Agent
核心功能：将学术论文转化为出版级图表/海报/视频等多种形式

已实现：Agent自动化图表生成
  → 根据论文章节自动生成出版级学术插图与统计图表
```

