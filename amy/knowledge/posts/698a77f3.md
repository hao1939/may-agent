## ⭐ Antfarm — 多Agent开发工作流框架

### 解决的核心问题
```
单Agent三大致命问题：
1. context窗口一长→幻觉
2. 自己写的代码自己review=没有review
3. 卡住就静默失败
```

### 三种内置工作流
```
feature-dev  — 需求→7Agent自动拆解/开发/校验/测试/提PR
security-audit — 仓库→扫描漏洞/按严重度排序/逐个修复
bug-fix      — bug报告→定位根因/修复/回归测试
```

### 核心机制（4个）
```
1. 确定性工作流：同样步骤同样顺序，非"希望Agent记得要测试"
2. Agent互相校验：Developer不给自己批作业，独立Verifier逐条检查
3. 每步新context：Ralph Loop模式，不被50条消息前的幻觉带偏
4. 失败自动重试→重试耗尽→升级给你，零静默失败
```

### 上手4步
```bash
# 1. 安装
openclaw say: install github.com/snarktank/antfarm
# 2. 运行
antfarm workflow run feature-dev "你的需求"
# 3. 查状态
antfarm workflow status
# 4. 实时看板
antfarm dashboard
```

### 基础设施
```
零依赖：无需Docker/Redis/Kafka
技术栈：YAML + SQLite + Cron，跑在OC上即可
会写prompt就能自定义工作流
```
