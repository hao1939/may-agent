## 5 Key Lessons (from description + comments)

### 1. MEMORY.md: Index only, not content
"MEMORY.md只放索引不放内容" — Put only an index in MEMORY.md, detailed content goes into memory/ subdirectory files. Prevents context explosion.

### 2. Multi-agent workspace isolation
"多agent隔离workspace" — Each agent gets its own workspace. Community confirms but notes skill permission issues: "我试过多agent隔离work space。但是会经常出现skill无法读取，没有权限的问题。后来就直接放开了。"

### 3. Automated memory cron
"记忆自动化cron" — Automate memory management. Author recommends heartbeat timing checks ("建议开 heartbeat 定时检测，凌晨挂了能第一时间知道").

### 4. Markdown GTD for task management
"Markdown GTD管理任务" — Use Markdown-based Getting Things Done methodology for agent task management.

### 5. Write SOUL.md with soul
"SOUL.md写出灵魂" — Agent identity/personality needs to be explicit and persistent.
