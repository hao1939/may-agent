# X上讨论很多的 Pi 是什么

Pi 是 一 个 极 简 的 编 程 Agent （ coding agent ）， 由 Mario Zechner （ GitHub @badlogic）开发，是目前一些热门聊天机器人项目（如 OpenClaw，也 曾 叫 ClawdBot 或 MoltBot）的核心引擎。

Pi 的设计思路非常简单：只提供四个最基础的工具—— read（读文件）、write（写文件）、edit（编辑文件）、bash（执行 shell 命令）。除此之外，没有预装大量功能、复杂的工具链或 UI 组件。所有额外能力（如搜索、git 操作、TODO 管理、代码审查、浏览器自动化、甚至自定义 TUI 界面）都通过 LLM 自己写代码来实现和扩展。

Armin Ronacher（Flask 作者）在 2026 年 1

[Slide 2]
月 的 博 客 《 Pi: The Minimal Agent Within OpenClaw 》中提到，他目前只用 Pi 作为编程 Agent，觉得它像一个优秀的软件：极致精简、内存占用低、运行稳定。他认为 Pi 的价值在于它真正让"软件构建软件"这件事变得可行。


## 核心特点

– 极简内核：系统提示词很短，工具只有四个，避免了上下文膨胀和不必要的 token 消耗。

– 扩展机制：支持 extensions，可以注册新工具 、 slash 命 令 （ 比 如 /todos、/review、/answer），并持久化状态。Agent 可以自己写扩展代码，热重载、测试、迭代，形成闭环。

– 会话树结构：支持分支（branch）、导航、总结变更、回滚，适合并行尝试不同方案或修复 bug。

– TUI 支持：能自己生成 spinner、进度条、文件选择器、数据表格、预览面板等交互组件。

[Slide 3]
– 模型兼容： 支持 Anthropic 、 OpenAI 、 Google、Groq 等多种模型，甚至能在同一个会话里切换。

– 自举能力： 你可以把 Pi 指向自己的代码或 mom 包，让它帮你生成新的 Agent 或 bot。


**实际使用场景**

很多人用 Pi 来完成日常编码任务： 写代码、重构 、 debug 、 生成 commit message 、 changelog、代码审查等。因为上下文干净、响应快、崩溃少，切换后不少人就基本不再用其他工具了。

OpenClaw 则是 Pi 最知名的应用场景。它把 Pi 去掉终端 UI，直接接入 Telegram、Discord、Slack 等聊天平台，让用户通过聊天就能调用 Agent 能力。OpenClaw 的快速走红也带动了 Pi 的关注度。

另外，开发者会用 Pi 来构建自己的 slash 命令、自定义技能，或者研究 Agent 的底层循环和自扩

[Slide 4]
展机制。



**优点与局限**

优点在于它的可靠性和灵活性：内核小、崩溃少、扩展靠自己写就不会被工具限制卡死。Armin 提到 Pi 的代码质量高，运行稳定，扩展过程像"软件活起来了一样"。

局限是入门需要熟悉命令行和 Node.js 生态，没有图形界面，主要靠 CLI + TUI 操作。效果也依赖模型能力（Claude 系列或强模型表现更好）。它故意不内置很多高级功能（如 MCP 支持），而是鼓励用户或 Agent 自己去实现。

总的来说，Pi 代表了一种"少即是多"的思路：不试图做成万能工具箱，而是做一个能自己长出工具箱的种子。如果你对极简、可自扩展的 coding agent 感兴趣，可以去GitHub上关注！
