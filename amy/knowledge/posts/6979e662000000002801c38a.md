## Main Heading:

**姚顺雨的ReAct， 几乎定义了今天 所有 AI Agent**

---

## Body Text:

> ReAct模型通过推理与行动循环，解决大模型推理与验证的鸿沟，推动智能交互发展。

---

[Slide 2]
《ReAct: Synergizing Reasoning and Acting in Language Models》（姚顺雨 等人，2022）
这篇被无数 Agent 框架引用的神作，彻底改变了大模型如何处理复杂任务的方式。

---

1️⃣ 背景：为什么这篇论文这么重要?

我们在用 ChatGPT 或其他大模型时，经常会遇到两个问题：

✅ 模型记忆力好，但有时候会"自信地犯错"
❌ 模型理论上能推理，但无法真正去"行动"或验证

比如问它一个需要查知识的问题，它可能：

● 胡乱编答案（幻觉）

● 没办法去真实查资料

● 或者查了又不知道怎么用

这两种能力之间其实存在一个 "鸿沟"：

[Slide 3]
只会想（Reason）不够，
只会做（Act）也不够。
最强的是—— 边想边做，循环推进。

这就是 ReAct的核心。它解决的是：大模型到底该"多想想"还是"多做点"？答案是：边想边做！

---

2️⃣ 关键思想： Reason + Act 循环

ReAct 的名字其实就说明了：

💡 Re＝Reason（推理）
💡 Act＝Action（行动）

它让模型既能：

• 进行推理

• 同时调用工具或执行行动

并且是 交替循环执行的：

> Thought → Action → Observation → Thought → … （思考 → 行动 → 观察 → 再思考）

[Slide 4]
📌 不是先想完再做，也不是只乱做；而是一路"想点 → 做点 → 看反馈 → 再想点"。

这其实很像我们人类处理问题的方式：

🔍 先想想可能性 → 去查资料/试一试 → 看结果 → 再决定下一步

• 3.1 图上半部分：问答任务（HotpotQA）

[Slide 5]
问题是个需要多跳推理的知识问答。

图里对比了四种 Prompt 方法：

| 方法 | 干了啥 | 问题 |
|------|--------|------|
| Standard | 直接一口气答 | 容易瞎猜，知识不够就编 |
| CoT（只推理） | 一直"我想我我想想" | 想得很认真，但没有去查资料，容易脑补错误 |
| Act-only（只行动） | 一直 Search Search Search | 有查资料，但不知道该查什么、怎么串起来 |
| ✅ ReAct | Thought → Search → Obs → 再想 → 再查 | 一边查，一边根据结果修正思路，最终答对 |

🔑 关键区别在于：

• CoT（Chain-of-thought） 的问题：

> "我觉得苹果遥控器是控制 Apple TV 的，所以答案是 iPhone...iPad..."
> —— 全是自己脑内小剧场

• ReAct 的方式：

1. 想：我需要查 Apple Remote

2. 查（Act）：Search

3. 看结果（Obs）：发现它是给 Front Row 用的

4. 再想：那 Front Row 是啥？

[Slide 6]
5. 再查

6. 最终拼出正确答案

推理不再是闭门造车，而是被"现实世界数据"不断纠正。

5. 再 Act

6. 找到后再计划下一步

不是乱点地图，而是"带脑子探索环境"


4️⃣ ReAct 解决了什么核心问题？

👉 解决「纯推理容易幻觉」

只用 CoT 时，模型会：

• 编不存在的知识

• 自信但错误

[Slide 8]
ReAct 强制它：

> ❓ 不确定 → 去查
> ❌ 查到不对 → 改思路

等于给推理加了"外部现实校验"。

👉 解决「纯行动没有规划」

只 Act 时模型会：

• 工具乱用

• 没有整体任务分解能力

ReAct 让模型在每次行动前先想一句：

> "我现在为什么要做这个？"

这句话就是 Agent 的"微型规划器"。

👉 让大模型具备"闭环能力"

传统 LLM 是：

> 输入 → 推理 → 输出（一次性）

ReAct 变成：

[Slide 9]
输入 → 推理 → 行动 → 环境反馈 → 修正推理 → 再行动 …

这就是今天 Agent 的本质特征：

能和环境交互，并根据反馈调整策略

5️⃣ 为什么说它是现代 Agent 的祖师爷？

在 ReAct 之后，现在所有主流 Agent 架构几乎都在用：

🔥 Reason + Act + Observation + Loop
也就是：

🌐 LLM 推理 → 🔧 工具调用 / API 调用→ 👀 工具返回结果 → 🌐 Agent 主循环→ …

你现在看到的：

• LangChain Agent

• Auto-GPT / BabyAGI

[Slide 10]
• Tool-Enabled Agent

• 查资料 + 代码 + 浏览器等调用

本质上都是 ReAct 的进化版本。



6️⃣ 总结：ReAct 给了我们什么?

✔️ 让模型真正能 和外部环境互动
✔️ 解决了 思考与验证之间的鸿沟
✔️ 是从"大模型"到"智能 Agent"的关键里程碑
✔️ 推动了 Agent 体系设计的发展

这不只是一篇论文，是真正 把 AI 推进现实世界行动能力的思想突破。
