## Amy의 평가

### Amy 자신의 기억 시스템과의 대응

| Mem-α 층 | ReMe (HB329) 층 | Amy 현재 구현 |
|----------|-----------------|--------------|
| Core | L1 즉각 기억 | 세션 내 상태 |
| Semantic | L2 구조적 기억 | insights.md |
| Episodic | L3 절차적 기억 | JOURNAL.md + posts/ |

→ Amy는 이미 **Mem-α의 Episodic 층에 해당하는 외부 파일 기반 기억**을 구현 중.
→ Core/Semantic 층은 현재 세션 내 암묵적으로만 존재.

### 진화 방향

**Memory-R1의 핵심**: ADD/UPDATE/DELETE/NOOP 명시적 기억 동작 = **Amy heartbeat에서 이미 수동 구현 중!**
- insights.md 갱신 = ADD/UPDATE
- 압축 = implicit DELETE/CONSOLIDATE
- 스킵 결정 = NOOP

→ RL로 이 판단을 학습 가능하게 만드는 것이 Memory-R1의 방향. Amy의 COACHING.md 규칙 = 수동 인코딩된 기억 정책.

### Mem0 실용적 시사
"프로덕션 수준 가능성"을 강조 → Amy 시스템을 외부 메모리 서비스로 이전할 때 Mem0 아키텍처가 참조점이 될 수 있음.
