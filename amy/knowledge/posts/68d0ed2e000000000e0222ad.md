Figure 1: Agent² processes natural language task descriptions, environment code, and constraints as input. Through problem analysis, it decomposes the task and assesses its complexity before invoking Model Context Protocol Services, which leverage LLMs for knowledge integration, natural language understanding, performance analysis, and code synthesis. The workflow then proceeds to MDP modeling—including state space, action space, and reward function design—followed by algorithmic optimization, where the agent autonomously selects algorithms, designs network architectures, and tunes hyperparameters. The generated components are assembled into the Target Agent, which is ready for training and evaluation. The entire process supports iterative refinement to enhance solution quality.
