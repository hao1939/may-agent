## Key Design Principles (19 distilled)

1. Tool extension is safe; reasoning modification is not.
2. Claude-specific iteration budget: T≤3. Lean into single-pass depth.
3. Verify coordination, not just output. 79% of MAS failures are coordination failures.
4. Separate detection from diagnosis. Trust anomaly flags; never trust explanations.
5. Memory-reasoning decomposition is fractal.
6. Two attack surfaces dominate MAS: tool orchestration + memory management.
7. Operation-count bounds for delegations.
8. Dual-objective QA: "catches bad" AND "allows good."
9. Format perturbation testing: cheapest high-signal evaluator reliability test.
10. Topology Before Headcount.
11. Pipeline depth matters exponentially. 3 hops = 7×; 5 hops = 31×.
12. Memory value = Structure × Causality × Verification.
13. Skills > Workflows is industry consensus.
14. Decision Point Elimination. Every unnecessary meta-decision is a failure point.
15. Context asymmetry determines drift direction.
16. Match protocol sophistication to resource regime. Simple under scarcity, structured under abundance.
17. Controlled dissipation is a formal requirement. γ ≈ 0 → past stability boundary. Archive/compact/prune as stability engineering.
18. Reasoning judges are adversarially exploitable. Multi-judge + geometric monitoring + dynamic evaluation needed.
19. Build on Unix primitives (CLI, files, pipes), not protocol abstractions. Protocol creators pivot; Unix is forever.
20. Allocation > Quantity. Reasoning performance is dominated by compute allocation quality, not compute quantity. 52.7% token reduction with +3.7pp accuracy.
21. Infrastructure First. 88.4% of real agent failures are infrastructure bugs; 78.3% are silent. Infra hardening yields 5× system improvement — more than all other layers combined.
22. Safety Externalization. Parametric safety (weight modification, RLHF) produces iatrogenic effects; structural safety (gates, middleware, external verification) does not. Build safety into the scaffold, not the model.
23. Observability Inversion. Reasoning quality assessment reliability is inversely proportional to observer proximity. Self-report systematically misleading. External behavioral observation > internal state examination at every scale.
24. Context Structure > Context Length. How you organize context matters more than how much you have. Structured retrieval beats long-context brute force. Claude 1M "saw it but can't remember"; OpenViking filesystem paradigm; AGENTS.md architecture. Design for structure, not volume.
