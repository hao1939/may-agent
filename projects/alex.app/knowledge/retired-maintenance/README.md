# Historical maintenance methods

These directories preserve knowledge and methods from the retired Host
Operations App. They are historical reference material, not executable Host
profiles. Alex owns current improvement Tasks and chooses his plain-named
[specialists](../../README.md), including
[Bob](../../agents/bob/AGENTS.md) and
[tech-lead](../../agents/tech-lead/AGENTS.md).

| Historical specialist | Retained focus |
| --- | --- |
| `tech-lead` | Host implementation and coordination. |
| `dev` | Runtime debugging, metrics, and focused reliability fixes. |
| `arc` | Architecture and design-coherence review. |
| `qa` | Independent verification. |
| `master` | Bounded implementation coordination. |
| `bob` | Evidence-backed architecture experiments. |
| `coach` | Agent-training and Gym experiments. |
| `optimizer` | Measured efficiency and behavior improvements. |

Earlier instructions here may refer to retired manifests, schedules or paths.
Consult current Alex guidance before applying a method; retaining it does not
restore execution authority or require recreating an `agent.json`. Preserve
original accepted evidence and use the
[retirement guide](../../archive/retired-apps/README.md) to locate archived data.
