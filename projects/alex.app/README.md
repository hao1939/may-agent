# Alex

Alex owns system improvement. May keeps human priorities and escalation; Scout
keeps research and shared knowledge. See the
[migration design](../may-agent.app/docs/proposals/alex-improvement-app.md).

This initial bootstrap admits ordinary goals and messages into durable Tasks
owned by Alex, using the standard agent execution path. It has no schedules or
automatic review subscriptions. Alex's first assignment migrates useful specialist
capabilities and unfinished obligations before claiming the new organization is
complete.
