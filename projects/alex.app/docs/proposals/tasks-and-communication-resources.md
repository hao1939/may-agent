## Remaining routing choice

May still maps several Evaluation and operational findings into Conversation
input in its source declaration. Decide which need ordinary owned Task work
that can execute while Conversation execution is unavailable. Reuse typed App
input, existing Task admission, creator authority and exact result/return links.
A report alone neither creates a human promise nor authorizes another action.

Start with one demonstrated failure route. Keep its original input or Task,
failed operation and useful evidence readable. A contribution supplies evidence;
the accepting Task retains the original promise and reply responsibility.
Publication, recipient admission, consideration and verified repair are distinct.
Do not add another supervisor resource, queue or work lifecycle for this change.

## Smallest useful verification

Use the normal App mapping and worker path with Conversation execution still
unavailable. Deliver one operational finding to usable owned work; return the
repair evidence to the exact original obligation and show it can continue.
Include the unavailable-recipient case without claiming that notification alone
establishes recovery. [Hierarchical recovery](unified-agent-recovery-20261017.md)
owns the shared recovery question, so these are one connected trial rather than
two independent routing mechanisms.

Keep the common publication/retry regressions: save a human ask and reply,
fail the later finish, then retry with the same operation identity. Accepted
publication must survive, and the original ask must not be falsely fulfilled.

For quiet automated work, verify retained evidence and waits without an
unnecessary human message. A meaningful answer or decision can still be sent
through the existing communication contract. Judge useful outcomes and total
cost; a smaller result object alone is not behavioral acceptance.

## Out of scope

Standalone agent addressing, automatic initiative and transport idempotency
retain their own proposals. Current upgrade operations remain in the
[stopped conversion procedure](../2b-manual/app-operations-recovery.md#upgrade-retired-task-contracts).
This follow-up authorizes no live route change, restart or model experiment.
