# Retired improvement Apps

The executable `may-agent`, `evaluation` and `gym` Apps were replaced by
Alex. Source removal does not fulfill their Tasks or erase their history.
The [migration receipt](../../migration-receipt-2026-10-04.md) and retained
frontier record track those separate obligations.

Useful information now has these homes:

| Retired content | Current home |
| --- | --- |
| Shared principles, contracts, manuals and manual skills | [Alex design manual](../../docs/README.md) |
| Maintenance specialists' knowledge and methods | [Improvement knowledge](../../knowledge/README.md) |
| Evaluation criteria and calibration | [Criteria](../../criteria/criteria.md) |
| Evaluation design and trials | [Evaluation guidance](../../docs/evaluation/README.md) and `evaluation/` here |
| Comparison design and trials | [Comparison guidance](../../docs/comparison/README.md) and `gym/` here |
| Earlier maintenance experiments and archives | `may-agent/` here |

These dated archives are evidence, not executable App definitions. Duplicate
runtime code, old schedules, manifests and agent profiles are removed. The
last complete source is retained in Git at
`06f9c03922f523524d89341a88f783c2f373cfdf`; for example,
`git show <commit>:projects/evaluation.app/app.ts` retrieves a former manifest.
The previous READMEs remain alongside their historical records.

Runtime data, reports, accepted artifacts and the database are not source
garbage. Local retirement retains their bytes and a relocation receipt.
Historical path aliases may remain locally for accepted artifact references;
they contain no active App registration. The configured shared report store,
immutable definition releases, saved Tasks, inputs and Conditions retain their
original identities. Alex must still judge and migrate unfinished obligations.
