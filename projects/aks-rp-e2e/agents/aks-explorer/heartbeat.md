# aks-explorer Heartbeat

Use this only when asked to wake the project-local agent.

1. Read `project.md` and the unread tail of `discussion.md`.
2. Check the newest relevant artifact in `outputs/`.
3. Decide whether there is new actionable input.
4. If actionable, perform the smallest evidence-producing step.
5. If not actionable, finish with the exact reason and do not create noise.

Current project preference: final work artifacts matter more than historical session traces.
