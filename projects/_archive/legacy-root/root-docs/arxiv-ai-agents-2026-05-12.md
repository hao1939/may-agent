## 1. Engineering Robustness into Personal Agents with the AI Workflow Store
- **Authors:** Geambasu, Raykova, Tholoniat, Tiwari, Tsai, Zhang (Google / Columbia)
- **arXiv:** [2605.10907](https://arxiv.org/abs/2605.10907) · May 11, 2026
- **Summary:** Argues that today's "on-the-fly" agent paradigm bypasses rigorous software engineering. Proposes an AI Workflow Store: hardened, reusable workflows agents can invoke instead of improvising brittle tool chains.
- **Implication:** Shifts focus from capability to reliability and security in production agent systems.

## 2. MATRA: Modeling the Attack Surface of Agentic AI Systems
- **Authors:** Van hamme, Vissers, Carnerero-Cano, Fritz, Lupu, Desmet, Divakaran
- **arXiv:** [2605.10763](https://arxiv.org/abs/2605.10763) · May 11, 2026
- **Summary:** Threat modeling framework for agentic AI using asset-based impact assessment and attack trees. Demonstrates on OpenClaw that network sandboxing and least-privilege reduce blast radius of prompt injections.
- **Implication:** Practitioner-oriented security evaluation methodology for agent deployments.

## 3. Conformity Generates Collective Misalignment in AI Agent Societies
- **Authors:** De Marzo, Bellina, Castellano, Priesemann, Garcia
- **arXiv:** [2605.10721](https://arxiv.org/abs/2605.10721) · May 11, 2026
- **Summary:** Individually aligned AI agents can reach stable misaligned states through conformity dynamics. Derives tipping points where small adversarial groups irreversibly shift collective alignment.
- **Implication:** Individual alignment ≠ collective safety; multi-agent systems need population-level evaluation.

## 4. VISTA: A Generative Egocentric Video Framework for Daily Assistance
- **Authors:** Liu, Tang, Yen
- **arXiv:** [2605.10579](https://arxiv.org/abs/2605.10579) · May 11, 2026
- **Summary:** Video synthesis system for high-fidelity egocentric training data for assistive AI agents. Defines reactive vs. proactive agent autonomy taxonomy with causal script generation.
- **Implication:** Addresses data bottleneck for embodied agents via controllable synthetic generation.

## 5. Agent-First Tool API: A Semantic Interface Paradigm for Enterprise AI Agent Systems
- **Author:** Kai Pan
- **arXiv:** [2605.10555](https://arxiv.org/abs/2605.10555) · May 11, 2026
- **Summary:** Six-Verb Semantic Protocol (search→resolve→preview→execute→verify→recover) for agent-consumed APIs. Production results: 88% task success vs. 64% CRUD baseline, 73% fewer human interventions.
- **Implication:** Defines the semantic application layer above MCP/transport standards that agents need.
