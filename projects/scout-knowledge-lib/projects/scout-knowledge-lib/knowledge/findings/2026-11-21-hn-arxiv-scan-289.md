## arXiv — New Agent Architecture Papers

### OpsMem: Dual-Memory Reasoning for Failure Diagnosis
- **Paper**: OpsMem introduces short-term (diagnostic state) + long-term (operational experience) memory with "cross-memory resonance" — activating relevant long-term memory conditioned on current diagnostic state.
- **Result**: +46.88% Match, +18.39% Relevant over strongest baseline on Huawei microservice failure dataset.
- **Pattern**: Dual-memory with cross-memory activation is a concrete implementation of the compiled experience + live reasoning split. Validates that separating "what I know from past incidents" from "what I'm seeing now" and explicitly bridging them outperforms flat context approaches.
- **Implication**: Agent memory architectures converging on short-term/long-term split with explicit retrieval bridges, not monolithic context windows.
- Source: https://arxiv.org/abs/2607.11250 (approximate — from cs.AI recent submissions)

### Hierarchical Agent Orchestration with Stack-Based Execution and Lazy Discovery
- **Paper**: Formalizes agent orchestration as a pushdown automaton — capabilities organized as a rooted tree, LIFO stack for execution context, lazy-loaded child manifests. Prevents cross-branch context leakage.
- **Key insight**: Flat tool registries cause decision-space explosion. Hierarchical routing + stack frames give agents structured execution memory and branch isolation.
- **Production context**: UPI Help (digital payments support) as deployment target — regulated enterprise environment requiring isolation guarantees.
- **Pattern**: Agent-as-PDA (pushdown automaton) is a formalization of what many agent frameworks do informally. Stack-based execution = natural fit for nested tool calls.
- Source: arXiv cs.AI recent submissions (hierarchical agentic orchestration)

### PHILIA: Multi-Robot Agent with Gateway Abstraction
- **Paper**: Robot gateway decouples high-semantic agent reasoning (low-frequency) from low-level robot execution (high-frequency). Plug-and-play integration across embodiments, UIs, and policy backends.
- **Pattern**: The "gateway abstraction" — mediating between reasoning and execution at different temporal frequencies — applies beyond robotics to any agent system where planning and action operate at different speeds.
- Source: arXiv cs.AI recent submissions (PHILIA)
