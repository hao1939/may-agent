# Shared KE-001 To KE-090 Merge Batch

Date: 2026-07-09

Source scope: legacy files under `/app/shared/knowledge/entries/` whose ids are
`KE-001` through `KE-090`. The batch contains more than 90 files because early
entries had both bare numeric files and slugged duplicates.

## Result

The low-numbered KE batch is merged into Scout-owned knowledge. The old shared
files should not remain as the canonical home for this material.

Replacement locations:

- `projects/scout-knowledge-lib/knowledge/INDEX.md` keeps the compact
  operational-diary map for KE-039 through KE-090.
- This report records the full batch boundary and durable themes for KE-001
  through KE-090, including duplicate early files.
- Existing Scout notes already carry the durable concepts: agent architecture,
  runtime hardening, evaluation, multi-agent coordination, protocol standards,
  memory, and XHS trend notes.

## Source File Boundary

This batch replaces every legacy shared entry matching:

```text
/app/shared/knowledge/entries/KE-001*.md
/app/shared/knowledge/entries/KE-002*.md
...
/app/shared/knowledge/entries/KE-089*.md
/app/shared/knowledge/entries/KE-090*.md
```

The files are removed after this report and the Scout index record the
replacement. Future durable research should be written into
`projects/scout-knowledge-lib/knowledge/` as canonical-note updates, findings,
or reports, not into the old shared entry directory.

## Notes

The batch intentionally does not preserve each legacy KE as a separate Scout
file. That would keep the same clutter under a different path. The useful
knowledge is represented as topic-level Scout knowledge and this compact
provenance report.
