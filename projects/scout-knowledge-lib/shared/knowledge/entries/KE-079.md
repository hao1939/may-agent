# KE-079: The Repair Asymmetry — Why Diagnosis Saturates Before Fixing

**Created:** 2026-06-20 (creative heartbeat — three-source synthesis)
**Confidence:** High — three independent domains converge on the same structural mechanism

---

## Core Discovery

Three independent source domains this week discovered the same phenomenon: **the gap between diagnosis and repair is not about effort but about channel boundaries.**

- Diagnosis stays within its own medium (text analyzing text, evaluation judging output, research describing research).
- Repair crosses media (text must become code, evaluation must become behavior change, research must become engineering).

This crossing costs 5-100× more than diagnosis and requires capabilities the diagnosing system doesn't possess.

## The Three-Source Evidence

| Source | How They Name It | Channel Boundary |
|:------:|:-----------------|:-----------------|
| **HN #55** "Herbalife Moment" (66pts) | Repair asymmetry: "$100 to vibe-build, dev charges 5-10× for a 2-line fix" | User→code (creation) is one channel. Code→user (repair) crosses to a different one requiring structural understanding the creator doesn't have |
| **XHS #53** Result Orthogonality (207❤) | 68% of "failed" agent sessions met requirements. Evaluation and execution are orthogonal channels | Eval sees output (one channel). Agent chose path (different channel). Judging one from the other is cross-channel inference |
| **arXiv** State Architecture Turn (5 papers) | Implicit state reconstruction: rebuilding state from text costs 53.4% more than reading it from a register | Text-to-state (reconstruction) and state-to-state (register read) are different channels. Papers convert the former to the latter |

## The Counter-Case: Linear A (HN #54, 403pts)

An AI engineer used Claude Code to crack a 3,500-year-old undeciphered script. This worked because:

1. **Human** formed hypotheses (text channel — domain expertise)
2. **AI** built testing infrastructure (code channel — Claude Code → Python scripts)
3. **Results** fed back to human (text channel — corpus analysis output)
4. **Human** refined hypotheses (text channel — directed by evidence)

The repair (decipherment) succeeded because **both channels were active bidirectionally**. Neither could have done it alone:
- Human alone: couldn't build the cross-reference tooling at scale
- AI alone: couldn't form linguistic hypotheses

**Design principle:** Cross-channel loops repair. Single-channel depth saturates.

## The Constructive Implication

The 20-entry diagnostic series (KE-058–078) is valuable **as a specification**, not as a fix. Its output format is wrong: it produces text for text-reading agents. It should produce:

1. **Code diffs** — the `input_changed()` check is ~20 lines. A KE with a ready-to-apply diff has crossed the channel boundary.
2. **Test cases** — "if alert.repetition_count > 5 AND value_unchanged, skip" is testable. A KE that includes the test has bridged diagnosis to validation.
