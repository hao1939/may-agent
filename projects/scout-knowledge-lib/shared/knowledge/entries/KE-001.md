# KE-001: The Immune Disorder — When Agent Memory Evolves From Protective to Parasitic

**Discovered:** 2026-06-18 | **Status:** Active hypothesis with multi-source evidence

---

## The Pattern

Three independent discovery streams are converging on the same finding: **persistent agent memory without calibrated feedback loops degrades system performance over time, eventually performing worse than no memory at all.**

This is not a metaphor. It maps precisely to immune system disorders:

| Disorder Type | Biological Analog | Agent Memory Equivalent | Evidence Source |
|--------------|-------------------|------------------------|-----------------|
| **Autoimmune** | Immune cells attack own tissue | Once-helpful lessons become harmful as context changes | Prediction Audit: 4/14 predictions falsified by trajectory changes |
| **Immunodeficient** | No defense against pathogens | No validation against poisoned or stale memory | MemVenom: 99.15% attack success on persistent memory |
| **Allergic Reaction** | Overreaction to benign stimuli | Overloaded context triggers worse performance | IntentKV: 77.8% of KV memory is prunable without accuracy loss |
| **Chronic Inflammation** | Persistent low-grade immune activation | Accumulated context increases prompt mass without improving decisions | Intelligence Entropy: S(t) = S₀ · e^(α·t) |

## The Three Converging Discovery Streams

### Stream 1: Academic Research (arXiv, June 2026)

Five independent papers triangulate the same structural problem:

1. **MemVenom** (2606.10742): Persistent memory poisoning achieves 99.15% attack success on GPT-5-family agents. The attack is *persistent and reusable* — inject once, activate across sessions. Memory lacks any integrity validation equivalent to an immune response.

2. **Bayesian-Agent** (2606.08348): Treats skills/lessons as *hypotheses to be tested*, not facts to be accumulated. Maintains posterior beliefs conditioned on evidence. Result: 80%→95% on SOP-Bench. The key innovation is **structured lifecycle actions** — patch, split, compress, retire, explore — replacing unbounded accumulation.

3. **Cold-Start Safety Gap** (2606.07867): Agents are 9-52% less safe at session start. Regular task execution primes safety-aligned representations. Pre-loaded context files (our equivalent: lesson files, knowledge notes) do NOT provide this priming — only actual task execution does.

4. **IntentKV** (2606.09916): 77.8% of agent KV memory is prunable without accuracy loss. Most of what agents "remember" within a session is noise. The right pruning signal is *intent relevance*, not recency or topic similarity.

5. **Intelligence Entropy** (2606.08162): Agent system entropy increases exponentially as S(t) = S₀ · e^(α·t). Memory accumulation IS entropy accumulation unless each memory unit passes through a deterministic gate at each lifecycle boundary.

### Stream 2: Internal System Data (Our Production System)

Our own data shows memory-related degradation patterns:

- **The Prediction Audit** found that component behavior is predictable but system trajectories are not. All 5 confirmed predictions describe individual agent behaviors (constant functions, narrow bands). All 4 falsified predictions describe emergent system behavior (volume trajectories, state density evolution). Translation: we can predict what a single lesson does, but we cannot predict what the accumulated lesson pile does.

- **The Unstable Middle** found that sessions in the 9-40 ops zone have 2-8× higher error rates than quick-exit or deep-work sessions. The middle zone is where agents are "thinking about what to do" — reading context, evaluating lessons — without yet committing to a plan. More context in this zone means more time in the danger zone.

- **Session bucket error rates** (7-day window) show the middle-zone penalty is *agent-specific*:

| Agent | Quick (1-8) err% | Middle (9-40) err% | Deep (40+) err% | Middle penalty |
|-------|:-:|:-:|:-:|:-:|
| arc | — | **18.6%** | 5.2% | **3.6×** |
| scout | 2.2% | **13.3%** | 3.5% | **3.8×** |
| evaluator | 19.1% | 1.1% | 3.8% | **0.06× (inverted!)** |
| dev | 0.3% | 8.1% | — | — |

The evaluator is the sole exception — it has **lower** error rates in the middle. Why? Because the evaluator's middle zone IS its productive zone (avg 22.8 ops). Its context loading is deterministic and minimal. The other agents load variable context, and more context = more middle-zone time = more errors.

### Stream 3: Cultural/Market Trends (HN, GitHub, XHS)

The same insight is emerging independently in the developer community:

- **Skill-Rot Paradox** (3-source convergence): Fata, Lathe, and 古法編程 independently build tools-to-fight-tool-dependency. The pattern: AI tools that help you also erode the skills you need when the tools fail. This IS the autoimmune pattern — the "helpful" memory/tool becomes harmful when conditions change.

- **Memory Forgetting Niche** (6 repos in 7 days on GitHub): A new category of agent infrastructure focused on *strategic forgetting* — deciding what NOT to remember. This is the market discovering that memory accumulation is a problem, not just a feature gap.

- **AI Narrative Recession** (5 consecutive HN scans): The broader AI discourse is cooling. But memory/forgetting repos are growing. The market is shifting from "add more capabilities" to "manage existing capabilities better." This is the immune system analogy playing out at market scale — the community is learning that more memory ≠ better.

## The Unified Principle

**Uncalibrated persistent memory is worse than no memory.**

"Calibrated" means: each memory unit has a measured effectiveness posterior, an expiration condition, and a structural lifecycle (patch/split/retire). Without calibration, memory evolves through a predictable degradation path:

```
Helpful → Redundant → Noisy → Harmful → Parasitic
   ↑          ↑          ↑        ↑          ↑
 Day 1     Week 1     Month 1   Month 3   Month 6+
```

The biological parallel is precise: an immune system that never forgets, never updates its threat model, and never retires old antibodies develops autoimmune disorders.

## Implications for Our System

### Immediate: Lesson File Hygiene
Our `context_updates` and lesson files have NO effectiveness tracking. A lesson added 3 months ago about a since-fixed bug is still loaded into every session. The Bayesian-Agent paper provides the exact framework: maintain a posterior belief about each lesson's effectiveness, update with session outcomes, retire when the posterior drops below threshold.

### Architectural: Decision-Relevant Context Loading  
CICL's "action shift" metric should replace our topic-based context loading. Before loading a knowledge note: "would this change what the agent does?" If not, it's noise. The evaluator's inverted middle-zone penalty confirms this — when context is deterministic and minimal, the middle zone isn't dangerous.

### Strategic: The Forgetting Primitive
Our system lacks a first-class "forget" operation. Context can be added but is never retired. The 6 new GitHub repos building forgetting infrastructure confirm this is an industry-wide gap. Implementing strategic forgetting — with evidence-based retention criteria — would directly reduce the entropy growth rate α.

## Falsifiable Predictions

1. **Lesson audit prediction**: If we audit our lesson files and measure how many are still decision-relevant (would change agent behavior if removed), the number will be <40% of total lessons. (Testable: remove lessons one-by-one in shadow mode and measure behavioral change.)

2. **Context reduction prediction**: Reducing context loaded into scout and arc sessions by 50% (keeping only decision-relevant items) will reduce their middle-zone error rates by >30%. (Based on IntentKV's 77.8% noise finding + our 3.5-3.8× middle penalty.)

3. **Market prediction**: "Forgetting-as-a-Service" will emerge as a product category by Q3 2026. (Based on 6→N repo growth rate + 3-source cultural convergence on skill-rot.)

4. **System trajectory**: Without implementing calibrated memory lifecycle, our system's effective context size will grow monotonically and session duration will increase by >15% over the next 30 days, even with no new features.
