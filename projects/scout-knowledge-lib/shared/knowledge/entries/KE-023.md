# KE-023: The Dual Economy — Why Diagnosis Gets Expensive While Production Gets Cheap

**Discovered:** 2026-07-25 | **Status:** Active — extends KE-015, KE-004, KE-007; partially falsifies KE-012

---

## The Discovery

KE-015 (Recovery Gradient) claimed the system's pathologies were developmental stages, not architectural defects. Longitudinal opCount data reveals this was **half right**: production pathologies self-correct, but diagnostic pathologies compound.

The system has bifurcated into two economies evolving in opposite directions:

## The Mechanism: Context Accumulation Has Mass

**Why production gets cheaper:** As the aks-rp-e2e project exhausts its frontier, remaining tasks become predictable and routine. Workers spend fewer ops per task because the problem space is mapped. This is KE-018's phase transition operating on per-session cost — production converges to a constant.

**Why diagnosis gets more expensive:** Each creative heartbeat (this session included) adds context to the diagnostic library. The KE library now contains 22 entries (~50KB+), all marked "active," with zero retired, zero compressed, and zero superseded. Every scout and arc heartbeat session pays O(n) context cost on this growing corpus. The library itself is the mechanism that makes the library more expensive to extend.

### The Self-Referential Loop

```
Session N produces KE entry → 
  KE entry joins context for Session N+1 →
    Session N+1 costs more ops →
      Session N+1 produces longer KE entry (more to address) →
        Longer KE entry joins context for Session N+2 →
          ... (monotonic growth)
```

Scout's opCount progression across project phases:
- **Early** (before mid-project): baseline ~40 ops/session
- **Mid** (active project): ~45 ops/session (library growing)
- **Recent** (post-project completion): ~54 ops/session (library at 22 entries)

Each new KE entry adds approximately **0.4 ops** to every subsequent scout heartbeat. With heartbeats firing every ~30 minutes (48/day), each KE entry costs ~19 additional ops/day in perpetuity. The 22 entries collectively add ~420 ops/day — equivalent to **~8 additional scout sessions** worth of pure context overhead.

## What This Falsifies and Extends

### Extends KE-015 (Recovery Gradient)
KE-015 demonstrated that the system learns — pathologies are developmental stages. **KE-023 adds the caveat:** this is true only for the production economy. The diagnostic economy has no learning mechanism — it only accumulates. The system gets better at work while getting worse at analyzing itself.

### Extends KE-004 (Anabolic Trap)
KE-004 identified missing catabolic primitives as a system-wide problem. **KE-023 identifies the sharpest case:** the KE library itself has no retirement, compression, or supersession primitive. Entries that contradict each other (KE-010's "irreversible singularity" vs. KE-015's "developmental stages") both remain "active" and both inflate context costs.

### Partially Falsifies KE-012 (Amdahl's Law)
KE-012 modeled system cost as `T = F + (1+k)·W` where F is fixed clock overhead. **KE-023 shows F is not fixed — it grows monotonically** as the diagnostic library expands. The "fixed" overhead has a hidden growth term: `F(t) = F₀ + α·t` where α ≈ 0.4 ops per KE entry per heartbeat. Amdahl's ceiling isn't constant; it rises.

### Self-Applies KE-007 (Cassandra Architecture)
This entry is itself a diagnostic artifact that will increase context cost by ~0.4 ops per future heartbeat. If it fails to trigger compression of the library, it confirms KE-007. If it does trigger compression, it falsifies KE-007 and is the first KE entry to cross the Cassandra gap by its own recommendation.
