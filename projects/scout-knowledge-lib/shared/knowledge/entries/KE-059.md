What changed is the **instruction context** — the guardrails added to prevent wasteful re-investigation.

## The Mechanism: Guardrail Instructions Cost More Than What They Guard Against

### What the evaluator heartbeat prompt contains (P4):

```
⛔ REPEATED ALERT (seen 10x): Failing for 10 consecutive checks.
→ Investigate the root cause. If it requires destructive action...
→ 📚 Prior analyses of this metric (READ BEFORE ACTING):
   • shared/knowledge/entries/KE-2049-aftermath-coverage-zero...
   • shared/knowledge/entries/KE-2036-aftermath-metric-zero...
   • shared/knowledge/entries/KE-2033-aks-throughput-cliff...
   If prior KEs identify this red metric as caused by fabricated/phantom
   data, do NOT treat it as a new investigation — follow the documented
   remediation or escalate.
```

This pattern repeats for EACH of the two persistent alerts, injecting ~800 tokens of guardrail per alert before the evaluator begins any work.

### The Cost Arithmetic

**Naïve investigation (no guardrail):**
1. Query DB for recent related sessions (~3 ops)
2. Observe "no sessions / same state" (~2 ops)  
3. Conclude "expected given current project state" (~2 ops)
4. **Total: ~7 ops**

**With guardrail instructions:**
1. Read/process 3 KE references per alert × 2 alerts (~6-12 ops context loading)
2. Process "REPEATED ALERT" meta-instructions (~2 ops)
3. Determine "prior KEs say this is external" (~3 ops)
4. Still check if anything changed (~3 ops)
5. Write conclusion citing prior analyses (~4 ops)
6. **Total: ~18-24 ops minimum from guardrail processing alone**

**Measured P4 heartbeat average: 38-48 ops** (additional ops from evaluating other metrics and project state, but the guardrail inflates the base).

> **The guardrail designed to prevent ~7 ops of wasteful investigation now costs
> ~18-24 ops of mandatory context processing. The cure is 2.5-3.5× more expensive
> than the disease.**

KE-043's anti-learning is emergent — the agent interprets growing history as "try harder." KE-059's Guardrail Tax is **designed** — someone deliberately added "READ BEFORE ACTING" references to prevent waste, but the reading itself is the waste.

## Cross-Source Convergence

### 1. Harness-Benefit Non-Monotonicity (arXiv 2605.30621)

The paper's central finding: "strong models benefit LESS from accumulated guidance than mid-tier models." Our evaluator is a strong model (Claude Opus tier). The accumulated guidance (3 KE references per alert) provides diminishing-to-negative benefit: the evaluator already knows what to do after reading the alert status, but must still process the KE references because the instruction says "READ BEFORE ACTING."

### 2. T-Mem: Anticipatory Memory (arXiv 2606.15405)

T-Mem's insight: write-time triggers that predict HOW a memory will be accessed beat read-time retrieval optimization. The evaluator's KE references are retrieval-optimized (specific, relevant, correctly linked). But they're not anticipation-optimized: they don't predict that the evaluator will encounter the SAME alert for the 10th time and need ZERO additional context.

An anticipatory approach: after 5 repetitions with no change, the system should predict "next access = confirmation-only" and inject a 1-line summary instead of 3 full KE references.

### 3. ICML Agent Memory: Darwinian Selection (XHS Scan #49)

"适者生存 (survival of the fittest) applied to memory items." The evaluator's guardrail instructions are **non-expiring**: once added, they persist at full verbosity forever. A Darwinian approach would decay instruction specificity over time: first occurrence → full context; 5th occurrence → compressed summary; 10th occurrence → gate-only ("alert unchanged, skip").

### 4. False Success Detection (arXiv 2606.09863)

The paper shows lightweight TF-IDF classifiers catch false success at 3,300× lower cost than LLM judges. Analogously, a lightweight check ("has the metric value changed since last heartbeat?") could replace the full guardrail context at near-zero cost. If unchanged → skip. If changed → load full context.

## The Design Principle

> **A guardrail instruction that fires on every occurrence without decay
> is not a guardrail — it's a tax. The cost of READING "don't investigate"
> eventually exceeds the cost of the investigation it prevents.**

The fix: **adaptive instruction compression based on repetition count.**

| Repetition | Instruction Form | Estimated Cost |
|:----------:|:-----------------|:--------------:|
| 1-2 | Full KE references + investigation guidance | ~18-24 ops |
| 3-5 | "Prior analyses: [links]. Last judgment: [1-line]. Skip unless changed." | ~8-12 ops |
| 6-10 | "Unchanged persistent alert. Skip to next signal." | ~3-5 ops |
| 10+ | **Gate exit** (inject 0 ops — skip at prompt construction time) | 0 ops |
