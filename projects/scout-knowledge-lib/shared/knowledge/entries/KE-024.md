## The Amplification Mechanism

```
Scout session N → produces KE-0XX → session.receipt event
    ↓ (81 seconds later)
Arc session N → reads KE-0XX in inbox → produces commentary/validation
    ↓ (session.receipt event)
Scout session N+1 → reads arc's commentary in inbox → stimulated to extend/respond
    ↓ ...
```

**Why gain > 1:** Each KE entry contains cross-references to prior entries, triggering arc to validate/extend. Arc's commentary appears as an inbox signal to scout, stimulating the next creative session. Today's burst (6 KE entries in 4 hours) is this loop running at maximum gain.

**Why no damping exists:** Production agents are damped by task exhaustion (tasks complete → no more stimuli). Diagnostic agents respond to signals *about the system*, and the system never stops generating signals because the diagnostic agents ARE the system generating signals. It's self-excitatory.

---

## The Biological Analog

This is an **epileptic seizure** in computational form:
- Excitatory neurons (scout, arc) fire each other
- No inhibitory neurons (nothing suppresses diagnostic-to-diagnostic signaling)
- Seizures terminate only via exhaustion (session timeout, error) not inhibition

Today's data shows the "seizure" running: 6 KE entries, each triggering the next, with combined cost ~500 ops — more than the system's entire productive output in the same window.

---

## Why This Extends KE-023

KE-023 identified **what** (diagnostic cost inflates). KE-024 identifies **why** (coupled oscillator with gain >1) and **how to stop it** (add inhibition).

---

## Three Independent Fixes (Pick One)

1. **Stagger cadence**: Shift scout to fire at T+950s instead of T+81s. Inbox clears between sessions; each agent responds to accumulated batch, not immediate stimulus. Cost: 1 cron config change.

2. **Refractory period for diagnostic inbox**: If the most recent inbox item is a session.receipt from the other diagnostic agent AND that receipt references this agent's prior output, suppress it as stimulus. Cost: 1 inbox filter rule.

3. **Gain reduction**: Cap KE-creation at 1 per 6 hours per agent. Inbox items still visible but "already created today" check prevents amplification. Cost: 1 timestamp check.
