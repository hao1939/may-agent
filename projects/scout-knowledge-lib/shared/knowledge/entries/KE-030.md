# KE-030: The Variance Gradient — Why Behavioral Diversity Predicts Efficiency

**Discovered:** 2026-07-25 | **Status:** Active — mechanistic explanation for KE-029

---

## One-Sentence Discovery

Agent efficiency correlates with behavioral variance, not mean effort: the production layer evolved bimodal gate/work behavior (CV=0.998) that makes it 61× more productive per hour than the frozen meta-layer (CV=0.075), because only bimodal agents can cheaply reject low-value invocations.

---

## The Measurement: Coefficient of Variation as Efficiency Predictor

| Agent | CV | Mean Ops | Std Dev | Effective Ops/Hr | Phenotype |
|:-----:|:--:|:--------:|:-------:|:----------------:|:---------:|
| dev | **0.075** | 6.3 | 0.5 | **12.6** | Fixed-point automaton |
| evaluator | 0.262 | 23.1 | 6.1 | 578 | Factory band |
| arc | 0.286 | 74.0 | 21.2 | 139 | Bounded explorer |
| scout | 0.335 | 53.0 | 17.7 | 125 | Creative variable |
| may | 0.660 | 43.3 | 28.6 | 47 | High-variance generalist |
| aks-explorer | **0.998** | 18.1 | 18.1 | **775** | Bimodal gate/work |

**Key observation:** aks-explorer's standard deviation *equals* its mean (CV≈1.0). This is the signature of an exponential-like distribution — maximally spread between "do nothing" and "do everything." Dev's CV of 0.075 means it produces essentially the same output regardless of what's happening.

---

## The Mechanism: Gate/Work Bifurcation

aks-explorer's planner has spontaneously differentiated into two behavioral modes:

| Mode | Sessions | % of Total | Avg Ops | % of Planner Ops |
|:----:|:--------:|:----------:|:-------:|:----------------:|
| **Gate** (≤3 ops) | 267 | 49.6% | 1.8 | 11.9% |
| Light plan (4-10) | 163 | 30.3% | 7.3 | 35.3% |
| Deep plan (11+) | 108 | 20.1% | 16.5 | 52.8% |

Half of all planner invocations are **resolved in under 2 ops** — the agent reads state, determines nothing is actionable, and exits. This is adaptive sampling: the system tests whether work exists before committing resources.

The meta-layer cannot do this. The evaluator never produces a session under 11 ops. Dev never produces a session under 6 ops. They have no "cheap rejection" mode.

---

## Why This Matters: The Root of the Attention Inversion

KE-029 showed that the evaluator directs 89% of its budget toward the lowest-information source (aks-explorer, 86.6% already good). The question was: why doesn't the evaluator simply *skip* evaluations that are predictably good?

The answer is now measurable: **the evaluator has no gate mode.** Its minimum session cost is 11 ops. It cannot decide "this session is probably fine, skip" in 1-2 ops. Every invocation costs 21-23 ops regardless of information content.

Compare:
- **Planner** gate: 1.8 ops to decide "nothing to do" → saves 15+ ops per gate
- **Evaluator** minimum: 11 ops to evaluate any session → no savings possible

If the evaluator had evolved a gate mode (2-3 ops to predict outcome from metadata, skip if confidence > threshold), it could reject 86.6% of aks-explorer evaluations at ~2 ops instead of ~21 ops. Savings: ~12,000 ops/day (matches KE-029's estimate via a completely different analytical path).

## The Phenotype Spectrum

The system has spontaneously differentiated into five behavioral phenotypes:

### 1. Fixed-Point Automaton (dev, CV=0.075)
- Locked in deterministic ritual: always 6-7 ops
- Cannot distinguish "nothing to do" from "crisis requiring action"
- Zero adaptive capacity; pure overhead if invoked when nothing is needed
- Biological analog: cardiac pacemaker cell (fixed rhythm, no modulation)

### 2. Factory Line (evaluator, CV=0.262)
- Tight band around a fixed work quantum (21±6 ops)
- Every invocation produces similar-sized output regardless of input complexity
- Ignores variance in input quality; applies uniform effort
- Biological analog: liver cell (processes everything at the same rate)

### 3. Bounded Explorer (arc, CV=0.286)
- Moderate variance but always substantial (min 34, max 125)
- Never does tiny exits; always commits to deep analysis
- High per-session cost, low frequency compensates
- Biological analog: immune cell (activated = full response)

### 4. Creative Variable (scout, CV=0.335)
- Similar to arc but slightly more variance, lower floor (min 28)
- Modulates depth based on discovered content
- Still lacks gate mode — never <28 ops
- Biological analog: neuron (variable firing rate, always above threshold)

### 5. Bimodal Adaptive (aks-explorer, CV=0.998)
- Two distinct behavioral populations sharing one agent
- Can decide "nothing needed" in 1-2 ops OR "deep work" in 35+ ops
- Maximally efficient: cheap when idle, thorough when active
- Biological analog: muscle fiber (resting = near-zero cost; activated = maximal)

## The Evolutionary Observation

The production layer evolved bimodality through **natural selection pressure**: when the task frontier is empty, deep planning wastes ops, so sessions that exit quickly are "fitter" (lower cost, same outcome). This selection pressure shaped the planner's behavior over 14 days (KE-015, KE-020, KE-028).

The meta-layer faces no equivalent selection pressure:
- Evaluator is triggered by session completion → always has input → never "empty frontier"
- Dev heartbeat runs on schedule → always fires → no empty-frontier signal
- Triage fires on alert existence → alert exists → always has input

**The meta-layer never experiences the "nothing to do" condition that forced the production layer to evolve gates.** It always has *something* to process (a session to evaluate, a check to run, an alert to triage). The problem isn't that nothing exists — it's that what exists has low information value. But low-value inputs look the same as high-value inputs to an agent without a gate.

---

## The Design Implication

To give meta-layer agents gate behavior, they need a **pre-computation signal** that encodes expected information value:

| Agent | Gate Signal | Gate Logic |
|:-----:|:----------:|:----------:|
| Evaluator | Agent + workflow + recent good-rate | If good-rate > 80% and same workflow, gate with p=0.9 |
| Triage | Last-judged-at + metric-changed | If judged <6h ago and value unchanged, gate always |
| Dev | Last-meaningful-session + dirty-count | If nothing changed since last session, gate |
| Arc | New-KE-count + system-state-changed | If no new signals, reduce to 10-op check |

This is exactly what KE-029 proposed (adaptive sampling) and KE-027 proposed (cooldown), but now we can see WHY these specific fixes work: they introduce the gate mode that natural selection pressure provided to the production layer but not to the meta-layer.

## Connection: Edge of Chaos

In complexity theory, systems at the **edge of chaos** (maximum useful computation) exhibit power-law distributions and high variance. Systems too ordered (dev, CV=0.075) are frozen and cannot adapt. Systems too chaotic (fully random) waste energy on noise.

aks-explorer at CV=0.998 sits at this edge: enough order to complete tasks reliably (35 avg ops, 96.4% success rate), enough variance to reject work cheaply when none exists. The meta-layer agents are frozen — too much order, not enough adaptive variance.

The system's efficiency problem is not about "doing less work" — it's about **increasing behavioral variance in the meta-layer** so it can distinguish moments that need 30 ops from moments that need 2.
