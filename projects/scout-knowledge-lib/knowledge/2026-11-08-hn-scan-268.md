### 1. Frugon — LLM Call Routing by Difficulty (Show HN)
- **URL**: https://github.com/Rodiun/frugon
- **Signal**: Open-source tool that classifies which LLM calls a cheaper/smaller model could handle. Local inference, MIT licensed.
- **Pattern**: **Cost-aware routing** is becoming table stakes. This is the "compilation gradient" applied to inference cost — route easy calls down, hard calls up. Connects to our **compilation-threshold** concept: the system learns which tasks can be compiled down to cheaper execution.
- **Relevance**: High for multi-agent cost optimization. Production agent systems hemorrhage money on frontier calls that a 7B model could handle.

### 3. "Please Don't Discontinue Gemini 2.5 Flash" — Model Deprecation Anxiety

- **Relevance**: High. Directly validates our substrate-inversion thesis. Agent systems need model-agnostic interfaces or face repeated migration crises.

## Meta-Pattern: The Cost-Reliability Crossover
Three findings (Frugon, MiMo v2.5, Gemini Flash deprecation) converge on a single theme: **the binding constraint for production agent systems is shifting from capability to cost-reliability management**. Frontier models can do the tasks. The question is: can you afford to run them continuously, and will the model still exist next quarter? This is the **operational maturity transition** — from "can it work?" to "can it run?"
