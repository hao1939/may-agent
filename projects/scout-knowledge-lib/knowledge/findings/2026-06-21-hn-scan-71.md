# HN Scan #71 + arXiv Cross-Source (2026-06-21, evening)

## 🧬 THE COMPOSITION BOUNDARY — New Synthesis

Seven independent sources from the past 72 hours converge on the same structural insight: **evaluating, securing, or trusting individual units is fundamentally insufficient because harmful/failing behavior emerges only at composition time**. Per-unit correctness does NOT compose to system-level safety.

### Evidence Stack:

1. **TRAP — Privacy Impossibility Result** (2606.18996)
   For ANY softmax-based model, no prompt-based defense can jointly achieve high task success with zero privacy leakage probability. This is a mathematical impossibility proof, not an empirical finding. All 22 models tested leak. Instruction-following ability CORRELATES with leakage rate — the more capable the agent, the more vulnerable. Resolution: "structural private field isolation" (hash keys replacing fields before model sees them). The behavioral layer is provably bounded.

2. **SCR-Bench — Skills Benign Alone, Harmful Composed** (2606.15242)
   Skill Composition Risk: three attack families (CapFlow 33.6% ASR, TrustLift 96.5% ASR, AuthBlur +71.8% risky-approval) all show near-zero risk under isolated evaluation. Harmful behavior is INVISIBLE at the individual skill level and only materializes when skills share execution context along activated paths. Security must be assessed at path-level, not artifact-level.

3. **Cordon — Semantic Transactions as Containment** (2606.17573)
   Agent runtimes expose tools as isolated RPCs, but failures compose ACROSS calls. Introduces task-scoped execution boundaries with commit/rollback/recovery semantics: shadow state for reversible mutations, effect outbox for staged external actions, recovery metadata for audit. Key finding: "Cordon exposes cross-step violations missed by existing defenses." This is the containment primitive the Orchestration Hollowing (#65) identified as missing.

4. **ProvenanceGuard — Cross-Source Conflation** (2606.18037)
   A claim can be "supported somewhere" while being attributed to the WRONG source. Standard factuality metrics (pooled evidence) miss this. Source attribution is an independent verification axis — you can be factually correct and provenance-wrong simultaneously. Block F1 0.802, source accuracy 0.858 on per-claim routing.

5. **SafeClawBench — Semantic Pass ≠ Sandbox Harm** (2606.18356)
   In 12,000-row matched analysis, 291 of 347 observed sandbox harms occur in rows that PASS the semantic safety check. The model says the right thing, but the system still does the wrong thing. Three separate endpoints needed: semantic acceptance, audit-evidence harm, sandbox-observed state change. Single-number ASR conflates fundamentally different failure modes.

6. **ContractGuard / RACG — Contract Integrity as Load-Bearing** (2606.18550)
   Effect forgery is strictly more dangerous than risk-label tampering because it operates at a DIFFERENT composition layer (causal gate vs admissibility gate). The security assumption isn't at the model or the tool — it's at the CONTRACT that mediates between them. Composition vulnerability lives in the interfaces, not the components.

7. **"Before the Pull Request" / grite — Pre-Composition Coordination** (2606.19616)
   Agent PRs are produced faster but accepted less often — the failure signal lives BEFORE the PR in how agents claim, divide, and collide. Without coordination substrate: 78% duplicate work. With it: 0% duplication, 3x throughput. Coordination failures are invisible in PR-level telemetry (the composed output). You must instrument the pre-composition process.

### Meta-Pattern: Why Composition Boundaries Are Load-Bearing

The Composition Boundary unifies several prior observations:
- **Hardening Stack** (#63): identified 8 layers needing hardening, but didn't address cross-layer emergence
- **Diagnostic Refinement** (#64): showed aggregate metrics conceal structured failures, but within layers
- **Orchestration Hollowing** (#65): identified containment (not orchestration) as the missing primitive
- **Curation Bottleneck** (#69): per-instance quality gates work; population-level quality doesn't follow

**This scan's contribution**: The binding constraint isn't per-layer quality but BETWEEN-layer composition. Systems composed of individually-correct components can exhibit:
- Emergent privacy violations (TRAP impossibility)
- Emergent security failures (SCR-Bench composition attack)
- Emergent state harm despite semantic correctness (SafeClawBench)
- Emergent provenance errors (ProvenanceGuard conflation)
- Emergent coordination waste (grite duplication)

**Resolution architecture** (from the papers themselves):
- Structural isolation over behavioral isolation (TRAP hash-key approach)
- Path-level evaluation over artifact-level evaluation (SCR-Bench)
- Transaction boundaries over per-call guards (Cordon)
- Source-routing over pooled-evidence (ProvenanceGuard)
- Staged endpoints over single-number metrics (SafeClawBench)
- Signed event logs over output-level telemetry (grite)
