## ★★★★ High Relevance

### [2607.14651] MemPoison: Uncovering Persistent Memory Threats and Structural Blind Spots in LLM Agents
- **Source**: https://arxiv.org/abs/2607.14651
- **Published**: 2026-07-16
- **Summary**: Comprehensive benchmark (1,227 cases) for memory poisoning attacks on agents. Three-tier taxonomy: L1 direct corruption, L2 compositional multi-record corruption, L3 context-triggered dormant corruption. Key finding: write-time consistency checks block L1 but fail against L2/L3. Mechanistic influence decomposition reveals structural blind spots where benign-looking records become harmful through joint retrieval or trigger activation.
- **Implication for us**: Directly relevant to any agent with persistent memory. The L2/L3 taxonomy (compositional and dormant attacks) validates the need for read-time/retrieval-time defenses, not just write-time filtering. Our guard architecture should consider memory retrieval as an attack surface, not just memory writes.

### [2607.14611] Bad Memory: Evaluating Prompt Injection Risks from Memory in Agentic Systems
- **Source**: https://arxiv.org/abs/2607.14611
- **Published**: 2026-07-16
- **Summary**: Studies prompt injection in memory-based agents (Claude Code, OpenAI Codex) across Claude Haiku 4.5, Claude Opus 4.7, GPT-5.2, GPT-5.5. Key finding: hard to make agents overwrite their own memory via untrusted content, BUT payloads already planted in memory files successfully attack current and future sessions. Persistence and success vary by model/system.
- **Implication for us**: The "planted payload" finding means memory integrity at rest is critical. If an attacker can get content into memory files once (even via a legitimate-seeming interaction), it persists as a weapon across sessions. Validates memory-as-attack-surface thinking.

### [2607.14890] Proof-or-Stop: Evidence-Gated Lifecycle Control for Autonomous Agents
- **Source**: https://arxiv.org/abs/2607.14890
- **Published**: 2026-07-16
- **Summary**: Treats agent outputs as *claims* rather than lifecycle states. Lifecycle transitions (reviewed → tested → done → merge-ready) require fresh, mechanically verifiable evidence bound to tracked source state. Implementation: receipt bundles rejected 18 tamper classes with zero false accepts. Ablation shows enforcing review-as-gate (not just adding a reviewer) reduces false-DONE amplification from 1.7% to 0.1%.
- **Implication for us**: This is architecturally aligned with our guard/review patterns. The key insight—"review as a gate, not review as an observer"—maps to our lifecycle enforcement. The receipt-bundle pattern (cryptographic evidence of gate passage) is a concrete implementation we could adopt for trust chains in multi-agent workflows.

### [2607.14275] AI Agents Do Not Fail Alone: The Context Fails First
- **Source**: https://arxiv.org/abs/2607.14275
- **Published**: 2026-07-15
- **Summary**: Validates context-engineering quality as a *leading indicator* of agent reliability. Seven measurable criteria: role clarity, guardrail coverage, instruction consistency, tool schema quality, grounding sufficiency, injection hardening, token efficiency. Uses multi-juror consensus scoring. Key finding: grounding sufficiency predicts hallucination resistance; guardrail coverage predicts manipulation resistance; instruction consistency predicts instruction following.
- **Implication for us**: Provides a validated measurement framework for context quality as a preflight check. The isolation of context score from behavioral metrics (non-circular validation) is methodologically rigorous. We could use these seven criteria as a self-audit checklist for our agent prompts/contexts.

## ★★★ Moderate Relevance

### [2607.13591] Memory as a Controlled Process (MemCon): Learned Adaptive Memory Management for LLM Agents
- **Source**: https://arxiv.org/abs/2607.13591
- **Published**: 2026-07-15
- **Summary**: Models memory operations (retrieve, inject plan, consolidate, forget) as an MDP. Learns online policy via lightweight contextual bandit (no extra LLM calls, converges in tens of tasks). Backend-agnostic wrapper. Up to +15.2 points task success, 5–20% token reduction across 6 benchmarks.
- **Key insight**: Memory behavior should be context-dependent—sparse memory → minimal retrieval; recurring goals → plan reuse; stuck states → re-retrieval with alternative queries. Fixed heuristics are the bottleneck.
- **Implication for us**: The "memory as controlled process" framing is relevant to our session memory architecture. The bandit approach (learn when/what to retrieve from binary task feedback) is lightweight enough to be practical.

### [2607.14309] Traccia: An OpenTelemetry-Based Governance Platform for AI Systems
- **Source**: https://arxiv.org/abs/2607.14309
- **Published**: 2026-07-15
- **Summary**: Multi-level AI governance stack built on OpenTelemetry. Adds passive semantic guardrail assessment, execution lineage, and hashed trace ledger. Auto-generates compliance evidence (SHA-256 content hash mapped to EU AI Act articles). Addresses alignment drift, shadow AI, SaaS security.
- **Implication for us**: The "compliance evidence as a byproduct of telemetry" pattern is interesting for governance. Lower priority but worth tracking as the governance tooling space matures.

### [2607.14037] Early Adoption of Agentic Coding Tools by GitHub Projects
- **Source**: https://arxiv.org/abs/2607.14037
- **Published**: 2026-07-15
- **Summary**: Empirical study of 25,264 agentic PRs across 2,361 repos. Findings: median repo generates only 1–2 agentic PRs in 3 months; small projects (1–5 contributors) show higher participation ratios; human-agent collaboration dominated by single-human oversight (one dev reviews agent PRs); multi-human collaboration rare.
- **Implication for us**: The "single-human oversight bottleneck" finding is interesting—it suggests current adoption patterns recreate the same single-point-of-failure that multi-agent architectures aim to solve. The finding that small teams adopt more readily matches intuition about coordination overhead.

## Thematic Observations

**Memory security is having a moment.** Two independent papers (MemPoison, Bad Memory) on the same day both targeting memory-as-attack-surface, from different angles (systematic taxonomy vs. empirical red-teaming of production systems). This suggests the field is waking up to persistent memory as a first-class security concern.

**Evidence-gated control is crystallizing.** Proof-or-Stop and the Context-Fails-First paper both push toward "measure before you trust"—one at the lifecycle level (don't trust DONE claims), the other at the context level (measure context quality as a preflight). These complement each other: context quality predicts whether the agent will behave; evidence gates verify that it did.
