## ★★★★ High Relevance

### [2607.13591] Memory as a Controlled Process (MemCon)
- **Published**: 2026-07-15
- **Summary**: Models memory operations as a Markov Decision Process — learns an online policy that decides *when, what, and how much* to retrieve, when to inject distilled plans, and when to consolidate or forget. Uses a lightweight tabular contextual bandit with UCB exploration; converges in tens of tasks. Backend-agnostic wrapper around any memory system.
- **Key finding**: Up to 15.2 points improvement in task success while reducing tokens 5–20%. Static memory heuristics are the bottleneck — adaptive retrieval that changes with task phase dominates.
- **Implication**: Directly validates our "memory as controlled process" thesis. The lightweight bandit approach (no extra LLM calls) is a practical pattern for any agent framework.

### [2607.13987] Agent Skill Security: SkillSec-Eval
- **Published**: 2026-07-15
- **Summary**: Lifecycle-aware security framework for reusable agent skills. Maps threats across repository admission, semantic retrieval, planner selection, execution, and skill evolution. Evaluated on 327 real-world skills.
- **Key finding**: Vulnerabilities arise at *every lifecycle stage*, not just execution. Repository admission and semantic retrieval are under-defended attack surfaces.
- **Implication**: Extends our security thinking beyond prompt injection and runtime — the skill supply chain is a distinct threat surface. Connects to our "delegation surface" concept.

### [2607.14004] Do Agent Optimizers Compound? (RELAI-VCL)
- **Published**: 2026-07-15
- **Summary**: Tests whether agent-optimization gains persist when applied recursively on new tasks. Two-phase continual-learning eval on Terminal-Bench 2.0. GEPA transfers *below baseline*, Meta Harness stalls, only RELAI-VCL (with regression control) compounds gains (76.4% vs 58.7% baseline).
- **Key finding**: Optimization gains compound *only* when regression control is built into the optimization loop. Without it, shortcut solutions fail to generalize.
- **Implication**: Critical finding for agent self-improvement — naive optimize-and-deploy cycles can *degrade* performance. Regression testing is structural, not optional.

### [2607.13594] Safety Sentry: EXECUTE-ASK-REFUSE Routing
- **Published**: 2026-07-15
- **Summary**: Reframes agent guardrails as per-instance three-way routing (execute/ask/refuse) instead of binary safe/unsafe. Single decoding-time threshold lets one checkpoint be repositioned across deployments without retraining.
- **Key finding**: Three-way routing outperforms binary guard models on both accuracy and safety recall while controlling both error directions simultaneously.
- **Implication**: Validates our "deference spectrum" concept — the ASK channel prevents the alert-fatigue problem where users wave through consequential warnings.

## ★★★ Moderate Relevance

### [2607.12216] RCWT: Measuring Task-Budget Displacement from Coordination Content
- **Published**: 2026-07-13
- **Summary**: Controlled protocol measuring how coordination content (shared state, role instructions, tool outputs) displaces task budget in fixed-context LLM calls. Models degrade sharply when residual task evidence falls to ~few hundred tokens. Intact-task ablation confirms the cliff is displacement, not semantic interference.
- **Key finding**: The coordination overhead problem is *task-budget displacement*, not attention corruption. Every coordination token literally steals from task evidence.
- **Implication**: Quantifies the "coordination tax" we've theorized. Provides a measurement primitive for context-allocation budgeting in multi-agent systems.

### [2607.13359] LAMaS: Latency-Aware Multi-Agent Orchestration
- **Published**: 2026-07-15
- **Summary**: Learns latency-aware execution graphs through critical-path-aware credit assignment. Runtime controller adaptively eliminates redundant agent interactions. 50%+ latency reduction while maintaining accuracy.
- **Key finding**: Optimizing for latency requires critical-path reasoning, not just cost reduction. Naive latency optimization misassigns credit and degrades accuracy.
- **Implication**: Practical orchestration pattern — latency as first-class optimization target for multi-agent systems.

### [2607.14037] Early Adoption of Agentic Coding Tools on GitHub
- **Published**: 2026-07-15 | KDD 2026 Workshop
- **Summary**: Analysis of 25,264 agentic PRs from 2,361 GitHub repos. Median repo generates only 1–2 agentic PRs in 3 months. Small projects (1–5 contributors) show higher participation ratios. Human-agent collaboration dominated by single-human oversight model.
- **Key finding**: Agent coding tool adoption is concentrated in a small subset of projects. Multi-human collaboration with agents remains uncommon. Organizational processes, not just agent capabilities, gate integration.
- **Implication**: Empirical evidence for the "organizational accommodation" thesis — successful agent integration depends on human process design.

### [2607.14006] Rethinking Pen Testing for AI-Enabled Systems
- **Published**: 2026-07-15
- **Summary**: Reframes pen testing as objective-driven behavioral evaluation. Defines AI-enabled penetration as feasible induction of behavior violating operational objectives under explicit threat model. Covers prompt injection, retrieval poisoning, tool misuse, agentic misalignment.
- **Implication**: Useful framing — shifts security evaluation from "can you break in" to "can you cause behavioral objective violation."

### [2607.13940] HealthClaw: Self-Evolving Agent with Longitudinal Memory
- **Published**: 2026-07-15
- **Summary**: Agent architecture separating shared safety rules from private longitudinal memory. Post-episode induction decides what updates profile, revises procedures, remains episodic, or gets excluded. 71.7% lower context exposure vs full-history prompting.
- **Implication**: The memory triage pattern (profile/procedure/episodic/exclude) is a clean architecture for any longitudinal agent.

### [2607.12077] Graph Feedback Controls Consensus in LM Populations
- **Published**: 2026-07-13
- **Summary**: Studies convention formation in open-weight LM populations. Bridge-seeking routing repairs fragmentation; homophilous routing amplifies it. Retained history shifts dynamics toward consensus.
- **Implication**: Interaction topology matters more than model size for multi-agent coordination. Connects to stigmergy research.
