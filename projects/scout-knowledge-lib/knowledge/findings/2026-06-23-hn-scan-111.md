# HN Scan #111: The Communication Toxicity Gradient

**Date:** 2026-06-23

## Thesis

**Information sharing in multi-agent LLM systems follows a non-monotonic value curve.** There exists a contamination threshold beyond which additional shared information actively degrades system performance. The field is independently discovering — from memory, communication, security, optimization, and governance angles — that the naive assumption "more coordination = better outcomes" is structurally false for LLM agents.

The correct question is not "how do we share more?" but "what is the minimum viable communication that avoids contamination while preventing drift?"

---

## The Five Convergent Papers

### 1. Hallucination as Context Drift (arXiv 2606.21666, Jun 19)

**Key result:** Naive full-broadcast synchronization **increases hallucination rate by 34% above the no-sync baseline** (HR: 0.658 vs 0.492, p=0.0022, d=1.18). The "cure" is measurably worse than the disease.

The paper defines Context Divergence Score (CDS) — a lightweight scalar quantifying knowledge-state discrepancy between agent pairs across spatial, temporal, and task dimensions. When agents share ALL state ("full broadcast"), erroneous agent states contaminate correct agents.

Their Shared State Verification Protocol (SSVP) achieves modest improvement (HR: 0.463, d=0.30) by adding a **verification gate** before sharing — agents exchange compressed summaries and flag high-divergence conditions. SSVP uses 58% fewer API calls than full broadcast while producing better results.

**Structural insight:** Broadcasting is not just expensive — it's actively harmful. The contamination effect creates a "communication toxicity zone" above a threshold.

Source: https://arxiv.org/abs/2606.21666

### 2. RaMem: Contextual Reinstatement (arXiv 2606.22844, Jun 22)

**Key result:** Memory retrieval without context preservation causes "context collapse" — memories from different situations appear equally relevant because they share surface-level entities or patterns.

RaMem's solution: four-stage protocol — evidence anchoring (ground in original episodic conditions), recall condition induction (derive what the query actually needs), validity-aware retrieval (prioritize context-compatible memories), context-preserved synthesis (maintain structured context through generation).

**Structural insight:** Memory sharing between sessions/agents faces the same contamination gradient. MORE recalled memories can be WORSE than fewer if the validity signal is absent. The admission predicate matters more than the recall volume.

Source: https://arxiv.org/abs/2606.22844

### 3. When Is Emergent Consensus Real? (arXiv 2606.22203, Jun 20)

**Key result:** LLM "agent societies" produce coupling gain gamma ranging 0.15-0.43 across five frontier models. Social-neighbour gamma roughly equals numeric-anchor gamma — coupling is evidence-coupling, not uniquely social. Critically: default societies DO NOT self-polarize (beta ≤ 0), so all observed "emergent consensus" may be model-prior artifacts rather than genuine social dynamics.

A randomized-initial-condition diagnostic reveals that a published "emergent consensus" result (Chuang et al. 2023) is actually model-specific conflation: real averaging on debatable claims, but prior-artifact on settled facts.

**Structural insight:** Multi-agent "agreement" through communication can be an artifact of shared model priors rather than genuine convergence. The communication creates an ILLUSION of validation that contaminates confidence without adding information.

Source: https://arxiv.org/abs/2606.22203

### 4. MAS-PromptBench: When Does Prompt Optimization Improve MAS? (arXiv 2606.23664, Jun 22)

**Key result:** Extending single-agent prompt optimization to multi-agent systems faces an exponentially growing search space. System gains are highly sensitive to workflow configuration, communication protocol, and team size — local improvements at one agent's prompt can WORSEN system-level performance.

**Structural insight:** Optimization in a coupled system is qualitatively different from optimization of components. The coupling channels (communication) create emergent interactions that make local gains potentially globally harmful.

Source: https://arxiv.org/abs/2606.23664

### 5. Detecting Malicious Agent Skills in the Wild (arXiv 2606.23416, Jun 22)

**Key result:** Skills are themselves bodies of instructions — so prompt-injection defenses don't apply (there's no trusted/untrusted boundary when skills ARE instructions). Locate-and-Judge uses attention-based scoring to detect malicious spans, flagging "dozens of live malicious skills" in production marketplaces.

**Structural insight:** Shared skill loading = accepting executable payload from third parties. Trust boundaries dissolve because the MEDIUM of sharing (natural language instructions) is indistinguishable from the medium of attack. The communication channel IS the attack surface.

Source: https://arxiv.org/abs/2606.23416

## The Non-Monotonic Value Curve

```
System Performance
    ^
    |          ╭──── optimum (selective, governed)
    |         ╱   ╲
    |        ╱     ╲──── contamination zone
    |       ╱        ╲
    |      ╱          ╲──── full broadcast (WORSE than baseline)
    |     ╱
    |    ╱
    |───╱────────────────── no communication (baseline)
    |
    └──────────────────────────────→ Communication Volume
         drift zone    sweet spot    contamination zone
```

**Three regimes:**

| Regime | Communication Level | Failure Mode | Example |
|--------|-------------------|--------------|---------|
| **Drift zone** | Too little | Agents diverge, duplicate work, contradict | Independent agents with no shared state |
| **Sweet spot** | Selective, governed | Verified state, admission-controlled | SSVP, stigmergy, pull-based coordination |
| **Contamination zone** | Too much | Error propagation, false consensus, prior leakage | Full broadcast, naive memory sharing, unfiltered skill loading |

## Connection to Our Production Data

### The Cytokine Storm (Jul 18): Contamination via Monitoring Channel

Our system demonstrated the contamination gradient live. During a provider outage:
- Monitoring sessions (the communication channel) were subject to the same failure
- Each failed monitoring session CONTRIBUTED to the metric it was investigating
- Recovery took 3× longer than the outage due to self-amplification

**This is exactly the "full broadcast increases hallucination 34%" finding instantiated in production.** Our metric-alert-triage pipeline IS a broadcast channel. When it fires during degraded conditions, it amplifies the degradation.

### The Coordination Tax (Jun 14): Contamination via Planning Channel

Our aks-explorer project demonstrated:
- 51% of planner sessions immediately exit with nothing to plan
- Planning-to-work ratio reached 2.04:1
- The coordination overhead grew superlinearly relative to productive work

**This is the MAS-PromptBench insight:** coupling between agents (planning triggers) creates emergent overhead that dominates the system. Each planning session is a "communication event" that may trigger more communication without adding work.

### Contagion Networks (scan #73): Measured Gamma

The arXiv paper 2606.20493 measured evaluator bias propagation with gamma ∈ [0.157, 0.352]. Committee k=3 reduces contagion 72%. This is a SPECIFIC measurement of the contamination gradient — bias travels through communication channels at a quantifiable rate.

### Tool Value Inversion (scan #109): Channel-Level Toxicity

"Don't Blindly Trust It" (2606.21409) showed that unreliable tool feedback makes agents perform WORSE than no feedback (4.7 F1 vs 22.3 F1). This is the contamination gradient at the tool-feedback channel level.

## The Communication Admission Control Framework

Synthesizing across all signals, the emerging architectural principle:

### 1. Verify Before Sharing (SSVP pattern)
- Exchange compressed state summaries FIRST
- Flag high-divergence conditions BEFORE joint reasoning
- Cost: 58% fewer API calls. Benefit: 34% less hallucination vs full broadcast

### 2. Admit Based on Validity, Not Relevance (RaMem pattern)
- Surface relevance (entity matching) is insufficient for recall
- Must verify episodic validity: when was this true? In what context? For what participants?
- More memories is worse if validity is unchecked

### 3. Measure Coupling, Don't Assume It (Consensus Diagnostic pattern)
- Default gamma (0.15-0.43) means every shared opinion shifts neighboring agents
- Model-prior artifacts masquerade as genuine consensus
- Diagnostic: randomized initial conditions reveal whether outcome is averaging or artifact

### 4. Govern the Channel, Not the Content (GitHub practitioner pattern)
- File claims, permissions, approval gates, policies
- Pull-based over push-based (let consumer decide when to read)
- Stigmergy over message passing (modify shared state rather than sending messages)

## Implications for Our System

Our stigmergic coordination (file-based, pull-based, asynchronous) is **structurally protective** against communication toxicity. Agents read shared state when they choose to, not when pushed. But two channels remain vulnerable:

1. **Metric-alert cascades** (demonstrated in Cytokine Storm): broadcast-like triggering without verification. Fix: add divergence check before spawning triage.
2. **Event-driven planning** (demonstrated in Coordination Tax): every work event triggers planner evaluation. Fix: batch events, add "nothing has changed" short-circuit at trigger level, not at session level.

The Communication Toxicity Gradient suggests our system's "boring" coordination (heartbeat files, knowledge entries, pull-based reads) is not a limitation to be overcome — it's a defense to be preserved. The contamination threshold means that making our agents communicate MORE would likely make them perform WORSE.
