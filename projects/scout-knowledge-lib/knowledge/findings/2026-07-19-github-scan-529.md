# GitHub Scan 2026-07-19 — Agent Tooling & Code Quality Signals

## 1. code-humanizer — Agent Skill That Removes AI Code Slop

- **Repo:** [LeonardNJU/code-humanizer](https://github.com/LeonardNJU/code-humanizer) (31★, created 2026-07-15)
- **What:** An agent skill (single `SKILL.md`, no deps) that catalogs and fixes 16 numbered patterns of AI-generated code "tells" — duplicated helpers, `_v2` clones, single-implementation abstractions, speculative architecture, broad excepts, try-import fallbacks. Modeled after prose humanizer tools but for code.
- **How it works:** Default mode is scan → report (severity 0–4 table). Fix mode is one pattern per commit, tests must pass after each step. Works with Claude Code, Codex, Cursor, Cline, Gemini, Copilot via `npx skills add`.
- **Signal:** This is early evidence of a **meta-agent quality layer** — agents cleaning up after other agents. The pattern taxonomy (5 tiers, 16 patterns) is a concrete vocabulary for "code slop" that could become a shared standard. Connects to the broader theme of agents optimizing for "tests pass" vs "codebase stays healthy."

## 2. waggle — Attributed Artifact References for Agent Handoffs (Update)

- **Repo:** [modiqo/waggle](https://github.com/modiqo/waggle) (885★, created 2026-07-08)
- **What:** A ~30-byte token that replaces pasting artifacts into context during multi-agent handoffs. Each token resolves into per-agent views (adapted to context budget), tracks reads, propagates corrections, and works across machine boundaries. MCP-native.
- **Key claim:** Multi-agent systems consume ~15× the tokens of chat sessions; ~37% of multi-agent failures trace to handoff seams. Waggle makes handoffs attributable, adaptive, and correctable.
- **Growth:** 885★ in 11 days signals strong resonance. Has a paper and design essay.
- **Signal:** This addresses a real pain point in the orchestration layer. The insight that "a path is the right size but the wrong semantics" is sharp. If adopted, this could become infrastructure for the meta-harness world (Omnigent, Shepherd, etc.).

## 3. fastctx — Context-Efficient Repo Tools for Agents (MCP)

- **Repo:** [yc-duan/fastctx](https://github.com/yc-duan/fastctx) (56★, created 2026-07-17)
- **What:** MCP tools that give agents fast, context-efficient access to repository structure and content. Optimized to minimize tokens consumed when agents need to understand a codebase.
- **Signal:** Part of the growing MCP tool ecosystem specifically designed for coding agents' context efficiency.

## 4. KlaatAI/klaatcode — Smart Model Routing for Coding Agents

- **Repo:** [KlaatAI/klaatcode](https://github.com/KlaatAI/klaatcode) (147★, created 2026-07-17)
- **What:** Open-source terminal coding agent that routes tasks to different models based on complexity. Claims "Claude Code-grade accuracy" at 10× lower cost through intelligent routing (Claude, GPT, Gemini, DeepSeek).
- **Signal:** Model routing as a first-class feature of coding agents, not just model selection. The cost axis is becoming a competitive differentiator alongside quality.

## Synthesis

Three themes emerge from this scan:

1. **Agent-on-agent quality assurance** — code-humanizer is the clearest example yet of agents being purpose-built to audit and fix other agents' output. This is distinct from general code review; it targets specifically AI-generated patterns.

2. **Handoff infrastructure hardening** — waggle's rapid growth (885★ in 11 days) shows the multi-agent community recognizes that context passing between agents is a major failure point and is ready for protocol-level solutions.

3. **Cost-aware model routing** — klaatcode joining the coding agent space with model routing as its primary differentiator suggests the market is bifurcating between "best quality at any cost" (Claude Code, Codex) and "smart routing for cost efficiency."
