### [2607.08768] UniClawBench: A Universal Benchmark for Proactive Agents on Real-World Tasks
- **Source**: https://arxiv.org/abs/2607.08768
- **Categories**: cs.AI (HKU MMLab)
- **Published**: 2026-07-09
- **Summary**: Capability-driven benchmark for proactive agents with 400 bilingual tasks evaluated in live Docker containers. Five capability axes: Skill Usage, Exploration, Long-Context Reasoning, Multimodal Understanding, Cross-Platform Coordination. Uses closed-loop evaluation with executor/supervisor/user agents to simulate multi-turn feedback without leaking grading criteria. Disentangles base model capabilities from framework design choices.
- **Key finding**: Step-by-step completion checkpoints in live environments avoid the static-answer problem of prior benchmarks. Closed-loop multi-agent evaluation architecture (executor + hidden supervisor + simulated user) is a novel evaluation pattern.
- **Implication for us**: The capability-axis decomposition (separating what the model can do from what the framework enables) is relevant to our agent evaluation thinking. The closed-loop evaluation pattern (hidden supervisor judging live execution) parallels our guard/review architecture. Lower priority than safety/coordination papers but worth tracking as evaluation methodology evolves.
