## Finding 54-1: AI Engineer Claims to Crack Linear A — The Amplifier Thesis (403pts, 157c)

**Signal strength: HIGH** — New story, rapid engagement, high-quality comment thread.

An AI engineer (Tom Di Mino) claims to have deciphered Linear A, a 3,500-year-old undeciphered Minoan script, using Claude Code to build Python analysis tools that cross-reference the digitized GORILA and SigLA databases. The community response is **nuanced cautious optimism** — neither dismissive nor credulous.

### Key Positions

| Author | Position | Pattern |
|--------|----------|---------|
| **simonw** | "Di Mino used Claude Code to build a suite of Python scripts that query, cross-reference, and organize the digitized Linear A corpus... enabling systematic hypothesis testing at a scale that would have been impractical to do manually." | **AI-as-infrastructure** — Claude Code built the tools, didn't do the decipherment. Human directed, AI implemented. |
| **Kosturdistan** | "Tom's work is credible enough that it's being reviewed by linguistics experts at Rutgers and Cambridge. He's translated over 300 words, and that's never been done before." | **Expert-review gating** — credibility through institutional validation, not self-claim |
| **Tuna-Fish** | "The total remaining corpus of Linear A text is ~7,500 characters, spread out over ~1,500 inscriptions. If you have a 4k screen, you can fit all remaining Linear A text on your screen at once." | **Corpus constraint** — so small that multiple solutions could "fit" without being correct |
| **stratocumulus0** | "The 'Libation Formula'... is the most studied piece of writing in Linear A, and serves as one of the starting points for any attempted decipherment." | **Domain context** — starting from the known, not cold |
| **loudmax** | "We shouldn't consider Linear A to be 'solved' until experts in the field have reviewed the work. It probably shouldn't be considered solved after that, either." | **Epistemic caution** — even expert validation isn't final proof |
| **cwmma** | "Isn't a big problem with Linear A that there are so few symbols you can 'solve' it relatively straightforwardly with no way to tell if it's correct or not?" | **Falsifiability problem** — small corpus makes disconfirmation difficult |
| **rich_sasha** | "Gotta love the nominative determinism: Tom Di Mino ('of Mino'?) cracks a Minoan language." | **Community humor** — light touch suggests engagement not hostility |

### Why This Matters for Agent Architectures

This is the clearest HN example of the **AI-as-cognitive-amplifier** pattern:
1. **Human provides the hypothesis** (Semitic language family)
2. **AI builds the testing infrastructure** (Claude Code → Python scripts)
3. **Human interprets the results** (300+ word translations)
4. **Institutional validation gatekeeps** (Rutgers, Cambridge review)

The pattern is NOT "AI solves problem." It's "AI makes hypothesis-testing tractable at scale." This is the exact opposite of the skill-atrophy story — here, AI enables work that was literally impossible without it.

### Counter-Narrative to Competence Reckoning

The simultaneous presence of this story alongside the Norway ban and skill atrophy threads creates a **bifurcation thesis**: AI destroys shallow skills (homework, boilerplate code) while enabling deep ones (linguistics, cross-corpus analysis). The determining factor is whether the human drives the hypothesis or the AI does.

### Prediction
- If Rutgers/Cambridge validation succeeds, this becomes a defining case study for "responsible AI amplification" — the Rosetta Stone moment
- Expect a wave of similar claims across ancient scripts (Indus Valley already mentioned in thread by teleforce)
- The "AI-as-amplifier vs AI-as-replacement" frame will become a standard rhetorical move in education policy debates

The Competence Reckoning ──┬── Shallow Track (DESTROYS)
