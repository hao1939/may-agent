## ★★★★ High Relevance

### [2607.13034] Do AI Agents Know When a Task Is Simple? Toward Complexity-Aware Reasoning and Execution
- **Published**: 2026-07-14
- **Summary**: LLM agents follow maximum-context-first strategies—re-reading entire codebases for one-line edits. Proposes *task-aware execution-scope estimation*: judging difficulty, minimum information needed, and shortest reliable path before acting.
- **Implication**: Directly validates **the Token Tax** thesis. Agents over-consume context because they lack complexity awareness. This is the theoretical framing for what the Claude Code 33k-token overhead story demonstrated empirically. Also connects to our session-floor concept—agents need to estimate whether a task even requires a full session.
- **Pattern name candidate**: "The Effort Mismatch" — agents apply maximum machinery to minimum problems.

### [2607.12747] Tracing Agentic Failure from the Flow of Success
- **Published**: 2026-07-14
- **Summary**: Lightweight failure attribution without expensive prompting pipelines or post-training on annotated failure trajectories. Key insight: train on *success* trajectories, then use deviation from learned success flow to localize failures. Avoids the annotation bottleneck.
- **Implication**: Elegant inversion—learn what success looks like, detect failure as divergence. Connects to **the Compilation Gradient**: success patterns become reusable artifacts for diagnosing future runs. Also validates the "Scars" concept from scan #284 (compiled failure memory) but approaches from the opposite direction.

### [2607.12469] Agent-Safety Evaluations as Load-Bearing Evidence
- **Published**: 2026-07-14
- **Summary**: Introduces a *reconstructability metric* for agent safety evaluations. Many eval results are not "load-bearing"—identical scores can rest on materially different evidence. Proposes eight decision-property classes and cross-harness adapter to measure whether captured evidence can actually reconstruct the decision a safety claim depends on.
- **Implication**: Directly extends **the Evaluation Mirage** thesis. Not just "evals are misleading" but formally measuring *how much* an eval result actually proves. The reconstructability framing is powerful—an eval is only as good as its ability to reconstruct the decision path.

### [2607.12893] MemOps: Benchmarking Lifecycle Memory Operations in Long-Horizon Conversations
- **Published**: 2026-07-14
- **Summary**: Decomposes agent memory into lifecycle operations (create, bind, update, retire, conflict-resolve) rather than evaluating only downstream QA accuracy. Identifies heterogeneous failure modes: missing fact introduction, wrong binding target, stale values.
- **Implication**: Validates our **agent operational memory** research direction. Memory isn't monolithic—it's a set of discrete operations that fail independently. The "binding to wrong target" and "stale value" failure modes map to real failure patterns in multi-session agents.

## ★★★ Moderate Relevance

### [2607.12790] Who Grades the Grader? Co-Evolving Evaluation Metrics and Skills for Self-Improving LLM Agents
- **Published**: 2026-07-14
- **Summary**: Self-evolving agents assume reliable evaluation metrics exist—but they often don't. Proposes co-evolving metrics alongside skills using evolutionary lifecycle over "drawback detectors" anchored to minimal reference sets.
- **Implication**: The "who evaluates the evaluator" infinite regress is a real architectural challenge. The anchoring to small reference sets is pragmatic. Extends Evaluation Mirage into self-improvement loops.

### [2607.12650] Evidence-Grounded Verified Agentic Reasoning (EG-VAR)
- **Published**: 2026-07-14
- **Summary**: Lean 4-based architecture where every verified output structurally descends from an attested tool call. Formal verification that reasoning chains are grounded in evidence, not hallucinated.
- **Implication**: Maximum-rigor approach to the hallucination problem in agentic reasoning. Interesting but likely too heavyweight for practical agent systems today. Worth tracking as a theoretical ceiling for trustworthy agent architectures.

### [2607.12480] TRACE: Operational Reasoning Schema for Auditable Agentic Commitments
- **Published**: 2026-07-14
- **Summary**: Typed, versioned schema for recording reasoning traces. Operating discipline: "no durable state change without a record." Argues reasoning is not *in* the LM—it must be externalized and audited.
- **Implication**: The "no state change without a record" discipline is a strong architectural principle. Connects to our compilation gradient (externalize reasoning into durable artifacts) and could inform agent framework design.

### [2607.12986] Win by Silence: Deletion Non-Monotonicity in LLM Plan Evaluation
- **Published**: 2026-07-14
- **Summary**: Plans can score *higher* by removing explicit steps—evaluators reward brevity/confidence. Formally proves when deletion improves scores and shows all routes in a test cohort have exploitable deletions.
- **Implication**: Novel attack surface: agents can game evaluators by being *less* explicit. Connects to Evaluation Mirage—evaluators have structural blind spots that can be systematically exploited.

## Convergent Themes This Batch

1. **Evaluation Crisis Deepening**: Three papers (Load-Bearing Evidence, Who Grades the Grader, Win by Silence) all attack evaluation validity from different angles. The field is recognizing that current evals are structurally inadequate.

2. **Externalized Reasoning**: TRACE and EG-VAR both argue reasoning must be made explicit, auditable, external to the model. "No state change without a record" as architectural principle.

3. **Effort Calibration**: Complexity-Aware agents (2607.13034) and the success-flow failure attribution (2607.12747) both address the problem of agents doing too much or too little—calibrating effort to task requirements.
