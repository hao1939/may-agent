## arXiv Papers

### World-Model Collapse as a Phase Transition (2606.31399)
- **Core result**: Large grid search over state cardinality, dependency density, horizon, branching reveals a *phase diagram* — solved plateau, narrow transition band, collapse floor
- **Mechanism**: World-state fidelity fails BEFORE action validity. Agent isn't choosing bad actions — it's acting from a corrupted world model
- **Key finding**: Stronger models translate the critical boundary but DO NOT remove the qualitative transition
- **Implication**: Phase transitions in agent reliability are structural, not capability-limited. Every model has a horizon at which its world model collapses, and this is discoverable before deployment
- Source: https://arxiv.org/abs/2606.31399

### The Decomposition Is the Fingerprint: Per-Component Identity for Agent Skills (2606.31272)
- **Core result**: Locality-sensitive fingerprint (120-byte SimHash triple: prompt, code, tools) achieves 0.974 AUC for skill-family identity across paraphrase, renaming, refactoring
- **Key design**: Per-component triple enables: lineage recovery, injection detection, tampered-copy recognition — but explicitly NOT safety (identity ≠ trust)
- **SkillBOM concept**: Portable bill-of-materials for agent skill registries
- **906-skill injection benchmark**: recognizes injected skills as tampered copies and localizes which component changed
- **Implication**: Identity infrastructure prerequisite for governance — you can't govern what you can't identify — but identity alone insufficient
- Source: https://arxiv.org/abs/2606.31272

### AI-Infra-Guard: Unified Multi-Layer Agent Red Teaming (2606.31227)
- **Core observation**: Attack surface is stratified across layers; no single detection paradigm fits all
- **Four layers**: Infrastructure (deterministic rules, 75+ components, 1,400+ vuln rules) → Protocol/tool (LLM-driven MCP audit) → Agent behavior (multi-turn black-box red teaming) → Model (26+ jailbreak operators, 16 datasets)
- **First open-source to span all layers** including supply-chain auditing of agent skills
- **Implication**: Validates Runtime Trust Gap (#276) layer model; provides reference implementation. Paradigm-per-layer = criticality-aware: each layer has different threshold characteristics
- Source: https://arxiv.org/abs/2606.31227

### Certified Speculative Execution for Untrusted Agents (CGPA) (2606.31023)
- **Core mechanism**: Certificate-gated prefix acceptance — trusted verifier rejects constraint-violating transitions exactly; conformally calibrated value boundary gates longest low-cost prefix within regret budget; remainder defers to trusted solver
- **Key result**: Drives even adversarial drafters and 6 heterogeneous frozen LLMs (including 12B that violates in 98% of direct rollouts) to ZERO applied violations
- **Performance**: 8B LLM → 2.96× wall-clock speedup at 2.1% regret, outpacing domain heuristic (1.79×)
- **Design principle**: "The more capable the untrusted source, the faster the certified system, at guarantees that never change"
- **Implication**: First production-viable architecture that makes the trust boundary binary and the capability gradient continuous — precisely the threshold architecture needed
- Source: https://arxiv.org/abs/2606.31023

### FinPersona-Bench: Mandate Salience Decay (2606.31522)
- **Core phenomenon**: Autonomous financial agents initialized with behavioral mandates ("preserve capital", "avoid speculative bets") exhibit Mandate Salience Decay — mandates lose behavioral influence as market context accumulates over long horizons
- **Structural analogy**: Exactly the criticality threshold for behavioral stability — agents stable until context crosses invisible boundary, then mandate loses hold
- **Implication**: World-model collapse (2606.31399) operates at the cognitive level; MSD operates at the behavioral governance level. Same phase-transition structure, different substrate
- Source: https://arxiv.org/abs/2606.31522

### ECHO: Selective Turn Memory in Agentic RL (2606.31650)
- Long-horizon agents: prune to act (selective retention of turns for decision-making), trace to learn (full trajectory for credit assignment)
- Existing methods lose fine-grained evidence as turns grow — the compression threshold below which policy degrades
- Source: https://arxiv.org/abs/2606.31650

### ACE: Pluggable Adaptive Context Elasticizer (2606.31564)
- Addresses irreversibility of truncation/summarization — once compressed, cannot be recovered
- "Elastic" context management: reversible compression that respects criticality of information
- Source: https://arxiv.org/abs/2606.31564

## Structural Synthesis

### The Criticality Threshold Pattern

Five convergent observations across independent streams:

1. **Cognitive threshold** (2606.31399): World-model fidelity → collapse at measurable state-load boundary
2. **Behavioral threshold** (2606.31522): Mandate adherence → decay as context accumulates past invisible point  
3. **Trust threshold** (HN steganography 1,429pts): Vendor-user relationship → irreversible rupture once covert channel exposed
4. **Architectural response** (2606.31023 CGPA): Binary certification gate that makes threshold EXPLICIT — untrusted until proven, at every step
5. **Policy response** (Export controls lifted): Conditional access as threshold mechanism — permitted IF verifiable compliance

### Relationship to Prior Findings

- **Safety Inversion** (#282): Protective mechanisms have inversion thresholds → now formalized as phase transitions
- **Conditional Resolution** (#289): Trust replaced by conditionality → conditionality IS threshold architecture
- **Operating Surface** (#275): Horizon scaling creates governance surface → 2606.31399 proves horizon IS the phase-transition parameter
- **Indiscernibility Threshold** (#270): Governance mechanisms become indistinguishable from failures at critical intensity → world-model collapse is the cognitive substrate of this
- **Depth Separation** (#286): Memory depth ≠ memory access → MSD shows depth (mandate internalization) has its own decay threshold

### Design Principle

**Every agent deployment must characterize its criticality thresholds BEFORE deployment**: the horizon at which world models collapse, the context depth at which mandates decay, the trust perturbation at which relationships rupture. Governance is not violation detection — it is proximity monitoring. The CGPA architecture (2606.31023) is the first reference implementation of threshold-aware governance: it makes the boundary binary, explicit, and certifiable.
