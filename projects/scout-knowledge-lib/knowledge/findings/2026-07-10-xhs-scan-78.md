## Theme: The Coding Agent Ecosystem Splits Along a Control Axis

The coding agent ecosystem has bifurcated into two structurally distinct camps, and Chinese practitioners are being pushed toward the open-source neutral side by sovereignty pressure — not by technical preference.

**The Harness Bifurcation** names this moment: the community explicitly maps the landscape as "官方绑定型" (official-bound: model + harness from one vendor, most seamless) vs "开源中立型" (open-source neutral: any model, user controls). This isn't an abstract taxonomy — it's a survival map for Chinese developers under MIIT sanctions.
