# GitHub Scan 530 — 2026-07-19

## Key Signals

### 1. AgentSmith — Universal Operating Harness (309★ in 3 days)

- **Repo:** [PromptPartner/agentsmith](https://github.com/PromptPartner/agentsmith) (309★, created 2026-07-16)
- **What:** Model-agnostic "operating harness" for coding agents — lean core + work-type profiles assembled by a single setup script. Supports Claude, Codex, Gemini.
- **Signal:** Confirms the **harness engineering** pattern is now the default architectural choice. The framing as "operating harness" (not framework) mirrors OS-level vocabulary. Work-type profiles = role templates rather than monolithic system prompts. This is the Shell-script tier of the harness stack — below SDK-level projects like ECC but above raw CLAUDE.md files.

### 2. Déjà Vu — Memory Recycling From Existing Session Logs (377★ in 5 days)

- **Repo:** [vshulcz/deja-vu](https://github.com/vshulcz/deja-vu) (377★, created 2026-07-14)
- **What:** Zero-dep Go binary that turns session logs agents already write (Claude Code, Codex, Cursor, etc.) into a searchable memory layer with MCP recall, auto-context injection, secret redaction, and cross-session sync.
- **Signal:** This is a **memory recycling** pattern — rather than building new memory infrastructure, it mines the exhaust of existing agent sessions. Key insight: agents already produce structured logs; memory is a read-path problem, not a write-path problem. Also notable: secret redaction built in from day one, treating memory as a security surface.

### 3. LLMVault — OWASP-Aligned Agent Security Training Lab (199★ in 4 days)

- **Repo:** [CyberSunil/LLMVault](https://github.com/CyberSunil/LLMVault) (199★, created 2026-07-15)
- **What:** Intentionally vulnerable training platform covering OWASP LLM Top 10 — prompt injection, RAG poisoning, agent security, GenAI pentest exercises. Docker-based, CTF-style.
- **Signal:** The agent security education layer is materializing. This is the "DVWA for LLMs" — a marker that agent security knowledge is shifting from research papers to practitioner training. 50 forks in 4 days suggests active use in security teams.

### 4. Circuit Framework — Multi-Agent Trading Research (484★ in 3 days)

- **Repo:** [PengZhang64/circuit-framework](https://github.com/PengZhang64/circuit-framework) (484★, created 2026-07-16)

### 5. Codesteward — Agentic Code Review as PR Gate (61★)

- **Repo:** [Codesteward/codesteward](https://github.com/Codesteward/codesteward) (61★, created 2026-07-14)

### 6. GitLord — Git-Backed Agent Orchestration (23★, early)

- **Repo:** [yashneil75/gitlord](https://github.com/yashneil75/gitlord) (23★, created 2026-07-16)
- **What:** Every agent turn becomes a Git commit — inspectable, rewindable, forkable.
- **Signal:** Small but conceptually interesting: using Git as the coordination substrate for multi-agent systems. Every turn is a commit = full auditability + branching for speculative execution.

## Emerging Patterns

1. **Harness layering**: The stack is stratifying — Shell-script harnesses (AgentSmith) → SDK harnesses (ECC) → platform harnesses (sandbaseai/managed-agents). Each layer assumes the one below.

2. **Memory recycling > memory building**: Déjà Vu and MemTensor both treat memory as a read-side problem over existing artifacts, not a new write-side system. This inverts the assumption that agents need dedicated memory stores.

3. **Security education pipeline**: LLMVault signals that agent security is mature enough for CTF-style training — the pattern that preceded the DevSecOps boom for traditional software.

4. **Finance as second vertical**: After coding, finance is the next domain producing dedicated multi-agent infrastructure (Circuit Framework, financial-agent-api, dex-trade-agent-kit).
