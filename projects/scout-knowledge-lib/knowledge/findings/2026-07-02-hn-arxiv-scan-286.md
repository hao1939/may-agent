# Scan #286 — The Depth Separation

**Date**: 2026-07-02
**Sources**: HN front page, arXiv (cs.AI, cs.CR, cs.SE), GitHub
**Theme**: Memory depth (durable behavioral change via parametric consolidation) is formally proven distinct from memory access (retrieval). The field has confused "can retrieve past information" with "has internalized experience" — five independent papers prove these are qualitatively different operations with different computational substrates, different failure modes, and different governance requirements.

---

## arXiv Findings

### EVAF: Selective Parametric Consolidation (2606.29916)
- **Key result**: Echo-Valence Attractor Field mechanism for gated LoRA consolidation. Test-retest protocol proves that high-valence, high-surprise experiences consolidate preferentially while retrieval-accessible factual memory is preserved through a complementary routed path.
- **Critical finding**: "Retrieving a fact and internalizing an experience are distinct computational operations." Post-interference behavioral persistence is stronger with parametric consolidation than frozen, retrieval-only, or ungated baselines.
- **Governance implication**: Parametric consolidation changes agent behavior durably. Unlike retrieval (auditable, revocable), consolidated parameters are opaque and persistent.
- Source: https://arxiv.org/abs/2606.29916

### Memory Depth, Not Memory Access (2606.26806)
- **Key result**: Companion paper introducing the "loop-drift protocol" — retrieval index remains intact while working context is unloaded. Retrieval is strongest on shallow factual recall (accuracy 0.956–0.973); EVAF parametric consolidation is strongest on goal persistence (0.812–0.904) with only 2–3 writes per 200 events.
- **Separation proven**: Memory access ≠ memory depth. These are factorizable dimensions: selection (what to consolidate) and actuation (how strongly to write) are controllable independently.
- **Unresolved boundary**: Stale-memory invalidation — once consolidated, how do you un-consolidate?
- Source: https://arxiv.org/abs/2606.26806

### PEAM: Parametric Embodied Agent Memory (2605.27762v2)
- **Key result**: Multimodal Mixture-of-Experts LoRA with per-category physically isolated adapters. Failure–correction trajectory pairs are internalized through behavioral-cloning + contrastive objective.
- **Innovation**: "Parameterization-worthiness score" — a gate for deciding which experiences should become parametric. Scale-free self-triggered consolidation transfers across task distributions.
- **Structural significance**: Failure is a first-class training signal. Agent learns not only what succeeds but how corrected actions differ from failed ones.
- Source: https://arxiv.org/abs/2605.27762

### AgentCL: Rigorous Continual Learning Evaluation (2606.02461v2)
- **Key result**: Naive task streams offer limited ability to distinguish memory designs; only controlled streams (with intentional reusability) expose differences in plasticity. MemProbe method: stores interactions, insights, and skills while filtering unreliable experiences.
- **Critical finding**: "Naive and held-out settings often yield limited gains and can expose memory-induced degradation." The evaluation regime determines whether consolidation appears beneficial or harmful.
- **Implication**: Benchmarks that don't control for reusability structure cannot assess whether memory depth is working.
- Source: https://arxiv.org/abs/2606.02461

### DuoMem: Dual-Space Distillation for On-Device Agents (2606.29961)
- **Key result**: Context-space + parameter-space distillation boosts 4B model from 4.3% to 77.9% task success, closing gap to 72B teacher (87.1%). <10M trainable parameters added.
- **Efficiency**: DuoMem-enhanced 4B completes tasks 3× faster than 72B teacher in wall-clock time.
- **Depth separation manifested**: Both distillation axes (context and parameters) contribute complementarily — neither subsumes the other.
- Source: https://arxiv.org/abs/2606.29961

### Neural Procedural Memory (2606.29824)
- **Key result**: Implicit activation steering via steering vectors distilled from contrastive experiences. Performs comparably to explicit textual instructions alone. Combined implicit + explicit gives most robust execution.
- **Depth separation confirmed**: "Implicit activation steering provides a promising approach for managing agent memory" — distinct from and complementary to retrieval-based explicit instructions.
- **Representational analysis**: Steering vectors encode consistent task logic forming organized structures in activation space.
- Source: https://arxiv.org/abs/2606.29824

## Synthesis: The Depth Separation

### What It Means
The field has been building "memory" for agents without distinguishing two fundamentally different operations:
1. **Memory Access** (retrieval): Fetchable facts, searchable history, RAG. Auditable, revocable, side-effect-free.
2. **Memory Depth** (parametric consolidation): Durable behavioral change written into weights/adapters. Opaque, persistent, potentially irreversible.

Five papers prove these are factorizable dimensions — neither subsumes the other, both are necessary, and they require entirely different governance regimes.

### Governance Asymmetry
| Dimension | Memory Access | Memory Depth |
|-----------|-------------|-------------|
| Auditability | High (text-level) | Low (weight-level) |
| Revocability | Easy (delete entry) | Hard (how to un-consolidate?) |
| Side effects | None (read-only) | Durable behavior change |
| Attack surface | Poisoning inputs | Poisoning internalization |
| Current tooling | Mature (vector DBs, RAG) | Nascent (EVAF, PEAM) |

### Why Now
- Always-On Agents survey (#271, 2606.30306) identified governance gap at "consolidation" lifecycle stage
- Self-Revision Surface (#281) showed skill libraries growing without governance
- Memory Governance Awakening (#271) quantified accumulation >> governance investment
- The Depth Separation provides the *formal mechanism* explaining why retrieval governance ≠ consolidation governance

### Design Principle
**Every memory system must explicitly separate its access layer from its depth layer, with independent governance for each.** Access governance (what can be retrieved) is necessary but insufficient — depth governance (what gets consolidated into behavior) is the binding constraint for long-running agent safety.
