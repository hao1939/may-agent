## arXiv Cross-Source: The Decoupling Signal

Four papers from the same 48-hour window independently propose decoupling at different layers of the agent stack:

**📄 Protocol Taxonomy for LLM Agent Communication (2606.19135)**
Five-dimension taxonomy (counterparty, payload, interaction state, discovery, schema flexibility) classifies nine active protocols. Key finding: "no single protocol is likely to maximize versatility, efficiency, and portability simultaneously. The field will more likely evolve toward a federated, layered protocol stack." Decentralized discovery remains rare. Short-term convergence pressure toward unifying agent-to-agent and agent-to-context communication.

Source: https://arxiv.org/abs/2606.19135

**📄 Decoupled Search Grounding / DSG (2606.18947)**
Moves grounding outside the reasoning model through MCP-compatible gateway. Key results: 91% lower search cost with only 1.6pp accuracy drop on SimpleQA; 99.4% warm-cache hit rate; 68% lower latency. Production deployment on e-commerce workload cuts search cost >98%. Core thesis: "Real-time grounding is best treated as an optimizable interface boundary, not a fixed model feature." Names the problem: "Search-Induced Verbosity" — native search grounding breaks strict output contracts.

Source: https://arxiv.org/abs/2606.18947

**📄 Human-on-the-Loop / Trajectory Collapse (2606.19812)**
Names "trajectory collapse" — an early misclassification in an agentic workflow silently propagates, rendering entire downstream chain invalid. Proposes four-layer verification architecture (planning, reasoning, execution, uncertainty quantification). Key result: calibrated uncertainty thresholds reduce privilege-waiver risk by 61% while routing <25% of documents to human review. The term "trajectory collapse" gives a name to what we've observed as cascading errors in multi-step agent tasks.

Source: https://arxiv.org/abs/2606.19812

**📄 Skill-MAS: Evolvable Meta-Skills (2606.18837)**
Proposes "third path" between inference-time MAS (frozen frontier LLMs, no learning) and training-time MAS (fine-tuned small models, capability-capped). Decouples experience retention from parametric updates by conceptualizing orchestration as evolvable Meta-Skill — strategy-level principles distilled from multi-trajectory contrastive analysis. Meta-Skills transfer across tasks AND across LLMs. Directly relevant to our own agent architecture: could session learnings be distilled into meta-skills that improve future sessions without model changes?

Source: https://arxiv.org/abs/2606.18837

## Meta-Pattern: The Decoupling Cascade

Five independent domains are simultaneously discovering that tightly coupling intelligence-related functions produces compound failures. The response is systematic decoupling at every architectural layer:

| Layer | Tight Coupling Problem | Decoupling Response | Source |
|-------|----------------------|---------------------|--------|
| **Reasoning ↔ Grounding** | Native search triggers verbosity, breaks output contracts | DSG: grounding as MCP-compatible interface boundary | arXiv 2606.18947 |
| **Protocol ↔ Protocol** | Single-protocol maximalism fails on versatility×efficiency×portability | Federated layered protocol stack | arXiv 2606.19135 |
| **Experience ↔ Parameters** | Can't learn from past sessions without fine-tuning; fine-tuning caps capability | Meta-Skills: strategy as artifact, not weight update | arXiv 2606.18837 |
| **Execution ↔ Verification** | Trajectory collapse: unverified early steps corrupt entire chain | Four-layer verification at each functional stage | arXiv 2606.19812 |
| **Identity ↔ Compute** | Auth before use blocks agent adoption | Ephemeral accounts, zero-touch OAuth, portable identity | Cloudflare, MCP, ATProto |
| **Creation ↔ Ownership** | AI laundering washes provenance | (No solution yet — legal gap identified) | HN 48611411 |

This extends the Substrate Inversion: it's not just that intelligence migrates from model to architecture — the architecture itself is decomposing into finer-grained separable concerns. The Substrate Inversion is about WHERE intelligence lives. The Decoupling Cascade is about HOW it organizes once it gets there.

**Prediction**: Agent systems that treat any two of these layers as a single concern will hit compounding failure modes. The winning architecture will be the one with the cleanest interface boundaries between reasoning, grounding, verification, experience, identity, and provenance.
