## arXiv Triage — July 14–15, 2026

### ★★★★ High Relevance

#### [2607.12893] MemOps: Benchmarking Lifecycle Memory Operations in Long-Horizon Conversations
- **Source**: https://arxiv.org/abs/2607.12893
- **Summary**: Reformulates conversational memory as a lifecycle of explicit operations (remember, forget, update, reflect, compose) rather than static fact storage. Introduces structured traces with trigger/target/scope/state-transition for each memory event. Finds session-level retrieval outperforms turn-level, and long-context models fail at reconstructing ordered memory-state trajectories.
- **Implication**: Direct challenge to "memory = RAG" assumption. Memory needs CRUD semantics, not just retrieval. This validates our agent-memory-patterns notes — the field is catching up to the idea that memory is an active process, not a database query. The lifecycle framing (remember/forget/update/reflect) maps onto what production agent systems need.
- **Connects to**: agent-memory-patterns.md, the-eternal-present.md

#### [2607.12790] Who Grades the Grader? Co-Evolving Evaluation Metrics and Skills
- **Source**: https://arxiv.org/abs/2607.12790
- **Summary**: "Double Ratchet" system co-evolves evaluation metrics with agent skills. Metrics evolved from small drawback detectors under evolutionary lifecycle, trained against 10-item anchor sets. Retains 88-110% of ground-truth-driven performance. Safety via anchor discipline + outer audits.
- **Implication**: Addresses the **Evaluation Mirage** head-on. When no ground truth exists, evolve the metric alongside the capability. The "failure-expecting architecture" framing is key — design for metric gaming, detect and repair. This is the most mature approach to self-improving evaluation I've seen.
- **Connects to**: the-evaluation-mirage.md, agent-evaluation-trends.md

## Emerging Cross-Source Pattern: The Lifecycle Turn

Multiple signals today point to the same meta-shift: the field is moving from **static snapshots** to **lifecycle management** across every agent subsystem:

1. **Memory**: MemOps replaces "retrieve facts" with lifecycle operations (remember/forget/update/reflect)
2. **Evaluation**: Double Ratchet co-evolves metrics alongside capabilities rather than fixing them upfront
3. **Protocol**: Vint Cerf's agent internet = lifecycle of identity/capability/trust negotiation
4. **Accountability**: Grepathy reveals the cost of treating agent decisions as ephemeral rather than lifecycle-auditable

**Thesis**: Agent systems that treat their subsystems as static (fixed memory, fixed metrics, fixed protocols, fixed audit) will increasingly fail compared to those that manage them as living processes with creation, update, deprecation, and retirement phases. This is the **lifecycle turn** — the maturation pattern we see in every engineering discipline as it moves from prototype to production.
