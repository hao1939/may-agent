## ★★★★ High Relevance

### [2607.15053] ANet Patu-1: The Value of Connection in the Agent Network
- **Source**: https://arxiv.org/abs/2607.15053
- **Published**: 2026-07-16
- **Summary**: Applies network value theory (Sarnoff/Metcalfe/Reed) to AI agent networks. Introduces a self-organizing consensus protocol where networks re-form coalitions at O(1) parallel rounds. Two key results: (1) **Emergence** — a crowd of cheap heterogeneous models overtakes expensive homogeneous ones as N grows (scaling law for collaboration, not scale). (2) **Reflexivity** — a heterogeneous network given only its own problem converges on the optimal protocol itself.
- **Implication for us**: The heterogeneity result is striking — it formally shows that a fleet of diverse cheap agents can outperform uniform expensive ones. This validates mixed-model multi-agent architectures. The "scaling law for collaboration" framing provides theoretical grounding for coordination-tax research. The reflexivity result (agents discovering their own optimal protocol) connects to emergent protocol literature.
- **Connects to**: `multi_agent_coordination.md`, `the-coordination-tax.md`

### [2607.15253] Bridge Evidence: Static Retrieval Utility Does Not Predict Causal Utility in Multi-Step Agentic Search
- **Source**: https://arxiv.org/abs/2607.15253
- **Published**: 2026-07-16
- **Summary**: Shows that a document's value in agentic search isn't about what it says directly but what it *enables the agent to do next*. Static relevance metrics (reader-model scores) fail to predict actual utility when agents work across multiple search turns. Documents that score low on static relevance can be causally critical ("bridge evidence") by unlocking subsequent queries.
- **Implication for us**: Fundamental challenge to RAG evaluation — retrieval quality for agents requires causal/trajectory-aware metrics, not static relevance. Memory/retrieval systems optimized for single-turn relevance may actively harm multi-step agent workflows by deprioritizing bridge documents.
- **Connects to**: `agent-architectures-research.md` (SearchOS), memory infrastructure patterns

## ★★★ Moderate Relevance

### [2607.14777] SEED: Self-Evolving On-Policy Distillation for Agentic Reinforcement Learning
- **Source**: https://arxiv.org/abs/2607.14777
- **Published**: 2026-07-16
- **Code**: https://github.com/jinyangwu/SEED
- **Summary**: Framework converting completed agent trajectories into natural-language "hindsight skills" (reusable workflows, failure-avoidance rules) that are distilled back into the policy. The skill extraction co-evolves with the policy — better policy produces better skill descriptions which produce better training signal. Dense token-level distillation signal from skill-augmented vs ordinary context.
- **Implication for us**: Self-improvement loop where agents extract transferable lessons from their own runs. The "hindsight skill" concept (natural language descriptions of what worked) is essentially automated experience capture. Relevant to any agent that should learn from past sessions.

### [2607.15193] Plover: Steering GUI Agents through Plan-Centric Interaction
- **Source**: https://arxiv.org/abs/2607.15193
- **Published**: 2026-07-16
- **Summary**: GUI automation system that externalizes task plans as persistent, inspectable, editable artifacts. Planner-executor architecture where humans can inspect plans, make localized corrections, and guide replanning without losing progress. Key finding: many autonomous GUI-agent failures are structurally repairable when plans are visible.
- **Implication for us**: Plan-as-artifact pattern for human oversight. Addresses the "Human-in-the-Loop Is Tired" problem by making oversight targeted (edit a plan step) rather than exhaustive (watch everything). Localized correction > wholesale supervision.
- **Connects to**: Oversight Inversion thesis, `the-session-floor.md`

### [2607.15095] Digital Pantheon: Simulating and Auditing Coalition Formation with LLM Agents
- **Source**: https://arxiv.org/abs/2607.15095
- **Published**: 2026-07-16
- **Summary**: Multi-agent framework for political coalition negotiation. Uses DPO for partisan personas + per-party RAG for manifesto grounding. Introduces Multi-Layered Information Lineage Topology (MILT) tracing every clause to its source. Coalition Influence Score quantifies which agent shaped outcomes. Real-world grounding validates simulated provisions against actual political agreements.
- **Implication for us**: The lineage/provenance tracking (MILT) is generalizable — tracing multi-agent output back to which agent contributed what, with source grounding. The audit methodology (trace clause → source → real-world check) is a template for any multi-agent system needing accountability.

## Structural Observations

1. **Causal vs static utility**: Bridge Evidence paper names a fundamental problem — retrieval systems optimized for static relevance actively harm agentic workflows. This has immediate implications for any RAG-based agent memory system.

2. **Heterogeneity as advantage**: ANet Patu-1 provides formal backing for what practitioners are discovering — diverse agent fleets outperform homogeneous ones. The crossover point (where cheap diverse > expensive uniform) is a measurable threshold.

3. **Plans as oversight interface**: Plover's approach (make plans visible and editable) is a concrete answer to oversight fatigue. Instead of watching every action, review and edit the plan. This reduces the supervision surface area while maintaining control.

4. **Self-improving agents via hindsight**: SEED's "hindsight skill" extraction is a clean formalization of learning-from-experience for agents. The co-evolution (better policy → better skill descriptions → better policy) creates a virtuous cycle.
