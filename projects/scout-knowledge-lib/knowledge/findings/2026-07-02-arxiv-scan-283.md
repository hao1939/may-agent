# Scan #283: The Transition Locus

**Date**: 2026-07-02
**Sources**: arXiv, GitHub, Hacker News
**Scan number**: 283 (continues from #282: The Safety Inversion)
**Theme**: Agent failures concentrate at phase boundaries, not within phases

## Core Thesis

Five independent research streams — empirical workload analysis, diagnostic benchmarking, open-source enforcement tooling, geometric routing defense, and adversarial security validation — converge on the same structural finding: **agent competence within phases is high and improving; agent failure at phase transitions is severe and undertreated**.

The implication for system design: enforcement budgets should be concentrated at transition points (plan→implement, select→bind, decide→route, propose→verify) rather than uniformly distributed across execution. The model doesn't need more capability within a phase — it needs reliable state transfer between phases.

## Five Convergent Streams

### 1. TraceLab: Real Coding Agent Sessions Have Phase Structure (2606.30560)
Source: https://arxiv.org/abs/2606.30560

**Empirical finding**: Analysis of ~4,300 coding-agent sessions (Claude Code + Codex), containing ~350K LLM steps and ~430K tool calls, reveals that coding-agent workloads are not homogeneous streams. They consist of:
- Long autonomous loops (sustained phases of read-plan-edit-test)
- Long contexts with short outputs (within-phase operations are bounded)
- Diverse, heavily-tailed tool calls (phase transitions trigger different tool distributions)
- High but imperfect prefix cache hit rates (phase boundaries break cache patterns)

**Structural significance**: The "high but imperfect" cache hit rate is the operational signature of phase transitions — within a phase, context remains stable (high hits); at a transition, the context shifts (cache miss). These transition points are where serving efficiency degrades, and where the agent's continuity of state reference is most fragile.

**GitHub signal**: TraceLab repo (uw-syfi/TraceLab, 12★, 3 forks since June 13) — first open dataset of real-world coding agent traces. Dataset enables empirical study of transition patterns.

### 2. Entity Binding Failures: Right Tool, Wrong World (2606.30531)
Source: https://arxiv.org/abs/2606.30531

**Diagnostic finding**: In a controlled evaluation across 60 tasks, 5 model backends, and 6 tool-use methods, all methods achieved **0.0% wrong-tool error** — yet action-oriented baselines still produced **wrong-entity actions in 24-26% of runs**. Entity-aware methods eliminate wrong-entity actions entirely but reduce direct task completion by deferring under ambiguity.

**Structural significance**: The failure doesn't occur during tool selection (within-phase reasoning). It occurs at the **binding moment** — the transition from "I know what to do" (tool selection) to "I know what to do it to" (entity resolution). This is a phase transition: from planning space to execution space. The representations are different in each space, and the binding between them can break silently.

**GitHub signal**: R-Suresh/EntityBindingFailures (1★) — first diagnostic benchmark specifically targeting the transition between tool correctness and entity correctness.

### 3. Statewright: Phase Enforcement Makes Small Models Reliable (GitHub 410★)
Source: https://github.com/statewright/statewright

**Practitioner finding**: State machine guardrails that explicitly constrain which tools are available in each workflow phase produce dramatic reliability improvements:
- 13B local models go from unreliable to production-viable
- 5-task SWE-bench subset: 2/10 → 10/10 passing with same model + Statewright
- Principle: "Agents are suggestions, states are laws"

**Structural significance**: Statewright doesn't improve the model's reasoning within any phase. It **enforces transitions** — planning gets read-only tools; implementation gets edit tools only after planning completes; testing gates deployment. The entire value proposition is governance of the transition, not augmentation of within-phase capability.

**Growth signal**: 410★ (up from 126pts HN in May). Ecosystem forming: juncture (19★, Rust LangGraph-compatible implementation), ix-flow (1★, CLI workflows with human gates), state-machine-for-agents (0★, Claude Code skill). The pattern is replicating across implementations.

### 4. ANTAP/Linguistic Firewall: Geometric Defense at the Routing Boundary (2606.30555)
Source: https://arxiv.org/abs/2606.30555
Published at: Second Workshop on Agents in the Wild (AIWILD) at ICML 2026

**Security finding**: ANTAP achieves near-zero attack success rate against description-based injection attacks (vs. 67.3%+ for text-based routing), plus 20% ASR reduction against adaptive embedding attacks. Method: active capability testing distilled into fixed behavioral operators, with routing performed via algebraic projection in a shared semantic space — a "linguistic firewall" that renders metadata-based attacks inexpressible.

**Structural significance**: The routing decision is a phase transition — from "requests arrive" to "agents handle them." Text-based routing trusts metadata generated in one phase (description/registration) during execution in another phase (runtime routing). ANTAP eliminates this cross-phase trust transfer by making the routing boundary non-textual — geometry replaces language at the transition point. The vulnerability was always at the transition, never within the agent's execution.

### 5. COHORT: Offensive Replay at the Deployment Boundary (2606.30479)
Source: https://arxiv.org/abs/2606.30479

**Security validation finding**: Multi-agent LLM workflow for network hardening achieves 46.7% success rate (mitigations that disrupt attacks while preserving connectivity), 4.4× the rate of a single-agent baseline. Key mechanism: offensive replay at the deployment boundary — re-executing the original adversary on the mitigated network for a paired comparison against the unmitigated baseline.

**Structural significance**: COHORT's value is entirely at the transition from "proposed mitigation" to "deployed mitigation." The proposal phase uses standard multi-agent collaboration; the verification happens only at the deployment boundary via replay. Without boundary verification, the 4.4× advantage disappears. The transition from "plan" to "deploy" is the critical locus.

**Pattern**: Every high-engagement agent failure story on HN is a transition failure. The agent was competent within its phase (it could scan networks, execute SQL, write articles, pass benchmarks). It failed at the boundary (it couldn't limit scope, pick the right target, maintain attribution, or generalize to deployment).

## Structural Architecture: The Phase Transition Stack

```
Phase N                      TRANSITION BOUNDARY                    Phase N+1
(high within-phase          (concentration of failure,              (different context
competence)                  binding errors, cache misses,           representation)
                             attack surfaces, oversight needs)
                             
Planning ─────────────────── [entity resolution] ──────────────── Execution
Selection ────────────────── [target binding] ──────────────────── Action
Evaluation ───────────────── [metric→capability inference] ──────── Deployment
Proposal ─────────────────── [verification replay] ─────────────── Enforcement
Registration ─────────────── [geometric projection] ──────────────── Routing
```

Each transition boundary:
- Has a different **representation** on each side
- Requires **binding** between the two representations
- Concentrates **failure modes** invisible to within-phase measurement
- Is the optimal **enforcement investment** location
- Creates the **cache miss** pattern visible in TraceLab workload traces

## Design Principle

> **Enforcement budgets should follow the transition locus, not uniform distribution.**

A system with N phases needs N-1 transition guards. Each guard should:
1. **Verify binding** — confirm that references from Phase N correctly resolve in Phase N+1's representation space
2. **Gate progression** — prevent forward movement until binding is verified
3. **Preserve provenance** — maintain which Phase N decisions led to which Phase N+1 bindings
4. **Detect representation shift** — flag when Phase N+1's context is incompatible with Phase N's assumptions

## Connections

- **Dereference Crisis** (scan #98-102): Identified state-addressing as the failure mode. The Transition Locus identifies WHERE those failures concentrate — at phase boundaries where context representation changes.
- **Compilation Gradient** (Stage 3): Statewright IS the Stage 3 pattern applied specifically to phase transitions. The gradient's "compiled enforcement" gains maximum leverage when targeted at transition boundaries.
- **Decoupling Cascade**: The reason decoupling works is that it creates explicit transition boundaries where enforcement can be placed. Tight coupling obscures transitions — they happen implicitly.
- **Safety Inversion** (#282): Safety mechanisms that don't respect phase boundaries become self-defeating because they apply uniform pressure where differential treatment is needed.
- **Self-Revision Surface** (#281): Self-revision is dangerous specifically because it crosses phase boundaries (belief→action, world-model→plan) without governance at the crossing.
- **Entity Binding** (#265): The canonical proof that within-phase correctness (tool selection) and cross-phase correctness (entity binding) are orthogonal dimensions.

## Implication for Our System

Our system has phase boundaries everywhere:
- **Session boundaries**: context loading → execution → reporting
- **Delegation boundaries**: parent task understanding → child task specification
- **Knowledge boundaries**: observation → extraction → persistence
- **Evaluation boundaries**: measurement → inference → action

The Transition Locus predicts that failures concentrate at these boundaries. Current enforcement (AGENTS.md, context files, heartbeats) is mostly within-phase guidance. The highest-leverage intervention would be explicit transition verification: before the system moves from one phase to another, verify that bindings are correct.
