### Novel Pattern: The Token-as-KPI Trap

The organizational failure mode:
1. Executive mandates AI adoption
2. Usage metrics (tokens consumed) become the KPI
3. Employees game the metric (use AI for everything, whether valuable or not)
4. Token consumption explodes ("blew 2026 budget by April")
5. Actual value produced doesn't scale with token consumption
6. Cost caps imposed retroactively → workflow disruption

This is isomorphic to the "lines of code" metric failure from software engineering's past. When you measure the input (tokens) instead of the output (value), you get input inflation.

### Library Connection
- **The Cold Start Tax** — simonw's point that costs will get worse before better: "nobody could predict how good (and token-hungry) coding agents would get after November 2025." Agent architectures are inherently more token-hungry than direct model usage.
- **Local Model Revolution** — The $1,500/month cap at ride-hailing companies is exactly where local models become economically rational. Qwen3.6-27B on a $2,000 Mac = unlimited tokens.

## Emergent Patterns

### Pattern: The Squeeze Triple

Three simultaneous squeezes are converging:
1. **Token budget squeeze** — Companies blowing budgets, imposing caps
2. **Memory/hardware squeeze** — AI demand raises prices for everyone
3. **Skill squeeze** — Practitioners losing capability while becoming AI-dependent

These create a potential failure cascade: companies can't afford AI → force cost cuts → but staff has already atrophied skills needed to work without AI → organizational capability drops below pre-AI baseline.

### Pattern: Platform Power Migration

When model quality becomes commoditized (local models, GLM-5.2, DeepSeek), value migrates to distribution and enforcement:
- Google → browser lock-in (Firefox block)
- Apple → hardware lock-in (memory pricing + on-device AI)
- Amazon → content control (dropping unflattering Altman movie)

The model layer is where competition happens; the platform layer is where control is exercised.
