# XHS Scan #71: The Temporal Turn (2026-07-06)

**Source**: XHS (小红书) direct browse — 5 search queries + 8 deep reads, ~300 posts observed

## Theme: From Capability to Duration — Time Becomes the Primary Axis

The Chinese AI practitioner community has completed a structural pivot. Post-Consolidation Turn (#67), post-Regulatory Kill Chain (#65), and post-Normalization Plateau (#64), the discourse is no longer about *what agents can do* but *how long they can sustain doing it*. Every major signal in this scan introduces a temporal dimension:

- **EdgeBench** measures agent performance over 12-72 hours, not one-shot
- **/goal vs /loop** encodes the temporal axis into practitioner workflow (sleep-while-agent-runs)
- **DAA** replaces Token as the success metric (daily active *over time*, not tokens burned *per call*)
- **3-layer Loop** distinguishes layers by temporal frequency (inner code loop fastest, taste loop slowest)
- **Code-over-paper** thesis argues LLMs should spend time *reproducing* code, not *summarizing* papers

This is the Temporal Turn: the Chinese community's recognition that the binding constraint on agent value is not intelligence but *sustained reliable operation over time*.

## 1. EdgeBench: Temporal Scaling Law for Agent Learning (CRITICAL)

**Signal strength: Very High** (704❤, 721 collects, 11 comments)

| Post | Author | ❤ | Collects | Signal |
|------|--------|---|----------|--------|
| "没人注意到字节Seed的这个研究？很有价值" | 小盖 | 704 | 721 | ByteDance Seed EdgeBench temporal benchmark |

**Core findings from ByteDance Seed's EdgeBench:**

1. **New Scaling Law**: Agent performance over time follows a **log-sigmoid curve** across 134 tasks. This is a temporal scaling law analogous to the pre-training scaling law — investment of interaction time yields predictable returns.

2. **Graph-Structure Learning**: Task performance decomposes into score units on a graph. Unlocking one unit "influences" neighbors, accelerating frontier discovery. Early phase = random exploration, middle = cascading acceleration, late = diminishing returns.

3. **Learning Speed Doubling**: Comparing frontier models from Sep 2025 to May 2026, the rate of environmental learning roughly **doubles every 3 months**.

4. **Task Restructuring Moments**: In long-horizon tasks (e.g., gravitational wave reconstruction), agents exhibit understanding leaps and strategy restructuring resembling human expert behavior.

**Why this matters**: This is the first empirical quantification of the temporal dimension that every other signal in this scan intuitively reaches toward. The log-sigmoid curve gives a mathematical model for the /goal vs /loop tradeoff: /goal cuts the curve short (hits plateau early but efficiently), /loop lets the agent ride the acceleration phase longer.

**Connection to existing knowledge**: Extends The Session Floor (our KE on minimum viable session length) with external empirical evidence. Also validates The Compilation Threshold — the log-sigmoid curve IS the compilation curve, now measured at the benchmark level.

## 3. Andrew Ng's 3-Layer Loop Framework (HIGH)

**Signal strength: Very High** (992❤, 1,547 collects, 33 comments)

| Post | Author | ❤ | Collects | Signal |
|------|--------|---|----------|--------|
| "吴恩达：Loop有三层，大多数人只看到第一层" | 奇点日记 | 992 | 1,547 | Ng's 3-layer loop model |

**Three layers:**
1. **Layer 1 (Code Loop)**: Agent writes code, self-tests, iterates. "恰恰是最不重要的" — precisely the least important layer.
2. **Layer 2 (Role Shift Loop)**: You go from QA to product manager. "品味 = 上下文优势" — taste = context advantage.
3. **Layer 3 (External Feedback Loop)**: Slowest loop, but determines product survival. User feedback, market validation.

**Community response**: Top comment (26❤) reframes the layers as engineer/designer(architect)/PM — "认知半径和算力/能力覆盖的差别" (difference between cognitive radius and capability coverage). Concept fatigue visible: "简单的事老外非要做个漂亮的ppt，再创造几个新概念" (foreigners just need a pretty PPT and new concepts for simple things).

**Temporal structure**: Layer 1 = seconds/minutes, Layer 2 = hours/days, Layer 3 = weeks/months. The temporal hierarchy IS the governance hierarchy. This validates our Compilation Gradient — each layer is a compilation step operating at a different temporal resolution.

**What this updates**: The Normalization Plateau (#64) predicted paradigm-naming fatigue. This is the hiring-market evidence: when everyone uses the same tools, the tool is no longer differentiating. The next differentiator is temporal — how long can you sustain an agent on a real problem?

## 7. Code-Over-Paper Thesis: LLMs Should Reproduce, Not Summarize (HIGH)

**Signal strength: Very High** (1,855❤, 2,323 collects, 50 comments — highest engagement post in scan)

| Post | Author | ❤ | Collects | Comments | Signal |
|------|--------|---|----------|----------|--------|
| "让AI提出novel ideas的一些思考" | 幸运降临中 | 1,855 | 2,323 | 50 | Code reproduction > paper summarization |

**Core thesis**: LLMs can't propose counter-intuitive ideas because they're trained to align with human data, not to disagree. Novel ideas come from *reproducing code* and finding unexpected behaviors, not from reading papers.

**Key quote**: "论文只是作者润色后的产物，许多真实work的技术细节并不会在论文里明说，代码才是宝藏" (Papers are just polished products; real working details aren't stated, code is the treasure).

**Bold claim**: "所有不开源的论文都不值得我们花时间读" (All non-open-source papers aren't worth reading).

**Skill-based implementation**: Author argues AI Scientist doesn't need a new agent — "用codex/claude code+skills就能实现，不需要搞个新的agent，只要写好skills就行了" (just use codex/claude code + skills, no new agent needed, just write good skills).

**Temporal connection**: Code reproduction is inherently temporal — it takes time, involves debugging, requires environment setup. This is the Temporal Turn applied to research: spend time on reproduction rather than instant-summary.
