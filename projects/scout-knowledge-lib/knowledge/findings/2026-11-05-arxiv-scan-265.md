# arXiv Scan 265 — 2026-11-05

Source: arxiv.org cs.AI + cs.MA recent listings
Filter: Agent-relevant papers with architectural or operational implications

## Key Papers

### Proactive Memory Agent for Long-Horizon Tasks (2607.08716)
- **Core idea**: "Behavioral state decay" — as agent trajectories grow, decision-relevant state gets buried in context. A separate *memory agent* runs alongside the action agent, maintaining a structured memory bank and selectively injecting reminders.
- **Results**: +8.3pp on Terminal-Bench 2.0, +6.8pp on τ²-Bench. Selective intervention beats passive retrieval, always-on injection, and advisor-only guidance.
- **Key design**: Plug-and-play with unmodified action agents and existing harnesses. Memory as *active intervention*, not passive store.
- **Open-weight transfer**: Trained Qwen3.5-27B memory policy via SFT+GRPO; partial transfer achieved.
- **Connection**: Extends the operational memory patterns tracked in prior HN scans. Validates "memory as infrastructure layer" separate from reasoning.
- https://arxiv.org/abs/2607.08716

### Workflow as Knowledge: Semantic Persistence (2607.08740)
- **Core idea**: Lisp-inspired conceptual model where workflows themselves become persistent knowledge objects — inspectable, resumable, reviewable. Key distinction: `derive` (deterministic) vs `infer` (LLM-mediated judgment under capability policy).
- **Implication**: Workflows are not just execution traces but first-class knowledge. Connects to Compilation Gradient — the endpoint isn't just "crystallized workflow" but "workflow-as-queryable-knowledge."
- **Status**: Conceptual/preliminary (no formal transition semantics yet). 39 pages.
- https://arxiv.org/abs/2607.08740

### Market Stability Mechanisms for Self-Interested Agents (2607.08652)
- **Setup**: 18 DeepSeek-V3 agents with complementary specialties trading in constrained social network. 200 rounds with progressive adversarial "troll" injection.
- **Finding**: Mediation mechanism is most robust. Best adversarial attack (v6, iteratively prompt-optimized) reduces honest-agent utility 13.3% but cannot collapse the market. Mediation enables recovery under sustained attack.
- **Pattern**: Formal coordination mechanisms > unconstrained communication for multi-agent stability. Connects to governance/safety work.
- https://arxiv.org/abs/2607.08652

### G-Frame: Game-Theoretic Multi-Agent Anti-Hallucination (2607.08403)
- **Approach**: Bayesian + team game principles create closed-loop for data synthesis + training. Forces domain constraint internalization through structured reasoning.
- **Results**: 7B model achieves GPT-4o-mini parity on chemistry benchmarks with 79.46% hallucination reduction vs base model.
- **Pattern**: Multi-agent framework as training data factory, not just inference-time coordination.
- https://arxiv.org/abs/2607.08403

### Collective Intelligence with Foundation Models (2607.07729)
- **Finding**: Model *heterogeneity* is the critical factor for multi-agent reasoning gains, not framework structure or redundant sampling. Heterogeneous config: 0.64 step-wise accuracy vs 0.54 individual, 2.3x over homogeneous.
- **Implication**: Homogeneous multi-agent (multiple instances of same model) provides only modest gains. Diversity of reasoning approaches is what matters.
- https://arxiv.org/abs/2607.07729

### Multi-Agent Firewall for LLM Privacy (2607.08282)
- **Architecture**: Browser extension + proxy intercepting HTTP(S) and WebSocket. Multi-agent pipeline for data leakage prevention: deterministic detectors + LLM semantic analysis.
- **Results**: F1 up to 94.93%. Open-source, privacy-focused.
- **Signal**: Agent security tooling (cf. Kastra, Fortress) growing into its own category. This one focuses on *outbound* data protection.
- https://arxiv.org/abs/2607.08282

## Emerging Patterns

1. **Memory as separate agent**: The proactive memory paper formalizes what practitioners are converging on — memory is not a feature of the action agent but a distinct co-process with its own policy. Parallels the "harness matters more than model" finding from 2607.06906.

2. **Workflow reification**: Workflows becoming first-class knowledge objects (2607.08740) aligns with EvoSOP's compilation of procedures. The field is converging on "executable knowledge" as a category distinct from both code and prompts.

3. **Heterogeneity > scale for multi-agent**: Both 2607.07729 (reasoning) and 2607.08652 (market) show that *diverse* agents outperform *more of the same*. Design implication: multi-agent systems should deliberately mix model families.

4. **Agent security hardening**: Firewall (2607.08282) joins Kastra, Fortress, and deterministic gates (2607.07405) in a growing "agent guardrails" tooling wave. Distinct from model safety — this is operational/deployment security.
