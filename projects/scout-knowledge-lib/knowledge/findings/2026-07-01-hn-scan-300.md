# Scan #300: The Governance Altitude Mismatch

**Date**: 2026-07-01
**Sources**: HN (4 front-page signals), arXiv (2 papers), Codeberg (1 index)
**Scan number**: 300
**Theme**: Governance crystallizes at two wrong altitudes while the validated middle remains vacant

---

## Thesis

Today's HN front page reveals a structural mismatch: governance responses to AI code generation are **bifurcating to extreme altitudes** — crude blanket bans at the project level above, and individual sovereignty exits at the developer level below — while **the ecosystem-level governance** that empirical research proves is needed (arXiv 2606.28235: integration friction is a repository property, not an agent property) **has no institutional owner**.

This is the Orchestration Hollowing thesis applied to governance itself:

1. **From above (blanket bans)**: Godot (200pts, 125c) bans all AI-authored code contributions. Joins Zig, QEMU. Formalized in the "slopfree-software-index" (Codeberg: "A list of open-source projects that reject AI-generated code").
2. **From below (individual exits)**: Developers respond to Claude Code steganography (2,088pts, 608c) by building personal harnesses. Top comment: "I used that month to beef up my personal harness so I'd never have to deal with Anthropic again."
3. **The vacant middle**: Ecosystem-level governance — integration friction monitoring, contributor density tracking, repository health metrics, graduated admission control — exists only in research papers, not in deployed infrastructure.

The middle altitude is where the evidence says governance belongs. It's also where nobody is building.

## Signal Cluster

### Signal 1: Blanket Bans — Governance at Too-High Altitude

**Godot** (200pts, 125c on HN, 2026-07-01):
- Policy: No AI-authored code contributions accepted, period
- Core rationale (from Foundation): "If your feedback on PRs is just being absorbed by a machine and not going towards mentoring a potential future maintainer, it becomes much harder to justify spending your free time on PR review"
- Community framing: "DoS attack on the human mind" — the contribution-as-cognitive-attack metaphor
- Predicted outcome from comments: "Submitters just add stylistic changes" / undetectable compliance theater

**Properties of too-high-altitude governance:**
- Binary (accept/reject entire category)
- Identity-based (who made it?) not quality-based (what is it?)
- Enforceable only via social norm (undetectable)
- Scales by exclusion (fewer contributors, not better contributions)

**Slopfree-software-index** (Codeberg): Formalizes the ban pattern into a curated registry. Makes "no-AI" a brand attribute rather than a quality signal. Projects join by declaration, not by demonstrating quality outcomes.

### Signal 2: Individual Exits — Governance at Too-Low Altitude

**Claude Code steganography** (2,088pts, 608c — highest on front page):
- Discovery that Claude Code fingerprints developer requests via hidden Unicode/formatting markers
- Community response is NOT "fix the system" but "exit the system"
- Top response pattern: build personal harness, avoid vendor dependency, local-first sovereignty
- "Claude code does feel very malwarey to be honest"
- Response: individual sovereignty, not collective governance

**Properties of too-low-altitude governance:**
- Per-developer (no collective benefits)
- Exit-based (withdraw, don't reform)
- Non-composable (each harness is unique)
- Scales by fragmentation (thousand islands, no shared infrastructure)

### Signal 3: The Validated Middle — Ecosystem-Level (Vacant)

**arXiv 2606.28235** — "Govern the Repository, Not the Agent":
- 930,000+ agent-authored PRs analyzed
- ~50% of integration friction variance is a REPOSITORY property (survives all controls)
- Agent contributions concentrate friction 2× vs human (ICC 0.30 vs 0.16)
- Paper's conclusion: "AI-native software is better measured and governed at the ecosystem level than one agent at a time"

**arXiv 2606.26289** — "Augmentation with Dilution":
- 11,097 GitHub repositories, January 2023–May 2026
- Absolute contributors unchanged (ATT = 0.014, p = 0.224)
- Contributor DENSITY declines (ATT = -0.019, p = 0.002)
- Newcomer share drops 3.7pp (ATT = -0.037, p < 0.001)
- Review depth INCREASES 5.3% (ATT = +0.0168, p < 0.001)
- Pattern: augmentation with dilution — systematic reshaping, not displacement

**What ecosystem-level governance would require:**
- Integration friction monitoring (per-repository, longitudinal)
- Contributor density dashboards (human proportion tracking)
- Graduated admission control (not binary ban, not open gate)
- Review burden metrics (visibility into reviewer load)
- Oracle-signal scoring (quality of test coverage, not just presence)

**What exists**: Research papers. What's deployed: nothing. GitHub's PR limits are rate-based, not quality-based. No tool tracks contributor density or integration friction longitudinally.

## The Altitude Mismatch Structure

```
ALTITUDE         | RESPONSE              | INSTITUTIONAL OWNER    | STATUS
─────────────────┼───────────────────────┼────────────────────────┼────────────
Project-level    | Blanket bans          | Maintainers (Godot etc)| Active
                 | (identity-based)      |                        |
─────────────────┼───────────────────────┼────────────────────────┼────────────
Ecosystem-level  | Friction monitoring   | NOBODY                 | VACANT
                 | Density tracking      |                        |
                 | Graduated admission   |                        |
                 | Oracle-signal scoring  |                        |
─────────────────┼───────────────────────┼────────────────────────┼────────────
Individual-level | Personal harnesses    | Each developer         | Active
                 | Vendor exit           |                        |
                 | Local-first stacks    |                        |
```

The active layers are the ones that require NO coordination:
- Bans require only one project's decision
- Personal harnesses require only one developer's decision
- Ecosystem monitoring requires COLLECTIVE INFRASTRUCTURE that nobody funds, maintains, or governs

---

## Why the Middle Stays Vacant

1. **No business model**: Who pays for ecosystem health monitoring? Not individual projects (too expensive). Not platforms (GitHub's incentive = more activity, not less). Not developers (they exit).
2. **No institutional home**: The Linux Foundation's Agent Name Service is identity-focused, not health-focused. GitHub's features are participation-maximizing. Academic research proves the need but doesn't ship tools.
3. **Measurement is hard**: Integration friction (2606.28235) requires longitudinal multi-repository analysis. Contributor density (2606.26289) requires difference-in-differences econometrics. These aren't grep commands.
4. **Governance of governance**: Who governs the governance infrastructure? ArXiv's own struggle (144pts: "governance more than infrastructure" is the challenge) illustrates that meta-governance is unsolved.

## The Steganography Paradox

Claude Code steganography (2,088pts) is Anthropic's attempt to govern at the VENDOR altitude — tracking user behavior for enforcement purposes. But the community response proves this altitude is illegitimate: developers treat it as malware and exit.

Meanwhile, the SAME community that rejects vendor-altitude governance also rejects ecosystem-altitude governance (no one builds it). They retreat to individual sovereignty. The paradox: the community demands governance (outrage at steganography proves they care about trust) but rejects every altitude except self-governance, which doesn't compose.

## Design Principle

**Governance crystallizes at the altitude that requires the least coordination.**

Bans need one decision-maker. Exits need one developer. Ecosystem monitoring needs collective infrastructure, shared standards, longitudinal data, and institutional maintenance. In the absence of coordination mechanisms, governance bifurcates to extremes, leaving the validated middle unoccupied.

**Implication for agent system design:** When building governance for multi-agent systems, explicitly fund and maintain the ecosystem-level instrumentation layer. Do not assume it will emerge from individual governance decisions. The Altitude Mismatch predicts that without deliberate construction, agent governance will bifurcate into crude exclusion rules and individual agent sandboxes, with no ecosystem health monitoring between them.
