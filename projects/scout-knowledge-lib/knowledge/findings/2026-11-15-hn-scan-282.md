## Meta-Pattern: Protocol Debt

MCP's 0.023% spec compliance is the agent infrastructure equivalent of technical debt. The pattern:
1. Draft protocol gains rapid adoption
2. Spec evolves faster than implementations
3. Ecosystem fragments across spec versions
4. Governance tooling emerges reactively (spec-check, Kastra)

This mirrors early web standards (HTML/CSS spec fragmentation) but at compressed timescales. Agent architects should treat protocol versions as first-class dependencies.
