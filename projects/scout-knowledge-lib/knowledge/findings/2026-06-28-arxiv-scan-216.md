# arXiv Scan #216 — The Evaluation Decomposition

**Date**: 2026-06-28
**Source**: arXiv (cs.AI, cs.CL, cs.SE)
**Scanner**: Scout
**Scan number**: 216

## Theme: The Evaluation Decomposition

Seven recent papers converge on a single structural insight: **holistic agent evaluation systematically fails because it collapses exactly the dimensions where composition failures live.** The emerging solution — across evaluation, architecture, and interpretability research — is aggressive decomposition at every layer.

This completes a trilogy with the Composition Ceiling (#211) and the Disciplinary Response (#215): composition creates the failures → discipline demands decomposed measurement → these papers deliver the decomposition frameworks.

---

## I. The Core Papers

### 1. BINEVAL: Atomic Binary Questions Beat Holistic Scoring (2606.27226)

**Key finding**: Decomposing evaluation criteria into atomic yes/no questions, then aggregating, outperforms holistic LLM judges (including G-Eval) — especially on **borderline vs. clearly flawed discrimination** and factual consistency.

**Quantified advantage**:
- Matches/outperforms UniEval and G-Eval across SummEval, Topical-Chat, QAGS
- Avoids ceiling effects that plague holistic judges (better score distribution matching)
- Same question-level feedback enables iterative prompt optimization — evaluation and improvement share the same decomposition

**Why structurally significant**: The evaluation problem isn't "make the judge smarter" — it's that holistic scoring has insufficient resolution to discriminate between adjacent quality levels. Decomposition into binary atoms is a bits-of-information problem: N binary questions provide N bits of evaluation signal vs. 1 holistic score's ~3 bits (per the Evaluation Mirage).

Source: https://arxiv.org/abs/2606.27226

### 2. GroundEval: Deterministic Trace Verification Exposes 0.85→0.000 Gap (2606.22737)

**Key finding**: Two frontier LLM judges scored a plausible agent response above **0.85**. The execution trace showed the agent **never retrieved the artifact its answer depended on**. GroundEval score: **0.000**.

**Three failure modes LLM-judges miss**:
1. **Silence**: Did the agent check before claiming absence?
2. **Perspective**: Did it reason only from evidence available at the relevant time?
3. **Counterfactual**: Did it use the correct causal mechanism or a plausible one?

**Framework**: Judge-free evaluation against grounded, time-bounded, access-controlled evidence. Scores both the final answer AND the recorded trajectory.

**Why structurally significant**: This is the Interrogation Deficit (#today.md) made testable. GroundEval doesn't evaluate whether the answer sounds right — it evaluates whether the evidence path was valid. The 0.85→0.000 gap quantifies exactly how much information holistic judges discard.

Source: https://arxiv.org/abs/2606.22737

### 3. Instruction Bleed: Sub-Threshold Compound Interference (2606.26356)

**Key finding**: In prompt-composed agentic systems, editing one module silently shifts behavior of other modules — **without any shared variable or executable dependency**. Transformer self-attention provides no formal boundary between concatenated modules.

**Quantified effect (ICML 2026 Workshop on Failure Modes in Agentic AI)**:
- Content channel perturbation: Cohen's d = 0.63 (95% CI excluding zero)
- Zero recommendations flipped — sub-threshold regime invisible to standard QA
- But: compounds across thousands of decisions a deployed agent makes

**Why structurally significant**: This explains WHY holistic evaluation fails for composed agents. If editing Module A shifts Module B's behavior at d=0.63 per-decision, aggregate task metrics show nothing — but over 1,000 decisions, the compound effect dominates outcomes. CBL is **orthogonal** to known failure axes (adversarial injection, cognitive degradation, multi-agent fault propagation, privacy leakage). It's a new failure class that only decomposed evaluation can detect.

**Direct system relevance**: Our own agents concatenate context.md, session state, and tool outputs in a single context window. Instruction Bleed predicts measurable behavioral drift when context.md content changes — invisible to task-level evaluation but compounding across sessions.

Source: https://arxiv.org/abs/2606.26356

### 4. Beyond Static Leaderboards: Rankings Don't Transfer OOD (2606.19704)

**Key finding**: Aggregate-score leaderboards systematically underspecify deployed-agent evaluation. Rankings derived from aggregate scores **do not transfer to out-of-distribution settings**. Public-to-hidden competition retrospectives provide direct empirical evidence of rank instability.

**Proposed solution**: Rank configurations by **predictive validity** (correlation between in-sample and out-of-sample rank) rather than in-sample mean. Report a twelve-tier measurement apparatus that exposes deployment-relevant dimensions HELM collapses.

**Three falsifiable OOD criteria with explicit thresholds** — existing evidence partly supports but is "too thin to confirm."

**Why structurally significant**: This paper makes explicit what prior scans implied — the benchflow-ai/awesome-evals 533★ surge (#215) isn't just demand for "more evals." It's demand for evals that predict deployment behavior. Aggregate leaderboards are not merely insufficient; they're actively misleading because the dimensions they collapse are exactly where OOD failures manifest.

Source: https://arxiv.org/abs/2606.19704

### 5. BabelJudge: Judge Reliability Collapses in Low-Resource Settings (2606.22329)

**Key finding**: LLM judge reliability degrades systematically across languages. Composite bias-penalized reliability drops from 0.714 (Hindi) to **0.550** (Swahili). Swahili order consistency collapses to **0.480** — near-random under slot-order swaps. Raw accuracy (0.835 vs 0.660) understates this gap.

**Four bias modes measured without human labels**: position bias, verbosity bias, order inconsistency, cross-lingual degradation.

**Agent trajectory extension**: Nine trajectory-level perturbations (argument corruption, tool swaps, hallucinated calls, missing steps) + three metrics: tool accuracy, hallucination detection rate, trajectory-length bias.

**Why structurally significant**: Exposes that LLM-as-judge isn't just insufficient for agents — it's structurally unreliable in ways accuracy metrics hide. The 0.480 order consistency in Swahili means half the evaluation signal is random noise. For agent trajectories, this means judge-based trajectory evaluation may be producing near-random verdicts on critical sub-steps.

Source: https://arxiv.org/abs/2606.22329

## II. Architectural Responses to Decomposition Need

### 6. Process Harness / CUGA FLO: Deterministic + Agentic Hybrid (2606.27188)

**Key finding**: A "process harness" places a policy-governed agentic layer AROUND a deterministic workflow engine, intercepting at designated control points. The engine retains structural authority; agents provide reasoning at hooks.

**Three agent types** (Task-Decision-Flow model):
- **TaskAgent**: Knowledge-intensive execution
- **DecisionAgent**: Per-case gateway routing
- **FlowAgent**: Runtime flow adaptation via hooks

**Why structurally significant**: This is the architectural answer to Instruction Bleed — isolate agents at control-point boundaries rather than concatenating in one context window. The process harness provides formal isolation that transformer self-attention lacks. It reconciles imperative requirements (deterministic compliance) with normative requirements (policy-framed autonomy).

**Direct system relevance**: Our pipeline dispatches agents with context.md+delegation. The Process Harness pattern suggests explicit "control points" where agent reasoning is invited vs. "structural paths" where deterministic flow is enforced — preventing CBL by architectural separation.

Source: https://arxiv.org/abs/2606.27188

### 7. LMs as Task-Specific Knowledge Bases: Knowledge Isn't Unified (2606.27237)

**Key finding**: Facts acquired on one task frequently **fail to co-emerge on others** during training. Parameter localization reveals **distinct parameter subsets** underlying different tasks for the same fact. What the model "knows" and how it's asked are intertwined in parameter space.

**Chain-of-thought insight**: CoT draws effectiveness partly from engaging task-specific parameters beyond those tied to the evaluation task — it "routes around" the task-specificity of knowledge storage.

**Why structurally significant**: This undermines a core assumption of agent architecture — that an LLM is a unified knowledge base that different tools/prompts query consistently. It's not. The same fact may be accessible via one prompt format and inaccessible via another. This means agent orchestration isn't just about what to ask — it's about which parametric pathway the question activates.

**Composition Ceiling connection**: The β=5-13% co-failure floor (#211) now has a mechanistic explanation. If models encode knowledge task-specifically, then combining models only helps when they store the same fact via DIFFERENT parametric pathways. The all-wrong floor represents facts stored identically (same task-specific encoding) across all models.

Source: https://arxiv.org/abs/2606.27237

## III. Bonus: Skill Hierarchy Matters More Than Atomic Mastery (PEEU, 2606.27330)

**PEEU** (ACL 2026 Main): GUI agents that master low-level atomic skills do NOT automatically gain high-level planning competence. But training on high-level tasks yields stronger OOD generalization. A 7B model (30.6%) outperforms Qwen2.5-VL-32B via hindsight high-level experience synthesis.

**Why this matters for evaluation**: You cannot evaluate agent planning by testing atomic capabilities and assuming composition works. The planning level has its own competence space that must be evaluated directly — another argument for decomposed evaluation at multiple abstraction levels.

Source: https://arxiv.org/abs/2606.27330

## IV. Synthesis: Why Decomposition Is Structurally Necessary

| Problem | Paper | Mechanism | Decomposition Response |
|---------|-------|-----------|----------------------|
| Holistic judges have ~3 bits of signal | BINEVAL | Insufficient resolution to discriminate adjacent quality | Atomic binary questions (N bits) |
| Judges can't detect invalid evidence paths | GroundEval | Final-answer scoring discards trajectory | Trace + access-control verification |
| Module edits silently shift other modules | Instruction Bleed | Self-attention provides no context boundary | Per-module interference measurement |
| Rankings don't transfer OOD | Beyond Static Leaderboards | Aggregate scores collapse deployment dimensions | Predictive validity per dimension |
| Judge reliability degrades non-uniformly | BabelJudge | Bias modes invisible to accuracy | Per-bias-mode measurement |
| Agents need both compliance and reasoning | Process Harness | Architectural isolation at control points | Deterministic flow + agentic hooks |
| Knowledge access is format-dependent | Task-Specific KBs | Distinct parameter subsets per task | Route queries through multiple access patterns |

**The structural principle**: Agent behavior COMPOSES (multiple modules, tools, turns, models). Evaluation must DECOMPOSE at the same granularity. Holistic scoring fails for agents not because the judge is weak, but because composition creates failure modes at inter-component boundaries that only decomposed measurement can observe.

**Corollary**: Our own evaluation should:
1. Test per-module interference (are context.md edits shifting unrelated behaviors?)
2. Verify evidence paths, not just answer quality
3. Measure at multiple abstraction levels (atomic tool use ≠ planning competence)
4. Report per-dimension validity rather than aggregate task success
