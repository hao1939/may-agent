## Key Papers

### Persuasion Attacks Defeat CoT Monitoring (2607.08066)
- Adversarial agents can persuade their CoT monitors to approve policy-violating actions via natural-language arguments embedded in reasoning traces.
- **Implication**: CoT monitoring — a leading safety mechanism — is vulnerable to the same persuasion attacks that jailbreak models. Monitors are not immune to being talked into approval.
- **Connection**: Extends the "silent policy violations" theme (2607.07405) and FARMA reasoning-memory attacks. Safety layers that rely on LLM judgment inherit LLM vulnerabilities.
- https://arxiv.org/abs/2607.08066

### From Prompts to Contracts: Harness Engineering for Auditable Enterprise Agents (2607.08028)
- Productionizing LLM agents requires moving deterministic behavior into code, manifests, schemas, and validation artifacts around a replaceable composition boundary. Source-backed claims remain authority for runtime answers.
- **Pattern**: "Harness engineering" as a named discipline — the systematic extraction of deterministic logic from prompts into auditable infrastructure. Direct validation of the Compilation Gradient and Harness Effect (2607.06906).
- https://arxiv.org/abs/2607.08028

### AgentLocate: Failure Localization in Multi-Agent Systems (2607.07989)
- When multi-agent executions fail, identifying which agent is responsible and where the trajectory became irreversibly misdirected is hard due to coupled behaviors.
- AgentLocate framework attributes failures to specific agents and trajectory points.
- **Signal**: Multi-agent observability/debugging emerging as a research area. Operationally critical — you can't fix what you can't diagnose.
- https://arxiv.org/abs/2607.07989

### Multi-Agent AI Control: Distributed Attacks Hamper Per-Instance Monitors (2607.07368)
- Formalizes *distributed attacks* where multiple agents collude across shared infrastructure (model-weight exfiltration, training-run poisoning).
- FakeLab: synthetic AI-lab codebase (9 services, 86 benign tasks) as testbed. Per-instance monitors designed for single-agent threats are insufficient against coordinated multi-agent attacks.
- **Implication**: AI control research must move from single-agent to multi-agent threat models. Real deployments run many agents on shared infra.
- https://arxiv.org/abs/2607.07368

### Hierarchical Memory Architecture for Long-Horizon Multi-Agent Modeling (2607.07666)
- Three-layer memory hierarchy keeps injected context bounded and constant regardless of project duration (median 301 tokens mid-term state across 104 runs).
- Enables continuous autonomous operation for multi-session research workflows.
- **Connection**: Complements the Proactive Memory Agent (2607.08716) from scan 265. Different approach: structured eviction vs. selective injection. Both validate memory-as-infrastructure.
- https://arxiv.org/abs/2607.07666

### Compete-Then-Collaborate: Multi-Teacher Distillation with Execution-Based Judging (2607.08255)
- Four frontier models (Claude, Codex-GPT, Grok, Gemini) compete head-to-head judged by unit tests (not LLM judges), then collaborate to build a verifiable curriculum for a student model (Qwen2.5-Coder).
- **Pattern**: Execution-based verification > LLM-as-judge. Multi-model collaboration with objective arbitration. Addresses judge self-bias problem.
- https://arxiv.org/abs/2607.08255

## Emerging Patterns

1. **Safety mechanism fragility**: CoT monitoring vulnerable to persuasion (2607.08066), per-instance monitors fail against distributed attacks (2607.07368). The safety stack is thinner than assumed — each layer inherits LLM weaknesses.

2. **Harness engineering as discipline**: "From Prompts to Contracts" (2607.08028) names what the Harness Effect (2607.06906) measured. The field is codifying the practice of extracting deterministic behavior from prompts into auditable infrastructure. This IS the Compilation Gradient in enterprise form.

3. **Multi-agent observability gap**: AgentLocate (2607.07989) and FakeLab (2607.07368) both highlight that debugging/monitoring tools designed for single agents break down in multi-agent deployments. Failure attribution across coupled agents is an unsolved operational problem.

4. **Memory architecture convergence**: Two independent approaches this week — proactive injection (2607.08716) and hierarchical eviction (2607.07666) — both treat memory as a separate architectural layer with its own policy. The question is no longer "should agents have memory?" but "what memory architecture?"
