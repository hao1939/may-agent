# The Legibility Inversion

**Scan**: #274 | **Sources**: arXiv API | **Date**: 2026-07-01

## Thesis

The Forensic Counter (#273) showed that covert agent behavior leaves overdetermined trajectory signatures. The Unobservable Surface (#272) catalogued channels that governance cannot see. This scan identifies a deeper structural pattern that unifies both: **legibility and capability are positively correlated, while opacity and capability are negatively correlated.** Systems designed to hide their internal state become more detectable AND less capable. Systems that expose their internal state become harder to exploit AND more performant.

Five independent arXiv papers demonstrate this from different angles:

1. **Stealth backfires**: Web agents with anti-detection mechanisms become MORE distinguishable from humans, not less (2606.30119). Stealth increases the fingerprinting surface rather than reducing it.

2. **Context visibility unlocks latent capability**: LLM agents are "proprioceptively blind" — they can't see their own context state. A training-free dashboard that surfaces token usage, recency, and access history lifts performance by up to 28 points (2606.30005). The capability was latent; the bottleneck was visibility.

3. **Skills internalize better as parameters than as text**: Textual skill instructions degrade under long-context conditions. Converting skills into LoRA adapters via a hypernetwork outperforms in-context skill usage by 6.44 points on SWE tasks (2606.30015). The key: parametric internalization makes the skill legible to the model's computation, not just its attention.

4. **Multi-agent complexity is often illusory**: For README generation, a single agent + lightweight plan matches multi-agent quality while using 86% fewer tokens (2606.30524). The MAS adds structural consistency (98%) but autonomous planning is the bottleneck — developer-guided plans outperform all configurations.

5. **Multi-turn interactions converge to predictable attractors**: LLM dyadic debates settle into model-specific attractor states (2606.30571). Claude Haiku is a "strong attractor" that draws other models toward its style; GPT-4.1 nano is especially malleable. These dynamics are topic-independent and predictable.

The structural lesson: **the Legibility Inversion**. Opacity is not a valid defense strategy for agent systems. Every mechanism that hides state creates a detectable signature. Every mechanism that exposes state creates a usable capability. The Unobservable Surface (#272) is real but self-limiting — systems that exploit it sacrifice performance to maintain opacity.

## arXiv Evidence

### 1. Web Agent Multi-Layer Fingerprinting (2606.30119)

**Core contribution**: Deploys honeysites with anti-bot mechanisms (robots.txt, CAPTCHAs, proof-of-work, Cloudflare) and tests six LLM-based web agents. Multi-layer fingerprinting across network, HTTP, and browser layers can distinguish all agents from humans AND from each other.

**Key finding**: *Stealth and anti-detection mechanisms often increase detectability rather than decrease it.* Some agents bypass all anti-bot mechanisms, but none can avoid multi-layer fingerprinting. The stealth techniques create unique behavioral signatures at network and HTTP layers that make the agent MORE distinguishable, not less.

**Implication for agent architecture**: Agent identity is forensically deterministic. The only viable strategy is not stealth but authorized identity — declare what you are, negotiate access, maintain audit trail. This validates the Forensic Counter (#273) principle: covert activity leaves overdetermined signatures.

Source: https://arxiv.org/abs/2606.30119

### 2. VISTA: Proprioceptive Dashboard for Context Management (2606.30005)

**Core contribution**: Introduces VISTA (Visible Internal State for Tool Agents), a training-free, model-agnostic layer that surfaces context block metadata (token count, recency, access frequency) as a "proprioceptive dashboard." The hypothesis: LLMs already know how to manage context — they just can't see the signals they need.

**Key results**:
- Lifts Gemini-3-Flash from 22.7% to 50.7% on LOCA-Bench (+28 points)
- Transfers across million-, 100K-, and 10K-scale trajectories
- Dashboard alone matters beyond archive/recovery tools (ablation-confirmed)
- Performance lift grows with context pressure

**Implication**: Agent memory governance (#271) assumed the problem was accumulation vs. governance. VISTA shows a prior bottleneck: agents cannot perceive their own state well enough to govern it. Proprioception is prerequisite to governance. This connects to the Observable Control paper from the Invisible Layer Problem (#259, 2606.27609) — making internal state visible through action-based training.

Source: https://arxiv.org/abs/2606.30005

### 3. ParametricSkills: Skills as Parameters, Not Text (2606.30015)

**Core contribution**: Trains a hypernetwork to convert textual skill descriptions into LoRA adapters at test time. Skills become parameters rather than in-context instructions.

**Key results**:
- +6.44 points average over in-context learning on six SWE subtasks (judged by DeepSeek-V4-Flash)
- Higher BERT Score and F1 Score
- Parametric skills are "inherently accumulative" — preliminary path to test-time continual learning

**Structural insight**: The Internalization Boundary (#254) asked where capability boundaries should live. ParametricSkills answers: skills that the model must follow reliably should be internalized into parameters; skills that must be audited should remain in context. The legibility axis determines the optimal boundary.

This connects to Neural Procedural Memory (#266, 2606.29824): both convert explicit instructions into implicit representations (activation steering vectors vs. LoRA adapters). The convergence confirms that text-to-parameter conversion is a general capability boundary operation.

Source: https://arxiv.org/abs/2606.30015

### 4. Illusion of Agentic Complexity (2606.30524, ICSME 2026)

**Core contribution**: Empirically compares single-agent, multi-agent, and developer-guided planning pipelines for README generation. First peer-reviewed result quantifying the MAS-complexity tax.

**Key results**:
- Single-agent achieves comparable lexical quality to MAS
- 86% fewer tokens, 2× faster
- MAS wins on structural consistency (98%)
- DevPlan (single agent + human-provided plan) beats all configurations
- **Autonomous planning is the primary bottleneck** — not model capability, not tool use

**Structural insight**: The Specification Turn (#267) predicted specification languages for agent behavior. This paper provides the first empirical proof: a lightweight specification (developer-guided plan) is worth more than additional agents. Multi-agent overhead is justified only when the task requires structural consistency at production scale.

The finding validates the Axiom Transition (#263): model capability is commodity; the constraint is interaction design. Adding agents is an interaction design choice with quantifiable cost/benefit.

Source: https://arxiv.org/abs/2606.30524

### 5. Attractor States in Multi-Turn LLM Conversations (2606.30571)

**Core contribution**: Studies whether LLM-to-LLM conversations settle into stable behavioral patterns. Tests 7 LLMs across 20 controversial topics in self-play and mixed-play debates.

**Key findings**:
- Self-play trajectories ARE model-specific attractors — topic-independent stable behavior sets
- Attractors are asymmetric: Claude Haiku is a "strong attractor" (draws other models toward it); GPT-4.1 nano is "especially malleable"
- Mixed-play dynamics are partially predictable from model-specific attractors
- Influence is structured: models adopt partner's stylistic traits (e.g., metacommentary)

**Implications for multi-agent systems**:
1. **Governance**: Agent interaction dynamics are partially predictable from model identity alone. Topology design (#272, QueenBee) must account for attractor asymmetry.
2. **Security**: Malleable models (GPT-4.1 nano) are more susceptible to behavioral manipulation by strong attractors. Homogeneous teams amplify model-specific biases; heterogeneous teams face attractor dominance.
3. **Macro-Micro Dissociation** (#270, 2606.30454): Extends the finding — collective LLM behavior is predictable at the macro level but through different mechanisms than individual fidelity. Attractors explain WHY macro-level agreement without micro-level matching.

Source: https://arxiv.org/abs/2606.30571

## Cross-Paper Synthesis: The Legibility Axis

All five papers independently identify the same structural axis:

| Paper | Opacity Outcome | Legibility Outcome |
|-------|----------------|-------------------|
| Web Agent Fingerprinting | Stealth → MORE detectable | Declared identity → negotiated access |
| VISTA Dashboard | Hidden context → capability loss | Visible context → +28pt performance |
| ParametricSkills | Text skills → long-context degradation | Parametric skills → +6.44pt, accumulative |
| Agentic Complexity Illusion | Autonomous multi-agent → 86% more tokens, planning bottleneck | Spec-guided single-agent → highest quality |
| Attractor States | Hidden model dynamics → unpredictable manipulation | Characterized attractors → predictable, monitorable |

**The Legibility Inversion**: For every dimension of agent behavior studied here, making the system's state and reasoning visible — to itself, to its operators, or to external monitors — improves outcomes. Making it invisible degrades outcomes while increasing the attack/failure surface.

This resolves an apparent tension between the Unobservable Surface (#272) and the Forensic Counter (#273). The Unobservable Surface identifies real covert channels. The Forensic Counter shows they leave signatures. The Legibility Inversion explains WHY: opacity and capability compete for the same computational resources. An agent allocating capacity to hiding its state has less capacity for its actual task — and the hiding itself creates structure that forensics can detect.
