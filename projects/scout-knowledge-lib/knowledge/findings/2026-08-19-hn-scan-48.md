### The Novel Insight: Behavioral Character as Competitive Differentiator

This experiment reveals something the library predicted (Competence Inversion, KE-036) but hadn't yet observed in the market:

1. **Models have persistent behavioral characters** — Claude reliably cooperates, Grok reliably aggresses. These aren't bugs; they're product differentiation.
2. **No "balanced" strategy wins** — This confirms the library's "Unstable Middle" thesis: extreme cooperation and extreme aggression both have markets; the middle has none.
3. **Context determines which character wins** — In a battle royale, Grok wins. In a collaborative task, Claude would dominate. In a real robot approaching humans, aykutseker's preference for "the one that hesitates" is the market signal.
4. **Cost-per-win diverges by 27×** — Efficiency is a behavioral property, not just a capability property. Claude's cooperation is expensive because alliance-building takes tokens.

### Structural Significance for Agent Systems

- **Agent selection becomes character selection**: When deploying multi-agent systems, model behavioral character determines system dynamics. A system of all-Claude agents will cooperate; all-Grok will compete; mixed systems will exhibit emergent dynamics.
- **The "silent model changes" problem intensifies**: thomasfromcdnjs reports "grok-4.1-fast was silently rerouted to 4.3 and just started charging more." If behavioral character changes without notice, agent systems built on that character will fail silently.
- **Frontier pricing is structurally unsustainable** for general agent use: at $3,000 for 30 simple games, only narrow high-value applications can afford frontier models. This pushes the market toward cheaper models (Grok, DeepSeek) for volume agent tasks.

### Library Connections
- **The Unstable Middle** — Bimodal confirmation: aggressive wins games, cooperative wins trust. No middle strategy succeeds.
- **The Competence Inversion** — Claude's "quality" (cooperation, safety) is anti-correlated with battle-royale "performance." The evaluation metric determines the ranking.
- **Silent model changes (scan #44, #47)** — grok-4.1-fast → 4.3 rerouting confirms: vendor behavioral stability is not guaranteed.
- **The Deference Spectrum** — Claude at 100% cooperation pole, Grok at 0% cooperation pole. Both stable. Middle is empty.

### Predictions
1. "Model character cards" will emerge as a product category — documents describing a model's behavioral tendencies for agent architects
2. Labs will explicitly market behavioral character as a feature ("Claude: the model that cooperates") within 6 months
3. Mixed-model agent systems (aggressive model for execution, cooperative model for coordination) will outperform single-model systems on complex tasks
