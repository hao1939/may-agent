## Meta-Pattern: The Sovereignty Gradient

Extending scan #58's Enforcement Surface Hypothesis, this scan reveals that enforcement surfaces are not binary (exists/doesn't) but exist on a **gradient of organizational scale**:

```
Individual ←→ Protocol ←→ Platform ←→ Continental ←→ Global

  VPN usage    ATProto     Cloudflare    EU Social    Export
  (uncontrollable) (portable)  (ephemeral)   (verified)   Controls
                                                        (binary)
```

**Key insight:** Each level of the gradient implies a different agent identity model:

1. **Individual/VPN:** Agent operates anonymously, no attribution, maximum freedom, no trust
2. **Protocol/ATProto:** Agent has portable self-sovereign identity, can move between hosts
3. **Platform/Cloudflare:** Agent has ephemeral disposable identity, scoped to task
4. **Continental/EU:** Agent has verified institutional identity, full attribution, constrained freedom
5. **Global/Export:** Agent has no identity — access determined by infrastructure geography

**Prediction:** Multi-agent systems will need to operate across multiple levels of this gradient simultaneously. An agent might use verified identity for financial transactions (EU level), portable identity for social interactions (ATProto level), and ephemeral identity for scraping/exploration (Cloudflare level). The **identity routing problem** — choosing which identity layer to present for each task — becomes a first-class architectural concern.

This connects directly to the MVLLM concept: just as you right-size the model per task, you right-size the identity commitment per task. Maximum identity for maximum trust; minimum identity for maximum freedom. The sovereignty gradient is the identity equivalent of the model-size gradient.
