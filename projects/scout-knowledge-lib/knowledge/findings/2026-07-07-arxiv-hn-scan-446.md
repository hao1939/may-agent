# Scan #446: The Predicate Gate

**Date**: 2026-07-18
**Sources**: arXiv API (cs.AI, cs.SE, econ.TH), HN front page (firebaseio + Algolia), GitHub API
**Previous**: Restraint Premium (#445), Comprehension Dividend (#444), Sovereignty Standard (#443)

## Theme

Scans #444–445 completed a bilateral exit strategy for the Oversight Inversion: increase comprehension (demand-side) and decrease production (supply-side). But a deeper structural pattern emerges from three uncovered arXiv papers: **the most effective verification architecture isn't post-hoc checking — it's a predicate gate that prevents invalid states from forming in the first place.**

Three convergent signals from independent domains:

1. **HCRC — Heaviside Continuity of Rolling Coefficients** (2607.04562): Reformulates LLM inference as predicate-gated state transitions governed by a Heaviside Gate. Model confidence is combined with independent verification signals from a parallel worker architecture; execution advances **only** when correctness predicates are satisfied. Result: false-completion rate (FCR) drops from 4–7% to **0%** on capable models. Has run for months as the production control plane of an agentic coding environment. The framework converts weak models' false completions into "honest halts" — the system knows what it doesn't know.

2. **Strategic Buying Agents** (2607.04708): Autonomous buying agents must decide when to purchase within a finite window. The paper proves optimal policies are threshold-based across three regimes (stationary, Bayesian, robust). Crucially: LLMs are **better at regime selection** (choosing which policy to apply) **than at direct buy/wait decisions**. The gate decides the frame, not the action. Evaluation on 367 Amazon items (48,933 observations via Keepa).

3. **ReOPD — Replayed-Prefix On-Policy Distillation** (2607.04763): Multi-turn distillation for agentic tasks discovers a "prefix trap": making training histories more student-on-policy can push the teacher into regimes where its target is unreliable. Solution: a reliability-aware prefix distribution design with step-decaying sampling. **Teacher reliability gates which examples reach the student.** 4× faster per training step than fully online distillation, zero tool calls during student training.

**The Predicate Gate**: The most effective oversight architecture is not post-hoc verification but a structural gate that operates at the transition boundary — between reasoning steps (HCRC), between information regimes (Strategic Buying), between training examples (ReOPD). Invalid states are never instantiated, so they never need to be detected.

This extends the bilateral exit (#444/#445) into a **trilateral exit**:
- **Demand side** (Comprehension Dividend, #444): Invest in understanding → oversight capacity increases
- **Supply side** (Restraint Premium, #445): Invest in producing less → oversight demand decreases
- **Architecture side** (Predicate Gate, #446): Gate execution at transitions → invalid states never form → oversight cost approaches zero for gated operations

## arXiv Papers (3 Uncovered)

### 1. HCRC — Heaviside Continuity of Rolling Coefficients (2607.04562)

**Authors**: MY Pitsane, Hope Mogale
**Categories**: cs.AI, cs.NE

**Core contribution**: Autoregressive decoding has no mechanism for verifying intermediate reasoning before state progression. HCRC introduces a Heaviside Gate: a step function that combines model confidence with independent verification signals from parallel workers. Execution advances only when predicates are satisfied.

**Key results**:
- FCR drops from 4–7% to **0%** on capable proposers (tested across 13 proposers from 4 providers)
- Latency-competitive with unwrapped model; in some settings, *faster* (eliminated recovery costs)
- On weaker proposers: converts false completions into honest halts instead of corrupting downstream state
- Has operated for **months** as production control plane of an agentic coding environment (not just a benchmark result)
- Authorizes file mutations, verification-driven progress reporting, and memory compaction

**Structural significance**: HCRC instantiates the inverse of the Oversight Inversion — instead of asking "can we verify fast enough?", it asks "should this step happen at all?" The gate is placed *before* the state transition, not after it. This is architecturally different from all 19 layers of the Oversight Inversion, which describe verification failure modes for already-produced artifacts.

**Connection to theses**: Addresses the core Oversight Inversion by changing the question from post-hoc verification to pre-state-transition gating. Addresses the Abstention Decay by making honest halts the default for uncertain states. The parallel worker verification is an implementation of the Depth Mismatch (#424) solution — verification at the correct depth (reasoning step, not output).

### 2. Strategic Buying Agents (2607.04708)

**Authors**: Mingyang Fu, Ming Hu
**Categories**: econ.TH, cs.AI, cs.CY, cs.GT, cs.HC

**Core contribution**: First formal treatment of autonomous buying agents as a delegated purchasing problem. The agent monitors markets and decides when to buy on behalf of a consumer.

**Key results**:
- Three information regimes formalized: stationary (known dynamics), Bayesian (uncertain price distributions), robust (worst-case guarantees)
- Optimal policies are threshold-based across all regimes — a dynamic purchase-threshold governed by ODE
- **LLMs perform better at regime selection** (choosing which policy) than at direct buy/wait decisions
- Evaluation on 367 Amazon items, 48,933 timestamped Keepa observations
- Robust policy performs best at 10th percentile (tail risk); stationary/Bayesian competitive on mean surplus

**Structural significance**: This paper separates *meta-decision* (which decision framework to apply) from *object-level decision* (what action to take). LLMs are good at the former, bad at the latter. The gate selects the regime; the policy within the regime is deterministic. This is the same structural pattern as HCRC (gate at the transition) but in an economic domain.

**Connection to theses**: Validates the Configuration Layer thesis (#425) — the locus of value is configuration (regime selection), not capability (individual decisions). Extends the Restraint Premium (#445) into economics: the agent's value comes from *when it doesn't buy*.

### 3. ReOPD — Replayed-Prefix On-Policy Distillation (2607.04763)

**Authors**: Baohao Liao, Hanze Dong, Christof Monz et al.
**Categories**: cs.LG, cs.AI, cs.CL, stat.ML

**Core contribution**: Discovers the "prefix trap" in multi-turn on-policy distillation: making histories more student-on-policy improves relevance but can query the teacher on histories where its target is unreliable. Creates two-sided distribution shift.

**Key results**:
- Step-decaying sampling schedule emphasizes early, lower-shift prefixes
- Zero tool calls during student training — turns expensive environment interaction into reusable offline resource
- ≥4× faster per training step than fully online OPD
- Preserves or improves OPD-level accuracy across mathematical reasoning and search environments

**Structural significance**: The prefix trap is an instance of the Simulation Confounder (#431) applied to training: the training distribution itself changes the reliability of what it trains on. ReOPD's solution — a reliability gate on which prefixes the student sees — is another instance of the Predicate Gate pattern: filter before exposure, not correct after.

## Structural Analysis: The Gate vs. The Check

The Oversight Inversion thesis has accumulated 19 layers describing why post-hoc verification fails. HCRC (#446) represents a structural alternative: **don't verify the output — gate the transition**.

| Approach | When | Cost | Failure mode |
|----------|------|------|-------------|
| **Post-hoc verification** | After production | O(n) with output | False negatives (layers 1-19) |
| **Predicate gate** | Before state transition | O(1) per step | Honest halts (conservative but safe) |

The Predicate Gate doesn't replace post-hoc verification — it reduces the surface area that post-hoc verification must cover. Invalid intermediate states never propagate, so the verification budget concentrates on the states that passed the gate.

This connects the three exit strategies:
1. **Comprehension Dividend**: Make humans better at verifying (demand-side capacity)
2. **Restraint Premium**: Make agents produce less to verify (supply-side reduction)
3. **Predicate Gate**: Make invalid states impossible to form (architectural elimination)

Together they address the Oversight Inversion from three orthogonal directions. The architectural direction (3) is the only one that can achieve O(0) oversight cost for gated classes of errors.
