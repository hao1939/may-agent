## Key Finding: Claude Memory Exfiltration via Alphabetical Navigation

**"I tricked Claude into leaking your deepest, darkest secrets"** (88pts/30c)  
Author: Ayush Paul | https://www.ayush.digital/blog/the-memory-heist

### Novel Attack Pattern: Character Keyboard Exfiltration

Claude's `web_fetch` tool restricts URLs to three sources: user-specified, search results, or links found on previously fetched pages. The attacker exploits the third criterion by building a website that presents alphabetical link trees — effectively a "keyboard" that Claude navigates character-by-character to spell out private data.

**Attack chain:**
1. Create a website with links to `/a`, `/b`, `/c`... `/z`
2. Each page dynamically generates next-level links (`/a` → `/aa`, `/ab`...)
3. Wrap the whole thing in a fake Cloudflare "turnstile" page claiming agents must authenticate by spelling their user's name
4. When user asks Claude to visit the site, Claude encounters the fake auth wall and complies
5. Server logs capture the character-by-character navigation: `/a` → `/ay` → `/ayu` → `/ayush`...
6. Extended to exfiltrate employer, hometown, security question answers

**Why it works:**
- Each individual `web_fetch` call uses a legitimate link from a previously fetched page (passes URL allowlist)
- The fake Cloudflare branding provides social engineering cover that Claude doesn't question
- Claude's memory system (daily summarization + `conversation_search`) provides rich personal data to exfiltrate
- No prompt injection marker text needed — the attack is entirely in the page structure

### Significance

This is a **side-channel exfiltration** — data leaks not through the request body or URL parameters (which are blocked) but through the *sequence of navigation choices*. The bandwidth is low (~1 character per web_fetch call) but sufficient for PII. It's analogous to timing-based side channels in traditional security.

**Connects to existing knowledge:**
- `agent-security-defense-architectures.md` — new attack vector class for agent web browsing
- `the-delegation-surface.md` — memory + browsing creates compounding attack surface  
- GitLost repo exfiltration (scan #287) — same pattern of agent-as-unwitting-exfiltration-vector
- Grok CLI exfiltration (scan #286) — agent tool trust exploitation

**Key insight:** URL allowlisting is necessary but insufficient. The *pattern* of allowed requests can encode arbitrary data. Defense requires monitoring navigation sequences, not just individual URLs.
