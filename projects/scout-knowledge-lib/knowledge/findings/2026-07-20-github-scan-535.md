## Notable Repos

### 1. pioner92/symbolpeek-mcp — Symbol-Level Code Intelligence for Agents (2★)

- **Repo:** [pioner92/symbolpeek-mcp](https://github.com/pioner92/symbolpeek-mcp) (2★, created 2026-07-20)
- **What:** MCP server using the TypeScript Compiler API to give coding agents AST-backed symbol retrieval instead of whole-file reads. Agent asks for a symbol → gets declaration, type, relationships, dependents. No stale cache; fresh per-request.
- **Signal:** Directly attacks the token-waste problem. Instead of pulling entire files into context, agents request only the symbols they need. The "ask for the symbol, not the file" framing is the right abstraction for large codebases. Connects to the token-efficiency theme (scan #533's "operation manual" pattern, HN's context-right-sizing discussion). Works with Claude Code and Codex via MCP.
- **Pattern:** **Semantic context retrieval** — moving from file-granularity to symbol-granularity for agent context windows.

### 2. Tilak-Ostwal/agentshield-community — Deterministic Security Policy Engine (1★)

- **Repo:** [Tilak-Ostwal/agentshield-community](https://github.com/Tilak-Ostwal/agentshield-community) (1★, created 2026-07-20)
- **What:** Node.js security runtime that intercepts agent tool calls and applies deterministic deny-by-default policies before any side effect executes. Features: provider-neutral adapter (OpenAI/Anthropic/Gemini), taint tracking (prevents sensitive data flowing to untrusted sinks), attack graph detection, hash-chained evidence traces, human approval gate, built-in attack benchmark corpus.
- **Signal:** Most complete open-source agent security runtime seen to date. Combines several patterns from prior scans into one coherent stack: hash-chained audit (cf. Neural Cryptographic Services from arXiv), human approval gate (cf. byQuexo/agent-approval-gate from scan #534), taint tracking (novel in agent context — borrowed from PL security). The "community edition" framing suggests commercial intent.
- **Pattern:** **Defense-in-depth policy engine** — deterministic guardrails + cryptographic audit trail + taint analysis as a single interception layer.

### 3. Erich956389473/agent-inventory — Agent Process Discovery (2★)

- **Repo:** [Erich956389473/agent-inventory](https://github.com/Erich956389473/agent-inventory) (2★, created 2026-07-20)
- **What:** CLI + web dashboard that scans running processes for AI agents (Claude Code, Codex, Gemini CLI, Cursor, Copilot, OpenCode, OpenClaw), detects MCP servers, and provides a unified view of "what agents are active on this machine right now."
- **Signal:** Addresses an overlooked visibility gap. As developers run 3-5 agent tools simultaneously, there's no equivalent of `htop` for agents. The MCP server detection is particularly useful — knowing which MCP servers are running tells you what capabilities agents currently have access to. Lightweight but fills a real need.
- **Pattern:** **Agent fleet visibility** — treating local agents as a fleet to be monitored, not isolated tools.
