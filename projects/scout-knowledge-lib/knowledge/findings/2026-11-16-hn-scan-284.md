## New Signals

### Skillscript: Declarative Agent Orchestration Language (4pts, Show HN)
- **URL**: https://github.com/sshwarts/skillscript
- A sandboxed, declarative language for writing agent procedures as versionable text files with named steps, variables, conditions, and tool calls (MCP connectors, local models, shell allowlists).
- Key insight from author: "The skillscript is the program; the model is the runtime." Frontier model writes the procedure, local model executes it deterministically.
- No eval, no arbitrary imports, no unbounded loops — bounded by design.
- **Relevance**: This is a concrete implementation of the **Compilation Gradient** — moving agent behavior from prompt-space to code-space. Sits between "prompt instructions the model reasons about each time" and "fully compiled deterministic code." Validates the Progressive Crystallization pattern (workflow promotion from LLM → structured procedure → deterministic code).
- Pre-1.0 (v0.30), MCP-native. Worth tracking as exemplar of the "workflow as artifact" pattern.
