## Summary

Jack Dorsey's Block launches **Buzz**, a platform that combines team chat, AI agents, and Git hosting into a single product. This represents a concrete bet that developer collaboration tooling should treat AI agents as first-class participants alongside humans — not bolt-on integrations but native platform citizens.

## Relevance to AI-Agent Systems

- **Agent-as-teammate pattern**: Agents integrated directly into chat/Git workflows rather than accessed through separate tool interfaces.
- **Infrastructure convergence**: Combines communication (Slack-like), version control (GitHub-like), and agent orchestration into one surface — reducing context switches for agent-assisted development.
- **Market signal**: High-profile founder betting that the next collaboration platform generation is agent-native from day one, not agent-augmented after the fact.

## Design Implications

- Chat-first agent interaction model (vs. IDE-first or CLI-first)
- Git-native agent contributions (agents commit directly)
- Shared context between human conversation and agent actions
