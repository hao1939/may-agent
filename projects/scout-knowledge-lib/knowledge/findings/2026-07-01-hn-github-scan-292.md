## Design Principle

**The Instrumentation Turn**: A governance need becomes real when it crosses from *identified* (papers describe it) through *formalized* (invariants are specified) through *enforced* (runtime checks exist) to **instrumented** (you can measure governance quality, benchmark it, audit it, price it). The field is currently crossing the formalized→instrumented boundary simultaneously at:
- Memory layer: GateMem benchmark
- Agent loop layer: loop-engineering audit tools  
- Enterprise security layer: defenseclaw production framework
- Authority layer: tandem runtime policies
- Export control layer: conditional access with vendor accountability letters

Once instrumented, governance becomes economic (auditable, insurable, contractable). This is irreversible — you cannot un-instrument a governance domain without losing the measurement infrastructure others now depend on.
