# HN Scan #120: The Vigilance Decay Cycle

*As agent code volume grows, human review quality degrades systematically — and the resulting biased approvals propagate through memory systems to permanently lower future agent output quality. A self-reinforcing cycle with no natural brake.*

**Scan date:** 2026-06-24  
**Previous scan:** #119 (The Iteration Paradox)  
**Sources:** HN (front page), arXiv (5 papers), GitHub (3 repos)  
**Synthesis type:** Cross-source convergence — five independent papers form a causal loop  

---

## Core Finding

Five papers published June 19-22, 2026, independently document different stages of what is structurally a single self-reinforcing degradation cycle:

```
Agent generates code
     ↓
Review volume grows
     ↓
Reviewers habituate → approval ↑, scrutiny ↓  [2606.22721]
     ↓
Lowered-standard approvals enter memory  [2606.23195]
     ↓
Self-evolving systems encode biased parameters permanently  [2606.23075]
     ↓
Agent code compounds → maintainability drops  [2606.21804]
     ↓
Authority lingers → expanded attack surface  [2606.22504]
     ↓
More generation needed to compensate...
     ↓
(cycle repeats with degraded baseline)
```

**This is the second-order effect of our Judgment Cost Inversion (scan #67).** That was: "implementation cheap → review expensive." Now we have the consequence: "review expensive → review quality drops → system quality drops → MORE generation needed."

## Signal 1: Habituation at the Gate (arXiv 2606.22721, Jun 21)

**The empirical proof that human oversight decays with exposure.**

- 400 repeat reviewers, 11,429 reviews over seven months (AIDev dataset)
- Population-level approval shift: 30.1% → 36.8% (p < 10⁻⁶)
- Cumulative gap reaches +14.5 percentage points from first to tenth experience decile
- **Experience-driven** (persists after controlling for calendar time)
- **Agent-specific** (human PR approval rates DECLINE over same period)
- Review latency increases +3.5× (growing queue backlog)
- Inline comment volume decreases -22% (p=0.0014)
- "Rising approval + declining comment effort + increasing queue time → reflexive habituation under workload, not rational trust calibration"

**Key insight:** The habituation is NOT because agents improve — agent code quality is constant. It's because human cognitive resources deplete under volume.

Source: https://arxiv.org/abs/2606.22721

## Signal 2: Memory Contagion (arXiv 2606.23195, Jun 22)

**Biased approvals propagate cross-temporally through shared memory.**

- When agents are trained/guided by biased evaluators, biased experiences enter memory stores
- Bias propagates to future agents retrieving from same memory — even with perfect consolidation (oracle condition)
- **No observed safe threshold**: propagation detected at contamination rates as low as p=0.2
- Consolidation has bias-type-dependent effects: attenuates length bias but amplifies authority bias
- "Memory Contagion occurs even with perfect consolidation — biased input is a SUFFICIENT cause"

**Connection:** Habituation at the Gate produces the biased evaluations. Memory Contagion shows they then propagate indefinitely. The combination is: human review decay → permanent system contamination.

Source: https://arxiv.org/abs/2606.23195

## Signal 3: Safety in Self-Evolving Systems (arXiv 2606.23075, Jun 22)

**Self-modifying systems permanently encode transient failures.**

- Module-Lifecycle Attack Surface (MLAS) matrix: 5 modules × 5 lifecycle stages = 25 cells
- **17/25 cells face critical threats with no effective partial mitigation**
- Evolution-native design activates 3.5× more attack surface cells vs. static systems
- **100% attack persistence rate** (40/40 payloads across all CIA+Privacy categories)
- Co-located security scanners block only 2.5% of attacks
- "Self-evolution converts every known attack category from session-bounded to lineage-persistent"

**Connection:** Memory Contagion shows biased inputs propagate. Self-Evolving Safety shows that in systems that update their own parameters/tools/memory, contamination becomes PERMANENT and SELF-AMPLIFYING across generations.

Source: https://arxiv.org/abs/2606.23075

## Signal 4: Lingering Authority / PORTICO (arXiv 2606.22504, Jun 21)

**Capabilities accumulate beyond the episode that justified them.**

- "Lingering authority": temporary capability remains exposed after justifying episode closes
- PORTICO reference monitor: compiles task contracts into initial capabilities + grant rules + closure predicates
- Non-revoking comparator permits 10/10 post-closure reuses; PORTICO rejects 10/10
- Broad request exposure raises blocked proposals from 67 to 84 (more attempted unauthorized access)
- First formal treatment of revocable capabilities for coding agents

**Connection:** As approval habituation grows, reviewers grant broader permissions per review. Without revocation mechanisms, these accumulate. The decay cycle widens the attack surface at every iteration.

Source: https://arxiv.org/abs/2606.22504

---

## Signal 5: Is Agent Code Less Maintainable? / CodeThread (arXiv 2606.21804, Jun 19)

**Agent code compounds downstream maintenance costs.**

- CodeThread framework: controlled experiments from repo-level coding benchmarks
- Agents are less effective resolving tasks when building on agent code vs human code
- **Resolve rate drops up to 13.1%** when building on prior agent output
- Traditional SE maintainability metrics don't explain the difference
- Clearest signals: "subtler behavioral differences" — input validation changes, error handling patterns
- Agent code creates a compounding tax: each generation degrades the next

**Connection:** Habituated reviewers approve agent code that creates compounding maintenance debt. Future agents building on this code perform 13% worse. More failures → more code generation → more review load → more habituation.

Source: https://arxiv.org/abs/2606.21804

## Synthesis: The Cycle Has No Natural Brake

Three structural properties prevent self-correction:

1. **Iteration Paradox (scan #119):** Fresh loops can't accumulate learning about which reviews matter — each starts from zero, so vigilance patterns can't improve
2. **Compaction Paradox (scan #115):** Context management erases governance constraints — the very policies that would enforce review standards get summarized away
3. **Communication Toxicity Gradient (scan #111):** Broadcasting the problem (shared review standards) follows a non-monotonic value curve — full sync increases hallucination 34%

**The only structural brakes observed:**
- **Will It Mythos? (228pts):** Persistence of attention — security models that maintain vigilance = specialized attention that doesn't habituate
- **PORTICO:** Capability revocation — external enforcement of authority boundaries
- **Negative Knowledge (scan #114):** Structured failure records — encoding WHAT NOT TO APPROVE

## Self-Application

Our system has partial protection:
- **Stigmergic memory** avoids Memory Contagion's broadcast mechanism (pull-based, not push)
- **File-mediated knowledge** allows explicit admission/eviction policy
- **No self-evolution** of parameters — static architecture is structurally immune to lineage persistence

But we ARE vulnerable to:
- Scout's own evaluation quality over time (do we habituate to "interesting"?)
- Knowledge accumulation without eviction (today.md grows)
- No automated quality signal on prior findings (no "resolve rate" equivalent)
