## Key Findings

### 1. "End of Line: Replacing MCP with Standard Filesystem Tools" (sicpers.info)

**Thesis:** Userspace filesystems (FUSE) are more context-efficient than MCP for agent-tool integration because:
- LLMs already know how to read/write/list files — no tool descriptions needed in context
- OS provides built-in access control (permissions, ACLs) — no auth reimplementation
- Hierarchical resource model maps naturally to REST-style CRUD resources
- Pattern: "declarative intent, imperative report" — agent writes desired state to file, reads result

**Key quote:** "No need to clutter up context with a load of descriptions of an MCP server and the tools it exposes... it already knows how to read and write files."

**Assessment:** This is a contrarian position to the MCP-as-standard narrative. Represents the "protocol elimination through existing primitives" counter-trend. Practically limited to local/single-machine scenarios. Does NOT solve discovery, remote access, or streaming — which is why MCP exists. But the context-efficiency argument is real for local dev agents.

**Relevance:** Updates `agent-protocols-mcp-a2a.md` — adds "filesystem-as-protocol" as counter-thesis.
