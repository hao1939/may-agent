## ★★★★ High Relevance

### [2607.11698] Agent Hacks Agent: Autoresearch for Production-Agent Red-Teaming (AHA)
- **Source**: https://arxiv.org/abs/2607.11698
- **Categories**: cs.AI
- **Summary**: Automated red-teaming system where one agent discovers reusable vulnerability knowledge about another (Claude Code, Codex). Uses a falsifiable discovery loop: propose vulnerability hypothesis → construct falsifier → instantiate attack → execute in sandbox → reflect → promote to a **Vulnerability Concept Graph (VCG)**. Each concept links attacker surface to unsafe trajectory with enabling conditions.
- **Key finding**: A frozen VCG (no further search needed) outperforms strongest discovery baseline by 14.2pp under single-shot protocol and transfers across scenarios/attack channels. Vulnerabilities form a reusable core across models.
- **Implication**: The VCG as auditable safety artifact is a compelling pattern — accumulating vulnerability *knowledge* rather than just attack *instances*. Directly relevant to our agent safety thinking. The "concept graph of exploits" parallels how we might think about defensive knowledge compilation.

### [2607.11250] Multi-Agent LLMs Fail to Explore Each Other (MACE)
- **Source**: https://arxiv.org/abs/2607.11250
- **Categories**: cs.AI
- **Summary**: Shows LLM agents exhibit myopic, polarized interaction patterns when exploring peer capabilities — leading to suboptimal coordination. Formalized as POSG problem. MACE framework adds structured peer selection to promote exploration. Theory shows value of exploration increases with agent diversity.
- **Key finding**: Current LLM agents have a fundamental exploration deficit in multi-agent settings. They don't probe peers to learn capabilities; they assume and commit too early.
- **Implication**: Critical for multi-agent system design. Agents need explicit mechanisms to discover what collaborators can do. Connects to our coordination-tax theme — the cost of not exploring is invisible until coordination fails.

### [2607.11346] Compile, Then Page: Executable SOP Programs for Procedural LLM Agents
- **Source**: https://arxiv.org/abs/2607.11346
- **Categories**: cs.AI
- **Summary**: Compiles SOPs into executable pseudo-code, runs them on a program-guided stack machine. LLM does semantic execution while the machine handles control flow. Active-frame paging (show only current frame) works for strong models but harms weak ones. Key insight: **capability-gated** — strong models benefit from structure, weak models are confused by it.
- **Key finding**: Compilation gain is 16pts in some domains. But runtime guidance is capability-gated: you need a "discipline check" before enabling paging. On Bank domain: 70.4 → 86.4 → 92.8 with 100% refusal correctness.
- **Implication**: Directly relevant to our compilation gradient thesis. SOPs as compiled programs is the next step beyond "prompt engineering." The capability-gating observation is crucial — not all agents benefit equally from structure.

## ★★★ Moderate-High Relevance

### [2607.11098] AgentCheck: Reproduce-Intervene-Mitigate Workbench for LLM Agents over MCP
- **Source**: https://arxiv.org/abs/2607.11098
- **Categories**: cs.AI
- **Summary**: Turns an MCP server into a fault injection surface. Records real tool responses, replays with perturbations (12 fault types), confirms fixes before deployment. Key finding: failures are usually *silent confident use of incorrect tool outputs* rather than crashes. Retry helps timeouts but not stale-data faults.
- **Implication**: First serious testing workbench built on MCP. The "silent confidence on wrong data" failure mode is exactly the hard problem. Relevant to our agent evaluation thinking and MCP protocol notes.

### [2607.11226] Heterogeneous Agent Cohorts for Safe Open-Ended Exploration with Runtime Constraint Memory
- **Source**: https://arxiv.org/abs/2607.11226
- **Categories**: cs.AI
- **Summary**: Separates creativity (Disrupter), safety (Validator), and novelty (Broker) across specialized roles. Failures compiled via MCTS into "Scars" — signed constraint patches cached and inherited by future cohorts. CAS (Communication Allocation Scores) reduce token costs 55.9%.
- **Key finding**: "Scars" as compiled failure memory that persists across cohort generations. Turns repeated failures into reusable runtime constraints. 15.1% token reduction from avoiding redundant validator checks.
- **Implication**: The "Scar" concept = compiled failure knowledge. Connects to our damage-gradient and session-floor themes. Persistent constraint memory across agent generations is a powerful pattern for long-running systems.

### [2607.11871] Inside the Unfair Judge: Mechanistic Interpretability of LLM-as-Judge Bias
- **Source**: https://arxiv.org/abs/2607.11871
- **Categories**: cs.AI
- **Summary**: Mechanistic interpretability account of why LLM-as-Judge exhibits systematic biases. (Full abstract not retrieved but title signals first mechanistic explanation of judge bias.)
- **Implication**: Relevant to evaluation-mirage theme. If we can explain *why* LLM judges are biased mechanistically, we can potentially correct for it rather than just documenting it.

### [2607.11787] Forgetting Our Way to Shared Meaning: Memory & Conceptual Alignment
- **Source**: https://arxiv.org/abs/2607.11787
- **Categories**: cs.MA (primary)
- **Summary**: Models how memory characteristics (adaptiveness, forgetting rate) affect emergence of shared meaning in multi-agent coordination games. Adaptive agents converge faster; non-adaptive agents *perceive* convergence earlier (false consensus). Weighing novel info less over time yields more stable agreements.
- **Implication**: Connects to agent memory patterns. The false-consensus finding (perceiving agreement before achieving it) is a failure mode for multi-agent systems with degraded memory.

## Cross-Cutting Themes This Scan

1. **Compiled knowledge > raw search**: AHA's VCG, Scars, Compile-Then-Page all show the same pattern — compile experience into reusable structured artifacts rather than re-discovering.
2. **Capability-gating**: Structure helps strong agents, hurts weak ones. Design must account for agent capability level.
3. **Silent failures**: AgentCheck confirms agents fail by confidently using wrong data, not by crashing. The hard failures are invisible.
4. **Exploration deficit**: MACE shows agents don't probe peers. Multi-agent coordination requires explicit exploration mechanisms.
