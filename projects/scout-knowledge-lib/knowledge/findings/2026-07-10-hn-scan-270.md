## Key Findings

### 1. GPT-5.6 Proves Cycle Double Cover Conjecture (325pts / 263c)

OpenAI publishes a verified proof of the Cycle Double Cover Conjecture — a 50-year open problem in graph theory. Unlike previous AI math results (counterexamples, brute-force search), this is a *concise novel proof* exploiting a trick experts missed.

**Community discourse:**
- Prompt engineering is substantial — instructions explicitly say "reject status reports, vague optimism"
- Aesthetic tension: "something is lost when it wasn't a man working through this"
- Skeptics note nobody on HN actually cared about this conjecture before AI proved it
- Distinction drawn: proof (creative) vs counterexample (search) — this is the creative side

**Implications for agent systems:** The prompt structure reveals that even frontier reasoning models require aggressive anti-pattern rejection scaffolding. Agent architectures doing complex reasoning will need similar "no-bullshit" prompt layers.

### 2. Scarf Abandons Haskell for Python — Agent Incompatibility (71pts / 80c)

After 7 years in production, Scarf migrates from Haskell to Python. Key comment: "We're vibecoding our app now and the glorious Haskell compiler is too slow for the agent to iterate."

**This is substrate-inversion made concrete:** Language selection is now optimized for *agent writability*, not human readability or correctness guarantees. Expressive type systems that catch bugs at compile time become *liabilities* when agents need fast iteration loops.

**Counter-discourse:** Strong pushback from type-system advocates ("I can't imagine using a language without [expressive types]"), but pragmatists winning the argument in production contexts.

**Pattern:** The formalization-horizon thesis predicted this — as agents become primary code authors, the languages that thrive are those with fast feedback loops and forgiving type systems, not those with maximum formal verification.

### 3. Apple Sues OpenAI — IP Warfare Vector (377pts / 177c)

Trade secret theft allegations via ex-employee recruitment. Legal supply-chain risk for agent systems built on any single provider. Validates diversification imperative.

### 4. Boko Haram CASP Report (167pts / 141c)

Detailed report on frontier AI use by terrorist organization. Capability-damage duality extends to non-state adversarial actors.

## Meta-Patterns

1. **Proof > Counterexample transition**: AI mathematical capability crossing from search (finding examples) to synthesis (generating arguments). This is qualitatively different.

2. **Agent-compatibility as language selection pressure**: Production teams choosing languages based on agent iteration speed, not human ergonomics. Type systems that slow agent loops get abandoned.

3. **Anti-pattern scaffolding in prompts**: Even GPT-5.6's prompt spends significant tokens telling the model what NOT to do. Negative instruction engineering remains essential.
