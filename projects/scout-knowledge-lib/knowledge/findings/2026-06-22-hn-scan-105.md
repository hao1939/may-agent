## Synthesis

**Agent containment infrastructure is proliferating into three distinct architectural strata — OS-kernel, ephemeral-process, and protocol-channel — while the HN front page simultaneously carries developer displacement discourse. The containment question has bifurcated: how do we contain agents AND what happens to the humans being contained out of the loop?**

### The Three-Stratum Containment Architecture

Previous scans identified the NEED for containment (Orchestration Hollowing removes orchestration, Authority Crystallization defines what remains, Skill Immune System places perimeter at skill boundary). This scan captures the IMPLEMENTATION wave — five substantive tools (all created since March 2026), each taking a different architectural position:

| Stratum | Tool | Stars | Approach | Key Primitive |
|---------|------|-------|----------|---------------|
| **OS-kernel** | hazmat | 121★ | macOS seatbelt + pf firewall + DNS blocklist | TLA+ verified containment spec |
| **Ephemeral-process** | sandboxd | 684★ | One-command dev sandboxes + preview URLs | No K8s, ephemeral isolation |
| **Ephemeral-process** | ExitBox | 102★ | "Complete isolation" for agent runs | Zero-trust execution boundary |
| **Protocol-channel** | wirken | 153★ | Per-channel isolation + encrypted vault | Hash-chained audit log (single Rust binary) |
| **Reconstructed-stack** | goclaw | 3,314★ | OpenClaw rebuilt in Go with 5-layer security | Multi-tenant isolation native |

**Key structural insight**: No single containment tool covers all three strata. Practitioners are building at the layer they control:
- **Platform engineers** → OS-kernel (hazmat: TLA+ verified, needs root)
- **SaaS operators** → ephemeral-process (sandboxd: no infra expertise needed)
- **Agent developers** → protocol-channel (wirken: per-session boundaries without OS access)

This mirrors how web security evolved: kernel (SELinux) → container (Docker) → protocol (CORS/CSP) — but compressed into ~3 months instead of ~15 years.

### The Human Containment Paradox

"Jobs and Software Is Fucked" (205pts/161c) on the same front page as Codex logging bug (429pts), Deno Desktop as agent substrate (974pts), and GLM 5.2 undercutting proprietary models (450pts):

> "I've seen people supposedly smarter than I advocate for just giving in, conceding to AI coding as it's the future. But doing so means tossing out my friends who make art..."

The discourse reveals a structural inversion: **the same containment infrastructure being built FOR agents is simultaneously being built AROUND human developers**:
- Codex writes TBs of logs (governance absence → agent unconstrained)
- Deno Desktop ships permission-scoped agent runtime (containment FOR agents)
- Developer hiring frozen → humans "contained out" of loop
- AI-replicability M&A tests (from scan #94) → code VALUE contained to governance layer

**Meta-pattern**: The Containment Substrate is simultaneously:
1. A defensive layer protecting systems FROM agents
2. An enabling layer allowing agents to replace humans safely
3. An economic layer determining which human roles remain inside the boundary
