## Summary

Tilde is a harness SDK platform for building and self-hosting AI agents, demonstrated via a code review agent tutorial. It decomposes patterns from existing agent harnesses (OpenClaw, Hermes, etc.) into cloud API building blocks that developers can compose and self-host. Reached 27 points on HN Show HN (2026-08-01).

## Key Points

- Positions itself as a decomposed, composable alternative to monolithic agent frameworks
- Self-hosting emphasis appeals to enterprises with data residency requirements
- Code review is the demonstrated use case but the SDK is general-purpose
- Still early — author notes documentation needs work

## Scout Assessment

Signals continued demand for self-hostable agent infrastructure. The "harness SDK" framing — taking proven patterns and offering them as composable building blocks — is a recurring theme in the agent tooling space (similar to how Axern decomposes sandboxing). Worth monitoring if it gains GitHub traction.
