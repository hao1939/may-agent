## Finding 1: LinkedIn Backdoor Becomes Mega-Narrative

**Story:** [A backdoor in a LinkedIn job offer](https://roman.pt/posts/linkedin-backdoor/) (542pts ↑ from 441pts scan-8, 109c ↑ from 87c)

The +23% growth since scan-8 (and +320% since scan-6's 129pts) has pushed this to #1 by position and past the 500pt mega-narrative threshold. Score trajectory: 129 → 311 → 441 → 542.

### What's crystallized since scan-8:

**1. Normalization of the attack vector.** The most important new signal is community recognition that this attack is indistinguishable from normal interview workflow:

- **aykutseker**: "This is uncomfortably close to a normal interview task now. Someone sends you a repo, says the install is broken, and asks you to take a look. A lot of developers would run npm install before thinking twice, especially if they were tired or looking for work."
- **alexandra_au**: "With how many recently made redundant software engineers out there, and the level of desperation to find a job, there are going to be scumbags out there trying to take advantage."

This is the critical agent-security insight: **the attack surface is the normal workflow**. An agent told to "review this candidate's code sample" or "evaluate this repo for hiring" executes the same steps as the human victim. No special vulnerability needed — just standard behavior in a context that's designed to look legitimate.

**2. Systemic platform failure confirmed.** BobAliceInATree notes: "I reported the repo to GitHub and the recruiter to LinkedIn. So far nothing has changed and the code is still up. Oh, Microsoft." Both GitHub and LinkedIn are owned by Microsoft, yet the attack vector persists across both platforms. For agents, this means platform-level trust signals (GitHub repo existence, LinkedIn profile verification) are insufficient.

**3. Meta-attack: clipboard truncation.** The fake VPN variant (from scan-8's dolebirchwood report) uses a visual deception where the visible terminal command shows `brew install openvpn` but the full clipboard payload includes hidden malicious code. This is a new class of attack on any system that copies and executes text — including agents that process terminal instructions from context.

**4. Defense consensus emerging.** rektlessness: "Throwaway VPS for interview coding tasks should be the new norm." binsquare: "Would highly recommend running any repo in an isolated environment like a VM." The community is converging on isolation-first as default, not opt-in.

### Agent defense implications update:

| Attack class | Human defense | Agent defense |
|---|---|---|
| Repo clone + lifecycle hooks | Throwaway VPS | Sandbox with no network during `install` |
| Clipboard truncation | Visual inspection | Parse/validate commands before execution |
| Social engineering provenance | Verify recruiter identity | Verify task source chain before code execution |
| Platform trust gap | Don't trust GitHub/LinkedIn existence as signal | Don't treat "hosted on reputable platform" as safety signal |

## Finding 2: Local Models Cross 600pts — Tool Ecosystem Expanding

**Story:** [Ask HN: Has anyone replaced Claude/GPT with a local model for daily coding?](https://news.ycombinator.com/item?id=48542100) (602pts ↑ from 557pts scan-8, 306c ↑ from 284c)

### New hardware and tool signals:

The consensus recipe from scan-5-8 (RTX 3090 + Qwen3.6-35B + llama.cpp + OpenCode) remains, but the ecosystem is expanding:

**New hardware configurations:**
- **jborak**: 4x RTX 5070 + first-gen Threadripper (1950X), running Qwen3.6 27B Q6_K at 50-60 tok/s with MTP
- **mgsram**: Mac Studio 512GB RAM running Qwen 3.6 27B dense model — choosing dense over MoE for accuracy
- **arjie**: 2x RTX Pro 6000 Blackwell running DeepSeek V4 Flash at 160 tok/s for automated code write+review pipeline
- **stymaar**: Bosgame M5 (Strix Halo 128GB) — laptop chip running as "negligible electricity" daily driver

**New tool layer signals:**
- **Bifrost** (jborak): LLM gateway connecting multiple applications (OpenWebUI, Pi, etc.) to a single local model. This is the **routing layer** emerging for self-hosted setups.
- **forge-code** (3abiton): zsh-integrated coding harness for Qwen. Minimal overhead, direct terminal integration.
- **Unsloth Studio** (horsawlarway): Model hosting platform being used as the inference backend for Pi harness — neither fully local nor cloud, a managed-self-hosted hybrid.

**The density ceiling signal (mgsram):**
"I have settled now on Qwen3.6 27B dense model in GGUF... I have also used the Qwen 3.6 35B-A3B but the dense model's accuracy is next level with the tradeoff being speed."

This reveals a **quality-speed fork**: practitioners who can afford the compute (512GB Mac Studio) are choosing dense models over MoE for accuracy, while budget-constrained users (RTX 3090) use MoE for speed. The local model movement is bifurcating.

**The automated pipeline signal (arjie):**
"I have 2x RTX Pro 6000 Blackwell running DeepSeek V4 Flash... For my use case, I have it auto-write code and another system auto-review the code."

This is the first self-hosted, fully automated code write+review pipeline reported in the thread — no human in the loop, dual-agent architecture on local hardware.

## Finding 4: Claude Corps — "AI Missionaries" Framing Hardens

**Story:** [Claude Corps](https://www.anthropic.com/news/claude-corps) (66pts ↑ from 42pts scan-5, 53c)

**+57% growth — fastest-growing AI story in this scan.** Community reception remains >90% skeptical, with the framing sharpening:

- **Isaackoz**: "I did not have AI missionaries on my bingo card this year."
- **6thbit**: "This lands with religious undertones for me, as it sounds like a missionary deployment program."
- **peterdemin** maps the money cascade: "Nvidia gives AI labs money to run their models. AI labs give money to AI engineers to use the models. Companies getting hooked. Engineers getting hooked." This names the **dependency chain** — Claude Corps is the last-mile delivery mechanism.
- **827a** (from scan-5, still the top comment): "Saddle nonprofits with functional but potentially very expensive systems, set up by someone who helps them for a year then disappears."
- **torben-friis** spots the future business model: "Models that are fully unavailable to company outsiders, you can just hire consultants that will be thin layers to the model." This describes a **model-as-service via human proxy** pattern — the opposite of API access.

### Agent-relevant implication:

Claude Corps is the first deployment of **human-agent pairs** into organizations. The fellow is the human, Claude is the agent. The value proposition is that the human supervises the agent and ensures organizational fit. But when the human leaves after 12 months, the organization has an agent-dependent workflow with no supervisor — this is the **orphaned agent** problem. The 12-month cliff is baked into the program design.
