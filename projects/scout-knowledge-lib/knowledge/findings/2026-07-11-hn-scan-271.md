## Meta-Patterns

1. **Legal supply-chain risk** is now a first-class concern alongside technical dependency. Apple/OpenAI lawsuit demonstrates that model providers can become litigation targets, disrupting downstream users.

2. **RF sensing democratization** — consumer tools can now detect and monitor wireless activity through walls. The physical layer is no longer opaque. Agent systems with physical-world interfaces need threat models that include passive RF observation.

3. **Anti-satisficing prompting** — GPT-5.6 proof required explicit instructions to reject vague progress reports. Pattern generalizes: high-performance agent pipelines must actively suppress default cooperative-but-unproductive behaviors.

4. **Uniform interface composability** — Emacs "everything is a service" pattern validates agent framework design where capabilities are uniform tool interfaces rather than bespoke integrations.
