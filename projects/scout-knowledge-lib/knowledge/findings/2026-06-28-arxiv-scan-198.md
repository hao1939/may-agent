## Key Papers

### 1. The Shift to Agentic AI: Evidence from Codex (2606.26959)

**Source**: https://arxiv.org/abs/2606.26959
**Authors**: Johnston, Holtz, Richmond, Ong, Tambe, Chatterji (OpenAI)
**Category**: econ.GN (Economics)

**Summary**: First large-scale empirical analysis of agentic AI adoption using OpenAI's own Codex usage data. Compares three populations: external personal accounts, external organizational accounts, and OpenAI internal workers. The paper provides unprecedented quantitative evidence of how agentic tools are restructuring work.

**Key Findings**:
- **5× user growth** in H1 2026, with fastest increase OUTSIDE the initial software developer audience
- **Within OpenAI, Codex has largely replaced ChatGPT** for business usage — the conversational interface is being superseded by the agentic one
- **10%+ of users manage 3+ concurrent agents weekly** — multi-agent orchestration is not a research aspiration but an operational reality
- **26.6% use "skills"** — shared instructions for complex workflows — indicating emergence of institutional agent knowledge
- **Task complexity increased ~10×**: share of users submitting requests estimated at >8 hours for an experienced human grew nearly tenfold
- **Output scaling**: Median OpenAI legal employee: 13× more monthly output tokens (Jun 2026 vs Nov 2025). Median researcher: **50× more output tokens**
- External organizational adoption is growing but lags internal adoption; personal accounts lag further

**Implications**:
- This is the first empirical confirmation that the chat→agent shift is structural, not incremental. ChatGPT becoming legacy within OpenAI itself validates the Commoditization Crisis prediction (#158) — the conversational interface is already commodity
- The 10× task complexity increase directly connects to the Supervision Cost Spiral (#191): if each task needs 10× more verification but human capacity is flat, supervision becomes the binding constraint
- 50× output token growth means 50× more to verify — Verification-Generation Inversion (#186) quantified from inside a frontier lab
- Multi-agent concurrent usage (10%+ managing 3+ agents) validates Infrastructure Legitimation (#197) at practitioner level
- Skills adoption (26.6%) shows governance artifacts (AGENTS.md, skills files) becoming operational reality — the Governance Artifact Gap (#188) matters

**Connection to Library**: This paper provides the quantitative foundation for multiple library themes simultaneously. It is the empirical keystone connecting adoption patterns to governance, verification, and supervision costs.

### 2. Scalability of Morality: Decoupling of Law and Ethics in Large-Scale Populations (2606.27039)

**Source**: https://arxiv.org/abs/2606.27039
**Authors**: Haghrah & Haghrah
**Category**: eess.SY / cs.MA
**Venue**: N/A (submitted Jun 25)

**Summary**: Mathematical framework using particle-based Monte Carlo simulations proving that when population N exceeds agent memory capacity L, decentralized peer-to-peer accountability collapses via a phase transition. Norms drift irreversibly toward a "minimalist legal floor."

**Key Findings**:
- Agents modeled as particles with finite memory L and stochastic choice profiles μ
- Phase transition: when N >> L, re-encounter probability drops as O(L/N)
- Below the threshold, local reciprocity enforces ethical norms; above it, anonymity destroys accountability
- **Hysteresis loop**: once norms decay, restoring them requires disproportionate effort — the process is irreversible (non-Markovian)
- The system inevitably drifts to whatever formal enforcement ("law") provides as a floor

**Implications for Agent Ecosystems**:
- The Codex paper (#1 above) shows N growing 5× in 6 months. Agent population is scaling exponentially
- Individual agent memory is bounded (context windows, retrieval stores)
- When agents can't re-encounter and remember prior interactions with specific peers, trust collapses to whatever the formal enforcement floor provides
- This mathematically formalizes the Trust Deficit Stack (#156): identity trust (3-15% real agents per ERC-8004 audit) IS the floor, and the floor is structural, not fixable by adding more agents
- The hysteresis result explains why trust is so hard to build in agent economies — once lost, restoration costs are super-linear
- **Direct relevance**: Our own library has 490+ files and growing. When the knowledge exceeds retrieval memory, the same phase transition applies — agents stop re-encountering relevant knowledge, and behavior decouples from documented norms

### 3. Parametric Open Source Games (2606.27068)

**Source**: https://arxiv.org/abs/2606.27068
**Authors**: Todorov, ten Napel, Müller
**Category**: cs.GT / cs.AI
**Venue**: ICML Workshop NExT-Game

**Summary**: Extends open-source game theory to continuous parameter spaces. When agents can inspect each other's internal parameterizations, a sharp coupling threshold exists at which selfish gradient ascent switches from defection to cooperation.

**Key Findings**:
- First exact coupling threshold for cooperation emergence in parametric games
- Neural semantics class: cooperation condition governed by ratio of cross-player to self-player sensitivity
- Sufficiently strong "open-source coupling" steers selfish optimization toward cooperative outcomes
- Access to internal parameterizations qualitatively reshapes equilibrium structure

**Implications**:
- Directly relevant to multi-agent system design: if agents can observe each other's parameters/policies (not just outputs), cooperation emerges naturally above a threshold
- This is the mathematical case for agent transparency — "open-source agents cooperate better" is now a theorem, not a hope
- Counter-case for the Opacity Spiral (#181): making agents more transparent (open-source coupling) may be the mechanism that prevents the spiral from degrading cooperation
- Suggests that agent protocols should include parameter/policy transparency as a design requirement, not just output transparency

### 4. EconSimulacra: Digital Twin of Socio-Economic Systems (2606.26883)

**Source**: https://arxiv.org/abs/2606.26883
**Authors**: Hashimoto, Kaneko, Ueda, Takayanagi, Izumi
**Category**: cs.DL

**Summary**: Multi-agent social simulator coupling consumer economy, mobility, and social networks through shared internal-state mechanism. Experiences across domains stored in memory and transformed into shared internal states connecting heterogeneous domains through individual decision making.

**Key Findings**:
- Shared internal state (e.g., stress level) connects heterogeneous domains (economy, mobility, social networks)
- Reproduces nonlinear relationship between online social attention and offline local popularity
- Demonstrates that cross-domain dynamics emerge from unified memory, not explicit coupling rules
- Memory → internal state → decision is the coupling mechanism

**Implications**:
- Validates the memory-mediated ecosystem dynamics finding from scan #195 (2606.07552v2): system-level effects transmit through accumulated memory, not through individual decisions
- The shared internal state mechanism is an implementation of what our library calls "stigmergy" — indirect coordination through shared environmental traces
- Relevant to multi-agent architectures: coupling through shared memory/state is more robust than coupling through explicit message-passing protocols

## Synthesis: The Adoption Phase Transition

These four papers, read together, describe a phase transition:

1. **Adoption is exponential, not linear** (Codex: 5× in 6 months, 10× task complexity, 50× output)
2. **Trust collapses at scale** (Morality Scalability: N >> L → accountability phase transition)
3. **Cooperation requires transparency** (Parametric Games: coupling threshold for cooperation)
4. **System dynamics are memory-mediated** (EconSimulacra: cross-domain coupling through shared state)

The structural consequence: we are adopting agentic AI faster than we can build the trust infrastructure to govern it. The Codex data shows N (agent population) growing 5× per half-year. The Morality paper proves accountability collapses when N >> L (memory). The Parametric Games paper shows the fix (transparency/coupling) but it requires open-source access to parameters — exactly what the Capture Spiral (#194) and political gatekeeping are preventing.

**Key Insight**: The adoption curve and the trust curve are diverging. Adoption is super-linear (Codex data). Trust infrastructure is sub-linear (governance artifacts are 58% single-commit, skills have 36% critical security issues per ToxicSkills). The gap between them is the systemic risk — and the Morality paper proves the gap exhibits hysteresis: once trust erodes past the phase transition, restoration is super-linear in cost.
