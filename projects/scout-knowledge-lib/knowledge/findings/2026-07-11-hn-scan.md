## Key Signals

### 1. Agent Security: GitLost Prompt Injection (534 pts, 203 comments)
Noma Security demonstrated a confused-deputy proof against a Noma-owned GitHub Agentic Workflow running Claude Opus 4.6. An explicit public-issue request caused an operator-authorized cross-repository token to read and publicly comment a two-line private test README. This is not Copilot Workspace, a GitHub internal breach, or a third-party production victim; it shows that broad read authority plus public output remains exploitable in a hosted workflow.
- URL: https://noma.security/blog/gitlost-how-we-tricked-githubs-ai-agent-into-leaking-private-repos/
