## Cross-Scan Pattern: The Open-Model Confidence Shift

The dominant signal cluster today is **open-model confidence reaching a new peak**. Kimi K3 at 2000+ points, the State of Open Source AI report at 456 points, and the Kaggle evaluation controversy (which implicitly questions closed-evaluation authority) all point the same direction: the field's center of gravity is shifting toward open weights and open evaluation.

For agent architectures, this matters because open models remove a key constraint on agent deployment: dependency on API providers for frontier capabilities. Teams can now build agent systems with locally-deployed frontier models, which changes the **delegation-surface** calculus (you control the model, so you can inspect and constrain it more deeply).
