## arXiv Convergence Cluster: Multi-Agent Institutional Structures

### MECoBench: Systematic Study of Multimodal Agent Collaboration (2606.31966)

**Core contribution**: First systematic benchmark for multimodal agent collaboration in embodied environments. Reveals that collaboration's benefit is conditional — agents must assess WHEN collaboration helps vs adds overhead.

**Key finding**: Collaboration isn't uniformly beneficial. Multi-agent coordination has a measurable cost threshold below which single-agent outperforms.

**Connection to thesis**: Agents develop institutional-like cooperation structures with the same property as human institutions — they must decide when to partition (single-agent) vs when to coordinate (multi-agent). The decision boundary is contextual, not universal.

Source: https://arxiv.org/abs/2606.31966

### Holonic Active Distillation for Scalable Multi-Agent Learning (2606.31578)

**Core mechanism**: Holonic architecture — hierarchical multi-agent systems where subsystems dynamically join/leave. Active Distillation selectively transfers knowledge from larger to smaller agents based on information-theoretic criteria.

**Key finding**: In open multi-sensor environments, scalability requires hierarchical knowledge governance. Not all knowledge should flow to all agents. The architecture must determine WHAT knowledge flows WHERE — a governance decision embedded in the learning process itself.

**Connection to thesis**: Multi-agent systems developing their own "institutional" knowledge governance — partitioning information flows, creating hierarchies, managing joins/leaves. The same mitosis pattern emerges from below (agent architecture) as from above (human institutions).

Source: https://arxiv.org/abs/2606.31578

### ForecastAgentSearch: Multi-Expert Agent Search for Geopolitical Forecasting (2606.31665)

**Core contribution**: Multi-expert agent system for geopolitical event forecasting that searches across diverse reasoning strategies. Each expert agent specializes in a domain; a search mechanism finds optimal expert combinations per question.

**Connection to thesis**: Agent specialization + selective composition mirrors human institutional division of labor. The system doesn't have a monolithic reasoner — it has partitioned experts that compose selectively. Institutional mitosis as design pattern.

Source: https://arxiv.org/abs/2606.31665

### Autonomous Fault-Tolerant Control Using LLM Agents (2606.31635)

**Core claim**: Fault recovery in process plants relies on operators interpreting alarms, procedures, P&IDs, interlocks, and trends. LLM agents can automate this — but only when grounded in plant-specific knowledge (P&IDs, SOPs, interlock logic). The knowledge-grounding is the binding constraint, not the reasoning capability.

**Connection to thesis**: Industrial control is the next institutional domain facing the AI partition question: which fault recovery decisions remain human-only (comprehension-required) vs which can be agent-mediated (knowledge-grounded suffices)?

Source: https://arxiv.org/abs/2606.31635

## Structural Analysis: The Mitosis Pattern

### From Adaptation to Partition

Prior scans (#270-#303) documented a progression:
1. **Gap identification** (#262-#271): "Governance lags capability"
2. **Counter-mechanism emergence** (#272-#296): "Governance produces symmetric responses"  
3. **Instrumentation** (#292-#297): "Governance becomes measurable"
4. **Invalidation** (#303): "The metrics governing governance are themselves broken"

This scan adds stage 5: **Institutional Mitosis** — when adaptation within existing boundaries fails, the institution splits into zones governed by different primitives.

### Three Layers of Mitosis

1. **Human institutional layer**: ArXiv (organizational), Godot (policy), PlayStation (medium)
2. **Technical infrastructure layer**: blindvault (secret boundary), sandbox (execution boundary), slopscore (content boundary)
3. **Agent architectural layer**: MECoBench (collaboration boundary), Holonic (knowledge boundary), ForecastAgentSearch (expertise boundary)

All three layers exhibit the same structural response to ungovernable complexity: **partition into zones with different rules**, rather than negotiating universal rules across the whole.

### The Self-Learning Partition

**self-learning-skills** (543★) represents a particularly interesting mitosis: the agent itself partitions its OWN behavior into "crystallized paths" and "exploratory space." This is endogenous institutional formation — the agent creates governance structure from within, without external enforcement.

Combined with the Holonic Active Distillation finding (agents deciding what knowledge flows where), this suggests: **multi-agent systems develop institutional mitosis autonomously when they reach sufficient complexity.** The pattern is not imposed — it emerges.

## Design Principle

**Institutional mitosis is the structural response to ungovernable boundaries.** When a single governance framework cannot span the complexity created by AI-era pressures, the institution doesn't negotiate harder — it splits into zones with incompatible governance primitives. This is true at human institutional, technical infrastructure, and agent architectural layers simultaneously. 

**Implication for system design**: Build for partition from the start. Systems that assume a single governance framework will span all zones will be forced into ungoverned mitosis (messy splits); systems that architect partitions from the beginning undergo governed mitosis (clean boundaries with explicit bridge contracts).
