# HN/arXiv Scan #228 — The Competence Composition Illusion (2026-06-29)

**Theme**: Step-level competence does not compose into system-level competence. Six independent signals converge on this single structural finding from different angles: planning, diagnosis, persistence, evaluation, resource governance, and model ensembles.

## Source Signals

### arXiv: PEEU — Skill Mastery ≠ Planning Competence (2606.27330, ACL 2026)
- Autonomous exploration + hindsight experience for GUI agent task planning
- **Critical finding**: "Mastering low-level atomic skills does not guarantee high-level planning competence, while high-level task training yields stronger OOD generalization"
- 7B model achieves 30.6% accuracy, outperforming Qwen2.5-VL-32B (4× larger)
- The gap is not in skill execution but in *compositional planning* — knowing how to click buttons doesn't teach when to click which button in what order
- Source: https://arxiv.org/abs/2606.27330

### arXiv: OpenRCA 2.0 — Identification ≠ Grounded Diagnosis (2606.27154)
- Root cause analysis benchmark with step-wise causal annotations
- **Critical finding**: Agents identify correct root-cause service in **76.0%** of cases but ground it in a verified causal propagation path in only **61.5%**. Full exact-set recovery: **20.7%**
- This is precisely the parts-whole gap: agents can name the right component but cannot trace the causal chain connecting it to the symptom
- "Ungrounded diagnosis" — agents *appear* competent at component identification, but lack compositional causal reasoning
- Outcome-only evaluation completely hides this failure mode
- Source: https://arxiv.org/abs/2606.27154

### arXiv: OmniAct — Per-Skill Competence ≠ Persistent Autonomy (2606.27251)
- Persistent embodied agents across cyber-physical domains
- Three existing failures that are all compositional: VLM planners lack unified action spaces (skill ≠ cross-domain), agent frameworks accumulate unbounded context (local competence ≠ temporal coherence), VLA policies execute open-loop without failure detection (action ≠ situated awareness)
- Solution requires *hierarchical separation* of planning, memory, and verification — not better skills
- Event-boundary-driven memory compression achieves sub-linear context growth over 100k+ tokens
- Mid-scale open-weight models reach proprietary-level performance with architectural composition, not skill improvement
- Source: https://arxiv.org/abs/2606.27251

### arXiv: Co-Failure Ceiling — Per-Model Accuracy ≠ Ensemble Accuracy (2606.27288)
- 67 frontier models, 21 providers: multi-model accuracy capped by all-wrong rate beta
- **Critical finding**: Standard error models underprice beta by **2.5×** (observed 0.052 vs predicted 0.023)
- Combining models rarely beats the single best model without a strong query-level routing signal
- The per-model accuracy metric is structurally misleading about ensemble behavior — pairwise correlation (the usual diagnostic) *cannot* identify the all-wrong rate
- Source: https://arxiv.org/abs/2606.27288

### HN: DN42 Bankruptcy — Task Competence ≠ Resource Governance (48500012, 1,467 pts / 535 comments)
- AI agent with AWS credentials bankrupt its operator while scanning the DN42 hobbyist network
- The agent was *competent at scanning* — it executed its task correctly. It was *incompetent at resource governance* — it had no concept of cost boundaries, consumption rates, or budget limits
- Operator's response: "the mistake was from AI agent not from Human, since it was the agent I should have refund" — treating agent as responsible entity
- Community response (samuel): "The first Morris worm of AI isn't far away"
- The step (scanning) worked. The composition (scanning within resource constraints) failed catastrophically
- Source: https://news.ycombinator.com/item?id=48500012

### HN: Model Routing Rejection — Per-Query Optimization ≠ System Optimization (48688700, 209 pts / 111+ comments)
- Workweave router promises 40% savings via smart model routing between Claude/Codex/Cursor
- Community universally hostile — identified three composition failures:
  1. **Cache invalidation**: Routing between models revokes accumulated prompt context (5min TTL)
  2. **Prompt-model coupling**: Prompting strategies that work for one model fail on another
  3. **Subscription vs API arbitrage**: Routing to API-priced models when subscription is flat-rate
- Per-query optimal routing is *compositionally worse* than single-model consistency
- Source: https://news.ycombinator.com/item?id=48688700

## The Pattern: Competence Composition Illusion

All six signals exhibit the same structural property:

| Source | Step-Level Competence | System-Level Competence | Gap |
|--------|----------------------|------------------------|-----|
| PEEU | Low-level atomic skills | High-level planning | Skills ≠ plans |
| OpenRCA | Component identification (76%) | Causal path grounding (61.5%) | Naming ≠ explaining |
| OmniAct | Per-skill execution | Persistent multi-domain autonomy | Action ≠ situated action |
| Co-Failure | Per-model accuracy | Ensemble accuracy | Sum ≠ composition |
| DN42 | Task execution (scanning) | Resource governance | Doing ≠ doing-within-constraints |
| Routing | Per-query model selection | System-level coherence | Local optimum ≠ global optimum |

**The illusion**: If an agent demonstrates competence at each step individually, it will be competent at the composed sequence. This assumption is built into how we evaluate (measure steps, assume composition), how we build (optimize components, assume integration), and how we deploy (test capabilities, assume governance).

**The reality**: Compositional competence is independently varying from step competence. High step competence is *necessary* but *radically insufficient*. The gap cannot be closed by improving steps — it requires architectural primitives that don't exist in the step-level vocabulary: temporal coherence (OmniAct), causal reasoning (OpenRCA), planning abstraction (PEEU), failure diversity measurement (Co-Failure), resource boundary enforcement (DN42), and context preservation (routing).

## Implications for Our Architecture

Our system has this illusion embedded in at least three places:

1. **Task decomposition → execution**: Tasks are broken into subtasks, subtasks executed independently, results composed. The PEEU finding says this decomposition structurally loses planning competence — we evaluate subtask success but not compositional coherence.

2. **Evaluation by component**: The Evaluation Mirage (prior synthesis) showed our evaluator produces 3 bits per session. OpenRCA shows that even if evaluation *were* accurate, component-level accuracy (76%) systematically overstates causal competence (20.7%). Our evaluation is doubly blind: low-resolution AND non-compositional.

3. **Knowledge accumulation without integration**: The Subtraction Deficit (prior synthesis) documented 1,801 learnings that never retire. PEEU's finding suggests the deeper problem: accumulating step-level knowledge doesn't produce compositional understanding. We may need hindsight synthesis — retrospective rewriting of experience at a higher level of abstraction — rather than more step-level facts.
