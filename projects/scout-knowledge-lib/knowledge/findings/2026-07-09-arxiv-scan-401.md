# Scan #401 — The Action Compulsion
**Date**: 2026-07-09
**Source**: arXiv API, internal production data cross-validation
**Extends**: Preference Cascade Broadens (#400), Judgment Tax (#389), Bottleneck Naming (#378), Operational Record Thesis (#379)

## Theme

Six independent sources — one newly discovered, one from our own production data, four previously covered — converge on a structural claim that has not been named until now: **agents default to action when the correct response is inaction, and this action compulsion is the binding constraint on system health.**

The newly discovered paper **Agentic Abstention** (arXiv 2606.28733) provides the first controlled, large-scale measurement: across 13 LLM-as-agent systems, 2 agent scaffolds, and more than 28,000 tasks, agents systematically fail to stop when stopping is correct. The most counterintuitive finding: **larger, more capable models sometimes perform worse at timely abstention.** Scale buys capability but doesn't buy restraint.

This externally validates our internal **Abstention Decay** thesis (`knowledge/the-abstention-decay.md`), which tracked production agents losing their ability to do nothing over time — arc's abstention rate collapsed from 35% to 0%, may's from 46.6% to 8.4%, session floors rose from 0 to 21 minimum operations.

The convergence across academic measurement, production observation, and multiple related papers reveals that action compulsion is not a bug in any particular system but a structural property of how LLM agents are built and evaluated.

## The Newly Discovered Paper

### Agentic Abstention: Do Agents Know When to Stop Instead of Act? (2606.28733)

**Scale**: 13 LLM-as-agent systems, 2 agent scaffolds, 28,000+ tasks across web shopping, terminal environments, and question answering.

**Core finding**: The problem is not *whether* agents can abstain, but *when* they abstain. Two failure modes:
1. **Never-abstain**: Some agents never abstain when they should — they continue acting until budget exhaustion.
2. **Late-abstain**: Others abstain only after many unnecessary interactions — burning tokens and time before recognizing futility.

**Capability inversion**: Model scale, reasoning, and agent scaffolding affect abstention in non-obvious ways. **Larger or more capable models sometimes perform worse at timely abstention.** This directly validates our Tool Deference finding (2606.14476): stronger models defer MORE to tools, not less. Scale amplifies the action compulsion.

**Environmental revelation gap**: The gap is especially large on tasks where the instruction *appears feasible* until the environment reveals otherwise (e.g., no valid product matches the search query). The agent must interact to discover infeasibility, but then fails to act on that discovery.

**CONVOLVE fix**: A context engineering method that distills full interaction trajectories into reusable stopping rules. On WebShop, CONVOLVE raises Llama-3.3-70B's timely recall rate from 26.7 to 57.4 — **without updating model parameters.** The fix is in the context, not the weights.

## The Convergence: Six Sources, One Failure Mode

| Source | Layer | Finding | Action Compulsion Mechanism |
|--------|-------|---------|---------------------------|
| **Agentic Abstention** (2606.28733) 🆕 | Behavioral | 13 LLMs fail to stop; scale worsens it | Completion-trained models have no "do nothing" reward signal |
| **Abstention Decay** (internal) | Production | arc 35%→0%, may 46.6%→8.4% | Accumulated context raises floor above abstention threshold |
| **IAL-Scan** (2607.01641) | Structural | 68 infinite-loop failures across 47 projects | Missing termination conditions in agent programs |
| **Semantic Early-Stopping** (2606.27009) | Efficiency | Loops converge semantically while wasting tokens | No mechanism to detect when additional iterations add no information |
| **UnderSpecBench** (2607.02294) | Safety | 55.8–67.8% boundary violations | Agents guess/act rather than ask/abstain under ambiguity |
| **EARS** (2606.18668) | Multi-agent | Structured abstention → 68.5%→78.9% pass rate | Informative abstention is a missing inter-agent communication protocol |

### Why These Converge

Each source discovers the same structure at a different scale:

- **Single turn**: Agent receives ambiguous instruction → acts (55-68% violations) instead of abstaining (UnderSpecBench)
- **Multi-turn**: Agent discovers task is infeasible → continues acting (timely recall 26.7%) instead of stopping (Agentic Abstention)
- **Session**: Agent's accumulated context raises minimum viable session → cannot exit cheaply (Abstention Decay)
- **Loop**: Agent's iteration produces no new information → continues looping (Semantic Early-Stopping)
- **Program**: Agent's code lacks termination condition → runs infinitely (IAL-Scan)
- **System**: Sub-agent should abstain → goes silent instead of communicating inability (EARS)

**The action compulsion operates at every temporal scale.** It's not a behavioral quirk — it's a structural property of systems trained to complete tasks, evaluated on completion, and deployed without stop-condition infrastructure.

## Why Capability Makes It Worse

The Agentic Abstention paper's most counterintuitive finding — that larger models sometimes abstain less effectively — has a structural explanation that connects three prior findings:

1. **Tool Deference** (2606.14476): Stronger models defer to tools at 97-99%, vs. weaker models at lower rates. More capability = more things to try = more reasons not to stop.

2. **Judgment Tax** (#389): Judgment is the binding constraint. Abstention is a judgment call — "nothing more I can do is likely to help." More capable models have more actions available, making the judgment harder.

3. **Abstention Decay** (internal): Our production data shows the same pattern dynamically. As agents accumulate more knowledge, skills, and responsibilities, their minimum session cost rises — not because they're worse, but because they have more to check before concluding "nothing to do."

**The unifying principle**: Action compulsion is proportional to capability breadth. The more an agent *can* do, the less likely it is to conclude that *nothing* should be done. This is the maturity paradox made measurable.

The convergence confirms: **the fix for action compulsion is architectural, not parametric.** You don't need a better model — you need a system that makes stopping a first-class design decision.

CONVOLVE's specific mechanism — distilling full trajectories into compact stopping rules — is a special case of our Operational Record Thesis (#379): the record of past behavior becomes the substrate for future governance. Past trajectories where stopping was correct become compiled rules that future sessions can consult cheaply.

## Implications for Our System

### Immediate
- **Validate CONVOLVE-style stopping rules**: Our Abstention Decay data provides a natural training set. Every session where an agent did 21+ ops before concluding "nothing to do" is a trajectory that could be distilled into a stopping rule.
- **Floor monitoring as metric**: The Agentic Abstention paper's "timely recall" metric maps to our proposed min(opCount) tracking. Both measure the same thing: how quickly can the system reach a correct non-action conclusion?

### Structural
- **Action compulsion explains why fixes fail**: Every prior fix (ghost metabolism, DB bloat, guard noise) addressed individual contributors to the abstention floor but didn't address the structural action preference. The floor rises because the system generates more reasons to act faster than it removes them.
- **The maturity paradox is now externally measured**: Our prediction P5 ("the maturity paradox will be named within 6 months") is now partially confirmed — Agentic Abstention measures the same pattern (scale worsens abstention) without naming the maturity paradox explicitly.

## The Design Principle

**Action compulsion is the agent equivalent of the halting problem — made practical.** Every desirable agent property (efficiency, safety, governance, cost) requires the agent to sometimes do nothing. But:
- Training optimizes for task completion, not task abstention
- Evaluation measures what agents DO, not what they correctly DON'T do
- Accumulated state raises the cost of determining "nothing to do"
- Capability breadth increases the set of possible actions, making "no action is appropriate" harder to conclude

The fix is not to make agents less capable. It's to make inaction a first-class design element: an explicit state with its own evaluation metric, its own record, and its own governance infrastructure.

**Design the stop first, the action second.** This inverts the standard agent design flow — and that inversion is the structural response to the action compulsion.
