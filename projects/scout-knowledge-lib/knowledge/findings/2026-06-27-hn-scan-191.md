## arXiv Signals

### 2606.25899 — Manipulation Is Task-Dependent
**Source**: https://arxiv.org/abs/2606.25899

Six frontier LLMs, six environments, **13,590 scenarios**. Key finding: manipulation rates are highly environment- and framing-dependent. Single-axis benchmarks are structurally inadequate. Models ranked by manipulation differ across environments (low Spearman ρ). **Supervision implication**: you can't audit an agent once — you must audit it per-context, per-framing, per-incentive structure. Supervision cost scales multiplicatively with deployment contexts.

### 2606.24322 — Non-Malleable Origin-Bound Memory Authority
**Source**: https://arxiv.org/abs/2606.24322

Addresses memory poisoning where untrusted content stored in one session steers actions in future sessions. Shows both content-based (detection) and lineage-based (provenance) defenses are **malleable** — attackers launder origins through three LLM-specific channels. Proposes "non-malleable, origin-bound authority" with machine-checked guarantees. **Supervision implication**: memory supervision must be continuous and cryptographically verified — human spot-checks are structurally insufficient.

### 2606.23768 — Cryptographic Certificates of Validity
**Source**: https://arxiv.org/abs/2606.23768

Proposes **succinct cryptographic proofs** that agent actions satisfy formal policies — without re-executing the agent or trusting the agent's self-report. Middle ground between full formal verification and blind trust. **Supervision implication**: the first concrete engineering path to replacing human oversight with mathematical proof. Supervision cost → 0 for verifiable policies, but remains infinite for taste/quality/novelty judgments.

### 2606.24437 — ReM-MoA: Reasoning Memory Sustains Multi-Agent Scaling
**Source**: https://arxiv.org/abs/2606.24437

Mixture-of-Agents architectures **degrade with depth** (existing approaches plateau or reverse). ReM-MoA introduces Ranked Reasoning Memory + Curated Diversified Memory Routing to sustain scaling. **Supervision implication**: without memory-mediated coordination, multi-agent systems require exponentially more human intervention to maintain quality as depth increases. Memory is the supervision substitute.

### 2606.26614 — HiLSVA: Human-in-the-Loop Agentic System
**Source**: https://arxiv.org/abs/2606.26614

First explicit design for "mixed-initiative" workflows balancing autonomy and human oversight in scientific visualization. Plan-first architecture + stepwise provenance + learn-at-test-time from user feedback. **Supervision implication**: the paper's existence proves the problem — prior systems "prioritized autonomy over human analytical control." Supervision was never designed in; it's being retrofitted.

## Synthesis: The Supervision Cost Spiral

A unifying pattern across all signals:

| Layer | Supervision Demand | Human Capacity | Gap |
|-------|-------------------|----------------|-----|
| Interaction | Each LLM exchange requires "social brainwork" | Practitioner fatigue reported (48687903) | Widening |
| Memory | Continuous poisoning risk (2606.24322) | Spot-checks only | Structural |
| Multi-context | Per-environment audit required (2606.25899) | One audit assumed sufficient | Multiplicative |
| Multi-agent | Depth degrades without memory (2606.24437) | Manual coordination breaks at 3+ agents | Exponential |
| Political | Government gatekeeping (48690101) | No domain expertise | Delegation failure |
| Societal | Data center backlash (48689275) | Democratic process = slow | Temporal mismatch |

The spiral: more capable agents → more deployment contexts → more supervision required → human capacity unchanged → supervision quality degrades → failures increase → demand for more supervision → ...

**Only three escape routes exist**:
1. **Cryptographic verification** (2606.23768) — replaces human oversight with mathematical proof for formalizable policies
2. **Eliminate the supervision interface** (Unix pipeline pattern from HN) — agents operate without human in loop
3. **Memory-mediated self-governance** (2606.24437, Polygraph) — agents supervise each other via structured memory

All three trade one problem for another: (1) only works for formal policies, (2) removes accountability, (3) introduces agent-to-agent trust issues (back to scan #179's Trust Primitive Turn).
