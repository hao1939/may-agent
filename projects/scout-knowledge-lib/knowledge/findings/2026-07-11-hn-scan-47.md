## Finding 47-1: Ghost Font — Adversarial Legibility Already Arms-Racing (193pts, 65c)

**Signal strength: HIGH** — first mainstream adversarial font to hit HN front page.

Ghost Font uses temporal animation (frame-shifting) to make text readable by humans but not parseable by AI vision models. Key community findings:

- **Already defeated**: GPT-5.6 cracks it via temporal analysis with optical flow and vertical-displacement maps
- **Not novel in principle**: Similar to motion-CAPTCHA approaches, which are also already beaten
- **The real insight**: Any static adversarial technique has a short half-life. The arms race is now measured in weeks, not years.
- **Practical angle**: CAPTCHA-style applications suggested but skeptics note "human-style temporal averaging" defeats it trivially

**Agent relevance**: Anti-AI obfuscation is a losing game for text. The community consensus is clear — if information is visually accessible to humans, it's accessible to sufficiently advanced vision models. This closes off "font-level" access control as a viable strategy.

## Finding 47-3: Ant JS Runtime — AI Authorship Trust Crisis in Open Source (173pts, 76c)

**Signal strength: MEDIUM-HIGH** — surfaces a new norm violation.

Ant is a new JS runtime claiming "from-scratch hand-built" construction. Community immediately surfaced evidence of heavy AI code generation in early versions, triggering trust backlash:

- *"The 'from-scratch hand-built' framing specifically – for me – somewhat grates given the original heavy lifting from an [AI]"*
- Author claims rewrite since, but damage to credibility done
- Separate naming conflict with Apache Ant seen as evidence of unseriousness

**Pattern**: "AI-laundered authorship" — presenting AI-generated code as hand-crafted — is becoming a reputational risk in open source. The community is developing detection heuristics and social norms around disclosure.

**Agent relevance**: Tools and frameworks used in agent infrastructure will face increasing scrutiny about their provenance. Projects that transparently acknowledge AI assistance may build more trust than those claiming pure human authorship.
