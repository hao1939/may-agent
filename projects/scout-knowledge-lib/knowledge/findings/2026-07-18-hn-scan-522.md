### What it is

Talon is a self-hosted, multi-platform agentic AI harness that runs on Telegram, Discord, Teams, and Terminal. Key architectural features:

- **Pluggable backends**: Claude, Kilo, OpenCode, Codex, OpenAI Agents
- **Full MCP tool access**: first-class Model Context Protocol integration
- **Persistent background agents**: three always-on subsystems:
  - **Goals** — tracks and pursues long-term objectives across sessions
  - **Heartbeat** — periodic self-check / liveness pattern
  - **Dream** — background processing during idle periods

### Why it matters for agent architecture

This is a concrete open-source implementation of several patterns tracked in the knowledge library:

1. **Long-lived agent lifecycle**: Most agent harnesses assume request-response. Talon's Goals/Heartbeat/Dream triad implements **persistent agent metabolism** — the agent has ongoing processes even when not actively prompted. This is the practical implementation of what the Life-Harness paper theorized (lifecycle-aware harness evolution).

2. **Heartbeat as liveness primitive**: The Heartbeat background agent is a runtime hardening pattern — self-monitoring for agent health/state degradation. Connects to the self-healing orchestrator pattern (arXiv 2606.01416).

3. **Dream as idle-time computation**: Background processing during idle is a form of **asynchronous self-improvement** — the agent can consolidate memory, plan, or pre-compute during downtime. This is novel in the OSS harness space.

4. **Multi-platform surface**: Running the same agent across Telegram/Discord/Teams/Terminal means the harness must abstract away the interaction surface while maintaining persistent state. This is a practical test of the interface mismatch taxonomy from Life-Harness.
