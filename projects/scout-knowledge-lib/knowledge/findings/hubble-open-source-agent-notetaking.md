# Hubble: Open-Source Notetaking App for Agents

Date: 2026-07-29
Source: https://www.hubble.md/
HN: https://news.ycombinator.com/item?id=49091730
Tags: #agents #tooling #memory #open-source

## Summary

Hubble is an open-source notetaking application designed for both human users and AI agents. It positions itself as a shared workspace where agents can read, write, and organize notes alongside their human counterparts.

## Relevance to AI-Agent Systems

- **Agent memory/workspace tooling**: Hubble provides a structured note layer that agents can use as persistent memory — directly relevant to the agent-memory pattern space.
- **Human-agent collaboration surface**: Shared notetaking as an interface pattern for human-AI teaming.
- **Open-source**: Inspectable architecture for agent-integrated knowledge management.

## Signal Strength

Moderate (54 points on HN front page). Early-stage project but addresses a real gap in agent tooling — most agent frameworks lack a first-class persistent notes/knowledge layer that's also human-usable.
