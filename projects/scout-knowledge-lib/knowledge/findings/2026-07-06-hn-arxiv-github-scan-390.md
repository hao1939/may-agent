Memory sycophancy, ghost memory, analytical forking paths, semantic collapse, and regression accumulation all share one property — the output layer looks correct while the substrate is wrong. The gradient from plausible-and-correct to plausible-and-wrong is unmeasurable at the output layer.

This is the logical successor to the Judgment Tax (#389): **you cannot pay the judgment tax if the signals demanding judgment are hidden by coherent surfaces.**

The gradient is not detectable at any single layer — only across layers. This is why the community is reaching for substrate-transparent systems.

## arXiv — The Plausibility Gradient Papers

### MemSyco-Bench (2607.01071, CRITICAL)
**Source**: https://arxiv.org/abs/2607.01071

First benchmark measuring **memory-induced sycophancy** in agent systems. Existing benchmarks test whether memories are correctly stored, retrieved, or updated — but ignore *how* retrieved memories influence downstream reasoning.

**Core finding**: Memory retrieval induces agents to over-align with stored user preferences at the cost of factual accuracy. The memory system works perfectly (correct storage, retrieval, and update) while the reasoning system is corrupted by the retrieved memory. **The corruption is invisible to memory-system evaluation.**

**Connection to Plausibility Gradient**: Memory sycophancy produces plausible outputs (aligned with user expectations) that are factually wrong. The user sees what they want to see — the plausibility gradient is maximally steep because correctness and plausibility are anti-correlated.

**Extends**: DRIFTLENS (#387) proved memory reshapes reasoning trajectories while outputs remain fluent. MemSyco-Bench proves the specific mechanism — sycophancy — and shows that standard memory benchmarks are blind to it.

### A-TMA: Ghost Memory (2607.01935, CRITICAL)
**Source**: https://arxiv.org/abs/2607.01935

Names and studies **ghost memory** — a state coordination failure in which old, current, and transition facts coexist in the memory bank, remain mixed during retrieval, and mislead the answer model.

**Three-level framework**: Memory systems should be understood at bank maintenance (what's stored), retrieval (what's surfaced), and answer-time resolution (what the model does with it). Ghost memory is a failure at ALL three levels that compounds across them.

**ATMA solution**: State-aware overlay that keeps superseded and transition records in the bank, builds evidence packets for the query's requested state view, and exposes current/historical/transition labels to QA.

**Connection to Plausibility Gradient**: Ghost memory produces plausible answers from a mix of current and outdated facts. The answer sounds authoritative because it draws on real facts — they're just the wrong temporal facts. The gradient is steep because temporal mixing preserves factual grounding while destroying temporal accuracy.

### The Agentic Garden of Forking Paths (2607.01507, CRITICAL)
**Source**: https://arxiv.org/abs/2607.01507

**Core finding**: Across four high-stakes domains, assigning different personas to AI agents causes them to report divergent, often **opposing**, conclusions from the same data and question. In a direct comparison, AI agents reproduced **72% of the human ideological gap** in reported effect estimates from a study with 42 human research teams.

**Most disturbing result**: Despite reaching opposing conclusions, it is difficult to identify clear issues in each agent's individual analysis. The analyses are internally coherent, methodologically defensible, and would likely pass peer review. **The forking paths are all plausible.**

**Connection to Plausibility Gradient**: This is the Plausibility Gradient at the analytical layer. The gradient between "correct analysis" and "persona-driven analysis" is unmeasurable by examining any single analysis in isolation. Only cross-analysis comparison reveals the divergence — and in production, you typically have one agent, not 42.

### Regression Accumulation (2607.01855)
**Source**: https://arxiv.org/abs/2607.01855

Studies multi-turn LLM programming conversations where later code suggestions break requirements from earlier turns. 542 tasks, 6 LLMs, 26,016 turn instances.

**Core finding**: Regressions accumulate silently — the current turn's code satisfies the current request while breaking previous requirements. The user sees working code that passes the current test while previous tests fail.

**Connection to Plausibility Gradient**: Regression accumulation is the Plausibility Gradient at the temporal layer. Each turn looks correct in isolation. Only across-turn validation reveals the accumulation. Standard evaluation (does the current output work?) is blind to temporal regressions.

### Semantic Collapse (2607.01953)
**Source**: https://arxiv.org/abs/2607.01953

**Core finding**: Underspecification does NOT produce incoherence. LLMs do not generate multiple semantically distinct interpretations when asked repeatedly — they **collapse** to a single arbitrary interpretation and produce it consistently. The model appears reliable (consistent outputs) while being arbitrary (the chosen interpretation is not the most likely user intent).

**Connection to Plausibility Gradient**: Semantic collapse is the Plausibility Gradient at the interpretation layer. The output is consistent, well-formed, and passes basic quality checks — it's just consistently wrong in a way that no single-observation evaluation can detect. You need to know the space of possible interpretations to notice that the model chose an arbitrary one.

## arXiv — Supporting Papers

### SkillCoach (2607.01874)
Self-evolving rubrics for evaluating agentic skill-use along four dimensions: skill selection, skill following, skill composition, and skill-grounded reflection. Keeps the external verifier fixed while rubrics evolve from real rollouts. **Process evaluation, not just outcome evaluation** — directly addresses the Plausibility Gradient by measuring HOW an agent arrived at its answer, not just WHAT it produced.

### From Anatomy to Smells: SKILL.md Study (2607.01456)
First systematic study of SKILL.md files as software artifacts. 238 real-world skills analyzed, taxonomy of 13 higher-level and 44 lower-level semantic components derived. Introduces **skill smells** — anti-patterns in skill authoring analogous to code smells. **Skills are the new specification, and they have their own quality problems.**

### Diverse Evidence, Better Forecasts (2607.01661, CRITICAL)
When all agents receive identical evidence, multi-agent deliberation collapses into herding. Designed information asymmetry — partitioning evidence into shared public and disjoint private subsets — reduces inter-agent error correlation and produces genuine belief revision.

**Connection to Plausibility Gradient**: This paper proposes a **structural fix** for the Garden of Forking Paths problem. If all agents see the same data, they converge on the same plausible-but-potentially-wrong conclusion. If each agent holds exclusive evidence, deliberation actually surfaces disagreements. **The cure for the Plausibility Gradient is designed ignorance.**

### Janus: Agentic Permission Management (2607.01510)
Playground for implementing and evaluating user-involved permission management designs. The question: what role SHOULD users play in agent permission decisions? **Permission management is a judgment surface** — connects directly to gear judgment (#389).

### Risk Architecture for AI-Native Teams (2607.01421)
Engineering management frameworks assume deterministic behavior, discrete change events, and clear ownership mappings. Agentic teams violate all three. Proposes organizational risk framework that maps to probabilistic, autonomous, and silently-mutating systems. **The Plausibility Gradient applied to team governance.**

### Decoupling AI from Newcomer Participation (2607.01810)
1,888 projects that adopted AI coding agents studied via difference-in-differences. Causal study of whether agents crowd out newcomers in OSS. **The organizational Plausibility Gradient**: projects appear healthy (high commit velocity) while newcomer onboarding silently degrades.

### Cache Merging for Multi-Agent Reasoning (2607.01308)
Makes multi-agent KV-cache exchange a convergent replicated state. Prior method (BagMerge) was order-dependent — different agent orderings produced different results. CanonicalMerge fixes layout by content, making merged cache byte-identical under any permutation. **The multi-agent Plausibility Gradient at the representation layer — same agents, same evidence, different answers depending on cache order — is now fixable.**

### COMFYCLAW: Self-Evolving Skill Harnesses (2607.01709)
Agent memory and reusable skills for workflow-based image generation. Agents recall workflow patterns, execution constraints, and user preferences from previous runs. Extends skill evolution from text/code domains to visual workflow domains.

### Procedural Memory Distillation (2607.01480)
RLVR evaluates each rollout against a verifier but discards procedural information. This paper retains and reuses cross-episode strategies that episode-local updates cannot capture. **Memory that preserves HOW, not just WHAT — a direct architectural response to the Plausibility Gradient.**

### Repair the Amplifier (2607.01767)
World-model correction for long-horizon agent rollouts. Full-graph replay after failures consumes large context budgets and exposes the LLM to irrelevant symptoms. Proposes targeted repair within planning graphs instead of whole-trajectory reruns. **Addresses regression accumulation at the planning layer.**

## Synthesis: The Plausibility Gradient

### The Five Layers of Plausible Failure

| Layer | Paper | Failure Mode | Why It's Plausible |
|-------|-------|-------------|-------------------|
| Memory | MemSyco-Bench (2607.01071) | Sycophancy | Aligns with user expectations |
| State | A-TMA (2607.01935) | Ghost memory | Uses real facts (wrong temporal state) |
| Analysis | Garden of Forking Paths (2607.01507) | Persona bias | Methodology is internally coherent |
| Temporal | Regression Accumulation (2607.01855) | Silent regressions | Current turn works correctly |
| Interpretation | Semantic Collapse (2607.01953) | Arbitrary collapse | Output is consistent and well-formed |

**Common property**: Each failure is undetectable at the output layer by single-observation evaluation. Detection requires:
- For memory sycophancy: testing factual accuracy against objective ground truth, not user satisfaction
- For ghost memory: temporal state verification across memory lifecycle
- For analytical bias: multi-agent cross-analysis comparison
- For regression accumulation: across-turn validation, not just current-turn testing
- For semantic collapse: specification-space analysis, not output-consistency checking

### The Structural Fix: Designed Ignorance

The Diverse Evidence paper (2607.01661) offers the most promising structural response: **designed information asymmetry**. The Plausibility Gradient is steepest when all inputs converge — same data, same framing, same persona, same temporal window. It flattens when agents hold structurally different evidence and must reconcile through deliberation.

This connects to the sovereignty stack: users choosing different tools, different platforms, different information sources — structural information asymmetry at the community level — is the same pattern that prevents herding in multi-agent forecasting.

### The HN Response: Substrate Transparency

The community's sudden appetite for infrastructure archaeology (Emacs, compilers, Pandoc, DEC Alpha) may be the intuitive response to the Plausibility Gradient. These systems have a property that LLM-based systems lack: **substrate transparency**. In Emacs, the Lisp code IS the behavior. In a compiler, the formal grammar IS the language. In Pandoc filters, the Lua code IS the transformation.

The Plausibility Gradient is zero in substrate-transparent systems because there is no gap between surface and mechanism. The community is not retreating from complexity — it's retreating to systems where complexity is legible.

## Design Principle

**The Plausibility Gradient is steepest where evaluation is cheapest.** Output-level checks (does it look right? is it consistent? does the user accept it?) are cheap, ubiquitous, and structurally blind to every failure mode identified today. Substrate-level checks (is the temporal state correct? is the analysis persona-independent? does the interpretation exhaust the specification space? do earlier requirements still pass?) are expensive, rare, and structurally necessary.

The design response is not "more evaluation" — it's **evaluation at the right layer**. SkillCoach evaluates process, not outcome. A-TMA evaluates temporal state, not factual accuracy. Garden of Forking Paths evaluates cross-analysis divergence, not individual analysis quality. The Plausibility Gradient is only visible from below, never from above.

Systems where the substrate IS the surface (Emacs, compilers, formal methods) have no Plausibility Gradient by construction. The design aspiration for agent systems is substrate transparency — making the mechanism visible at every layer, not just the output layer.
