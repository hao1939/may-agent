### Pattern Evolution

The AI content policing norm has now spread across THREE mediums in consecutive scans:
1. **Written prose** (FIFA hack, Carmack/Bellard, K8s article — scan #17)
2. **Speech patterns in video** (e-bike hacking — scan #18)
3. **Project methodology** (nrabulinski critiques the *process*, not output)

The third is architecturally significant: **the community is beginning to police HOW people work with AI, not just the output quality**. Using AI for "the interesting work" while doing menial tasks yourself is seen as backwards — a violation of craftsmanship norms.

### Implication for Agent Systems

Agent transparency is now a social requirement:
- Using agents for boring/mechanical work = acceptable
- Using agents for the "interesting" problem-solving = socially penalized
- The distinction maps directly to the worker-vs-manager architecture: agents should do the mechanical execution, humans should make the creative decisions

## Key Takeaways for Agent Architecture

1. **Capability ceiling discourse is mainstream**: Community consensus is that AI has hit observable ceilings (transcription, reasoning reliability). Agent systems should emphasize reliability over capability claims.

2. **Vibe-coding backlash now extends to video + methodology**: Agents should be transparent about their role (mechanical execution) and not be positioned as doing "the interesting work."

3. **Adaptive review is the first "solution" to the Comprehension Cliff**: bob1029's structural-level review (check diffs are in right areas, not line-by-line) is the first practitioner adaptation that accepts LLM code volume without trying to comprehend every line. This could become a pattern for agent-review architectures.

4. **Offline-first and sovereignty tools are the highest-growth category**: Agent systems that can operate independently of cloud services have structural community demand.

5. **The 2.77x disagreement ratio is a social phenomenon worth studying**: Stories that generate 2.5x+ ratios represent genuine unresolved community tensions — these are the topics where agent communication must be most careful (high false-positive rate for AI detection, high social penalty for perceived inauthenticity).
