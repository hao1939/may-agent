## arXiv Evidence

### 5. GILP: Grounded Iterative Language Planning (2606.27806)

**Parameterized backbone + LLM agent reasoning with consistency gate — first systematic approach to grounding agent planning.**

- **Problem**: Agent-based world models reason flexibly but hallucinate state changes. Parameterized world models are measurable but weak as planners.
- **Architecture**: Small trained backbone supplies valid actions, predicted state deltas, risk, and value. LLM drafts action and imagined delta. Consistency gate asks for revision when the two disagree.
- **Results**: Hallucinated-state rate 0.176 → **0.035** (5× reduction). Success 0.668 → **0.838** with only ~22% extra LLM calls.
- **Key insight**: The backbone IS a structural verifier — cheap, deterministic, and domain-specific. This is the Serving-Layer Crystallization applied to planning: a lightweight deterministic component grounds an expensive stochastic one.

**Connection to library**: Directly extends the Grounding Gap (#174) and Anti-Deliberation Principle (#176). The consistency gate is an agent-EXTERNAL signal — the backbone catches hallucinations the LLM cannot self-detect. Validates the "always use agent-external signals" design principle. Also connects to Simulation Dividend (#252) — the backbone IS a lightweight world model that closes the learning loop.

Source: https://arxiv.org/abs/2606.27806

### 6. Detection-to-Action: LLM Agents for Fault-Tolerant Control (2606.28011)

**Multi-agent industrial control with digital twin, Graph RAG, and deterministic validation.**

- **Architecture**: (i) Multi-agent workflow (monitoring, planning, action synthesis, simulation, validation, reprompting), (ii) Digital Process Plant Twin exposing simulation for pre-execution testing, (iii) Graph RAG on CPSMod ontology for relation-aware knowledge retrieval
- **Safety model**: Corrective actions validated deterministically against interlocks, envelopes, and dynamic feasibility BEFORE actuation. If no plan found within bounded time, control handed to safety fallback.
- **Results**: Lightweight LLMs (GPT-4o-mini, GPT-4.1-mini) derive valid recovery decisions within latency budgets for both discrete batch and continuous PID-regulated processes.
- **Key insight**: The agent has ZERO execution authority until deterministic validation passes. This is Institutional Attestation (#176) applied to physical infrastructure — "govern actions, not agents."

**Connection to library**: Extends MCP-in-physical-world trajectory (#183 trapped-ion quantum, #197 Unreal Engine).
