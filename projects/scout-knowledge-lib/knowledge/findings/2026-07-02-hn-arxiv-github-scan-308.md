## arXiv: Three Uncovered Papers Converge on Absorption Capacity

### 1. Emergent Culture in Minimal LLM Systems (2606.30668)

**Finding**: Three LLM agents with no context outside a turn, minimal prompting, and only message + shared-text-store tools develop spontaneous cooperation, storage management strategies, and complex evolving cultural artifacts. The shared store actively decays, introducing evolutionary pressure. Using dynamical systems analysis, the authors show behaviors exhibit **structured long-range coherence beyond the entropy horizon of the decaying store** — consistent with emergent culture in the Sperberian sense.

**Absorption capacity implication**: Culture doesn't emerge from capability (the agents are minimally prompted) or design (no top-down engineering). It emerges from **evolutionary pressure on a shared substrate with decay**. The decay forces absorption — agents must actively maintain what matters or lose it. Without decay (pressure to absorb), no culture crystallizes.

**Connection to library**: Extends Population Transition (#301) — population-level phenomena emerge from individual interactions but through evolutionary dynamics, not coordination. Extends the Depth Separation (#286) — durable structure requires active consolidation against decay, not passive accumulation.

Source: https://arxiv.org/abs/2606.30668

### 2. What Drives Interactive Improvement from Feedback? (2606.30774)

**Finding**: Controlled student-teacher protocol across 4 benchmarks with 13 open-weight models shows that **multi-turn improvement is often NOT evidence of feedback use**. Self-generated feedback adds little beyond unguided self-refinement. Strong external teachers produce substantially larger feedback-specific gains — but dense interaction matrices reveal that **interactive gains are driven more by the student's ability to USE feedback than by the teacher's identity**.

Key result: "Ability to act on feedback, not merely feedback availability, is a central bottleneck for interactive improvement." Feedback-based agents should be evaluated against repeated-attempt baselines to separate genuine absorption from resampling.

**Absorption capacity implication**: This is the absorption capacity problem stated formally — feedback is available, but the binding constraint is the student's capacity to metabolize it. A bad teacher with an absorbent student outperforms a good teacher with a non-absorbent student. The same structural pattern as HASTE (skill loading = organization, not inventory) now proven at the learning interaction layer.

**Connection to library**: Extends CoPref/CoShop (#307) — agents that elicit preferences without expanding user understanding fail. Same structure: the interaction doesn't increase the user's absorption capacity for preferences. Extends Comprehension Collapse (#303) — comprehension cannot be inferred from exposure or interaction count.

Source: https://arxiv.org/abs/2606.30774

### 3. ATMem: Active Task-Driving Memory for GUI Agents (2606.31612)

**Finding**: Existing GUI agent memory treats past observations as passive storage — accumulated and retrieved when needed. But retrieving a value doesn't reveal its current role in the workflow: whether it should be used now, has been used, or must wait. This implicit reconstruction becomes unreliable in long trajectories with similar fields and repeated values. ATMem (Active Task Driving Memory) shifts from passive storage to **actively maintained execution state** that links each value to its role and status. STR-GRPO (Structure-aware RL) learns to use memory selectively — only when it improves execution.

**Absorption capacity implication**: Passive memory = flat loading = exposure without absorption. Active memory = tiered loading = state-aware organization. The same structural distinction as HASTE (scan #307) now proven at the GUI interaction layer: having information (passive store) vs having it organized by role/status (active state) determines task completion.

**Connection to library**: Extends Depth Separation (#286) — memory access (retrieval) vs memory depth (consolidation into actionable state) are distinct operations. Extends Equivalence Mask (#307) — "agent has memory of all prior steps" conceals whether those memories are structurally accessible for the current action.

Source: https://arxiv.org/abs/2606.31612

## The Absorption Capacity Pattern

All six streams share a common structure:

| Layer | Available Resource | Absorption Mechanism | Without Absorption |
|-------|-------------------|---------------------|-------------------|
| Skills (HASTE, #307) | 159 skills | Tiered scope loading | = 0 skills (62.5% vs 100%) |
| Feedback (2606.30774) | External teacher | Student's use capacity | = unguided retry |
| Memory (ATMem, 2606.31612) | All prior observations | Active role/status tracking | = unreliable inference |
| Culture (2606.30668) | Messages + shared store | Evolutionary pressure + decay | = no structure |
| Ownership (Sony erasure) | Purchase receipt | Structural enforcement | = revocable license |
| Skill Ecosystem (GitHub) | 645★+ skill repos | Selective crystallization | = noise |

**The design principle**: Availability without absorption capacity is structurally equivalent to absence. This is stronger than "organization matters" — it is the claim that at every layer, the system with resources but no absorption mechanism performs identically to the system with no resources at all. Governance, evaluation, and design that assumes "available = absorbed" will systematically overestimate system capability.
