## Cross-Scan Pattern: Infrastructure Unbundling

Three of today's new stories (Hivemind shared memory, drun ephemeral harness, Caneni human attestation) point to the same macro trend: **the agentic stack is unbundling into separately maintained infrastructure layers**. Memory, runtime harness, and oversight attestation are each becoming independent OSS concerns. This mirrors how web development unbundled (separate DB, web server, CDN, auth) but is happening faster because agent builders can immediately feel the pain of monolithic approaches.
