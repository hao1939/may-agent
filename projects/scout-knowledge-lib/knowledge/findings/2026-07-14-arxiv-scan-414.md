## Paper Analysis

### 1. ATM: CID-Brokered Pre-Write Admission for Multi-Agent Code Co-Synthesis (2607.00041) — HIGH

**Core contribution**: A governance substrate that solves the concurrent-write-admission problem for multi-agent code generation. Before any governed shared mutation is applied, ATM decides which concurrently formed write intents may proceed in parallel, which require deterministic composition or serialization, and which must take a fail-closed path.

**How it works**:
- **CID broker**: A Content Identifier broker serves as the shared-mutation admission subsystem. It doesn't decide *what* to write — it decides *whether* concurrent writes conflict.
- **Semantic atomization**: Adapter-guided atomization maps write intents to semantic atoms and bounded regions. Each write intent is decomposed into the smallest units whose interactions can be assessed.
- **Virtual atoms**: When persistent atom-map coverage is incomplete, virtual atoms provide temporary auditable governance units for conservative comparison and routing. The system degrades gracefully rather than silently.
- **Neutral steward**: Governed shared writes are applied by a neutral steward, not by proposing agents. The writing agent never directly mutates the shared codebase — a structural separation of intent from execution.
- **Fail-closed**: When admission can't be determined, the system takes a fail-closed path. No default-allow.

**Evaluation**: 12-scenario deterministic design matrix, three archived runner cases, three same-file boundary cases, a three-week external-adopter study, and an operational recovery-routing benchmark. Results support feasibility, auditability, and bounded recoverability within single-domain settings.

**Why this matters for the library**:

ATM is the **Compilation Gradient materialized at the write-admission layer**:

| Stage | ATM Implementation |
|-------|--------------------|
| **Behavioral** (soft) | Agent proposes a write intent |
| **Structural** (architecture) | CID broker decomposes into semantic atoms, compares with concurrent intents |
| **Compiled** (enforcement) | Neutral steward applies write; agent never writes directly; fail-closed on ambiguity |

This is also the **Verification Stack** (#412) extended one layer deeper — below specification, code, and architecture verification, there's a **write-admission** layer that governs whether code changes even reach the codebase.

**Connection to Oversight Inversion**: ATM addresses a specific sub-problem of the Oversight Inversion — when multiple agents produce code concurrently, the oversight burden is not just "review each output" but "determine whether concurrent outputs conflict." ATM compiles this determination into infrastructure (CID broker + semantic atoms) rather than leaving it to human reviewers.

**Connection to Verification Commons Collapse**: ATM is an institutional response to the verification commons — instead of relying on reviewers to catch conflicting writes, the CID broker serves as automated admission control. The verification commons is preserved by removing concurrent-write conflict detection from human attention.

### 2. SOLAR: Learning-Augmented Replacement for Semantic Retrieval Buffers (2607.00394) — HIGH

**Core contribution**: The first formal treatment of agent memory cache replacement as a distinct problem from traditional caching, proving that classic heuristics consistently fail on semantic workloads and proposing a learning-augmented framework with provable competitive guarantees.

**The surprising finding**: Classic cache replacement heuristics (LRU, LFU) **consistently underperform the naive FIFO baseline** on semantic agent workloads. This inverts a 40-year assumption in systems design. The failure mechanism: semantic workloads lack temporal locality and frequency concentration — the two properties that LRU and LFU exploit. When items are matched by embedding similarity rather than exact keys, and hit quality is continuous rather than binary, the foundations of classic caching policies collapse.

**SOLAR framework**:
- **Modification timing**: Derived from regret accumulation (~17% modification rate), not fixed schedules. The cache changes only when accumulated regret justifies the switching cost.
- **Content selection**: Bayesian online learning over implicit retrieval feedback. The cache learns what to retain from downstream usage patterns, not from access recency.
- **Provable guarantees**: Constant competitive ratio ≤3, independent of cache size and horizon (vs. Ω(K) for FIFO). Eviction regret O(√(KT log T)), matching the Ω(√(KT)) lower bound up to logarithmic factors.
- **Performance**: 5–75% relative improvement over FIFO at tight cache sizes.

**The capacity insight**: Synthetic experiments with 5,000-item pools reveal an **inverted-U relationship between pool size and retrieval quality**, justifying capacity constraints as a **retrieval noise phenomenon** rather than a storage limitation. This is structural: more items in the pool don't help because the retrieval mechanism becomes less precise — not because storage is expensive.

**Why this matters for the library**:

1. **Token Economics Trap extension**: If classic caching policies are wrong for semantic workloads, then every agent memory system using LRU/LFU eviction (the default in most implementations) is systematically sub-optimal. The token cost of memory management is higher than it needs to be — and the quality is lower.

2. **Memory Architecture Divergence extension** (#393): Adds a sixth orthogonal failure mode — **cache policy failure**. The existing five (retention collapse, encoding skill, visibility governance, skill evolution, attention/precision) operate at the retrieval and representation layers. SOLAR shows the eviction policy layer is independently broken.

3. **Compilation Gradient**: SOLAR compiles cache replacement from behavioral heuristics (LRU/LFU = rules of thumb) into a learning-augmented framework with provable bounds. The governance of what stays in memory and what's evicted moves from soft signal to compiled enforcement.

4. **The Eternal Present extension**: Our Eternal Present thesis notes that agents lack temporal awareness. SOLAR proves this at the memory management layer — temporal locality doesn't exist in semantic workloads, so policies designed for temporal locality fail. Agent memory operates in a semantic topology, not a temporal one.

Source: https://arxiv.org/abs/2607.00394
