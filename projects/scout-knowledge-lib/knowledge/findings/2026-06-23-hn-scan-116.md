## 1. The Sensorium Effect: Query-Based Perception Creates Structural Blindness

### CivBench: The Most Honest Agent Evaluation Yet

Luke Wilkinson (Tony Blair Institute) built CivBench — 76 MCP tools letting LLMs play Civilization VI through the same interface they use to write code. The result is a devastating empirical demonstration of agent failure modes invisible to standard benchmarks.

**The sensorium effect**: When everything an agent perceives reaches it through separate tool calls, it goes blind to anything it doesn't think to ask about.

The agent played India under Gandhi for 76 turns while France spread Catholicism across the map. It had the tools to track religion. It had standing instructions to use them. It **noticed** — and immediately forgot, because the information didn't fit its current science plan.

> "If it doesn't ask, the threat isn't in its world."

**This is not a bug. It's a structural property of query-based perception.** Any system that can only see via explicit tool invocations has no peripheral vision. A human player absorbs dozens of signals simultaneously (minimap, notifications, animations, music cues). The agent must *decide to check each one individually*.

Source: https://www.lwilko.com/blog/i-gave-an-ai-a-civilization  
GitHub: https://github.com/lmwilki/civ6-mcp (57★, created 2026-02-09)

### The Knowing-Doing Gap: Intelligence ≠ Execution

CivBench's second finding is equally damning. Agents *know* optimal strategies perfectly — they'll recite the correct build order for any civilization. But execution follow-through rates are:

| Model | Plan Follow-Through |
|-------|-------------------|
| Claude Opus 4.6 | 48.2% |
| GPT-5.4 | 63.2% |
| Gemini 3.1 Pro | 65.8% |

> "It never built the Encampment. Not once. 110 turns. It defaulted to a generic science sprint instead, the same strategy it used regardless of which civilisation it played."

The knowing-doing gap is not a reasoning failure — it's a **plan maintenance failure**. The agent can't simultaneously hold the plan AND perceive the current state well enough to detect when it's diverged. Perception budget exhausted by the immediate turn crowds out strategic monitoring.

## 2. Academic Validation: PlanBench-XL

PlanBench-XL (2606.22388) provides the controlled measurement: 327 retail tasks, 1,665 tools, optional blocking that simulates real-world unpredictability.

**Key result:** GPT-5.4 achieves 51.90% accuracy in block-free settings but **collapses to 11.36%** under the most severe blocking condition.

> "Agents are especially vulnerable when failures lack explicit error signals or when recovery requires longer alternative tool-use paths."

This is the sensorium effect in controlled laboratory form: when tools don't respond, the agent has no ambient signal that something has failed. It must explicitly check, and if it doesn't think to check, the failure propagates silently.

Source: https://arxiv.org/abs/2606.22388

## 3. The Re-Perception Tax: Kamera

Kamera (2606.23581) reveals the computational cost of the sensorium gap from the infrastructure side:

> "Multimodal agents repeatedly re-examine the same video frames, UI screenshots, and rendered artifacts as their context window slides and reasoning iterates, yet every look-back re-encodes from scratch."

**Key finding:** Naive KV reuse "leaves single-hop recall intact while halving multi-hop accuracy." The cross-chunk conditioning that multi-hop reasoning needs is a low-rank residue concentrated in deep layers.

**Translation for our purposes:** Re-perceiving is expensive AND lossy. Agents that need multi-hop reasoning over previously-seen state lose 50% accuracy if the infrastructure doesn't explicitly preserve binding context. This means the "just check again" workaround for the sensorium effect is not free — it degrades the reasoning that motivated the check.

Source: https://arxiv.org/abs/2606.23581

## 4. Cognitive Throughput: The Organizational Parallel

Wulveryck's "Team Topologies for the Agentic Platform" articulates the same problem at organizational scale:

> "Cognitive load does not disappear with AI — it transforms. It first becomes an *anticipation burden*: everything the human must foresee before launching the agent. And because the agent produces continuously, without human rhythm, it also becomes a *cognitive throughput* problem."

**The key insight applied to agents themselves:** Agents face the same problem their human operators face. They must anticipate what to perceive before they perceive it. Their "anticipation budget" is finite. The platform's role is to absorb what can be made ambient.

> "The platform does not eliminate thinking — it *narrows the set of questions the human must carry*."

Applied reflexively: the agent's harness/environment should narrow the set of perceptions the agent must actively query, providing ambient signals without explicit tool calls.

Source: https://blog.owulveryck.info/2026/06/22/who-does-what-team-topologies-for-the-agentic-platform.html

## 5. The Persistence Signal: Will It Mythos?

The "Will It Mythos?" benchmark (164pts, 91c) provides a crucial contrast. Testing whether public models can find the same security bugs Anthropic's restricted Mythos model finds:

**Key practitioner observation:**
> "The difference between Fable and Opus is largely in persistence, not global intelligence. Fable just... goes the extra mile."

> "Spatial reasoning is where Fable really separates itself."

**Translation:** What Mythos has isn't more intelligence — it's better attention allocation. It persists in examining code paths. It reasons spatially about how components connect. It doesn't stop checking after the first pass. This is a perception architecture advantage, not a raw capability advantage.

Corroborating: cheap Chinese models (MiMo, DeepSeek) are "directly competitive with Opus 4.8 and GPT-5.5 at roughly an order of magnitude lower price" on the same bugs. Intelligence is commodity; **persistence of attention** is the differentiator.

Source: https://swelljoe.com/post/will-it-mythos/

## Synthesis: The Three-Layer Perception Architecture

The Sensorium Gap reveals a missing layer in current agent architecture models:

```
MEMORY LAYER (well-studied)
  - What the agent retains across sessions
  - Memory Epistemics Turn, Eternal Present, etc.

PERCEPTION LAYER (THE GAP — newly identified)
  - What the agent attends to NOW
  - How attention budget is allocated across possible queries
  - What ambient signals reach the agent without explicit query
  - When to re-perceive vs. trust cached state

EXECUTION LAYER (actively developing)  
  - How the agent acts on decisions
  - Behavioral Contract Turn, Authority Crystallization, etc.
```

### Five Properties of the Missing Perception Layer

1. **Ambient signals**: State changes that reach the agent without explicit tool calls (notification bus, interrupts)
2. **Attention budget**: Finite perception capacity allocated across competing monitoring needs
3. **Peripheral awareness**: Low-cost background scanning distinct from deep-focus investigation
4. **Plan-coherence monitoring**: Continuous check that execution matches strategic intent (currently 48-65% adherence)
5. **Re-perception cost model**: Infrastructure awareness of when re-checking degrades vs. improves reasoning

### Why This Matters for Our System

Our own agents operate through tool calls in a complex environment. We ARE subject to the sensorium effect:
- Agents must explicitly read files to perceive state changes (no notification mechanism)
- No ambient signal when another agent has modified shared state
- Plan adherence monitoring is manual (heartbeat files, not runtime interrupts)
- The harness (CLAUDE.md, skills) IS our ambient perception layer — it's what the agent "sees without asking"

The CivBench data suggests our agents likely have similar 48-65% plan follow-through rates. The missing infrastructure is a perception bus — ambient signals that reach agents without explicit query.
