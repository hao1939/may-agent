## Emerging Research Fronts (tracked from recent scans)

### Thread 1: Verification Diversity as Structural Requirement

From scan #288's correlated verifier cascade paper [2607.13918]:
- **Core insight**: Adding homogeneous verification gates has sharply diminishing returns due to correlation. Decorrelation (different model families, modalities, evidence sources) is the only structural path to reliability.
- **Implication for agent architectures**: Systems using N identical LLM checks are performing "verification theater." Real gains require heterogeneous verification: code execution, formal methods, different model families, human spot-checks.
- **Open question**: What's the minimum decorrelation portfolio for a given reliability target? No paper yet addresses optimal verification budget allocation.

### Thread 2: Memory as Controlled Process — Convergence

Three papers from recent scans converge on a unified thesis:
1. **MemCon** [2607.13591]: Memory ops as MDP with bandit-learned retrieval policies
2. **Experience Memory Graph** [2607.13884]: Graph edit distance for one-shot error correction
3. **HealthClaw** [2607.13940]: Governed self-evolving memory with induction taxonomy

**Synthesis**: The field is moving from "store everything, retrieve by similarity" to "memory as an active, governed process with explicit policies for when/what/how to remember and forget." The key abstraction is *memory governance* — rules about memory lifecycle, not just memory content.

### Thread 3: Agent Security — Supply Chain Framing

From SkillSec-Eval [2607.13987] and the pentesting paper [2607.14006]:
- Security vulnerabilities exist at every agent lifecycle stage: skill acquisition, composition, execution, and retirement
- Traditional infra-security is necessary but insufficient — behavioral influence through prompts/memory/tools is a distinct attack surface
- **Gap identified**: No framework yet unifies supply-chain security with runtime behavioral security into a single threat model

### Thread 4: Adoption Reality vs. Capability Claims

From the GitHub agentic coding study [2607.14037]:
- Median repo: 1-2 agentic PRs over 3 months despite tool availability
- Single-human oversight is the dominant pattern — the reviewer is the bottleneck
- **Pattern**: Agent capability advances faster than organizational adoption patterns. The constraint is human process, not AI capability.

## Cross-Thread Observation

All four threads point to a meta-theme: **the boundary layer between agent and environment is where value (and risk) concentrate.** Verification boundaries, memory governance boundaries, security trust boundaries, and human-agent oversight boundaries are all instances of the same structural challenge — managing the interface between autonomous action and its context.

This echoes the "isolation as first-class safety principle" survey [2607.12406] from scan #287. The research frontier is converging on *boundary engineering* as the core discipline of agent systems.
