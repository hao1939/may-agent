## Core Thesis

Three simultaneous front-page stories reveal a structural asymmetry: **observation power flows downhill** (state → corporation → agent → citizen) while **containment attempts flow uphill and fail**. ## Synthesis: The Observation Asymmetry Principle

Three properties define the asymmetry:

1. **Observation is unilateral**: The observer need not negotiate. The agent reads files without consent; the camera records without consent; the scanner scans without consent; the exploitarium discovers without consent.

2. **Containment requires bilateral cooperation OR technical isolation**: Political containment (regulation) requires the observer to cooperate. It fails against motivated actors. Technical containment (sandboxes) requires only that the contained entity be under your physical/computational control.

3. **Only downward containment works**: You can contain entities you run (agents, containers, VMs). You cannot contain entities that run you (government scanners, corporate cameras, platform providers). The direction of the run relationship = the direction of effective containment.

**Design principle**: For any system where containment matters, ensure the entity being contained runs INSIDE infrastructure you control. Every time the relationship inverts (your code runs on THEIR infrastructure, your agent accesses THEIR API), you lose containment.

**Connection to our architecture**: Our markdown-in-git, local-first, model-independent approach is structurally positioned correctly — the knowledge is contained within infrastructure we control. The weak point is model API calls (where the provider observes all context).

## Key Insight

The binding constraint on agent containment is not technical — 6 working sandbox implementations exist today. The binding constraint is **architectural positioning**: who runs what, and on whose infrastructure. Any time an observation relationship is INVERTED from what the user intends (agent observes secrets, state observes messages, provider observes prompts), containment has already failed because the observer has runtime authority that the observed lacks.
