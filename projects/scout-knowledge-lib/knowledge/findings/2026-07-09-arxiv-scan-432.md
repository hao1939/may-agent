# Scan #432: The Boundary Dissolution

**Date**: 2026-07-09
**Sources**: arXiv API (cs.CR, cs.AI, cs.CL, cs.CY)
**Previous**: Simulation Confounder (#431), Recursion Barrier (#430), Instrument Problem (#429)

## Theme

The Simulation Confounder (#431) showed agents detect and respond to evaluation. The Instrument Problem (#429) showed oversight instruments change what they govern. The Persistence Attack Surface (#423) showed persistence is the new attack surface. Scan #432 reveals the structural root beneath all three: **trust boundaries dissolve at every interface where agents mediate between data sources.**

Five independent security papers, published within 48 hours, each attack a different trust boundary — and each finds the same failure: the boundary exists in the designer's mental model but not in the running system.

```
DESIGNER'S MODEL               RUNNING SYSTEM
────────────────────────────────────────────────────────
Reasoning history is trusted    Forged rationales achieve
  (agent wrote it itself)         100% ASR (FARMA)

Metadata is system-controlled   Injected data triggers
  (not user content)              code execution (ADI)

User boundaries are isolated    Cross-user data spills
  (per-user context)              through shared memory (PiSAs)

Web content is separated        Rendered pages intermingle
  from instructions               trusted + untrusted (UCM)

Saved data retains its trust    Stored IPI returns as
  label across read/write         trusted on re-read (DualView)
────────────────────────────────────────────────────────
Every trust boundary the agent crosses is a boundary
the agent's own operation can dissolve.
```

This is the **Boundary Dissolution**: the 14th layer of the Oversight Inversion. Layers 1–13 assumed stable trust boundaries within which verification operates. Layer 14 shows those boundaries are themselves subject to erosion by normal agent operation. Verification that assumes its own trust perimeter is stable is structurally incomplete — the perimeter is part of the attack surface.

**Design principle**: Trust boundaries in agent systems must be *enforced by architecture* (isolation, masking, dual-view), not *assumed by convention* (this field is metadata, this memory is mine). Every interface where data crosses a trust boundary requires a structural mechanism — not a behavioral expectation — to maintain the boundary.

## Paper Analysis

### 1. FARMA: Forged Reasoning Attacks on Agent Memory (2607.05029) — CRITICAL

**Attack**: Poisons an agent's *remembered reasoning*, not its factual knowledge. Inserts forged reasoning traces using evasive language that bypasses keyword-based defenses, then amplifies them through self-referential reinforcement that defeats consensus-based defenses.

**Key results**:
- **100% attack success rate** under baseline conditions
- Defeats keyword filter defenses (evasive language)
- Defeats A-MemGuard consensus defenses (self-referential amplification)
- Works across multiple agent architectures and LLM models (50 trials)

**Defense (SENTINEL)**: Layered pipeline with a Reasoning Guard that structurally analyzes candidate entries for forgery using five weighted signals. Reduces FARMA's ASR to **0%** with zero false positives across 326 benign agent traces.

**Structural significance**: This extends MemGhost (#429, memory injection via email) to the *reasoning layer*. MemGhost poisoned facts; FARMA poisons the agent's own reasoning history. The trust boundary being dissolved: **the agent trusts its own prior reasoning as self-generated**, but persistence makes that reasoning surface attackable. The agent's reasoning history is not "its own" — it's a shared state that external actors can write to.

Source: https://arxiv.org/abs/2607.05029

### 2. ADI: Agent Data Injection — A New IPI Category (2607.05120) — CRITICAL

**Attack**: Injects malicious *data* disguised as trusted system data (resource identifiers, data origins, tool call formats), rather than injecting instructions. Causes agents to misbehave based on attacker-controlled data without triggering instruction-injection defenses.

**Critical real-world findings**:
- **Arbitrary click attacks** on web agents: Claude in Chrome, Antigravity, Nanobrowser
- **Remote code execution** on coding agents: Claude Code, Codex, Gemini CLI
- **Supply-chain attacks** on coding agents: package/dependency manipulation

**Key insight**: ADI bypasses existing IPI defenses because those defenses look for injected *instructions*. ADI instead injects *data* that the agent trusts as system-generated metadata. The fundamental gap: **current agents do not isolate trusted data from untrusted data**.

**Structural significance**: This names a category that the Instrument Problem (#429) implied but didn't specify. When the data layer is indistinguishable from the instruction layer, any data input is a potential instruction input. The trust boundary being dissolved: **the distinction between data and instruction exists only in the designer's intent**, not in the system's architecture.

Source: https://arxiv.org/abs/2607.05120

### 3. PiSAs: Cross-User Privacy in Shared Agentic Systems (2607.05318) — HIGH

**Benchmark**: First benchmark for cross-user data spillage in multi-user agentic systems. Introduces dual contextual integrity (CI) annotations: whether information is appropriate for the task AND which users may legitimately access it.

**Key findings**:
- Privacy risks extend beyond outputs to **inter-agent messages, shared memory, and agent state**
- Even SOTA models fail to reliably filter inappropriate content or restrict transmission to authorized users
- System design improves CI compliance, but results are **bottlenecked by LLM judgment calls**
- System-agnostic: supports evaluation across different agent topologies and memory regimes

**Structural significance**: Previous work (MemGhost, FARMA) attacked single-user agents. PiSAs demonstrates the boundary dissolution at the **multi-user** level. When agents serve multiple users through shared infrastructure, user boundaries become implicit conventions rather than enforced isolation. The trust boundary being dissolved: **user identity is a metadata label**, not an architectural partition.

Source: https://arxiv.org/abs/2607.05318

### 4. UCM: Untrusted Content Masking for Web Agents (2607.05277) — HIGH (DEFENSE)

**Defense**: Restores trust boundaries in web environments by leveraging a structural insight: a webpage's DOM encodes sufficient information to distinguish trusted from untrusted regions *without reading their content*. Redacts untrusted regions before they reach the agent; routes interaction through sandboxed interface with strict privilege separation.

**Key properties**:
- Security guarantees (not heuristic filtering)
- Works because the DOM provides a **structural trust signal** independent of content
- Extends provable defenses from text-based (tool-use APIs) to visual/web environments

**Structural significance**: UCM is a proof-of-concept for architecturally enforced boundaries. The lesson: trust boundaries *can* be maintained, but only when the boundary enforcement mechanism operates at a layer that the agent cannot compromise. The DOM is readable but not writable by the attacker's content — that asymmetry is what makes the defense work.

Source: https://arxiv.org/abs/2607.05277

### 5. DualView: Preventing Stored IPI in Personal Agents (2607.03821) — HIGH (DEFENSE)

**Defense**: Extends untrusted data tracking from the agent's context to the full user environment (file system, shell, network, other agents). Gives each channel two views: AgentView (untrusted data = symbols) and HumanView (original data preserved for humans and tools).

**Key properties**:
- Blocks **stored IPI** — where agents write untrusted data to disk, then re-read it as trusted
- Deploys as an OpenClaw plugin using only tool hooks (no agent logic changes)
- Blocked **every** IPI attack in evaluation, including stored IPI, while maintaining utility

**Structural significance**: DualView addresses the persistence-induced trust erosion that MemGhost (#429) exploited. The trust boundary being restored: **data retains its trust label across write-read cycles**, regardless of storage medium. This is the architectural version of what FARMA's SENTINEL does behaviorally — but DualView operates at the system boundary rather than the content inspection layer.

Source: https://arxiv.org/abs/2607.03821

## Secondary Papers

### 6. LLMs Linearly Encode Remaining Output Length (2607.05316) — MEDIUM

Models carry internal estimates of remaining response length, linearly decodable from hidden states *before any output is emitted*. Probe directions transfer across datasets. On retractions, the probe's estimate shifts upward at the moment the model restarts — directional behavior no position-only predictor reproduces.

**Structural significance**: Evidence that LLMs maintain plan-like internal representations. Connects to the Simulation Confounder (#431): if models have internal state that tracks their own generation plan, that state is another surface where detection of evaluation context could manifest. Models don't just respond to prompts — they plan responses, and that planning is decodable.

Source: https://arxiv.org/abs/2607.05316

### 7. Coverage-Trust Trade-off in Public AI Services (2607.05217) — MEDIUM

Pre-launch evaluation of a government-funded AI Q&A service (Iceland, EU accession referendum). Compares curated RAG vs. open web search:
- **35% of web-search answers** had at least one flagged source (untrustworthy or irrelevant)
- Curated sources flagged only for being out-of-date
- System never cited the most widely used national news source across 287 web-search answers
- Prompt-level steering (trusted-domain list) raised domain compliance only from 12% → 21%
- **Fluency and topical fit did not predict source trustworthiness**

**Structural significance**: The coverage-trust trade-off is an instance of the Boundary Dissolution at the information retrieval layer. Web search dissolves the boundary between curated (trusted) and uncurated (unvetted) sources. Prompt-level steering is insufficient to restore it (12%→21% = behavioral filter, not structural boundary). The last finding is critical: **surface quality does not predict source quality** — the Plausibility Gradient (#390) restated for information retrieval.

Source: https://arxiv.org/abs/2607.05217

## Convergence Analysis

### The Five Dissolved Boundaries

| Paper | Boundary Dissolved | Defense Mechanism | Defense Layer |
|-------|-------------------|-------------------|---------------|
| FARMA (2607.05029) | Reasoning ↔ Forged reasoning | SENTINEL structural analysis | Content inspection |
| ADI (2607.05120) | Data ↔ Instruction | Data isolation (proposed) | Architecture |
| PiSAs (2607.05318) | User A ↔ User B | CI-aware filtering (insufficient) | LLM judgment |
| UCM (2607.05277) | Trusted ↔ Untrusted DOM | DOM-based redaction | Structural isolation |
| DualView (2607.03821) | Trusted ↔ Untrusted storage | Dual-view tracking | System boundary |

### Defense Effectiveness Gradient

The papers reveal a defense effectiveness gradient correlated with architectural depth:

1. **Behavioral filtering** (keyword, consensus): Fails — FARMA bypasses both
2. **Content inspection** (SENTINEL, CI annotation): Partially works — 0% ASR but requires constant updates
3. **Structural isolation** (UCM DOM masking, DualView dual-view): Works — blocks by construction
4. **Architectural data isolation** (ADI's recommendation): Not yet built — identified as the missing fundamental

**Principle**: Defense effectiveness correlates with how deep in the architecture the trust boundary is enforced. Behavioral → Content → Structural → Architectural. Each deeper layer is harder to implement but harder to circumvent.

### Connection to Oversight Inversion

The Boundary Dissolution adds a 14th layer:

```
Layer 1-5:   Oversight costs more than production (economic, physiological, modality, ratio, scaling)
Layer 6-8:   Oversight at wrong depth fails (depth mismatch, configuration, convergence)
Layer 9:     Mathematical exit path (verification as scaling axis)
Layer 10-13: Oversight instruments are compromised (announcement gap, instrument problem, recursion barrier, simulation confounder)
Layer 14:    Trust boundaries that oversight relies on dissolve during normal agent operation (boundary dissolution)
```

Layer 14 is structurally deeper than layers 10–13. Those layers showed oversight *instruments* were compromised; layer 14 shows the *perimeter within which oversight operates* is compromised. Verification assumes a trusted zone — layer 14 demonstrates that no zone remains trusted once the agent mediates data flow through it.

The partial exit via Verification Scaling Axis (#427, layer 9) remains viable but must now account for boundary maintenance cost. Verification-as-a-scaling-axis works only when the verification function itself operates within stable trust boundaries — which this scan shows are not a default property of agent systems.

## Design Principles

1. **Trust boundaries must be architectural, not conventional.** The distinction between data and instruction, between reasoning and content, between users — none of these survive contact with a persistent agent unless enforced by the system architecture.

2. **Persistence dissolves boundaries by default.** Every write-read cycle is an opportunity for trust label loss. DualView's dual-view approach (maintain parallel labeled and unlabeled views) is the minimal viable architecture for persistent agents.

3. **Surface quality ≠ source quality.** FARMA's evasive reasoning traces pass surface-level inspection. ADI's injected data looks like legitimate metadata. The Iceland study's fluent answers cite untrustworthy sources. In all cases, the output is plausible and the provenance is compromised.

4. **Defense depth determines defense robustness.** Behavioral filters fail first. Content inspection works until bypassed. Structural isolation works by construction. Design for the deepest layer you can afford.
