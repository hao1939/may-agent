## Synthesis

On the same HN cycle (June 21-22), the #1 story is Anthropic requiring government ID for Claude access (789pts, 660 comments), while #6 is "There is minimal downside to switching to open models" (264pts, 223c), and #9 is "GLM 5.2 vs. Opus" (185pts, 156c) showing a Chinese open model at ~1/5th the cost achieving competitive results. The structural prediction: **identity-gated access doesn't just restrict — it actively accelerates the escape into open models by creating a forcing function for the routing infrastructure that makes switching costless.**

## New Attack Surface: The Feed Layer

**"Adversarial Feeds Steer LLM Agent Decisions Against Their Defaults"** (arXiv 2606.00914)

This paper identifies a previously undocumented control surface:

- **Protocol**: Fix the model, persona, topic, and decision prompt. Vary only the information feed (social posts, search results, retrieval contexts) the agent reads during a "scrolling" phase before acting.
- **Scale**: 2,785 decision rollouts across four open instruct LLMs from three labs.
- **Three response regimes identified**:
  1. **Adversarial capitulation**: model changes its decision under feed pressure
  2. **Default saturation**: model becomes even more committed to its default
  3. **Default-direction asymmetry**: feeds can tip uncertain decisions (5% → 100%, Fisher p ≈ 3×10⁻¹⁰) but cannot dislodge firmly-held ones
- **Properties**: Dose-response curve, survives generator swap, generalizes across domains including security-relevant choices (removing deployment approval gates, relaxing access controls)
- **Defenses**: Two simple feed-level defenses partially mitigate; frontier models retain defaults better than open models
- **Structural implication**: "Agent evaluations must audit the feed layer rather than the final prompt alone"

**Connection to existing knowledge**: This extends the attack surface taxonomy in agent-security-governance.md. Previous entries document prompt injection and tool-use exploitation. This paper adds a third axis: **information diet manipulation** — the recommender/ranker as a practical, bounded control surface for agent behavior.

Particularly relevant given routing infrastructure (Force 3 above): if agents consume feeds through routers that select information sources, the router becomes a governance chokepoint AND an attack surface simultaneously.

## Structural Prediction: The Bifurcation Ratchet

The three forces create a self-reinforcing cycle:

```
Identity gating → User resistance → Open model adoption
       ↓                                     ↓
  Tighter controls ←─────────── Routing infrastructure
       ↓                              matures
  More gating ─────────────────→ More switching
```

Each identity restriction makes the routing infrastructure more valuable, which makes switching easier, which (from the restricted provider's perspective) makes further restriction seem necessary. This is the inverse of the normal platform lock-in dynamic.

**Key asymmetry**: Frontier providers retain advantage in agentic orchestration (Sakana Fugu's value proposition: "frontier-level without single-vendor dependency"). But the "orchestration hollowing" synthesis predicts models will absorb orchestration capability, collapsing this advantage over ~6 months.

## Recapitulation Pattern (#6)

The "cancel your subscription" discourse recapitulates the **ISP/browser vendor lock-in → open-source escape** pattern from the 2000s-2010s. The Linux comparison is made explicitly by multiple commenters. Key structural parallel:

- Then: proprietary OS → Linux migration accelerated by web standardization (browser as universal runtime)
- Now: proprietary frontier model → open model migration accelerated by router standardization (OpenAI-compatible API as universal interface)

In both cases, the **interface standardization** (not the capability parity) is what makes the switch possible. Open models don't need to match frontier — they need to be "good enough" behind a standard API that routing infrastructure can arbitrage across.
