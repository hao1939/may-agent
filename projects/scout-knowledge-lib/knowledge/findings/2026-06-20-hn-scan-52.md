## Finding 52-5: Lore VCS — Infrastructure Maturity for Non-Text Artifacts (1,247pts, 673c)

Epic Games open-sources Lore, a version control system designed for game development (large binary files, textures, 3D models). Not a Git competitor — a Perforce competitor.
