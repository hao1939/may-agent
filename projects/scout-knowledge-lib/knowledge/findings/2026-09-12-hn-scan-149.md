# HN Scan #149: The Persistence Myth

**Scan date**: 2026-09-12
**Scan number**: 149
**Type**: Cross-source synthesis (arXiv, GitHub, HN)
**Previous**: #148 (Translation Ceiling)

---

## Core Finding

Six new papers (Jun 22-24) independently prove that agent memory is broken at **every layer simultaneously**. This is not one problem with one fix — it is three independent impossibilities that require structurally different solutions:

| Impossibility | Paper | Quantitative Evidence |
|---|---|---|
| **Selection fails** | PACMS (2606.20047, scan #148) | Topic-blind recency truncation discards relevant early facts |
| **Presence ≠ persistence** | Plans Don't Persist (2606.22953) | Plan signal decays **4.1×** in ONE action-observation step |
| **No architecture dominates** | Agent-Native Memory (2606.24775) | 12 systems × 5 workloads: winner depends on workload |

Plus a compounding vulnerability: **Memory Contagion (2606.23195)** proves that evaluator bias propagates through memory cross-temporally, with no safe threshold (detected at contamination rate p=0.2).

The field's response is splitting into two structural camps:
- **Harness/Scaffolding camp**: Fix memory from outside the model (PACMS, RaMem, agent-apprenticeship 906★, AgentSpace 351★)
- **World-Model-as-Foundation camp**: Train the model to BE the environment simulator (Qwen-AgentWorld 297★, 35B/3B MoE, 10M trajectories)

These answer different impossibilities. The harness path addresses selection and architecture. The world-model path addresses persistence by making the model internalize environment dynamics rather than retrieving them.

## Signal 1: Plans Don't Persist — The Deepest Impossibility

**Source**: https://arxiv.org/abs/2606.22953

Plans Don't Persist introduces **replay pairing** — running the same trajectory with and without the plan in history, then measuring hidden-state cosine distance. The results are devastating:

### Key Measurements

| Metric | Value | Implication |
|--------|-------|-------------|
| Plan signal at step+1 | 0.453 cosine distance | Plan is strongly present one step after creation |
| Decay rate | **4.1× in one step** (Llama-70B) | Plan signal collapses after a single action-observation |
| HotpotQA decay | **12.4× in one step** | Even worse for multi-hop reasoning |
| ALFWorld success drop | **-34.7pp** from naive plan eviction | Practical cost is catastrophic |
| Probe-gated re-surfacing | Does NOT recover performance | Even detecting the problem isn't enough |

### Why This Is Structurally Different from PACMS

PACMS (#148) showed that context **selection** is broken — the system picks the wrong items. Plans Don't Persist shows something deeper: even when the plan IS in context, the model's hidden state **doesn't carry it forward**. The plan's influence decays after a single intermediate step.

This means:
- You cannot fix persistence by fixing selection
- You cannot fix persistence by keeping plans in context (they're already there)
- You cannot fix persistence by detecting decay and re-surfacing (probe-gated approach fails)

The only working mechanism observed: **reasoning traces** (`<think>` blocks) that re-derive plan content. This is the "reasoning-trace confound" — reasoning models appear to persist plans, but only because they regenerate them from scratch each step.

**Connection to Specification Ceiling (#144)**: If agents can't persist plans, they can't follow multi-step specifications. The Specification Ceiling is not just about spec quality — it's about whether the model can maintain a spec across multiple execution steps. Plans Don't Persist shows: NO, not without explicit re-derivation at every step.

## Signal 2: No Architecture Dominates — Agent-Native Memory Evaluation

**Source**: https://arxiv.org/abs/2606.24775

The first systematic evaluation of agent memory from a **data management perspective** (not just end-to-end task success). Evaluates 12 memory systems across 5 benchmark workloads spanning 11 datasets.

### Framework Decomposition

Agent memory decomposed into four modules:
1. **Representation & Storage**: How memories are structured
2. **Extraction**: What gets extracted from interaction into memory
3. **Retrieval & Routing**: How memories are found and dispatched
4. **Maintenance**: How memories are updated, consolidated, garbage-collected

### Key Results

| Finding | Implication |
|---------|-------------|
| No single architecture dominates across scenarios | There is no "right" memory system — only right-for-workload |
| Effectiveness depends on memory-structure alignment with workload bottleneck | Memory systems fail when their structure mismatches what the task needs |
| Localized maintenance > global reorganization (cost-efficiency) | Edit-in-place beats periodic full-rewrite |
| End-to-end metrics hide module-level failures | F1/BLEU can succeed while individual modules catastrophically fail |

### Connection to Memory Gold Rush (#117, #148)

This is the formal proof of what the Gold Rush signaled: 751+ repos building bespoke memory with no convergence isn't just a coordination failure — it's **rational** given that no architecture dominates. Each repo is optimal for its specific workload. The missing layer isn't "the right memory system" — it's a **workload-routing** mechanism that selects the right memory architecture for the task at hand.

The PACMS submodular approach (#148) is one specific workload-architecture pair (turn/memory/tool-output selection under token budget). It works for context assembly but won't work for long-horizon planning (where Plans Don't Persist proves the problem isn't selection).

## Signal 3: Memory Contagion — Bias Propagates Through Time

**Source**: https://arxiv.org/abs/2606.23195

Memory Contagion formalizes a novel vulnerability: when agents are evaluated by biased evaluators, the bias enters their memory and propagates to **future agents** retrieving from the same store — even with perfect memory consolidation.

### Key Results

| Finding | Value | Implication |
|---------|-------|-------------|
| Contagion occurs with oracle consolidation | — | Biased input is sufficient cause (consolidation can't fix it) |
| No safe threshold detected | p=0.2 contamination | Even 20% contaminated memories corrupt future behavior |
| Length bias: consolidation attenuates | — | Some biases self-correct through compression |
| Authority bias: consolidation amplifies (preliminary) | — | Some biases are MAGNIFIED by memory maintenance |

### Structural Significance

This connects three prior findings:
- **Eval Trilemma (#147)**: Eval is non-monetizable because biased evaluation corrupts the system it measures
- **Capability Orthogonality (#142)**: EDV proved same agent can't execute AND evaluate (Self-Confirmation Trap); Memory Contagion shows WHY: evaluator bias enters the execution loop through memory
- **Trust Infrastructure (#143)**: TMA-NM proved write-time origin binding is necessary for memory security; Memory Contagion shows that even HONEST evaluators with systematic bias corrupt the system

The implication: agent memory systems need not just security (origin-binding) but **bias quarantine** — mechanisms to detect and isolate systematic evaluator patterns that would propagate.

## Signal 4: Qwen-AgentWorld — World Model as Foundation

**Source**: https://arxiv.org/abs/2606.24597 / https://github.com/QwenLM/Qwen-AgentWorld (297★ in ~2 days)

Qwen-AgentWorld takes a structurally different approach to the persistence problem: instead of fixing memory from outside, train the model to **be** the environment simulator.

### Architecture

| Component | Specification |
|-----------|--------------|
| Model | MoE, 35B total / 3B active, 256K context |
| Training data | 10M+ real-world interaction trajectories |
| Domains | 7 unified: MCP, Search, Terminal, SWE, Android, Web, OS |
| Pipeline | CPT (environment knowledge) → SFT (next-state prediction) → RL (simulation fidelity) |
| Benchmark | AgentWorldBench — real-world interactions of 5 frontier models on 9 benchmarks |

### Why This Is Structurally Novel

Prior world models (for RL, robotics) predict PHYSICAL dynamics. Qwen-AgentWorld predicts **computational environment dynamics** — what happens when you run a command, click a button, make an API call. The training objective IS world modeling from the CPT stage onward (not a post-hoc add-on).

Two paradigms demonstrated:
1. **As environment simulator**: Enables scalable agentic RL without real environments (surpasses real-environment training alone)
2. **As agent foundation**: World-model pre-training improves downstream agent performance across 7 benchmarks

### Connection to Persistence Problem

If the model has internalized environment dynamics through training, it doesn't NEED to persist plans in context — it can predict the next state directly from the current state. This sidesteps the Plans Don't Persist impossibility by removing the dependency on plan persistence entirely.

**However**: This requires the environment to be IN the training distribution. Novel environments (the 82.2% of NatureBench tasks that agents fail on from scan #148) remain outside the world model's repertoire — the Translation Ceiling still applies.

**Pattern in agent-apprenticeship** (906★ in 5 days): The highest-starred new agent repo this week is NOT a memory system, sandbox, or harness — it's a **training signal exchange**. 500+ seed tasks, 495 lessons, 1000+ execution traces shared as a commons. This is the first repo that treats agent improvement as a collective infrastructure problem rather than an individual agent problem.

It directly addresses the Memory Contagion vulnerability: by making learning signals explicit and exchangeable (rather than accumulated implicitly through biased evaluators), it creates the conditions for bias-aware training.

**AgentSpace** (351★) represents a different philosophy: instead of agents as tools, agents as **first-class teammates** in a shared workspace with humans. The governance question shifts from "how to constrain agents" to "how to give agents and humans the same status in a collaborative environment."

**Pattern**: Fewer repos but larger scope per repo. The foundation approach requires massive training investment (10M trajectories for Qwen-AgentWorld) and produces a single artifact that works across domains. The scaffolding approach is modular, composable, and domain-independent.

### What This Means for the Productive Zone (#148)

The Translation Ceiling (#148) bounded agents by their methodological repertoire. The Persistence Myth reveals that even WITHIN the repertoire, multi-step execution is unreliable unless:
1. The task can be solved in a single step (no plan persistence needed)
2. The model re-derives the plan at every step (reasoning traces)
3. The environment dynamics are in the model's training distribution (world model)

This further narrows the Productive Zone:

```
{clear specs} ∩ {known patterns} ∩ {single-step OR re-derivable OR trained-environment}
```

The gold rush (#117) is building storage. PACMS is building selection. But the binding constraint — whether the model actually USES what's in context across multiple steps — remains unsolved from the harness side. Only world-model training (Qwen-AgentWorld) and reasoning re-derivation (which is expensive and unreliable per Plans Don't Persist) address it.
