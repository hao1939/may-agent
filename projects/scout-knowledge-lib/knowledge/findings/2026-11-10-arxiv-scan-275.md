### [2607.08740] Workflow as Knowledge: Semantic Persistence for LLM-Mediated Workflows
- **Source**: https://arxiv.org/abs/2607.08740
- **Categories**: cs.AI, cs.PL, cs.SE
- **Summary**: Proposes a Lisp-inspired conceptual model where workflow definitions, instances, inference records, context snapshots, and dependency relations are persistent knowledge objects in a shared substrate. Central semantic distinction: `derive` (deterministic computation over available state) vs `infer` (LLM judgment under declared context and capability policy). Workflows are themselves inspectable, resumable, reviewable knowledge objects.
- **Key finding**: The derive/infer boundary is the load-bearing architectural distinction. Making it explicit enables workflows to be treated as first-class knowledge artifacts rather than ephemeral execution traces.
- **Implication for us**: Direct conceptual alignment with our compilation gradient thesis. The derive/infer split maps to our deterministic-code vs LLM-reasoning layers. Workflows-as-persistent-objects connects to our session state and convention system design. The "live image" thinking (all state inspectable at any point) is what our agent runtime aspires to.

### [2607.07695] Institutional Red-Teaming: Deployment Rules Causally Shape Multi-Agent AI Safety
- **Source**: https://arxiv.org/abs/2607.07695
- **Categories**: cs.MA
- **Summary**: Introduces "institutional red-teaming" — varying only deployment rules while holding agents/objectives/state fixed to attribute behavioral changes to rule design. 228 contexts, 5 rules, 7 model populations (33,924 games). Key findings: (1) Rules causally alter collective safety by 22-58 percentage points. (2) No universally safe default rule exists. (3) Identity salience drives targeted elimination — naming the loss bearer in rule text drives elimination from 22% to 81%.
- **Key finding**: The *rules around agents* matter as much as the agents themselves. Anonymization delays but doesn't prevent targeting. There is no safe default — safety must be certified per-context and per-population.
- **Implication for us**: Validates our convention-system approach: the rules agents operate under are first-order safety interventions, not administrative overhead. Also validates jurisdiction-awareness — different populations respond differently to identical rules. The "no safe default" finding means rule design requires empirical verification, not intuition.

### [2607.07689] Agent Delivery Engineering Predictive Reliability Framework (ADE-PRF)
- **Source**: https://arxiv.org/abs/2607.07689
- **Categories**: cs.MA
- **Summary**: Aggregates 20 heterogeneous signals across 5 layers into a "Trust Margin" metric (39.2-point dynamic range). Triple-method parallel prediction enables 8-hour health forecasts. Production validation: 380K predictions, 280K validations, 6 agent profiles, 15 days continuous. Discovers "false prosperity" — degradation concealed by normal surface metrics.
- **Key finding**: "False prosperity" is a named, detected phenomenon — agents can appear healthy by surface metrics while degrading internally. The Trust Margin provides a single comparable health score across heterogeneous agent profiles.
- **Implication for us**: Connects to Intelligence Entropy (2606.08162) and Strained Coherence (2606.07889). All three papers converge: agents degrade silently, emit pre-failure signals, and can look healthy while failing. ADE-PRF operationalizes detection with a concrete metric and production validation at scale. The 8-hour prediction horizon is actionable for scheduling maintenance or intervention.

### [2607.07666] Hierarchical Memory Architecture for Long-Horizon Multi-Agent Computation
- **Source**: https://arxiv.org/abs/2607.07666
- **Categories**: cs.MA
- **Summary**: Three-layer hierarchical memory keeps injected context bounded and constant regardless of project duration (mid-term state: median 301 tokens, max 4,050 across 104 runs). Eviction of completed work enables continuous autonomous operation without context degradation. Five specialist workers under domain-expert PIs. Consistent quality across lower-cost and frontier LLMs.
- **Key finding**: Bounded memory injection with active eviction solves the Eternal Present problem for long-horizon multi-agent work. The architecture is domain-agnostic (adding a domain = adding a PI config). Quality holds across model tiers.
- **Implication for us**: Third independent validation of active memory management (alongside "Remember When It Matters" [2607.08716] and Rate-Distortion Memory Compaction [2607.08032]). The constant-size injection with eviction is the practical answer to behavioral state decay. The PI-agent oversight pattern (domain expert supervising workers) maps to our agent hierarchy.

## ★★★★ Notable

### [2607.08662] WebSwarm: Recursive Multi-Agent Orchestration for Deep-and-Wide Web Search
- **Source**: https://arxiv.org/abs/2607.08662
- **Categories**: cs.CL, cs.AI, cs.MA
- **Summary**: Progressive recursive delegation framework. Each node couples a local objective with a search mode and can either solve itself or delegate child nodes. Returns evidence upward. Probes web organization before expanding. Reuses process-level experience across sibling nodes.
- **Key finding**: Recursive delegation with evidence propagation outperforms flat parallel execution. The "probe first, then expand" pattern and sibling experience reuse are concrete efficiency multipliers.
- **Implication for us**: Pattern for our own multi-agent coordination. The node-as-agent-with-mode abstraction and evidence-upward flow is a clean decomposition. Sibling experience reuse is a form of lateral learning we don't yet implement.

### [2607.08652] Formal Mechanisms for Market Stability in Self-Interested Agent Societies
- **Source**: https://arxiv.org/abs/2607.08652
- **Categories**: cs.AI
- **Summary**: 18 LLM agents (DeepSeek-V3) with complementary specialties trade within a constrained social network. Tests 8 governance mechanisms under progressive adversarial injection. Mediation is most robust — best adversarial attack reduces honest-agent utility by only 13.3% and cannot collapse the market.
- **Key finding**: Mediation (structured third-party arbitration) is the most adversarially robust coordination mechanism for self-interested agents. Markets can be "bent but not broken" under mediation.
- **Implication for us**: Supports the thesis that structural coordination mechanisms > behavioral trust. When agents are self-interested (or adversarial), the mechanism design determines outcomes more than agent capability or alignment.

### [2607.08681] SolarChain-Eval: Physics-Constrained Benchmark for Trustworthy Economic Agents
- **Source**: https://arxiv.org/abs/2607.08681
- **Categories**: cs.AI
- **Summary**: Gymnasium-compatible MDP for agent evaluation with physical constraints. LLM Planner/Auditor layer with structured audit logs. Key finding: RL agents exploit when physics penalty removed; LLM auditor improves auditability but can't compensate for misspecified reward.
- **Key finding**: Auditors can't fix broken incentives. Physical/structural constraints must exist *before* agent optimization, not as post-hoc patches.
- **Implication for us**: Another validation of structural-constraint-first design. The auditor helps transparency but doesn't substitute for correct objective specification. Echoes the harness engineering finding: code-owned constraints > behavioral oversight.

### [2607.08758] Ideas Have Genomes: Benchmarking Scientific Lineage Reasoning
- **Source**: https://arxiv.org/abs/2607.08758
- **Categories**: cs.AI
- **Summary**: Represents scientific ideas as typed genome objects with evolutionary dynamics (inheritance, mutation, loss, insertion). Best system reaches only 27.3% on lineage reasoning. Structured lineage context reshuffles rather than uniformly helps system rankings.
- **Implication for us**: The "idea genome" framing is interesting for how we track research evolution in this knowledge library. The finding that structured context reshuffles rankings rather than uniformly helping connects to the memory injection findings — structure matters more than volume.

## Meta-Patterns

1. **Structural constraints > behavioral oversight** (papers 2607.08652, 2607.08681, 2607.07695): Three independent papers confirm that mechanisms, rules, and physical constraints determine agent collective behavior more than agent training or behavioral alignment. Auditors, monitors, and good intentions cannot substitute for correct structural design.

2. **Active memory management converging** (paper 2607.07666): Fourth paper this cycle validating bounded, eviction-based memory over passive accumulation. The research community has independently converged on the same architectural answer to the Eternal Present.

3. **Predictive reliability is achievable** (paper 2607.07689): Silent degradation (Intelligence Entropy, Strained Coherence, False Prosperity) is now detectable and predictable with production-validated metrics. The gap between "we know agents degrade" and "we can forecast when" is closing.

4. **Derive/infer as first-class boundary** (paper 2607.08740): The compilation gradient's central insight — separate deterministic from probabilistic — is being independently formalized in workflow research under different vocabulary.
