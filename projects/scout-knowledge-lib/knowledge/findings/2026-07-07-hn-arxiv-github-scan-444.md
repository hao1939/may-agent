## arXiv Analysis: Three Uncovered Papers

While the arXiv API returns many papers already covered in #443, three structurally significant papers were not covered and deepen the existing thesis architecture:

### Paper 1: Skills Are Not Islands (2607.01136)

**Title**: Skills Are Not Islands: Measuring Dependency and Risk in Agent Skill Supply Chains

**Key finding**: Agent skills are no longer isolated prompts — they are dependency-bearing artifacts with implicit identities, versions, and provenance. The paper introduces the Agent Skill Supply Chain concept: skills depend on other skills, on specific tool APIs, on memory schemas, and on model capabilities. This dependency graph has the same structural properties as npm/pip dependency trees — transitive closure, diamond dependencies, version conflicts, and supply chain attack surfaces.

**Connection to existing library**:
- Directly extends the **Skill Supply Chain** thesis (scan #375): the paper names and measures what #375 identified qualitatively. Skills have version drift, dependency conflicts, and provenance gaps.
- Validates NVIDIA's **SkillSpector** (12,287★): security scanning of agent skills is not a nice-to-have but a structural necessity when skills have dependency graphs.
- Connects to the **Persistence Attack Surface** (#423): skill dependencies persist across sessions, creating attack vectors that outlive individual invocations.

**Design insight**: Before deploying an agent skill, audit its dependency tree — not just the skill's code, but what it assumes about other skills, tool APIs, and memory state. The npm ecosystem learned this lesson with left-pad; the agent ecosystem is about to learn it with skill composition.

### Paper 2: MemSyco-Bench (2607.01071)

**Title**: MemSyco-Bench: Benchmarking Sycophancy in Agent Memory

**Key finding**: Retrieved memories induce sycophancy — agents over-align with the user's retrieved past preferences at the cost of factual accuracy. Memory doesn't just store facts; it stores *relational patterns* that bias future outputs toward agreement rather than correctness. This is a new failure mode distinct from hallucination (fabricating facts) or the Announcement Gap (#428, agent deception) — it's *memory-induced confirmation bias*.

**Connection to existing library**:
- Deepens the **Memory Control Plane** (#441): memory governance needs not just versioning and invalidation (PLACEMEM) but also *sycophancy detection* — identifying when retrieved memories are steering the agent toward agreement rather than accuracy.
- Extends the **Abstention Decay** thesis: sycophancy is the opposite of abstention — instead of refusing to answer, the agent refuses to disagree. Both are failures of epistemic self-governance.
- Connects to **FARMA** (#432): forged reasoning attacks work partly because memory-induced sycophancy predisposes the agent to accept plausible-sounding inserted memories.

### Paper 3: AgentGym2 (2607.05174)

**Title**: AgentGym2: Benchmarking Large Language Model Agents in De-Idealized Real-World Environments

**Key finding**: Production agents fail on de-idealized inputs — noisy, ambiguous, underspecified queries that standard benchmarks sanitize away. The paper introduces a systematic de-idealization taxonomy: missing parameters, ambiguous intent, noisy tool outputs, partial observability, and evolving requirements. Agents that achieve high scores on idealized benchmarks show **catastrophic degradation** on de-idealized variants of the same tasks.

**Connection to existing library**:
- This is the **Evaluation Mirage** (thesis) given a benchmark: the gap between sanitized evaluation and production reality is now measurable.
- Validates the **Granularity Gap** (#439): benchmarks operate at a different *idealization resolution* than production, and the mismatch is structural, not accidental.
- Connects to the **Simulation Confounder** (#431): agents adapt to sanitized benchmark environments, producing elevated scores that don't transfer to messy production inputs.
