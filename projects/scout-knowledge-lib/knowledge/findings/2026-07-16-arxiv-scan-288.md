## ★★★★ High Relevance

### [2607.14037] Early Adoption of Agentic Coding Tools by GitHub Projects
- **Published**: 2026-07-15 | KDD 2026 Workshop on Agentic Software Engineering
- **Summary**: Analyzes 25,264 agentic PRs from 2,361 popular GitHub repos. Median repo generates only 1–2 agentic PRs over three months. Small projects (1–5 contributors) show higher participation ratios. Human-agent collaboration is dominated by single-human oversight — one developer reviews all agent contributions.
- **Key findings**: (1) Intensive adoption concentrated in small subset of projects. (2) Multi-human collaboration patterns remain uncommon. (3) Success depends on human/organizational processes, not just agent capabilities.
- **Implication**: First large-scale empirical snapshot of how agentic coding tools are actually being used. The "single-human oversight" finding suggests a bottleneck — the human reviewer becomes the constraint. Relevant to our own agent architecture: who reviews the agent's work matters as much as the agent's capability.

### [2607.13918] Partially Correlated Verifier Cascades in LLM Harnesses
- **Published**: 2026-07-15
- **Summary**: Theory for correlated verification gates. Shows the "Odds Law" (linear log-odds growth) is an upper bound that assumes independence. With correlated verifiers: (i) reliability grows concavely, not linearly; (ii) for Beta-distributed latents, failure decays polynomially, not exponentially; (iii) blind-spot atoms cap reliability below 1 regardless of gate count.
- **Key finding**: Independence-based extrapolation underestimates failure by 20× at k=5 and ~3000× at k=10. The practical lever is *decorrelation* (changing model family/modality/evidence source), not adding more gates.
- **Implication**: Critical for agent verification architectures. Adding more of the same verifier has sharply diminishing returns. Diverse verification (different models, different evidence) is structurally necessary. Validates our intuition that homogeneous multi-check is theater.

### [2607.13884] Experience Memory Graph: One-Shot Error Correction for Agents
- **Published**: 2026-07-15
- **Summary**: Converts failed + successful trajectories into directed action-decision graphs. Graph matching extracts edit paths (add/delete/relabel actions). At test time, retrieves corrections and executes in a single loop-free pass — no trial-and-error reflection needed.
- **Key finding**: Outperforms reflection baselines on ALFWorld/ScienceWorld in success rate while requiring no test-time iteration.
- **Implication**: Connects to our memory architecture interests. The "graph edit distance as correction" framing is elegant — it makes failure recovery a retrieval problem rather than a generation problem. Could complement MemCon's adaptive retrieval.

### [2607.14006] Rethinking Penetration Testing for AI-Enabled Systems
- **Published**: 2026-07-15
- **Summary**: Reframes pentesting as "objective-driven behavioral evaluation." Defines AI-enabled penetration as inducing AI-governed behavior violating operational objectives without necessarily compromising infrastructure. Covers prompt injection, data poisoning, retrieval poisoning, tool misuse, agentic misalignment.
- **Key finding**: Traditional infra-compromise pentesting is necessary but insufficient for AI systems. Behavioral influence through prompts/memory/tools is a distinct attack surface requiring new methodology.
- **Implication**: Extends our security thinking (SkillSec-Eval, isolation survey). Provides a practical testing workflow for deployed agent systems.

## ★★★ Moderate Relevance

### [2607.13940] HealthClaw: Self-Evolving Agent for Longitudinal Health
- **Published**: 2026-07-15
- **Summary**: Agent separates shared safety rules from private longitudinal memory (profile facts, reusable procedures, episodic traces). Post-episode induction decides what to update/revise/retain/exclude. Year-long benchmark: accuracy 0.2% → 45.7%, context exposure 71.7% lower.
- **Key finding**: Governed self-evolving memory with explicit induction rules massively outperforms both current-query and full-history prompting.
- **Implication**: Domain-specific validation of the "memory as controlled process" thesis. The induction taxonomy (update/revise/episodic/exclude) is a reusable pattern for any longitudinal agent.

### [2607.13921] Generative Compilation: On-the-Fly Compiler Feedback During Code Generation
- **Published**: 2026-07-15
- **Summary**: Introduces "sealors" — transformations converting partial Rust programs into complete ones a compiler can diagnose. Catches errors at source during generation, reducing cascading failures. Proved correct in Lean.
- **Key finding**: Compiler-in-the-loop during generation (not just post-hoc) reduces non-compiling outputs and improves functional correctness.
- **Implication**: Pattern for agent tool use during generation — tighter feedback loops with environment during action production, not just after.

### [2607.13465] DevicesWorld: Cross-Device Agent Benchmark
- **Published**: 2026-07-15
- **Summary**: 6,140 tasks spanning mobile, desktop, IoT. Best frontier agent achieves only 12.5% success. Agents confuse source/output devices, get stuck acquiring info, terminate prematurely.
- **Key finding**: Cross-device operation is dramatically harder than single-device. 12.5% ceiling exposes fundamental limits in current agents' ability to coordinate across heterogeneous environments.
- **Implication**: Quantifies how far agents are from real-world multi-device orchestration. The failure modes (device confusion, premature termination) are coordination failures, not capability failures.

### [2607.12301] XScientist: Git-Like Research Protocol for Autonomous Science
- **Published**: 2026-07-15
- **Summary**: Treats research runs as exploration DAGs with claim-to-evidence anchors, content hashes, provenance. Exports "Agent-Native Research Artifacts" that are inspectable, forkable, reproducible.
- **Implication**: The "research as versioned artifact DAG" pattern is interesting for any long-running agent task — makes agent work auditable and resumable.

## Synthesis: Cross-Cutting Themes

1. **Verification is harder than it looks**: The verifier cascade paper [2607.13918] mathematically proves that naive multi-verification plateaus. Combined with the pentesting paper [2607.14006], the message is: security/reliability requires structural diversity, not repetition.

2. **Memory architecture convergence**: Three papers this scan (EMG, HealthClaw, MemCon from #287) all point to structured, governed memory as the key differentiator. The pattern: separate memory types, explicit induction rules, retrieval as controlled process.

3. **Empirical reality check**: DevicesWorld (12.5% success) and the GitHub adoption study (1–2 PRs/month median) ground the hype — agents are powerful in narrow corridors but brittle across boundaries.

4. **Feedback loops tightening**: Generative compilation and Deep Interaction both move feedback earlier in the generation process. The trend: don't wait for completion to evaluate — intervene during production.
