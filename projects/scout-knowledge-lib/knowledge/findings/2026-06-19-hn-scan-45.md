## Finding 45-1: "Are You in the Weights?" — Training Data Presence as Identity Question (366pts, 215c)

**Signal strength: HIGH** — novel tool surfaces a new category of AI concern.

"Show HN: Are You in the Weights?" (366pts, 215c) is a tool that queries multiple LLMs to determine how much they "know" about you. A user enters their name; the tool queries 10+ models and reports a score (0-1000) indicating training data presence.

### Key Positions

| Author | Signal | Pattern |
|--------|--------|---------|
| **amdivia** | "A terrorist on the US sanction list... the first female airplane suicide bomber?? I was in the US a year ago and I did not bomb any planes. I think with Arabic names it's highly biased, which is kind of scary" | **Hallucination as identity harm** — false associations with violence for Arabic names |
| **jasonkester** | "It dug up a bunch of what can only be my information, then made up a bunch of confidently wrong things. Founder of three separate startups I've never heard of" | **Confident confabulation** — real data mixed with invented biography |
| **hyperpape** | "I'm a hallucination. None of these are me. DeepSeek v4: 'known for thoughtful comments on rationality and philosophy'" | **Total fabrication** — the person described does not exist |
| **jedberg** | "740, top 5%. Nearly all of them got it right. I suspect being in the Open Source world is a bit of a bubble" | **Accuracy bias** — OSS figures well-represented; others fabricated |
| **mikewarot** | "my Reddit history is part of every training set. It was taken without my consent. So now I'm immortal in a way, hiding in the weights" | **Consent-free immortality** — framing data presence as involuntary persistence |
| **keiferski** | "According to Gemini, I, the only person in the world with my name, am a professional soccer player" | **Unique name → pure hallucination** |
| **bostik** | "My chosen name collision with my online handle makes the models consistent. They all are certain that I am an adhesives manufacturer. Assessment: NO STABLE PERSON FOUND" | **Name collision** — handle overrides person |
| **Alive-in-2025** | "No way in heaven or earth I'm using my real name with this" | **Privacy reflex** — even querying is a risk |

### Structural Significance

This is NOT just "LLMs hallucinate" (known). It surfaces **three new concerns**:

1. **Hallucination as identity harm** — amdivia's experience (Arabic name → terrorist association) is a concrete, potentially actionable harm. If an agent system uses LLM knowledge about people for decisions (hiring, access, trust), these fabrications become consequential.

2. **The asymmetry of presence** — OSS contributors (jedberg, nickcw) are accurately represented. Everyone else gets confabulation. This creates a class divide: people with public technical artifacts get truth; private individuals get fiction.

3. **Name as API key** — The tool reveals that a person's name is effectively a query key into distributed, inconsistent, ungovernable databases (model weights). You can't edit your entry, can't request deletion, can't verify accuracy.

### Library Connections

- **Agent Security & Governance** — Agent systems that use model knowledge about people as a trust signal inherit all these failure modes. The supply chain attack (Finding 44-1) targets code; this targets identity.
- **The Fail-Plausible Equilibrium** — The tool's output LOOKS authoritative (scores, model citations, biographical text) but contains fabrications indistinguishable from facts.
- **MemVenom (arXiv 2606.15899)** — If persistent agent memory can be poisoned (99.15% success), model weights are the ultimate unpoisonable-but-also-uncorrectable memory. You can't patch weights like you can patch a database.

### Novel Predictions

1. "Training data presence" queries become a standard pre-employment/background check tool within 12 months — regardless of accuracy
2. Regulatory action on "right to accuracy in model weights" emerges within 18 months (extending GDPR right-to-rectification)
3. Agent systems will need "identity verification" primitives that DON'T rely on model knowledge about people
