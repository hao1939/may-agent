# Scan #222: The Hard Boundary Requirement

**Date**: 2026-10-28
**Sources**: arXiv, Hacker News, GitHub
**Theme**: Soft governance fails at agent scale — only hard boundaries produce reliable containment

---

## Core Thesis

Five independent research/practitioner streams converge on the same structural lesson: every soft governance mechanism (iteration caps, ML-based routing, reputation scores, token monitoring) fails under the specific pressures of autonomous agent operation. The replacement in each case is a *hard boundary* — formal, deterministic, information-theoretic, or cryptographic. The transition from soft to hard is the binding constraint on production agent deployment.

---

## Signal 1: Semantic Early-Stopping (arXiv 2606.27009)

**Paper**: "Semantic Early-Stopping for Iterative LLM Agent Loops"

Multi-agent loops (Writer→Critic cycles) almost universally use `max_iterations` — a syntactic kill-switch blind to whether the answer is still improving. This paper proves:

- **38% token reduction** at quality parity (ΔIS = -0.004, p=0.81) using judge-free semantic stopping (cosine distance + patience window)
- Full quality-gated stopping is *counter-productive* because per-round judging dominates cost
- Oracle that selects best round achieves +0.115 Information Score over every practical policy (p ≈ 4e-11)
- **Key reframe**: the problem is not "when to stop" (easy via distance convergence) but "which round is best" (open problem)

**Hard boundary contribution**: Replaces soft cap with formal convergence criterion. Deterministic termination proved and machine-checked.

Source: https://arxiv.org/abs/2606.27009

## Signal 2: On-Chain Trust Collapse (arXiv 2606.26028)

**Paper**: "Can Trustless Agents Be Trusted? An Empirical Study of the ERC-8004 Decentralized AI Agent Ecosystem"

First empirical audit of the only deployed permissionless trust layer for agent economies:

- **73.6%, 59.2%, 90.6%** of reviewers across Ethereum, BSC, Base exhibit coordinated Sybil behavior
- After removing Sybil feedback: 15.5%, 72.3%, 89.4% of rated agents have **zero valid feedback**
- Only 3-15% of registered agents expose a valid registration file with live endpoint
- Reputation values are *not commensurable* — no aggregation produces trust signal
- Feedback records rarely grounded in verifiable interactions

**Hard boundary implication**: Soft reputation (rating, review, social proof) cannot produce trust at agent scale. Only cryptographic/formal verification (cryptographic certificates from scan #191, parameter transparency from scan #198) can close the gap. The entire ERC-8004 approach — soft social trust primitives on chain — is structurally inadequate.

Source: https://arxiv.org/abs/2606.26028

## Signal 3: Intelligence as Compression (arXiv 2606.25960)

**Paper**: "Agentic System as Compressor: Quantifying System Intelligence in Bits"

First formal information-theoretic metric for *system-level* agent intelligence:

- Under fixed task distribution, interface, and compute budget: stronger system = fewer bits to reconstruct target
- Operationalized via arithmetic coding, seed coding, and fallback
- Validated in 5 settings: reversed text, chess, protein sequences, RAG QA, semantic compression
- **All agentic components reduce codelength** — tools, retrieval, verifiers, search all measurably compress

**Hard boundary contribution**: Replaces benchmark scores (soft, task-specific, gameable) with information-theoretic quantity (hard, universal, budget-conditioned). First principled way to compare agent *systems* (not just models) under resource constraints.

Source: https://arxiv.org/abs/2606.25960

## Convergence Analysis

| Domain | Soft (failing) | Hard (emerging) | Evidence |
|--------|---------------|-----------------|----------|
| Loop control | max_iterations | Semantic convergence | 38% savings, formal termination proof |
| Trust | Reputation/ratings | Cryptographic/formal | 73-90% Sybil on-chain |
| Evaluation | Benchmark scores | Information-theoretic bits | Compression metric, budget-conditioned |
| Routing | ML model selection | Deterministic rules | ML routers ≤7pts; deterministic = 86pts |
| Budget | Monitoring/alerting | Pre-execution enforcement | 7+ tools, all need hard-stop semantics |
| Disclosure | 90-day social norm | (none yet) | Exploitarium broke the norm |
| Access control | Political gatekeeping | (none — diffusion wins) | Asian models launched during ban |

**The pattern**: soft governance works when (1) actors are cooperative, (2) scale is bounded, (3) speed is human-scale. Autonomous agents violate all three simultaneously. The field is discovering this independently in every governance domain.

---

## Implications for Our System

1. **Loop control**: Our multi-agent loops should use semantic convergence (cosine distance on outputs) rather than hard iteration caps. The "which round is best" open problem is more relevant than "when to stop."

2. **Memory governance**: The ERC-8004 collapse validates our investment in write-path governance (scan #220, Read-Write Attention Inversion). Soft trust in writes (reputation, social proof) structurally fails. Our approach — explicit file ownership, git provenance, governed writes — is the correct hard boundary.

3. **Budget enforcement**: Our agents currently have no hard budget stops. The tool graveyard suggests this should be framework-integrated, not bolt-on. Token counting at the harness level is the right surface.

4. **Eval**: Compression-as-intelligence metric could complement our existing eval patterns. An agent that produces the same output with fewer bits of context is measurably better.
