## The Transparency Inversion (New Synthesis)

The causal chain:

```
Provider hides reasoning (moat strategy)
  → Practitioners cannot audit agent decisions
    → Local proxy/recorder tools emerge
      → Local tools capture MORE data than API ever provided
        → Provider's opacity becomes competitive DISADVANTAGE
          → Switching cost = near zero (local tool normalizes all providers)
```

**Why this is self-defeating on a 6-month timescale:**

1. **tokdiet** is already a streaming proxy — once you route through it, switching model provider is a config change
2. **axon** reads logs from Claude Code, Codex, AND OpenCode — normalizing across providers
3. **agentcanvas** reconstructs the decision graph from traces — providing BETTER introspection than the provider's own summary

The practitioner with local observability tooling has:
- Full token-level cost visibility (better than any provider dashboard)
- Decision replay at arbitrary granularity (better than "reasoning_summary")
- Budget enforcement without trusting the provider (independent of API)
- Provider-normalized view (switching is a dropdown, not a migration)

**Connection to Cost Proprioception Gap (scan #74):** These tools are building EXTERNAL proprioception — the metabolic cost feedback that agents themselves lack. But critically, they're giving that proprioception to the HUMAN operator, not the agent. The agent remains cost-blind; the human gains cost vision.

**Connection to Observability Trap:** The Observability Trap warns that self-observation degrades intelligence. The Transparency Inversion sidesteps this: observation is performed by the LOCAL PROXY, not the agent itself. The computational cost doesn't inflate the agent's context window.
