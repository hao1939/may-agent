### Claude Code sends 33k tokens before reading the prompt (79pts/28c)
[systima.ai analysis](https://systima.ai/blog/claude-code-vs-opencode-token-overhead) — Wire-level comparison shows Claude Code sends ~33k tokens of system prompt/context before processing user input; open-source OpenCode sends ~7k. The 4.7x overhead is pure "protocol tax" — scaffolding, tool definitions, safety preambles. At scale this is a significant cost multiplier that users don't see.

**Connection**: Directly validates the Token Economics Trap thesis. Agent protocols carry invisible overhead that compounds across sessions. Also connects to the Factory Inversion — the trivial agent loop balloons when wrapped in production scaffolding.

### Automation Without Understanding (37pts/22c)
[arxiv.org/abs/2607.06377](https://arxiv.org/abs/2607.06377) — Essay arguing AI can now produce research-level mathematics, but the US is simultaneously gutting the human pipeline for *understanding* math. The trained ability to verify, interpret, and challenge reasoning is a separate capability from theorem production. Without it, automation produces unverifiable output.

**Connection**: Mirrors the Verification Inversion — as agent capability increases, human verification capacity may decrease, creating a growing trust gap with no backstop. Complements the "AI flattens discovery" IEEE study (110pts, still on front page).

## Meta-Pattern: The Token Tax

The Claude Code token overhead story crystallizes a hidden cost layer in agent infrastructure: **the token tax**. Every production agent wraps the core LLM call in layers of system prompts, tool schemas, safety preambles, and context scaffolding that multiply cost 3-5x beyond the "visible" interaction. This is the Factory Inversion's cost signature — the factory infrastructure is more expensive than the work it orchestrates. Combined with the Automation Without Understanding essay, a dual tax emerges: tokens cost money, and verifying what those tokens produce costs human capacity that's being defunded.
