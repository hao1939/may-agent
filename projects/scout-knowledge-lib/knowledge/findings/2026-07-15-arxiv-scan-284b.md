## ★★★★ High Relevance

### [2607.12893] MemOps: Benchmarking Lifecycle Memory Operations in Long-Horizon Conversations
- **Source**: https://arxiv.org/abs/2607.12893
- **Published**: 2026-07-14
- **Summary**: Reformulates agent memory as a lifecycle of explicit operations (remember, forget, update, reflect, compose) rather than static fact retrieval. Introduces structured traces per memory event (trigger, target, scope, state transition, evidence). Evaluates long-context, retrieval-based, parametric, and managed-memory systems.
- **Key findings**: Session-level retrieval outperforms turn-level retrieval. Long-context models are notably weak at reconstructing ordered memory-state trajectories. Final-answer accuracy conceals heterogeneous failure modes.
- **Implication for us**: Directly relevant to our agent memory architecture. The lifecycle-operation framing (memory as verbs not nouns) maps to how we think about context persistence. The finding that ordered trajectory reconstruction is a weak point validates our append-only trace design. Could inform how we evaluate our own memory systems.

### [2607.12215] RCWT: Measuring Task-Budget Displacement from Coordination Content in LLM Calls
- **Source**: https://arxiv.org/abs/2607.12215
- **Published**: 2026-07-13
- **Summary**: Formalizes and measures how coordination content (shared state, prior discussion, tool outputs, role instructions) displaces task budget in fixed-context-window calls. Introduces "Roundtable Context Window Test" protocol.
- **Key findings**: Models degrade sharply once residual reference evidence falls to a few hundred tokens. BUT when task evidence remains intact (expanded total length), no degradation occurs even at 95% coordination ratio. The cliff is displacement, not interference.
- **Implication for us**: Critical validation of our context-management approach. The finding that coordination overhead only hurts when it *displaces* task content (not when total window expands) means the right fix is budget allocation, not coordination reduction. Directly relevant to multi-agent prompt assembly.

### [2607.12469] Agent-Safety Evaluations as Load-Bearing Evidence
- **Source**: https://arxiv.org/abs/2607.12469
- **Published**: 2026-07-14
- **Summary**: Argues safety eval results aren't yet "load-bearing evidence" — identical nominal outcomes may sit atop different evidence regimes. Introduces reconstructability metric: can captured evidence reconstruct the decision a claim depends on? Defines Evidence Sufficiency Cards and overclaim gaps.
- **Key findings**: Sufficiency spans 0.458–0.833 across inputs sharing a surface reading. Replay preconditions unmet in every scored trace. Safety claims should travel with their reconstructability vector.
- **Implication for us**: Extends our Evaluation Mirage thesis. The "reconstructability" concept is a precise operationalization of what we've been calling evaluation depth. The sufficiency-gate pattern (block raw variant, pass instrumented) is a deployable governance primitive.

## ★★★ Moderate-High Relevance

### [2607.13034] Do AI Agents Know When a Task Is Simple? (E3 Framework)
- **Source**: https://arxiv.org/abs/2607.13034
- **Published**: 2026-07-14
- **Summary**: Formalizes "minimum-sufficient execution" and proposes E3 (Estimate, Execute, Expand). Agents estimate task difficulty, execute minimum viable path, expand only on verification failure. Achieves 100% success with 85% cost reduction, 91% token reduction, 92% fewer files inspected.
- **Key finding**: Agent Cognitive Redundancy Ratio (ACRR) — most agent work is over-reading. The minimum viable execution path is dramatically cheaper than the default maximum-context approach.
- **Implication for us**: Validates our reasoning_effort / lean-execution patterns. The "expand only on failure" principle is our escalation architecture in empirical form. Direct practical relevance to how we configure agent sessions.

### [2607.12406] Isolation as a First-Class Principle for LLM-Agent System Safety
- **Source**: https://arxiv.org/abs/2607.12406
- **Published**: 2026-07-14
- **Summary**: Survey treating isolation (separation of user inputs, tool access, execution channels, inter-agent communication, environment context) as the organizing principle for agent safety. Five-boundary taxonomy: user-agent, agent-tool, agent-execution, agent-agent, system-environment. Shows how compromise propagates across boundaries.
- **Implication for us**: Validates our boundary-centric security thinking. The five-boundary taxonomy is a useful reference frame. The key insight — prompt injection, tool misuse, and memory poisoning share structural cause (isolation loss) — confirms our unified threat model.

### [2607.12480] TRACE: An Operational Reasoning Schema for Auditable Agentic Commitments
- **Source**: https://arxiv.org/abs/2607.12480
- **Published**: 2026-07-14
- **Summary**: Defines TRACE (Typed Reasoning And Commitment Evidence): schema for recording reasoning traces with a discipline of "no durable state change without a record." Argues reasoning is not in the language model — chain-of-thought inherits autoregressive limits. Proposes record-consumer contract.
- **Implication for us**: The "no durable state change without a record" discipline is architecturally aligned with our trace-first approach. The typed record schema (TraceRecord with causal specialization) could inform our own trace format evolution. The explicit separation of "association vs. intervention vs. prescription" in traces is a useful precision upgrade.

## Synthesis: Emerging Themes (July 10–14 cohort)

1. **Memory as lifecycle, not storage**: MemOps + TRACE both frame memory as operations with typed state transitions, not passive fact stores.
2. **Budget displacement > interference**: RCWT shows coordination overhead hurts only through displacement, not semantic confusion — the fix is allocation, not reduction.
3. **Minimum-sufficient execution**: E3 shows 10x cost savings from estimating task difficulty before committing full context. Over-reading is the default failure mode.
4. **Safety evals need reconstructability**: Claims must travel with evidence of what they actually measured. Surface metrics hide heterogeneous evidence regimes.
5. **Isolation as unifying safety frame**: Five-boundary taxonomy organizes the scattered agent-safety literature into a coherent propagation model.
