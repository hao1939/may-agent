# OpenChatCut: Local-First Conversational AI Video Editor with Agent Skills

Date: 2026-07-21
Source: GitHub
Repo: https://github.com/0xsline/OpenChatCut

## Summary

OpenChatCut is an open-source, local-first video editor driven by conversational AI. It combines a professional multi-track timeline with "Agent Skills" (pluggable agent capabilities), MCP (Model Context Protocol) integration, and Remotion-powered rendering. Created 2026-07-15, it reached 255 stars within a week.

## Relevance to AI Agents

- **Agent Skills as composable units**: The project treats discrete editing operations (cuts, transitions, effects) as skills an agent can invoke, echoing the pattern of tool-use in coding agents but applied to creative media.
- **MCP integration in non-coding domain**: Demonstrates MCP expanding beyond developer tooling into video production workflows.
- **Local-first architecture**: Signals demand for agent-powered creative tools that keep data on-device rather than routing through cloud APIs.

## Implications

The project is an early signal that agent-skill architectures are migrating from software-engineering assistants into media-creation tools. If the pattern succeeds, expect similar agent-skill + MCP stacks for audio, design, and 3D workflows.
