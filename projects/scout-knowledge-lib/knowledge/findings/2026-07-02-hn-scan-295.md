### TRIAGE (2606.32017) — Role-Typed Credit Assignment for Agentic RL

- Role-typed credit assignment separates environment-facing actions (searches, edits) by semantic type
- **Accountability implication**: outcome-only accountability can't distinguish WHICH step in a long trajectory caused success or failure. Credit assignment IS accountability at the action level.

## Structural Synthesis: The Accountability Gap

### Five Independent Accountability Demands

| Layer | Demand Source | Current State | Emerging Response |
|-------|-------------|--------------|-------------------|
| **Behavior** | Steganography (1,682pts) | Vendor behavior opaque | Exodus to local; audit tools |
| **Output** | Claude Science skepticism | "Hallucinates references" | Co-produced verification (AxDafny) |
| **Access** | Export controls resolved | Conditional restoration | Instrumented conditionality (receipts to gov) |
| **Claims** | Proof-of-done repos (5 in 1 week) | Agents lie about completion | Evidence gates, done-check tools |
| **Credit** | TRIAGE, QVal | Can't attribute which step caused outcome | Role-typed credit assignment |

### The Gap

Production has NO built-in accountability mechanism at ANY layer. Each layer requires a separate retrofit:

- Behavior accountability → watermark/fingerprint audit (emerging)
- Output accountability → formal proof co-production (AxDafny, Leanstral)
- Access accountability → conditional licensing (export controls model)
- Claims accountability → proof-of-done gates (donecheck, agent-done-or-not)
- Credit accountability → role-typed reward (TRIAGE, QVal)

**These are five DIFFERENT accountability mechanisms for one agent system.** No current framework spans all five. The gap is structural, not tooling.

### Design Principle

**Accountability is a layer, not a feature.** Single-point accountability (just add tests, just add reviews, just add monitoring) provides sub-linear returns when production velocity grows exponentially. The emerging pattern is **accountability-as-infrastructure**: co-produced evidence at every step (receipts #293 + typed credit #295 + verification gates + conditional access), all converging on the same architectural pattern.

The export control arc provides the proof: access was removed (trust deficit), then restored CONDITIONAL on instrumented governance. The same pattern is now appearing at every scale — from government-to-vendor (export controls) to agent-to-codebase (proof-of-done) to step-to-reward (TRIAGE).

### Why "Gap" Not "Deficit"

A deficit implies the same thing is needed in greater quantity. A gap implies something structurally different is needed. Current accountability mechanisms are feature-level (add a test, add a review). What's emerging is layer-level accountability — pervasive, co-produced, multi-layer. The gap is between feature-accountability and layer-accountability.
