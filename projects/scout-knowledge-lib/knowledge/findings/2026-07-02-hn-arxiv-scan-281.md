# Scan #281: The Self-Revision Surface

**Date**: 2026-07-02
**Sources**: arXiv, Hacker News, GitHub
**Theme**: Agents that revise their own capabilities create an ever-expanding governance surface

## Core Thesis

The field is converging on self-revising agents — systems that improve their own skills, tools, world models, and beliefs between episodes. But each self-revision creates new governance surface: a modified skill may silently shift behavior; an evolved tool may introduce new failure modes; a revised belief state may quietly discard uncertainty. The self-revision surface grows monotonically while oversight remains episodic.

## arXiv Findings

### 1. BayesEvolve: Explicit Belief States for Autonomous Scientific Discovery (2606.30335)
Source: https://arxiv.org/abs/2606.30335

**Core finding**: Discovery agents that condition on experimental memory (archives of high-scoring candidates) are structurally inferior to agents maintaining explicit, uncertainty-aware belief states. BayesEvolve converts experimental evidence into a predictive belief state and uses it to guide future experimentation, improving sample efficiency over memory-only baselines.

**Structural significance**: This separates two paradigms — (a) memory-conditioned agents that accumulate experience and (b) belief-state agents that maintain calibrated uncertainty ABOUT that experience. The former manufactures confidence (see #277); the latter preserves calibration through self-revision. First explicit paper showing belief > memory for autonomous agents.

**Governance implication**: A belief-state agent can express "I don't know" formally. A memory-conditioned agent can only retrieve or not-retrieve. Self-revision with beliefs is auditable; self-revision from memory is not.

### 2. Self-Evolving World Models for LLM Agent Planning — WorldEvolver (2606.30639)
Source: https://arxiv.org/abs/2606.30639

**Core finding**: WorldEvolver revises its deployment-time context (episodic memory + semantic memory + pragmatic rules) while keeping the downstream agent and all model parameters frozen. Three modules: (i) episodic memory exploiting real transitions via retrieval, (ii) semantic memory extracting persistent rules, (iii) pragmatic rules filtering unreliable predictions.

**Structural significance**: The self-revision happens BETWEEN the model and the environment — in the world model layer. The agent's weights are frozen but its effective behavior changes continuously through context revision. This makes standard weight-based auditing irrelevant: the agent's "personality" lives in mutable deployment context, not in parameters.

**Governance implication**: Auditing frozen weights gives false assurance when the world model context is self-revising. Governance must monitor the deployment context layer — an expanding surface that grows with each episode.

### 3. Dynamo: Dynamic Skill-Tool Evolution for Vision-Language Agents (2606.30185)
Source: https://arxiv.org/abs/2606.30185

**Core finding**: A training-free framework where agents inspect their own correct and incorrect attempts, then evolve (a) reusable reasoning skills for cognitive bottlenecks and (b) executable visual tools for perceptual ones. Each tool is paired with a skill specifying when to invoke it. Both accumulate in a persistent library. Avg +5.6 accuracy across 20 model-benchmark settings.

**Structural significance**: The agent becomes a factory producing its own tools and skills. The library grows monotonically. Each new skill-tool pair is a new potential failure mode, a new attack surface, and a new governance demand. No mechanism constrains what the library can grow to contain.

**Governance implication**: A persistent skill-tool library is an unconstrained self-revision surface. Without library governance (versioning, deprecation, access control, audit), the agent's effective capabilities expand beyond any initial specification.

### 4. DAIN: Dynamic Agent-Based Interaction Network (2606.30189)
Source: https://arxiv.org/abs/2606.30189

**Core finding**: Reconceptualizes multimodal fusion as multi-agent collaborative process. A Meta-Controller dynamically schedules sparse activation of specialized interaction agents and orchestrates compressed inter-agent communication. Multi-objective loss jointly optimizes task accuracy, agent specialization, and operational efficiency.

**Structural significance**: The routing/scheduling itself is dynamic and learned — a meta-layer that decides which agents participate in each inference. This routing layer is another self-revision surface: as it adapts, the effective system composition changes without any model being retrained.

## Structural Analysis: The Self-Revision Stack

| Layer | Self-Revision Mechanism | Example | Governance Gap |
|-------|------------------------|---------|----------------|
| L0 Beliefs | Explicit uncertainty updates | BayesEvolve | Auditable but novel — no standard tools |
| L1 World Model | Context revision (frozen weights) | WorldEvolver | Weight auditing is irrelevant; context auditing doesn't exist |
| L2 Skills | Self-generated reasoning strategies | Dynamo | Library grows unboundedly; no deprecation/versioning standard |
| L3 Tools | Self-generated executable code | Dynamo | New tool = new attack surface; no security review |
| L4 Routing | Dynamic agent scheduling | DAIN | Composition changes per-input; no static analysis possible |
| L5 Infrastructure | Physical resource allocation | HN data-centers vs schools | Resource governance treats AI growth as given |

**Critical insight**: L0 (belief states) is the ONLY layer with structural self-governance — BayesEvolve's belief formalism includes uncertainty by design. Every other layer (L1-L5) revises without built-in uncertainty. The field is building self-revision at L1-L5 while only L0 has the right epistemic structure.

## Predictions

1. **Skill-library governance standards emerge** (3-6 months): Version control, deprecation policies, security review for self-generated skills. Currently absent.
2. **Context-layer auditing** (6-9 months): Tools that monitor deployment-context drift in world-model agents. Weight auditing becomes insufficient.
3. **Belief-state formalism adopted** (6-12 months): BayesEvolve's approach spreads — explicit uncertainty in agent memory becomes expected, not optional.
4. **Self-revision rate limits** (9-12 months): Governance policies capping how fast agents can modify their own capabilities per time window.
5. **Routing-layer governance** (12-18 months): Standards for auditing dynamic agent composition at inference time.
