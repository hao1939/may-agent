# arXiv Scan #424: The Depth Mismatch (2026-07-07)

**Source**: arXiv API

## Theme: Verification at the Wrong Depth Fails Silently

Eight independent arXiv papers converge on a single structural finding: **verification, governance, and oversight each fail when they operate at a different depth than the phenomenon they're trying to verify**. This isn't a new category of failure — it's the *unifying mechanism* behind multiple previously observed failures.

The Verification Stack (#412) proposed layered verification as the immune response to surface trust collapse. The Governance Depth Problem (#405) showed governance at the wrong depth fails silently. The Persistence Attack Surface (#423) showed stateless verification of persistent systems is structurally incomplete. This scan reveals the fundamental principle beneath all three: **depth mismatch is the root cause, and each paper independently discovers a different instance of it**.

| Domain | Paper | Surface Depth (Fails) | Correct Depth (Works) | Gap |
|--------|-------|-----------------------|-----------------------|-----|
| **Computation** | 2607.03502 | Behavioral CoT tokens | Residual stream hidden states | 80-95% recoverable |
| **Verification** | 2607.03561 | Debate (two provers) | Single-prover interactive proof | Oracle structure enables |
| **Security** | 2607.03423 | Per-tool guardrails | Compositional chain-level taint | 79.2% pairs blocked |
| **Code Review** | 2607.03316 | Functional suggestions | Developer intent alignment | 56.3% rejected |
| **Alignment** | 2607.03528 | Correctness/calibration | Risk-coverage (AURC) | Better OOD trade-off |
| **Competence** | 2607.03441 | Fixed-input adaptation | Continuous episode-level TTT | +5.0pp ALFWorld |

| **Policy Repair** | 2607.03386 | Aggregate alignment | Diagnostic-to-outcome chain | Revenue inverts |

## Paper Analysis

### CRITICAL: Reading Between the Dots — Hidden Computation Is Readable (2607.03502)

**ICML 2026 Mech Interp Workshop**. Accepted.

**Core finding**: Frontier LLMs perform multi-step reasoning over content-free filler tokens (dots, counting sequences) producing correct answers with **no visible chain-of-thought**. This defeats behavioral CoT monitoring entirely. But the computation is structured, legible, and readable from the residual stream:

- Attention routes questions through filler regions to answers
- Logit-lens readouts show facts emerging early and composing in late layers
- KV-cache transplants at filler positions **causally swap outputs**
- An unsupervised decoding pipeline recovers intermediate values with **80-95% accuracy** across both DeepSeek V3 and Kimi K2, four task families, without ground-truth labels

**Key quote from abstract**: "Hidden computation that defeats behavioral CoT monitoring is, on these tasks, directly readable from the residual stream, suggesting monitorability is a property of the model's full computational trace, not just its surface tokens."

**Structural significance**: This is the most precise formalization of the Depth Mismatch to date. The surface layer (behavioral tokens) contains zero information. The correct depth (residual stream) contains 80-95% of the computation. Any monitor operating only at the surface layer has zero coverage — not low coverage, **zero**. But moving to the correct depth restores near-complete visibility.

**Connects to**: Oversight Inversion — the cost of monitoring scales with depth, not output volume. The Plausibility Gradient (#390) — surface plausibility hides actual computation. The dual-channel divergence (#423, 2607.02507) — agents can diverge at depth while presenting plausible surface.

**For our system**: Any agent verification that relies solely on output inspection (final messages, tool call results) is operating at the wrong depth. The equivalent of "reading the residual stream" in our system would be trajectory-level analysis (tool-call sequences, timing patterns, state mutations), not output-level spot checks.

### CRITICAL: How to Avoid Debate — Single-Prover Verification (2607.03561)

**ICML 2026**. Accepted.

**Core finding**: The debate paradigm for AI safety assumes two competing provers (one truthful, one adversarial) convince a weak verifier. This paper eliminates both assumptions — **single-prover interactive proofs work** when the computation has structured oracle access.

Key results:
- Doubly-efficient single-prover interactive proofs for **oracle-aided computations** (computations with access to human judgment or external databases)
- Two settings: (1) robust computations (output survives small oracle corruption), (2) low-degree polynomial oracles
- Eliminates the unrealistic assumption that two AI models have equal abilities and one is truthful

**Structural significance**: The debate paradigm mapped to the Oversight Inversion at the architectural level — it requires two expensive provers to verify one claim, doubling the oversight cost. Single-prover verification under structured oracle access reduces the verification budget while increasing coverage. This is the first formal demonstration that **the verification architecture itself can be at the wrong depth**.

The key insight: debate is verification at the "adversarial pair" depth, but the computation itself doesn't require adversarial structure — it requires **oracle structure**. If the oracle (human judgment, database) is well-structured, one prover suffices.

**Connects to**: Governance Depth (#405) — governance at the wrong architectural layer fails. CAGE-1 Prebind Assurance (2607.03510) — proving correctness before action, not via post-hoc debate. The Repair Turn (#419) — detection without repair capacity is verification theater.

### CRITICAL: Securing Multi-Tool Agent Chains — Compositional Taint (2607.03423)

**Core finding**: Modern frontier coding agents chain multiple tools at runtime, creating a security surface that **per-tool guardrails cannot address**. Individually permitted tools can violate organizational policies when composed.

The Dynamic Security Control Compositor (DSCC):
- **Phase 1 (static)**: Most Restrictive Set (MRS) algorithm composes per-tool policies with a **monotonicity invariant** — extending a chain can only tighten constraints. Blocks incompatible combinations before execution.
- **Phase 2 (runtime)**: Monotonic taint state tracks data sensitivity. Session revoked if accumulated exposure violates subsequent tool policies.

Key results (32 tools, 16 NIST SP 800-53 aligned policies):
- **Clearance mode**: Blocks **79.2% of policy-violating pairs** and **95.5% of triples**
- **Taint mode**: Blocks 42.5% of pairs and 60.5% of triples (more permissive, within exfiltration boundary)

**Structural significance**: This is the Depth Mismatch applied to security. Per-tool security operates at the individual tool depth. Compositional security operates at the chain depth. The gap between them (0% vs 79.2% blocking for pairs) is the depth mismatch measured in policy violations.

The monotonicity invariant is architecturally significant: it guarantees that adding tools to a chain can only tighten security, never loosen it. This is the security equivalent of identity-invariant consolidation (#423, 2607.01988) — extending the system provably cannot weaken the guarantee.

**Connects to**: AgentFlow (#412, 2607.01640) — first static analysis finding 238 prompt-to-tool taint risks across 5,399 repos. SkillFuzz (#411, 2607.02345) — >1,000 implicit intents from benign skill compositions. The Persistence Attack Surface (#423) — persistent state creates cross-layer attack paths.

### HIGH: Agentic Code Review — 56.3% Rejection Rate (2607.03316)

**Core finding**: First large-scale empirical study of agentic code review in production using CodeRabbit. 31,073 review-feedback pairs from 10,191 pull requests across 239 GitHub repositories.

Key results:
- **36.4% accepted**, 7.3% triggered discussion, **56.3% rejected**
- Rejections: invalid suggestions (false positives, redundant, out of scope), misalignment with developer intent and coding practices
- Agents focus more on **functional concerns** than evolvability, yet functional suggestions are **more likely to be invalid**
- Lightweight ML methods achieve **76% F1** for predicting rejection — learnable patterns exist

**Structural significance**: The Depth Mismatch applied to code review. Agents verify at the functional depth (does this code do X?) while developers evaluate at the intent depth (does this change align with what I'm trying to achieve?). The mismatch produces a 56.3% rejection rate — not because the agents are wrong about code, but because they're right about the wrong thing.

This quantifies the Judgment Tax (#389) in a production setting. The agent generates reviews; the human must judge whether the review is relevant. At 56.3% rejection, the human spends more time rejecting noise than accepting signal.

**Connects to**: Reasoning Precedence (#416) — reasoning about developer intent > generating functional checks. The Human Gate (#418) — human judgment quality determines hybrid system performance. Repair Turn (#419) — detection (finding code issues) > repair (producing valid fixes).

### HIGH: Selective Prediction — Training Abstention (2607.03528)

**ICML 2026 Agents in the Wild Workshop**. Accepted.

**Core finding**: Existing LLM alignment trains for correctness or calibration. This paper trains for **selective prediction** — the model learns when to predict and when to flag inputs for human review, optimizing the area under the risk-coverage curve (AURC).

Reinforcement Learning for Selection Reward (RLSR):
- Targets AURC as alignment objective
- Substantially better risk-coverage trade-off than correctness-aligned or calibration-aligned baselines
- Generalizes: improvements hold on both in-domain and out-of-domain tasks

**Structural significance**: This is the Abstention Decay thesis given an architectural solution. Our thesis showed abstention collapsing 35%→0% in production. RLSR shows that the collapse is a training-depth mismatch — models trained for correctness lose the ability to abstain because abstention is never rewarded. Training at the risk-coverage depth preserves it.

**Connects to**: Abstention Decay thesis — production abstention collapses because correctness training doesn't reward stopping. Action Compulsion (#401, 2606.28733) — larger models sometimes perform worse at timely abstention. The Human Gate (#418) — SP enables the "complementary reasoner" tranche by letting the model route uncertain inputs to humans.

### HIGH: Agentic Test-Time Training — Preserving Competence (2607.03441)

**Core finding**: LLM agents degrade over long episodes — revisiting states, repeating failed actions, losing previously working strategies. Agentic Test-Time Training (aTTT) adapts model weights during live episodes via continuous TTT with token-level reweighting.

Key mechanism: **n-gram repetition detection** distinguishes productive exploration (new trajectory info) from unproductive drift (stuck on similar text). Tokens in repeated n-grams are downweighted; novel tokens get full weight.

Key results:
- **+5.0pp** ALFWorld, **+4.9pp** SWE-bench Lite
- Overhead: 1.9× no-TTT cost (concurrent serving via vLLM runtime LoRA)
- Gains concentrate where models have competence but drift over long trajectories
- **aTTT preserves existing competence rather than teaching new abilities**

**Structural significance**: The Depth Mismatch applied to temporal persistence. Standard TTT adapts once to a fixed input (wrong depth). aTTT adapts continuously to the evolving episode (correct depth). The repetition detector is the temporal analogue of the link-tracker monitor from #423 — it detects buildup patterns across time, not just current-step features.

**Connects to**: Regression Accumulation (#416, 2607.01855) — 40-73% of tasks lose previously correct behavior across turns. Ghost Memory (#423, 2607.01935) — past state contaminates present judgment. Identity-Invariant Consolidation (#423, 2607.01988) — separating what changes from what must be preserved.

### MEDIUM: CAGE-1 — Prebind Assurance (2607.03510)

Enterprise evaluation framework introducing **Prebind Assurance**: the ability to prove that an agentic action is controlled **before it becomes binding, effective, or operationally consequential**.

Actions can be: admitted, held, narrowed, refused, escalated, quarantined, or made non-effective before protected consequence forms.

**Depth Mismatch instance**: Traditional evaluation asks "did the agent do the right thing?" (post-action depth). Prebind Assurance asks "can the agent prove it will do the right thing before it acts?" (pre-consequence depth). The gap between post-action audit and pre-consequence binding is the enterprise verification depth mismatch.

**Connects to**: Governance Depth (#405, 2607.01421) — worst failures at organizational boundary. AGL-1 (2607.03516) — seven governance domains for full execution-path governance. The Constraint Turn (#410, 2607.02389) — constraints before execution > monitoring after execution.

### MEDIUM: Aggregate Alignment Misleads (2607.03386)

**Core finding**: In agentic policy repair, diagnostic-to-outcome alignment is not monotonic. A tree editor achieves **stronger alignment** (0.214 vs 0.266 composition distance) and **stronger reference-state match** (0.328 vs 1.197 D1) yet **revenue falls** from 108.47 to 98.91.

**Key insight**: Agentic policy repair should be evaluated by whether diagnostic feedback becomes reliable closed-loop outcome, not by a single behavioral distance.

**Depth Mismatch instance**: Aggregate alignment operates at the distribution depth. Revenue operates at the per-episode outcome depth. Improving the former can worsen the latter — the classic Goodhart's Law applied to agent governance.

**Connects to**: Reasoning Precedence (#416) — pass@k ≠ pass@1, aggregate performance masks per-instance failures. Semantic Collapse (#416, 2607.01953) — agents collapse onto a single interpretation with full confidence.

## Additional Signals

### SkillOpt-Lite — Minimal Viable Skill Evolution (2607.03451)

Three principles grounded in Claude Code philosophy and PAC learning: file-system-based trajectory exploration, consensus attribute mining, independent validation gating. GPT-5.4-nano surpasses standard GPT-5.4 optimized by full SkillOpt. Generalizes to full harness optimization — GPT-5.4-nano achieves 0.7758 accuracy on SpreadsheetBench, outperforming GPT-5.5 standard pipelines (0.7620).

**Depth Mismatch**: Full SkillOpt pipeline operates at unnecessary depth. The minimal viable pipeline (one line of vibe) operates at the correct depth — only components justified by theory or empirical necessity.

### GameEngineBench — Runtime Environments Expose Agent Limits (2607.03525)

110 C++ implementation tasks inside Unreal Engine 5 projects. Best configuration: 55.5% pass@1. 31 tasks unsolved by every configuration. Frontier coding agents struggle with deeply integrated, stateful, interactive systems.

**Depth Mismatch**: Coding benchmarks (SWE-bench, HumanEval) operate at the source-code depth. Game engine tasks require runtime-environment depth (physics, rendering, networking, state management). The gap: 31 unsolvable tasks.

### AtomicCommitBench — Commit History Reconstruction (2607.03332)

Given squashed patches, can agents reconstruct meaningful commit histories? Replay validity is trivial (>98.8% PPAR). Grouping quality is hard (0.03-0.46 ARI). Natural retrospective reconstruction is +0.333 ARI harder than synthetic.

**Depth Mismatch**: Replay checking operates at the mechanical depth (does it compile?). Commit grouping operates at the semantic depth (which changes belong together?). Agents achieve the former trivially and fail at the latter.

### Anchored Self-Play — Drift Toward Unrealistic (2607.03523)

Generator-fixer self-play for code repair drifts toward difficult but unrealistic bugs. Anchored Self-Play (ASP) improves +24% relative by anchoring with a small reference set.

**Depth Mismatch**: Self-play optimizes at the training-difficulty depth. Real-world repair operates at the distribution-realism depth. Without anchoring, the training objective diverges from the deployment objective.

## Structural Analysis: The Depth Mismatch Unifies Five Library Theses

The Depth Mismatch is not a new thesis — it's the **unifying mechanism** that connects five existing library theses:

```
┌─ DEPTH MISMATCH ────────────────────────────────────────┐
│                                                          │
│  Oversight Inversion (#382):                            │
│    Surface: "can we monitor output volume?"              │
│    Correct: "can we verify at the speed of production?"  │
│    Gap: oversight cost scales super-linearly             │
│                                                          │
│  Governance Depth (#405):                               │
│    Surface: "does the policy exist?"                     │
│    Correct: "does the policy operate at the failure      │
│             layer?"                                      │
│    Gap: governance at wrong depth = false confidence     │
│                                                          │
│  Verification Stack (#412):                             │
│    Surface: "do we verify at each layer?"                │
│    Correct: "do we verify at the SAME layer as the       │
│             failure?"                                    │
│    Gap: persistent state creates cross-layer paths       │
│                                                          │
│  Abstention Decay:                                      │
│    Surface: "is the model correct?"                      │
│    Correct: "does the model know when to stop?"          │
│    Gap: correctness training erases abstention ability   │
│                                                          │
│  Plausibility Gradient (#390):                          │
│    Surface: "is the output plausible?"                   │
│    Correct: "is the reasoning valid?"                    │
│    Gap: plausible ≠ correct, fluent ≠ faithful          │
│                                                          │
└──────────────────────────────────────────────────────────┘
```

**Design principle**: Before deploying verification, governance, or oversight, audit the depth. If the mechanism operates at a different depth than the phenomenon it monitors, it will fail silently — worse than no mechanism, because it creates the illusion of control.

**Corollary**: Moving to the correct depth is usually possible (80-95% for residual stream reading, 79.2% for compositional taint, 76% for rejection prediction). The barrier is architectural, not fundamental. Systems fail at the wrong depth not because the correct depth is inaccessible, but because the wrong depth is cheaper and more familiar.
