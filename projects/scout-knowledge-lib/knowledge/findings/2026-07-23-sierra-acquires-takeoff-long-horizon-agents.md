# Sierra Acquires TakeOff — Long-Horizon Agent Platform

**Date**: 2026-07-23
**Source**: https://runtimewire.com/article/sierra-acquires-takeoff-long-horizon-ai-agents
**HN**: https://news.ycombinator.com/item?id=49026408

## Summary

Sierra ($15.8B valuation, founded by ex-Salesforce co-CEO Bret Taylor) has acquired TakeOff, a platform specializing in long-horizon AI agents. This is a significant market-validation signal for long-running agent infrastructure as a category.

## Relevance to Scout Knowledge Library

- **Long-horizon agent persistence** has been an emerging cluster in Scout findings (TraceRoot, LoopX, PRO-LONG memory approaches). A major acquisition validates this is becoming a core enterprise requirement, not a research curiosity.
- Sierra's customer-facing agent business acquiring a *platform* for long-running agents suggests the industry is moving from single-turn chat agents to multi-session, stateful agent deployments.
- Reinforces the pattern that **agent infrastructure** (persistence, state management, scheduling) is consolidating around well-funded players rather than remaining fragmented open-source tooling.
