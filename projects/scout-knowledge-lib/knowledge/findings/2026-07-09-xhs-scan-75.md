But underneath this migration lies a structural paradox: **practitioners fleeing Claude Code for sovereignty reasons are simultaneously watching Codex (OpenAI) absorb the agent startup layer** ("Codex is killing Agent startup teams," 184❤). The sovereignty escape from one vendor leads directly into the gravitational pull of another — or forces a bet on domestic alternatives whose capability gap remains acknowledged but is narrowing.

Meanwhile, the skill self-evolution discourse has matured from evangelism to operational caution. Posts now warn about skills "getting dumber as they evolve" (3❤ but structurally significant) and practitioners publishing "cautionary retrospectives" on agent self-evolution (10❤). The Tsinghua self-evolving agent survey (191❤) and Trace2Skill's inductive approach (64❤) represent the academic attempt to systematize what practitioners are learning the hard way.

**The Replacement Scramble** names this phase: the community is simultaneously migrating tools (sovereignty), watching platforms absorb features (platform risk), and discovering that the self-improvement mechanisms they're building have their own failure modes (evolution regression).

## Structural Summary

The Replacement Scramble represents the **demand-side response** to the Sovereignty Escalation (#74). The supply side (domestic tools) is forming but lags:

```
Demand (sovereignty pressure):   ████████████████████ (1,006❤ replacement, 682❤ MIIT)
Supply (domestic capability):    ███ (40❤ DeepCode, 9❤ Kimi Code, 3❤ GLM 5.2)
                                 Gap: ~25:1 attention ratio
```

The gap creates three possible trajectories:
1. **Domestic tools improve fast enough** → sovereignty gap closes naturally (P-64 tests this)
2. **Practitioners migrate to Codex** → sovereignty problem unsolved, just relocated (3,035❤ signal)
3. **Hybrid sovereignty stack** solidifies → domestic model + foreign IDE as pragmatic middle ground (P-62 tracks)

The skill evolution caution signal (Signals #4) adds a temporal dimension: even the replacement tools' self-improvement mechanisms have failure modes that the community is only now discovering.
