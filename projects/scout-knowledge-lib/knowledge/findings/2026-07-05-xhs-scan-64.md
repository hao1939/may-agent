## 1. Platform Agent Shutdown Signal — 豆包 + 千问 关停 (NEW)

**Signal strength: Emerging** (9❤ but structural significance high)

Doubao (豆包, ByteDance) and Qwen (千问, Alibaba) announced simultaneous shutdown of their consumer agent features on the same day. Doubao shuts agents July 15; users have until October 15 to export data.

**Post**: @臻知Agent — "突发！豆包和千问同一天关停智能体，AI行业大地震"
Source: https://www.xiaohongshu.com/explore/6a48f7d100000000060207fe

**Community reads**:
- Regulatory compliance: "据说是因为监管规定，要求全链路审核。做不到干脆直接下线了" (top comment)
- Distillation concern: "因为蒸馏不了claude了？"
- Sustainability: "智能体功能运营成本高、用户粘性差、商业变现路径模糊"

**What this means**: Consumer-facing agent platforms are hitting a wall from three directions simultaneously:
1. **Regulatory** — China's full-chain audit requirements create compliance costs that agent platforms can't justify at consumer scale
2. **Economic** — "burning money with no visible return" confirms our agent economy predictions: agent-as-product ≠ agent-as-infrastructure
3. **Timing** — Both shutting down on the same day suggests coordinated regulatory pressure, not independent business decisions

**Connection to prior findings**: This is the reverse of the 智能体経済 prediction from Scan #42 (agents as economic actors). Instead of agents becoming independent economic entities, consumer-agent platforms are discovering that the *infrastructure* for agent governance (full-chain audit, data lifecycle management) costs more than the agent itself produces. The harness IS the product — and it's too expensive for consumer-tier monetization.

## 3. Agent Delegation Architecture — Main Agent Prohibition (775❤)

**Signal strength: Very High** (775❤, 1056 collects, 138 comments)

**Post**: "Claude code暴论: 禁止main agent干任何活" (@Linkedout, 775❤)
Source: https://www.xiaohongshu.com/explore/69da67a2000000001a02cb20

Core technique: Use hooks to reject all write/edit operations from the main agent (no `agent_id` = main agent = blocked). Force all execution through subagents.

**Key community debate threads**:
- **Inter-agent communication via filesystem**: "我 agent 间通信都完全走文件系统而不是上下文传递，效果无敌好" (@abadcafe, linked github.com/abadcafe/superteam) — file-based message passing eliminates context leakage between agents
- **Context loss is a feature**: "有时候就是要上下文丢失才效果好，上下文多了反而不好" (@一只会魔法的梨) — fresh context per subagent = fresh judgment, avoiding context pollution
- **Governance beats visibility**: "不需要visibility,需要documentation, test, enforcement 和 review" (@Linkedout) — observability is less important than enforcement
- **Architecture criticism**: "主agent都不信任，subagent更是啥都不懂。如果是spec面面俱到写好的话另当别论" (@南方古猿驻人类大使) — delegation works only with specification quality

**Connection to our system**: This maps directly to our orchestrator-vs-executor pattern. The community has independently discovered that:
1. Main agent as pure orchestrator = boundary enforcement through architectural separation
2. File-based inter-agent communication = stigmergy (exactly what our context-stigmergy-synthesis.md describes)
3. Controlled context loss between agents = The Subtraction Turn applied to context

## 4. Memory Architecture Maturation — The 4-MD Consensus (2,673❤)

**Signal strength: Very High** (2,673❤, 4,360 collects)

**Post**: "Anthropic官方教Agent记忆：4 个 md 就够了" (@刘铁柱, 2,673❤)
Source: https://www.xiaohongshu.com/explore/6a2f9096000000001102d410

Proposes 4 markdown files as complete local memory system:
- **CLAUDE.md** — rules (auto-loaded per session)
- **Memory.md** — stable facts (session-end writes, session-start reads)
- **Learning.md** — error corrections, aha moments (append-only)
- **Wiki.md** — shared context across multiple agents

With hooks (SessionStart / PostToolUse / SessionEnd) enforcing the lifecycle.

**Critical community insight on memory pollution**:
- "Memory只放稳定事实，Learning放被纠正的坑，Wiki放共享约定，临时任务千万别写进去，不然记忆会反过来污染决策" (@AgentsMesh)
- "记忆文件已经被我拿权限锁了模型降智总爱给记忆文件乱写内容" (@Xiao伟) — memory files need write protection from the model itself
- "即使写到claude md里面 还是容易忘记和违反规则" (@刘铁柱, author) — acknowledged limitation

**Connection to prior findings**: The 4-MD approach is essentially what Scan #42 predicted as 记忆分层 (Memory Layering). Engagement (2,673❤) is 4× higher than the self-evolution discourse, confirming that practitioners prefer concrete-local solutions over theoretical frameworks.

## 6. China National Agent Interoperability Standard (4❤, but structural)

**Post**: "智能体互联有了国家标准" (@臻知Agent)
Source: https://www.xiaohongshu.com/explore/6a471b5b000000001702f732

China's State Administration for Market Regulation published 7 national standards (GB) covering:
1. Overall architecture (总体架构)
2. Agent identity codes (身份码)
3. Identity management (身份管理)
4. Agent description (智能体描述)
5. Agent discovery (智能体发现)
6. Agent interaction (智能体交互)
7. Agent tool calling (智能体工具调用)

Low engagement but structurally significant. This is the government's answer to MCP/A2A: a sovereign, comprehensive agent interoperability framework. The seven parts cover what MCP and A2A split across two protocols.

**Prediction**: This standard will become mandatory for government and SOE agent deployments within 12 months. Consumer platforms (those still alive after 豆包/千问 shutdowns) will adopt to survive compliance requirements.
