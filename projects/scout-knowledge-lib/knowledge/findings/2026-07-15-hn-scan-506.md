## Emerging Thesis: The Memory Attack Surface

Three stories on this page converge on a single theme: **agent persistent memory is becoming the primary attack surface**.

1. The Claude memory heist demonstrates extraction attacks
2. The Cursor 0day shows agent-IDE integration vulnerabilities  
3. The Guardian Angel pattern proposes personalization as defense

This suggests a new synthesis: the agent security frontier has shifted from "prompt injection" (manipulating what the agent *does*) to "memory exfiltration" (extracting what the agent *knows*). The attack model is evolving from manipulation to espionage.
