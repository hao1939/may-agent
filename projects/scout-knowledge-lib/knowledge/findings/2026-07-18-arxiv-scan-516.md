## Tier 1 — High-relevance papers

### 2607.15263: Beyond Success Rate: Cost-Aware Evaluation of Offensive and Defensive Security Agents
- Evaluates security agents through a **cost-success lens** on offensive (Cybench CTF) and defensive (Splunk BOTS v1) tasks
- Key finding: offensive CTF performance scales with test-time compute; **defensive SOC investigation does not** — it depends on disciplined tool use and selective enrichment
- Scaled open-weight models approach frontier proprietary systems on offense while remaining cost-competitive
- **Pattern**: Cost-aware evaluation reveals fundamentally different scaling regimes for red vs blue team agents
- **Library connection**: Extends `agent-evaluation-research.md`, `agent-security-defense-architectures.md`, `the-token-economics-trap.md`

### 2607.15257: SearchOS-V1 — System-Level Multi-Agent Search Framework
- Externalizes implicit search progress into **persistent shared state**: Frontier Task, Evidence Graph, Coverage Map, Failure Memory
- Pipeline-parallel scheduling overlaps sub-agent execution and continuously refills slots targeting coverage gaps
- **Search Tool Middleware Harness** intercepts model-tool interactions to record evidence and react to stalls
- Hierarchical skill system (strategy + access skills) prevents repeating failed search patterns
- **Pattern**: State externalization + middleware harness for multi-agent search — production-grade coordination
- **Library connection**: Extends `multi-agent-coordination.md`, `agent-runtime-hardening.md`

### 2607.15053: ANet Patu-1 — The Value of Connection in the Agent Network
- Models net value of agent connection as function of coordination-group size across Sarnoff/Metcalfe/Reed regimes
- **Emergence result**: crowd of cheapest heterogeneous model overtakes crowd of stronger homogeneous model as N grows — "scaling law for collaboration not scale"
- **Reflexivity result**: heterogeneous network, given only its own problem, converges on ANet Patu-1 protocol itself
- Self-organizing consensus protocol with O(1) parallel rounds
- **Pattern**: Heterogeneity-beats-capability in multi-agent networks; collaboration scaling law
- **Library connection**: Extends `multi-agent-coordination.md`, `the-competence-inversion.md`

### 2607.15218: PRISM — Physical Safety Probing via Hidden-State Analysis
- Content danger (CD) and physical danger (PD) form **separable signals** in LLM representations
- PRISM probe: 86-88% accuracy, 12-14% FPR on SafeAgentBench vs LLM judges at 25-39% FPR
- On contrastive PhysicalSafetyBench-1K: 99.6% accuracy, 0.7% FPR
- **Pattern**: Representation-level safety probing beats prompt-level moderation for embodied agents
- **Library connection**: Extends `agent-security-defense-architectures.md`, `the-guard-paradox.md`

## Tier 2 — Notable papers

### 2607.14989: OmniaBench — Benchmarking General Agents Across Diverse Scenarios
- 1,431 tasks across 90 L1 / 354 L2 domains (ToC, ToB, ToE); 10-dimension capability taxonomy + 8 difficulty factors
- Even Claude-Sonnet-5 and GPT-5.6-Sol only achieve 58.5% and 57.1% Pass@1
- Persistent limitations: planning, constraint maintenance, adaptive correction
- **Library connection**: `agent-evaluation-research.md`

### 2607.15193: Plover — Plan-Centric GUI Agent Interaction
- Externalizes task plans as persistent, inspectable, revisable artifacts
- Users can inspect, supervise, correct via natural language + screenshot-grounded interventions
- Many autonomous GUI-agent failures are structurally repairable when plans remain visible
- **Pattern**: Plan externalization enables human-in-the-loop repair for GUI agents
- **Library connection**: `agent-architectures.md`, `the-oversight-inversion.md`

### 2607.15095: Digital Pantheon — Coalition Formation with LLM Agents
- Multi-agent framework combining SFT + DPO + RAG for partisan political simulation
- Multi-Layered Information Lineage Topology (MILT) traces agreement clauses to manifesto origin
- **Pattern**: Provenance tracing in multi-agent negotiation outputs
- **Library connection**: `multi-agent-coordination.md`

### 2607.14896: StructureClaw — Artifact-Centered Agent Evaluation for Engineering
- LLM agents operate through governed engineering skills, typed tools, shared artifact state
- Scenario succeeds only when all artifact- and execution-level assertions pass
- Average success rate: 56.8% baseline → 88.6% with full workflow
- **Pattern**: Artifact-centered evaluation exposes workflow-level failures invisible in final responses
- **Library connection**: `agent-evaluation-research.md`

### 2607.14658: TopoAgent — Self-Evolving Topological Agent for Scientific Reasoning
- Replaces linear trajectories with dynamic DAG evolution + state isolation
- Adaptive atomic fission splits bottleneck nodes at runtime
- Outperforms linear agent frameworks on math/physics/chemistry benchmarks
- **Pattern**: DAG-based reasoning with runtime fission beats linear chain-of-thought
- **Library connection**: `agent-architectures.md`

### 2607.14574: Collaborative Spatial Learning with Multi-LLM Agents
- Replicates Mason-Watts experiment with 16 LLM agents on 8 network topologies
- Network-efficiency effect only appears when agents randomize first-round choices
- Single instruction sentence improves collective payoff by 3x the topology effect
- **Pattern**: Instruction sensitivity dominates network topology in LLM agent collectives
- **Library connection**: `multi-agent-coordination.md`
