多智能体系统（MAS）虽然比单模型强，但失败率高到离谱（UCB发现：MetaGPT等框架失败率可达86%🤯）。问题在于：到底是谁、在哪一步搞砸了？现有大模型（GPT-4.1、DeepSeek-R1等）诊断准确率都在10%以下。于是作者提出 AgenTracer，专门给MAS做失败归因与纠错。AgenTracer能自动定位MAS失败的“罪魁祸首”，并通过RL训练的小模型帮助MetaGPT、MaAS等系统性能提升4.8%～14.2%。
	
📌 我的Takeaway notes（粗读）
	
1️⃣ Motivation：MAS会出错，为什么呢？
- 任务拆分错 → 后续全崩
- Agent角色不服从 → 步调混乱
- 工具/数据库错误 → 累积放大
- 错误往往发生在早期，最后才显现
	
2️⃣ 方法
- Counterfactual replay：替换某一步为“oracle动作”，看能否修正 → 找到关键错误
- Fault injection：在成功轨迹里故意制造bug → 合成失败数据
- 最终得到 TracerTraj-2.5K 数据集
	
3️⃣ 训练过程
- Qwen3-8B+GRPO强化学习
- 奖励设计：Format reward；Agent reward（找到错误的Agent）；Step reward（找到具体错误步骤，越接近奖励越高）
	
4️⃣ 实验结果
- 在Who&When基准上，AgenTracer比Gemini-2.5-Pro、Claude-Sonnet-4高最多18%
- 部署在MetaGPT、MaAS等系统上，性能提升4.8%～14.2%
	
5️⃣ 槽点
- 数据集规模（2.5K）还偏小，未来能否覆盖更多任务未知
- 应用主要在代码/数学/推理，通用性有待验证
- 本质还是一个verifier，不是直接提升模型推理能力，整个链路很长，略复杂，可能引入新的问题，更难debug

# 🔍AGENTRACER: WHO IS INDUCING FAILURE IN THE LLM AGENTIC SYSTEMS?

Guibin Zhang 🔍†, Junhao Wang 🍁†, Junjie Chen🔍†, Wangchunshu Zhou🔺, Kun Wang 🐢✉, Shuicheng Yan🔍✉
🔍NUS  🍁CUHK  🔺OPPO  🐢NTU
✉ Main Contact: `guibinz@outlook.com`

## Abstract

Large Language Model (LLM)-based agentic systems, often comprising multiple models, complex tool invocations, and orchestration protocols, substantially outperform monolithic agents. Yet this very sophistication amplifies their fragility, making them more prone to system failure. Pinpointing the specific agent or step responsible for an error within long execution traces defines the task of **agentic system failure attribution**. Current state-of-the-art reasoning LLMs, however, remain strikingly inadequate for this challenge, with accuracy generally below 10%. To address this gap, we propose `AgenTracer`, the first automated framework for annotating failed multi-agent trajectories via counterfactual replay and programmed fault injection, producing the curated dataset `TracerTraj`. Leveraging this resource, we develop `AgenTracer`-8B, a lightweight failure tracer trained with multi-granular reinforcement learning, capable of efficiently diagnosing errors in verbose multi-agent interactions. On Who&When benchmark, `AgenTracer`-8B outperforms giant proprietary LLMs like Gemini-2.5-Pro and Claude-4-Sonnet by up 18.18%, setting a new standard in LLM agentic failure attribution. More importantly, `AgenTracer`-8B delivers actionable feedback to off-the-shelf multi-agent systems like MetaGPT and MaAS with 4.8 ∼ 14.2% performance gains, empowering self-correcting and self-evolving agentic AI. Our project page is at https://bingreeky.github.io/atracer/.

**Algorithm 1:** Automated Trajectory Annotation Pipeline of **AgenTracer**

**Input:** Corpus of failed trajectories $\mathcal{T}_\text{fail}$; Corpus of successful trajectories $\mathcal{T}_\text{succ}$; Analyzer agent $\pi_\text{analyzer}$; perturbation operator Π; Rectification operator $\mathcal{R}$

**Output:** The curated dataset $\mathcal{D}_\text{tracer}$

```
1  Initialize dataset: D⁻ ← ∅, D⁺ ← ∅
   /* Part 1:  Locate Decisive Errors via Counterfactual Intervention          */
2  for each trajectory τ ∈ T_fail do
3      for t ← 0 to T do
4          a't ← π_analyzer(s_t, a_t, H_t, F, G)// Analyzer agent proposes a corrected action
5          τ' ← R(τ, t, a't)// Apply intervention to generate a new trajectory
6          if Ω(τ') = 1 then
7              i* ← μ(t), t* ← t, D⁻ ← D⁻ ∪ {(τ, ⟨i*, t*⟩)}
8              break // Found the earliest decisive error
   /* Part 2:  Generate Errors via Programmatic Fault Injection               */
9  for each trajectory τ ∈ T_succ do
10     Let J ← {0, 1, . . . , T} be the set of possible injection points
11     Let J_sample ← RandomSample(J, K) // Randomly select K steps
12     for t ∈ J_sample do
13         ã_t ← Π(a_t) // Perturb original action to create a fault
14         τ̃ ← R(τ, t, ã_t) // Apply injection to generate a new trajectory
15         if Ω(τ̃) = 0 then
16             i* ← μ(t), t* ← t, D⁺ ← D⁺ ∪ {(τ̃, ⟨i*, t*⟩)}
17             break // Stop after first successful injection for this trajectory
18 return curated dataset D_tracer := D⁻ ∪ D⁺
```
