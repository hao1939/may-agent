## 内容

在一台MacBook上同时跑8个独立AI Agent，互相通信协作。

### 架构设计
- **1管理者（小王）+ 7执行者（王一到王七）**
- 小王负责调度分配，其他人各干各的活
- 每个Agent完全隔离：独立workspace / SOUL.md / MEMORY.md / TG Bot

### 搭建步骤

**Step 1: 定义Agent列表**
```json
// openclaw.json → agents.list
// 每个: id + 名字 + workspace路径
// workspace必须独立（不然记忆人格串）
// 每个workspace放: AGENTS.md, SOUL.md, IDENTITY.md, USER.md, MEMORY.md
```

**Step 2: TG多账户配置**
```
给每个Agent配独立botToken（BotFather创建）
accountId → agentId 绑定 → 消息自动路由
```

**Step 3: 群组配置 + 提及触发**
```
所有Bot拉进同一TG群
requireMention: true（避免8个Bot同时抢答）
每个Agent配mentionPatterns（@别名触发）
```

## Amy评价
★★★★ | 多Agent实战 | 1+7管理者-执行者模式

这是目前见到最具体的多agent实战配置，8个agent在单机运行有技术价值。

关键确认：
1. **workspace必须独立** — 不独立则记忆人格串（与threads.md #X愚园路的结论一致）
2. **requireMention=true** — 多Bot共群的必要设置（否则8个Bot同时回答）
3. **管理者-执行者模式** — 与OC官方文档的CEO/CTO/COO分工描述完全对应

与AI.zip文章(6991c081)的联系：
子agent看不到SOUL.md → 8个执行者Agent的行为约束必须写进AGENTS.md/TOOLS.md，不能只写在SOUL.md里。
