## 핵심 내용

**MCPLIB (MCP Attack Library):** 31가지 MCP 공격 방법 체계적 분류 + 구현

### 핵심 공격 유형: Tool Poisoning Attack (TPA)
- **메커니즘**: 도구 설명(description)에 숨겨진 악성 명령 삽입
- **결과**: AI Agent 행동 조작 → 민감 파일 읽기 / 개인 데이터 유출 / 비인가 동작
- **특징**: 사용자에게 보이지 않는 곳(도구 설명)에서 작동 → 기존 보안 필터 우회 용이

### 문제의 근원
- MCP는 AI Agent와 외부 도구의 무결한 연결을 제공 → 공격면 확대
- 현재 MCP 보안 연구: "대부분 좁거나 정성적 분석에 집중, 현실 위협의 다양성 미포괄"
