## 01. 安装与初始化
```bash
openclaw onboard --install-daemon   # 安装并启用后台守护程序(开机自启+自动崩溃重启)
```

## 02. Gateway 服务管理
```bash
openclaw gateway restart            # 重启服务(配置更新后必跑!)
openclaw gateway status             # 查看服务运行状态
openclaw gateway --force            # 强制清理端口占用并启动

# macOS底层重启(Launchctl)
launchctl kickstart -k gui/$(id -u)/ai.openclaw.gateway
```

## 03. 日志监控与诊断
```bash
openclaw gateway logs -f            # 实时监控日志(排障最常用)
openclaw gateway logs --lines 50    # 查看最近50行日志
openclaw doctor                     # 系统全面体检(遇到问题先跑这个!)
openclaw status                     # 查看频道在线状态
```

## 04. 技能与配置管理
```bash
openclaw skills list                # 列出已安装技能
openclaw skills install             # 安装技能
openclaw config get                 # 查看当前生效配置
openclaw configure                  # 交互式快速重新配置
openclaw cron list                  # 查看Cron定时任务
```

## 05. 极客科普：Gateway vs Daemon
- **CLI层面**: 两者是别名关系，代码完全一致
- **架构层面**: `--install-daemon`后，真正的守护者是**macOS Launchd**
- **逻辑**: `restart`命令 = 给系统发信号，让macOS完成"起死回生"
- **结论**: "OpenClaw本身不生产守护进程，它只是macOS服务的搬运工"
