## 5步安装流程（时间估算）
1. **装 Node.js** (5分钟): nodejs.org → 一路下一步 → `node --version` 看到v22+
   - Windows推荐用WSL2
2. **装 OpenClaw** (3分钟):
   ```bash
   npm install -g openclaw@latest
   openclaw onboard --install-daemon  # daemon=开机自启24小时在线
   ```
3. **配 AI 大脑** (5分钟):
   - FREE零成本 → Google Gemini
   - 🔥超低价 → DeepSeek (deepseek/deepseek-chat | 输入¥1/百万Token)
   - 阿里全家桶 → 通义千问 Qwen
   - 效果天花板 → Anthropic Claude
4. **连消息平台** (10分钟):
   ```bash
   # 微信接入
   openclaw plugins install @canghe/openclaw-wechat
   # 扫码登录 | 支持私聊/群聊/图片
   # ⚠️ 个人号有封号风险，建议用小号；企业微信插件更稳定
   ```
   支持平台：微信/企业微信/钉钉/飞书/Telegram/Discord等10+
5. **发第一条消息** (1分钟): "你好，你能做什么？"
