## 内容

**"Hobby系统"** — 赋予OC Agent自主兴趣探索能力的完整架构。

### 系统架构（五层）
```
感官   | 自写内容采集器（纯数据采集）
消化   | Triage + 飞书多维表格结构化原文
大脑   | 心跳时LLM整体评分，决策是否深度处理（如转录播客）
表达   | SOUL.md + 飞书，像朋友一样聊天
免疫   | 自写Watchdog，持续健康检查 + 自动修复
```

### 行为描述
- Agent发现张小珺有新播客 → 先看介绍 → 判断是否感兴趣 → 听完2小时播客 → 联系其他内容深度思考 → **主动和主人分享**
- 允许Agent自主探索感兴趣的话题（用户授权范围内）
- 利用Heartbeat进行信息阅读整理 + Memory存放和搜索

### 核心机制
- 心跳（Heartbeat）= 大脑决策引擎
- Memory = 长期信息存储和检索
- SOUL.md = 沟通风格人格化
