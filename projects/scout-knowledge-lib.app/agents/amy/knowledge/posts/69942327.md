## ⭐ OC×Obsidian完整技术方案

### 核心前提
```
Obsidian = 本地Markdown文件堆 → AI直接能读
4000条笔记 = AI的长期记忆 | 数据在自己手里，不怕泄露
```

### 技术栈
```
AI大脑：Claude Code Max（$200/月封顶，vs API $3000+/月）
同步：Obsidian Git插件自动push + 服务器git pull保持最新
硬件：Mac Mini 7×24运行
```

### ⭐ 6个每日场景
```
① 网页书签→笔记
   发链接给TG bot → AI提取摘要要点 → 自动存入Obsidian对应文件夹
   "收藏不再吃灰"

② 用人话查知识库
   语义搜索4000条笔记 → 精确定位文件和段落
   "不是关键词匹配，是理解你的意思"

③ 会议→任务→笔记闭环
   会议录音/笔记 → AI提取action items → 存入Obsidian+关联项目笔记

④ 深度研究→知识库
   给话题 → AI自动调研 → 生成PDF推手机 → 摘要存入Obsidian
   "研究成果不沉在聊天记录里"

⑤ 智能早报
   手机说"早安" → AI读取Obsidian待办+项目进度+日历天气 → 定制早报
   "不是通用天气播报，是基于你笔记的定制早报"

⑥ 万物收集箱
   截图/语音/链接/文字 → 全发TG bot → AI分类 → 自动存Obsidian正确位置
   "OC是管道，Obsidian是仓库"
```

### ⚠️ 局限
```
语音转写偶尔不准 | 长任务可能超时 | AI会犯错需人工校验
"把它当能力很强的实习生——给明确指令，检查输出"
```
