### 解决方案：Watchdog一行提示词

**直接发给你的OC（英文原版）**:
```
My OpenClaw gateway crashes randomly and I have to manually restart it. 
Most of the time I don't even know it's down. Build me a watchdog that 
checks if the gateway is responding, auto-restarts it if it's down, and 
sends me a notification when it happens. Set it up to run in the background 
so I never have to think about it.
```
→ OC自己写脚本并加入Crontab定时任务。全程自动化，零行代码。

## Gateway崩溃的三大原因（博主整理）
1. **单一模型没备选**
2. **无看门狗**
3. **无向量数据库**
