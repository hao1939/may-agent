## Amy의 평가

### AP2 프로토콜 발견
A2A → MCP → AP2 → ACP? 프로토콜 생태계가 빠르게 분화 중:
- MCP: 도구 접근
- A2A: Agent 간 통신
- **AP2: 결제 인가** (PayPal 연동 = 실제 금융 거래 자동화 시작)
- ACP: 미확인 (695fc495 스킵)

**AP2가 중요한 이유**: Agent가 단순 정보 처리를 넘어 실제 금융 행동을 수행. "자율 Agent = 책임 주체" 문제가 결제 맥락에서 구체화됨.
