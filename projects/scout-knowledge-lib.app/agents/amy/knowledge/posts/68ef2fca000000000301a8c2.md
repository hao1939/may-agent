Google新出的URL context grounding 会撼动传统RAG的地位吗？

Google Gemini推出URL context grounding工具，无需RAG流程直接读取网页内容，支持多模态信息处理与多步骤任务。

[Slide 2]
Google在AI领域的更新节奏持续加快，继此前多项功能后，近期又为Gemini推出了名为URL context grounding的新工具。这款工具既可单独使用，也能与Google搜索功能结合，帮助用户深入挖掘互联网内容，其核心特点在于无需传统RAG处理流程，就能直接读取、理解并回答单个网页URL（包括PDF链接）中的内容与数据相关问题。

传统RAG技术需要先提取URL文本内容，再进行分块、向量化、存储等多个步骤，而URL context grounding省去了这些繁琐操作。用户只需提供目标URL，就能快速获取所需信息，不仅代码编写简单，信息提取的准确性也较高，这让不少人认为它可能成为"传统RAG的又一挑战"。

为验证其能力，相关测试给出了直观结果。在处理特斯拉长达50页、包含复杂表格的10-Q季度财报时，面对"2022年和2023年的总负债与总资产分别是多少"这一问题，传统RAG曾难以高效获取答案，而URL context grounding顺利输出了准确结果；当被问及财报中信件里标有星号（***）的退出日期原因时，它同样给出了精准回应。

除了文档深度查询，URL context grounding还拓

展出多种实用场景。在内容分析与合成方面，它能从多个URL中提取价格、名称等特定信息，对比多份报告或文章以发现差异、追踪趋势，甚至结合多个来源生成摘要、博客或报告——比如开发者可借助它对比不同网站的食谱，分析食材与烹饪时间。对开发者而言，它还能解读GitHub仓库或技术文档，辅助解释代码、生成安装指南；结合Google搜索后，还能构建复杂的多步骤任务流程，例如AI代理先搜索相关文章，再用该工具深度"研读"关键结果并整合信息，开源AI代理Gemini CLI的web-fetch命令就用到了这一功能，支持开发者在终端快速总结网页、提取信息或翻译内容。

在信息准确性与内容兼容性上，这款工具也有突破。它通过将回答基于具体网页内容，减少了AI生成错误或虚构信息的可能，还能提供信息来源引用，增强用户信任；同时支持PDF、PNG、JPEG等多种格式，既能提取PDF中的文本与表格结构，也能分析图片中的图表，对HTML、JSON、CSV等文件格式也能良好适配，甚至可用于在线产品价格对比，比如查询索尼WH-1000XM5无线降噪耳机的不同平台售价，或是对比亚马逊与微软2025年第二季度的财报，提取关键信息并总结两家公司的核

不过，URL context grounding并非毫无局限，它目前无法处理付费墙内容和部分媒体内容。但整体来看，在众多使用场景中，它已能有效替代传统RAG流程，尤其与Google搜索结合后，在构建复杂任务流程、保证信息真实性、分析多模态内容等方面表现更为突出，为AI内容处理提供了新的高效方案。
