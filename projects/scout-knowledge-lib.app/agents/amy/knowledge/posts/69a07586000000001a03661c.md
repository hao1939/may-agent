## 配置步骤与踩坑清单

### 准备阶段
1. 创建子Agent，Workspace隔离（独立记忆/人设/数据管理）
2. 每个子Agent配独立Channel，对接多个飞书Bot
3. 为每个Agent配独立人设（在SOUL.md/底层规则写入）

### 关键配置：agentToAgent
```json
{
  "tools": {
    "agentToAgent": {
      "enabled": true,
      "allow": ["main", "dev", "qa", "mgr", "zeagt"]
    }
  }
}
```
**调试方法：** 把 `docs.openclaw.ai/zh-CN/gateway/conf...` 喂给龙虾即可自动配置

⚠️ **openclaw.json做好备份** — 部分场景doctor命令无法修复，需手动恢复

### 执行阶段——4个问题的解决方案

| 问题 | 解决 |
|------|------|
| 主Agent调用子Agent**超时** | 指令主Agent调大超时：`调整超时时间为十分钟` |
| 流程**中断** | Loop逻辑固定迭代次数：`采用loop逻辑，迭代五次` |
| 迭代结束后**需人工触发** | 子Agent完成后主动sessions_send通知主Agent |
| 子Agent**未加载预设配置** | 指定子Agent使用独立工作区读取.md配置文件 |

### sessions_send通知格式（关键）
```json
{"sessionKey": "agent:mgr:main","message": "第X轮完成，需要继续"}
```

### 提示词模板（完整）
```
使用dev agent（牛马1号）设计旅游攻略，由qa agent（牛马2号）评估，
使用指令dev agent重新优化。
采用loop逻辑，迭代五次。
子agent必须使用自己的独立工作区。
在工作区创建目录，存储文稿与每次交互记录。
重要：子agent完成任务后，必须使用sessions_send调用主agent：
{"sessionKey": "agent:mgr:main","message": "第X轮完成，需要继续"}
要求评分95分才算通过
```

## Amy Analysis

**★★★★ — 最早发布的生产级多Agent loop实现**

**四大坑全部有解法** — 超时/流程中断/人工触发/配置未加载，这四个问题是所有多Agent系统的通病，解法都在这帖里。

**sessionKey格式 `agent:mgr:main`** — 确认了sessions_send的sessionKey命名规范。

**最优先的下一步优化（作者自评）：**
- 换更优模型（当前minmax2.5）
- 给规划Agent加机票/酒店MCP
- 评审Agent提示词要更细（地铁路线/路程距离/多出行方案对比）
