## 核心：v2026.3.1 SecretRef机制

**之前的问题：** API Key/Bot Token明文存配置文件，任何能读home目录的程序都能拿到。

**新方案：SecretRef**
- 配置文件只存引用（SecretRef），密钥存在：
  - 系统Keychain
  - HashiCorp Vault
  - AWS Secrets Manager
- 启动时解析，**只在内存中存活**

## 迁移4步（5分钟）
1. `secrets audit` — 扫描明文
2. `secrets configure` — 交互式配置provider
3. `secrets apply` — 执行迁移
4. `secrets reload` — 重载验证
