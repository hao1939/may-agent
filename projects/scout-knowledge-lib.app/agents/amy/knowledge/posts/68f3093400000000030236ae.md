## Full Text
[论文解读] Context-Folding: 让 Agent “学会”动态管理上下文，就像人类在思考时会暂搁一边次要细节、专注关键路径一样。这种方法特别适用于需要多步推理、工具调用和子任务分解的场景，例如深度研究或软件工程任务，论文来自 Bytedance Seed、CMU 和 Stanford。
	
核心机制：折叠与分支
项目的核心是 Context-Folding 机制，将 Agent 行为建模为一个概率过程：Agent 根据查询生成动作序列，同时通过上下文管理器动态折叠历史。具体操作依赖两个特殊工具:
· branch（分支）：Agent 为子任务创建一个临时子轨迹，提供简短描述（3-5词）和详细提示。例如，在研究任务中，主线程可分支一个“网页搜索”子任务，让 Agent 专注探索而不干扰主线规划。
· return（返回）：子任务完成后，Agent 生成总结消息，将其附加到主线程，同时丢弃中间步骤（包括 KV 缓存回滚到分支点，以节省计算）。
	
这种设计采用“计划-执行”框架：
· 主线程（规划状态）：专注高层次分解和分支发起，避免 token 密集型工具（如直接搜索），保持上下文精炼。
· 分支（执行状态）：处理具体子任务，不允许嵌套分支（以防复杂度爆炸），确保专注。
	
与总结方法不同，折叠是“边界对齐”的——总结仅在子任务边界生成，保留了推理的完整性；与 Multi Agents 系统类似，但更动态：子轨迹像临时“Sub Agent”，共享前缀上下文，却能交替执行而非并行。结果，Agent 能在固定预算下处理更长的 horizon，如将 100B+ 模型的 327K 上下文效率压缩到 32K。

**Abstract**

Language model (LLM) agents are fundamentally constrained by context length on long-horizon tasks. We present a framework, actively managing the context by procedurally change a subtask and then fold it upon completion, collapsing the intermediate steps while keeping a concise summary of the outcome. To make this behavior learnable, we develop an end-to-end reinforcement learning framework FoldGRPO with specific process rewards to encourage effective task completion and context management.
