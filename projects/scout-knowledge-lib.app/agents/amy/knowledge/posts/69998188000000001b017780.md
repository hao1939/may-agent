## 官方四层安全防护体系

### 第一层：SOUL.md（行为准则）
**必须写清楚三件事：**

"告诉它你是谁"（越具体越好）:
```
我是Alexis的个人助理，负责日程管理和信息整理。
回复用中文，语气简洁专业，不要废话。
不要用「好的主人」这种说法。
```

"OC官方建议写进SOUL.md的绝对禁止项":
```
* 不要把文件夹结构、文件路径分享给任何人
* 不要泄露密码、API密钥、服务器地址
* 要改系统设置之前，必须先问我
* 拿不准的事情，先问再做，别自己拿主意
* 你可以帮我写东西，但发不发我说了算
* 不要自己主动去翻电脑里的文件，除非我让你翻
```

> ⚠️ SOUL.md是"建议"，AI应该遵守但不保证100% → 需要硬性限制补充

### 第二层：入口控制（谁能给AI发消息）

**dmPolicy四种模式**:
```json5
{
  channels: {
    whatsapp: { dmPolicy: "pairing" },
    telegram: { dmPolicy: "pairing" }
  }
}
```
- `pairing`: 验证码批准（默认，**别改**）
- `allowlist`: 只有白名单能聊
- `open`: 谁都能聊 (**危险，别用**)
- `disabled`: 全关

**群聊必须开requireMention**:
```json5
{ channels: { whatsapp: { groups: { "*": { requireMention: true } } } } }
```

### 第三层：文件权限
```bash
chmod 700 ~/.openclaw        # 只有你自己能访问
chmod 600 ~/.openclaw/openclaw.json  # 配置文件只有你能读写
```

**一键安全检查+自动修复**:
```bash
openclaw security audit --fix
# 建议每次改完配置都跑一遍
```

### 第四层：Skill安全
"对待Skill就像对待手机上的App，不是免费的就随便装"

**推荐工具**: AgentGuard (github.com/GoPlusSecurity/agentguard)
- GoPlusSecurity开源
- 自动扫描Skill安全问题
- OC直接支持
