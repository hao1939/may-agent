## 安装步骤

### 准备工作
```bash
node -v   # → v24.13.1 (作者环境)
npm -v    # → 11.8.0
git -v    # → 2.53.0
```

### 模型选择：智谱GLM4.7（BigModel平台）
1. 去 bigmodel.cn → 控制台 → API Key → 添加新的API Key
2. API Key格式：`{API Key ID}.{secret}`

### 安装命令
```bash
npm install -g openclaw@latest
openclaw onboard --install-daemon
# 建议：魔法开启"TUN"模式
```

### 配置向导选择
1. yes → 知晓风险
2. quick start → 快速开始
3. 模型选 Z.AI → GLM4.7 → 粘贴APIKEY
4. 后续问题都选跳过或no（后续图形界面设置）
5. 最后选 open the Web UI 网页版

---

## 避坑点 🔥
- **⚠️ API Key区分大小写！** 如果无法复制粘贴，终端里右键一下
- **⚠️ Dashboard重新打开**: 每次服务重启后，必须关掉旧的Dashboard，再通过 `openclaw dashboard` 重新打开
