# Tool-Integrated RL 会是 Agents 应用突破「基模能力限制」的关键技术吗?

> AI智能体需结合强化学习与工具推理，突破复杂任务瓶颈，提升自主行动能力。

[Slide 2]
到2025年，简单的工具使用能力无法帮助AI智能体应对更复杂的逻辑和更大的计算负担。因此，业界开始关注结合强化学习与工具集成推理（TIR），使智能体能够"借助工具思考"，以适应复杂多变的任务环境。

# Scaling law 能够拿到的优质数据越来越少，agentic ai 的 tool-integrated reasoning 能力有何瓶颈?

人们对"智能体"的定义与预期这半年来发生了巨大变化，但普遍认同更强智能体需具备与外部世界交互和采取行动的能力，仅依赖预训练的内部知识难以应对复杂逻辑与多步骤推理任务。

1. 有一种观点将AI系统区分为"基础模型（LLM)"、"AI助手"和"AI智能体"。LLM是基础模型；AI助手可以视作强大的助理，除非人类明确指示（如撰写邮件、归纳文档等），否则不会主动行动；AI智能体则像自由的专家，增加了推理、规划及行动能力，通

[Slide 3]
常需要跨工具、跨API，甚至与其他智能体协作。

2. 还有的研究通过"生成式AI（GenAI）"、"AI智能体"和"Agentic AI"进行分类。生成式AI的核心在于无法主动发起任务的生成工具；AI智能体则具备"主动执行"的能力，能够独立使用工具（API）完成具体任务，但在推理深度和知识更新上遇到困难；Agentic AI是自主系统，内部具备多角色的智能体，通过"总指挥"协调协作。

在这一趋势下，智能体需要理解目标、自主规划与调用工具，最终完成任务，这使得工具集成推理（TIR）成为重要研究方向。

# 为何TIR的重心要从SFT转向RL？

最初，简单的工具调用与外部知识接入方式是检索增强生成（RAG），在2023年2月发布的Toolformer创新性地推进了外部工具调用的概念，使TIR开始兴起。

1. Toolformer表明，LLM不仅能被动整合检索到的

[Slide 4]
文本，还能通过训练主动学习何时以及如何调用外部API，如计算器、搜索引擎或翻译系统。

2. TIR使模型从被动的文本生成器转变为更主动的问题解决者，为智能体构建一个"行动层"，赋予其在现实世界中感知和行动的能力。

TIR的主要价值在于突破传统LLM能力的限制，尤其是在处理需精确计算、事实核查或实时交互等任务时。其贡献在于帮助扩展模型的"支持集"。

经验支持集扩展指外部工具赋予LLM生成理论上不可能的问题解决路径的能力。例如，纯文本模型无法进行复杂的多位数运算，而集成Python解释器的模型可以将这样的计算转化为可执行的代码。

可行支持集扩展则通过外部工具，使得复杂策略在有限的token预算内得以实施。某些问题可能需要冗长复杂的推理，往往超出实际应用的上下文限制，导致策略无法执行。通过TIR，模型可以用几行代码或一次API调用高效完成任务，将原本"理论上可能但实践中不可行"的解决方案转化为高效且实际的策略。

[Slide 5]
TIR将工具使用从简单的事后调用提升到与推理过程深度融合的层面。这些方法的核心在于将工具调用结果视为一种观察，为多步决策过程中的策略优化提供奖励信号，即"借助工具思考"。基于TIR的操作模式，近期有研究总结三种典型的"涌现认知模式"。

1. 从洞察到计算的转化模式是模型利用语言推理能力分析与构建问题，并将其中需要精确计算的部分委托给工具执行。

2. 代码探索与验证模式是模型生成并执行代码来测试假设或验证推理步骤正确性的一种自我修正方式。

3. 卸载复杂计算模式则是将计算密集型子任务完全交给专业工具处理，使LLM能够将更多认知资源集中在更高层次的战略规划上。

以Toolformer为代表，TIR初期的训练主要依赖专家演示轨迹的SFT。随着SFT局限性的逐渐显现，这一方法已无法支撑现代智能体解决越来越复杂的任务。

1. SFT作为模仿学习的核心在于让模型复现高质量的专家示范，而这些示范不一定是最优解。这导致通过

[Slide 6]
模仿学习训练的智能体会受到教师水平的限制，容易学习到低效或冗长的工具使用方式。

2. SFT也难以应对需要一系列相互依赖的动作才能完成的任务，特别是复杂的数学问题。由于模型只训练模仿静态轨迹，每一步的错误都会积累，且没有机制根据中间结果进行自我修正或调整计划。

3. 此外，由于SFT面临"灾难性遗忘"和"静态性质"等问题，基于SFT的TIR方法在处理复杂数学逻辑推理、多步推理任务、开放式目标的动态Agentic任务和多工具协同任务等方面表现不佳。

相比而论，近期研究开始聚焦于基于强化学习的TIR方法。与SFT的密集监督信号不同，RL可以从稀疏的奖励信号中学习，捕捉SFT数据集中难以表现的细微行为，从而发现优于专家示范的解决方案。

基于强化学习的TIR方法将目标从简单复制造型转向优化最终任务的性能，使智能体得以战略性决定何时、如何以及以什么组合调用工具，从而适应新奇环境与意外失败。

# Agent 结合 Tool-Integrated RL 能实现 1+1>2 吗?

在模仿范式局限的基础上，基于强化学习的工具使用方法（Tool-Integrated RL）将目标从复制造型转向最终任务性能优化，使智能体能够战略性地决定如何调用工具，以适应新环境和意外情况。

在Tool-Integrated RL的研究中，如"ToolRL"、"ToRL"、"OTC-PO"、"ReTool"等都采用强化学习策略，将符号计算（如代码执行、图像编辑）与自然语言推理深度结合在一个单一的认知循环中，探索集成RL和动态工具使用的不同方法，让具备TIR能力的智能体学习与环境互动的最佳策略。

1. "ToolRL"是UIUC的研究者在2025年4月提出的成果。该研究将工具调用任务建模为TIR的任务范式，要求模型不仅能够"使用"工具，还需以合理顺序和逻辑调用多个工具，并根据信息灵活调整思维路径。

[Slide 8]
- 该研究系统分析了工具使用任务中的奖励设计维度，包括"如何平衡不同奖励信号？"和"如何细分奖励信号粒度而不是简单的二值选择？"等问题。

- 基于分析结果，提出了一种结合"格式规范"与"调用正确性"的结构化奖励设计（ToolRL），确保模型不仅生成合理的工具链式思维，还能精准理解工具的含义与使用语义。

- 测试结果显示，采用ToolRL的"GTPO+奖励设计"策略训练的模型，在多个下游任务中的准确率平均提升超过15%，超过原始模型基线的表现也提升超过17%。

2. "ToRL"是上海交大、SII和GAIR的研究者在3月提出的训练方法，允许模型从基座模型出发，通过强化学习自主探索最优工具使用策略，而无须先进行监督微调。

- 该工作将TIR与直接从基础语言模型进行的强化学习结合，使模型自主发现有效的工具使用策略。

- 在推理过程中，系统一旦检测到代码终止标识符，

[Slide 9]
将暂停文本生成，提取执行的代码块并将结构化执行结果插入上下文中，并继续进行后续自然语言推理，直至最终答案呈现或生成新的代码块。

　- 测试结果显示，ToRL在所有测试基准上表现优于基线模型。对于1.5B参数模型，ToRL-1.5B的平均准确率已达到48.5%，超过了Qwen2.5-Math-1.5B-Instruct（35.9%）和Qwen2.5-Math-1.5B-Instruct-TIR（41.3%）。在7B参数模型中的性能提升更为显著，ToRL-7B的准确率达到62.1%，比其他具有相同基础模型的开源模型高出14.7%。

3. 在8月的"ZeroTIR"项目中，复旦大学、小红书以及华东师范大学的研究者探索在Python代码执行环境下，基于结果奖励的RL训练LLM的数学能力，揭示出计算量与自发代码执行频率、平均响应长度和最终任务准确性之间的显著关联（Scaling Law）。

　- ZeroTIR框架的核心在于利用强化学习（PPO和Reinforce++）训练基础LLMs，使其能够自主借助Python代码执行环境解决数学问题。

　- 训练过程中，为提升稳定性与效率，研究者采用重

[Slide 10]
放缓冲区过滤机制，优先选择准确中等范围的样本进行训练，并设计高效的交互机制，通过动态停止标记（如"python"）来整合推理、代码生成、与外部代码环境的交互及执行反馈。

　- 测试显示，ZeroTIR训练的模型（ZTRL）在AIME24、AIME25和MATH500等数学基准测试中的表现显著优于基线和基于SFT的TIR方法。例如，7B的ZTRL模型平均准确率达到54.0%，而其他方法的准确率约为39%。

　- 研究还发现，随着训练步骤的增多，模型自发代码执行的频率、平均响应长度与任务准确率都显著提高，表明训练投入与增强工具推理策略之间存在可量化的正相关关系，体现出一种Scaling Law。

近期的多个研究证据表明工具集成强化学习在优化单一推理循环内的有效性，但大多数工作依然围绕RLVR框架展开，考虑如何在现有方法中集成工具调用能力，尚未将此能力扩展至多轮推理的长时域任务。

对于长期TIR能力，当前RL方法难以精准识别长链中各个相互依赖工具调用环节对成功的贡献。为使未来

[Slide 11]
的Agentic AI具备"借助工具思考"的能力，工具集成强化学习仍具潜力值得进一步挖掘。

1. 最近的综述指出，长期TIR的前景挑战在于实现长期信用分配，以确保跨多轮交互的稳定和长效表现。这要求模型不仅优化单步工具调用，还需优化整个任务的完成路径，处理因稀疏或延迟奖励带来的挑战。

2. 因此，开发更精细的功劳分配机制，使模型能够有效引导智能体穿越复杂决策链，同时避免对有益探索的误惩罚或促成激励作弊，这仍是推动智能体系统发展的关键且尚待解决的难题。
