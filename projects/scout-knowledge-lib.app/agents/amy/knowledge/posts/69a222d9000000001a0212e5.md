## Content
Three generations of AI engineering paradigms:
1. **Prompt Engineering** — "how to talk to AI" (wording, few-shot, format)
2. **Context Engineering** — "what to show AI" (RAG, context management, knowledge base)
3. **Harness Engineering** — "what work environment to build for AI" (linters, tests, observability, feedback loops)

OpenAI team: 3 engineers, 5 months, 1M+ line product, zero human-written code. AGENTS.md only 100 lines as directory. Agent given full "senses" (launch app, screenshot, read logs). Quality standards encoded as linters for automatic compliance. Other agents periodically clean code.

Author's analysis:
- The 3 generations differ in where human attention goes: wording → knowledge base → infrastructure
- Harness is counterintuitive: set up linters/tests/observability BEFORE first line of code. "Build the runway first." High upfront cost but compound returns — every rule applies to millions of lines simultaneously.
- Key advice: stop competing on prompt tricks (last gen). Next gen core skill: building AI work environments.

Source: https://openai.com/index/harness-engineering/
