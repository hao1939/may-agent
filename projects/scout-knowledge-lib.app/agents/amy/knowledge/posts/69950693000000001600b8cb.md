## 四层记忆架构

### Layer 1: Daily Memory Flush
- **触发**: session context快满时自动触发（OC内置机制）
- **动作**: 提醒AI写入当日memory文件（结构化模板）
- **原则**: "不管多忙都要写，宁可少写不能没写！"

**记忆格式模板**:
```markdown
# 2026-02-18 Daily Log
## 决策 Decisions
- [决策内容及原因]
## 待办 Action Items
- [x] 已完成 / [ ] 待完成
## 关键对话 Key Conversations
- 重要讨论摘要
## 技术/技能 Notes
- 学到的新技能、踩坑记录
```

### Layer 2: Hourly Micro-Sync（工作日10/13/16点）
- **触发**: 10:00, 13:00, 16:00（工作日三个时间点）
- **动作**: 读取当日memory文件→检查最近几小时→有则追加，无则静默
- **设计**: 安静执行不发通知 | append模式不覆盖

### Layer 3: Daily Context Sync（23:30）
- **流程**: `sessions_list`获取今日所有session → 每个session调`sessions_history`读完整对话 → 对比当日memory → 找遗漏决策/讨论 → `edit`追加
- **关键**: `sessionTarget: "isolated"` — 不污染主session！

### Layer 4: Weekly Memory Compound（周日22:00）
- **流程**: 读取本周7个memory/YYYY-MM-DD.md → 读当前MEMORY.md → 分析提取新偏好/决策模式变化/过时信息 → `edit`更新MEMORY.md
- **效果**: "跑了两周后，MEMORY.md里关于我投资偏好的描述准确得吓人，甚至总结出了决策模式"

## 配置参考

### openclaw.json（开启memoryFlush）
```json
{
  "agents": {
    "defaults": {
      "compaction": {
        "memoryFlush": {
          "enabled": true
        }
      },
      "memorySearch": {
        "sources": ["memory", "sessions"],
        "experimental": {
          "sessionMemory": true
        }
      }
    }
  }
}
```

### Cron任务示例（Daily Context Sync）
```json
{
  "name": "Daily Context Sync",
  "schedule": {
    "kind": "cron",
    "expr": "30 23 * * *",
    "tz": "Asia/Shanghai"
  },
  "payload": {
    "kind": "agentTurn",
    "message": "执行 Daily Context Sync...",
    "model": "minimax-portal/MiniMax-M2.1"
  },
  "sessionTarget": "isolated"
}
```

## 文件结构
```
workspace/
├── MEMORY.md    # 精华，每次session自动注入
├── AGENTS.md    # AI行为规则
├── USER.md      # 投资组合、偏好
├── SOUL.md      # AI人格设定
└── memory/
    ├── 2026-02-18.md
    └── ...
```

**使用规范（写入AGENTS.md）**:
- 禁止暴力读取所有memory文件！
- 必须先用: ①`memory_search`(语义) ②`memory_get`(精确段落)
- 只有搜索空结果时才fallback到直接读文件
