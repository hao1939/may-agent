## 三个必开配置（全带JSON代码）

### 坑①：消息不实时发（blockStreamingDefault）
**问题：** 默认关闭，AI全程沉默，最后一股脑发5条。
**修复：**
```json
{
  "agents": {
    "defaults": {
      "blockStreamingDefault": "on",
      "blockStreamingBreak": "text_end"
    }
  }
}
```
效果：AI每完成一段发一条，实时进度可见。

### 坑②：群里必须@（requireMention）
**问题：** 默认每句话都得@机器人。
**修复（白名单+免@）：**
```json
{
  "channels": {
    "telegram": {
      "groups": {
        "*": { "requireMention": false }
      },
      "allowFrom": ["-你的群ID"],
      "groupPolicy": "allowlist"
    }
  }
}
```
只有白名单里的群响应，且不用@。

### 坑③：不知道消息收没收到（ackReactionScope）
**问题：** 发了消息没反应，不知道是在处理还是挂了。
**修复：**
```json
{
  "messages": {
    "ackReactionScope": "all"
  }
}
```
收到消息自动点emoji确认。

**修改方式：**
1. 直接编辑 `~/.openclaw/openclaw.json`
2. 用命令 `openclaw gateway config.patch`

## 进阶：为什么用群聊Forum而不是私聊

Telegram的Forum群支持**Topics（话题）**：
- 每个topic = 独立对话（写代码/查资料/翻译文档 三个并行）
- 私聊只能排队，Forum可以并行
- topic可命名，便于上下文追溯
