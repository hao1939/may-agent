# Retired Scout Agents

This directory preserves the former `amy` and `amy-kimi` agents and their
research archives. They are historical evidence, not current Agent App
definitions, instructions, credential stores, or knowledge authority.

The Host discovers App-local agents only below `agents/`, so nothing here is
loaded or runnable. Current Scout behavior lives under `../../agents/scout/`;
durable knowledge lives in `/app/projects/scout-knowledge-lib/knowledge/`.

Do not copy an archived `agent.json`, heartbeat, tool, or knowledge path back
into active use. Reintroduction requires an explicit non-duplicative role and a
reviewed output boundary. Credentials must never be stored in this archive.
