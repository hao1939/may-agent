## 核心：Reddit+X真实痛点→MVP，全流程0代码

### 两步流水线
**Step 1：挖痛点**
```
用 Last 30 Days skill 研究 [话题] 的用户痛点。
按频率排序：Top pain points / 具体抱怨 / 现有方案缺口 / 产品机会
```

**Step 2：造MVP**
```
Build me an MVP that solves [痛点].
Keep it simple — just core functionality. Ship as a web app.
```

**Step 3：持续情报（每周一）**
```
每周一上午，用 Last 30 Days 研究 [你的细分市场]，发Telegram
```
