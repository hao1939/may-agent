## Content
Paper: **EvoFSM: Controllable Self-Evolution for Deep Research with Finite State Machines**

### Problem
Current DeepSearch Agents are either rigid Workflows (hit walls on new problems) or unconstrained Self-Evolution (self-rewriting code is unstable). Need controlled middle ground.

### Core Approach: Agent in FSM
**Part 1: Flow-Skill decoupling**
- Flow = macro logic jumps (e.g., on search failure: backtrack or reflect?)
- Skill = micro instruction execution (how each state node operates)

**Part 2: Controlled evolution via Critic**
- When agent hits dead loops or capability gaps, Critic issues "prescriptions": ADD_STATE or MODIFY_EDGE
- Atomic operations much more stable than full code rewrite
- Tested effective against "instruction drift" in long tasks

**Part 3: Memory bank for historical experience**
- Successful paths → Priors
- Failed paths → Constraints
- Next similar problem starts from optimal strategy

### Author's Self-Critique (important)
"This self-evolution approach doesn't really follow scaling law. Long-term it's still A Bitter Lesson. Short-term it may inspire some 'controlled evolution' approaches."
