## Content
**SkillsBench:** First benchmark treating agent skills as first-class evaluation artifacts.

### Three Conditions
1. **No skills:** Agent receives only instructions
2. **Curated skills:** Complete skills directory with examples, code snippets, resources
3. **Self-generated skills:** Agent prompted to generate procedural knowledge before task

### Key Results
- **Curated skills:** +16.2 percentage points (24.3% → 40.6%)
- **Self-generated skills:** –1.3pp (drops to 21.0%) — **WORSE than no skills**
- **Conclusion:** Agents cannot teach themselves. They need human-expert-prepared "skill packs."

### Domain Variance
- **Medical:** +51.9pp (standardized procedures fit skill encapsulation)
- **Software Engineering:** only +4.5pp (flexibility needs > rigid skills)

### Framework
Based on Harbor. Containerized environments, deterministic validation. Each task: instruction, environment (Docker), solution (ground truth), validator (automated test scripts). Anti-leakage: skills must provide generalizable guidance for a CLASS of problems.

### Scale
84 tasks, 11 domains, 47,150 unique skills (deduplicated), 7,308 evaluation trajectories across 7 agent model configurations.

## Synthesis Notes
- **Critical finding for our system:** SOUL.md and channel configs are essentially "curated skills" — human-expert-written procedural knowledge. This benchmark validates that approach: +16.2pp average improvement.
- Self-generated skills being WORSE than none is a strong "Iteration Is Poison" (#1) signal: the model generates noise that actively interferes with performance.
- Domain variance is important: our system spans multiple domains, so skill effectiveness will vary. Medical-like standardized procedures (security rules, protocol compliance) should benefit most.
- **Connects to MemSkill paper:** MemSkill's Designer uses failure-driven feedback to evolve skills — this might be the middle ground between "pure curated" and "pure self-generated." Context-aware skill generation from real failures.
- The "cooking vs recipe-writing" metaphor from comments is memorable and quotable.
