## LobsterAI完整技术规格（最权威来源）

### 基础信息
- **开发方**: 网易有道
- **License**: **MIT** ← 开源确认
- **平台**: macOS (Intel+Apple Silicon) / Windows / Linux / Mobile
- **技术栈**: Electron 40 + React 18 + Claude SDK + Redux

### 架构（Slide 2 OCR — 完整架构图）

```
ELECTRON主进程:
  CoworkRunner (Claude SDK + 执行引擎)
  技能管理器: 16个内置 + 自定义
  沙箱VM (QEMU): Alpine Linux + virtio-serial通信  ← 重要!隔离安全
  SQLite (sql.js WASM): 会话/消息/记忆/配置/定时任务
  IM网关: 钉钉/飞书/Telegram等
  定时任务调度器 (cron表达式)
  IPC消息路由: 40+通道
  Preload脚本 (IPC安全桥接)

渲染进程(React):
  Redux Store
  Cowork UI: 会话/权限/记忆管理
  Artifacts渲染器: HTML/SVG/Mermaid/React/Code (沙箱iframe)
```

### 核心特性
1. **全场景办公**: 数据分析/PPT/视频(Remotion)/文档/搜索/邮件
2. **本地+沙箱执行**: QEMU Alpine Linux隔离沙箱
3. **16个内置技能**: Office文档/Web搜索/Playwright/Remotion视频生成
4. **定时任务**: 对话式/GUI界面，支持cron表达式
5. **持久记忆**: 自动提取偏好，SQLite本地存储
6. **IM远程操控**: 钉钉/飞书/Telegram/Discord
7. **权限门控**: 敏感工具调用需用户明确批准
8. **数据本地化**: 聊天记录和配置不离开设备
