## Content
SKILLRL framework: teaches AI to "reflect and evolve from failure."

### Core Architecture: SKILLBANK (Evolving Skill Brain)
- **From success:** Extract reusable SOPs (e.g., "search keyword → filter" for shopping)
- **From failure:** Generate reflection containing "error cause + correct approach + general principle" — an "错题本" (error notebook)

### RL + Skill Evolution Loop
1. Agent uses SKILLBANK knowledge for decision-making
2. After environment interaction, RL (e.g., GRPO) updates policy
3. On frequent failures → triggers "reflection mechanism" → generates new skills → updates SKILLBANK

### Results
- Open-source small model with SKILLRL outperformed GPT-4o
- Beat all mainstream RL and memory-augmented methods on ALFWorld

"真正强大的智能体，不是靠堆算力，而是靠聪明的学习机制。"
