## 7条实战铁律

### 1. 先想后打 ⭐
**Shift+Tab×2 → Plan Mode**
```
❌ "Build me an auth system"
✅ "Build email/password auth using existing User model, 
   store sessions in Redis with 24h expiry, 
   add middleware protecting /api/protected routes"
```
**5分钟规划省几小时debug** | 10次中10次Plan Mode显著优于直接开聊

### 2. CLAUDE.md写法 ⭐
Claude每次启动第一件事读这个文件。四原则：

| 原则 | 说明 |
|------|------|
| 精简 | 模型只能可靠遵循~150-200条指令；系统提示已占~50条 |
| 只写项目特有 | 别解释components是什么；写奇怪的/独特的约定 |
| 说why不只说what | "Use strict mode **because** we've had production bugs from implicit any" |
| 持续更新 | 按#键→自动添加；同一问题纠正两次→写进文件 |

> **Golden rule**: 好的CLAUDE.md像你明天会失忆时给自己留的笔记

### 3. 上下文管理
- 200K窗口**20-40%就开始降质**
- 四招: 功能分会话 | 外部记忆SCRATCHPAD.md | Copy-Paste Reset大法 | 果断/clear重来
- **Copy-Paste Reset**: 复制关键内容→/compact→/clear→粘贴回

### 4. 提示词+模型分工
- 具体>模糊 | 约束>开放 | 示例>描述
- 明确说"不要做什么"防过度工程化
- **Opus做规划，Sonnet做执行**，CLAUDE.md保证交接一致

### 5. 系统化
- `claude -p` 跑headless批任务
- 日志复盘→改进CLAUDE.md→下轮更好
