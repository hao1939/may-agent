💡 Coevolving with the Other You: Fine-Tuning LLM with Sequential Cooperative Multi-Agent Reinforcement Learning

**收录**：arXiv:2410.06101v2 [cs.AI] 22 Feb 2025

**概述**：本文提出了一种名为 CORY 的新方法，将大型语言模型的强化学习（RL）微调扩展到序贯合作多智能体强化学习框架中。通过将 LLM 复制为自主智能体（Pioneer 和 Observer），并设计知识转移（Knowledge Transfer）和角色交换（Role Exchange）机制，CORY 实现了两个智能体之间的合作与共同进化。实验表明，CORY 在策略最优性、抵抗分布崩溃和训练鲁棒性方面优于传统的 PPO 算法。

**背景**：大型语言模型（LLM）在多种下游任务中取得了显著的成功，但针对特定任务的微调仍然是一个挑战。现有的 RL 微调方法主要依赖于 PPO 及其变体，这些算法在应用于 LLM 微调时表现出不稳定性和对分布崩溃的脆弱性。LLM 微调面临的挑战包括巨大的离散动作空间和稀疏奖励问题，这些问题阻碍了在如此大的搜索空间中的探索，导致流行算法如 PPO 的不稳定性。

**相关工作**：

• 强化学习从人类反馈（RLHF）：如 InstructGPT 通过结合人类偏好数据集的监督微调和基于人类偏好的 RL 来微调 GPT-3 类模型。

• 多智能体强化学习（MARL）：多智能体在复杂系统中共进化，产生新技能。例如，在 Go、StarCraft II 和 Diplomacy 等游戏中，多智能体学习推动了 AI 的发展。

• LLM 微调方法：包括监督微调（SFT）、RL 微调和直接偏好优化（DPO）。RL 微调因其直接优化路径和潜在的更好分布外性能而显示出潜力。

[Slide 3]
**框架与方法**：CORY 将 LLM 复制为两个自主智能体：Pioneer 和 Observer。Pioneer 根据查询生成响应，Observer 则根据查询和 Pioneer 的响应生成响应。两个智能体共享集体奖励，并在训练过程中定期交换角色，以促进合作和共同进化。CORY 通过以下两个关键机制实现两个 LLM 智能体之间的合作学习：

- **Knowledge Transfer**：Pioneer 首先根据查询生成响应，Observer 随后基于查询和 Pioneer 的响应生成自己的响应。这种顺序交互促进了知识转移，Observer 利用 Pioneer 的输出来指导自己的生成过程，可能因此产生更优的响应。

- **Role Exchange**：在训练过程中，Observer 可能会因持续接收结合原始查询和 Pioneer 响应的输入而产生提示偏差。为解决此问题，CORY 引入角色交换机制，定期交换 Pioneer 和 Observer 的角色，确保两个 LLM 智能体在训练过程中多次体验两种角色，从而在推理时可以独立使用任一 LLM 智能体。

其中观察者利用先驱者的输出来指导自己的生成过程，由于 LLM 的上下文学习能力，这可能导致生成更优的响应。

$$r_{\text{CORY}}(s_0, a_1, a_2) = r(s_0, a_1) + r(s_0, a_2)$$
