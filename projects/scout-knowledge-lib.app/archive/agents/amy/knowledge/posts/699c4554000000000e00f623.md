# 1． CLAUDE. md: 项目的"宪法"

　　什么是 CLAUDE.md？

　　CLAUDE.md 是每个会话都会自动加载的持久上下文文件。你可以把它理解为项目的"宪法"——这里写的是 Claude 必须始终遵守的规则。

　　核心特点

　　应该放什么内容？

✅ 适合放入 CLAUDE.md 的内容：

* · 编码约定（命名规范、文件结构）

* · 构建命令和测试流程

* · "永远不要做 X"的规则

* · 项目特定的术语和缩写

[Slide 5]
* · 技术栈选择（"用 TypeScript 不用 JavaScript"）

❌ 不适合放入 CLAUDE.md 的内容：

* · 长篇 API 文档

* · 偶尔需要的参考资料

* · 可以按需触发的工作流

# 2． Skills：可重用的知识和工作流

　　什么是 Skills?

　　Skill 是一个包含知识、工作流或说明的 Markdown 文件。它是 Claude 工具包中的额外功能，可以通过斜杠命令（如 /deploy）调用，也可以由 Claude 在相关时自动加载。

　　核心特点

　　Skills 的两种类型

　　类型 1：参考型 Skills

[Slide 7]
提供 Claude 在整个会话中使用的知识。

类型 2：操作型 Skills

告诉 Claude 执行特定操作的工作流。

# 3． Subagents: 隔离的执行上下文

什么是 Subagents?

Subagent 是在隔离上下文中运行的独立工作者，具有自己的上下文窗口，只向主对话返回摘要结果。

核心特点

何时使用 Subagents?

✅ 适合场景：

* · 上下文隔离需求（处理敏感数据）

* · 并行任务（同时研究多个问题）

* · 读取大量文件但只需要摘要

* · 专门工作者（代码审查、文档生成）

❌ 不适合场景：

[Slide 9]
* · 需要看到中间工作过程

* · 简单的单一任务

* · 需要与主对话频繁交互

Subagent vs Skill：核心区别

理解二者的关键区别：

* · Skills 是"给主对话看的说明书"

* · Subagents 是"派出去干活的专员"
