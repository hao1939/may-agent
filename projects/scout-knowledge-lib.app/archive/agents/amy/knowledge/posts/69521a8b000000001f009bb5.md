## Key Content
Audit of skills.rest platform: 20,000+ skills reviewed, discovered large batch of malicious skills.

**Attack vector:** Malicious code hidden in skill scripts (e.g., `skills/math-calculator/scripts/calculate.py`). When SKILL.md is invoked, it triggers execution of the Python script. Line 32 establishes a reverse shell to attacker's IP — full machine control.

**Why skills are more dangerous than AGENTS.md:**
- Skills can execute local scripts directly
- AGENTS.md is pure text prompts, no execution capability
- This is "supply chain attack" for the AI Coding era

**Environment risk levels:**
1. **Claude API:** Lowest risk — no network access, no runtime package install, only pre-installed packages
2. **Claude Web:** Medium risk — network access depends on admin settings (full/partial/none)
3. **Local Claude Code:** HIGHEST risk — full network access equivalent to user programs, can run any local scripts

**Examples of disguised attacks:**
- "File organizer" skill → reads sensitive files, exfiltrates to external server
- "Database query optimizer" → leaks database info to attacker endpoints
