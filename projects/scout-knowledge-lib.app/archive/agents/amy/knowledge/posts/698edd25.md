## ⭐ 公众号内容自动化全流程

### 场景
```
程序员副业：白天写代码，晚上运营公众号
追热点+选题+写稿+排版 → 每天3-4小时 → 压到<1小时
```

### 技术架构
```
调度：OpenClaw（多Agent各管一摊）
Skills：21个，覆盖选题→发布全流程
入口：Telegram Bot（手机操作）
驱动：定时任务（不需要手动触发）
存储：Obsidian（选题和素材，便于回溯）
```

### 四步流程
```
① 热点自动扫（Hacker News/Reddit/Product Hunt → TG推送）
② 选题卡片生成（从几十条热点挑出值得写的，含角度+标题备选）
③ 初稿+配图自动生成（按个人风格）→ 人工润色
④ 直接推公众号草稿箱（含封面图+排版）→ 检查→一键发布
```
