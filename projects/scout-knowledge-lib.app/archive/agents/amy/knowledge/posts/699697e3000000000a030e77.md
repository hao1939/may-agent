## 安全配置命令（可直接使用）

### 1. 网关安全（openclaw.json）
```json
{
  "gateway.mode": "local",
  "gateway.bind": "loopback"
}
```
- ✅ 永远不要把 gateway 绑定到 0.0.0.0/公网
- 需要远程访问: 走隧道/VPN/反代白名单

### 2. 沙箱配置（推荐折中方案）
```json
{
  "agents.defaults.sandbox.mode": "non-main",
  "agents.defaults.sandbox.scope": "session",
  "agents.defaults.sandbox.workspaceAccess": "none"
}
```
- `non-main` = 主会话在宿主机，其他会话进沙箱
- `scope: session` = 每会话一个容器，隔离更强
- `workspaceAccess: none` = 沙箱看不到真实workspace（最安全）

哪些进沙箱: `exec/read/write/edit/process` 等工具调用（Gateway进程本身不进）

### 3. 权限控制
- Channel权限: allow list模式，只设置`view channel`与`send message`
- 遵循"Restrict DM policies / default-deny"原则
- 工作区: 避免存密钥，引用官方文档: "**Keep it private and treat it as memory**"

1. `gateway.mode: "local"` + `gateway.bind: "loopback"` ← **新的安全配置键**

3. `agents.defaults.sandbox.workspaceAccess: "none"` ← **最强隔离**
4. "Keep it private and treat it as memory" = 官方文档原话 ← 重要安全原则
5. **Docker容器沙箱** = 不是完美安全边界，但能"显著降低爆炸半径" — 坦诚表述
