## Peter Steinberger 原话整理

### 核心理念
```
最核心建议只有一个字：play（玩）
"那些试图把所有事情自动化的人，做出来的东西缺少风格、缺少爱、缺少人味。"
"编程作为一种手艺正在消亡，但构建（building）作为一种能力正在爆发。"
"以后这就叫coding了，只是coding的意思变了。"
```

### Q1：Agentic Engineering vs Vibe Coding
```
Agentic Engineering（清醒状态）：
  理解Agent视角 | 引导看正确的文件 | 讨论架构
  让Agent在合理范围内自主 | review结果并触发重构
  需要：同理心 + 系统思维

Vibe Coding（凌晨三点）：
  不管不顾让Agent随便写 | 第二天收拾残局
  只需要：咖啡因
```

### Q2：OC为什么赢过竞品
```
Peter原话："因为他们都太把自己当回事了。"
设计决策：追求delight（愉悦感）而非enterprise-ready（企业级）
  龙虾logo | soul.md（灵魂文件）
  Agent能修改自身源码
  Heartbeat主动关心用户
结果：175,000人自发点star
```

### Q3：普通人如何加入
```
"找一个你想解决的问题，用Agent去做。"
"不需要完美，不需要懂底层原理。做完一个，做下一个。"
"这就像学吉他——不弹就永远不会。"
"你现在有一个无限耐心的老师，问就行了。"
给程序员：不要再自我定义为iOS工程师/后端工程师，你是builder。
"这个身份在Agent时代比任何技术栈标签都值钱。"
```
