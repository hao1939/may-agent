阿东今天给大家分享一个值得关注的开源模型——MiroMind团队刚发布的 MiroThinker v1.0，这是一款智能体基座模型，最大的创新点在于提出了全新的Scaling维度："深度交互Scaling"。
	
💡 核心创新：重新定义AI进化路径
传统Scaling Law的逻辑是"更多数据+更大参数=更强模型"，但这条路已经接近瓶颈。MiroThinker提出的"深度交互Scaling"换了个思路：让AI在环境中反复"试错"和"反思"，通过交互深度提升推理和决策能力。简单说就是"实践出真知"，对AI同样适用。
	
🔥 三大技术亮点
1. 超长交互能力：256K上下文窗口 + 支持600轮工具调用，不只是"看得长"，更能像人类一样"持续思考+动手试错"。
2. 性能炸裂：
BrowseComp测试达47.1%，逼近OpenAI DeepResearch的51.5%
HLE测试37.7%，超越GPT-5-high的35.2%
中文任务比DeepSeek-v3.2高出7.7个百分点
72B版本性能已跻身第一梯队
3. 彻底开源：模型权重、工具链、交互框架全部开放，真正赋能社区。
	
🎯 为什么值得关注？
MiroThinker突破了传统LLM对"上下文长度"和"有效交互轮数"的限制。它不是简单的大力出奇迹，而是通过环境交互的深度和广度实现能力跃迁。这个方向与Ilya Sutskever在NeurIPS 2024的判断一致：预训练时代即将终结，下一阶段是智能体的推理、自主学习和自我进化。
MiroMind团队仅成立半年就达到SOTA级性能，更重要的是验证了"深度交互"这条技术路线的可行性。从"被动执行的工具"到"主动学习的伙伴"，这才是AI应该走的方向。

## 🚀 Try our Demo!

> **MiroThinker** is the official implementation of the MiroMind Research Agent Project. It is an open-source research agent designed to advance tool-augmented reasoning and information-seeking capabilities, enabling complex real-world research workflows across diverse challenges.

The project currently comprises four key components:

- 💡 **MiroThinker**: An open-source research agent model that natively supports tool-assisted reasoning, achieving state-of-the-art performance across multiple benchmarks (e.g., HLE, HLE-Text-2158, HLE-Text-500, BrowserComp, BrowserComp-ZH, GAIA, xBench-DeepSearch, FutureX, and Frames). See Quick Start.

- 🧑‍💻 **MiroFlow**: An open-source research agent framework that offers reproducible state-of-the-art performance across multiple benchmarks. See MiroFlow for details.

- 📚 **MiroVerse**: A premium open-source training dataset with 147k samples supporting research agent training. See MiroVerse on HuggingFace.

- 🔧 **MiroTrain / MiroRL**: Training infrastructure that supports stable and efficient training for research agent models. See MiroTrain and MiroRL for details.
