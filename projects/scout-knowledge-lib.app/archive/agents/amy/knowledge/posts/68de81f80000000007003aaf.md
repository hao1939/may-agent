## Full Text
✨ 欢迎关注我们UIUC, Stanford, AMD团队的新工作：《AgentDebug: Where LLM Agents Fail and How They Can Learn From Failures》,LLM Agents 尽管具备强大的规划、记忆、反思与工具使用能力，却依旧频繁出现 cascading failures（级联失败），例如早期错误持续扩散，最终导致任务失败,当前缺乏系统化机制来定位 agent 失败的“根本原因”，更无法给予 agent 有效反馈，辅助其自主修复🔥 我们提出 AgentDebug 框架，开启 LLM Agent 可解释 Debugging 新范式：
🧩 AgentErrorTaxonomy：模块化错误分类体系，覆盖记忆 / 反思 / 规划 / 执行 / 系统五大模块
📊 AgentErrorBench：首个系统标注失败轨迹的数据集，涵盖 ALFWorld、GAIA、WebShop 三大基准
🔧 AgentDebug 框架：训练 free 的三阶段调试器，精准定位 root-cause errors 并生成逐步纠错反馈
📈 效果亮眼：
在 AgentErrorBench 上，AgentDebug 的 all-correct 识别精度比最强 baseline 提高了 24%, 在下游任务中实现 最高 26% 的任务成功率提升，显著优于 Self-Refine / Tree-of-Thought / Best-of-N 等方法,支持多种 backbone（GPT-4o-mini, Qwen3-8B, Qwen3-Next-80B），小模型收益尤为明显
📃 论文：arxiv:2509.25370
💥 AgentDebug 揭示了 “早期误差传播” 是 LLM Agent 失败的关键瓶颈，首创 root-cause tracing + iterative feedback 的 agent debugging 流程，是构建更可靠 agent 的重要一步！欢迎来挑战 AgentErrorBench，看看你的 Agent 能否从失败中真正学会成长？
