## Skill 哲学（最有价值部分）

```
Skill = 教给Agent的一套工作流程（不是能力扩展，而是偏好固化）
"Skill的价值在于让它嵌入具体工作流"
"装太多Skill → Agent不可预测，不知道什么时候用哪个 → 系统混乱"
```

### 调教Skill的正确流程（每周信案例）
```
1. 让Agent执行任务（写周信）
2. 第一版：语气太正式，说"更像朋友聊天，少总结陈词，多具体观察"
3. 第二版：段落太长，说"每个要点单独成段，控制三四句话以内"
4. 反复迭代直到符合预期
5. 让它把这些规则保存为Skill

→ "让AI帮你定制专属Skill才是最聪明的玩法"
```

### 核心观点
```
"跟OC沟通，本质是跟新员工沟通：做了不对的事纠正它就会记住，
 告诉它你的偏好它就会学会"
Skill = 把未来经常用到的流程固定下来的容器
```
