## Multi-Agent vs Sub-Agent 权威对比

| 对比项 | Multi-Agent | Sub-Agent |
|--------|-------------|-----------|
| 本质 | 独立正式员工 | 临时实习生 |
| Workspace | 有完整Workspace | 无独立Workspace |
| Session Store | 永久保存 | 临时，任务后可删 |
| 记忆 | 完整长期记忆 | 只有本次临时记忆 |
| 生命周期 | 永久存在 | 任务完成即结束 |
| 配置方式 | agents.list + bindings | sessions_spawn(task) |
| 适用场景 | 严格隔离/多人共享/成本优化 | 后台研究/并行多任务/长时任务 |

---

## 应用场景示例（自由职业者三个AI分身）
```
日常Agent: 微信 + Sonnet($3/M) → 闲聊/查天气，性格俏皮
投资Agent: Telegram + Opus($15/M) → 股市分析，性格谨慎
网店Agent: 飞书 + Sonnet($3/M) → 客服应答，性格高效
```
**核心优势: 成本优化省50%-70%（社区数据）**
