## Heartbeat vs Cron 核心对比表

| 对比项 | Heartbeat | Cron |
|--------|-----------|------|
| 本质 | 定期巡查 | 定时执行 |
| 触发方式 | 有事才通知 | 到点必执行 |
| 时间精度 | 约每30分钟 | 精确到分钟 |
| 运行环境 | 主会话(有记忆) | 隔离运行(无干扰) |
| 模型选择 | 使用主会话模型 | 可指定不同模型 |
| 典型场景 | 检查邮箱/日历 | 发晨报/周报 |
| 没变化时 | 保持安静 | 照样执行 |
| 成本 | 一次查多项(省钱) | 每任务独立运行 |

**记住两句话:**
- Heartbeat: "看看有没有事" → 有事才说
- Cron: "到点就做事" → 到点必做

---

## Heartbeat特性
```
✅ 批量打包: 邮箱+日历+天气 一次全查，不用建5个任务
✅ 有记忆: 知道你最近在忙什么，能判断轻重缓急
✅ 聪明安静: 深夜营销邮件? 自动忽略，不敲门
```

## Cron特性
```
✅ 时间精确: 8点就是8点，不会漂到8点15
✅ 独立运行: 后台干活，不刷屏聊天
✅ 灵活配置: 简报用便宜模型，深度分析用贵模型 ← 成本优化关键
```

## 打工人的一天（最佳实践示例）
```
08:00 🟠 Cron     → 发晨报(天气+日程+邮件摘要)
10:30 🟢 Heartbeat → 发现11点有会，提醒准备材料
14:00 ⚫ Heartbeat → 巡逻无事，安静
17:00 🟠 Cron     → 发日报(今日工作总结)
22:00 ⚫ Heartbeat → 深夜值守，不打扰

全天只收3条消息，不被AI刷屏
```

## 选择决策树
```
需要精确时间? YES → Cron
需要独立运行? YES → Cron(隔离)
能和其他检查打包? YES → Heartbeat
一次性提醒? YES → Cron --at
以上都不是? → Heartbeat(默认)
```
