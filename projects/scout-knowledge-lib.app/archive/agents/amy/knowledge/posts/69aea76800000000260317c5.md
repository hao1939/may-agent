## Content
SkillsBench — first benchmark specifically evaluating Agent Skills effectiveness. Conducted by 105 researchers from Stanford, CMU, UC Berkeley, and 30+ institutions. Covers 84 tasks, 11 domains, 7 model combinations, producing 7,308 evaluation trajectories.

### Four Core Findings:
1. **Human-written skills boost pass rate by +16.2 percentage points** — carefully crafted skill documents significantly improve agent performance
2. **AI-generated skills are nearly worthless** — average -1.3 percentage points, actually HURTS performance
3. **"Less is more"** — 2-3 focused modules outperform comprehensive long documents
4. **Small model + good skills > large model without skills** — skills are a force multiplier that can compensate for model size

### Hidden Finding (in appendix):
Analyzed 47,150 real community skill documents. **Average quality score: 6.2/12.** The benchmark used top 25% quality skills. The +16.2pp result is best-case. **Bad skills don't just fail to help — they actively make AI perform worse.**

## Key Community Insights
- **elsa (11❤️):** "不是'有 skill 就行'，而是得短、准、真能贴着任务走" — Not "having skills is enough" but they must be short, precise, and task-aligned. Many people write skills like product manuals. "模型还没干活先被你讲困了" — the model falls asleep reading before it starts working.
- **nono:** Long skills usually contain garbage or errors that humans haven't audited. Feeding garbage in → garbage out.
- **一级棒的饲养员:** Understanding context mechanism is prerequisite for good skill writing. But Claude is smart enough to self-optimize if given the official skill guide.
