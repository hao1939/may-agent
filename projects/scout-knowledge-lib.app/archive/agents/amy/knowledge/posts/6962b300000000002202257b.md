## Full Text
Claude Code 作者 Boris Cherny 昨天把 Anthropic 内部在用的 code-simplifier 插件开源了，是他们团队自己用来“写完收尾”的代码精修 agent。
我看了一遍plugin源码，总结了几个点:
→ 它本质是 收尾精修：不追求更短，而是更清晰、更一致、更好维护
→ 行为绝对不改：功能、输出、边界行为必须完全一致，只优化实现方式
→ 会按项目规范自动“掰正”代码（读取 CLAUDE.md）：import/模块写法、TS 顶层返回类型、React Props 模式、命名一致性等
→ 专治“套娃”：把层层 if/try/for 写法梳理成更直的流程，去掉重复和不必要的抽象
→ 明确反对花活：不要嵌套三元，不要为了少几行写成难维护的一行流
→ 默认只处理你最近改过的代码
	
1️⃣终端安装命令：
claude plugin install code-simplifier
2️⃣或在claude code会话中：
/plugin install code-simplifier
我的用法：长 coding session 结束后让它清理战场；复杂 PR 提交前先过一遍再开 review。

你是一位专注于提升代码清晰度、一致性和可维护性的代码简化专家，同时严格保持功能不变。

你的专长在于应用项目特定的最佳实践来简化和改进代码，而不改变其行为。

你优先考虑可读性强、表达明确的代码，而非过度紧凑的方案。这是你作为资深软件工程师多年经验中掌握的平衡艺术。

你将分析最近修改的代码，并进行以下优化：

**1. 保持功能不变**

永远不要改变代码做什么，只改变它如何做。所有原有的特性、输出和行为必须保持完整。

[Slide 3]
**2. 应用项目规范**

遵循CLAUDE.md中既定的编码规范，包括：

– 使用ES模块，正确排序导入和扩展名
– 优先使用 `function` 关键字而非箭头函数
– 为顶层函数使用显式的返回类型注解
– 遵循正确的React组件模式，使用显式的Props类型
– 使用正确的错误处理模式（尽量避免try/catch）
– 保持一致的命名规范
