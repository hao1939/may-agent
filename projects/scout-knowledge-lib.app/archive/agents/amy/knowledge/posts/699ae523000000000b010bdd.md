## 完整五步配置流程（阿里云服务器实测）

### Step 1: 飞书开放平台
- 「企业自建应用」→【创建企业自建应用】
- 添加「机器人」能力，权限按需勾选
- 复制 App ID 和 App Secret 备用

### Step 2: 服务器创建Agent
```bash
openclaw agents add technique-expert
```
**OCR截图揭示的交互选项**:
- 确认工作目录: `/home/admin/.openclaw/workspace-technique-expert`
- "Copy auth profiles from main?" → **选Yes** (Kimi密钥等自动复制)
- "Configure model/auth for this agent now?" → **选No** (已从main同步)
- "配置飞书?" → **选No** (已经配过飞书accounts和bindings路由)
- 显示 Agent ready → 创建完成

### Step 3: 角色&路由配置
```bash
vi ~/.openclaw/workspace-technique-expert/SOUL.md
```

飞书账号配置 (`channels.feishu.accounts`):
```json
"<agent名>": {
  "appId": "你的App ID",
  "appSecret": "你的App Secret",
  "domain": "feishu",
  "enabled": true
}
```

bindings路由配置:
```json
{
  "agentId": "<agent名>",
  "match": {
    "channel": "feishu",
    "accountId": "<agent名>"
  }
}
```

重启网关生效:
```bash
openclaw gateway restart
```

### Step 4: 飞书后台配置
- 「事件与回调」→ 订阅方式选**【使用长连接接收事件】**
- 添加事件: `im.message.receive_v1`
- ⚠️ **每次改飞书后台配置都要发布版本，否则不会生效！**

### Step 5: 测试验证
飞书给新创建的机器人发消息，能正常收到回复就完成了。

## 踩坑小贴士
- 收不到消息先检查消息权限
- 改完 `openclaw.json` 一定要重启网关 (`openclaw gateway restart`)
- "整套配置流程现在已经可以用AI全自动化完成"
