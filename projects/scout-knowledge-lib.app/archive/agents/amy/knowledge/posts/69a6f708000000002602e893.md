## Content
ByteDance security team published analysis of skill poisoning cases in OpenClaw. Author realized skill poisoning is far more severe than imagined. Had uninstalled OpenClaw initially due to high permission requirements, then used cloud version — but skill problems are equally severe.

**Recommended defense:** Install `skill-security-auditor` skill first (manually audit this one skill), then add safety rules to AGENTS.md:
- Before installing any new skill, must run `skill-security-auditor` audit
- Skills with risk score >40 should not be installed
- Don't exfiltrate private data
