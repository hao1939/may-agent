## 核心原则
**capture = 发消息，retrieval = 搜索**
"每个笔记App最终都变成苦差——整理的摩擦大于遗忘的代价"

## 工作流
1. Telegram/iMessage/Discord随时发：
   `"Remind me to read 'Designing Data-Intensive Applications'"`
   `"Remember: John推荐了5th street那家餐厅"`
2. OC内建记忆系统永久存储
3. 让OC自建Next.js搜索面板：
   ```
   Build a second brain dashboard in Next.js:
   - 所有记忆+对话的可搜索列表
   - 全局搜索（Cmd+K）
   - 按日期/类型筛选
   - 干净极简UI
   ```
4. OC自动构建并部署→给你URL→Done

## 三个关键洞察
1. **零摩擦捕获** — 不需要开App/选文件夹/加标签，就是发消息
2. **累积效应** — 越用越强，记住你告诉过它的一切
3. **"你在手机发消息，它在电脑上构建"** — 对话即界面
