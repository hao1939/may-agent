| **实验频率** | 每小时约12个实验 | 可控迭代速度 |

**关键洞察:**
> "氛围编程是AI帮你做你已经知道要做的事，你是产品经理。autoresearch是AI去探索你不知道答案的事，你是研究总监。"

| 边界 | 完全禁止 | 明确约束下的有限探索 |
| 回滚 | 无 | git版本控制 |
| 目标 | 安全优先 | 研究效率 |
| 人类角色 | 规则制定者 | 研究总监(编程程序者) |

**可能的路径:**
- **审计沙盒** + 固定预算 + 可回滚 = 有限实验空间

### 关键洞察 1: REOPOLD策略蒸馏 — 松弛模仿的新范式

**LLM 翰林院** — 8赞/11收藏
**论文**: arXiv:2603.11137v1

**核心创新:**
传统策略蒸馏是严格模仿教师行为，REOPOLD将其视为**策略优化问题**：
- 教师-学生对数似然比 = 奖励标记
- 混合奖励裁剪 + 熵基动态采样

**效果:**
| 指标 | 提升 |
|------|------|
| 样本效率 | 6.7~12倍 |
| 模型压缩 | 7B = 32B教师 |
| 推理速度 | 3.32倍 |

**对我们的意义:**
- 蒸馏方向可能改变模型选型策略
- 小模型+蒸馏 = 大模型效果

### 关键洞察 2: Agent最小架构 — 3模块极简设计

**Codex&Openclaw** — 23赞/52收藏

**三模块架构:**
```
LLM (推理核心) + Tool System (能力扩展) + Agent Loop (控制循环)
```

**与"六要素工程约束"的关系:**
这是同一思想的不同抽象层级：
- **六要素**: 从实现角度定义(状态、工具、记忆、权限、观测、回滚)
- **三模块**: 从架构角度定义(LLM、Tool、Loop)

**完全验证我们的设计:**
| 最小架构 | 我们的实现 |
|----------|-----------|
| LLM | Runtime LLM推理 |
| Tool System | Skill系统 + Gateway层 |
| Agent Loop | Channel编排 + 状态管理 |
