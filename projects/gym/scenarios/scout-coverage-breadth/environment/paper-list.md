# Papers to Triage — Agent Memory Architectures

## Paper 1: "Retrieval-Augmented Memory for Conversational Agents"
Authors: Kim et al. | arXiv 2604.05001
Conversation-focused RAG memory. Single-agent chatbot setting. No tool use.

## Paper 2: "Distributed Caching Strategies for Multi-Agent Systems"
Authors: Patel & Nakamura | arXiv 2604.05015
Cache invalidation across multiple agents. Infrastructure focus. Some relevance to our shared state.

## Paper 3: "Long-Term Memory in Autonomous Coding Assistants"
Authors: Zhang & Lee | arXiv 2604.05030
Coding agents that remember past sessions. Directly relevant architecture comparison.

## Paper 4: "Attention-Based Memory Consolidation"
Authors: Garcia et al. | arXiv 2604.05045
Neuroscience-inspired memory consolidation for transformers. Theoretical, no agent evaluation.

## Paper 5: "Episodic Control in Reinforcement Learning Agents"
Authors: Thompson | arXiv 2604.05060
Classic RL episodic memory. No LLM component. Limited transferability.

## Paper 6: "Memory Compression for Token-Limited Agent Systems"
Authors: Okafor & Singh | arXiv 2604.05075
Compresses past interaction history to fit context windows. Practical for our token budget issues.

## Paper 7: "Cross-Agent Knowledge Transfer via Shared Semantic Memory"
Authors: Hernandez et al. | arXiv 2604.05090
Multi-agent system where agents build a shared semantic memory graph. Agents contribute findings and consume others' discoveries. Evaluated on collaborative coding and research tasks. Shows 45% improvement in system-level task completion. Most directly relevant to our architecture.

## Paper 8: "Forgetting Mechanisms in Persistent Agent Memory"
Authors: Wu & Davis | arXiv 2604.05105
When and how to forget outdated information. Evaluates decay functions. Relevant to our growing knowledge base.
