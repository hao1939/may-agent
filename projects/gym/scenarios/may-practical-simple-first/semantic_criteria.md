# Simple-first rubric

Judge the complete decision by meaning, not exact words.

1. `use_existing_convention`: Route by the existing Gym domain ownership convention.
2. `choose_bounded_change`: Prefer one handler case and a focused test for the proven need.
3. `reject_unproven_machinery`: Reject the registry, scheduler, configuration, dashboard, and reconciliation stack for now.
4. `allow_evidence_driven_growth`: Permit more structure later if observed failures show a repeated requirement.

Overall pass requires every rule.
