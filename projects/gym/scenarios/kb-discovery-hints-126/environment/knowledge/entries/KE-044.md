# KE-044: Response Time Percentile Analysis

**Type**: Knowledge Entry
**Created**: 2026-03-25
**Sources**: EXP-131, production monitoring
**Status**: Active

## Key Findings

P50 response times mask significant P99 tail latency issues. Our standard "average
response time" metric has been misleading because cache hits (fast) dominate the
average while cache misses (slow) create 5-10s tail latencies.

EXP-131 measured P50=42ms, P95=380ms, P99=2100ms for the current architecture.
The cache-first approach (EXP-142 validation pending) is expected to compress this
distribution significantly.
