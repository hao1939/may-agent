# RKE-011: Forced Externalization Improves Judgment Quality

**Status**: PENDING VERIFICATION
**Confidence**: 85%
**Created**: 2026-03-22
**Needs**: Additional evidence from non-judgment tasks

## Finding

When agents are forced to write their analysis to a file before acting (forced externalization), judgment quality improves by +74pp on average. The mechanism appears to be that writing activates systematic thinking, preventing reactive/impulsive decisions.

## Key Data

- 19/19 judgment scenarios improved with forced externalization
- Average improvement: +74pp (from ~20% to ~94%)
- Works across 7 different scenario types

## Pending Verification

This finding is well-supported for JUDGMENT tasks, but needs verification on:
1. Non-judgment tasks (debugging, code generation)
2. Tasks where speed matters more than accuracy
3. Multi-session scenarios where externalization adds overhead

## Mechanism Hypothesis

Writing forces the agent to:
1. Articulate its reasoning explicitly (catches gaps)
2. Consider alternatives before committing
3. Create a record it can review (reduces working memory load)
4. Slow down impulsive tool-calling patterns
