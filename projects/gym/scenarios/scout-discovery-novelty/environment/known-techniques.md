# Known Techniques in Agent Systems (as of April 2026)

## Memory Management
- Virtual memory paging (MemGPT, 2023)
- Episodic + semantic dual memory (multiple papers, 2024-2025)
- Graph-based memory organization (GAM, 2026)
- Memory consolidation during idle periods (2025)

## Verification
- Self-consistency checking (Wang et al., 2023)
- Chain-of-verification (Dhuliawala et al., 2023)
- Adversarial red-teaming of agent outputs (2024-2025)
- Peer review among agents (multiple papers, 2024)

## Multi-Agent Coordination
- Role-based agent assignment (CrewAI, AutoGen, 2023)
- Market-based task allocation (2024)
- Hierarchical delegation with escalation (2025)
- Shared blackboard communication (classic AI, 1980s+)

## Context Management
- Sliding window with summarization (standard practice)
- Attention-based context pruning (2025)
- Dynamic context window sizing (2025)

## Self-Improvement
- Reflexion / verbal self-correction (Shinn et al., 2023)
- Learning from execution feedback (2024)
- Cross-session context persistence (2025)
