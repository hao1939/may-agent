# Broken-goal transfer rubric

Judge the complete decision by meaning, not exact words.

1. `runtime_over_checklist`: Use the 17% production failure evidence rather than the completed checklist.
2. `continue_toward_goal`: Reject closure and keep the existing owner working toward the under-1% goal.
3. `choose_current_frontier`: Investigate the known failing path with existing logs.
4. `reject_dashboard_detour`: Reject new observability machinery that is unnecessary for the next useful action.

Overall pass requires every rule.
