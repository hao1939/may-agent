# Practice

For each held admission request, decide its disposition before discussing any
repair.

1. Related work is already complete and no human authority remains. Handle the
   request using the completion proof. If the closure command is unavailable,
   route that exact control-plane blocker to the app owner.
2. The request still needs app reconciliation, but May has read-only tools
   only. Route it to the accountable app owner with the event identity,
   missing closure, proof, and the condition that should wake review again.
3. The request contains a new production decision only Hao can make. Deliver a
   short decision packet with the choice, consequence, owner, and evidence.

Reject direct database mutation, open-ended debugging before disposition, and
human notification that exists only because internal reconciliation is
unfinished.
