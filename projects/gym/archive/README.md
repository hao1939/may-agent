# Gym Archive

This directory contains frozen historical evidence that remains useful for
audit but is not consumed as current runtime state.

- `legacy-results.jsonl` — aggregate results imported from the original Gym
  location.
- `experiments/` — retired experiment runners, logs, and result snapshots.

New run databases, transcripts, generated reports, and caches belong in the
ignored `.state/` directory. Approved benchmark labels and append-only human
adjudications remain version-controlled with their benchmark.
