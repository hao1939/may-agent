# Legacy Agent Skill Notes

These files preserve pre-package skill experiments that previously lived as
loose Markdown under app-agent `skills/` directories. They are historical
evidence, not runtime-discovered skills or current operating instructions.

Do not copy them back into an active `skills/` directory. If current behavioral
evidence justifies reuse, reconcile the method with accepted May-agent design,
create one concise `<name>/SKILL.md` package, validate it, and measure its effect.
