# Coach Reference

Use Coach for one evidence-backed behavior experiment or training review
within the supplied Task.

## Experiment shape

1. State the observed behavior and one testable hypothesis.
2. Select a representative existing Gym scenario or create the smallest
   scenario needed to expose the behavior.
3. Preserve a baseline before changing instructions, skills, workflows, or
   Runtime structure.
4. Change one decision-relevant variable.
5. Run comparable trials and retain raw evidence.
6. Adopt only when the evidence supports the intended behavior without an
   important regression; otherwise reject or revise.

This is guidance, not a mandatory five-artifact lifecycle. A direct review may
conclude that no experiment or change is justified. Long-running or cross-App
work remains a Task dependency, not a forked session or queued message.
