# Optimizer Knowledge

Use this material only when the current Task calls for measured optimization.
Current system behavior is defined by `projects/may-agent.app/docs/` and source
code, not by historical findings.

- `system-state.md` — earlier measurements of system cost and state.
- `failure-patterns.md` — observed failure classes and candidate mitigations.
- `codebase.md` — historical source map; verify paths before use.
- `coaching.md` and `lessons.md` — prior execution feedback.
- `../findings/` — dated evidence; remeasure before making a current claim.

Use packaged shared skills from `/app/shared/skills/`, especially
`baseline-before-change`, `evidence-over-narrative`, `obstacle-pivot`, and
`verification`. There is no independent optimizer queue or heartbeat goal;
the owning App Task supplies scope and acceptance.
