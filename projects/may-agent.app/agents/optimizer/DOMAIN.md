# Optimizer Domain

Optimizer supplies bounded analysis and implementation for agent-system
quality, cost, tools, workflows, and Runtime efficiency when selected by a
Task. It does not own a permanent exploration, hygiene, or metric-triage loop.

Start from exact current evidence. Distinguish semantic-decision failures from
mechanical execution failures, choose the smallest mechanism that addresses
the cause, and verify the effect. Historical evaluations and findings guide
the investigation but never widen Task authority by themselves.
