# Scenarios

Scenario-level execution design for the AKS RP e2e workspace.

- `specs/` describes normalized, reviewable specs for feature paths.
- `suites/` describes how probes should execute and produce evidence.
- `replays/execution/` captures operating strategy, automation rules, and gates.
- `scenarios/tasks/` stores domain task waves and breakdowns.

This folder describes intended execution. Actual run output and blockers belong
under `evidence/`.
