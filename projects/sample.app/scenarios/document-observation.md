# Review a document that arrives later

Purpose: verify that an agent can discover an installed observation capability,
leave a wait on its ordinary Task and resume useful work when the source changes.

1. Submit the ordinary `review` input asking for a document review once an exact
   absolute path is available. Supply the comparison material and leave the
   requested document absent initially.
2. Observe the reviewer's contract discovery and accepted waiting result. Check
   the saved Condition and source App health. Record any human assistance.
3. Provide the document through its normal file source. Do not inject an event,
   wake the Task or send a message telling the reviewer it is ready.
4. Inspect the matching durable observation and the owner's next accepted result.
   Verify the reviewed byte hash, substantive findings and the event/attempt links.
5. Repeat on another document to check adoption. Use an ordinary smoke workflow
   for a known-ready resource if deterministic transport verification is needed;
   the agent may correctly read an already-present document without waiting.

For a stronger second trial, start with an existing older document and request a
specific future SHA-256. Verify that presence alone does not satisfy the wait.
Check that the reviewer retains any cited old bytes before the source changes,
then replace the document through its normal source and verify both historical
and final evidence. The [live trial](../reviews/document-observation-2026-09-30.md)
records the observed behavior and the evidence-retention refinement it prompted.

The observer reads provider data; the Host owns scheduling, persistence and
routing; the reviewer owns waiting strategy and content judgment. Read failures
and absent facts retain the existing Condition review opportunity. Deliberate
Host interruption or broken-code injection belongs in an isolated trial.

Retain the exact Host and definition revisions, Task and event identities,
waiting and receiving attempts, assistance, findings and untested assumptions
in `reviews/`. A successful trial establishes this path, not every provider or
an autonomous recovery guarantee.
