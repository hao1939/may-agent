## 发现摘要
本次探索发现 5 个关键洞察：

1. **Agent Sandbox 架构** (LangChain CEO Harrison Chase)
   - Pattern 1 (Agent IN Sandbox) vs Pattern 2 (Sandbox as Tool)
   - Pattern 2 成为主流：API keys 留外、状态分离、只为执行付费
   - 安全洞察：sandbox 里 tool 权限不能超过 bash tool

2. **AI Skill 分层法** (Shiv)
   - 原子-分子-化合物三层模型
   - 渐进式放权：底层零容错 → 上层给空间
   - 生产力杠杆提升近百倍

3. **HyperMem** (中科院 arXiv:2604.08256)
   - 三层超图记忆架构 Topic→Episode→Fact
   - 超边建模高阶关联
   - 解决跨时间/片段/主题检索碎片化

4. **Agent-World** (RUC arXiv:2604.18292)
   - 环境-模型协同进化训练场
   - 2000+ 环境、2万工具、多环境 RL + 自动诊断
   - 超越开源 SOTA，多项击败顶尖商业模型

5. **Skill 能力治理** (XHS社区)
   - Skill 不只是工具接入，更是"能力治理"
   - 触发条件、输入验证、权限控制、审计追踪
