# KE-014 — Evaluations DB is canonical; `.state/evaluations/` is legacy/stale

## Claim
When checking **Session Evaluation pipeline liveness**, treat `.state/may.db` (table `evaluations`) as the canonical signal. The directory `.state/evaluations/` may remain stale even while DB writes are fresh.

## Evidence
- Heartbeat check (2026-04-08): `.state/may.db` contains `evaluations`; `MAX(createdAt)=1775617418077`.
- At the same time, `.state/evaluations/` newest files had mtimes around 2026-03-24.

## Impact
- Avoid false “pipeline is dead” alerts based solely on `.state/evaluations/` mtimes.
- Update any runbooks/criteria that still treat `.state/evaluations/` as authoritative.
