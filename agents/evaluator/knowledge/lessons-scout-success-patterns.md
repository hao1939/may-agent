# Scout Success Patterns

- Creative heartbeat sessions are genuinely valuable when they synthesize multiple recent findings into one new architectural rule with explicit downstream implications, not when they merely add another source summary.
- A blocked first finish(success) for missing post-write read-back is an efficiency penalty, not automatic evidence that the underlying deliverable lacks value, if the agent corrects it immediately and the artifact is substantive.
- Scout research sessions create real value when they convert fresh papers into connected knowledge entries tied to existing KEs, rather than stopping at standalone paper summaries.
- When a scout session updates a mutable workspace digest and later commits it, evaluate the committed snapshot for session quality if the live digest has drifted since the session.
- Scout can produce strong heartbeat value by turning internal operational failures into a reusable architectural test rule; credit the session when the new KE adds a concrete criterion (for example testing graceful idling / no-op behavior), not just a recap of the incident.
- In scout success-candidate research reviews, credit sessions that fetch fresh external paper results during the session and convert them into committed shared KEs with explicit local implications, even if HTTP/query-format issues or finish/read-back guards required one quick self-repair.
- In scout creative heartbeat reviews, also credit sessions that synthesize multiple recent internal KEs into a new benchmark, mechanism, or metric shift; substantive second-order synthesis is real novelty even without a fresh external fetch in that same session.
- When scout collapses several adjacent same-day KEs into a named evaluation paradox with explicit mitigation criteria (for example stateful fallback paths plus graceful idling), treat it as substantive new knowledge rather than a duplicate-shaped recap; the value is the sharper local design rule.
- For external exploration tasks, credit scout when a fresh fetch is narrowed to a few high-signal incidents and converted into durable shared KEs with explicit links back to local architectural constraints; brief finish/verification self-repair is only an efficiency blemish when the landed artifacts are substantive.
- When scout starts from an already noisy daily digest, real value comes from selecting one promising pattern and promoting it into a single durable KE with mechanism + implications; evaluate the committed KE as the primary output rather than penalizing the surrounding digest noise.
- When scout explicitly checks for same-topic saturation, decides not to deepen a stale thread, then pivots to one fresh external incident and maps it onto an existing local failure pattern, the resulting KE is often genuinely novel even inside a crowded same-day research thread.
- For short external-exploration tasks that end in a digest-only append, count the work as real but limited value when the agent fetches fresh high-signal incidents, summarizes them accurately, and ties them back to local guardrails; downgrade for redundancy when the digest already contains a near-duplicate section.
- In scout creative heartbeat reviews, do not require a new KE every time: when fresh external signal is synthesized into a rolling digest and explicitly mapped to an existing KE with a clear system implication, credit it as real value rather than ceremonial non-output.
- In scout creative heartbeat aftermath reviews, distinguish between a sharper second-pass synthesis and a true duplicate: if a new KE adds a clearer design rule, credit partial value, but downgrade novelty when a near-identical KE already exists from the same research thread and the session did not check for/update the existing entry.
- In scout creative heartbeat sessions, a same-day synthesis still counts as genuine value when it crystallizes a distinct local threat model with concrete may-agent implications, even if it extends an adjacent KE thread rather than introducing a wholly unrelated topic.
- A scout creative heartbeat can be a valid no-op when the transcript shows a bounded saturation check against the current digest and existing KEs, but score it as limited value unless it also leaves a durable artifact (for example a digest compression or explicit stop-note).
- When scout only reads the current digest/KE corpus, concludes no new synthesis is warranted, and lands no write/edit/commit/message, treat the outcome as acceptable bounded restraint rather than a material knowledge update; do not credit nearby digest or KE files unless the transcript itself shows they were produced in-session.
- When scout explicitly checks for KE saturation, verifies the action gap with a live requests query, and lands a committed digest note naming one highest-leverage implementation target, credit it as real value even without creating a new KE; the novelty is the process-correction from diagnosis sprawl to actionable prioritization.
