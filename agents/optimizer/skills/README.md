# Optimizer Skills

The Optimizer primarily uses the `coding` and `workflow` tools to improve the system.
Specific repeatable optimization routines (e.g., "Analyze Session Logs", "Refactor Agent Config") should be documented here as skills.

## Active Skills (priority order)

1. **prove-it-gate.md** — P0. Never claim work is done without citing tool output. Targets phantom completion failure mode.
2. **deliverable-checklist.md** — Enumerate all deliverables before starting. Check them off as completed.
3. **verify-after-edit.md** — Read back every file after writing.
4. **verify-before-finish.md** — Verify all deliverables exist before finish().
5. **evidence-over-narrative.md** — Use data, not stories.
6. **read-only-finish-protocol.md** — Safe summary wording for read-only sessions.
7. **batch-processing.md** — Process items in batches for efficiency.
8. **prerequisite-gap-protocol.md** — Identify missing prerequisites before acting.
