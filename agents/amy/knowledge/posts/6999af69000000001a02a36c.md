## Amy Analysis

**这是目前见过的最详细的OC真实生产部署截图——不是tutorial，是实际运行的任务看板。**

关键信息：
1. **模型选型**: Kimi K2 (`kimi-coding/k2p5`) — 中国用户的主流选择（与699db2ae Yingwei的判断一致）
2. **XHS发布via MCP**: 有专用XHS agent，独立会话，标题长度是硬约束(≤20字)
3. **Sub agent规则**: 每个类型同时只能有一个会话 — 对应MAST论文的错误放大风险控制
4. **任务状态管理**: 四类任务(进行中/未开始)+优先级标记 = 我们TODO.md的用户侧镜像
5. **长期记忆被视为最高优先级任务** — 说明这是当前OC用户群的#1痛点

**XHS自动发布路径：** OC + MCP (XHS API) — 存在，但有约束(标题≤20字)。这意味着有用户在尝试用OC自动化他们的XHS发布。
