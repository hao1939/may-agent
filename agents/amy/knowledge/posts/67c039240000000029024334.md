# 文章是怎么生成的？

x₂  x₃  y₁  y₂  ·  **待预测*y₃***

[神经网络图示：多层网络结构，底层输入为 x₁ x₂ x₃ y₁ y₂]

大模型的token是逐步一个接一个生成的，每一步都基于上文预测词表中概率最大的词进行输出，token顺序连接生成文章。

$$P(y_1) = P(y_1 | x_1, x_2, x_3)$$

$$P(y_2) = P(y_2 | x_1, x_2, x_3, y_1)$$

$$P(y_3) = P(y_3 | x_1, x_2, x_3, y_1, y_2)$$

# 把每个token的生成概率相乘

模型的输出是基于其训练数据中学习到的概率分布，选择最可能的token进行生成。

token概率相乘 = P(y₁)P(y₂)P(y₃)…P(yₙ)

**所以如果把大模型生成的每个token的概率相乘，这个值一定会很大，因为AI就是选择概率最大的词进行输出。**

我们把token生成概率的乘积取自然对数、求均值并取相反数后，通过指数运算的值称为困惑度（perplexity）：

$$\text{Perplexity} = \exp\left(-\frac{1}{N}\sum_{i=1}^{N}\log P(y_i|\ y_1, y_2, \ldots, y_{i-1})\right)$$

困惑度的核心是每个token的生成概率的乘积

[Slide 4]
# 3 困惑度来判断文章是否由AI生成

困惑度反映了语言模型对文本的惊讶、熟悉程度。因为给每个token的生成概率的乘积前加了负号，可以得出以下结论：

$$\text{Perplexity} = \exp\left(-\frac{1}{N}\sum_{i=1}^{N} \log P(y_i \mid y_1, y_2, \ldots, y_{i-1})\right)$$

**困惑度越低，模型对文本越熟悉，越不惊讶**

**困惑度越高，模型对文本越惊讶，越不熟悉**

AI生成文本的特点

AI生成的文本符合训练数据的分布，因此语言模型对其自己生成的文本困惑度较低，对人类的自然语言困惑度较高。

**泰哥总结：具体做法**

1. 将一篇文章输入自己部署的大语言模型

2. 对文章进行Mask，依次计算每个token的生成概率，然后计算困惑度

3. 设置阈值，若困惑度低于阈值，则大概率为AI生成；若困惑度高于阈值，则判定为人工书写
