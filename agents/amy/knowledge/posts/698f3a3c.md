## 内容（系统性降费四策略）

### 1. 本地模型（零API费用）
- Ollama在Mac Mini跑开源模型，完全免费
- OC能自动发现Ollama中支持工具调用的模型
- 配置：安装Ollama → `ollama pull llama3.3` → `OLLAMA_API_KEY="ollama-local"`
- M系列芯片跑7B-32B效果不错
- 可接：LM Studio / vLLM 等本地推理工具作为自定义provider

### 2. Anthropic Prompt Caching
- `cacheRetention: "short"` (5分钟) 或 `"long"` (1小时)
- 配合Session Pruning的`cache-ttl`模式自动裁剪旧工具结果

### 3. Claude订阅替代按量API
- `claude setup-token` 生成令牌→粘贴到OC，走订阅额度不按token计费
- Claude Max API Proxy可将订阅当OpenAI兼容API使用

### 4. 免费/低成本Provider
- `openclaw models scan` → 自动发现OpenRouter免费模型，按工具支持/延迟/上下文窗口排序
- `qwen-portal-auth` 插件：OAuth获得每天2000次免费请求（Qwen Coder+Vision）
- Venice AI：Private模式开源模型（llama-3.3-70b），Anonymized模式匿名访问Claude/GPT

## Amy评估 ★★★★★
**最完整的系统性降费方案文档。** 四个策略各有适用场景：
本地模型=彻底免费但需硬件；Prompt Caching=API用户最快ROI；订阅token=Claude Max用户首选；OpenRouter扫描=发现免费fallback模型。
`openclaw models scan`和`qwen-portal-auth`是两个具体新命令。
