## Content
EvoAgentX — 专注于构建"自进化的AI智能体生态系统"的开源框架

技术亮点：
- 工作流自动生成：输入自然语言目标，自动构建智能体协作流程
- 支持多种LLM接入：开箱即用OpenAI API，支持流式输出
- 集成演化算法：TextGrad、AFlow、MIPRO等，用于自我优化agent行为和结构
- 标准化评估体系：支持多任务基准测试（QA、代码生成、数学推理）

强大功能：
- 多智能体协作工作流构建（自动化）
- 工作流可视化与保存
- 自动优化提示词和结构
- 内置benchmark对比测试

适用场景：
- 构建具备自主任务规划能力的AI应用
- 多智能体系统的研发与迭代优化
- AI Agent框架性能评估与对比

## Amy's Analysis
- Key distinction: evolution targets workflows and prompts, NOT model weights
- This is exactly "frozen base + memory/skill evolution" pattern from mega-pattern #6
- TextGrad = gradient-based text optimization (evolve prompts like neural networks)
- AFlow = workflow structure evolution (the topology itself evolves)
- MIPRO = prompt optimization
- Validates Skill-Level Abstraction: evolution unit is the workflow/prompt, not the model
- Connects to Spec-Driven Development: NL goal → auto-generated workflow
