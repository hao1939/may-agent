## 核心方案：单Gateway模式

**"单 Gateway 模式 + 同一个 Bot + 不同飞书群组 = 物理隔离的专家团队"**

每个群里的Bot虽然看起来是同一个，但底层连接着不同的Agent、独立工作区、甚至不同的模型：
- 头脑风暴助手群 → `zai/glm-4.7`（中文创意能力）
- 公众号写手群 → `deepseek`（性价比+逻辑输出）

"同一个机器人，在不同群里，换个脑子干活。"

## 完整配置步骤

### Step 1: 添加新Agent
```bash
openclaw agents add work \
  --model zai/glm-4.7 \
  --workspace ~/.openclaw/workspace-work

openclaw agents set-identity --agent work --name "全能小秘书" --emoji "🤖"
```

### Step 2: 入职材料（SOUL.md + AGENTS.md + USER.md）
**"命令行给了Agent身体，这些文件赋予了它大脑和记忆"**

## 评论区关键洞察

**月球邮差(3赞 作者赞过)**:
> "openclaw的官方文档有写，可以调用session_send的方式进行agent间通信，**不要用session_spawn**。这样每个agent之间才是真正隔离，workspace和memory都是独立个体。"
> "openclaw决定使用文件而不是向量数据库管理本地记忆，是希望用户可以**手动编辑**"
> "现在飞书3个机器人，对应openclaw三个agent，一个调研一个设计一个写代码还是挺带劲的。"

**"飞书群里的Agent的Memory好像不能用"** — 重要确认！

**多机器人同群问题**: "两个机器人拉进一个群，艾特只能对其中一个有效？"
