```
"小到可以在8分钟内理解"

```

```
可在10美元硬件运行，内存<5MB

"零开销。零妥协。"
```

### PicoClaw（Go）— ⭐新发现

## Amy评估 ★★★★★
**迄今最完整的OC替代品全景，新增IronClaw/PicoClaw/TinyClaw三个此前未记录的项目。**

生态分化格局清晰：
- 学术/研究：Nanobot(Python,4k行)
- 极简理解：NanoClaw(TS,8分钟理解)
- 安全优先：IronClaw(Rust,WASM沙箱)
- 极限轻量：ZeroClaw(Rust,5MB) + PicoClaw(Go,旧Android)
- 团队协作：TinyClaw(TS,多代理+TUI仪表板)

momo的问题点出了核心：生态兼容性。OC的3000+技能库和活跃社区是护城河，替代品再轻量也难复制。
