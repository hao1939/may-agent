## 核心方案
> Bot正在执行长任务（写代码），想同时发另一个问题？
> **解决：不同Telegram Group = 并行Session！**
> OC把每个群视为独立"上下文"，群A写代码 / 群B翻译文档，互不干扰

---

## 三步配置

### ①修改openclaw.json
```json
{
  "channels": {
    "telegram": {
      "groups": {
        "*": { "requireMention": true }
      }
    }
  }
}
```
`requireMention: true` → 只有@它才回应，防止乱插话

**进阶**: 把`"*"`换成具体群ID → 该群不需要@即可回复
**获取群ID**: 把`@getidsbot`拉进群 → 它立刻报告ID → 踢掉

### ②关闭BotFather Privacy（99%不生效的原因！）
```
@BotFather → /mybots → 选Bot → Bot Settings → Group Privacy → Turn off
```

### ③把Bot拉进群，@Bot你的问题
