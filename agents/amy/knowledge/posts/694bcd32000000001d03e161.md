# 别再选错了！智能体的两大门派

ReAct vs. Workflow：
核心差异与选型思路

[Slide 2]
# 核心概念：智能体（Agent）

• AI智能体是能自主规划、调用工具并完成任务的人工智能系统。

• 其核心目标是实现复杂任务的自动化。

• 当前有两种主流的构建范式，它们代表了不同的设计哲学：

🔄 ReAct智能体　　🗂 工作流

[Slide 3]
# 范式一：ReAct智能体

• 🧠 ReAct智能体的核心是一个自主的"思考-行动"循环。

• 🖥 它在单一、连续的上下文窗口中运行，动态决定每一步操作。

• 🔀 优势在于灵活性极高，能自主应对复杂和不确定的任务。

[Slide 4]
# 范式二： 工作流

🧩 • 工作流将复杂任务分解为多个离散、有序的步骤（节点）。

🔷 • 每个节点功能专注，流程由预定义的图结构驱动。

🛡️ • 优势在于可控性强、可靠性高，流程清晰。

搜索 → 文档 → 检查

[Slide 5]
# 核心差异：信息管理方式

## ReAct智能体

📄 信息会不断累积，管理核心是做减法（如摘要、删除），防止信息过载。

---

## 工作流

🎯 为每个节点精准投喂所需信息，管理核心是做加法。

*(图中标注：节点1、节点2、节点3)*

[Slide 6]
# 核心差异：设计思维

## ReAct智能体

• 类似面向对象编程：状态集中，靠自身能力应对变化，但内部决策像黑盒，调试复杂。

## 工作流

• 类似函数式编程：通过结构设计分解复杂性，每个节点可独立测试，调试更简单。

[Slide 7]
# 如何选择与应用

🔆 •需要高度自主和创造性的任务（如探索性研究），宜选用ReAct智能体。

🛡️ •流程固定、要求高可靠性的任务（如数据报表生成），宜选用工作流。

⚙️ •现代复杂系统常融合两者，以兼顾灵活性与可靠性。
