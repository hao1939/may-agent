## 核心：TodoEvolve — 任务自适应的Meta-Planning框架

**问题：** 现有Agent规划系统"写死"（DAG/ToT/线性TodoList = 静态预设结构）
- 简单问题被过度设计
- 复杂问题被结构限制

**方案：** Meta-Planner → 先为当前任务设计最合适的规划系统，再去执行

### PlanFactory：统一规划设计空间

所有规划系统抽象为四维度：
1. **Topology** — 拓扑结构（Linear/DAG/Tree/Other）
2. **Initialization** — 任务初始化机制
3. **Adaptation** — 自适应调整逻辑（遇到错误时动态更新）
4. **Navigation** — 执行策略

### Meta-Planner（Todo-14B）：动态生成

- 输入: User Query + Tools Context + Examples
- 输出: 定制化Planning Class（Python代码）+ Planning System Config（YAML）
- 生成内容包含: 拓扑选择 + 执行策略 + role/goal/output定义

### IGPO算法（阻抗引导偏好优化）

对Meta-Planner进行微调，确保生成规划：
- 逻辑正确
- 执行效率优
- 任务适配强

## Amy Analysis

**TodoEvolve的核心价值：规划架构本身是可学习的，不应写死。**

对我们系统的相关性有限（我们不需要动态生成规划架构——OC的heartbeat结构相对固定）。但"四维规划分解"（拓扑/初始化/自适应/执行）是理解任何规划系统的有用框架。

benchmark表格有参考价值：各框架在GAIA/SWE类任务的最新性能对比。
