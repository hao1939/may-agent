## OC搜索原理（OC自述，Slide 1）

**当前无Brave API时的搜索方式:**
- `web_fetch` 直接抓Google/Bing搜索页 → HTML，不稳定，VPN IP经常空结果
- 浏览器自动化打开网页 → 慢，占资源，但最可靠

**配置Brave API后:**
- `web_search`工具直接可用，一次调用返回结构化结果（标题+URL+摘要）
- 速度快、稳定、不怕反爬
- 免费额度: **每月2000次查询**（$5免费credit，$5/1000请求）
- 不走浏览器，不占Chrome资源

### 搜索方式对比
| 维度 | 当前(web_fetch) | Brave API |
|---|---|---|
| 速度 | 慢（抓网页解析）| **快（结构化JSON）** |
| 稳定性 | 差（反爬/空结果）| **好** |
| 成本 | 免费 | 免费2000次/月 |
| 配置 | 无需 | 需要API key |

## 配置步骤
1. 去 `brave.com/search/api/` 注册
2. 绑定外卡（Visa/Mastercard，含虚拟卡），扣1USD验证，卡里存2USD
3. 选择`Search Plan`（Free计划，每月$5免费额度）
4. 设置usage limit防超用
5. 将API key写进OpenClaw配置

### 搜索提供商限制（评论区重要发现）
> **`runWebSearch`函数只支持`brave`和`perplexity`两个搜索提供商**
> (用户尝试加tavily: "无法直接修改OpenClaw代码，它是一个npm包")

### 国内替代方案（评论区）
- **博查API** — 无需代理，可直接用 (王磊评论)
- **Tavily MCP服务** — 更适配AI Agent（叶孤城fight 6986a54c ❤️837）
- **agent browser + playwright** — 直接用浏览器不需API
