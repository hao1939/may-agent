## Core Content
Author packages vibecoding expertise into a "front-end development expert Skill" for Coze 2.0's new Skill Store.

**Problem:** Non-technical users either (1) write enormous prompts with fonts/colors/layouts/animations → unstable results, or (2) generate with no guidance → generic "AI-looking" blue-purple output.

**Insight:** "What people lack is never the prompt — it's a method to turn IMPLICIT STANDARDS into STABLE OUTPUT." (把隐形标准变成稳定输出)

**Solution:** Package domain expertise as a Coze Skill. One-sentence request → non-AI-looking, maintainable, iterable frontend output.
