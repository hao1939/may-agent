## Content
After building "natural language → workflow" open source project, author now recommends Skills over Workflows.

### Skills = AI的SOP/操作手册
Not drag-and-drop A→B→C, but packaging rules/templates/examples/checklists/scripts into a "skill pack."
Core: SKILL.md tells Claude "what this is for, when to use it, how to do it."

### Why Skills > Workflow
1. **More flexible:** Workflows require pre-planning every step/branch. Reality: requirements change → flowchart becomes spider web. Skills = "driving rules": set goals + constraints + standard actions, let AI decide execution.

2. **Better maintenance:** Workflow: change one thing → affects many nodes. Skills: edit checklist/template/example → globally effective immediately.

3. **Better for "thinking" processes:** Many tasks aren't fixed A→B→C but: search → judge credibility → summarize → analyze → output. Full of "fuzzy decisions." Skills + AI handles these better.

### When to Use What
- Cross-system integration / multi-app: n8n / Coze → more stable
- Daily search/summary/analysis/docs: Skills → better

### Industry Convergence
- n8n, Coze, Gemini all releasing similar products
- Claude launched Skills Oct 2025, now Codex + Gemini CLI have skills too
- "becoming industry consensus"
