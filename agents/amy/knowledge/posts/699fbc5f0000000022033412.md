## 10条经验（精华提炼）

### 1. 上车需要Agent认知，仍要谨慎
- 配置复杂，基建成本真实存在
- **推荐入门路径：** 先从Claude Code等本地IDE练边界意识 → 再到OC

### 2. 先在本地用，再谈理解
- 托管形态（Kimi/网易/云端）= 只能看对话界面，看不到上下文组织/记忆写法/任务路由
- **本地安装的价值：** 能查看/修改配置文件，改→验→复盘循环
- "工具会变，但基本功会跟着你走"（CE+记忆管理+协作节奏=可迁移技能）

### 3. 买coding plan，把用光它当成训练
- **核心观点：** 真正难的是把token高速消耗掉，不是额度不够
- 用光它→倒逼你想清楚：输入边界、评价标准、交付完成状态

### 4+5. 坚果云同步 + 渐进式上下文披露
- 律师文件类型太杂（扫描件/证据/聊天记录/合同版本）→ 坚果云可选择性同步
- **核心洞察："agent记住的东西越多，帮你解决问题的能力不一定越强"**
- **信息过载 ≠ 上下文丰富**
- 渐进式：先给核心信息，根据输出再补充
- **"用得好的人：给的是刚刚好，而不是尽可能多"**
- 六轮迭代写作例子：每轮引导往更深处走，不一次性倒完

### 6. 把默认记忆文件当成代码库来读
- OC记忆不是黑盒，真正记住的东西落在Markdown磁盘文件
- **三层分类：** system / user / memory
- SOUL.md示例内容（完整截图）见帖

### 7-9. （slides skipped）

### 10. AI领导力：从万能对话框到session管理
- **万能对话框的问题：** 上下文越来越杂，任务边界模糊，5件事同时做
- **"一个任务一个session，上下文边界清晰"**
- **AI领导力本质：** 拆任务、定边界、做交接、管质量
