## 8个踩坑清单

### 坑1：config结构写错
appId/appSecret直接塞顶层，没有套`accounts`嵌套结构 → 插件读不到凭证
**每个插件结构不一样，看README**

### 坑2：飞书插件需要pnpm
```bash
npm install -g pnpm  # 先全局安装
```

### 坑3：用了Lark国际版 ⚠️
- Lark国际版**没有长连接模式**，只有webhook
- webhook需要公网地址 → 折腾Cloudflare Tunnel → 返回html不是json → 不行

### 坑4：社区插件只支持长连接
`@xzq-xu/feishu` **不支持webhook模式**，`connectionMode: "webhook"` 写了也白写

### 坑5：最终方案 ✅
**换回飞书国内版（个人账号，不需企业认证），长连接秒通**
"早换早解脱"

### 坑6：群消息权限没开
DM收到，群里一声不吭 → 原因：没开`im:message.group_msg`权限
（`im:message`还不够！**加了权限要重新发版**才生效）

### 坑7：requireMention放错层级（其实没用）
顶层写`requireMention: false`但群里还是必须@艾特
→ 对BatchProcessor不起作用，需要另开`autoReply`模式

### 坑8：autoReply放错层级
autoReply写在`groups`里不生效，**要放在`feishu`顶层**

## 评论热点
- "我添加了全部权限在群聊里面机器人依然收不到消息，排查一天了" ← 群权限还有其他坑
- "个人版不能拉群怎么解决" ← 额外限制
- "一条一条回复" vs "最后一股脑全发" ← 流式输出配置问题
