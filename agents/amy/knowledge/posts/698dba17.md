## 核心内容：4梯队安装路径

### 基础命令（4条走天下）
```bash
npm i -g clawhub          # 装技能市场（只需一次）
clawhub search "日历"     # 模糊搜索
clawhub install <名称>    # 装具体Skill
clawhub update --all      # 批量更新
```
**懒人通道：** 直接告诉AI"帮我装Gmail"，它自己跑命令 ✅

### 第一梯队·地基（5个必装，顺序严格）
1. ClawHub — 技能市场本体
2. **Agent Browser** — 网页自动化，"断它=断手"
3. **Brave Search** — 联网搜资料，免费API
4. **Shell** — 跑命令行，文件脚本全靠它
5. **Cron/Wake** — 定时任务，让AI主动找你

### 第二梯队·入口（选1个）
TG(个人首选) | 飞书(国内团队) | Slack(外企) | Discord(开源社区) | WhatsApp(海外)

### 第三/四梯队·按需加装
- 生产力：Gmail / Google Calendar / GitHub / Notion / Obsidian
- 进阶：Nodes(联动手机) / Skill Creator(自制) / Spotify / Home Assistant / Twitter(社媒监控)

### 三条保命建议
1. 别贪多：先5地基+1入口跑顺，两三天后再加
2. 权限即底线：Agent Browser/Shell越强风险越大 → 只装高下载量Skill，敏感操作开"确认模式"
3. 定期更新：`clawhub update --all`
