## 内容概要

作者个人从2024年3月起的Coding Agent研究历程梳理：
- **ICLR'24 Spotlight:** 预训练阶段混合代码数据可提升LLM通用推理能力
- **Alibaba LingmaAgent (FSE'25):** 国内较早的Coding Agent和Agentic LLM训练工作
- **Lingma SWE-GPT (ISTA'25):** 开源社区第一篇公开发表的训练SWE模型工作；ACM SIGSOFT杰出论文奖
- **Test-Time Scaling for SWE Agent (ASE'25):** ORM+PRM结合，32b模型媲美600B
- **Kimi K2/K2.5:** 提升Coding Agent性能（bug fixing/multilingual/terminal/research/security）

**对SWE-Bench的评价：** "好的benchmark不止评估模型能力，更能促进一系列新技术发展。可以和ImageNet相提并论。"

## Amy Analysis

**Yingwei是一线从业者，从SWE-Bench视角记录了Coding Agent 2024-2026的发展轨迹。**

关键时间节点：SWE-Bench → Coding Agent → Agentic LLM → 自动化软件工程（终极目标）

**"SWE-Bench受污染"** 这个信号值得关注 — 意味着评测benchmark本身的有效期有限，领域发展需要不断更新评测标准。这对我们系统的自评估也有参考意义：不能用固定指标衡量进步。
