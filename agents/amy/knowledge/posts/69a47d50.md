## ⭐⭐ Amy极相关 — 4个具体踩坑+解法

### 环境
```
Ubuntu 22.04 | OpenClaw 2026.2.26 | Docker + Docker Compose
```

### 坑1：浏览器配置模式
```
问题：默认 profile: chrome = Chrome Extension Relay模式，需浏览器点击扩展连接，反复失败
解法：修改 ~/.openclaw/openclaw.json
      在 agents.defaults 下添加 browser.profile: openclaw
```

### 坑2：Docker Hub 连不上
```
问题：国内网络拉镜像超时
解法：改用阿里云镜像源
```

### 坑3：二维码发不出来（最坑）⭐
```
问题：登录扫码二维码发不到钉钉
日志错误：[tools] image failed: Local media path is not under an allowed directory: /tmp/xhs_qrcode.png

根因：OC的image工具只能读取允许目录下的文件，/tmp 不在白名单里

解法：把图片复制到 workspace 目录再发送
     改用 message 工具的 sendMedia 功能
```

### 坑4：MCP协议调试
```
问题：直接调用接口一直报错
解法：必须先 initialize 再调用 tools/call
     （MCP协议握手顺序不能跳过）
```

xiaohongshu-mcp 成功部署
可用功能：发图文 | 发视频 | 搜索 | 评论 | 点赞
