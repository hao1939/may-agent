# May Skills

This directory contains specialized skills for the May agent.

- `breadcrumb-action.md` — act on red metrics before lower-priority work.
- `read-before-edit.md` — read a file before editing it.
- `verify-after-edit.md` — read back and structurally verify edits.
- `verify-before-finish.md` — verify before finishing a task.
- `blocked-capability-escalation/SKILL.md` — handle missing capabilities.
- `may-agent-system/SKILL.md` — maintain May-agent runtime, project apps,
  task trees, events, metrics, blockers, and escalation loops.
