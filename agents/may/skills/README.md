# May Skills

This directory contains specialized guidance for the May agent. Canonical
runtime-discovered skills use `<name>/SKILL.md`; loose Markdown files are legacy
notes and do not enter the skill catalog.

- `blocked-capability-escalation/SKILL.md` — handle missing capabilities.
- `may-agent-system/SKILL.md` — maintain May-agent runtime, project apps,
  task trees, events, metrics, blockers, and escalation loops.
