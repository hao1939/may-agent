**Root cause**: The previous 24h metric (2.4% interrupt rate) was misleadingly low. Looking at the 6h window reveals the problem concentrates in May and QA. When the system is busy (309 sessions today, on pace for 720), contention may further slow individual sessions.

**Mitigation**: This is likely a session-budget or timeout tuning issue, not a behavioral problem. Not within Coach's direct control — flagging for awareness.

### EXP-163 Ceiling Effect: Why Wasn't This Caught?

The design doc (H-161 test) should have predicted the ceiling. The product baseline for hidden-dep was already known to be high from EXP-154's data (4/34 overall, but the check breakdown would have shown 100% product pass). The design focused on overall pass rates without separating product vs process checks.

**Lesson**: Future experiment designs should require **product-only baseline verification** before committing to a scenario. If product baseline >80%, the scenario cannot measure intervention effects on quality.

## Emerging Patterns

### 1. The "Process vs Product" Distinction is Now Central

EXP-163 revealed that prior experiments were conflating process compliance (does the artifact exist?) with product quality (does the agent solve the task?). This distinction is critical:

- **Process effects**: Easy to achieve — any instruction that says "write X.md" will produce X.md
- **Product effects**: Hard to measure — need scenarios where the intervention actually changes the agent's reasoning quality

KE-178/179 show hard gates have huge *overall* effects (85-100pp), but we now know some of that effect may be definitional (the gate adds process checks that the gate itself satisfies). The true question is: **do hard gates improve product outcomes on scenarios where the agent fails without them?**

For `contradictory-requirements` (0% baseline → 100% with gate), the answer is clearly yes — the agent genuinely detects contradictions it would miss. For `hidden-dep`, the answer is no — the agent already finds both bugs.

### 2. Bob is Building the Next Generation of Scenarios

Bob's "recognition-layer" work is exactly what's needed post-EXP-163. The three-layer reasoning framework and new judgment scenarios address the scenario difficulty problem. If these new scenarios have baselines in the 30-70% range, they'll be viable for testing F1/F2 effects.

### 3. Guards Infrastructure is Converging with Research

Tech-lead's Guards-v2 implementation is advancing in parallel with the research program's conclusions about when to use gates. This is good alignment — by the time the deployment decision framework is ready, the infrastructure to deploy gates will exist.

### 4. Over-Intervention Cleanup is a Positive Signal

The system is now actively *removing* interventions that don't help, rather than only adding new ones. The evidence-over-narrative cleanup per KE-123 is a sign of maturity — knowing when NOT to intervene is as important as knowing when to intervene.
