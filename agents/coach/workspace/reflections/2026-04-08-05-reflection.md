## Deep Dive: KE-002 Reexamination (Coach Priority)

Hao's challenge to KE-002 deserves serious attention. Here's the analysis:

### The original KE-002 finding
- Tested 18 text-based instructions (conventions, rules, guidelines)
- 0/18 produced measurable behavioral improvement in gym scenarios
- Conclusion: text rules don't reliably change agent behavior

### Hao's counter-argument
- Text rules (system prompts, context.md, common-sense.md) ARE the primary method for guiding all agents
- Every agent operates based on text instructions — heartbeat prompts, role descriptions, skills
- If text rules truly didn't work, the entire agent system would be non-functional

### Possible reconciliation
1. **Scope mismatch**: KE-002 tested narrow compliance rules ("always verify before submitting"). Maybe text rules work for general guidance (role, approach, tone) but not for specific behavioral compliance. The distinction: text rules set the FRAME, not the GUARDRAILS.
2. **Measurement gap**: The gym scenarios may have been too narrow — testing if an agent follows a specific instruction vs. testing if an agent adopts a working philosophy.
3. **Base rate problem**: Agents may already follow many text rules as baseline behavior (because the LLM was trained on them). The experiment tested INCREMENTAL text rules, not foundational ones.
4. **Type confusion**: There are different types of text rules: (a) identity/role instructions ("you are a supervisor"), (b) procedural instructions ("always commit before finish"), (c) preference instructions ("prefer fork over message"), (d) skill/technique instructions ("use obstacle-pivot when stuck"). KE-002 may only apply to type (b) and (c), not (a) and (d).

### Required action
Design EXP-XXX to reexamine KE-002 with:
- Broader categories of text rules tested
- Larger scenario set
- Metrics that capture both compliance AND quality
- Comparison: foundation rules (role, approach) vs compliance rules (do X before Y)
