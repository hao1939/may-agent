### RCA-2: Supervisor Should Not Source Env (Input #2)

**What happened**: Hao corrected a design where the supervisor process sources the environment. The supervisor should just start may-agent, which sources its own env.

**Why it matters**: This is a separation-of-concerns correction. The supervisor is a lightweight process launcher, not the runtime. The may-agent binary owns its own environment setup.

**Root cause**: An agent (likely tech-lead or optimizer) conflated the supervisor and the application when designing or implementing the startup flow. This is a common architectural mistake: putting initialization logic in the wrong layer.

**Impact on Coach**: Low direct impact. But this connects to a pattern: agents don't always understand layered architecture well. When they implement infra changes, they tend to merge concerns that should be separate.
